**Goal:** Ship exactly what a remote `script`, `tool_call` or `agent_call` step needs — a content-addressed script bundle, rendered args, server-resolved node env, passthrough names, the canonical workspace and a secret-free agent descriptor — and let the hub dispatch those ops.

**Architecture:** `adapter/process.BuildScriptBundle` packs the resolved script folder (workflow folder or `@lib` scope folder as returned by `FileReader.ResolvePath`) into a deterministic tar.gz addressed by its SHA-256; `ScriptExecutor` stores it in a `runner.BundleStore` (filesystem adapter `adapter/checkpoint/bundles.go`) and stamps `ProcessSpec.Bundle`; `ToolCallExecutor` runs in `{{workspace}}` on every runner. The hub turns `StepJob.Process` / `StepJob.Agent` into domain `ProcessDispatch` / `AgentDispatch` / `WorkspaceDispatch` mirrors (pull plan + transfer tokens from the task 6/7 services) and `adapter/http` translates them to the new `runnerproto` payloads.

**Tech Stack:** Go 1.25.5, stdlib `archive/tar` + `compress/gzip` + `crypto/sha256`, testify, `nhooyr.io/websocket` (unchanged).

**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` (Execution and placement: "Scripts and workspace-based tools run with that workspace"); `docs/designs/2026-11-19-remote-runners-design-phase-3.md` §3.4 (script bundles and remote process steps), §5 rows "Resolved script path…", "Variables/script stdin…", "Passthrough names…", §8 Edge-case ("A lib script finds its siblings on a remote runner", "Passthrough env values come from the runner") and Checkpoint/ownership regressions ("workspace-relative tool commands use the workspace cwd"). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §5 (ProcessSpec / ScriptBundleRef), §11 (StepJob/StepOutput/Assignment), §15 (runnerproto, Hub), §16 (Bundles, transfer tokens, sync).

DECISION (2026-11-22, RR-09, outside-bundle dependencies): **remote placement of process nodes is an explicit author opt-in.**
- **Default:** script and `tool_call` nodes are `AffinityBuiltIn` (unbundled, exactly today's behaviour) unless the workflow author sets `portable: true` (new `workflow.NodeConfig.Portable`, JSON/YAML `portable`).
- **What `portable: true` asserts:** the process needs only (a) its own script folder, which is bundled; (b) the run's workspace, which is checkpointed; (c) the interpreter/command and the declared `requires` commands, checked on the runner per the DECISION below.
- **Unbundleable portable script:** a `portable: true` script whose folder cannot be bundled (absolute or escaping symlink, device/socket/FIFO, more than 128 MiB) is a **workflow validation error at load/save/validate time** (code `SCRIPT_NOT_PORTABLE`), never a silent built-in fallback.
- **Files changed after load:** if a portable script's folder stops being bundleable after validation, `ScriptExecutor` fails that step visibly with the bundle error. It is never silently downgraded.
- **Unflagged scripts** are never bundled, never placed remotely, and their outside references keep working on the built-in runner.
- **Non-Goal:** transferring or declaring dependencies that live outside the script folder (no dependency manifest). Authors move shared files into the script folder or the workspace.
- **Field producer:** Cycle 0 below.
- **Remote failures:** a portable script that still reads undeclared outside paths at run time fails on the remote runner with its own error. That is the author's assertion being wrong, and it is surfaced visibly.

DECISION (2026-11-22, RR-09, process capability policy): **command names only, checked on the runner at accept time, with a built-in fallback.**
- **Declaration:** script and `tool_call` nodes may declare `requires: [jq, git, node]` (new `workflow.NodeConfig.Requires []string`), validated at load:
  - each entry is a non-empty bare command name with no `/`, `\` or whitespace, and no duplicates (code `INVALID_REQUIRES`);
  - `requires` on a node without `portable: true` is a validation error (code `REQUIRES_WITHOUT_PORTABLE`).
- **Transport:** `engine.ProcessSpec` gains `Portable bool` and `Requires []string`, stamped by `ScriptExecutor`/`ToolCallExecutor` from the node config. They travel in `ProcessDispatch.Requires` and `runnerproto.WireProcess.Requires` (JSON `requires`).
- **Accept check (P3 T9):** before accepting, the runner runs `exec.LookPath` on the interpreter/command plus every `Requires` entry, against the `PATH` of its own locally built process environment. The first miss rejects with reject code `command_unavailable` and reason `command_unavailable: <name>`. No capability inventory is advertised in `hello`.
- **Re-placement (P3 T6/T13 "Preparation rejection mapping"):**
  - the rejecting runner is excluded for that step attempt, and the dispatcher tries the next eligible remote runner;
  - when no remote candidate remains, the step is placed on the **built-in runner**, which always accepts a process step and runs it exactly as today, even if the command is missing there (the step then fails with the process's own error, as today);
  - capability checks never park, wait or fail a step on their own.
- **Non-Goal:** command version constraints. A version mismatch surfaces as the script's own error.

// adapter/process/bundle.go
package process

import (
	"archive/tar"
	"bytes"
	"compress/gzip"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
)

// MaxBundleBytes bounds the uncompressed regular-file content of one script
// bundle. A larger portable script folder is a load-time validation error (RR-09 decision 2026-11-22).
const MaxBundleBytes int64 = 128 << 20

var (
	// ErrBundleOutsideReference: the folder holds a symlink that is absolute or
	// leaves the folder. Such content cannot be shipped to another machine (RR-09).
	ErrBundleOutsideReference = errors.New("script bundle: content references a path outside the script folder (RR-09)")
	// ErrBundleUnsupportedFile: devices, sockets, FIFOs and other special files.
	ErrBundleUnsupportedFile = errors.New("script bundle: unsupported file type")
	// ErrBundleTooLarge: the folder exceeds MaxBundleBytes.
	ErrBundleTooLarge = errors.New("script bundle: script folder exceeds the bundle size cap")
	// ErrBundleUnsafeEntry: an archive entry would write outside the extraction
	// directory, or has an unsupported type. Extraction stops.
	ErrBundleUnsafeEntry = errors.New("script bundle: unsafe archive entry")
)

// bundleEpoch is the fixed modification time of every archive entry, so two
// builds of identical content are byte-identical regardless of file mtimes.
var bundleEpoch = time.Unix(0, 0).UTC()

type bundleItem struct {
	rel  string // slash-separated, relative to the bundle root
	full string
	info fs.FileInfo
	link string
}

// BuildScriptBundle packs the folder holding scriptPath (the resolved path
// returned by FileReader.ResolvePath: a workflow folder or the @lib scope
// folder) into a deterministic tar.gz and returns its content address. The
// entrypoint is the script's name relative to that folder; the original
// absolute server path is never part of the bundle reference.
func BuildScriptBundle(scriptPath string) (engine.ScriptBundleRef, []byte, error) {
	if !filepath.IsAbs(scriptPath) {
		return engine.ScriptBundleRef{}, nil, fmt.Errorf("script bundle: %q is not an absolute resolved path", scriptPath)
	}
	info, err := os.Lstat(scriptPath)
	if err != nil {
		return engine.ScriptBundleRef{}, nil, fmt.Errorf("script bundle: entrypoint: %w", err)
	}
	if !info.Mode().IsRegular() {
		return engine.ScriptBundleRef{}, nil, fmt.Errorf("script bundle: entrypoint %q is not a regular file", scriptPath)
	}
	root := filepath.Dir(scriptPath)

	var items []bundleItem
	var total int64
	walkErr := filepath.WalkDir(root, func(p string, _ fs.DirEntry, werr error) error {
		if werr != nil {
			return werr
		}
		if p == root {
			return nil
		}
		rel, err := filepath.Rel(root, p)
		if err != nil {
			return err
		}
		fi, err := os.Lstat(p)
		if err != nil {
			return err
		}
		it := bundleItem{rel: filepath.ToSlash(rel), full: p, info: fi}
		switch mode := fi.Mode(); {
		case mode.IsRegular():
			total += fi.Size()
			if total > MaxBundleBytes {
				return fmt.Errorf("%w (%d bytes)", ErrBundleTooLarge, MaxBundleBytes)
			}
		case mode.IsDir():
		case mode&fs.ModeSymlink != 0:
			target, err := os.Readlink(p)
			if err != nil {
				return err
			}
			if filepath.IsAbs(target) || escapesRoot(filepath.Dir(rel), target) {
				return fmt.Errorf("%w: %s -> %s", ErrBundleOutsideReference, it.rel, target)
			}
			it.link = filepath.ToSlash(target)
		default:
			return fmt.Errorf("%w: %s (%s)", ErrBundleUnsupportedFile, it.rel, mode.Type())
		}
		items = append(items, it)
		return nil
	})
	if walkErr != nil {
		return engine.ScriptBundleRef{}, nil, walkErr
	}
	sort.Slice(items, func(i, j int) bool { return items[i].rel < items[j].rel })

	var buf bytes.Buffer
	zw, err := gzip.NewWriterLevel(&buf, gzip.BestCompression)
	if err != nil {
		return engine.ScriptBundleRef{}, nil, err
	}
	tw := tar.NewWriter(zw)
	for _, it := range items {
		if err := writeBundleEntry(tw, it); err != nil {
			return engine.ScriptBundleRef{}, nil, err
		}
	}
	if err := tw.Close(); err != nil {
		return engine.ScriptBundleRef{}, nil, err
	}
	if err := zw.Close(); err != nil {
		return engine.ScriptBundleRef{}, nil, err
	}
	sum := sha256.Sum256(buf.Bytes())
	return engine.ScriptBundleRef{
		Hash:       hex.EncodeToString(sum[:]),
		Entrypoint: filepath.ToSlash(filepath.Base(scriptPath)),
	}, buf.Bytes(), nil
}

// escapesRoot reports whether a relative link target, resolved from the
// link's own directory (relative to the root), leaves the root.
func escapesRoot(linkDir, target string) bool {
	resolved := filepath.Clean(filepath.Join(linkDir, target))
	return resolved == ".." || strings.HasPrefix(resolved, ".."+string(filepath.Separator))
}

func writeBundleEntry(tw *tar.Writer, it bundleItem) error {
	hdr := &tar.Header{
		Name:    it.rel,
		Mode:    int64(it.info.Mode().Perm()),
		ModTime: bundleEpoch,
		Format:  tar.FormatPAX,
	}
	switch {
	case it.info.IsDir():
		hdr.Typeflag = tar.TypeDir
		hdr.Name += "/"
	case it.link != "":
		hdr.Typeflag = tar.TypeSymlink
		hdr.Linkname = it.link
		hdr.Mode = 0o777
	default:
		hdr.Typeflag = tar.TypeReg
		hdr.Size = it.info.Size()
	}
	if err := tw.WriteHeader(hdr); err != nil {
		return err
	}
	if hdr.Typeflag != tar.TypeReg {
		return nil
	}
	f, err := os.Open(it.full)
	if err != nil {
		return err
	}
	defer f.Close()
	n, err := io.Copy(tw, f)
	if err != nil {
		return err
	}
	if n != hdr.Size {
		return fmt.Errorf("script bundle: %s changed size while bundling", it.rel)
	}
	return nil
}

// ExtractScriptBundle unpacks a bundle produced by BuildScriptBundle into dst
// (which must exist). Entries that are absolute, contain "..", are links
// leaving dst, or are not dir/regular/symlink fail with ErrBundleUnsafeEntry.
func ExtractScriptBundle(r io.Reader, dst string) error {
	zr, err := gzip.NewReader(r)
	if err != nil {
		return fmt.Errorf("script bundle: %w", err)
	}
	defer zr.Close()
	tr := tar.NewReader(zr)
	var total int64
	for {
		hdr, err := tr.Next()
		if errors.Is(err, io.EOF) {
			return nil
		}
		if err != nil {
			return fmt.Errorf("script bundle: %w", err)
		}
		name := strings.TrimSuffix(hdr.Name, "/")
		if name == "" || path.IsAbs(name) || path.Clean(name) != name || name == ".." || strings.HasPrefix(name, "../") {
			return fmt.Errorf("%w: %q", ErrBundleUnsafeEntry, hdr.Name)
		}
		target := filepath.Join(dst, filepath.FromSlash(name))
		if err := os.MkdirAll(filepath.Dir(target), 0o755); err != nil {
			return err
		}
		mode := os.FileMode(hdr.Mode).Perm()
		switch hdr.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(target, 0o755); err != nil {
				return err
			}
			if err := os.Chmod(target, mode|0o700); err != nil {
				return err
			}
		case tar.TypeReg:
			total += hdr.Size
			if total > MaxBundleBytes {
				return fmt.Errorf("%w: archive exceeds %d bytes", ErrBundleUnsafeEntry, MaxBundleBytes)
			}
			f, err := os.OpenFile(target, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, mode)
			if err != nil {
				return err
			}
			if _, err := io.CopyN(f, tr, hdr.Size); err != nil {
				f.Close()
				return err
			}
			if err := f.Close(); err != nil {
				return err
			}
			if err := os.Chmod(target, mode); err != nil {
				return err
			}
		case tar.TypeSymlink:
			if path.IsAbs(hdr.Linkname) || escapesRoot(filepath.Dir(filepath.FromSlash(name)), filepath.FromSlash(hdr.Linkname)) {
				return fmt.Errorf("%w: link %q -> %q", ErrBundleUnsafeEntry, hdr.Name, hdr.Linkname)
			}
			if err := os.Symlink(filepath.FromSlash(hdr.Linkname), target); err != nil {
				return err
			}
		default:
			return fmt.Errorf("%w: %q has type %c", ErrBundleUnsafeEntry, hdr.Name, hdr.Typeflag)
		}
	}
}

// domain/runner/bundles.go
package runner

import (
	"context"
	"errors"
	"io"

	"github.com/arbitron/arbitron/domain/engine"
)

// BundleStore holds content-addressed script bundles (D9). The server writes a
// bundle at dispatch; runners download it through the bundle transfer route.
type BundleStore interface {
	// Put stores data under ref.Hash; it verifies sha256(data) == ref.Hash and
	// is idempotent for identical content.
	Put(ctx context.Context, ref engine.ScriptBundleRef, data []byte) error
	// Open returns the bundle bytes; ErrBundleNotFound when absent or when hash
	// is not a canonical 64-character lower-case hex digest.
	Open(ctx context.Context, hash string) (io.ReadCloser, error)
	Has(ctx context.Context, hash string) (bool, error)
}

var (
	ErrBundleNotFound     = errors.New("runner: script bundle not found")
	ErrBundleHashMismatch = errors.New("runner: script bundle content does not match its hash")
)

// ValidBundleHash reports whether h is a canonical lower-case SHA-256 hex digest.
func ValidBundleHash(h string) bool {
	if len(h) != 64 {
		return false
	}
	for _, c := range h {
		if (c < '0' || c > '9') && (c < 'a' || c > 'f') {
			return false
		}
	}
	return true
}

// BundleStore is the filesystem runner.BundleStore: <dir>/<hash>.tar.gz,
// written via temp file + rename so a reader never sees a partial bundle.
type BundleStore struct{ dir string }

var _ runner.BundleStore = (*BundleStore)(nil)

// NewBundleStore creates dir (0700) if needed.
func NewBundleStore(dir string) (*BundleStore, error) {
	if dir == "" {
		return nil, errors.New("checkpoint: bundle directory is required")
	}
	if err := os.MkdirAll(dir, 0o700); err != nil {
		return nil, fmt.Errorf("checkpoint: bundle directory: %w", err)
	}
	return &BundleStore{dir: dir}, nil
}

func (s *BundleStore) path(hash string) string { return filepath.Join(s.dir, hash+".tar.gz") }

func (s *BundleStore) Put(_ context.Context, ref engine.ScriptBundleRef, data []byte) error {
	if !runner.ValidBundleHash(ref.Hash) {
		return fmt.Errorf("%w: malformed hash", runner.ErrBundleHashMismatch)
	}
	sum := sha256.Sum256(data)
	if hex.EncodeToString(sum[:]) != ref.Hash {
		return runner.ErrBundleHashMismatch
	}
	if _, err := os.Stat(s.path(ref.Hash)); err == nil {
		return nil
	}
	tmp, err := os.CreateTemp(s.dir, ".bundle-*")
	if err != nil {
		return err
	}
	defer os.Remove(tmp.Name())
	if _, err := tmp.Write(data); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Sync(); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Close(); err != nil {
		return err
	}
	return os.Rename(tmp.Name(), s.path(ref.Hash))
}

func (s *BundleStore) Open(_ context.Context, hash string) (io.ReadCloser, error) {
	if !runner.ValidBundleHash(hash) {
		return nil, runner.ErrBundleNotFound
	}
	f, err := os.Open(s.path(hash))
	if errors.Is(err, fs.ErrNotExist) {
		return nil, runner.ErrBundleNotFound
	}
	return f, err
}

func (s *BundleStore) Has(_ context.Context, hash string) (bool, error) {
	if !runner.ValidBundleHash(hash) {
		return false, nil
	}
	_, err := os.Stat(s.path(hash))
	if errors.Is(err, fs.ErrNotExist) {
		return false, nil
	}
	return err == nil, err
}
