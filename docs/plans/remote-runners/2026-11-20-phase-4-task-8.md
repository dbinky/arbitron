## Alignment correction — durable move state and complete ownership fence

Consume P4 T6's corrected atomic receipt contract and P4 T3's committed `AcceptedTurnBinding`; do not resolve current profile/defaults during a move. P4 T11's resource descriptor replaces every `BuiltInOnly` path. Missing account fingerprint is optional evidence; conservative persisted loss notices plus native-resume fallback satisfy required continuity without it.

Extend `SessionMoveCommit` with `Lease engine.TurnLease`, `InvocationID uuid.UUID`, `IntentID uuid.UUID`, `Resource engine.ResourceFenceRef`, `Completions []engine.StepCompletion`, and expected prior checkpoint/turn. `sqlite.SessionMoveRepo.CommitMove` validates those exact records in the SAME transaction as pin/session-id/move history publication; comparing only `m.Generation > stored_generation` is insufficient. `RecordSessionMove` remains an internal transaction helper. A stale mover cannot commit after another holder takes the lease, even if its generation numerically exceeds the previous row.

A move is a durable operation, not a sequence that can be abandoned after BumpGeneration/HandOff. This task adds `session_moves` state `preparing|restoring|importing|committed|failed`, old/new owner/resource fences, turn intent ID and target checkpoint/candidate. Persist the move intent and reserved target before effects; retry the same move ID/target/generation on restart. Fence/stop old owner using P3 resource handoff rules before target writes; source/local directory restore runs only while its exact resource ownership permits it. Failed import goes to rebuild; transfer/disk failure stays visible and retryable. Never leave a bumped lease paired with an old untracked pin. Only committed moves emit `session.moved`; the durable move/notice becomes idempotent by move ID. Target import failure must never leave its slot/lease active indefinitely.

`PendingRebuild` is stored with original prompt/nonce/transcript and accepted binding. Native import's first actual resume is marked provisional in committed session metadata. P4 T9 handles a deterministic resume rejection once by restoring the exact last successful workspace, clearing partial output, rebuilding and resending the same pending message. Transient/congestion/exhaustion retain their structured retry/move semantics. This closes RR-13/RR-14 without account-ID heuristics. A move between user turns can commit an imported/provisional or pending-rebuild pin without starting an invented user turn; the next accepted turn consumes that state automatically.

**Goal:** Move a pinned interactive session to another runner of the SAME model group under the caller's held turn lease: fence the old owner, bump the session generation, restore the last committed workspace, import the latest session bundle on the target (or fall back to a transcript rebuild with a visible loss notice), and commit the new pin + generation atomically with a `session_moves` row.

**Architecture:** `domain/engine/session_mover.go` declares the engine-side port (`engine.SessionMover`, mirror request/result types, move reasons, rebuild prompt builder, loss notice) so `domain/engine` never imports `domain/runner`. `domain/runner/session_mover.go` implements it on top of the Phase 1 placement/ledger, Phase 3 homes/workspace restore and Phase 4 lease/checkpoint stores; the import runs as a fenced ledger job with `Op = session_import` on the target `StepRunner` (built-in: in-process via `SessionPortabilityRegistry`; remote: Phase 4 Task 12). `adapter/sqlite/session_move_repo.go` commits the pin/generation/session-id update and the `session_moves` row in ONE transaction, fenced on the previous generation.

**Tech Stack:** Go 1.25.5, `database/sql` + modernc SQLite (`json_patch`), testify, google/uuid.

**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` (Recovery and session continuity: "Session moves preserve full available conversation context where supported…", "only one active execution owner"); `docs/designs/2026-11-19-remote-runners-design-phase-4.md` §3.5 (Session mover), §3.1 (import/rebuild), §4 (exhausted turn steps 3–6), §7 (error handling: import failure → rebuild, oversized rebuild, no eligible target, stale generation, loss notices), §8. **Decisions (unstick 2026-11-24, recorded in contracts "Decisions (unstick 2026-11-24)").**
- **(b) Target never returns.** Once an open move's persisted target is gone (lost, which includes revoked, or offline, or unregistered; suspect is still inside the grace), the move is FAILED, never retried on that target. A NEW move replaces it, and its extra generation bump is accepted. `Move` plans the replacement in the same call. After `ResumeMove` fails the move, the P4 T10 controller starts the replacement. See Cycle 3d.
- **(c) `session.moved` lost after a commit crash.** It is announced at most once; the committed `session_moves` row is the record (Cycle 3b assumption (e)).
- **(d) Native resume refused.** The mover stays move-only. P4 T9 writes its OWN fenced conversation patch for the provisional-resume fallback (P4 T9 Cycle 3b). The mover only sets the provisional marker on commit.

// domain/engine/session_mover.go
package engine

import (
	"context"
	"errors"
	"fmt"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/provider"
	"github.com/google/uuid"
)

// Move reasons. A session moves ONLY for these (design P4 §3.4): never for
// load, cordon, suspect status, a full slot limit or transient congestion.
const (
	MoveReasonExhausted  = "exhausted"
	MoveReasonLoggedOut  = "logged_out"
	MoveReasonDrain      = "drain"
	MoveReasonRunnerLost = "runner_lost"
)

// AllowedMoveReason reports whether reason authorizes a session move.
func AllowedMoveReason(reason string) bool {
	switch reason {
	case MoveReasonExhausted, MoveReasonLoggedOut, MoveReasonDrain, MoveReasonRunnerLost:
		return true
	}
	return false
}

// SessionLossNotice is the persisted, user-visible notice for every lossy move.
const SessionLossNotice = "tool details and reasoning may be lost"

// ConversationKeyPendingRebuild marks a session whose native bundle could not be
// restored: the NEXT turn starts a fresh provider session whose prompt is
// BuildRebuildPrompt(conversation, message). Cleared by the next successful turn.
const ConversationKeyPendingRebuild = "pendingRebuild"

// SessionMoveRequest mirrors runner.MoveRequest so domain/engine never imports
// domain/runner. Binding carries the exact accepted model/route/backend/tools.
type SessionMoveRequest struct {
	RunID, InvocationID, ExecutionID uuid.UUID
	NodeID                           string
	TurnIndex                        int
	Reason                           string
	From                             string
	Binding                          provider.ResolvedBinding
	WorkDir                          string
	ResourceID                       uuid.UUID
	RestoreWorkspace                 bool
	FirstTurn                        bool

    RequestID uuid.UUID
}

// SessionMoveResult mirrors runner.MoveResult. Generation is the session
// generation reserved by the move; the caller adopts it into its held lease.
type SessionMoveResult struct {
	To             string
	SessionID      string
	Lossy          bool
	Notice         string
	Generation     int64
	PendingRebuild bool
}

// SessionMover moves a pinned session while the caller HOLDS lease. It never
// acquires the lease itself (a mover called within a turn reuses the token).
type SessionMover interface {
	MoveSession(ctx context.Context, lease TurnLease, req SessionMoveRequest) (SessionMoveResult, error)
}

var (
	ErrSessionMoveNotAllowed = errors.New("engine: a session moves only for exhaustion, logout, drain or runner loss")
	ErrNoSessionTarget       = errors.New("engine: no eligible runner for the session's model group")
	ErrSessionRestoreFailed  = errors.New("engine: session restoration failed")
	ErrRebuildTooLarge       = errors.New("engine: recorded conversation exceeds the target context window; refusing to truncate")
)

// SessionWaitError is the visible wait a move reports when no same-group target
// is eligible (Kind "capacity") or every eligible target is full (Kind "slot").
type SessionWaitError struct {
	Kind      string
	Group     string
	Model     string
	NextReset *time.Time
}

func (e *SessionWaitError) Error() string {
	msg := fmt.Sprintf("session waiting for %s: group %s model %s", e.Kind, e.Group, e.Model)
	if e.NextReset != nil {
		msg += " next reset " + e.NextReset.UTC().Format(time.RFC3339)
	}
	return msg
}

// Is makes errors.Is(err, ErrNoSessionTarget) true.
func (e *SessionWaitError) Is(target error) bool { return target == ErrNoSessionTarget }

// RebuildLimitBytes bounds a transcript rebuild prompt for the binding's context
// window: tokens x 3 bytes/token x 0.8 (room for the reply). Never truncates.
func RebuildLimitBytes(cw provider.ContextWindow) int {
	if cw == provider.Context1M {
		return 2_400_000
	}
	return 480_000
}

const (
	rebuildTranscriptHeader = "The conversation so far, as recorded by Arbitron (earlier tool details and reasoning are not included):"
	rebuildContinueFooter   = "Continue this conversation from here. The user's next message follows."
)

// BuildRebuildPrompt renders the fresh-session primer: the ORIGINAL first prompt
// verbatim (it embeds the completion sentinel and its nonce), every later
// recorded message in order, then nextMessage. limitBytes <= 0 disables the
// bound. An oversized result is ErrRebuildTooLarge — never truncated.
func BuildRebuildPrompt(conv map[string]any, nextMessage string, limitBytes int) (string, error) {
	msgs := parseConversation(conv)
	if len(msgs) == 0 {
		return "", fmt.Errorf("%w: no recorded first prompt", ErrSessionRestoreFailed)
	}
	first, _ := msgs[0]["content"].(string)
	if strings.TrimSpace(first) == "" {
		return "", fmt.Errorf("%w: recorded first prompt is empty", ErrSessionRestoreFailed)
	}
	var b strings.Builder
	b.WriteString(first)
	if len(msgs) > 1 {
		b.WriteString("\n\n")
		b.WriteString(rebuildTranscriptHeader)
		b.WriteString("\n")
		for _, m := range msgs[1:] {
			role, _ := m["role"].(string)
			content, _ := m["content"].(string)
			fmt.Fprintf(&b, "\n[%s]\n%s\n", role, content)
		}
	}
	b.WriteString("\n")
	b.WriteString(rebuildContinueFooter)
	b.WriteString("\n\n")
	b.WriteString(nextMessage)
	if limitBytes > 0 && b.Len() > limitBytes {
		return "", fmt.Errorf("%w: %d bytes exceeds %d", ErrRebuildTooLarge, b.Len(), limitBytes)
	}
	return b.String(), nil
}

// recordSessionMoveTx is RecordSessionMove's body on a caller's transaction:
// the invocation-scoped pin/generation CAS (stored generation < m.Generation,
// same run/node, session invocation unset or equal), then the move row.
func recordSessionMoveTx(ctx context.Context, q sqlExecQuerier, execID uuid.UUID, m instance.SessionMoveRecord) error {
	res, err := q.ExecContext(ctx, `UPDATE node_executions SET session_pin_runner = ?, session_generation = ?, session_invocation_id = ?
WHERE id = ? AND instance_id = ? AND node_id = ? AND session_generation < ?
AND (session_invocation_id IS NULL OR session_invocation_id = ? OR session_invocation_id = ?)`, m.ToRunner, m.Generation, uuidToString(m.InvocationID), uuidToString(execID), uuidToString(m.RunID), m.NodeID, m.Generation, uuidToString(uuid.Nil), uuidToString(m.InvocationID))
	if err != nil {
		return fmt.Errorf("recording session move: %w", err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return fmt.Errorf("recording session move: %w", err)
	}
	if n != 1 {
		return missingOrStale(ctx, q, execID)
	}
	lossy := 0
	if m.Lossy {
		lossy = 1
	}

func NewSessionMover(d MoverDeps) *SessionMover {

// MoveSession adapts the engine port: it derives the exact model group and
// requirements from the accepted binding (same family only, GroupFor).
func (m *SessionMover) MoveSession(ctx context.Context, lease engine.TurnLease, req engine.SessionMoveRequest) (engine.SessionMoveResult, error) {
	group, err := GroupFor(req.Binding, OpType("stream"))
	if err != nil {
		return engine.SessionMoveResult{}, fmt.Errorf("session move: %w", err)
	}
	res, err := m.Move(ctx, lease, MoveRequest{
		RunID: req.RunID, InvocationID: req.InvocationID, NodeID: req.NodeID, Reason: req.Reason, From: RunnerID(req.From),
		Requirements: ExecRequirements{Group: group, Model: req.Binding.Model, Backend: req.Binding.Backend,
			RequireExecutedModel: req.Binding.RequiresModelEvidence(), Tools: req.Binding.AllowedTools},
		ExecutionID: req.ExecutionID, TurnIndex: req.TurnIndex, Binding: req.Binding, WorkDir: req.WorkDir,
		ResourceID: req.ResourceID, RestoreWorkspace: req.RestoreWorkspace, FirstTurn: req.FirstTurn,
	})
	if err != nil {
		return engine.SessionMoveResult{}, err
	}
	return engine.SessionMoveResult{To: string(res.To), SessionID: res.SessionID, Lossy: res.Lossy, Notice: res.Notice,
		Generation: res.Generation, PendingRebuild: res.PendingRebuild}, nil
}

// Move runs the move under the caller's HELD lease (never re-acquired).
func (m *SessionMover) Move(ctx context.Context, lease engine.TurnLease, req MoveRequest) (MoveResult, error) {
	if !engine.AllowedMoveReason(req.Reason) {
		return MoveResult{}, fmt.Errorf("session move %q: %w", req.Reason, engine.ErrSessionMoveNotAllowed)
	}
	if req.FirstTurn {
		return m.moveFirstTurn(ctx, lease, req)
	}
	exec, err := m.loadExecution(ctx, req.RunID, req.ExecutionID)
	if err != nil {
		return MoveResult{}, err
	}
	placeReq := req.Requirements
	placeReq.Op, placeReq.Affinity, placeReq.RunID, placeReq.PinnedRunner = OpType("stream"), AffinitySession, req.RunID, ""
	jobReq := placeReq
	jobReq.Op = OpSessionImport
	key := JobKey{RunID: req.RunID, InvocationID: req.InvocationID, OperationID: fmt.Sprintf("session-move/%d", lease.Generation), Attempt: 1}
	job, err := m.d.Ledger.EnsureIntent(ctx, key, req.NodeID, jobReq)
	if err != nil {
		return MoveResult{}, fmt.Errorf("session move: record intent: %w", err)
	}

	snap, err := m.d.Registry.Snapshot(ctx)
	if err != nil {
		return MoveResult{}, fmt.Errorf("session move: pool snapshot: %w", err)
	}
	if m.d.Telemetry != nil {
		snap.Telemetry = m.d.Telemetry.Latest()
	}
	snap.Now = m.d.Clock()
	dec := Place(placeReq, snap, m.d.Policy)
	if !dec.Placed {
		return MoveResult{}, m.visibleWait(ctx, job, dec.Wait, placeReq)
	}

	if err := m.fenceOldOwner(ctx, req); err != nil {
		return MoveResult{}, err
	}
	lease, err = m.d.Leases.BumpGeneration(ctx, lease)
	if err != nil {
		return MoveResult{}, fmt.Errorf("session move: reserve session generation: %w", err)
	}
	job, err = m.d.Ledger.Reserve(ctx, job.ID, dec, stepLimitOf(snap, dec.Runner), m.d.Clock().Add(m.d.OpLease))
	if errors.Is(err, ErrSlotTaken) {
		return MoveResult{}, &engine.SessionWaitError{Kind: "slot", Group: placeReq.Group.String(), Model: placeReq.Model}
	}
	if err != nil {
		return MoveResult{}, fmt.Errorf("session move: reserve target %s: %w", dec.Runner, err)
	}
	fence := Fence{JobID: job.ID, RunnerID: job.RunnerID, Generation: job.Generation}
	m.d.Status.Publish(ctx, job, instance.ExecutionState("recovering"))
	if err := m.d.Ledger.MarkRunning(ctx, fence); err != nil {
		return MoveResult{}, fmt.Errorf("session move: mark running: %w", err)
	}
	if req.RestoreWorkspace {
		if err := m.restoreWorkspace(ctx, req, dec.Runner); err != nil {
			_ = m.d.Ledger.Fail(ctx, fence, OutcomeOther)
			return MoveResult{}, fmt.Errorf("session move: restore committed workspace: %w: %v", engine.ErrSessionRestoreFailed, err)
		}
	}
	sessionID, rebuilt, err := m.importOrRebuild(ctx, Assignment{Job: job, Fence: fence}, req, exec)
	if err != nil {
		_ = m.d.Ledger.Fail(ctx, fence, OutcomeOther)
		return MoveResult{}, err
	}
	if err := m.d.Ledger.Complete(ctx, fence, ""); err != nil {
		return MoveResult{}, fmt.Errorf("session move: complete import job: %w", err)
	}

	lossy := rebuilt || m.alwaysLossy(req) || dec.Source != previousSource(exec)
	notice := ""
	if lossy {
		notice = engine.SessionLossNotice
	}
	rec := SessionMoveCommit{
		ExecutionID: req.ExecutionID, SessionID: sessionID, PendingRebuild: rebuilt,
		Move: instance.SessionMoveRecord{
			ID: uuid.New(), RunID: req.RunID, InvocationID: req.InvocationID, NodeID: req.NodeID,
			FromRunner: string(req.From), ToRunner: string(dec.Runner), Reason: req.Reason, Lossy: lossy, Notice: notice,
			Generation: lease.Generation, At: m.d.Clock().UTC(),
		},
	}
	if err := m.d.Moves.CommitMove(ctx, rec); err != nil {
		return MoveResult{}, fmt.Errorf("session move: commit: %w", err)
	}
	runID := req.RunID
	m.d.Events.Record(ctx, PoolEvent{
		ID: uuid.New(), At: rec.Move.At, Kind: engine.EventTypeSessionMoved, RunnerID: dec.Runner, SourceID: dec.Source, RunID: &runID,
		Cause:  Cause{Kind: causeKindFor(req.Reason), Outcome: outcomeFor(req.Reason)},
		Detail: map[string]any{"from": string(req.From), "to": string(dec.Runner), "reason": req.Reason, "lossy": lossy, "nodeId": req.NodeID},
	})
	if lossy {
		engine.PublishContextNotice(m.d.Bus, engine.InteractiveTurnIdentity{RunID:req.RunID, NodeID:req.NodeID, InvocationID:req.InvocationID, RequestID:req.RequestID, TurnIndex:req.TurnIndex, Generation:res.Generation}, notice)
	}
	return MoveResult{To: dec.Runner, SessionID: sessionID, Lossy: lossy, Notice: notice, Generation: lease.Generation, PendingRebuild: rebuilt}, nil
}

// moveFirstTurn: no bundle exists before the first success, so the step
// repeats as a whole on whichever runner the dispatcher places next. Fence the
// interrupted attempt, reserve the next generation, restore the committed
// workspace (discarding partial edits). There is no session record yet, so
// nothing is committed to session_moves.
func (m *SessionMover) moveFirstTurn(ctx context.Context, lease engine.TurnLease, req MoveRequest) (MoveResult, error) {
	if err := m.fenceOldOwner(ctx, req); err != nil {
		return MoveResult{}, err
	}
	lease, err := m.d.Leases.BumpGeneration(ctx, lease)
	if err != nil {
		return MoveResult{}, fmt.Errorf("session move: reserve session generation: %w", err)
	}
	if req.RestoreWorkspace {
		if err := m.restoreWorkspace(ctx, req, ""); err != nil {
			return MoveResult{}, fmt.Errorf("session move: restore committed workspace: %w: %v", engine.ErrSessionRestoreFailed, err)
		}
	}
	return MoveResult{Generation: lease.Generation}, nil
}

func (m *SessionMover) visibleWait(ctx context.Context, job Job, w *WaitReason, req ExecRequirements) error {
	if w == nil {
		w = &WaitReason{Kind: WaitKind("capacity"), Group: req.Group, Model: req.Model}
	}
	if err := m.d.Ledger.SetWait(ctx, job.ID, w); err != nil {
		return fmt.Errorf("session move: record wait: %w", err)
	}
	job.Wait = w
	state := instance.ExecutionState("waiting_capacity")
	if w.Kind == WaitKind("slot") {
		state = instance.ExecutionState("queued_slot")
	}
	m.d.Status.Publish(ctx, job, state)
	return &engine.SessionWaitError{Kind: string(w.Kind), Group: w.Group.String(), Model: w.Model, NextReset: w.NextReset}
}

// fenceOldOwner fails every still-active non-move job of this session's node:
// any late result/export from the old runner then fails FenceCheck.
func (m *SessionMover) fenceOldOwner(ctx context.Context, req MoveRequest) error {
	jobs, err := m.d.Ledger.ListByRun(ctx, req.RunID)
	if err != nil {
		return fmt.Errorf("session move: list run jobs: %w", err)
	}
	for _, j := range jobs {
		if j.NodeID != req.NodeID || j.Op == OpSessionImport || !jobActive(j.State) {
			continue
		}
		f := Fence{JobID: j.ID, RunnerID: j.RunnerID, Generation: j.Generation}
		if err := m.d.Ledger.Fail(ctx, f, outcomeFor(req.Reason)); err != nil && !errors.Is(err, ErrFenced) {
			return fmt.Errorf("session move: fence old owner job %s: %w", j.ID, err)
		}
	}
	return nil
}

// restoreWorkspace discards interrupted edits on built-in and remote runners
// alike: the server copy is rewritten from the last committed checkpoint, the
// resource home is handed to the target, and a remote target is marked dirty so
// its next dispatch pulls a full committed snapshot. target "" = unknown (first turn).
func (m *SessionMover) restoreWorkspace(ctx context.Context, req MoveRequest, target RunnerID) error {
	resource := req.ResourceID
	if resource == uuid.Nil {
		resource = req.RunID
	}
	if err := m.d.Restorer.RestoreBuiltIn(ctx, resource, req.WorkDir); err != nil {
		return err
	}
	home, err := m.d.Homes.GetHome(ctx, resource)
	if err != nil {
		return err
	}
	if target != "" && home.RunnerID != target {
		if _, err := m.d.Homes.HandOff(ctx, resource, target, "session_"+req.Reason, 0, home.Generation); err != nil {
			return err
		}
	}
	if target == BuiltInRunnerID {
		return m.d.Homes.MarkDirty(ctx, resource, false)
	}
	return m.d.Homes.MarkDirty(ctx, resource, true)
}

// importOrRebuild installs the latest committed bundle on the target. Any
// import failure (ErrBundleRequiresRebuild, version skew, transport) falls back
// to a transcript rebuild, refused visibly when it would not fit.
func (m *SessionMover) importOrRebuild(ctx context.Context, a Assignment, req MoveRequest, exec *instance.NodeExecution) (string, bool, error) {
	if ref := strPtr(exec.SessionCheckpointRef); ref != "" {
		if bundle, err := m.d.Checkpoints.Get(ctx, ref); err == nil {
			if sr, ok := m.d.Runners.For(a.Job.RunnerID); ok {
				out, err := sr.Run(ctx, a, StepJob{Op: OpSessionImport, Binding: req.Binding,
					Session: &SessionOp{Backend: bundle.Backend, SessionID: bundle.SessionID, WorkDir: req.WorkDir, Bundle: &bundle}})
				if err == nil && out.Session != nil && out.Session.SessionID != "" {
					return out.Session.SessionID, false, nil
				}
			}
		}
	}
	if _, err := engine.BuildRebuildPrompt(exec.LLMConversation, "", engine.RebuildLimitBytes(req.Binding.ContextWindow)); err != nil {
		return "", false, fmt.Errorf("session move: transcript rebuild: %w: %v", engine.ErrSessionRestoreFailed, err)
	}
	return "", true, nil
}

func (m *SessionMover) alwaysLossy(req MoveRequest) bool {
	backend := req.Requirements.Backend
	if backend == "" {
		backend = "claude-code"
	}
	p, ok := m.d.Portability.For(backend)
	if !ok {
		return true
	}
	l, ok := p.(engine.LossyImporter)
	return ok && l.AlwaysLossy()
}

func (m *SessionMover) loadExecution(ctx context.Context, runID, execID uuid.UUID) (*instance.NodeExecution, error) {
	execs, err := m.d.Executions.ListByInstance(ctx, runID)

type MoveState string

const (
	MoveStatePreparing MoveState = "preparing" // intent, target and planned generation persisted; no effect confirmed yet
	MoveStateRestoring MoveState = "restoring" // old owner fenced, generation and target slot reserved; workspace restore pending
	MoveStateImporting MoveState = "importing" // ready to import (restore done or not needed)

	MoveStateFailed    MoveState = "failed"

func (s MoveState) Open() bool {

// BeginMove implements runner.SessionMoveStore.
func (r *SessionMoveRepo) BeginMove(ctx context.Context, b runner.SessionMoveBegin) (runner.SessionMoveState, error) {
	st := b.State
	switch {
	case st.Move.ID == uuid.Nil || st.IntentID == uuid.Nil || st.JobID == uuid.Nil || st.Move.Generation < 1:
		return st, errors.New("session move: begin needs move, intent and job ids and a planned generation")
	case st.State != runner.MoveStatePreparing:
		return st, errors.New("session move: a move begins in state preparing")
	case b.Intent != nil && (!st.OwnsIntent || b.Intent.ID != st.IntentID || b.Intent.Kind != engine.TurnIntentMove):
		return st, errors.New("session move: only the move's own kind=move intent is persisted with it")
	case b.Intent == nil && st.OwnsIntent:
		return st, errors.New("session move: an owned intent must be persisted with its move")
	}
	reqs, err := json.Marshal(st.Requirements)
	if err != nil {
		return st, fmt.Errorf("session move: encode requirements: %w", err)
	}
	oldJobs, err := fencesJSON(st.OldJobs)
	if err != nil {
		return st, fmt.Errorf("session move: encode old jobs: %w", err)
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return st, fmt.Errorf("session move: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	cur, ok, err := moveForIntentTx(ctx, tx, st.IntentID)
	switch {
	case err != nil:
		return st, err
	case ok && cur.Move.ID == st.Move.ID:
		return cur, nil
	case ok && cur.State.Open():
		return st, fmt.Errorf("%w: intent %s already has open move %s", engine.ErrTurnFenced, st.IntentID, cur.Move.ID)
	}
	now := r.now().UTC()
	if b.Intent != nil {
		if err := persistTurnIntentTx(ctx, tx, *b.Intent, now); err != nil {
			return st, fmt.Errorf("session move: persist move intent: %w", err)
		}
	}
	in, err := loadIntentTx(ctx, tx, st.IntentID)
	if err != nil {
		return st, err
	}
	if in.completed || in.runID != st.Move.RunID.String() || in.invocationID != st.Move.InvocationID.String() {
		return st, fmt.Errorf("%w: intent %s cannot own a move of this session", engine.ErrTurnFenced, st.IntentID)
	}
	if st.Move.At.IsZero() {
		st.Move.At = now
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO session_moves (`+moveStateColumns+`, updated_at)
VALUES (?, ?, ?, ?, ?, ?, ?, 0, '', ?, ?, 'preparing', ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, '', '', ?)`,
		st.Move.ID.String(), st.Move.RunID.String(), st.Move.InvocationID.String(), st.Move.NodeID, st.Move.FromRunner,
		st.Move.ToRunner, st.Move.Reason, st.Move.Generation, st.Move.At.UTC().UnixMilli(),
		st.IntentID.String(), boolToInt(st.OwnsIntent), optUUID(st.ExecutionID), string(st.TargetSource), st.JobID.String(),
		string(reqs), st.WorkDir, optUUID(st.ResourceID), boolToInt(st.RestoreWorkspace), oldJobs, now.UnixMilli()); err != nil {
		return st, fmt.Errorf("session move: insert move row: %w", err)
	}

		return st, fmt.Errorf("session move: commit begin: %w", err)
	}
	return st, nil

	if err != nil {
		return fmt.Errorf("session move: begin fail: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	st, err := scanMoveState(tx.QueryRowContext(ctx, `SELECT `+moveStateColumns+` FROM session_moves WHERE id = ?`, moveID.String()))
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("session move %s: %w", moveID, instance.ErrNotFound)
	}
	if err != nil {
		return fmt.Errorf("session move: read: %w", err)
	}
	switch {
	case st.State == runner.MoveStateFailed:
		return nil
	case !st.State.Open():
		return fmt.Errorf("%w: move %s is already %s", engine.ErrTurnFenced, moveID, st.State)
	}
	now := r.now().UTC()
	if _, err := tx.ExecContext(ctx, `UPDATE session_moves SET state = 'failed', failure = ?, updated_at = ? WHERE id = ?`,
		cause, now.UnixMilli(), moveID.String()); err != nil {
		return fmt.Errorf("session move: fail: %w", err)
	}
	if st.OwnsIntent {
		if err := completeIntentTx(ctx, tx, st.IntentID, now); err != nil {
			return fmt.Errorf("session move: close move intent: %w", err)
		}
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("session move: commit fail: %w", err)
	}
	return nil
}

// CommitMove implements runner.SessionMoveStore (see the port for the contract).
func (r *SessionMoveRepo) CommitMove(ctx context.Context, c runner.SessionMoveCommit) error {
	if c.Move.ID == uuid.Nil || c.IntentID == uuid.Nil || c.Lease.Token == uuid.Nil || c.InvocationID == uuid.Nil {
		return fmt.Errorf("%w: move, intent, lease token and invocation are required", engine.ErrTurnFenced)
	}
	if len(c.Completions) != 1 {
		return fmt.Errorf("%w: a move commits exactly its reserved import job", engine.ErrInvalidStepCompletion)
	}
	f := c.Completions[0].JobFence
	if err := f.Validate(); err != nil {
		return err
	}
	if c.Move.At.IsZero() {
		c.Move.At = r.now().UTC()
	}
	patch, err := json.Marshal(map[string]any{
		engine.ConversationKeySessionID:         c.SessionID,
		engine.ConversationKeyPendingRebuild:    c.PendingRebuild,
		engine.ConversationKeyProvisionalResume: c.Provisional,
	})
	if err != nil {
		return fmt.Errorf("session move: encode conversation patch: %w", err)
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("session move: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()

	st, err := scanMoveState(tx.QueryRowContext(ctx, `SELECT `+moveStateColumns+` FROM session_moves WHERE id = ?`, c.Move.ID.String()))
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("%w: move %s was never begun", engine.ErrTurnFenced, c.Move.ID)
	}
	if err != nil {
		return fmt.Errorf("session move: read: %w", err)
	}
	if st.State == runner.MoveStateCommitted {
		if st.IntentID == c.IntentID && st.Move.ToRunner == c.Move.ToRunner && st.Move.Generation == c.Move.Generation {
			return nil // exact idempotent retry
		}
		return fmt.Errorf("%w: move %s already committed a different outcome", engine.ErrTurnFenced, c.Move.ID)
	}
	switch {
	case !st.State.Open():
		return fmt.Errorf("%w: move %s is %s", engine.ErrTurnFenced, c.Move.ID, st.State)
	case st.IntentID != c.IntentID, st.ExecutionID != c.ExecutionID, st.Move.RunID != c.Move.RunID,
		st.Move.InvocationID != c.InvocationID, st.Move.ToRunner != c.Move.ToRunner, st.JobID != f.JobID,
		f.RunnerID != c.Move.ToRunner, c.Lease.Generation != c.Move.Generation, st.Move.Generation > c.Move.Generation:
		return fmt.Errorf("%w: commit does not match persisted move %s", engine.ErrTurnFenced, c.Move.ID)
	}
	in, err := loadIntentTx(ctx, tx, c.IntentID)
	if err != nil {
		return err
	}
	if in.completed || in.leaseKey != c.Lease.Key || in.runID != c.Move.RunID.String() ||
		in.invocationID != c.InvocationID.String() || in.generation > c.Move.Generation {
		return fmt.Errorf("%w: intent %s does not own this move", engine.ErrTurnFenced, c.IntentID)
	}
	if err := checkMoveLeaseTx(ctx, tx, c.Lease, c.Move.Generation); err != nil {
		return err
	}
	var jobRun string
	err = tx.QueryRowContext(ctx, `SELECT run_id FROM runner_jobs WHERE `+fencedWhere, f.JobID.String(), f.RunnerID, f.Generation).Scan(&jobRun)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && jobRun != c.Move.RunID.String()) {
		return fmt.Errorf("%w: import job %s generation %d is not live on %s", engine.ErrTurnFenced, f.JobID, f.Generation, f.RunnerID)
	}
	if err != nil {
		return fmt.Errorf("session move: read import job: %w", err)
	}

// re-acquired). The move intent, target and planned generation are persisted
// BEFORE the first effect; every later step is idempotent against that row, so

// ResumeMove implements SessionMoveResumer (P4 T10): it finishes the persisted
// move of a pending kind=move intent exactly once, under the lease the
// recovery coordinator placed in ctx. A committed or failed move only closes
// the intent (idempotent); nothing is re-run or re-announced.
func (m *SessionMover) ResumeMove(ctx context.Context, in engine.TurnIntent) error {
	if in.Kind != engine.TurnIntentMove {
		return fmt.Errorf("session move resume %s (%s): %w", in.ID, in.Kind, ErrNotMoveIntent)
	}
	lease, ok := engine.TurnLeaseFromContext(ctx)
	if !ok || lease.Key != in.LeaseKey || lease.Token == uuid.Nil {
		return fmt.Errorf("session move resume %s: no recovered lease for %s: %w", in.ID, in.LeaseKey, engine.ErrTurnLeaseLost)
	}
	st, found, err := m.d.Moves.MoveForIntent(ctx, in.ID)
	if err != nil {
		return fmt.Errorf("session move resume %s: %w", in.ID, err)
	}
	if !found {
		return fmt.Errorf("session move resume %s: no persisted move: %w", in.ID, instance.ErrNotFound)
	}
	if !st.State.Open() {
		return m.d.Intents.Complete(ctx, in.ID)
	}
	exec, err := m.loadExecution(ctx, st.Move.RunID, st.ExecutionID)
	if err != nil {
		return err
	}
	_, err = m.drive(ctx, lease, st, in, exec)
	return err
}

// drive advances one persisted move to committed (or failed). Every step is
// idempotent against the row: the old owner is fenced before target writes,
// the planned generation is reserved once, the reserved slot is reused, the
// restore runs under the move's own claim, and the import job completes only
// inside CommitMove. A retryable failure requeues the slot and releases the
// claim; a deterministic one fails the move. Neither leaves them held.
func (m *SessionMover) drive(ctx context.Context, lease engine.TurnLease, st SessionMoveState, in engine.TurnIntent, exec *instance.NodeExecution) (MoveResult, error) {
	req := moveRequestFrom(st, in)
	if st.State == MoveStatePreparing {
		fenced, err := m.fenceOldOwner(ctx, req)
		if err != nil {
			return MoveResult{}, err
		}
		st.OldJobs = mergeJobFences(st.OldJobs, fenced)
	}
	if lease.Generation < st.Move.Generation {
		bumped, err := m.d.Leases.BumpGeneration(ctx, lease)
		if err != nil {
			return MoveResult{}, fmt.Errorf("session move: reserve session generation: %w", err)
		}
		lease = bumped
	}
	if lease.Generation < st.Move.Generation {
		return MoveResult{}, fmt.Errorf("session move %s: lease generation %d is below the planned %d: %w",
			st.Move.ID, lease.Generation, st.Move.Generation, engine.ErrTurnFenced)
	}
	st.Move.Generation = lease.Generation // a replay recovery may already have reserved a newer one: adopt, never bump twice
	job, err := m.reserveTarget(ctx, &st)
	if err != nil {
		_ = m.d.Moves.AdvanceMove(ctx, st) // keep fenced jobs and the reserved generation durable
		return MoveResult{}, err
	}
	fence := job.Fence()
	if st.State == MoveStatePreparing {
		st.State = MoveStateImporting
		if st.RestoreWorkspace {
			st.State = MoveStateRestoring
		}
	}
	if err := m.d.Moves.AdvanceMove(ctx, st); err != nil {
		return MoveResult{}, fmt.Errorf("session move: record progress: %w", err)
	}
	if st.State == MoveStateRestoring {
		if err := m.restoreUnderClaim(ctx, &st, req); err != nil {
			m.releaseForRetry(ctx, &st, fence)
			return MoveResult{}, fmt.Errorf("session move: restore committed workspace: %w: %w", engine.ErrSessionRestoreFailed, err)
		}
		st.State = MoveStateImporting
		if err := m.d.Moves.AdvanceMove(ctx, st); err != nil {
			return MoveResult{}, fmt.Errorf("session move: record progress: %w", err)
		}
	}
	sessionID, rebuilt, err := m.importOrRebuild(ctx, Assignment{Job: job, Fence: fence}, req, exec)
	if err != nil {
		return MoveResult{}, errors.Join(err, m.failMove(ctx, st, fence, err))
	}
	lossy := rebuilt || m.alwaysLossy(req) || st.TargetSource != previousSource(exec)
	notice := ""
	if lossy {
		notice = engine.SessionLossNotice
	}
	mv := st.Move
	mv.Lossy, mv.Notice, mv.At = lossy, notice, m.d.Clock().UTC()
	commit := SessionMoveCommit{ExecutionID: st.ExecutionID, Move: mv, SessionID: sessionID, PendingRebuild: rebuilt,
		Provisional: !rebuilt, Lease: lease, InvocationID: mv.InvocationID, IntentID: st.IntentID,
		Completions: []engine.StepCompletion{{JobFence: engine.JobFenceRef{JobID: fence.JobID, RunnerID: string(fence.RunnerID), Generation: fence.Generation}}}}
	if st.NewResource != nil {
		commit.Resource = *st.NewResource
	}
	if err := m.d.Moves.CommitMove(ctx, commit); err != nil {
		err = fmt.Errorf("session move: commit: %w", err)
		if errors.Is(err, engine.ErrTurnFenced) || errors.Is(err, instance.ErrStaleSessionGeneration) {
			return MoveResult{}, errors.Join(err, m.failMove(ctx, st, fence, err))
		}
		return MoveResult{}, err // transient: the move stays open and resumes with the same ID
	}
	m.announce(ctx, req, mv, st.TargetSource)
	return MoveResult{To: RunnerID(mv.ToRunner), SessionID: sessionID, Lossy: lossy, Notice: notice,
		Generation: mv.Generation, PendingRebuild: rebuilt}, nil
}

// reserveTarget returns the move's RUNNING import job on its persisted target.
// After a crash the reserved slot is reused; a reaped or terminal job is
// replaced by the next attempt of the SAME operation on the SAME target; a
// slot held anywhere else is released, never leaked.
func (m *SessionMover) reserveTarget(ctx context.Context, st *SessionMoveState) (Job, error) {
	target := RunnerID(st.Move.ToRunner)
	job, err := m.d.Ledger.Get(ctx, st.JobID)
	if err != nil {
		return Job{}, fmt.Errorf("session move: load import job: %w", err)
	}
	if job.State.HoldsSlot() && job.RunnerID == target {
		if job.State == JobOffered {
			if err := m.d.Ledger.MarkRunning(ctx, job.Fence()); err != nil {
				return Job{}, fmt.Errorf("session move: mark import running: %w", err)
			}
			job.State = JobRunning
		}
		return job, nil
	}
	if job.State.HoldsSlot() {
		if err := m.d.Ledger.Fail(ctx, job.Fence(), OutcomeOther); err != nil && !errors.Is(err, ErrFenced) {
			return Job{}, fmt.Errorf("session move: release stray import slot: %w", err)
		}
		job.State = JobFailed
	}
	if !job.State.Active() {
		key := job.Key
		key.Attempt++
		if job, err = m.d.Ledger.EnsureIntent(ctx, key, st.Move.NodeID, st.Requirements); err != nil {
			return Job{}, fmt.Errorf("session move: next import attempt: %w", err)
		}
		st.JobID = job.ID
	}
	snap, err := m.d.Registry.Snapshot(ctx)
	if err != nil {
		return Job{}, fmt.Errorf("session move: pool snapshot: %w", err)
	}
	dec := Decision{Placed: true, Runner: target, Source: st.TargetSource, Reason: "session_" + st.Move.Reason}
	job, err = m.d.Ledger.Reserve(ctx, job.ID, dec, stepLimitOf(snap, target), m.d.Clock().Add(m.d.OpLease))
	if errors.Is(err, ErrSlotTaken) {
		return Job{}, &engine.SessionWaitError{Kind: "slot", Group: st.Requirements.Group.String(), Model: st.Requirements.Model}
	}
	if err != nil {
		return Job{}, fmt.Errorf("session move: reserve target %s: %w", target, err)
	}
	m.d.Status.Publish(ctx, job, instance.ExecutionState("recovering"))
	if err := m.d.Ledger.MarkRunning(ctx, job.Fence()); err != nil {
		return Job{}, fmt.Errorf("session move: mark import running: %w", err)
	}
	job.State = JobRunning
	return job, nil
}

// restoreUnderClaim restores the committed workspace only while the move
// holds its own exact resource claim (P3 handoff: the old owner's claim
// blocks it with ErrResourceBusy). The claim is recorded before the write.
func (m *SessionMover) restoreUnderClaim(ctx context.Context, st *SessionMoveState, req MoveRequest) error {
	key := moveResourceKey(req)
	holder := "session-move:" + st.Move.ID.String()
	if st.NewResource != nil && m.d.Resources.Check(ctx, *st.NewResource) != nil {
		st.NewResource = nil
	}
	if st.NewResource == nil {
		rec, held, err := m.d.Resources.Active(ctx, key)
		if err != nil {
			return err
		}
		if held && rec.Holder == holder {
			ref := rec.Fence // claimed just before a crash, not yet recorded
			st.NewResource = &ref
		} else {
			ref, err := m.d.Resources.Claim(ctx, key, holder, BuiltInRunnerID)
			if err != nil {
				return err
			}
			st.NewResource = &ref
		}
		if err := m.d.Moves.AdvanceMove(ctx, *st); err != nil {
			return err
		}
	}
	return m.restoreWorkspace(ctx, req, RunnerID(st.Move.ToRunner))
}

// releaseForRetry: a transient restore failure stays visible and retryable
// (the move remains open), but its slot and claim are released.
func (m *SessionMover) releaseForRetry(ctx context.Context, st *SessionMoveState, f Fence) {
	_, _ = m.d.Ledger.Requeue(ctx, f, OutcomeOther)
	if st.NewResource != nil {
		_ = m.d.Resources.Release(ctx, *st.NewResource)
		st.NewResource = nil
	}
	_ = m.d.Moves.AdvanceMove(ctx, *st)
}

// failMove closes a move that can never commit: slot and claim released,
// row failed and an owned intent completed (the failure stays visible).
func (m *SessionMover) failMove(ctx context.Context, st SessionMoveState, f Fence, cause error) error {
	var errs []error
	if err := m.d.Ledger.Fail(ctx, f, OutcomeOther); err != nil && !errors.Is(err, ErrFenced) {
		errs = append(errs, fmt.Errorf("session move: release import slot: %w", err))
	}
	if st.NewResource != nil {
		if err := m.d.Resources.Release(ctx, *st.NewResource); err != nil && !errors.Is(err, ErrResourceFenced) {
			errs = append(errs, fmt.Errorf("session move: release restore claim: %w", err))
		}
	}
	if err := m.d.Moves.FailMove(ctx, st.Move.ID, cause.Error()); err != nil {
		errs = append(errs, fmt.Errorf("session move: record failure: %w", err))
	}
	return errors.Join(errs...)
}

// fenceOldOwner fails every still-active non-move job of this session's node
// (idempotent: an already-fenced job is skipped) and returns what it fenced.
func (m *SessionMover) fenceOldOwner(ctx context.Context, req MoveRequest) ([]engine.JobFenceRef, error) {
	jobs, err := m.d.Ledger.ListByRun(ctx, req.RunID)
	if err != nil {
		return nil, fmt.Errorf("session move: list run jobs: %w", err)
	}
	var fenced []engine.JobFenceRef
	for _, j := range jobs {
		if j.NodeID != req.NodeID || j.Op == OpSessionImport || !jobActive(j.State) {
			continue
		}
		f := j.Fence()
		if err := m.d.Ledger.Fail(ctx, f, outcomeFor(req.Reason)); err != nil && !errors.Is(err, ErrFenced) {
			return nil, fmt.Errorf("session move: fence old owner job %s: %w", j.ID, err)
		}
		fenced = append(fenced, engine.JobFenceRef{JobID: f.JobID, RunnerID: string(f.RunnerID), Generation: f.Generation})
	}
	return fenced, nil
}

func mergeJobFences(have, add []engine.JobFenceRef) []engine.JobFenceRef {
	seen := make(map[uuid.UUID]bool, len(have))
	for _, f := range have {
		seen[f.JobID] = true
	}
	for _, f := range add {
		if !seen[f.JobID] {
			have, seen[f.JobID] = append(have, f), true
		}
	}
	return have
}

The decision is: once the persisted target is **gone**, the move is **failed**, and a **new** move is planned (the extra generation bump is accepted). "Gone" uses the real liveness states in `domain/runner/model.go`:
- `LivenessLost` (missed heartbeats past `LostAfter`, and also key revocation: `Hub.RevokeRunner` → `markLost`);
- `LivenessOffline` (disconnected or incompatible);
- the runner is no longer in the registry snapshot.

`LivenessSuspect` is NOT gone: it is inside the liveness grace, and the move keeps waiting on the same target. The built-in runner is never gone.

The check runs at the top of every `drive` entry, after the generation is reserved or adopted, so it catches every retry and restart. The failure releases what the move holds: it fails the import job if it holds a slot, or abandons it through the optional `IntentAbandoner` if it is queued, and it releases the move's own resource claim. `FailMove` records the cause and closes an owned `kind = move` intent.
- **`Move`** (the in-turn path) then plans ONE replacement move in the same call, past the failed move's reserved generation. A mid-turn turn intent stays pending and binds the replacement. The partial unique index `idx_session_moves_open_intent` allows it, because the failed row is no longer open.
- **`ResumeMove`** (P4 T10's startup/recovery path) only fails the move and returns `ErrMoveTargetGone`. The intent is closed, and the P4 T10 controller starts the new move on its next pass through the ordinary `RecoverSession` → `MoveSession` path, because the session is still pinned to the gone runner.

Unchanged: `session.moved` is announced at most once, for the committed replacement only; the failed move is never announced (Cycle 3b assumption (e)).

	snap, err := m.d.Registry.Snapshot(ctx)

		case LivenessOffline:
			return "offline", nil
		}

	}
	return "unregistered", nil
}

// failGoneTarget fails a move whose target is gone. It releases the import
// slot (or abandons a queued import intent), the move's own resource claim,
// and records the failure; FailMove closes an owned move intent.
func (m *SessionMover) failGoneTarget(ctx context.Context, st SessionMoveState, lease engine.TurnLease, why string) error {
	gone := &moveTargetGoneError{move: st.Move.ID, target: RunnerID(st.Move.ToRunner), why: why, lease: lease}
	errs := []error{gone}
	job, err := m.d.Ledger.Get(ctx, st.JobID)
	switch {
	case err != nil:
		errs = append(errs, fmt.Errorf("session move: load import job: %w", err))
	case job.State.HoldsSlot():
		if err := m.d.Ledger.Fail(ctx, job.Fence(), OutcomeRunnerLost); err != nil && !errors.Is(err, ErrFenced) {
			errs = append(errs, fmt.Errorf("session move: release import slot: %w", err))
		}
	case job.State == JobQueued:
		if a, ok := m.d.Ledger.(IntentAbandoner); ok {
			if err := a.Abandon(ctx, job.ID); err != nil {
				errs = append(errs, fmt.Errorf("session move: abandon import intent: %w", err))
			}
		}
	}
	if st.NewResource != nil {
		if err := m.d.Resources.Release(ctx, *st.NewResource); err != nil && !errors.Is(err, ErrResourceFenced) {
			errs = append(errs, fmt.Errorf("session move: release restore claim: %w", err))
		}
	}
	if err := m.d.Moves.FailMove(ctx, st.Move.ID, gone.Error()); err != nil {
		errs = append(errs, fmt.Errorf("session move: record failure: %w", err))
	}
	return errors.Join(errs...)
}

// runSessionOp executes session export/import in-process through the
// SessionPortabilityRegistry (the built-in holds the harness session files).
func (r *Runner) runSessionOp(ctx context.Context, job runner.StepJob) (runner.StepOutput, error) {
	if job.Session == nil {
		return runner.StepOutput{}, fmt.Errorf("builtin: %s without a session payload", job.Op)
	}
	if r.deps.Sessions == nil {
		return runner.StepOutput{}, fmt.Errorf("builtin: %s: no session portability registry configured", job.Op)
	}
	backend := job.Session.Backend
	if backend == "" {
		backend = "claude-code"
	}
	p, ok := r.deps.Sessions.For(backend)
	if !ok {
		return runner.StepOutput{}, fmt.Errorf("builtin: %s: no session portability for backend %q", job.Op, backend)
	}
	if job.Op == runner.OpSessionExport {
		b, err := p.Export(ctx, job.Session.SessionID, job.Session.WorkDir)
		if err != nil {
			return runner.StepOutput{}, err
		}
		return runner.StepOutput{Session: &runner.SessionOpResult{SessionID: b.SessionID, Bundle: &b}}, nil
	}
	if job.Session.Bundle == nil {
		return runner.StepOutput{}, errors.New("builtin: session_import without a bundle")
	}
	id, err := p.Import(ctx, *job.Session.Bundle, job.Session.WorkDir)
	if err != nil {
		return runner.StepOutput{}, err
	}
	return runner.StepOutput{Session: &runner.SessionOpResult{SessionID: id}}, nil
}
