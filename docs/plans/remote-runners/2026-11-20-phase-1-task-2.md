# Remote Runners — Phase 1 Task 2: Step identity, placement sink and durable invocations

**Goal:** Give every dispatched provider/process operation a durable, valid `StepIdentity` (run, node, invocation-per-visit, operation, attempt) stamped at all four entry points, backed by a persisted `node_invocations` table, plus the per-attempt `PlacementSink` the dispatcher writes into.

**Architecture:** `domain/engine` gains three small files: `stepidentity.go` (context value + `WithSubOperation`), `placement_sink.go` (mutex-guarded fact list on the context) and `invocations.go` (the `InvocationStore` port, an in-memory default, `Engine.SetInvocationStore`). `Engine.executeWithRetry` begins (or reuses the open) invocation once per visit before the attempt loop, stamps identity + a fresh sink per attempt, and the run loop commits the invocation only after the engine has advanced past the node. `conversationHandler.HandleMessage`, `GroupResolutionBridge.StartResolution` and `LLMChildInputPreparer.Prepare` stamp their own operations under the same open invocation. `adapter/sqlite/invocation_repo.go` persists invocations (migration `040_node_invocations`), and the composition root installs it on all three stamping owners.

**Tech Stack:** Go 1.25.5, `database/sql` + modernc SQLite, `github.com/google/uuid`, testify.

**Spec / Design:** spec "Recovery and session continuity" (single owner; stale results rejected), "Parallel branches and child workflows receive independent placement"; design phase 1 §0 D3, §2 rows "Per-step retry loop", "Interactive turn entry", "Group resolution session", §3.3 (idempotency key, "Graph back-edges allocate a fresh invocation; reconnect/restart reuses it"), §3.5 "Idempotency key", §3.6 "Consumer contracts", §4 step 1, §5 RR-01 row "Durable invocation, child-preparation operation, turn ID", §8 Error bullet "each of the three stamping sites … reaches the dispatcher stamped", §8 cross-phase "loop revisits and child-preparation calls have distinct durable operation IDs". Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §1 (040), §3, §4.

Operation-ID vocabulary (what the dispatcher's `JobKey.OperationID` will contain):

| Site | Kind | OperationID | Attempt |
|---|---|---|---|
| `executeWithRetry` | `OperationNode` | `"node"` | workflow retry attempt 1..n (resets every visit) |
| `LLMChildInputPreparer.Prepare` | `OperationChildInput` | `"node/child-input"` (via `WithSubOperation`) | inherited |
| `HandleMessage` (ordinary session) | `OperationTurn` | `"turn/<n>"`, n = user messages already in history + 1 | 1 |
| `HandleMessage` (group conflict-resolution session) | `OperationTurn` | `"resolution/<groupRunID>:<mergeIndex>:<attempt>/turn/<n>"` | 1 |
| `StartResolution` | `OperationResolution` | `"resolution/<groupRunID>:<mergeIndex>:<attempt>"` | 1 |

The group-session turn prefix keeps two resolution attempts on the same group-node visit from colliding on `turn/<n>` (contracts §3 shows `turn/<n>` as the ordinary-session form; the prefix is the only refinement and is documented here). A failed turn is not persisted, so the next send reuses the same `turn/<n>` — the ledger (P1 T6) re-opens that key, which is exactly "resend the same turn".

**Visit lifecycle decisions (RR-01):**
- `executeWithRetry` calls `Begin` once per visit, *before* the attempt loop. A begin failure fails the step; nothing executes unrecorded.
- The run loop calls `Commit` only when the engine advanced (`halt == false` after `handleNodeSuccess`/`handleNodeError`), and after `consumeFinishedWait` advances a resumed wait node. A wait (`IsWait`), a pending gather, a cancellation, a crash, or a halting failure leaves the visit **open**, so a restart, a wake, or an instance `Retry` reuses it (D7: Phase 1 re-executes; the ledger re-opens a terminal job for the same key — P1 T6).
- A back-edge revisit happens only after the previous visit committed, so it always gets `visit+1` and a new ID.
- `Commit` runs under `context.WithoutCancel` so a cancel landing after the node finished cannot fail the run; a real persistence error fails the run (otherwise a later loop visit would reuse this invocation).

```go
package engine

import (
	"context"
	"errors"
	"fmt"

	"github.com/google/uuid"
)

// OperationKind classifies the durable operation a dispatched provider or
// process call belongs to (Remote Runners RR-01).
type OperationKind string

const (
	OperationNode       OperationKind = "node"
	OperationChildInput OperationKind = "child_input"
	OperationTurn       OperationKind = "turn"
	OperationResolution OperationKind = "resolution"
	OperationProbe      OperationKind = "probe"
)

// StepIdentity is the durable identity of one dispatched operation. The
// runner ledger keys a job on (RunID, InvocationID, OperationID, Attempt).
type StepIdentity struct {
	RunID        uuid.UUID
	NodeID       string
	InvocationID uuid.UUID // one per node VISIT (back-edge => new); reused across restart
	OperationID  string    // e.g. "node", "node/child-input", "turn/<n>", "resolution/<attempt id>"
	Kind         OperationKind
	Attempt      int // workflow retry attempt (1-based); resets every visit
}

// Valid reports whether every key component is present. The dispatcher
// refuses an invalid identity exactly like a missing one.
func (s StepIdentity) Valid() bool {
	return s.RunID != uuid.Nil && s.NodeID != "" && s.InvocationID != uuid.Nil && s.OperationID != "" && s.Attempt >= 1
}

// ErrMissingStepIdentity is returned by the dispatcher when a routed call has
// no (valid) identity on its context: there is never a silent unplaced run.
var ErrMissingStepIdentity = errors.New("engine: dispatched operation has no step identity")

type stepIdentityKey struct{}

// ContextWithStepIdentity attaches id to ctx (precedent: ContextWithInstanceID).
func ContextWithStepIdentity(ctx context.Context, id StepIdentity) context.Context {
	return context.WithValue(ctx, stepIdentityKey{}, id)
}

// StepIdentityFromContext returns the identity stamped on ctx.
func StepIdentityFromContext(ctx context.Context) (StepIdentity, bool) {
	id, ok := ctx.Value(stepIdentityKey{}).(StepIdentity)
	return id, ok
}

// WithSubOperation derives a child operation under the same invocation:
// OperationID = parent.OperationID + "/" + suffix. Without a parent identity
// ctx is returned unchanged, so a dispatch from it still fails closed.
func WithSubOperation(ctx context.Context, suffix string, kind OperationKind) context.Context {
	parent, ok := StepIdentityFromContext(ctx)
	if !ok {
		return ctx
	}
	child := parent
	child.OperationID = parent.OperationID + "/" + suffix
	child.Kind = kind
	return ContextWithStepIdentity(ctx, child)
}

// nodeOperationID is the operation id of a node's own execution attempt.
const nodeOperationID = "node"

// turnOperationID names the n-th user turn of an interactive session.
func turnOperationID(n int) string { return fmt.Sprintf("turn/%d", n) }

// resolutionOperationID names one group conflict-resolution attempt.
func resolutionOperationID(groupRunID uuid.UUID, mergeIndex, attempt int) string {
	return fmt.Sprintf("resolution/%s:%d:%d", groupRunID, mergeIndex, attempt)
}
```

```go
package engine

import (
	"context"
	"sync"
	"time"

	"github.com/google/uuid"
)

// PlacementFact is one placement attempt of a dispatched operation, recorded
// by the runner dispatcher and persisted on the NodeExecution (P1 T14).
type PlacementFact struct {
	JobID      uuid.UUID `json:"jobId"`
	RunnerID   string    `json:"runnerId"`
	SourceID   string    `json:"sourceId,omitempty"`
	Reason     string    `json:"reason"`
	Generation int64     `json:"generation"`
	Outcome    string    `json:"outcome"` // "completed" | "exhausted" | "logged_out" | "transient" | "runner_lost" | "other" | "fenced"
	At         time.Time `json:"at"`
}

// PlacementSink collects the placement facts of one execution attempt. The
// engine installs a fresh sink per attempt; the dispatcher records into it.
type PlacementSink struct {
	mu    sync.Mutex
	facts []PlacementFact
}

// NewPlacementSink returns an empty sink.
func NewPlacementSink() *PlacementSink { return &PlacementSink{} }

// Record appends f.
func (s *PlacementSink) Record(f PlacementFact) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.facts = append(s.facts, f)
}

// Facts returns a copy of the recorded facts in order.
func (s *PlacementSink) Facts() []PlacementFact {
	s.mu.Lock()
	defer s.mu.Unlock()
	out := make([]PlacementFact, len(s.facts))
	copy(out, s.facts)
	return out
}

type placementSinkKey struct{}

// ContextWithPlacementSink attaches s to ctx.
func ContextWithPlacementSink(ctx context.Context, s *PlacementSink) context.Context {
	return context.WithValue(ctx, placementSinkKey{}, s)
}

// PlacementSinkFromContext returns the sink installed on ctx.
func PlacementSinkFromContext(ctx context.Context) (*PlacementSink, bool) {
	s, ok := ctx.Value(placementSinkKey{}).(*PlacementSink)
	return s, ok && s != nil
}
```

```go
// InvocationStore is the durable producer of node-visit invocations (RR-01).
type InvocationStore interface {
	// Begin returns the OPEN (uncommitted) invocation for (runID,nodeID) if one
	// exists (restart reuse), else creates a new one with visit = previous + 1.
	Begin(ctx context.Context, runID uuid.UUID, nodeID string) (Invocation, error)
	// Commit marks the invocation committed (node finished and engine advanced).
	// Committing an already committed invocation is a no-op.
	Commit(ctx context.Context, invocationID uuid.UUID) error
	Get(ctx context.Context, invocationID uuid.UUID) (Invocation, error)
}

// Invocation is one visit of a node within a run.
type Invocation struct {
	ID          uuid.UUID
	RunID       uuid.UUID
	NodeID      string
	Visit       int
	CreatedAt   time.Time
	CommittedAt *time.Time
}

// ErrInvocationNotFound is returned for an unknown invocation id.
var ErrInvocationNotFound = errors.New("engine: invocation not found")

var errInvocationKey = errors.New("engine: an invocation needs a run and a node")

type invocationKey struct {
	run  uuid.UUID
	node string
}

// memoryInvocationStore is the in-process InvocationStore. It is the default
// for an Engine, conversation handler and group-resolution bridge built
// without the durable store (unit tests); production installs
// adapter/sqlite.InvocationRepo at the composition root.
type memoryInvocationStore struct {
	mu     sync.Mutex
	byID   map[uuid.UUID]Invocation
	open   map[invocationKey]uuid.UUID
	visits map[invocationKey]int
}

// NewMemoryInvocationStore returns an empty in-memory store.
func NewMemoryInvocationStore() InvocationStore {
	return &memoryInvocationStore{
		byID:   map[uuid.UUID]Invocation{},
		open:   map[invocationKey]uuid.UUID{},
		visits: map[invocationKey]int{},
	}
}

func (m *memoryInvocationStore) Begin(_ context.Context, runID uuid.UUID, nodeID string) (Invocation, error) {
	if runID == uuid.Nil || strings.TrimSpace(nodeID) == "" {
		return Invocation{}, errInvocationKey
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	k := invocationKey{run: runID, node: nodeID}
	if id, ok := m.open[k]; ok {
		return m.byID[id], nil
	}
	m.visits[k]++
	inv := Invocation{ID: uuid.New(), RunID: runID, NodeID: nodeID, Visit: m.visits[k], CreatedAt: time.Now().UTC()}
	m.byID[inv.ID] = inv
	m.open[k] = inv.ID
	return inv, nil
}

func (m *memoryInvocationStore) Commit(_ context.Context, id uuid.UUID) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	inv, ok := m.byID[id]
	if !ok {
		return fmt.Errorf("%w: %s", ErrInvocationNotFound, id)
	}
	if inv.CommittedAt != nil {
		return nil
	}
	now := time.Now().UTC()
	inv.CommittedAt = &now
	m.byID[id] = inv
	delete(m.open, invocationKey{run: inv.RunID, node: inv.NodeID})
	return nil
}

func (m *memoryInvocationStore) Get(_ context.Context, id uuid.UUID) (Invocation, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	inv, ok := m.byID[id]
	if !ok {
		return Invocation{}, fmt.Errorf("%w: %s", ErrInvocationNotFound, id)
	}
	return inv, nil
}

// SetInvocationStore installs the durable invocation producer. nil reinstalls
// the in-memory store (used only by legacy tests). Call before any run starts.
func (e *Engine) SetInvocationStore(s InvocationStore) {
	if s == nil {
		s = NewMemoryInvocationStore()
	}
	e.mu.Lock()
	e.invocations = s
	e.mu.Unlock()
}

// InvocationStore returns the installed store (read-back for wiring tests).
func (e *Engine) InvocationStore() InvocationStore { return e.invocationStore() }

func (e *Engine) invocationStore() InvocationStore {
	e.mu.Lock()
	defer e.mu.Unlock()
	return e.invocations
}
```

```go
// executeWithRetry executes a node, applying retry logic from the error behavior.
// A NodeExecution record is created for each attempt. The final record is returned
// so the caller can update it (e.g., marking it skipped).
//
// Each call is one node VISIT (RR-01). The durable invocation is begun — or,
// after a wake/restart, the still-open one reused — BEFORE the attempt loop, and
// every attempt executes with a StepIdentity {OperationID "node", Attempt n} and a
// fresh PlacementSink on its context. The invocation id is returned so the run
// loop commits it once the engine has advanced. A begin failure fails the step
// before anything executes.
func (e *Engine) executeWithRetry(ctx context.Context, instanceID uuid.UUID, node workflow.Node, vars *variable.VariableStore, wf workflow.Workflow) (*NodeResult, *instance.NodeExecution, uuid.UUID, error) {
	executor, ok := e.executorFor(node.Type)
	if !ok {
		return nil, nil, uuid.Nil, fmt.Errorf("no executor registered for node type: %s", node.Type)
	}

	inv, err := e.invocationStore().Begin(ctx, instanceID, node.ID)
	if err != nil {
		return nil, nil, uuid.Nil, fmt.Errorf("engine: begin invocation for node %q: %w", node.ID, err)
	}

	eb := resolveErrorBehavior(node, wf)
	maxAttempts := 1
	if eb.Type == "retry" && eb.Retries > 0 {
		maxAttempts = eb.Retries + 1
	}

	var lastErr error
	var lastExec *instance.NodeExecution

	for attempt := 1; attempt <= maxAttempts; attempt++ {
		if attempt > 1 && eb.RetryDelaySeconds > 0 {
			select {
			case <-ctx.Done():
				return nil, lastExec, inv.ID, ctx.Err()
			case <-time.After(time.Duration(eb.RetryDelaySeconds) * time.Second):
			}
		}

		resolvedInputs := vars.Snapshot()
		sink := NewPlacementSink()
		attemptCtx := ContextWithPlacementSink(ContextWithStepIdentity(ctx, StepIdentity{
			RunID:        instanceID,
			NodeID:       node.ID,
			InvocationID: inv.ID,
			OperationID:  nodeOperationID,
			Kind:         OperationNode,
			Attempt:      attempt,
		}), sink)
		startedAt := time.Now()
		result, err := executor.Execute(attemptCtx, node, vars, wf.Name)
		completedAt := time.Now()

		execStatus := instance.NodeStatusSucceeded
		var execError map[string]any
		if err != nil {
			execStatus = instance.NodeStatusFailed
			execError = map[string]any{"error": err.Error()}
		}

		var execOutput map[string]any
		if result != nil && result.Output != nil {
			if m, ok := result.Output.(map[string]any); ok {
				execOutput = m
			} else {
				execOutput = map[string]any{"value": result.Output}
			}
		}

		nodeExec := &instance.NodeExecution{
			ID:             uuid.New(),
			InstanceID:     instanceID,
			NodeID:         node.ID,
			Attempt:        attempt,
			Status:         execStatus,
			ResolvedInputs: resolvedInputs,
			Output:         execOutput,
			Error:          execError,
			StartedAt:      startedAt,
			CompletedAt:    &completedAt,
		}
		nodeResultToExecution(result, nodeExec)
		// sink holds this attempt's placement facts; P1 T14 copies them onto nodeExec here.
		// Skip writing when the executor itself already wrote the record (IsWait path).
		if result == nil || !result.IsWait {
			if persistErr := e.nodeExecutions.Create(ctx, nodeExec); persistErr != nil {
				return nil, nodeExec, inv.ID, fmt.Errorf("engine: persist node execution %q: %w", node.ID, persistErr)
			}
		}
		lastExec = nodeExec

		if err == nil {
			return result, nodeExec, inv.ID, nil
		}
		var pendingGather *pendingFileGatherError
		var pendingWait *pendingGroupWaitError

			return nil, nodeExec, inv.ID, err
		}
		lastErr = err
	}

	return nil, lastExec, inv.ID, lastErr
}

// commitVisit marks a finished visit committed once the engine has advanced
// past the node, so the next arrival (a graph back-edge) begins a new
// invocation. uuid.Nil (the visit never began) is a no-op. Commit is detached
// from cancellation: a cancel landing after the node finished must not fail the
// run. A persistence error fails the run, because a later visit would otherwise
// reuse this invocation and conflate two loop iterations.
func (e *Engine) commitVisit(ctx context.Context, instanceID uuid.UUID, nodeID string, invocationID uuid.UUID) bool {
	if invocationID == uuid.Nil {
		return true
	}
	if err := e.invocationStore().Commit(context.WithoutCancel(ctx), invocationID); err != nil {
		slog.Error("failed to commit node invocation", "instanceID", instanceID, "nodeID", nodeID, "invocationID", invocationID, "error", err)
		e.failInstance(ctx, instanceID, nodeID)
		return false
	}
	return true
}

// commitOpenVisit commits the node's open visit when a finished wait is
// consumed without re-executing the node (timer/webhook resume).
func (e *Engine) commitOpenVisit(ctx context.Context, instanceID uuid.UUID, nodeID string) bool {
	inv, err := e.invocationStore().Begin(context.WithoutCancel(ctx), instanceID, nodeID)
	if err != nil {
		slog.Error("failed to load open node invocation", "instanceID", instanceID, "nodeID", nodeID, "error", err)
		e.failInstance(ctx, instanceID, nodeID)
		return false
	}
	return e.commitVisit(ctx, instanceID, nodeID, inv.ID)
}
```

```sql
-- Durable per-visit node invocations (Remote Runners RR-01). One row per node
-- VISIT: a graph back-edge commits the previous visit and begins visit+1; a
-- restart reuses the open (uncommitted) row. The runner job ledger keys every
-- dispatched operation on (run, invocation, operation, attempt).
CREATE TABLE IF NOT EXISTS node_invocations (
    id           TEXT PRIMARY KEY,
    run_id       TEXT NOT NULL REFERENCES instances(id) ON DELETE CASCADE,
    node_id      TEXT NOT NULL,
    visit        INTEGER NOT NULL CHECK (visit >= 1),
    created_at   TEXT NOT NULL,
    committed_at TEXT,
    UNIQUE (run_id, node_id, visit)
);

-- At most one OPEN visit per (run, node): the structural guarantee behind
-- "restart reuses the open invocation".
CREATE UNIQUE INDEX IF NOT EXISTS idx_node_invocations_open
    ON node_invocations (run_id, node_id) WHERE committed_at IS NULL;
```

```go
import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/google/uuid"

// Compile-time: satisfies the engine's durable invocation port.
var _ engine.InvocationStore = (*InvocationRepo)(nil)

// InvocationRepo persists node-visit invocations (migration 040). Hand-written
// SQL, modeled on AuditRepo.
type InvocationRepo struct {
	db  *sql.DB
	now func() time.Time
}

// NewInvocationRepo creates an InvocationRepo over db.
func NewInvocationRepo(db *sql.DB) *InvocationRepo {
	return &InvocationRepo{db: db, now: time.Now}
}

const invocationSelect = `SELECT id, run_id, node_id, visit, created_at, committed_at FROM node_invocations`

// Begin returns the open invocation for (runID,nodeID) or creates visit+1.
// Read and insert share one transaction; the partial unique index rejects a
// concurrent second open row.
func (r *InvocationRepo) Begin(ctx context.Context, runID uuid.UUID, nodeID string) (engine.Invocation, error) {
	if runID == uuid.Nil || strings.TrimSpace(nodeID) == "" {
		return engine.Invocation{}, errors.New("invocation repo: run and node are required")
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return engine.Invocation{}, fmt.Errorf("beginning invocation transaction: %w", err)
	}
	defer func() { _ = tx.Rollback() }()

	open, err := scanInvocation(tx.QueryRowContext(ctx,
		invocationSelect+` WHERE run_id = ? AND node_id = ? AND committed_at IS NULL`,
		uuidToString(runID), nodeID))
	switch {
	case err == nil:
		if err := tx.Commit(); err != nil {
			return engine.Invocation{}, fmt.Errorf("committing invocation read: %w", err)
		}
		return open, nil
	case !errors.Is(err, sql.ErrNoRows):
		return engine.Invocation{}, fmt.Errorf("reading open invocation: %w", err)
	}

	var maxVisit int
	if err := tx.QueryRowContext(ctx,
		`SELECT COALESCE(MAX(visit), 0) FROM node_invocations WHERE run_id = ? AND node_id = ?`,
		uuidToString(runID), nodeID).Scan(&maxVisit); err != nil {
		return engine.Invocation{}, fmt.Errorf("reading last visit: %w", err)
	}
	inv := engine.Invocation{
		ID: uuid.New(), RunID: runID, NodeID: nodeID, Visit: maxVisit + 1,
		CreatedAt: r.now().UTC().Truncate(time.Second),
	}
	if _, err := tx.ExecContext(ctx,
		`INSERT INTO node_invocations (id, run_id, node_id, visit, created_at) VALUES (?, ?, ?, ?, ?)`,
		uuidToString(inv.ID), uuidToString(runID), nodeID, inv.Visit, timeToString(inv.CreatedAt)); err != nil {
		return engine.Invocation{}, fmt.Errorf("inserting invocation: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return engine.Invocation{}, fmt.Errorf("committing invocation: %w", err)
	}
	return inv, nil
}

// Commit marks the invocation committed; committing twice is a no-op.
func (r *InvocationRepo) Commit(ctx context.Context, id uuid.UUID) error {
	res, err := r.db.ExecContext(ctx,
		`UPDATE node_invocations SET committed_at = ? WHERE id = ? AND committed_at IS NULL`,
		timeToString(r.now()), uuidToString(id))
	if err != nil {
		return fmt.Errorf("committing invocation: %w", err)
	}
	if n, err := res.RowsAffected(); err == nil && n == 1 {
		return nil
	}
	_, err = r.Get(ctx, id) // already committed => nil; unknown => ErrInvocationNotFound
	return err
}

// Get loads one invocation.
func (r *InvocationRepo) Get(ctx context.Context, id uuid.UUID) (engine.Invocation, error) {
	inv, err := scanInvocation(r.db.QueryRowContext(ctx, invocationSelect+` WHERE id = ?`, uuidToString(id)))
	if errors.Is(err, sql.ErrNoRows) {
		return engine.Invocation{}, fmt.Errorf("%w: %s", engine.ErrInvocationNotFound, id)
	}
	if err != nil {
		return engine.Invocation{}, fmt.Errorf("reading invocation: %w", err)
	}
	return inv, nil
}

func scanInvocation(s rowScanner) (engine.Invocation, error) {
	var idStr, runStr, nodeID, createdStr string
	var visit int
	var committed sql.NullString
	if err := s.Scan(&idStr, &runStr, &nodeID, &visit, &createdStr, &committed); err != nil {
		return engine.Invocation{}, err
	}
	id, err := parseUUID(idStr)
	if err != nil {
		return engine.Invocation{}, err
	}
	run, err := parseUUID(runStr)
	if err != nil {
		return engine.Invocation{}, err
	}
	created, err := parseTime(createdStr)
	if err != nil {
		return engine.Invocation{}, err
	}
	committedAt, err := nullStringToTimePtr(committed)
	if err != nil {
		return engine.Invocation{}, err
	}
	return engine.Invocation{ID: id, RunID: run, NodeID: nodeID, Visit: visit, CreatedAt: created, CommittedAt: committedAt}, nil
}
```

```go
type invocationRow struct {
	ID        string
	NodeID    string
	Visit     int
	Committed bool
}

// invocationRows reads the SINK: the persisted node_invocations rows of a run.
func invocationRows(t *testing.T, db *sql.DB, runID uuid.UUID) []invocationRow {
	t.Helper()
	rows, err := db.Query(`SELECT id, node_id, visit, committed_at IS NOT NULL FROM node_invocations WHERE run_id = ? ORDER BY node_id, visit`, runID.String())
	require.NoError(t, err)
	defer rows.Close()
	var out []invocationRow
	for rows.Next() {
		var r invocationRow
		require.NoError(t, rows.Scan(&r.ID, &r.NodeID, &r.Visit, &r.Committed))
		out = append(out, r)
	}
	require.NoError(t, rows.Err())
	return out
}

func waitState(t *testing.T, ds *domainStack, id uuid.UUID, want instance.State) {
	t.Helper()
	require.Eventually(t, func() bool {
		inst, err := ds.instanceRepo.Get(context.Background(), id)
		return err == nil && inst.State == want
	}, 20*time.Second, 50*time.Millisecond, "run never reached %s", want)
}

func TestInvocationWiring_NodeVisitsPersistAndBackEdgesGetNewInvocations(t *testing.T) {
	root := t.TempDir()
	ds, err := initDomain(context.Background(), writeInvocationRoot(t, root))
	require.NoError(t, err)
	t.Cleanup(func() { ds.Close(context.Background()) })

	id, _, err := ds.eng.Trigger(context.Background(), "inv-loop", map[string]any{}, "normal")
	require.NoError(t, err)
	waitState(t, ds, id, instance.StateCompleted)

	rows := invocationRows(t, ds.db, id)
	byNode := map[string][]invocationRow{}
	for _, r := range rows {
		assert.True(t, r.Committed, "every visit of a completed run is committed: %+v", r)
		byNode[r.NodeID] = append(byNode[r.NodeID], r)
	}
	require.Len(t, byNode["init"], 1)
	require.Len(t, byNode["bump"], 2, "the back-edge revisits bump once")
	require.Len(t, byNode["check"], 2)
	require.Len(t, byNode["finish"], 1)
	assert.Equal(t, []int{1, 2}, []int{byNode["bump"][0].Visit, byNode["bump"][1].Visit})
	assert.NotEqual(t, byNode["bump"][0].ID, byNode["bump"][1].ID, "loop revisits have distinct durable invocation ids")
}

func TestInvocationWiring_RestartReusesOpenInvocation(t *testing.T) {
	root := t.TempDir()
	configPath := writeInvocationRoot(t, root)

	first, err := initStartedDomain(context.Background(), configPath)
	require.NoError(t, err)
	id, _, err := first.eng.Trigger(context.Background(), "inv-wait", map[string]any{}, "normal")
	require.NoError(t, err)
	waitState(t, first, id, instance.StateWaiting)
	open := invocationRows(t, first.db, id)
	require.Len(t, open, 1)
	assert.Equal(t, "w", open[0].NodeID)
	assert.False(t, open[0].Committed, "a waiting visit stays open across the restart")
	first.Close(context.Background())

	second, err := initStartedDomain(context.Background(), configPath)
	require.NoError(t, err)
	t.Cleanup(func() { second.Close(context.Background()) })
	waitState(t, second, id, instance.StateCompleted)

	rows := invocationRows(t, second.db, id)
	require.Len(t, rows, 2, "w (reused, now committed) + after; a restart must not begin a second w visit")
	assert.Equal(t, open[0].ID, rows[1].ID, "rows are ordered by node: after, w")
	assert.Equal(t, "w", rows[1].NodeID)
	assert.True(t, rows[1].Committed)
	assert.Equal(t, 1, rows[1].Visit)
}
```
