## Alignment repair — required replacement work (2026-11-20)

**Replace check-then-write workspace mutation and close the production graph.** Retire the supplied `ServerWorkspaceResource.Acquire`/`Commit` implementations that only inspect `ListByRun` and separately call `Checkpoints.Commit`/`Homes.SetCheckpoint`. Group launcher/finalizer/gatherer must hold an actual P3 T3 resource claim for the full filesystem operation and commit/rollback, including the clean built-in path; returning early for an existing clean home provides no lock.

Change `engine.WorkspaceResource` to `Acquire(ctx,runID,dir,reason) (ResourceFenceRef,error)`, `Commit(ctx,claim,runID,dir) error`, and `Release(ctx,claim) error`. Each group mutation stores the returned claim, defers release, restores the committed ref under that claim, stages changed files as a candidate and passes it to `ResourceCommitter.CommitResource(ctx, claim, ref)`. `adapter/sqlite/resource_commit_repo.go:ResourceCommitRepo` checks the exact active claim/base in one transaction, promotes the prepared artifact and home pointer/dirty flag, then releases the claim. A snapshot-only/finalize-read still holds the lease through its entire read. A group persistence error cannot expose a partially published workspace. The mutation operation has a durable group-operation holder identity, not a random process-local label.

`buildWorkspaceMobility` constructs one shared `ResourceLeaseRepo`, `ResourceCommitRepo`, P2 `RemoteInboxRepo`, built-in `ProcessSupervisor`, and interactive `InteractiveSessionInventory`; pass them into every sync/transfer/recovery/group/removal/drain/commit consumer named by P3 T2/T3/T5/T6/T7/T10/T11/T12. Wire supervisor-backed command launching into all built-in harness selectors and `LocalProcessRunner`, rather than constructing a supervisor nobody uses. Require these collaborators at production startup; no fallback/no-op on missing data. Install the invocation completion sink at engine execution, forward `StepOutput.Completion` through routing, and defer job/checkpoint completion to the validated committer.

Extend real-root tests **before** wiring: `TestPhase3E2E_BuiltInCandidateLinkedToCommittedStep` asserts nonempty exact ref/job/resource; `TestPhase3E2E_InvalidExecutorOutputPreservesPriorWorkspace`; `TestPhase3E2E_CrashAfterPushBeforeEngineCommitRestoresPriorFiles`; `TestPhase3E2E_TwoSameRunnerWritersCannotOverlap`; `TestPhase3E2E_GroupMutationAndStepShareOneLease`; `TestPhase3E2E_SurvivingProcessStopsBeforeRestore`; `TestPhase3E2E_DrainWaitsForTargetPull`; and `TestPhase3E2E_DrainBuiltInSessionBlocks`. Destructively omit each root edge after green and assert its named sink test fails. Old E2Es that assert only an owner row or use a fake immediate result are retained as narrow regressions, not completion evidence.

**Required dependency order:** P3 T1 schema → T2 artifacts / T3 resource leases → T5 transaction contract → T6 attempt receipts → T7 scoped transfer → T8/T9 process path → T10/T11/T12 lifecycle consumers → this root → T14 read projection. Cross-phase P4 turn commits use the same candidate/resource boundary; they cannot publish a turn workspace with a later independent `Homes.SetCheckpoint`.

---

**Goal:** Group snapshot, finalize and gather take the run's workspace home before they read or write files on the server, and publish a checkpoint after they change them. The whole Phase 3 workspace-mobility stack is built at the real composition root and proved end to end through the served router with in-memory runner agents on real WebSocket and transfer endpoints.

**Architecture:**
- **Engine port.** `domain/engine/workspace_resource.go` adds the `WorkspaceResource` port. `GroupLauncher`, `GroupFileFinalizer` and `FileGatherer` call it at their three server-side mutation points:
  - the parent snapshot (before `launchWorkspace`);
  - the task finalize (before `FinalizeTask`);
  - the gather (`Acquire` before merging; `Commit` after `Apply`).
- **Runner implementation.** `domain/runner/group_resource.go:ServerWorkspaceResource` implements the port over the copy-tracking `HomeStore` (P3 T11), the `CheckpointStore` (P3 T2) and the `Ledger`:
  - it refuses while a step of the run holds the workspace;
  - it hands the home to the server and restores the latest checkpoint;
  - it publishes the mutated directory as the next checkpoint, so the next remote placement pulls it.
- **Composition root.** `cmd/arbitron/runner_mobility.go:buildWorkspaceMobility` is the only constructor of the Phase 3 server objects. `main.go` and `startRuntime` wire them:
  - the dispatcher workspace service, the adopter and the placement policy;
  - the transfer routes, the bundle store and the step committer;
  - pool recovery in place of `RecoverCrashedInstancesContext`;
  - removal hooks, the drain controller, recovery notices and home history.

**Tech Stack:** Go 1.25.5, hand-written SQL (modernc SQLite), chi v5, testify, `adapter/runner/hubtest` (P2 T4), the P2 T10 E2E helpers, and the P3 T9 runner-agent adapters.

```go
// recordingResource is an engine.WorkspaceResource that records every call
// with its load-bearing arguments (run, dir, reason) and runs per-call hooks,
// so a test can stand in for "restore the committed checkpoint into dir".
type recordingResource struct {
	mu         sync.Mutex
	calls      []string
	acquireErr error
	commitErr  error
	onAcquire  func(dir string) error
	onCommit   func(dir string) error
	order      *callLog // optional cross-fake ordering (group_finalize_test.go)
}

var _ engine.WorkspaceResource = (*recordingResource)(nil)

func (r *recordingResource) Acquire(_ context.Context, runID uuid.UUID, dir, reason string) error {
	r.mu.Lock()
	r.calls = append(r.calls, fmt.Sprintf("acquire %s %s %s", runID, dir, reason))
	hook, err := r.onAcquire, r.acquireErr
	r.mu.Unlock()
	if r.order != nil {
		r.order.add("Acquire")
	}
	if err != nil {
		return err
	}
	if hook != nil {
		return hook(dir)
	}
	return nil
}

func (r *recordingResource) Commit(_ context.Context, runID uuid.UUID, dir string) error {
	r.mu.Lock()
	r.calls = append(r.calls, fmt.Sprintf("commit %s %s", runID, dir))
	hook, err := r.onCommit, r.commitErr
	r.mu.Unlock()
	if r.order != nil {
		r.order.add("Commit")
	}
	if err != nil {
		return err
	}
	if hook != nil {
		return hook(dir)
	}
	return nil
}

	r.mu.Lock()
	defer r.mu.Unlock()
```

```go
// WorkspaceResource is the run's workspace ownership fence for the server-side
// group mutations (design phase 3 §2 "Group workspaces", RR-11). Acquire
// makes the server the run's workspace home and brings dir to the run's latest
// committed checkpoint before a mutation reads or writes it. Commit publishes
// dir as the run's next checkpoint after a mutation changed it, so the next
// remote placement pulls the mutated files instead of a stale copy.
type WorkspaceResource interface {
	Acquire(ctx context.Context, runID uuid.UUID, dir, reason string) (ResourceFenceRef, error)
	Commit(ctx context.Context, claim ResourceFenceRef, runID uuid.UUID, dir string) error
}

// SetWorkspaceResource makes every launch acquire the parent's working area
// before snapshotting it. nil keeps server-only behaviour (no runner pool).
func (l *GroupLauncher) SetWorkspaceResource(r WorkspaceResource) { l.resource = r }
```

```go
import (
	"context"
```

```go
// ResourceCommitter publishes a server-side resource mutation (P3 T13 group
// snapshot/finalize/gather) as the run's next COMMITTED checkpoint. One
// transaction checks the exact active server-side claim and the committed
// base, inserts the staged artifact as committed with the claim's resource
// fence, advances the home pointer, clears dirty and releases the claim. It
// never falls back to an independent Homes.SetCheckpoint.
type ResourceCommitter interface {
	CommitResource(ctx context.Context, claim engine.ResourceFenceRef, staged StagedCheckpoint) error
}
```

```go
package sqlite

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

// ResourceCommitRepo implements runner.ResourceCommitter over the SAME
// *sql.DB as the lease, catalog and step-commit repos.
type ResourceCommitRepo struct {
	db  *sql.DB
	now func() time.Time
}

var _ runner.ResourceCommitter = (*ResourceCommitRepo)(nil)

// NewResourceCommitRepo builds the repo.
func NewResourceCommitRepo(db *sql.DB) *ResourceCommitRepo {
	return &ResourceCommitRepo{db: db, now: func() time.Time { return time.Now().UTC() }}
}

// CommitResource runs the contracts "Server-side group mutation commit"
// transaction. A refused commit changes nothing and keeps the claim active:
// the caller's deferred Release frees it.
func (r *ResourceCommitRepo) CommitResource(ctx context.Context, claim engine.ResourceFenceRef, s runner.StagedCheckpoint) error {
	if s.RunID == uuid.Nil || claim.Key != runResourceKey(s.RunID) {
		return fmt.Errorf("%w: staged artifact of run %s does not belong to claim %s", runner.ErrInvalidCandidate, s.RunID, claim.Key)
	}
	ref := runner.CheckpointRef{RunID: s.RunID, Version: s.Version, ManifestHash: s.Manifest.Hash}
	// Artifact shape only (run, version >= 1, hash, archive): a candidate with
	// no job, resource or base is exactly what ValidateBootstrap checks.
	if err := (runner.CheckpointCandidate{Ref: ref, ArchivePath: s.ArchivePath, SizeBytes: s.SizeBytes}).ValidateBootstrap(); err != nil {
		return err
	}
	if !s.Base.IsZero() && (s.Base.RunID != s.RunID || s.Version <= s.Base.Version) {
		return fmt.Errorf("%w: %s does not follow base %s", runner.ErrInvalidCandidate, ref, s.Base)
	}
	if s.Resource != (engine.ResourceFenceRef{}) && s.Resource != claim {
		return fmt.Errorf("%w: artifact %s was staged under another claim", runner.ErrResourceFenced, ref)
	}
	run := uuidToString(s.RunID)
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("resource commit: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	// First statement takes the SQLite write lock before anything is read.
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_leases SET active = active WHERE resource_key = ?`, claim.Key); err != nil {
		return fmt.Errorf("resource commit: lock: %w", err)
	}
	if err := checkResourceFenceTx(ctx, tx, claim); err != nil {
		return err
	}
	rec, ok, err := readHolder(ctx, tx, claim)
	if err != nil {
		return err
	}
	if !ok || rec.Job != nil {
		return fmt.Errorf("%w: %s generation %d is not a server-side claim", runner.ErrResourceFenced, claim.Key, claim.Generation)
	}
	var owner string
	err = tx.QueryRowContext(ctx, `SELECT runner_id FROM workspace_homes WHERE run_id = ?`, run).Scan(&owner)
	if err != nil && !errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("resource commit: read home: %w", err)
	}
	if owner != claim.Owner && !(owner == string(runner.ServerHome) && claim.Owner == string(runner.BuiltInRunnerID)) {
		return fmt.Errorf("%w: run %s is homed on %q, claim owner is %q", runner.ErrHomeOwned, s.RunID, owner, claim.Owner)
	}
	cur, err := committedRefTx(ctx, tx, s.RunID)
	if err != nil {
		return err
	}
	if cur != s.Base.String() {
		return fmt.Errorf("%w: run %s artifact is based on %q, but the committed checkpoint is %q", runner.ErrCheckpointConflict, s.RunID, s.Base, cur)
	}
	now := timeToString(r.now())
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_checkpoints
		(run_id, version, manifest_hash, archive_path, size_bytes, job_id, job_generation, state, base_ref,
		 resource_key, resource_owner, resource_generation, resource_token, created_at)
		VALUES (?, ?, ?, ?, ?, NULL, NULL, 'committed', ?, ?, ?, ?, ?, ?)`,
		run, ref.Version, ref.ManifestHash, s.ArchivePath, s.SizeBytes, s.Base.String(),
		claim.Key, claim.Owner, claim.Generation, claim.Token.String(), now); err != nil {
		if isUniqueViolation(err) {
			return fmt.Errorf("%w: run %s v%d already registered", runner.ErrCheckpointConflict, s.RunID, ref.Version)
		}
		return fmt.Errorf("resource commit: insert: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_homes (run_id, updated_at) VALUES (?, ?) ON CONFLICT(run_id) DO NOTHING`, run, now); err != nil {
		return fmt.Errorf("resource commit: home row: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_homes SET checkpoint_version = ?, dirty = 0, non_portable_reason = '', updated_at = ? WHERE run_id = ?`,
		ref.Version, now, run); err != nil {
		return fmt.Errorf("resource commit: advance home pointer: %w", err)
	}
	if err := releaseResourceTx(ctx, tx, claim); err != nil {
		return err
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("resource commit: commit: %w", err)
	}
	return nil
}
```

```go
package runner

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"strings"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/google/uuid"

// ServerWorkspaceDeps are ServerWorkspaceResource's collaborators (all required).
type ServerWorkspaceDeps struct {
	Leases      ResourceLeaseStore // the ONE shared lease repo (P3 T3; built once in buildWorkspaceMobility)
	Commits     ResourceCommitter  // Cycle 3a ResourceCommitRepo; never an independent Homes.SetCheckpoint
	Homes       HomeStore          // copy-tracking homes (P3 T11) over WorkspaceHomeRepo (P3 T3)
	Checkpoints CheckpointStore    // P3 T2
	Ledger      Ledger             // P1
}

// ServerWorkspaceResource is the engine.WorkspaceResource for server-side group
// mutations (design phase 3 §2 "Group workspaces", RR-11). A mutation holds the
// run's single writer lease for its whole filesystem operation: Acquire claims
// it, brings dir to the committed checkpoint and makes the built-in runner the
// home; Commit stages dir and commits it under the exact claim; Release frees
// an uncommitted claim.
type ServerWorkspaceResource struct{ d ServerWorkspaceDeps }

var _ engine.WorkspaceResource = (*ServerWorkspaceResource)(nil)

// NewServerWorkspaceResource validates deps.
func NewServerWorkspaceResource(d ServerWorkspaceDeps) (*ServerWorkspaceResource, error) {
	var missing []string
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if d.Commits == nil {
		missing = append(missing, "Commits")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if d.Checkpoints == nil {
		missing = append(missing, "Checkpoints")
	}
	if d.Ledger == nil {
		missing = append(missing, "Ledger")
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: NewServerWorkspaceResource requires %s", strings.Join(missing, ", "))
	}
	return &ServerWorkspaceResource{d: d}, nil
}

// GroupHolder is the durable holder identity of a server-side group mutation:
// derived from the run and the mutation kind, never a random process-local
// label. The claim row also records the server boot ID (ResourceLeaseRepo), so
// P3 T10 recovery supersedes it after a restart with SupersedeServerRestart.
func GroupHolder(runID uuid.UUID, reason string) string {
	return "group:" + strings.ReplaceAll(reason, " ", "-") + "/run:" + runID.String()
}

// Acquire claims run:<runID> for this mutation and makes dir the committed
// content. It refuses with engine.ErrWorkspaceBusy while a workspace step of
// the run is active or holds the lease, and fails closed (home untouched) when
// a remote home has no committed checkpoint to restore.
func (s *ServerWorkspaceResource) Acquire(ctx context.Context, runID uuid.UUID, dir, reason string) (engine.ResourceFenceRef, error) {
	if runID == uuid.Nil || dir == "" {
		return engine.ResourceFenceRef{}, fmt.Errorf("runner: group workspace acquire needs a run and a directory")
	}
	jobs, err := s.d.Ledger.ListByRun(ctx, runID)
	if err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("runner: list jobs of run %s: %w", runID, err)
	}
	for _, j := range jobs {
		if j.State.HoldsSlot() && j.Op != OpChat && j.Op != OpStream {
			return engine.ResourceFenceRef{}, fmt.Errorf("%w: job %s (%s) on %q", engine.ErrWorkspaceBusy, j.ID, j.NodeID, j.RunnerID)
		}
	}
	holder := GroupHolder(runID, reason)
	claim, err := s.d.Leases.Claim(ctx, runKey(runID), holder, BuiltInRunnerID)
	if errors.Is(err, ErrResourceBusy) {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: %w", engine.ErrWorkspaceBusy, err)
	}
	if err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("runner: claim workspace of run %s: %w", runID, err)
	}
	if err := s.takeHome(ctx, runID, dir, reason, holder); err != nil {
		if rerr := s.d.Leases.Release(context.WithoutCancel(ctx), claim); rerr != nil {
			slog.Error("runner: releasing a failed group acquire's claim", "run", runID, "error", rerr)
		}
		return engine.ResourceFenceRef{}, err
	}
	return claim, nil
}

// takeHome runs under the claim: no job can claim the run meanwhile.
func (s *ServerWorkspaceResource) takeHome(ctx context.Context, runID uuid.UUID, dir, reason, holder string) error {
	home, err := s.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return fmt.Errorf("runner: read workspace home of run %s: %w", runID, err)
	}
	base, ok, err := s.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return fmt.Errorf("runner: read committed checkpoint of run %s: %w", runID, err)
	}
	switch {
	case !isServerLocal(home.RunnerID):
		if !ok {
			return fmt.Errorf("%w: run %s is homed on %q with no committed checkpoint to restore", ErrCheckpointNotFound, runID, home.RunnerID)
		}
		cause := HomeMoveCause{OperationID: holder, FromGeneration: home.Generation, ToGeneration: home.Generation + 1}
		if _, err := s.d.Homes.HandOff(ctx, runID, BuiltInRunnerID, "server: "+reason, 0, home.Generation, cause); err != nil {
			return fmt.Errorf("runner: move workspace of run %s to the server: %w", runID, err)
		}
		if err := s.d.Checkpoints.Restore(ctx, base, dir); err != nil {
			return fmt.Errorf("runner: restore committed checkpoint of run %s: %w", runID, err)
		}
	case home.RunnerID == ServerHome:
		if _, err := s.d.Homes.AcquireResource(ctx, runID, BuiltInRunnerID, home.Generation); err != nil {
			return fmt.Errorf("runner: acquire workspace of run %s: %w", runID, err)
		}
		if ok && (home.Dirty || home.CheckpointVersion != base.Version) {
			if err := s.restoreClean(ctx, runID, base, dir); err != nil {
				return err
			}
		}
	default: // built-in home
		if ok && (home.Dirty || home.CheckpointVersion != base.Version) {
			if err := s.restoreClean(ctx, runID, base, dir); err != nil {
				return err
			}
		}
	}
	return nil
}

func (s *ServerWorkspaceResource) restoreClean(ctx context.Context, runID uuid.UUID, base CheckpointRef, dir string) error {
	if err := s.d.Checkpoints.Restore(ctx, base, dir); err != nil {
		return fmt.Errorf("runner: restore committed checkpoint of run %s: %w", runID, err)
	}
	if err := s.d.Homes.MarkDirty(ctx, runID, false); err != nil {
		return fmt.Errorf("runner: mark workspace of run %s clean: %w", runID, err)
	}
	return nil
}

// Commit publishes dir as the run's next committed checkpoint under claim, in
// the committer's single transaction (which also releases the claim). A failed
// commit leaves the claim active for the caller's deferred Release.
func (s *ServerWorkspaceResource) Commit(ctx context.Context, claim engine.ResourceFenceRef, runID uuid.UUID, dir string) error {
	if claim.Key != runKey(runID) {
		return fmt.Errorf("%w: claim %s does not cover run %s", ErrResourceFenced, claim.Key, runID)
	}
	if err := s.d.Leases.Check(ctx, claim); err != nil {
		return err
	}
	base, _, err := s.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return fmt.Errorf("runner: read committed checkpoint of run %s: %w", runID, err)
	}
	staged, err := s.d.Checkpoints.StageResource(ctx, runID, dir, base)
	if err != nil {
		return fmt.Errorf("runner: stage group workspace of run %s: %w", runID, err)
	}
	staged.Resource = claim
	if err := s.d.Commits.CommitResource(ctx, claim, staged); err != nil {
		return fmt.Errorf("runner: commit group workspace of run %s: %w", runID, err)
	}
	return nil
}

// Release frees an uncommitted claim. A claim already released by a successful
// Commit (or a stale one) is a no-op: the lease store's exact-token release
// can never free a newer holder.
func (s *ServerWorkspaceResource) Release(ctx context.Context, claim engine.ResourceFenceRef) error {
	if err := s.d.Leases.Release(ctx, claim); err != nil && !errors.Is(err, ErrResourceFenced) {
		return err
	}
	return nil
}
```

```go
// buildWorkspaceMobility is the ONLY constructor of the Phase 3 server
// objects. It builds one lease repo, one checkpoint store and one copy-tracking
// home store and feeds every consumer from them.
func buildWorkspaceMobility(in workspaceMobilityInputs) (*workspaceMobility, error) {
	if m := in.missing(); len(m) > 0 {
		return nil, fmt.Errorf("workspace mobility: missing %s", strings.Join(m, ", "))
	}
	clock := in.Clock
	if clock == nil {
		clock = time.Now
	}
	rc := in.Runners
	m := &workspaceMobility{BootID: in.BootID, Supervisor: in.Supervisor, Policy: placementPolicy(rc)}

	// One lease repo bound to this process's boot ID (contracts §25).
	leases := adaptsqlite.NewResourceLeaseRepo(in.DB, in.BootID)
	m.Leases = leases

	// Checkpoints (P3 T2) and script bundles (P3 T8).
	m.Checkpoints = checkpoint.NewStore(rc.CheckpointDir, checkpoint.WithCatalog(adaptsqlite.NewCheckpointCatalogRepo(in.DB)))
	bundles, err := checkpoint.NewBundleStore(filepath.Join(rc.CheckpointDir, "bundles"))
	if err != nil {
		return nil, fmt.Errorf("workspace mobility: bundle store: %w", err)
	}
	m.Bundles = bundles

	// Copy fencing (P3 T11): the hub reconciles held copies on every hello, and
	// every home change goes through the copy-tracking store.
	copies := adaptsqlite.NewRunnerCopyRepo(in.DB)
	keeper, err := runner.NewCopyKeeper(runner.CopyKeeperDeps{Inventory: copies, Homes: in.Homes, Deleter: in.Hub})
	if err != nil {
		return nil, fmt.Errorf("workspace mobility: copy keeper: %w", err)
	}
	in.Hub.SetCopyReconciler(keeper)
	m.Homes = runner.NewCopyTrackingHomes(in.Homes, keeper)

	// Transfer tokens (P3 T7): live job fence AND live resource claim.
	m.Tokens = runner.NewTransferTokenService(adaptsqlite.NewTransferSessionRepo(in.DB), in.Ledger, leases, clock)

	// Workspace sync (P3 T6) and baseline (P3 T6 Cycle 2).
	m.Sync = runner.NewWorkspaceSync(runner.SyncDeps{
		Checkpoints: m.Checkpoints, Homes: m.Homes, Leases: leases, Ledger: in.Ledger, Tokens: m.Tokens,
		Events: in.Events, Status: in.Status, Sizes: in.Workspaces, Clock: clock,
	})
	m.Baseline = runner.NewWorkspaceBaselineInitializer(runner.BaselineDeps{
		Checkpoints: m.Checkpoints, Ledger: in.Ledger, Leases: leases, Homes: m.Homes,
	})

	// Remote agent/process jobs (P3 T8).
	in.Hub.SetWorkspaceJobs(runner.WorkspaceJobDeps{
		Sync: m.Sync, Tokens: m.Tokens, Capabilities: in.Capabilities, PartBytes: rc.TransferPartBytes,
	})

	// Transfer endpoints (P3 T7).
	m.Transfers = adapthttp.NewRunnerTransferHandler(adapthttp.TransferHandlerDeps{
		Keys: in.Keys, Tokens: m.Tokens, Checkpoints: m.Checkpoints, Sync: m.Sync, Bundles: bundles,
		StagingDir: rc.StagingDir, PartBytes: rc.TransferPartBytes,
		StagingRetention: time.Duration(rc.StagingRetentionSeconds) * time.Second, Clock: clock,
	})

	// Durable commits (P3 T5 steps; Cycle 3a group mutations).
	m.Commits = adaptsqlite.NewStepCommitRepo(in.DB)
	m.Resources = adaptsqlite.NewResourceCommitRepo(in.DB)

	// Recovery and adoption (P3 T10).
	if m.Recovery, err = runner.NewPoolRecovery(runner.RecoveryDeps{
		Inbox: adaptsqlite.NewRemoteInboxRepo(in.DB), // stateless over the same DB as the hub's inbox (P2 T10)
		Leases: leases, Stopper: in.Supervisor, Ledger: in.Ledger, Homes: m.Homes, Restorer: m.Sync,
		Commits: m.Commits, Grace: in.Hub, Events: in.Events, Status: in.Status, Clock: clock,
		RestartGrace: time.Duration(rc.RestartGraceSeconds) * time.Second,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: pool recovery: %w", err)
	}
	if m.Adopter, err = runner.NewJobAdopter(runner.AdoptDeps{
		Ledger: in.Ledger, Registry: in.Registry, Hub: in.Hub, Events: in.Events, Status: in.Status, Clock: clock,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: job adopter: %w", err)
	}
	m.Notices = runner.NewRecoveryNoticeSource(in.Ledger)

	// Removal (P3 T11): the engine fires the hook; group code gets the decorated manager.
	if m.Removal, err = runner.NewRemovalNotifier(runner.RemovalDeps{
		Inventory: copies, Homes: m.Homes, Checkpoints: m.Checkpoints, Deleter: in.Hub,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: removal notifier: %w", err)
	}
	m.Workspaces = engine.WithWorkspaceRemovalHook(in.Workspaces, m.Removal)

	// Drain (P3 T12): pull-only maintenance transfers, durable items, session blockers.
	drainItems := adaptsqlite.NewDrainItemRepo(in.DB)
	if m.Pulls, err = runner.NewWorkspacePullCoordinator(runner.PullCoordinatorDeps{
		Hub: in.Hub, Tokens: m.Tokens, Leases: leases, Items: drainItems, Clock: clock,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: pull coordinator: %w", err)
	}
	if m.Drain, err = runner.NewDrainController(runner.DrainDeps{
		Pulls: m.Pulls, Sessions: in.Sessions, Leases: leases, Registry: in.Registry, Ledger: in.Ledger,
		Homes: m.Homes, Store: drainItems, Events: in.Events, Notifier: in.Notifier, Policy: m.Policy,
		Sizes: m.Sync, Clock: clock,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: drain controller: %w", err)
	}
	m.History = runner.NewWorkspaceHistorySource(m.Homes)

	// Group mutations (Cycle 3) share the SAME lease repo as every step.
	if m.Resource, err = runner.NewServerWorkspaceResource(runner.ServerWorkspaceDeps{
		Leases: leases, Commits: m.Resources, Homes: m.Homes, Checkpoints: m.Checkpoints, Ledger: in.Ledger,
	}); err != nil {
		return nil, fmt.Errorf("workspace mobility: group workspace resource: %w", err)
	}
	return m, nil
}
```

```go
// startWorkspaceRunner creates a runner key over REST and runs a real
// runneragent.Agent through the real wsclient with the P3 T9 workspace stack.
// caps defaults to process + agent.
func startWorkspaceRunner(t *testing.T, st *p3Stack, name string, caps ...string) *p3Runner {
	t.Helper()
	plaintext, runnerID, keyID := rrCreateKey(t, st.rr(), name)
	xfer := &countingTransfer{inner: transfer.NewClient(st.srv.URL, plaintext, nil, nil)}
	localRoot := t.TempDir()
	copyStore, err := copies.NewFileStore(t.TempDir())
	require.NoError(t, err)
	syncer, err := workspace.NewSyncer(workspace.SyncerDeps{WorkspaceRoot: st.workspaceDir, LocalRoot: localRoot, Transfer: xfer, Copies: copyStore})
	require.NoError(t, err)
	bundles, err := executor.NewBundleCache(t.TempDir(), xfer)
	require.NoError(t, err)
	jobs, err := executor.NewWorkspaceJobs(executor.WorkspaceJobsDeps{
		Syncer: syncer, Bundles: bundles, Process: process.NewLocalProcessRunner(),
		ClaudeBinary: st.runnerClaude, MaxResponseBytes: 1 << 20,
	})
	require.NoError(t, err)
	client, err := wsclient.New(wsclient.Options{ServerURL: st.srv.URL, RunnerKey: plaintext})
	require.NoError(t, err)
	conn := newRRConn(client)
	_, priv, err := ed25519.GenerateKey(rand.Reader)
	require.NoError(t, err)
	if len(caps) == 0 {
		caps = []string{runneragent.OpProcess, runneragent.OpAgent}
	}
	agent, err := runneragent.New(runneragent.Config{
		OS: "darwin", Arch: "arm64",
		ProtocolVersion: runnerproto.ProtocolVersion, RunnerVersion: "0.0.0-test",
		HarnessVersions: map[string]string{"claude": "2.1.300 (Claude Code)"},
		WorkspaceRoot:   st.workspaceDir, ScratchRoot: t.TempDir(),
		Capabilities: caps,
		Heartbeat:    time.Second, ProbeInterval: time.Minute,
		BackoffBase: 50 * time.Millisecond, BackoffCap: 200 * time.Millisecond,
	}, runneragent.Deps{
		Conn: conn, Exec: p3WorkspaceExec{jobs: jobs}, Sources: rrSources{}, Telemetry: rrTelemetry{t: runner.Telemetry{}},
		Spool: runneragent.NewMemorySpool(1024), Identity: rrIdentity{key: priv}, Copies: syncer,
	})
	require.NoError(t, err)
	ctx, cancel := context.WithCancel(context.Background())
	done := make(chan struct{})
	go func() {
		defer close(done)
		_ = agent.Run(ctx)
	}()
	t.Cleanup(func() {
		cancel()
		<-done
	})
	rrAwaitLiveness(t, st.rr(), runnerID, "online")
	return &p3Runner{id: runnerID, keyID: keyID, conn: conn, localRoot: localRoot, xfer: xfer}
}

	require.Eventually(t, func() bool {
		var err error
		inst, err = ds.instanceRepo.Get(context.Background(), id)
		return err == nil && inst.State.IsTerminal()
	}, within, 50*time.Millisecond, "run %s never reached a terminal state", id)
	if inst.State != instance.StateCompleted {
		errs := rrStrings(t, ds, `SELECT node_id || ': ' || error FROM node_executions WHERE instance_id = ? AND error IS NOT NULL AND error != ''`, id.String())

// p3Output is the latest succeeded output of node in run.
func p3Output(t *testing.T, ds *domainStack, id uuid.UUID, node string) string {
	t.Helper()
	outs := rrStrings(t, ds, `SELECT COALESCE(output, '') FROM node_executions WHERE instance_id = ? AND node_id = ? AND status = 'succeeded' ORDER BY started_at DESC`, id.String(), node)
	require.NotEmpty(t, outs, "node %s of run %s has no succeeded execution", node, id)
	return outs[0]
}

// p3CompletedOn lists, in order, the runners whose job for node completed.
func p3CompletedOn(t *testing.T, ds *domainStack, id uuid.UUID, node string) []string {
	t.Helper()

}

// p3HomeOwner never calls require: safe inside Eventually.
func p3HomeOwner(ds *domainStack, id uuid.UUID) (string, bool) {

	err := ds.db.QueryRow(`SELECT runner_id FROM workspace_homes WHERE run_id = ?`, id.String()).Scan(&owner)
	return owner, err == nil
}

// p3NoticeCount counts recovery notices on node's executions in the trace.

	t.Helper()
	trace, err := ds.eng.GetTrace(adminCtxForLocalUser(t, ds), id)
	require.NoError(t, err)
	n := 0

		if e.NodeID == node {
			n += len(e.Recovery)
		}
	}
	return n
}

	t.Helper()
	b, err := os.ReadFile(path)
	if os.IsNotExist(err) {
		return 0
	}
	require.NoError(t, err)
	return strings.Count(string(b), "\n")
}
```

```go
package main

import (
	"context"
	"log/slog"
	"time"

	"github.com/arbitron/arbitron/adapter/checkpoint"
)

// checkpointPruneInterval is how often orphaned checkpoint artifacts are reclaimed after boot.
const checkpointPruneInterval = time.Hour

type checkpointPruner interface {
	Prune(ctx context.Context, now time.Time) (checkpoint.PruneReport, error)
}

// startCheckpointPruner prunes once immediately, then on every tick, until ctx ends.
// The returned channel closes when the loop has stopped.
func startCheckpointPruner(ctx context.Context, p checkpointPruner, ticks <-chan time.Time, now func() time.Time, log *slog.Logger) <-chan struct{} {
	if p == nil {
		panic("arbitron: checkpoint pruner is required when workspace mobility is enabled")
	}
	if log == nil {
		log = slog.Default()
	}
	run := func(at time.Time) {
		rep, err := p.Prune(ctx, at)
		if err != nil {
			log.Warn("checkpoint prune failed; retrying next tick", "error", err)
			return
		}
		log.Info("checkpoint prune", "archives", rep.Archives, "markers", rep.Markers, "cache", rep.CacheEntries, "scratch", rep.ScratchDirs, "bytes", rep.Bytes, "skippedHeldRuns", rep.SkippedHeldRuns)
	}
	stopped := make(chan struct{})
	go func() {
		defer close(stopped)
		run(now())
		for {
			select {
			case <-ctx.Done():
				return
			case at := <-ticks:
				run(at)
			}
		}
	}()
	return stopped
}
```
