## Alignment repair — required replacement work (2026-11-20)

**Replace check-then-write workspace mutation and close the production graph.** Retire the supplied `ServerWorkspaceResource.Acquire`/`Commit` implementations that only inspect `ListByRun` and separately call `Checkpoints.Commit`/`Homes.SetCheckpoint`. Group launcher/finalizer/gatherer must hold an actual P3 T3 resource claim for the full filesystem operation and commit/rollback, including the clean built-in path; returning early for an existing clean home provides no lock.

Change `engine.WorkspaceResource` to `Acquire(ctx,runID,dir,reason) (ResourceFenceRef,error)`, `Commit(ctx,claim,runID,dir) error`, and `Release(ctx,claim) error`. Each group mutation stores the returned claim, defers release, restores the committed ref under that claim, stages changed files as a candidate and passes it to `ResourceCommitter.CommitResource(ctx, claim, ref)`. `adapter/sqlite/resource_commit_repo.go:ResourceCommitRepo` checks the exact active claim/base in one transaction, promotes the prepared artifact and home pointer/dirty flag, then releases the claim. A snapshot-only/finalize-read still holds the lease through its entire read. A group persistence error cannot expose a partially published workspace. The mutation operation has a durable group-operation holder identity, not a random process-local label.

`buildWorkspaceMobility` constructs one shared `ResourceLeaseRepo`, `ResourceCommitRepo`, P2 `RemoteInboxRepo`, built-in `ProcessSupervisor`, and interactive `InteractiveSessionInventory`; pass them into every sync/transfer/recovery/group/removal/drain/commit consumer named by P3 T2/T3/T5/T6/T7/T10/T11/T12. Wire supervisor-backed command launching into all built-in harness selectors and `LocalProcessRunner`, rather than constructing a supervisor nobody uses. Require these collaborators at production startup; no fallback/no-op on missing data. Install the invocation completion sink at engine execution, forward `StepOutput.Completion` through routing, and defer job/checkpoint completion to the validated committer.

Extend real-root tests **before** wiring: `TestPhase3E2E_BuiltInCandidateLinkedToCommittedStep` asserts nonempty exact ref/job/resource; `TestPhase3E2E_InvalidExecutorOutputPreservesPriorWorkspace`; `TestPhase3E2E_CrashAfterPushBeforeEngineCommitRestoresPriorFiles`; `TestPhase3E2E_TwoSameRunnerWritersCannotOverlap`; `TestPhase3E2E_GroupMutationAndStepShareOneLease`; `TestPhase3E2E_SurvivingProcessStopsBeforeRestore`; `TestPhase3E2E_DrainWaitsForTargetPull`; and `TestPhase3E2E_DrainBuiltInSessionBlocks`. Destructively omit each root edge after green and assert its named sink test fails. Old E2Es that assert only an owner row or use a fake immediate result are retained as narrow regressions, not completion evidence.

**Required dependency order:** P3 T1 schema → T2 artifacts / T3 resource leases → T5 transaction contract → T6 attempt receipts → T7 scoped transfer → T8/T9 process path → T10/T11/T12 lifecycle consumers → this root → T14 read projection. Cross-phase P4 turn commits use the same candidate/resource boundary; they cannot publish a turn workspace with a later independent `Homes.SetCheckpoint`.

---

**Goal:** Group snapshot, finalize and gather take the run's workspace home before they read or write files on the server, and publish a checkpoint after they change them. The whole Phase 3 workspace-mobility stack is built at the real composition root and proved end to end through the served router with in-memory runner agents on real WebSocket and transfer endpoints.

**Architecture:**
- **Engine port.** `domain/engine/workspace_resource.go` adds the `WorkspaceResource` port. `GroupLauncher`, `GroupFileFinalizer` and `FileGatherer` call it at their three server-side mutation points:
  - the parent snapshot (before `launchWorkspace`);
  - the task finalize (before `FinalizeTask`);
  - the gather (`Acquire` before merging; `Commit` after `Apply`).
- **Runner implementation.** `domain/runner/group_resource.go:ServerWorkspaceResource` implements the port over the copy-tracking `HomeStore` (P3 T11), the `CheckpointStore` (P3 T2) and the `Ledger`:
  - it refuses while a step of the run holds the workspace;
  - it hands the home to the server and restores the latest checkpoint;
  - it publishes the mutated directory as the next checkpoint, so the next remote placement pulls it.
- **Composition root.** `cmd/arbitron/runner_mobility.go:buildWorkspaceMobility` is the only constructor of the Phase 3 server objects. `main.go` and `startRuntime` wire them:
  - the dispatcher workspace service, the adopter and the placement policy;
  - the transfer routes, the bundle store and the step committer;
  - pool recovery in place of `RecoverCrashedInstancesContext`;
  - removal hooks, the drain controller, recovery notices and home history.

**Tech Stack:** Go 1.25.5, hand-written SQL (modernc SQLite), chi v5, testify, `adapter/runner/hubtest` (P2 T4), the P2 T10 E2E helpers, and the P3 T9 runner-agent adapters.

// WorkspaceResource is the run's workspace ownership fence for the server-side
// group mutations (design phase 3 §2 "Group workspaces", RR-11). Acquire
// makes the server the run's workspace home and brings dir to the run's latest
// committed checkpoint before a mutation reads or writes it. Commit publishes
// dir as the run's next checkpoint after a mutation changed it, so the next
// remote placement pulls the mutated files instead of a stale copy.
type WorkspaceResource interface {
	Acquire(ctx context.Context, runID uuid.UUID, dir, reason string) (ResourceFenceRef, error)
	Commit(ctx context.Context, claim ResourceFenceRef, runID uuid.UUID, dir string) error
}

// ErrWorkspaceBusy reports that a step of the run holds its working area on a
// runner, so a server-side mutation must not touch it now.
var ErrWorkspaceBusy = errors.New("engine: a step of the run is using its working area")

// SetWorkspaceResource makes every launch acquire the parent's working area
// before snapshotting it. nil keeps server-only behaviour (no runner pool).
func (l *GroupLauncher) SetWorkspaceResource(r WorkspaceResource) { l.resource = r }

func startWorkspaceRunner(t *testing.T, st *p3Stack, name string, caps ...string) *p3Runner {

	require.NoError(t, err)

	require.NoError(t, err)
	jobs, err := executor.NewWorkspaceJobs(executor.WorkspaceJobsDeps{
		Syncer: syncer, Bundles: bundles, Process: process.NewLocalProcessRunner(),
		ClaudeBinary: st.runnerClaude, MaxResponseBytes: 1 << 20,
	})
	require.NoError(t, err)
	client, err := wsclient.New(wsclient.Options{ServerURL: st.srv.URL, RunnerKey: plaintext})

// p3RequireCompleted waits up to within for a terminal state and fails with
// the node errors unless the run completed.
func p3RequireCompleted(t *testing.T, ds *domainStack, id uuid.UUID, within time.Duration) {
	t.Helper()
	var inst *instance.Instance
	require.Eventually(t, func() bool {
		var err error
		inst, err = ds.instanceRepo.Get(context.Background(), id)
		return err == nil && inst.State.IsTerminal()
	}, within, 50*time.Millisecond, "run %s never reached a terminal state", id)
	if inst.State != instance.StateCompleted {
		errs := rrStrings(t, ds, `SELECT node_id || ': ' || error FROM node_executions WHERE instance_id = ? AND error IS NOT NULL AND error != ''`, id.String())
		t.Fatalf("run %s ended %s; node errors: %v", id, inst.State, errs)
	}
}

// p3Output is the latest succeeded output of node in run.
func p3Output(t *testing.T, ds *domainStack, id uuid.UUID, node string) string {
	t.Helper()
	outs := rrStrings(t, ds, `SELECT COALESCE(output, '') FROM node_executions WHERE instance_id = ? AND node_id = ? AND status = 'succeeded' ORDER BY started_at DESC`, id.String(), node)
	require.NotEmpty(t, outs, "node %s of run %s has no succeeded execution", node, id)
	return outs[0]
}

// p3CompletedOn lists, in order, the runners whose job for node completed.
func p3CompletedOn(t *testing.T, ds *domainStack, id uuid.UUID, node string) []string {
	t.Helper()
	return rrStrings(t, ds, `SELECT runner_id FROM runner_jobs WHERE run_id = ? AND node_id = ? AND state = 'completed' ORDER BY created_at`, id.String(), node)
}

// p3HomeOwner never calls require: safe inside Eventually.
func p3HomeOwner(ds *domainStack, id uuid.UUID) (string, bool) {
	var owner string
	err := ds.db.QueryRow(`SELECT runner_id FROM workspace_homes WHERE run_id = ?`, id.String()).Scan(&owner)
	return owner, err == nil
}

// p3NoticeCount counts recovery notices on node's executions in the trace.
func p3NoticeCount(t *testing.T, ds *domainStack, id uuid.UUID, node string) int {
	t.Helper()
	trace, err := ds.eng.GetTrace(adminCtxForLocalUser(t, ds), id)
	require.NoError(t, err)
	n := 0
	for _, e := range trace {
		if e.NodeID == node {
			n += len(e.Recovery)
		}
	}
	return n
}

func p3CountLines(t *testing.T, path string) int {
	t.Helper()
	b, err := os.ReadFile(path)
	if os.IsNotExist(err) {
		return 0
	}
	require.NoError(t, err)
	return strings.Count(string(b), "\n")
}

// Design §8 Edge: workspace deletion reaches a runner that was offline when
// the run's workspace was removed; the server checkpoints go with it.
func TestPhase3E2E_RemovalReachesOfflineRunner(t *testing.T) {
	st := bootP3Stack(t, map[string]p3Workflow{
		"p3-wait-end":   {manifest: p3WaitEndManifest, files: p3Files(nil)},

		if st.ds.db.QueryRow(`SELECT state FROM runner_copies WHERE run_id = ? AND runner_id = ?`, id.String(), mac1.id).Scan(&s) != nil {
			return ""
		}
		return s
	}

	require.NoError(t, st.ds.db.QueryRow(`SELECT COUNT(*) FROM workspace_checkpoints WHERE run_id = ?`, id.String()).Scan(&checkpoints))

		30*time.Second, 50*time.Millisecond, "SINK: the reconnecting runner deletes its copy")
	mac1.conn.cut()
	mac1.conn.allow()
	require.Eventually(t, func() bool { return copyState() == "deleted" }, 30*time.Second, 50*time.Millisecond,
		"the next hello confirms the deletion")

func TestPhase3E2E_ParallelBranchesPlaceIndependentlyAndGatherSeesAll(t *testing.T) {

	for _, task := range run.Tasks {
		switch task.Key {
		case "a":
			onA = p3CompletedOn(t, st.ds, task.ChildInstanceID, "a-run")
		case "b":
			onB = p3CompletedOn(t, st.ds, task.ChildInstanceID, "b-run")
		}
	}

	require.Len(t, onB, 1)
