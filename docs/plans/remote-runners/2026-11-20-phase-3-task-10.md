# Remote Runners — Phase 3 Task 10: Pool-aware restart recovery, job adoption and the recovery notice

## Resolution amendment — RR-08 non-portable homes (decision 2026-11-22)

Decision (recorded in P3 T2 "Portable Git producer" and the Phase 3 design RR-08 row): Arbitron never fetches promisor objects over the network. A run whose repository has required promisor objects missing locally gets a **non-portable home**: it is pinned to the built-in runner, excluded from remote placement and load moves, and its steps keep running on the built-in runner as today, with no step failure. The marker clears automatically when a later built-in checkpoint attempt finds all objects present. Partial clones are a Non-Goal for remote execution. This amendment is authoritative over conflicting text below.

**DECISION (2026-11-22) RR-17: B** — non-portable homes get a **local checkpoint**. After each workspace-changing step completes, the server takes a plain copy of the home directory on its own disk. The copy is committed in the same step transaction, and only the latest is kept (P3 T16, `docs/plans/remote-runners/2026-11-20-phase-3-task-16.md`). This task **consumes P3 T16**, which runs after P3 T6 and before this task. PoolRecovery treats a non-portable home exactly like a portable built-in home: it fences and stops the interrupted writer, supersedes the claim, then calls the unchanged `RecoveryDeps.Restorer.RestoreBuiltIn`. That call is P3 T16's non-portable branch: it restores the latest committed local checkpoint, or else the home's initial state. The step then repeats under the same generation and resource fences. Only when no recovery base exists at all does `RestoreBuiltIn` return `runner.ErrNoRecoveryBase`. PrepareRun then records the durable `job.recovery_blocked` pool event and fails only that run with the visible reason; it never re-enters the step against dirty files. Replace the former `TestPoolRecovery_NonPortableHomeSkipsRestore` success expectation with `TestPoolRecovery_NonPortableHomeRestoresLocalCheckpointAndRepeats`, RED first. Keep `TestPoolRecovery_NonPortableMissingBaseShowsRecoveryBlocker` only for the no-checkpoint-at-all edge case. Both are specified in "RR-17 decision B — non-portable recovery" below.

---

**Goal:** Replace startup recovery's blanket `SetFailed` with pool-aware recovery: every `running` run re-enters its current step; live remote jobs get their leases extended by the restart grace and are adopted (no repeat) when their runner comes back, or recovered when it does not; interrupted built-in jobs are fenced, the last committed checkpoint is restored and the step repeats; committed steps replay without repeating. The step shows `recovering` while it waits, and every read of an affected run carries the persistent notice "interrupted work may repeat external effects; exactly-once effects are not guaranteed".

**Architecture:** The engine gets the policy seam (`RecoveryPolicy`, `RecoverRunningInstances`) and a read-side port for notices (`RecoveryNoticeSource`); the engine never imports `runner`. `domain/runner/recovery.go:PoolRecovery` implements the policy over the ledger, homes, step commits and `WorkspaceSync.RestoreBuiltIn`; `domain/runner/adopt.go:JobAdopter` is the dispatcher's adoption branch (a live job found by `EnsureIntent` after a restart is awaited, never re-dispatched); `domain/runner/hub_adopt.go` gives the hub a mailbox for results that arrive with no in-flight `Run` (replayed after reconnect) and a restart-grace window. Notices are derived, not stored separately: every ledger attempt that ended `runner_lost` (restart of a built-in job, lost runner, revoked key) is a notice.

**Tech Stack:** Go 1.25.5, testify, `sync`, existing engine fixtures (`newTestFixtures`, `snapshotOf`).

**Ordering / dependencies:** after P3 T1–T9 and **P3 T16** (Cycles 1–5: local checkpoints for non-portable homes, RR-17 B), which this task consumes through `WorkspaceSync.RestoreBuiltIn` and `runner.ErrNoRecoveryBase`. P3 T13 wires the root, and P3 T16 Cycle 6 proves the non-portable recovery sink. Cycles 2a–2e (the built-in process supervisor) have no dependency beyond the landed P1 ledger and 044 schema. They unblock Cycle 3 and P4 T10 Cycle 5.

**Spec / Design:** spec "Recovery and session continuity"; `docs/designs/2026-11-19-remote-runners-design-phase-3.md` §2 (Crash recovery, Run re-entry rows), §3.5 (Adoption, Lost runner, Server restart, Execution status), §4 "Server restart", §7 ("A runner that misses the restart grace goes lost…", "Repeated external effects… persistent recovery notice"), §8 Edge-case ("On a server restart, remote jobs re-attach with no repeat, and built-in steps repeat"; "A runner that is down for the whole restart grace becomes lost and is recovered"), regression ("crash after result/checkpoint commit but before engine advancement replays without repeating the completed step"). // domain/engine/recovery.go
```go
package engine

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"time"

	"github.com/arbitron/arbitron/domain/instance"
	"github.com/arbitron/arbitron/domain/workflow"
	"github.com/google/uuid"
)

// RecoveryAction is the pool's verdict for one running run at startup.
type RecoveryAction string

const (
	// RecoveryResume re-enters the current step: a live remote job is adopted
	// by the dispatcher, an interrupted built-in job was fenced and its
	// workspace restored, so the step repeats.
	RecoveryResume RecoveryAction = "resume"
	// RecoveryReplayCommitted re-enters the current step whose result is
	// already durably committed; the run loop replays it (P3 T5) and nothing
	// is restored or repeated.
	RecoveryReplayCommitted RecoveryAction = "replay_committed"
	// RecoveryFail marks the run failed (today's behaviour) — used when the
	// pool cannot safely recover it.
	RecoveryFail RecoveryAction = "fail"
)

// RecoveryPolicy prepares one running run for re-entry (runner.PoolRecovery).
type RecoveryPolicy interface {
	PrepareRun(ctx context.Context, inst *instance.Instance) (RecoveryAction, error)
}

const EventTypeInstanceRecovered = "instance.recovered"

var ErrNoRecoveryPolicy = errors.New("engine: RecoverRunningInstances needs a recovery policy")

// nonResumableOnRestart: steps whose re-entry would duplicate work owned by
// another reconciler, or whose session cannot move before Phase 4. They keep
// today's crash behaviour (failed; the spawn/group reconcilers settle them).
var nonResumableOnRestart = map[workflow.NodeType]string{
	workflow.NodeTypeInteractiveLLM:   "interactive steps are not resumed after a restart",
	workflow.NodeTypeInteractiveAgent: "interactive steps are not resumed after a restart",
	workflow.NodeTypeSpawnWorkflow:    "spawn steps are settled by the spawn reconciler",
	workflow.NodeTypeParallelGroup:    "group steps are settled by the group coordinator",
}

// RecoverRunningInstances replaces RecoverCrashedInstancesContext at startup
// (design §3.5): every running run whose current step can re-enter is
// prepared by rec and restarted through StartInstance; the rest are failed
// synchronously exactly as before. A SetFailed or StartInstance error aborts
// startup; a policy error fails only that run.
func (e *Engine) RecoverRunningInstances(ctx context.Context, rec RecoveryPolicy) error {
	if rec == nil {
		return ErrNoRecoveryPolicy
	}
	running, err := e.instances.ListRunning(ctx)
	var corrupt *instance.CorruptPinsError
	if errors.As(err, &corrupt) {
		for _, id := range corrupt.IDs {
			if ferr := e.failCorruptRun(ctx, id, false); ferr != nil {
				return ferr
			}
		}
	} else if err != nil {
		return fmt.Errorf("failed to list running instances: %w", err)
	}

	for _, inst := range running {
		node := ""
		if inst.CurrentNodeID != nil {
			node = *inst.CurrentNodeID
		}
		if reason := nonResumable(inst, node); reason != "" {
			if err := e.failRecovered(ctx, inst.ID, node, reason); err != nil {
				return err
			}
			continue
		}
		action, perr := rec.PrepareRun(ctx, inst)
		if perr != nil {
			slog.Error("recovery preparation failed", "instanceID", inst.ID, "error", perr)
			if err := e.failRecovered(ctx, inst.ID, node, "recovery preparation failed"); err != nil {
				return err
			}
			continue
		}
		switch action {
		case RecoveryResume, RecoveryReplayCommitted:
			e.eventBus.Publish(inst.ID, Event{Type: EventTypeInstanceRecovered, Timestamp: time.Now(), Data: map[string]any{
				"reason": "restart", "action": string(action), "nodeId": node, "notice": instance.RecoveryNoticeText,
			}})
			if err := e.StartInstance(ctx, inst.ID); err != nil {
				return fmt.Errorf("resuming instance %s: %w", inst.ID, err)
			}
		case RecoveryFail:
			if err := e.failRecovered(ctx, inst.ID, node, "the pool could not recover the run"); err != nil {
				return err
			}
		default:
			return fmt.Errorf("recovery policy returned unknown action %q for %s", action, inst.ID)
		}
	}
	return nil
}

// nonResumable returns "" when the run can re-enter its current step.
func nonResumable(inst *instance.Instance, node string) string {
	_, nodes, _, err := parseWorkflowGraph(inst.WorkflowSnapshot)
	if err != nil {
		return "workflow snapshot cannot be parsed"
	}
	if node == "" {
		return ""
	}
	n, ok := nodes[node]
	if !ok {
		return "current node is not in the workflow snapshot"
	}
	return nonResumableOnRestart[n.Type]
}

func (e *Engine) failRecovered(ctx context.Context, id uuid.UUID, node, detail string) error {
	if err := e.instances.SetFailed(ctx, id, node); err != nil {
		return fmt.Errorf("failed to set instance %s as failed: %w", id, err)
	}
	e.eventBus.Publish(id, Event{Type: EventTypeInstanceRecovered, Timestamp: time.Now(), Data: map[string]any{
		"reason": "restart", "action": string(RecoveryFail), "nodeId": node, "detail": detail,
	}})
	return nil
}
```

**Persisted state contract (044 `builtin_processes(job_id, generation, guardian_pid, process_start_marker, state)`; no new columns):**

| `state` | Written by | Meaning |
|---|---|---|
| `permitted` | `Permit`, inside a transaction that also checks that the ledger fence is live (`runner_jobs` row is `builtin` and `offered`/`running`), **before** the guardian is spawned. `guardian_pid = 0` and `process_start_marker = ''`. | A guardian may exist, but it is blocked on its release pipe and cannot do real work. If the server dies, the pipe closes and the guardian exits with code 97. |
| `running` | `Record`, using compare-and-set from `permitted`, after `cmd.Start`, with the guardian PID (= process-group ID) and its start marker. The guardian is released only after this write commits. | Real work may be running in process group `guardian_pid`. |
| `stopped` | `MarkStopped`, using compare-and-set from the observed state. It is written only after the whole group is confirmed gone (`kill(-pgid, 0) == ESRCH`, and the in-process leader has been reaped), after an unreleased permit is closed, or when nothing was ever permitted. | No process of this job generation can write. `ResourceLeaseRepo.Supersede(kind stopped)` for a built-in owner reads **exactly** this string (`adapter/sqlite/resource_lease_supersede.go:proveKind`, contracts §25). |

`StopAndWait` never writes `stopped` before the stop is confirmed. When the stop times out, is refused (EPERM), or fails in storage, `StopAndWait` returns an error and the row stays `running`. `Supersede`, restore and retry therefore stay blocked (`TestPoolRecovery_StopFailurePreventsRestoreAndRetry`, Cycle 3).

**Start marker:** on darwin the marker is `darwin:<sec>.<usec>`, read from `kern.proc.pid` `P_starttime` (`golang.org/x/sys/unix.SysctlKinfoProc`; `x/sys` is already a direct dependency). On linux it is `linux:<boot_id>:<starttime ticks>`, read from `/proc/<pid>/stat` field 22 and `/proc/sys/kernel/random/boot_id`. The marker does not shell out to `ps`, which is often missing from slim container images. A zombie or an absent PID counts as "gone". A PID is not reused while its process group exists, so a live leader with a different marker means the recorded group is already gone, and that PID is never signalled. Windows is not a target.

**Wiring (not this task):** P3 T13 builds one `builtin.NewProcessSupervisor(adaptsqlite.NewBuiltInProcessRepo(db), builtin.SupervisorOptions{})` in `main.go` before `newRunnerStack` and passes it into `buildWorkspaceMobility` as input `Supervisor` (commit 8e8235d4). Mobility passes that supervisor as `RecoveryDeps.Stopper` and `AdoptDeps.Stopper`; `newRunnerStack` wires it into every built-in harness selector through `claudecli.NewSupervisedExecRunner(sup)`, and into the built-in runner's `process.NewSupervisedLocalProcessRunner(sup)`. Read-only inventory, auth and version probes keep `claudecli.NewExecRunner()` and `process.NewLocalProcessRunner()`, which are explicitly unsupervised.

**Known limits (fail closed, by design):** one supervised process may be live per job generation, because the 044 primary key is `(job_id, generation)`. A harness that starts two subprocesses *concurrently* inside one job gets `ErrProcessActive`. Sequential launches are fine, because each confirmed exit reopens the row. A descendant that escapes the group and outlives a normal exit leaves the row `running`. The next sequential launch for that job is then refused until `StopAndWait` runs. `builtin_processes` has no `runner_id` column. The runner is always `builtin` and is enforced by the store, so P3 T13's root assertion checks `job_id` and `generation`, not `runner_id`.

```go
// domain/runner/assignment_context.go
package runner

import (
	"context"

	"github.com/google/uuid"
)

type assignmentCtxKey struct{}

// ContextWithAssignment stamps the exact dispatcher assignment onto ctx. The
// built-in StepRunner (adapter/runner/builtin.Run) stamps its actual
// assignment before invoking any inner harness or process adapter. The
// supervised launch wrapper (ProcessSupervisor) reads it to register the durable
// launch permit against that exact job fence.
func ContextWithAssignment(ctx context.Context, a Assignment) context.Context {
	return context.WithValue(ctx, assignmentCtxKey{}, a)
}

// AssignmentFromContext returns the stamped assignment. An incomplete fence
// (nil job, empty runner, generation < 1), or a Job that names a different job
// than the Fence, is reported absent. A supervised launch then fails closed and
// never invents a job identity, reads a global "current job", or rebuilds a
// fence from trace history.
func AssignmentFromContext(ctx context.Context) (Assignment, bool) {
	a, ok := ctx.Value(assignmentCtxKey{}).(Assignment)
	if !ok || a.Fence.JobID == uuid.Nil || a.Fence.RunnerID == "" || a.Fence.Generation < 1 {
		return Assignment{}, false
	}
	if a.Job.ID != uuid.Nil && a.Job.ID != a.Fence.JobID {
		return Assignment{}, false
	}
	return a, true
}
```

```go
// domain/runner/builtin_process.go
package runner

import (
	"context"
	"errors"
)

// BuiltInProcessState is the exact value persisted in 044
// builtin_processes.state.
type BuiltInProcessState string

const (
	// ProcessAbsent is the "from" state for a job that has no row at all.
	ProcessAbsent BuiltInProcessState = ""
	// ProcessPermitted is the durable launch permit. It is written before the
	// guardian is spawned. The guardian cannot do real work until it is released.
	ProcessPermitted BuiltInProcessState = "permitted"
	// ProcessRunning means the guardian PID (= process-group ID) and its start
	// marker are recorded, and the guardian may be released.
	ProcessRunning BuiltInProcessState = "running"
	// ProcessStopped is written only after confirmed whole-group exit (or for a
	// permit that was never released). ResourceLeaseRepo.Supersede(kind
	// "stopped") for a built-in owner reads exactly this value.
	ProcessStopped BuiltInProcessState = "stopped"
)

// BuiltInProcess is the durable identity of one supervised built-in job
// generation's process group.
type BuiltInProcess struct {
	Fence       Fence
	GuardianPID int
	StartMarker string
	State       BuiltInProcessState
}

// BuiltInProcessStore persists supervised process identity. Production:
// adapter/sqlite.BuiltInProcessRepo. Every method rejects a non-built-in or
// incomplete fence with ErrFenced.
type BuiltInProcessStore interface {
	// Permit moves absent|stopped -> permitted, in the same transaction that
	// checks the ledger fence is live (builtin, offered|running). A fenced job
	// is ErrFenced. A permitted or running row is ErrProcessActive.
	Permit(ctx context.Context, f Fence) error
	// Record moves permitted -> running with guardianPID > 1 and a non-empty
	// start marker. Any other current state is ErrProcessStateChanged.
	Record(ctx context.Context, f Fence, guardianPID int, startMarker string) error
	// MarkStopped moves from -> stopped (from == ProcessAbsent inserts a stopped
	// row). If the row is not in `from`, it returns ErrProcessStateChanged.
	MarkStopped(ctx context.Context, f Fence, from BuiltInProcessState) error
	Get(ctx context.Context, f Fence) (BuiltInProcess, bool, error)
}

// BuiltInStopper stops and waits for the exact process tree of one built-in
// job generation, then durably records `stopped`. Callers fence the job in
// the ledger first. An error means the stop is unconfirmed: never restore,
// supersede or retry on it. Producer:
// adapter/runner/builtin.ProcessSupervisor. Consumers: P3 T10
// RecoveryDeps.Stopper and P4 T10 TurnStopEvidenceDeps.Stopper.
type BuiltInStopper interface {
	StopAndWait(ctx context.Context, f Fence) error
}

var (
	ErrProcessActive       = errors.New("runner: a supervised process is already permitted or running for this job generation")
	ErrProcessStateChanged = errors.New("runner: supervised process state changed concurrently")
)
```

```go
// adapter/sqlite/builtin_process_repo.go
package sqlite

import (
	"context"
	"database/sql"
	"errors"
	"fmt"

	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

// BuiltInProcessRepo implements runner.BuiltInProcessStore over 044
// builtin_processes(job_id, generation, guardian_pid, process_start_marker,
// state). The built-in runner is implied: the table has no runner column, and
// every fence must name runner.BuiltInRunnerID.
type BuiltInProcessRepo struct{ db *sql.DB }

var _ runner.BuiltInProcessStore = (*BuiltInProcessRepo)(nil)

// NewBuiltInProcessRepo builds the repo on the shared DB.
func NewBuiltInProcessRepo(db *sql.DB) *BuiltInProcessRepo { return &BuiltInProcessRepo{db: db} }

func builtInFence(f runner.Fence) error {
	if f.JobID == uuid.Nil || f.RunnerID != runner.BuiltInRunnerID || f.Generation < 1 {
		return fmt.Errorf("%w: supervised processes need an exact built-in job fence (got %s/%q/%d)", runner.ErrFenced, f.JobID, f.RunnerID, f.Generation)
	}
	return nil
}

func readBuiltInProcess(ctx context.Context, q groupQueryer, f runner.Fence) (runner.BuiltInProcess, bool, error) {
	p := runner.BuiltInProcess{Fence: f}
	var state string
	err := q.QueryRowContext(ctx, `SELECT guardian_pid, process_start_marker, state FROM builtin_processes WHERE job_id = ? AND generation = ?`,
		uuidToString(f.JobID), f.Generation).Scan(&p.GuardianPID, &p.StartMarker, &state)
	if errors.Is(err, sql.ErrNoRows) {
		return runner.BuiltInProcess{}, false, nil
	}
	if err != nil {
		return runner.BuiltInProcess{}, false, fmt.Errorf("builtin process: read %s/%d: %w", f.JobID, f.Generation, err)
	}
	p.State = runner.BuiltInProcessState(state)
	return p, true, nil
}

func (r *BuiltInProcessRepo) Permit(ctx context.Context, f runner.Fence) error {
	if err := builtInFence(f); err != nil {
		return err
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("builtin process: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	// The first statement takes the SQLite write lock (the same idiom as
	// lockLease), so the fence read and the row write cannot interleave with a
	// concurrent stop.
	if _, err := tx.ExecContext(ctx, `UPDATE builtin_processes SET state = state WHERE job_id = ? AND generation = ?`, uuidToString(f.JobID), f.Generation); err != nil {
		return fmt.Errorf("builtin process: lock: %w", err)
	}
	var live int
	if err := tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM runner_jobs WHERE id = ? AND generation = ? AND runner_id = ? AND state IN ('offered', 'running')`,
		uuidToString(f.JobID), f.Generation, string(f.RunnerID)).Scan(&live); err != nil {
		return fmt.Errorf("builtin process: job fence: %w", err)
	}
	if live == 0 {
		return fmt.Errorf("%w: job %s generation %d is not an active built-in assignment", runner.ErrFenced, f.JobID, f.Generation)
	}
	cur, ok, err := readBuiltInProcess(ctx, tx, f)
	if err != nil {
		return err
	}
	switch {
	case !ok:
		_, err = tx.ExecContext(ctx, `INSERT INTO builtin_processes(job_id, generation, guardian_pid, process_start_marker, state) VALUES (?, ?, 0, '', ?)`,
			uuidToString(f.JobID), f.Generation, string(runner.ProcessPermitted))
	case cur.State == runner.ProcessStopped:
		_, err = tx.ExecContext(ctx, `UPDATE builtin_processes SET guardian_pid = 0, process_start_marker = '', state = ? WHERE job_id = ? AND generation = ?`,
			string(runner.ProcessPermitted), uuidToString(f.JobID), f.Generation)
	default:
		return fmt.Errorf("%w: job %s generation %d is %s", runner.ErrProcessActive, f.JobID, f.Generation, cur.State)
	}
	if err != nil {
		return fmt.Errorf("builtin process: permit: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("builtin process: commit: %w", err)
	}
	return nil
}

func (r *BuiltInProcessRepo) Record(ctx context.Context, f runner.Fence, guardianPID int, startMarker string) error {
	if err := builtInFence(f); err != nil {
		return err
	}
	if guardianPID <= 1 || startMarker == "" {
		return fmt.Errorf("builtin process: record needs a guardian pid > 1 and a start marker (got %d, %q)", guardianPID, startMarker)
	}
	return r.transition(ctx, f, `UPDATE builtin_processes SET guardian_pid = ?, process_start_marker = ?, state = ? WHERE job_id = ? AND generation = ? AND state = ?`,
		guardianPID, startMarker, string(runner.ProcessRunning), uuidToString(f.JobID), f.Generation, string(runner.ProcessPermitted))
}

func (r *BuiltInProcessRepo) MarkStopped(ctx context.Context, f runner.Fence, from runner.BuiltInProcessState) error {
	if err := builtInFence(f); err != nil {
		return err
	}
	switch from {
	case runner.ProcessAbsent:
		return r.transition(ctx, f, `INSERT INTO builtin_processes(job_id, generation, guardian_pid, process_start_marker, state) VALUES (?, ?, 0, '', ?) ON CONFLICT(job_id, generation) DO NOTHING`,
			uuidToString(f.JobID), f.Generation, string(runner.ProcessStopped))
	case runner.ProcessPermitted, runner.ProcessRunning:
		return r.transition(ctx, f, `UPDATE builtin_processes SET state = ? WHERE job_id = ? AND generation = ? AND state = ?`,
			string(runner.ProcessStopped), uuidToString(f.JobID), f.Generation, string(from))
	default:
		return fmt.Errorf("builtin process: cannot stop from state %q", from)
	}
}

func (r *BuiltInProcessRepo) Get(ctx context.Context, f runner.Fence) (runner.BuiltInProcess, bool, error) {
	if err := builtInFence(f); err != nil {
		return runner.BuiltInProcess{}, false, err
	}
	return readBuiltInProcess(ctx, r.db, f)
}

// transition runs one compare-and-set statement; zero affected rows means the
// row was not in the expected state.
func (r *BuiltInProcessRepo) transition(ctx context.Context, f runner.Fence, query string, args ...any) error {
	res, err := r.db.ExecContext(ctx, query, args...)
	if err != nil {
		return fmt.Errorf("builtin process: %s/%d: %w", f.JobID, f.Generation, err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return fmt.Errorf("builtin process: %s/%d: %w", f.JobID, f.Generation, err)
	}
	if n == 0 {
		return fmt.Errorf("%w: job %s generation %d", runner.ErrProcessStateChanged, f.JobID, f.Generation)
```

```go
// ErrNoAssignment: a supervised launch whose context has no complete runner
// assignment. It fails closed (contracts §25 "supervised assignment provenance").
var ErrNoAssignment = errors.New("builtin supervisor: supervised launch has no runner assignment in its context")

// ErrStopUnconfirmed: the process group could not be proven gone.
var ErrStopUnconfirmed = errors.New("builtin supervisor: process group exit not confirmed")

// errProcessGone: no live (non-zombie) process has this pid.
var errProcessGone = errors.New("builtin supervisor: process is gone")

const (
	guardianGo        = "go\n"
	guardianAbortExit = 97
)

// SupervisorOptions tunes stopping. Zero values take the defaults.
type SupervisorOptions struct {
	Grace time.Duration                           // SIGTERM -> SIGKILL; default 5s
	Poll  time.Duration                           // exit polling; default 25ms
	Kill  func(pid int, sig syscall.Signal) error // default syscall.Kill; test seam for EPERM/timeouts
}

// ProcessSupervisor is the built-in runner's supervised launch wrapper
// (procenv.Launcher) and its BuiltInStopper. Every launch is tied to the exact
// job fence stamped by builtin.Run. The durable permit is written before the
// guardian exists. The guardian records its pid/start marker before it may run
// the real command, so a crash between spawn and record cannot leave an
// untracked writer.
type ProcessSupervisor struct {
	store runner.BuiltInProcessStore
	opt   SupervisorOptions
	mu    sync.Mutex
	live  map[runner.Fence]*supervised
}

// supervised is this process's handle on a guardian it started; exited closes
// after the caller's cmd.Wait reaped the leader.
type supervised struct {
	pid    int
	exited chan struct{}
}

var _ procenv.Launcher = (*ProcessSupervisor)(nil)

// NewProcessSupervisor builds the supervisor. A nil store panics.
func NewProcessSupervisor(store runner.BuiltInProcessStore, opt SupervisorOptions) *ProcessSupervisor {
	if store == nil {
		panic("builtin: NewProcessSupervisor requires a BuiltInProcessStore")
	}
	if opt.Grace <= 0 {
		opt.Grace = 5 * time.Second
	}
	if opt.Poll <= 0 {
		opt.Poll = 25 * time.Millisecond
	}
	if opt.Kill == nil {
		opt.Kill = syscall.Kill
	}
	return &ProcessSupervisor{store: store, opt: opt, live: map[runner.Fence]*supervised{}}
}

// Start implements procenv.Launcher: permit -> spawn guardian -> record
// pid+marker -> release.
func (s *ProcessSupervisor) Start(ctx context.Context, cmd *exec.Cmd) (func(), error) {
	a, ok := runner.AssignmentFromContext(ctx)
	if !ok {
		return nil, ErrNoAssignment
	}
	if cmd.Err != nil {
		return nil, cmd.Err
	}
	f := a.Fence
	if err := s.store.Permit(ctx, f); err != nil {
		return nil, fmt.Errorf("builtin supervisor: launch permit: %w", err)
	}
	goR, goW, err := armGuardian(cmd)
	if err != nil {
		return nil, errors.Join(err, s.abandon(ctx, f))
	}
	startErr := cmd.Start()
	_ = goR.Close()
	if startErr != nil {
		_ = goW.Close()
		return nil, errors.Join(fmt.Errorf("builtin supervisor: start: %w", startErr), s.abandon(ctx, f))
	}
	pid := cmd.Process.Pid
	marker, err := processStartMarker(pid)
	if err == nil {
		err = s.store.Record(ctx, f, pid, marker)
	}
	if err != nil {
		_ = goW.Close() // the unreleased guardian exits 97 before any real work
		_ = cmd.Wait()  // reap it here: the caller never receives this command
		return nil, errors.Join(fmt.Errorf("builtin supervisor: record guardian: %w", err), s.abandon(ctx, f))
	}
	h := &supervised{pid: pid, exited: make(chan struct{})}
	s.mu.Lock()
	s.live[f] = h
	s.mu.Unlock()
	_, _ = io.WriteString(goW, guardianGo) // a failed write means the guardian already exited; the caller's Wait reports it
	_ = goW.Close()
	return func() { s.finish(f, h) }, nil
}

// abandon closes a permit whose guardian never ran real work. A concurrent
// StopAndWait may already have closed it.
func (s *ProcessSupervisor) abandon(ctx context.Context, f runner.Fence) error {
	err := s.store.MarkStopped(context.WithoutCancel(ctx), f, runner.ProcessPermitted)
	if errors.Is(err, runner.ErrProcessStateChanged) {
		return nil
	}
	return err
}

// finish runs after the caller reaped the leader. It confirms `stopped` only
// when no member of the group survives. Otherwise the row stays running and
// StopAndWait will stop the survivors.
func (s *ProcessSupervisor) finish(f runner.Fence, h *supervised) {
	close(h.exited)
	s.mu.Lock()
	if s.live[f] == h {
		delete(s.live, f)
	}
	s.mu.Unlock()
	alive, err := s.groupAlive(h.pid)
	if err == nil && !alive {
		err = s.store.MarkStopped(context.Background(), f, runner.ProcessRunning)
		if errors.Is(err, runner.ErrProcessStateChanged) {
			err = nil
		}
	}
	if err != nil {
		slog.Warn("builtin supervisor: supervised process exit not confirmed",
			slog.String("job", f.JobID.String()), slog.Int64("generation", f.Generation), slog.Any("error", err))
	}
}

// groupAlive reports whether any member of process group pgid exists. EPERM
// means it exists.
func (s *ProcessSupervisor) groupAlive(pgid int) (bool, error) {
	err := s.opt.Kill(-pgid, 0)
	switch {
	case err == nil, errors.Is(err, syscall.EPERM):
		return true, nil
	case errors.Is(err, syscall.ESRCH):
		return false, nil
	default:
		return false, fmt.Errorf("builtin supervisor: probe process group %d: %w", pgid, err)
	}
}

// armGuardian rewrites cmd so that /bin/sh, leading its own process group,
// blocks until the server writes "go" on an inherited pipe and then execs the
// real command in place (same pid, same start marker). If the server dies first,
// the pipe closes and the guardian exits guardianAbortExit without running
// anything. The write end is close-on-exec, so no other child inherits it.
func armGuardian(cmd *exec.Cmd) (goR, goW *os.File, err error) {
	fd := 3 + len(cmd.ExtraFiles)
	if fd > 9 {
		return nil, nil, fmt.Errorf("builtin supervisor: too many inherited files (%d)", len(cmd.ExtraFiles))
	}
	goR, goW, err = os.Pipe()
	if err != nil {
		return nil, nil, fmt.Errorf("builtin supervisor: guardian pipe: %w", err)
	}
	script := fmt.Sprintf(`IFS= read -r arbitron_go <&%d || exit %d; [ "$arbitron_go" = go ] || exit %d; exec %d<&-; exec "$@"`,
		fd, guardianAbortExit, guardianAbortExit, fd)
	orig := cmd.Args
	if len(orig) == 0 {
		orig = []string{cmd.Path}
	}
	cmd.Args = append([]string{"sh", "-c", script, "arbitron-guardian", cmd.Path}, orig[1:]...)
	cmd.Path = "/bin/sh"
	cmd.ExtraFiles = append(cmd.ExtraFiles, goR)
	if cmd.SysProcAttr == nil {
		cmd.SysProcAttr = &syscall.SysProcAttr{}
	}
	cmd.SysProcAttr.Setpgid = true
	return goR, goW, nil
}
```

```go
package builtin

import (
	"errors"
	"fmt"

	"golang.org/x/sys/unix"
)

const darwinZombie = 5 // SZOMB, <sys/proc.h>

// processStartMarker is the pid's kernel start time. It is stable for one
// process and different for a later process that reuses the pid.
func processStartMarker(pid int) (string, error) {
	kp, err := unix.SysctlKinfoProc("kern.proc.pid", pid)
	if errors.Is(err, unix.EIO) || errors.Is(err, unix.ESRCH) {
		return "", errProcessGone // a missing pid yields a short (EIO) sysctl result
	}
	if err != nil {
		return "", fmt.Errorf("builtin supervisor: sysctl kern.proc.pid.%d: %w", pid, err)
	}
	if int(kp.Proc.P_pid) != pid || kp.Proc.P_stat == darwinZombie {
		return "", errProcessGone
	}
	st := kp.Proc.P_starttime
	return fmt.Sprintf("darwin:%d.%06d", st.Sec, st.Usec), nil
}
```

```go
// adapter/runner/builtin/marker_linux.go
package builtin

import (
	"bytes"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"strings"
)

// processStartMarker is boot_id + /proc/<pid>/stat field 22 (starttime, in
// clock ticks since boot).
func processStartMarker(pid int) (string, error) {
	b, err := os.ReadFile(fmt.Sprintf("/proc/%d/stat", pid))
	if errors.Is(err, fs.ErrNotExist) {
		return "", errProcessGone
	}
	if err != nil {
		return "", fmt.Errorf("builtin supervisor: read /proc/%d/stat: %w", pid, err)
	}
	// comm (field 2) may contain spaces and parens, so the fields resume after
	// the LAST ')'. fields[0] is field 3 (state); starttime is field 22.
	i := bytes.LastIndexByte(b, ')')
	if i < 0 {
		return "", fmt.Errorf("builtin supervisor: malformed /proc/%d/stat", pid)
	}
	fields := strings.Fields(string(b[i+1:]))
	if len(fields) < 20 {
		return "", fmt.Errorf("builtin supervisor: malformed /proc/%d/stat", pid)
	}
	if fields[0] == "Z" || fields[0] == "X" {
		return "", errProcessGone
	}
	boot, _ := os.ReadFile("/proc/sys/kernel/random/boot_id")
	return "linux:" + strings.TrimSpace(string(boot)) + ":" + fields[19], nil
}
```

```go
var _ runner.BuiltInStopper = (*ProcessSupervisor)(nil)

// StopAndWait implements runner.BuiltInStopper. The caller has already fenced
// the job in the ledger, so Permit refuses any relaunch. It persists `stopped`
// only after confirmed whole-group exit (or for a permit that never released
// its guardian). On any error the row is left as it was.
func (s *ProcessSupervisor) StopAndWait(ctx context.Context, f runner.Fence) error {
	for {
		if err := ctx.Err(); err != nil {
			return fmt.Errorf("%w: %w", ErrStopUnconfirmed, err)
		}
		p, ok, err := s.store.Get(ctx, f)
		if err != nil {
			return fmt.Errorf("builtin supervisor: read process: %w", err)
		}
		switch {
		case !ok:
			err = s.store.MarkStopped(ctx, f, runner.ProcessAbsent)
		case p.State == runner.ProcessStopped:
			return nil
		case p.State == runner.ProcessPermitted:
			// Not released: Record (CAS from permitted) now fails and the
			// in-flight Start kills its guardian before any real work.
			err = s.store.MarkStopped(ctx, f, runner.ProcessPermitted)
		case p.State == runner.ProcessRunning:
			if err := s.stopGroup(ctx, f, p); err != nil {
				return err
			}
			err = s.store.MarkStopped(ctx, f, runner.ProcessRunning)
		default:
			return fmt.Errorf("builtin supervisor: unknown process state %q", p.State)
		}
		if errors.Is(err, runner.ErrProcessStateChanged) {
			continue // a concurrent launch/finish moved the row; re-read it
		}
		if err != nil {
			return fmt.Errorf("builtin supervisor: persist stopped: %w", err)
		}
		return nil
	}
}

// stopGroup proves the recorded identity, then sends SIGTERM to the group,
// waits Grace, sends SIGKILL, and waits until the group is confirmed gone.
func (s *ProcessSupervisor) stopGroup(ctx context.Context, f runner.Fence, p runner.BuiltInProcess) error {
	pgid := p.GuardianPID
	if pgid <= 1 {
		return fmt.Errorf("%w: refusing to signal recorded guardian pid %d", ErrStopUnconfirmed, pgid)
	}
	s.mu.Lock()
	h := s.live[f]
	s.mu.Unlock()
	if h == nil { // after a restart: prove the pid still names our guardian
		marker, err := processStartMarker(pgid)
		switch {
		case errors.Is(err, errProcessGone):
			// The leader is gone. Surviving descendants keep the group id,
			// and a pid is never reused while its group exists.
		case err != nil:
			return fmt.Errorf("builtin supervisor: start marker of %d: %w", pgid, err)
		case marker != p.StartMarker:
			return nil // the pid was reused, so the recorded group is already gone: never signal it
		}
	}
	if err := s.signal(pgid, syscall.SIGTERM); err != nil {
		return err
	}
	gone, err := s.waitGone(ctx, h, pgid, s.opt.Grace)
	if err != nil || gone {
		return err
	}
	if err := s.signal(pgid, syscall.SIGKILL); err != nil {
		return err
	}
	_, err = s.waitGone(ctx, h, pgid, 0)
	return err
}

func (s *ProcessSupervisor) signal(pgid int, sig syscall.Signal) error {
	if err := s.opt.Kill(-pgid, sig); err != nil && !errors.Is(err, syscall.ESRCH) {
		return fmt.Errorf("builtin supervisor: %s process group %d: %w", sig, pgid, err)
	}
	return nil
}

// waitGone polls until the group is confirmed gone. For an in-process guardian
// it also waits until the caller has reaped the leader, because a zombie
// leader still counts as a group member. limit > 0 bounds the wait (the grace
// before SIGKILL). limit == 0 waits until ctx ends.
func (s *ProcessSupervisor) waitGone(ctx context.Context, h *supervised, pgid int, limit time.Duration) (bool, error) {
	var deadline <-chan time.Time
	if limit > 0 {
		t := time.NewTimer(limit)
		defer t.Stop()
		deadline = t.C
	}
	tick := time.NewTicker(s.opt.Poll)
	defer tick.Stop()
	for {
		reaped := h == nil
		if h != nil {
			select {
			case <-h.exited:
				reaped = true
			default:
			}
		}
		if reaped {
			alive, err := s.groupAlive(pgid)
			if err != nil {
				return false, err
			}
			if !alive {
				return true, nil
			}
		}
		select {
		case <-ctx.Done():
			return false, fmt.Errorf("%w: process group %d: %w", ErrStopUnconfirmed, pgid, ctx.Err())
		case <-deadline:
			return false, nil
		case <-tick.C:
		}
	}
}
```

```go
// p3MemLeases is an in-memory runner.ResourceLeaseStore with P3 T3's evidence
// rules: no TTL; Supersede needs the old job fenced in the ledger AND the
// kind's evidence (stop log, liveness hook, earlier boot ID).
type p3MemLeases struct {
	mu      sync.Mutex
	ledger  runner.Ledger
	bootID  string
	lost    func(runner.RunnerID) bool // runner_lost / revoked evidence; nil = never proven
	active  map[string]runner.LeaseRecord
	gen     map[string]int64
	stopped map[runner.Fence]bool // mirrors builtin_processes.state = 'stopped'
	trail   *[]string
}

var _ runner.ResourceLeaseStore = (*p3MemLeases)(nil)

func newP3Leases(l runner.Ledger, bootID string, trail *[]string) *p3MemLeases {
	return &p3MemLeases{ledger: l, bootID: bootID, active: map[string]runner.LeaseRecord{}, gen: map[string]int64{},
		stopped: map[runner.Fence]bool{}, trail: trail}
}

func (m *p3MemLeases) note(s string) {
	if m.trail != nil {
		*m.trail = append(*m.trail, s)
	}
}

// MarkStopped is called by the stopper fake after a confirmed stop.
func (m *p3MemLeases) MarkStopped(f runner.Fence) {
	m.mu.Lock()
	defer m.mu.Unlock()
	m.stopped[f] = true
}

func (m *p3MemLeases) grantLocked(key, holder string, owner runner.RunnerID, job *runner.Fence, boot string) engine.ResourceFenceRef {
	m.gen[key]++
	ref := engine.ResourceFenceRef{Key: key, Owner: string(owner), Generation: m.gen[key], Token: uuid.New()}
	m.active[key] = runner.LeaseRecord{Fence: ref, Holder: holder, Job: job, BootID: boot}
	return ref
}

// seedServerClaim plants a server-side claim taken by an earlier server boot.
func (m *p3MemLeases) seedServerClaim(key, holder, boot string) engine.ResourceFenceRef {
	m.mu.Lock()
	defer m.mu.Unlock()
	return m.grantLocked(key, holder, runner.BuiltInRunnerID, nil, boot)
}

func (m *p3MemLeases) Claim(_ context.Context, key, holder string, owner runner.RunnerID) (engine.ResourceFenceRef, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	if _, ok := m.active[key]; ok {
		return engine.ResourceFenceRef{}, runner.ErrResourceBusy
	}
	m.note("claim")
	return m.grantLocked(key, holder, owner, nil, m.bootID), nil
}

func (m *p3MemLeases) ClaimJob(ctx context.Context, key, holder string, job runner.Fence) (engine.ResourceFenceRef, error) {
	if err := m.ledger.FenceCheck(ctx, job); err != nil {
		return engine.ResourceFenceRef{}, err
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	if rec, ok := m.active[key]; ok {
		if rec.Job != nil && *rec.Job == job && rec.Holder == holder {
			return rec.Fence, nil
		}
		return engine.ResourceFenceRef{}, runner.ErrResourceBusy
	}
	j := job
	return m.grantLocked(key, holder, job.RunnerID, &j, ""), nil
}

func (m *p3MemLeases) checkLocked(f engine.ResourceFenceRef) error {
	if rec, ok := m.active[f.Key]; !ok || rec.Fence != f {
		return runner.ErrResourceFenced
	}
	return nil
}

func (m *p3MemLeases) Check(_ context.Context, f engine.ResourceFenceRef) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	return m.checkLocked(f)
}

func (m *p3MemLeases) Active(_ context.Context, key string) (runner.LeaseRecord, bool, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	rec, ok := m.active[key]
	return rec, ok, nil
}

func (m *p3MemLeases) Release(_ context.Context, f engine.ResourceFenceRef) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	if err := m.checkLocked(f); err != nil {
		return err
	}
	delete(m.active, f.Key)
	m.note("release")
	return nil
}

func (m *p3MemLeases) Supersede(ctx context.Context, old engine.ResourceFenceRef, proof runner.SupersedeProof, holder string, owner runner.RunnerID) (engine.ResourceFenceRef, error) {
	m.mu.Lock()
	rec, ok := m.active[old.Key]
	m.mu.Unlock()
	if !ok || rec.Fence != old {
		return engine.ResourceFenceRef{}, runner.ErrResourceFenced
	}
	if (rec.Job == nil) != (proof.OldJob == nil) || (rec.Job != nil && *rec.Job != *proof.OldJob) {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: proof does not name the claim's job", runner.ErrSupersedeUnproven)
	}
	if rec.Job != nil && m.ledger.FenceCheck(ctx, *rec.Job) == nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: old job still authorized", runner.ErrSupersedeUnproven)
	}
	m.mu.Lock()
	defer m.mu.Unlock()
	remote := rec.Fence.Owner != string(runner.BuiltInRunnerID)
	proven := false
	switch proof.Kind {
	case runner.SupersedeRunnerLost, runner.SupersedeRevoked:
		proven = remote && m.lost != nil && m.lost(runner.RunnerID(rec.Fence.Owner))
	case runner.SupersedeStopped:
		proven = rec.Job != nil && !remote && m.stopped[*rec.Job]
	case runner.SupersedeServerRestart:
		proven = rec.Job == nil && rec.BootID != m.bootID
	}
	if !proven {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: %s", runner.ErrSupersedeUnproven, proof.Kind)
	}
	if err := m.checkLocked(old); err != nil {
		return engine.ResourceFenceRef{}, err
	}
	m.note("supersede")
	return m.grantLocked(old.Key, holder, owner, nil, m.bootID), nil
}

// p3Clock is a settable clock.
type p3Clock struct {
	mu sync.Mutex
	t  time.Time
}

func newP3Clock() *p3Clock { return &p3Clock{t: time.Date(2026, 11, 20, 12, 0, 0, 0, time.UTC)} }

	c.mu.Lock()
	defer c.mu.Unlock()
	return c.t
}

	c.mu.Lock()
```

```go
// Pool event kinds added in Phase 3 (contracts §9).
const (
	EventJobRecovered = "job.recovered"
	EventJobAdopted   = "job.adopted"

// BuiltInRestorer restores the last COMMITTED checkpoint into the built-in
// working directory (WorkspaceSync.RestoreBuiltIn, P3 T6; P3 T16 non-portable branch).
type BuiltInRestorer interface {
	RestoreBuiltIn(ctx context.Context, runID uuid.UUID, dir string) error
}

// RestartGraceSetter keeps the hub from declaring runners lost during the
// restart grace (Hub.BeginRestartGrace).
type RestartGraceSetter interface{ BeginRestartGrace(until time.Time) }

type RecoveryDeps struct {
	Inbox        RemoteInbox        // durable receipts (P2 T4)
	Leases       ResourceLeaseStore // the shared, boot-bound lease repo (P3 T3, wired by P3 T13)
	Stopper      BuiltInStopper     // builtin.ProcessSupervisor (Cycles 2a-2e)
	Ledger       Ledger
	Homes        HomeStore
	Restorer     BuiltInRestorer
	Commits      engine.StepCommitter
	Grace        RestartGraceSetter
	Events       *EventRecorder
	Status       *ExecutionStatusProjector
	Clock        func() time.Time
	RestartGrace time.Duration
}

// PoolRecovery is the engine.RecoveryPolicy for server restarts (design §3.5).
type PoolRecovery struct{ d RecoveryDeps }

func NewPoolRecovery(d RecoveryDeps) (*PoolRecovery, error) {
	var missing []string
	for _, dep := range []struct {
		name string
		ok   bool
	}{
		{"Inbox", d.Inbox != nil}, {"Leases", d.Leases != nil}, {"Stopper", d.Stopper != nil}, {"Ledger", d.Ledger != nil},
		{"Homes", d.Homes != nil}, {"Restorer", d.Restorer != nil}, {"Commits", d.Commits != nil}, {"Grace", d.Grace != nil},
		{"Events", d.Events != nil}, {"Status", d.Status != nil},
	} {
		if !dep.ok {
			missing = append(missing, dep.name)
		}
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: PoolRecovery needs %s", strings.Join(missing, ", "))
	}
	if d.RestartGrace <= 0 {
		return nil, errors.New("runner: PoolRecovery needs a positive RestartGrace")
	}
	if d.Clock == nil {
		d.Clock = time.Now
	}
	return &PoolRecovery{d: d}, nil
}

// recoveryHolder is the durable holder identity of recovery's own server-side claim.
func recoveryHolder(runID uuid.UUID) string { return "recovery:" + runKey(runID) }

// Recover runs once at startup, before any run re-enters: remote leases are
// extended by the restart grace and the hub's grace window opens, so a
// runner that reconnects in time keeps (and reports) its jobs.
func (p *PoolRecovery) Recover(ctx context.Context) error {
	until := p.d.Clock().Add(p.d.RestartGrace)
	jobs, err := p.d.Ledger.ListActive(ctx)
	if err != nil {
		return fmt.Errorf("runner: recovery: list active jobs: %w", err)
	}
	for _, j := range jobs {
		if !j.State.HoldsSlot() || j.RunnerID == "" || j.RunnerID == BuiltInRunnerID {
			continue
		}
		if err := p.d.Ledger.ExtendLease(ctx, j.Fence(), until); err != nil && !errors.Is(err, ErrFenced) {
			return fmt.Errorf("runner: recovery: extend lease of %s: %w", j.ID, err)
		}
	}
	p.d.Grace.BeginRestartGrace(until)
	return nil
}

// PrepareRun implements engine.RecoveryPolicy. See the order in Step 3's lead-in.
func (p *PoolRecovery) PrepareRun(ctx context.Context, inst *instance.Instance) (engine.RecoveryAction, error) {
	jobs, err := p.d.Ledger.ListByRun(ctx, inst.ID)
	if err != nil {
		return "", fmt.Errorf("runner: recovery: list jobs of %s: %w", inst.ID, err)
	}
	node := ""
	if inst.CurrentNodeID != nil {
		node = *inst.CurrentNodeID
	}
	var latest *Job
	var interrupted []Job
	for i := range jobs {
		j := jobs[i]
		if j.NodeID == node && (latest == nil || !j.CreatedAt.Before(latest.CreatedAt)) {
			latest = &jobs[i]
		}
		if !j.State.HoldsSlot() {
			continue
		}
		if j.RunnerID == BuiltInRunnerID {
			interrupted = append(interrupted, j)
			continue
		}
		// Remote: lease extended by Recover; job AND resource claim are kept
		// through suspect/restart grace. JobAdopter adopts or, after confirmed
		// loss/revocation, recovers it.
		retained, err := p.resultRetained(ctx, j)
		if err != nil {
			return "", err
		}
		if !retained {
			p.d.Status.Publish(ctx, j, instance.ExecRecovering)
		}
	}
	// 1. Fence every interrupted built-in operation.
	for _, j := range interrupted {
		if _, err := p.d.Ledger.Requeue(ctx, j.Fence(), OutcomeRunnerLost); err != nil && !errors.Is(err, ErrFenced) {
			return "", fmt.Errorf("runner: recovery: fence built-in job %s: %w", j.ID, err)
		}
		p.record(ctx, j, "server_restart")
	}
	// 2. Stop and wait for each exact process tree. An unconfirmed stop returns
	// here with the old claim untouched: no restore and no retry can follow.
	stopped := map[Fence]bool{}
	for _, j := range interrupted {
		if err := p.d.Stopper.StopAndWait(ctx, j.Fence()); err != nil {
			return "", fmt.Errorf("runner: recovery: stop built-in job %s: %w", j.ID, err)
		}
		stopped[j.Fence()] = true
	}
	// 3. Take the workspace over on durable evidence.
	claim, held, err := p.takeOver(ctx, inst.ID, len(interrupted) > 0, stopped)
	if err != nil {
		return "", err
	}
	release := func() error {
		if !held {
			return nil
		}
		if err := p.d.Leases.Release(context.WithoutCancel(ctx), claim); err != nil && !errors.Is(err, ErrResourceFenced) {
			return fmt.Errorf("runner: recovery: release workspace of run %s: %w", inst.ID, err)
		}
		return nil
	}
	// 4. A committed step replays: no restore, no provider call.
	if latest != nil {
		_, committed, err := p.d.Commits.CommittedResult(ctx, latest.Key.InvocationID)
		if err != nil {
			return "", errors.Join(fmt.Errorf("runner: recovery: committed result of %s: %w", latest.Key.InvocationID, err), release())
		}
		if committed {
			return engine.RecoveryReplayCommitted, release()
		}
	}
	// 5. Restore the last committed base, then free the workspace for the repeat.
	if held {
		if err := p.restore(ctx, inst); err != nil {
			return "", errors.Join(err, release())
		}
	}
	if err := release(); err != nil {
		return "", err
	}
	return engine.RecoveryResume, nil
}

// takeOver supersedes the run's workspace claim when recovery may prove the
// old holder can no longer write; held reports whether recovery now holds it.
func (p *PoolRecovery) takeOver(ctx context.Context, runID uuid.UUID, interrupted bool, stopped map[Fence]bool) (engine.ResourceFenceRef, bool, error) {
	key := runKey(runID)
	rec, ok, err := p.d.Leases.Active(ctx, key)
	if err != nil {
		return engine.ResourceFenceRef{}, false, fmt.Errorf("runner: recovery: read workspace claim of run %s: %w", runID, err)
	}
	if !ok {
		if !interrupted {
			return engine.ResourceFenceRef{}, false, nil
		}
		ref, err := p.d.Leases.Claim(ctx, key, recoveryHolder(runID), BuiltInRunnerID)
		if err != nil {
			return engine.ResourceFenceRef{}, false, fmt.Errorf("runner: recovery: claim workspace of run %s: %w", runID, err)
		}
		return ref, true, nil
	}
	var proof SupersedeProof
	switch {
	case rec.Job == nil: // server-side holder from an earlier boot (design D7)
		proof = SupersedeProof{Kind: SupersedeServerRestart}
	case rec.Job.RunnerID == BuiltInRunnerID: // includes a fenced-but-unreleased built-in claim
		old := *rec.Job
		if !stopped[old] {
			if err := p.d.Stopper.StopAndWait(ctx, old); err != nil {
				return engine.ResourceFenceRef{}, false, fmt.Errorf("runner: recovery: stop claim holder %s: %w", old.JobID, err)
			}
		}
		proof = SupersedeProof{Kind: SupersedeStopped, OldJob: &old}
	default: // a remote writer: only JobAdopter, after confirmed loss/revocation, takes it over
		return engine.ResourceFenceRef{}, false, nil
	}
	ref, err := p.d.Leases.Supersede(ctx, rec.Fence, proof, recoveryHolder(runID), BuiltInRunnerID)
	if err != nil {
		return engine.ResourceFenceRef{}, false, fmt.Errorf("runner: recovery: take over workspace of run %s (%s): %w", runID, proof.Kind, err)
	}
	return ref, true, nil
}

func (p *PoolRecovery) restore(ctx context.Context, inst *instance.Instance) error {
	home, err := p.d.Homes.GetHome(ctx, inst.ID)
	if err != nil {
		return fmt.Errorf("runner: recovery: home of %s: %w", inst.ID, err)
	}
	if !isServerLocal(home.RunnerID) {
		return nil // a remote home is re-pulled on its runner, never restored on the server
	}
	dir, _ := inst.Variables[engine.ReservedVarWorkspace].(string)
	if dir == "" {
		return nil
	}
	if err := p.d.Restorer.RestoreBuiltIn(ctx, inst.ID, dir); err != nil {
		return fmt.Errorf("runner: recovery: restore workspace of %s: %w", inst.ID, err)
	}
	return nil
}

func (p *PoolRecovery) resultRetained(ctx context.Context, j Job) (bool, error) {
	r, ok, err := p.d.Inbox.Receipt(ctx, j.Fence())
	if err != nil {
		return false, fmt.Errorf("runner: recovery: receipt of job %s: %w", j.ID, err)
	}
	return ok && r.Result != nil, nil
}

func (p *PoolRecovery) record(ctx context.Context, j Job, reason string) {
	run := j.Key.RunID
	p.d.Events.Record(ctx, PoolEvent{
		ID: uuid.New(), At: p.d.Clock(), Kind: EventJobRecovered, RunnerID: j.RunnerID, SourceID: j.SourceID, RunID: &run,
		Cause:  Cause{Kind: CauseSystem, Outcome: OutcomeRunnerLost},
		Detail: map[string]any{"jobId": j.ID.String(), "nodeId": j.NodeID, "reason": reason, "notice": instance.RecoveryNoticeText},
	})
}
```

```go
package runner

import (
	"context"

	"github.com/arbitron/arbitron/domain/instance"
	"github.com/google/uuid"

// RecoveryNoticeSource derives instance.RecoveryNotice values from the
// ledger: every attempt that ended runner_lost (restart of a built-in job,
// lost runner, revoked key) was interrupted and repeated.
type RecoveryNoticeSource struct{ ledger Ledger }

func NewRecoveryNoticeSource(l Ledger) *RecoveryNoticeSource { return &RecoveryNoticeSource{ledger: l} }

func (s *RecoveryNoticeSource) RecoveryNotices(ctx context.Context, runID uuid.UUID) ([]instance.RecoveryNotice, error) {
	jobs, err := s.ledger.ListByRun(ctx, runID)
	if err != nil {
		return nil, err
	}
	var out []instance.RecoveryNotice
	for _, j := range jobs {
		attempts, err := s.ledger.Attempts(ctx, j.ID)
		if err != nil {
			return nil, err
		}
		for _, a := range attempts {
			if a.Outcome != string(OutcomeRunnerLost) {
				continue
			}
			at := a.StartedAt
			if a.EndedAt != nil {
				at = *a.EndedAt
			}
			out = append(out, instance.RecoveryNotice{NodeID: j.NodeID, JobID: j.ID, RunnerID: string(a.RunnerID),
				Reason: a.Outcome, At: at, Text: instance.RecoveryNoticeText})
		}
	}
	return out, nil
}
```

```go
// domain/runner/hub_adopt.go
package runner

import (
	"context"
	"errors"
	"fmt"
	"sync"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
)

// ErrAdoptionUnsupported: a stream is adopted by Hub.Adopt (replay + live
// frames), never converted from one terminal result.
var ErrAdoptionUnsupported = errors.New("runner: this operation cannot be adopted from a single result")

const maxRetainedResults = 1024

type adoptMsg struct {
	res RemoteResult
	err error
}

// AdoptionBook wakes an adoption wait when a result (or failure) for the
// exact fence arrives with no in-flight Hub.Run. It caches, it does not own:
// the durable RemoteInbox receipt is the authority. Keyed by the full fence,
// so a stale generation never satisfies a newer wait. Zero value is ready.
type AdoptionBook struct {
	mu       sync.Mutex
	waiters  map[Fence]chan adoptMsg
	retained map[Fence]adoptMsg
	order    []Fence
}

func (b *AdoptionBook) init() {
	if b.waiters == nil {
		b.waiters = map[Fence]chan adoptMsg{}
		b.retained = map[Fence]adoptMsg{}
	}
}

// Wait blocks until the job's result (or failure) is delivered, or ctx ends.
func (b *AdoptionBook) Wait(ctx context.Context, f Fence) (RemoteResult, error) {
	b.mu.Lock()
	b.init()
	if m, ok := b.retained[f]; ok {
		delete(b.retained, f)
		b.mu.Unlock()
		return m.res, m.err
	}
	ch := make(chan adoptMsg, 1)
	b.waiters[f] = ch
	b.mu.Unlock()
	select {
	case m := <-ch:
		return m.res, m.err
	case <-ctx.Done():
		b.mu.Lock()
		if b.waiters[f] == ch {
			delete(b.waiters, f)
		}
		b.mu.Unlock()
		select {
		case m := <-ch: // delivered while giving up: keep it for the next wait
			b.put(f, m)
		default:
		}
		return RemoteResult{}, ctx.Err()
	}
}

// Waiting reports whether an adoption wait is registered for f.
func (b *AdoptionBook) Waiting(f Fence) bool {
	b.mu.Lock()
	defer b.mu.Unlock()
	_, ok := b.waiters[f]
	return ok
}

func (b *AdoptionBook) put(f Fence, m adoptMsg) {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.init()
	if ch, ok := b.waiters[f]; ok {
		delete(b.waiters, f)
		ch <- m
		return
	}
	if _, ok := b.retained[f]; !ok {
		b.order = append(b.order, f)
	}
	b.retained[f] = m
	for len(b.retained) > maxRetainedResults && len(b.order) > 0 {
		delete(b.retained, b.order[0])
		b.order = b.order[1:]
	}
}

// forget drops a cached entry once the durable receipt answered the wait.
func (b *AdoptionBook) forget(f Fence) {
	b.mu.Lock()
	defer b.mu.Unlock()
	delete(b.retained, f)
}

// Deliver wakes the waiter for a fence-checked, already-journaled result.
func (b *AdoptionBook) Deliver(f Fence, r RemoteResult) { b.put(f, adoptMsg{res: r}) }

// FailJob fails one job's adoption (the reconnecting runner no longer holds it).
func (b *AdoptionBook) FailJob(f Fence, err error) { b.put(f, adoptMsg{err: err}) }

// FailRunner releases every waiter for jobs on runner id (lost or revoked)
// and returns their fences: the waiting adopter owns their recovery, so the
// hub must not also fail them.
func (b *AdoptionBook) FailRunner(id RunnerID, err error) []Fence {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.init()
	var released []Fence
	for f, ch := range b.waiters {
		if f.RunnerID == id {
			delete(b.waiters, f)
			ch <- adoptMsg{err: err}
			released = append(released, f)
		}
	}
	return released
}

// AdoptedOutput converts an adopted terminal result exactly as Hub.Run does,
// refusing a payload that does not match the operation.
func AdoptedOutput(op OpType, res RemoteResult) (StepOutput, error) {
	switch op {
	case OpAgent, OpProcess, OpChat, OpConfirm:
	default:
		return StepOutput{}, fmt.Errorf("%w: %s", ErrAdoptionUnsupported, op)
	}
	if !res.OK {
		return StepOutput{}, remoteError(&res)
	}
	if (op == OpAgent && res.Agent == nil) || (op == OpProcess && res.Process == nil) ||
		(op == OpChat && res.Chat == nil) || (op == OpConfirm && res.Confirmation == nil) {
		return StepOutput{}, WithOutcome(fmt.Errorf("%w: adopted %s result carries no %s payload", ErrRemoteStepFailed, op, op),
			SourceOutcome{Class: OutcomeOther})
	}
	return remoteOutput(&res)
}

// Adopt waits for the outcome of a job this hub did not dispatch in this
// process lifetime. It never sends a dispatch. The ledger fence is checked
// first (h.receipt), then the durable receipt answers if it can.
func (h *Hub) Adopt(ctx context.Context, a Assignment, job StepJob) (StepOutput, error) {
	f := a.Fence
	if f.RunnerID == "" || f.RunnerID == BuiltInRunnerID {
		return StepOutput{}, fmt.Errorf("runner: hub cannot adopt a job on runner %q", f.RunnerID)
	}
	receipt, retained, err := h.receipt(ctx, f)
	if err != nil {
		return StepOutput{}, err
	}
	if job.Op == OpStream {
		return h.adoptStream(ctx, a, receipt, retained)
	}
	if retained && receipt.Result != nil {
		h.adopt.forget(f)
		return AdoptedOutput(job.Op, *receipt.Result) // no provider repeat
	}
	res, err := h.adopt.Wait(ctx, f)
	if err != nil {
		return StepOutput{}, err
	}
	return AdoptedOutput(job.Op, res)
}

// adoptStream re-attaches an in-flight stream WITHOUT a dispatch: persisted
// frames replay first, then live frames continue after the persisted cursor
// through the normal handleJob/handleOutput path; the terminal result
// closes it via finish.
func (h *Hub) adoptStream(ctx context.Context, a Assignment, receipt InboxReceipt, retained bool) (StepOutput, error) {
	j := &remoteJob{ctx: ctx, a: a, offeredAt: h.now(), stream: make(chan engine.ChatChunk, streamBuffer),
		acceptedCh: make(chan struct{}), done: make(chan struct{})}
	h.mu.Lock()
	if h.revoked[a.Fence.RunnerID] {
		h.mu.Unlock()
		return StepOutput{}, WithOutcome(fmt.Errorf("%w: %s", ErrRunnerRevoked, a.Fence.RunnerID), SourceOutcome{Class: OutcomeRunnerLost})
	}
	j.emitMu.Lock()
	h.jobs[a.Fence.JobID] = j
	h.mu.Unlock()
	h.markAccepted(j)
	frames, err := h.inbox.Outputs(ctx, a.Fence, 0)
	if err != nil {
		j.emitMu.Unlock()
		h.finish(j, nil, err)
		return StepOutput{}, err
	}
	go func() {
		last := receipt.LastOutputSeq
		for _, frame := range frames {
			select {
			case j.stream <- engine.ChatChunk{Token: frame.Token}:
			case <-ctx.Done():
			}
			if frame.Seq > last {
				last = frame.Seq
			}
		}
		h.mu.Lock()
		j.lastSeq = last
		h.mu.Unlock()
		j.emitMu.Unlock()
		if retained && receipt.Result != nil {
			h.finish(j, receipt.Result, nil)
		}
	}()
	return StepOutput{Stream: j.stream}, nil
}

// BeginRestartGrace stops Tick from declaring runners lost before until.
func (h *Hub) BeginRestartGrace(until time.Time) { h.restartGraceUntil.Store(until.UnixNano()) }

// InRestartGrace reports whether now is inside the restart grace window.
func (h *Hub) InRestartGrace(now time.Time) bool {
	u := h.restartGraceUntil.Load()
	return u != 0 && now.UnixNano() < u
}
```

```go
// Adopter waits for a job that is already running on a runner (the Hub).
type Adopter interface {
	Adopt(ctx context.Context, a Assignment, job StepJob) (StepOutput, error)
}

type AdoptDeps struct {
	Ledger   Ledger
	Registry Registry
	Hub      Adopter
	Leases   ResourceLeaseStore // the shared, boot-bound lease repo (P3 T13)
	Stopper  BuiltInStopper     // builtin.ProcessSupervisor (Cycles 2a-2e)
	Events   *EventRecorder
	Status   *ExecutionStatusProjector
	Clock    func() time.Time
	Poll     time.Duration // re-check interval while waiting; default 5s
}

// JobAdopter is the dispatcher's branch for a job EnsureIntent returned
// offered/running: after a restart it is awaited, never dispatched again.
type JobAdopter struct{ d AdoptDeps }

func NewJobAdopter(d AdoptDeps) (*JobAdopter, error) {
	var missing []string
	for _, dep := range []struct {
		name string
		ok   bool
	}{
		{"Ledger", d.Ledger != nil}, {"Registry", d.Registry != nil}, {"Hub", d.Hub != nil}, {"Leases", d.Leases != nil},
		{"Stopper", d.Stopper != nil}, {"Events", d.Events != nil}, {"Status", d.Status != nil},
	} {
		if !dep.ok {
			missing = append(missing, dep.name)
		}
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: JobAdopter needs %s", strings.Join(missing, ", "))
	}
	if d.Clock == nil {
		d.Clock = time.Now
	}
	if d.Poll <= 0 {
		d.Poll = 5 * time.Second
	}
	return &JobAdopter{d: d}, nil
}

// Resolve handles a job EnsureIntent returned offered/running:
//   - done, nil: the remote job finished; out is its output. The ledger is
//     untouched: the dispatcher completes it through completeStep (receipt).
//   - done, err: the adopted job ended with this classified failure (or ctx
//     ended); the dispatcher rolls the workspace back, then releases it.
//   - !done, nil: the job was requeued with takeover evidence; place it normally.
//   - !done, err: a takeover could not be proven; the step fails, nothing is re-placed.
func (a *JobAdopter) Resolve(ctx context.Context, j Job, job StepJob) (StepOutput, bool, error) {
	if !j.State.HoldsSlot() {
		return StepOutput{}, false, nil
	}
	if j.RunnerID == BuiltInRunnerID {
		return StepOutput{}, false, a.recover(ctx, j, "builtin_not_adoptable", SupersedeStopped)
	}
	fence := j.Fence()
	a.d.Status.Publish(ctx, j, instance.ExecRecovering)
	for {
		var out StepOutput
		var err error
		if job.Op == OpStream {
			out, err = a.d.Hub.Adopt(ctx, Assignment{Job: j, Fence: fence}, job) // returns at once; the stream lives on ctx
		} else {
			wctx, cancel := context.WithTimeout(ctx, a.d.Poll)
			out, err = a.d.Hub.Adopt(wctx, Assignment{Job: j, Fence: fence}, job)
			cancel()
		}
		if err == nil {
			a.event(ctx, j, EventJobAdopted, "server_restart")
			return out, true, nil
		}
		if ctx.Err() != nil {
			return StepOutput{}, true, ctx.Err()
		}
		if errors.Is(err, context.DeadlineExceeded) {
			cur, gerr := a.d.Ledger.Get(ctx, j.ID)
			if gerr != nil {
				return StepOutput{}, true, gerr
			}
			if cur.Generation != j.Generation || !cur.State.HoldsSlot() {
				return StepOutput{}, false, nil // recovered by someone else (lost-runner handler, revocation)
			}
			r, _, rerr := a.d.Registry.GetRunner(ctx, j.RunnerID)
			if rerr == nil && r.Liveness != LivenessLost {
				continue // online, suspect or offline-in-grace: keep waiting
			}
			if rerr != nil && !errors.Is(rerr, ErrRunnerNotFound) {
				return StepOutput{}, true, rerr
			}
			err = WithOutcome(fmt.Errorf("%w: %s", ErrRunnerLost, j.RunnerID), SourceOutcome{Class: OutcomeRunnerLost})
		}
		if errors.Is(err, ErrRunnerRevoked) {
			return StepOutput{}, false, a.recover(ctx, j, "runner_revoked", SupersedeRevoked)
		}
		if errors.Is(err, ErrRunnerLost) || ClassifyError(err).Class == OutcomeRunnerLost {
			return StepOutput{}, false, a.recover(ctx, j, "runner_lost", SupersedeRunnerLost)
		}
		return StepOutput{}, true, err
	}
}

// recover fences the job, stops a built-in writer, takes its claim over on
// durable evidence and frees it, then records job.recovered.
func (a *JobAdopter) recover(ctx context.Context, j Job, reason string, kind SupersedeKind) error {
	f := j.Fence()
	if _, err := a.d.Ledger.Requeue(ctx, f, OutcomeRunnerLost); err != nil && !errors.Is(err, ErrFenced) {
		return fmt.Errorf("runner: recover job %s: %w", j.ID, err)
	}
	if j.RunnerID == BuiltInRunnerID {
		if err := a.d.Stopper.StopAndWait(ctx, f); err != nil {
			return fmt.Errorf("runner: recover job %s: stop: %w", j.ID, err)
		}
	}
	if err := takeOverJobClaim(ctx, a.d.Leases, j, kind); err != nil {
		return err
	}
	a.event(ctx, j, EventJobRecovered, reason)
	return nil
}

// takeOverJobClaim supersedes and frees the run's workspace claim when THIS
// exact job generation holds it, so the requeued step can claim it again.
func takeOverJobClaim(ctx context.Context, leases ResourceLeaseStore, j Job, kind SupersedeKind) error {
	rec, ok, err := leases.Active(ctx, runKey(j.Key.RunID))
	if err != nil {
		return fmt.Errorf("runner: read workspace claim of run %s: %w", j.Key.RunID, err)
	}
	old := j.Fence()
	if !ok || rec.Job == nil || *rec.Job != old {
		return nil // hermetic op, or the claim is not this job's
	}
	ref, err := leases.Supersede(ctx, rec.Fence, SupersedeProof{Kind: kind, OldJob: &old}, recoveryHolder(j.Key.RunID), BuiltInRunnerID)
	if err != nil {
		return fmt.Errorf("runner: take over the workspace claim of job %s (%s): %w", j.ID, kind, err)
	}
	if err := leases.Release(ctx, ref); err != nil {
		return fmt.Errorf("runner: free the recovered workspace claim of run %s: %w", j.Key.RunID, err)
	}
	return nil
}

func (a *JobAdopter) event(ctx context.Context, j Job, kind, reason string) {
	run := j.Key.RunID
	detail := map[string]any{"jobId": j.ID.String(), "nodeId": j.NodeID, "generation": j.Generation, "reason": reason}
	cause := Cause{Kind: CauseSystem}
	if kind == EventJobRecovered {
		detail["notice"] = instance.RecoveryNoticeText
		cause.Outcome = OutcomeRunnerLost
	}
	a.d.Events.Record(ctx, PoolEvent{ID: uuid.New(), At: a.d.Clock(), Kind: kind, RunnerID: j.RunnerID, SourceID: j.SourceID,
		RunID: &run, Cause: cause, Detail: detail})
}
```

```go
// WorkspaceAdopter rebuilds an adopted job's workspace attempt (P3 T10).
type WorkspaceAdopter interface {
	AdoptAttempt(ctx context.Context, a Assignment, job *StepJob) (WorkspaceAttempt, error)
}

var _ WorkspaceAdopter = (*WorkspaceSync)(nil)

// AdoptAttempt rebuilds the workspace context of a job dispatched before a
// server restart. It never moves, restores or claims: the job's exact claim
// must still be active, and the base is the committed checkpoint it started
// from (nothing else could commit while that claim was held).
func (s *WorkspaceSync) AdoptAttempt(ctx context.Context, a Assignment, job *StepJob) (WorkspaceAttempt, error) {
	runID, workDir := a.Job.Key.RunID, jobWorkDir(job)
	if runID == uuid.Nil || workDir == "" {
		return WorkspaceAttempt{}, fmt.Errorf("%w: adopted job %s", ErrNoWorkspace, a.Job.ID)
	}
	if a.Fence != a.Job.Fence() {
		return WorkspaceAttempt{}, fmt.Errorf("%w: assignment fence does not match its job", ErrFenced)
	}
	if err := s.d.Ledger.FenceCheck(ctx, a.Fence); err != nil {
		return WorkspaceAttempt{}, err
	}
	rec, ok, err := s.d.Leases.Active(ctx, runKey(runID))
	if err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: read workspace claim of run %s: %w", runID, err)
	}
	if !ok || rec.Job == nil || *rec.Job != a.Fence {
		return WorkspaceAttempt{}, fmt.Errorf("%w: adopted job %s generation %d does not hold run %s's workspace",
			ErrResourceFenced, a.Fence.JobID, a.Fence.Generation, runID)
	}
	base, _, err := s.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: read committed checkpoint of run %s: %w", runID, err)
	}
	return WorkspaceAttempt{RunID: runID, WorkDir: workDir, Runner: a.Fence.RunnerID, Base: base, Resource: rec.Fence}, nil
}
```

## RR-17 decision B — non-portable recovery (consumes P3 T16)

**DECISION (2026-11-22) RR-17: B.** A non-portable home is recovered exactly like a portable built-in home. Its base is the latest committed **local checkpoint**, produced by P3 T16 (`docs/plans/remote-runners/2026-11-20-phase-3-task-16.md`). P3 T16 runs after P3 T6 and before this task. It is a plain server-disk copy that the step transaction commits as `workspace_homes.local_checkpoint`. If no local checkpoint exists, the base is the home's initial state.
- PrepareRun does not branch on `Home.NonPortableReason`. For a non-portable home on the built-in runner it takes the ordinary built-in path: fence the old operation, `Stopper.StopAndWait`, supersede the exact claim, `Restorer.RestoreBuiltIn(ctx, inst.ID, inst.Variables["workspace"])`, then return `engine.RecoveryResume`, so the step repeats under the new generation. The former "skip restore then repeat" instruction is deleted. It would re-run the step on possibly partial edits.
- `RestoreBuiltIn` returns an error wrapping `runner.ErrNoRecoveryBase` only when the home has neither a committed local checkpoint nor an initial state, or its local copy is missing or corrupt. In that case PrepareRun stops before any retry. It records the durable run-scoped pool event `EventJobRecoveryBlocked` (`job.recovery_blocked`, Detail `{"reason": <error text including the home's NonPortableReason>, "notice": instance.RecoveryNoticeText}`) through `Events.Record`.
