# Remote Runners — Phase 1 Task 12: Codex outcome classification (RR-03)

**Goal:** Classify every failed subscription Codex turn from the session's own rollout records (`codex_error_info` and `token_count.rate_limits`), never from prose. The adapter also gains:
- a token-free `account/rateLimits/read` client with the tri-state `ordinaryUsageAllowed`;
- `VersionEvidence`, which separates a missing binary from an incompatible one;
- a supported-version table.

**Architecture:**
- A bounded rollout outcome reader reuses `findRollout`, `resolveCodexHome` and `readRolloutRecord`.
- It folds `event_msg` records:
  - The last `codex_error_info` in the current turn decides the class. It is read from **both** `event_msg` `error` payloads **and** the terminal `task_complete.error` (Codex 0.171.0 writes a logged-out failure only on `task_complete`; see `docs/evidence/remote-runners/codex-logged-out.md`).
  - Object-form `codex_error_info` whose inner object carries `http_status_code` 401 or 403 (under any key; observed `http_connection_failed`) is logged out. Other object forms keep their transient mapping.
  - `token_count.rate_limits` windows are keyed by limit id, model scope and duration. They never overwrite another limit's same-duration bucket.
  - Resets are normalized: seconds, milliseconds, and relative `resets_in_seconds`.
- `attachRolloutOutcome` wraps the error with `runner.WithOutcome` before `SanitizeProcessError` at every subscription failure path:
  - `Provider.RunAgent`
  - `StreamProvider.Chat` and `StreamProvider.StreamChat`
  - `foldExecStream`

  LunaRoute launches are never classified as subscription.
- `RateLimitsRead` speaks header-less JSON-RPC over `codex app-server` stdio through a **dedicated stdio session** (new package-internal `appServerStarter` seam), not `claudecli.CommandRunner`: the observed 0.171.0 server exits on stdin EOF without answering `account/rateLimits/read`, so stdin must stay open until the id-1 answer arrives (`docs/evidence/remote-runners/codex-app-server.md`).

**Tech Stack:** Go 1.25, `encoding/json`, `os/exec`, testify; JSONL fixtures under `adapter/codex/testdata/outcomes/`. Synthetic fixtures use real Codex 0.170 message text (U+2019, `chatgpt.com/settings/usage`); the logged-out and app-server fixtures are copied from shapes observed on Codex 0.171.0 (redacted).

DECISION (2026-11-22, RR-03): Codex outcome coverage is the synthetic fixtures below plus fail-closed classification. Unrecognized records classify as "other", an ordinary step error that never parks a source. Real per-version capture certification (a capture script, captured-fixture acceptance test or reviewed capture manifest) is a **Non-Goal**. The one real shape that is cheap and safe to observe, a logged-out run against an empty `CODEX_HOME`, was recorded on 0.171.0 in `docs/evidence/remote-runners/codex-logged-out.md`; `exec_stdout_logged_out.jsonl` and `rollout_logged_out_401.jsonl` are copied from it. That observation changed the classifier contract: `codex_error_info` is read from `task_complete.error` as well as `event_msg` `error`, and an object form with `http_status_code` 401/403 is logged out (previously `http_connection_failed` was always transient).

DECISION (2026-11-22, RR-03): the `codex app-server` exchange is the one observed on 0.171.0 and recorded in `docs/evidence/remote-runners/codex-app-server.md`. Framing is header-less JSON-RPC, one object per line, with unsolicited notifications (no `id`) interleaved. The server **exits on stdin EOF without answering id 1**, so `RateLimitsRead` uses a dedicated stdio session: write `initialize`, `initialized`, `account/rateLimits/read`; keep stdin open; skip every message whose `id` is not 1; stop at id 1; then close stdin and kill/reap. The exchange is bounded by `probeTimeout` and `probeMaxResponseBytes`. The logged-in result schema matches the fields decoded here (`usedPercent` arrives as an integer and decodes as any JSON number). Any id-1 `error` (including the observed logged-out `-32600`), EOF before id 1, timeout, cap overflow or malformed JSON returns `ErrRateLimitsUnavailable`, which `CodexProber` (P1 T13) reports as capacity unknown and never as available or logged out.

DECISION (2026-11-22, RR-03): the Codex capability floor of 0.170.0 (rollout outcome records and `account/rateLimits/read`) is **evidence-inferred, not certified**: it comes from the 0.170.0 binary and `main`-branch schema, and the shapes above were observed on 0.171.0. `CheckVersion`/`VersionEvidence` enforce it, and `DetectLocal` (P1 T13) annotates below-floor binaries as unsupported while keeping them visible and blocking assignment with Source.UnavailableReason. No per-release verification gate exists.

## Execution and acceptance order

Dependencies are the producer tasks named below; implement them before their consumers. Follow strict TDD for **each** happy-path, success, failure, error and edge-case behavior: add the smallest behavioral test, run it against the current implementation and record its intended failure, implement only that behavior, rerun to green, then refactor. The implementation blocks below describe the final result; do not paste later-cycle behavior into an earlier cycle. A temporary production-code mutation after implementation is optional sensitivity validation and **does not count as the required RED step**. If a later-cycle test already passes, move that test to the cycle that first adds its behavior before implementing it. Never replace a meaningful assertion or skip a required case to get green.

Production acceptance also requires the named composition-root sink tests, with the real constructor path and SQLite/API/event sink. A fake-only unit test, a constructor read-back, a nil fallback, an empty collection, or a comment promising future wiring does not establish that a Phase-1 feature is connected. Explicit Phase-2/3/4 fields stay unavailable until their owning phase supplies the real producer; they are not Phase-1 completion claims.

package codex

import (
	"bufio"
	"encoding/json"

// errMalformedRolloutOutcome marks a rollout the outcome reader refuses. The
// caller then attaches nothing, so the failure classifies as "other".
var errMalformedRolloutOutcome = errors.New("codex: malformed rollout outcome record")

var transientErrorInfo = map[string]bool{
	"server_overloaded": true, "rate_limit_exceeded": true, "response_stream_disconnected": true,
	"internal_server_error": true, "http_connection_failed": true,
	"response_stream_connection_failed": true, "response_too_many_failed_attempts": true,
}

// classifiesRollout reports whether a binding's failures may be classified as
// subscription outcomes. LunaRoute launches never are (their health is the
// gateway's, and their private home is not the account's rollout store).
func classifiesRollout(b provider.ResolvedBinding) bool { return b.ConnectionRef == "" && !provider.IsLunaRoute(b.Provider) }

type windowKey struct {
	limitID string
	scope   string
	mins    int
}

type rawRolloutWindow struct {
	UsedPercent     *float64 `json:"used_percent"`
	WindowMinutes   int      `json:"window_minutes"`
	ResetsAt        *float64 `json:"resets_at"`
	ResetsInSeconds *float64 `json:"resets_in_seconds"`
}

type rawRolloutRateLimits struct {
	LimitID     *string           `json:"limit_id"`
	LimitName   *string           `json:"limit_name"`
	Primary     *rawRolloutWindow `json:"primary"`
	Secondary   *rawRolloutWindow `json:"secondary"`
	ReachedType *string           `json:"rate_limit_reached_type"`
}

// readRolloutOutcome folds a rollout's event_msg records into an outcome:
// the LAST codex_error_info (from an `error` event or `task_complete.error`)
// decides the class; an object form with http_status_code 401/403 is logged
// out (observed on 0.171.0, codex-logged-out.md); token_count rate_limits
// supply windows (latest snapshot per limit/scope/duration key) and the reset.
// ok=false when the rollout carries no outcome evidence. Any unreadable record
// refuses the whole file (errMalformedRolloutOutcome), never a partial read.
func readRolloutOutcome(r io.Reader, now time.Time) (pool.SourceOutcome, bool, error) {
	lr := &io.LimitedReader{R: r, N: int64(maxRolloutBytes) + 1}
	br := bufio.NewReader(lr)
	var info string
	var status int // http_status_code of the last object-form codex_error_info, 0 = none
	var reached bool
	windows := map[windowKey]pool.LimitWindow{}
	for {
		line, err := readRolloutRecord(br, maxRolloutRecordBytes)
		if err == errRolloutRecordTooLarge || lr.N <= 0 {
			return pool.SourceOutcome{}, false, errMalformedRolloutOutcome
		}
		if err != nil && err != io.EOF {
			return pool.SourceOutcome{}, false, errMalformedRolloutOutcome
		}
		if trimmed := strings.TrimSpace(string(line)); trimmed != "" {
			var rec struct {
				Timestamp string          `json:"timestamp"`
				Type      string          `json:"type"`
				Payload   json.RawMessage `json:"payload"`
			}
			if json.Unmarshal(line, &rec) != nil || rec.Type == "" {
				return pool.SourceOutcome{}, false, errMalformedRolloutOutcome
			}
			if rec.Type == "event_msg" {
				var p struct {
					Type       string          `json:"type"`
					ErrorInfo  json.RawMessage `json:"codex_error_info"`
					RateLimits json.RawMessage `json:"rate_limits"`
					Error      *struct {
						ErrorInfo json.RawMessage `json:"codex_error_info"`
					} `json:"error"` // task_complete only
				}
				if json.Unmarshal(rec.Payload, &p) != nil {
					return pool.SourceOutcome{}, false, errMalformedRolloutOutcome
				}
				switch p.Type {
				case "error":
					if v, st := decodeErrorInfo(p.ErrorInfo); v != "" {
						info, status = v, st
					}
				case "task_complete":
					if p.Error != nil {
						if v, st := decodeErrorInfo(p.Error.ErrorInfo); v != "" {
							info, status = v, st
						}
					}
				case "token_count":
					at := now
					if ts, terr := time.Parse(time.RFC3339Nano, rec.Timestamp); terr == nil {
						at = ts
					}
					if snap, ok := decodeRolloutRateLimits(p.RateLimits, at); ok {
						for k, w := range snap.windows {
							windows[k] = w // latest snapshot of the same key wins
						}
						reached = snap.reached
					}
				}
			}
		}
		if err == io.EOF {
			break
		}
	}

	var o pool.SourceOutcome
	switch {
	case info == "unauthorized" || status == 401 || status == 403:
		o.Class = pool.OutcomeLoggedOut
	case info == "usage_limit_exceeded" || info == "usage_not_included" || (info == "" && reached):
		o.Class = pool.OutcomeExhausted
		o.ResetAt = exhaustedReset(windows)
	case transientErrorInfo[info]:
		o.Class = pool.OutcomeTransient
	case info != "":
		o.Class = pool.OutcomeOther
	default:
		return pool.SourceOutcome{}, false, nil
	}
	o.Windows = sortedWindows(windows)
	return o, true, nil
}

// decodeErrorInfo accepts the unit-variant string form ("usage_limit_exceeded")
// and the data-variant object form ({"http_connection_failed":{"http_status_code":401}}).
// status is the inner http_status_code when present and numeric, else 0.
func decodeErrorInfo(raw json.RawMessage) (info string, status int) {
	if len(raw) == 0 {
		return "", 0
	}
	var s string
	if json.Unmarshal(raw, &s) == nil {
		return strings.TrimSpace(s), 0
	}
	var obj map[string]json.RawMessage
	if json.Unmarshal(raw, &obj) == nil && len(obj) == 1 {
		for k, inner := range obj {
			var d struct {
				HTTPStatusCode *int `json:"http_status_code"`
			}
			if json.Unmarshal(inner, &d) == nil && d.HTTPStatusCode != nil {
				status = *d.HTTPStatusCode
			}
			return strings.TrimSpace(k), status
		}
	}
	return "", 0
}

type rateSnapshot struct {
	windows map[windowKey]pool.LimitWindow
	reached bool
}

func decodeRolloutRateLimits(raw json.RawMessage, at time.Time) (rateSnapshot, bool) {
	if len(raw) == 0 || string(raw) == "null" {
		return rateSnapshot{}, false
	}
	var rl rawRolloutRateLimits
	if json.Unmarshal(raw, &rl) != nil {
		return rateSnapshot{}, false // lenient: an unreadable snapshot is ignored, not fatal
	}
	snap := rateSnapshot{windows: map[windowKey]pool.LimitWindow{}, reached: rl.ReachedType != nil && *rl.ReachedType != ""}
	id, scope := "codex", ""
	if rl.LimitID != nil && *rl.LimitID != "" {
		id = *rl.LimitID
	}
	if rl.LimitName != nil {
		scope = *rl.LimitName
	}
	for _, w := range []*rawRolloutWindow{rl.Primary, rl.Secondary} {
		if w == nil {
			continue
		}
		lw := pool.LimitWindow{LimitID: id, ModelScope: scope, DurationMins: w.WindowMinutes, UsedPercent: w.UsedPercent}
		if t := normalizeResetEpoch(w.ResetsAt); t != nil {
			lw.ResetAt = t
		} else if w.ResetsInSeconds != nil && *w.ResetsInSeconds > 0 {
			t := at.Add(time.Duration(*w.ResetsInSeconds * float64(time.Second))).UTC()
			lw.ResetAt = &t
		}
		putWindow(snap.windows, lw)
	}
	return snap, true
}

// putWindow stores w under its identity key; within one snapshot two windows
// with the same key keep the more-used one (never silently lose exhaustion).
func putWindow(m map[windowKey]pool.LimitWindow, w pool.LimitWindow) {
	k := windowKey{limitID: w.LimitID, scope: w.ModelScope, mins: w.DurationMins}
	if prev, ok := m[k]; ok && used(prev) >= used(w) {
		return
	}
	m[k] = w
}

func used(w pool.LimitWindow) float64 {
	if w.UsedPercent == nil {
		return -1
	}
	return *w.UsedPercent
}

// exhaustedReset is the LATEST reset among windows at or above 100% (the source
// is unusable until every exhausted window resets); nil = unknown.
func exhaustedReset(ws map[windowKey]pool.LimitWindow) *time.Time {
	var out *time.Time
	for _, w := range ws {
		if used(w) >= 100 && w.ResetAt != nil && (out == nil || w.ResetAt.After(*out)) {
			t := *w.ResetAt
			out = &t
		}
	}
	return out
}

func sortedWindows(ws map[windowKey]pool.LimitWindow) []pool.LimitWindow {
	if len(ws) == 0 {
		return nil
	}
	out := make([]pool.LimitWindow, 0, len(ws))
	for _, w := range ws {
		out = append(out, w)
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].LimitID != out[j].LimitID {
			return out[i].LimitID < out[j].LimitID
		}
		if out[i].ModelScope != out[j].ModelScope {
			return out[i].ModelScope < out[j].ModelScope
		}
		return out[i].DurationMins < out[j].DurationMins
	})
	return out
}

// normalizeResetEpoch converts epoch seconds (or ms when > 1e12) to UTC.
func normalizeResetEpoch(v *float64) *time.Time {
	if v == nil || *v <= 0 {
		return nil
	}
	sec := *v
	if sec > 1e12 {
		sec /= 1000
	}
	t := time.Unix(int64(sec), 0).UTC()
	return &t
}

// attachRolloutOutcome wraps err with the outcome read from threadID's rollout
// under env's codex home. Any lookup/read failure returns err unchanged
// (=> classified "other"). Must run BEFORE SanitizeProcessError.
func attachRolloutOutcome(env []string, threadID string, err error, now time.Time) error {
	if err == nil || strings.TrimSpace(threadID) == "" {
		return err
	}
	home, herr := resolveCodexHome(env)
	if herr != nil {
		return err
	}
	path, ferr := findRollout(home, strings.TrimSpace(threadID))
	if ferr != nil {
		return err
	}
	f, oerr := os.Open(path)
	if oerr != nil {
		return err
	}
	defer f.Close()
	o, ok, rerr := readRolloutOutcome(f, now)
	if rerr != nil || !ok {

// execAppServer starts `<bin> app-server` with pipes for stdin/stdout; stderr is
// discarded. Killing the process closes stdout, unblocking a pending read.
func execAppServer(_ context.Context, bin string, env []string) (appServerProc, error) {
	cmd := exec.Command(bin, "app-server")
	cmd.Env = env
	stdin, err := cmd.StdinPipe()
	if err != nil {
		return nil, err
	}
	stdout, err := cmd.StdoutPipe()
	if err != nil {
		return nil, err
	}
	if err := cmd.Start(); err != nil {
		return nil, err
	}
	return &execAppServerProc{cmd: cmd, stdin: stdin, stdout: stdout}, nil
}

	RateLimitsByLimitID  map[string]rpcSnapshot `json:"rateLimitsByLimitId"`
}

var errNoRateLimitsAnswer = errors.New("codex app-server: no account/rateLimits/read answer")

// RateLimitsRead runs `codex app-server`, writes the initialize handshake and
// account/rateLimits/read, and KEEPS STDIN OPEN until the id-1 answer arrives:
// 0.171.0 exits on stdin EOF without answering (codex-app-server.md). It then
// closes stdin, kills and reaps the process. Bounded by probeTimeout and
// probeMaxResponseBytes. Spends no model tokens; runs under the no-key env.
func RateLimitsRead(ctx context.Context, cfg Config) (RateLimitsSnapshot, error) {
	start := cfg.appServer
	if start == nil {
		start = execAppServer
	}
	callCtx, cancel := procenv.WithTimeout(ctx, probeTimeout)
	defer cancel()
	proc, err := start(callCtx, resolveBinary(cfg.BinaryPath), codexEnv())
	if err != nil {
		return RateLimitsSnapshot{}, fmt.Errorf("%w: %w", ErrRateLimitsUnavailable, claudecli.SanitizeProcessError(err))
	}
	stopped := make(chan struct{})
	go func() {
		select {
		case <-callCtx.Done():
			_ = proc.Kill() // deadline: unblocks the pending read
		case <-stopped:
		}
	}()
	defer func() {
		close(stopped)
		_ = proc.Stdin().Close()
		_ = proc.Kill()
		_ = proc.Wait() // stopped on purpose; exit status is irrelevant
	}()
	if _, err := io.WriteString(proc.Stdin(), appServerRequest); err != nil {
		return RateLimitsSnapshot{}, ErrRateLimitsUnavailable
	}
	result, err := readRateLimitsAnswer(io.LimitReader(proc.Stdout(), probeMaxResponseBytes))
	if err != nil {
		return RateLimitsSnapshot{}, ErrRateLimitsUnavailable
	}
	windows := map[windowKey]pool.LimitWindow{}
	add := func(s rpcSnapshot) {
		id, scope := "codex", ""
		if s.LimitID != nil && *s.LimitID != "" {
			id = *s.LimitID
		}
		if s.LimitName != nil {
			scope = *s.LimitName
		}
		for _, w := range []*rpcWindow{s.Primary, s.Secondary} {
			if w == nil {
				continue
			}
			putWindow(windows, pool.LimitWindow{LimitID: id, ModelScope: scope, DurationMins: w.WindowDurationMins, UsedPercent: w.UsedPercent, ResetAt: normalizeResetEpoch(w.ResetsAt)})
		}
	}
	if len(result.RateLimitsByLimitID) > 0 {
		for _, s := range result.RateLimitsByLimitID {
			add(s)
		}
	} else if result.RateLimits != nil {
		add(*result.RateLimits)
	}
	return RateLimitsSnapshot{OrdinaryUsageAllowed: result.OrdinaryUsageAllowed, Windows: sortedWindows(windows)}, nil
}

// readRateLimitsAnswer scans stdout lines, skipping the initialize reply,
// notifications (no id) and noise, and returns the id-1 result. Any id-1 error
// (whatever its code), unreadable result, oversized line or EOF first fails.
func readRateLimitsAnswer(r io.Reader) (*rpcRateLimitsResult, error) {
	sc := bufio.NewScanner(r)
	sc.Buffer(make([]byte, 0, 64<<10), int(probeMaxResponseBytes))
	for sc.Scan() {
		var msg struct {
			ID     *int            `json:"id"`
			Result json.RawMessage `json:"result"`
			Error  json.RawMessage `json:"error"`
		}
		if json.Unmarshal(sc.Bytes(), &msg) != nil || msg.ID == nil || *msg.ID != 1 {
			continue
		}
		if len(msg.Error) > 0 && string(msg.Error) != "null" {
			return nil, errNoRateLimitsAnswer // never classified from the error's prose
		}
		var res rpcRateLimitsResult
		if json.Unmarshal(msg.Result, &res) != nil {
			return nil, errNoRateLimitsAnswer
		}
		return &res, nil
	}
	return nil, errNoRateLimitsAnswer // EOF before id 1, cap reached, or scanner error
}

// HarnessFloor names a codex feature arbitron relies on and the first release
// that provides it.
type HarnessFloor struct {
	Feature string
	Min     string
}

// SupportedVersions is the codex capability table; the floor is the highest Min.
// minCodexVersion stays the execution floor; minLunaRouteCodexVersion stays the
// separate LunaRoute credential-safety floor (version.go). The 0.170.0 entries
// are evidence-inferred, not certified per release (RR-03 DECISION 2026-11-22,
// phase-1 task-12 plan); shapes were observed on 0.171.0.
var SupportedVersions = []HarnessFloor{
	{Feature: "exec --json event stream", Min: minCodexVersion},
	{Feature: "rollout codex_error_info and token_count rate_limits", Min: "0.170.0"},
	{Feature: "app-server account/rateLimits/read ordinaryUsageAllowed", Min: "0.170.0"},
}

// ErrCodexMissing means the codex binary could not be started.
var ErrCodexMissing = errors.New("codex: binary not found")

// CheckVersion reports whether v satisfies every SupportedVersions floor.
func CheckVersion(v string) (bool, string) {
	found := parseVersion(v)
	if found == nil {
		if strings.TrimSpace(v) == "" {
			return false, "codex version unknown"
		}
		return false, fmt.Sprintf("codex version %q is not parseable", v)
	}
	floor := SupportedVersions[0]
	for _, f := range SupportedVersions[1:] {
		if compareVersion(mustParseVersion(f.Min), mustParseVersion(floor.Min)) > 0 {
			floor = f
		}
	}
	if compareVersion(found, mustParseVersion(floor.Min)) < 0 {
		return false, fmt.Sprintf("codex %s is below %s (%s)", v, floor.Min, floor.Feature)
	}
	return true, ""
}

// VersionEvidence separates a MISSING binary (err wraps ErrCodexMissing) from
// an INCOMPATIBLE one (compatible=false with a reason, err nil).
func VersionEvidence(ctx context.Context, cfg Config) (string, bool, string, error) {
	runner := cfg.Runner
	if runner == nil {
		runner = claudecli.NewExecRunner()
	}
	probeCtx, cancel := procenv.WithTimeout(ctx, probeTimeout)
	defer cancel()
	lines, wait, err := runner.Run(probeCtx, claudecli.RunSpec{
		Bin:              resolveBinary(cfg.BinaryPath),
		Args:             []string{"--version"},
		Env:              codexEnv(),
		MaxResponseBytes: probeMaxResponseBytes,
	})
	if err != nil {
		return "", false, "codex binary not found", fmt.Errorf("%w: %w", ErrCodexMissing, claudecli.SanitizeProcessError(err))
	}
	var out []string
	for l := range lines {
		out = append(out, l)
	}
	if werr := wait(); werr != nil {
		return "", false, "codex --version failed", nil
	}
	found := parseVersion(strings.Join(out, "\n"))
	if found == nil {
		return "", false, "codex --version output is not parseable", nil
	}
	v := fmt.Sprintf("%d.%d.%d", found[0], found[1], found[2])
	if compareVersion(found, mustParseVersion(minCodexVersion)) < 0 {
		return v, false, fmt.Sprintf("codex %s is below the execution floor %s", v, minCodexVersion), nil
	}
	if ok, reason := CheckVersion(v); !ok {
		return v, false, reason, nil
	}
	return v, true, "", nil
}

## Alignment acceptance requirements (2026-11-20)

The rollout reader must scope evidence to the **current turn** before it can classify a failure. Reading the last error from an entire resumed session can park a healthy account because an earlier turn exhausted. Add RED cases `TestReadRolloutOutcome_OldExhaustionThenCurrentOther`, `TestReadRolloutOutcome_CurrentUnknownErrorClearsPriorClass`, `TestReadRolloutOutcome_TruncatedCurrentTurnFailsClosed` and `TestReadRolloutOutcome_CurrentWindowScope`. The adapter captures the rollout byte offset/turn ID before resume (new sessions use the stdout thread/turn identity); read only matching records through a bounded reader. A current-turn boundary that cannot be established returns no classification. Any current error without usable structured error info must replace the previous error classification with Other, not leave the old value latched. Validate reset numeric bounds and malformed window units before converting them to durations/times.

`classifiesRollout` is limited to native **no-connection** Codex subscription bindings. Connection-backed execution, including LunaRoute, must never read the host subscription rollout to infer source exhaustion. Add a non-LunaRoute connection-backed case alongside the LunaRoute case.

Per-version capture certification is a Non-Goal (DECISION RR-03, 2026-11-22): synthetic fixtures plus fail-closed Other/unknown are the accepted coverage, and the logged-out and app-server fixtures copied from the 0.171.0 evidence docs ground the shapes that were observable. The RPC implementation performs initialization in the observed order (`initialize`, `initialized`, `account/rateLimits/read`), keeps stdin open until the id-1 answer, and bounds/reaps the child after response, cancellation or deadline. Explicit `ordinaryUsageAllowed: true` confirms ordinary capacity, false holds exhaustion, null/missing/unreadable remains unknown regardless of percentages. Current-turn scoping (above) applies equally to `task_complete.error`: only the current turn's `task_complete` counts.
