## Resolution amendment — RR-08 non-portable homes (decision 2026-11-22)

Decision (recorded in P3 T2 "Portable Git producer" and the Phase 3 design RR-08 row): Arbitron never fetches promisor objects over the network. A run whose repository has required promisor objects missing locally gets a **non-portable home**: it is pinned to the built-in runner, excluded from remote placement and load moves, and its steps keep running on the built-in runner as today, with no step failure. The marker clears automatically when a later built-in checkpoint attempt finds all objects present. Partial clones are a Non-Goal for remote execution. This amendment is authoritative over conflicting text below.

## Alignment repair — required replacement work (2026-11-20)

**Location is not a writer lease.** Keep `HomeStore` as the location/history API, but retire the claim that same-owner `AcquireResource` provides exclusive execution. Add a required durable writer port in `domain/runner/resource_lease.go`:
```go
type ResourceLeaseStore interface {
 Claim(ctx context.Context, key, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
 Check(ctx context.Context, f engine.ResourceFenceRef) error
 Release(ctx context.Context, f engine.ResourceFenceRef) error
 Supersede(ctx context.Context, old engine.ResourceFenceRef, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
}
```
`engine.ResourceFenceRef` is `{Key string; Owner string; Generation int64; Token uuid.UUID}`. `holder` is the durable operation identity (`invocation/operation/attempt` or group mutation ID), and run workspaces use `run:<uuid>`. `adapter/sqlite/resource_lease_repo.go:ResourceLeaseRepo` implements it over 044 `workspace_leases`. `Claim` atomically fails `ErrResourceBusy` for any active holder, including another job on the same runner; each new claim gets a new random token and increments generation. The same holder may recover its exact existing claim only after verifying its durable operation/job identity. There is no TTL-based ownership transfer: suspect grace must not be bypassed.

`Supersede` is an internal recovery transaction only after the old job is fenced for confirmed runner loss/revocation, or cancellation plus confirmed process stop; it verifies the entire old token/generation. `Release` is also token/generation checked and cannot release a newer writer. `MarkDirty` and `SetCheckpoint` may not be invoked as independent unfenced progress writes: P3 T5/T6/T13 transactions own those changes together with the resource lease.

P3 T13 builds one `NewResourceLeaseRepo(db)` and passes it to workspace sync, group resource, recovery, transfer token issuer and committers. Before implementation add `TestResourceLease_SameRunnerWritersCannotOverlap`, `TestResourceLease_ConcurrentClaimHasOneWinner`, `TestResourceLease_StaleReleaseCannotClearNewOwner`, `TestResourceLease_SuspectDoesNotAuthorizeSupersede`, `TestResourceLease_StorageErrorNeverGrantsOwnership`.

**Goal:** Implement `runner.HomeStore` over SQLite so every run's workspace has exactly one owning runner (its home) guarded by an expected-generation CAS, with a move history row for every handoff, and expose homes in `Registry.Snapshot`.
**Architecture:** `workspace_homes` (migration 041, P1 T5) holds the current owner/generation/checkpoint version/dirty flag; `home_moves` (044, P3 T1) is the append-only history. Each mutation is one SQLite transaction (`SetMaxOpenConns(1)` ⇒ single writer) with a `WHERE generation = ?` CAS. The repo never reacts to liveness: a suspect home keeps ownership until a caller (dispatcher/recovery) hands it off after loss. Events (`workspace.moved`) are emitted by the sync service (P3 T6), not here.
**Tech Stack:** Go 1.25.5, hand-written SQL (pattern `adapter/sqlite/audit_repo.go`), modernc SQLite, testify.
**Spec / Design:** spec "Recovery and session continuity" (one active execution owner); design phase 3 §3.1 (homes, generation, history, exactly one writer, suspect keeps ownership), §5 row "Home/resource identity, lease/generation, ownership and move history" (RR-08), §8 ("two workspace writers cannot overlap", "suspect homes do not move before loss"). Semantics:
- `AcquireResource(owner)`: current owner == `owner` ⇒ returns the home unchanged (idempotent, no bump). No row or owner `""` ⇒ becomes `owner`, generation+1, history `{From:"", To: owner, Reason:"acquire"}`. Different owner ⇒ `ErrHomeOwned`. Generation ≠ `expectGen` ⇒ `ErrHomeGenerationConflict`.
- `HandOff(to)`: CAS on `expectGen`; `to` == current owner ⇒ unchanged; otherwise owner=`to`, generation+1, `dirty=0` (the new owner starts from the committed checkpoint), history row with reason/bytes.

```go
// Two workspace writers cannot overlap: N concurrent handoffs with the same
// expected generation produce exactly one winner (file-backed DB, real tx).
func TestWorkspaceHomeRepo_ConcurrentHandOffSingleWinner(t *testing.T) {
	ctx := context.Background()
	db, err := Open(filepath.Join(t.TempDir(), "homes.db"))
	require.NoError(t, err)
	t.Cleanup(func() { db.Close() })
	require.NoError(t, RunMigrations(db))
	repo := NewWorkspaceHomeRepo(db)
	run := uuid.New()
	_, err = repo.AcquireResource(ctx, run, runner.BuiltInRunnerID, 0)
	require.NoError(t, err)

	const writers = 12
	var wg sync.WaitGroup
	var mu sync.Mutex
	wins, conflicts := 0, 0
	for i := 0; i < writers; i++ {
		wg.Add(1)
		go func(i int) {
			defer wg.Done()
			_, err := repo.HandOff(ctx, run, runner.RunnerID(fmt.Sprintf("mac-%d", i)), "should_move", 0, 1)
			mu.Lock()
			defer mu.Unlock()
			switch {
			case err == nil:
				wins++
			case errors.Is(err, runner.ErrHomeGenerationConflict):
				conflicts++
			default:
				t.Errorf("unexpected error: %v", err)
			}
		}(i)
	}
	wg.Wait()
	assert.Equal(t, 1, wins)
	assert.Equal(t, writers-1, conflicts)
	h, err := repo.GetHome(ctx, run)
	require.NoError(t, err)
	assert.Equal(t, int64(2), h.Generation)
	hist, err := repo.History(ctx, run)
	require.NoError(t, err)
	assert.Len(t, hist, 2, "exactly one handoff recorded")
}
```

```go
	To         RunnerID  `json:"to"`

	Bytes      int64     `json:"bytes"`

// workspace. Every ownership change is a compare-and-swap on Generation and
// appends one HomeMove.

	ListByRunner(ctx context.Context, id RunnerID) ([]Home, error)

}
```

```go
// domain/runner/resource_lease.go
type LeaseRecord struct {
    Fence  engine.ResourceFenceRef // exact active key/owner/generation/token
    Holder string                  // durable operation identity
    Job    *Fence                  // exact P1 ledger fence of the writing job; nil for server-side holders
    BootID string                  // server boot that took a server-side (Job == nil) claim; "" for job claims
}
type SupersedeKind string
const (
    SupersedeRunnerLost    SupersedeKind = "runner_lost"    // remote owner: runners.liveness = 'lost'
    SupersedeRevoked       SupersedeKind = "revoked"        // remote owner: runner_keys.revoked_at IS NOT NULL
    SupersedeStopped       SupersedeKind = "stopped"        // cancellation + confirmed stop: builtin_processes(job,gen).state='stopped' (built-in) or runner_inbox_cursors(job,gen).result_received=1 (remote)
    SupersedeServerRestart SupersedeKind = "server_restart" // server-side holder (Job == nil) whose BootID != the repo's current boot ID (design D7: restart = built-in runner loss)
)
type SupersedeProof struct {
    Kind   SupersedeKind
    OldJob *Fence // must equal LeaseRecord.Job exactly when the lease has a job; nil otherwise
}
type ResourceLeaseStore interface {
    // Server-side holder (group mutation, drain/maintenance, recovery restore). Records BootID.
    Claim(ctx context.Context, key, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
    // Dispatched job holder. In ONE transaction: the job fence must be active in runner_jobs
    // (same rule as Ledger.FenceCheck), owner = job.RunnerID, and the job association is persisted.
    // The SAME exact job fence re-claiming returns the existing ref (adoption/idempotent retry).
    ClaimJob(ctx context.Context, key, holder string, job Fence) (engine.ResourceFenceRef, error)
    Check(ctx context.Context, f engine.ResourceFenceRef) error
    Active(ctx context.Context, key string) (LeaseRecord, bool, error)
    Release(ctx context.Context, f engine.ResourceFenceRef) error
    Supersede(ctx context.Context, old engine.ResourceFenceRef, proof SupersedeProof, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
}
func JobHolder(j Job) string // "job:<jobID>/inv:<invocationID>/op:<operationID>/attempt:<n>"
```

`Supersede` rules, all inside ONE SQLite transaction (any failure changes nothing and returns `ErrSupersedeUnproven` or `ErrResourceFenced`):
1. The active `workspace_leases` row for `old.Key` matches `old` exactly (token, generation, owner, active=1); otherwise `ErrResourceFenced`.
2. Its `workspace_lease_holders` row is loaded. If it has a job, `proof.OldJob` must equal it exactly, and `runner_jobs` must NOT still authorize that fence (`NOT (generation = ? AND runner_id = ? AND state IN ('offered','running'))`): the caller fences the old job (Requeue/Fail) first. A job-less holder requires `proof.OldJob == nil`.
3. Kind evidence, read in the same transaction:
   - `runner_lost`: owner != builtin AND `runners.liveness = 'lost'`. Suspect/offline is never enough.
   - `revoked`: owner != builtin AND `runner_keys.revoked_at IS NOT NULL` for that runner_id.
   - `stopped`: the lease has a job; owner == builtin → `builtin_processes(job_id, generation).state = 'stopped'` (written by P3 T10 `ProcessSupervisor.StopAndWait` after confirmed group exit); remote → `runner_inbox_cursors(job_id, generation).result_received = 1`.
   - `server_restart`: the lease has no job AND `boot_id !=` the current boot ID.
   - Any other combination: `ErrSupersedeUnproven`.
4. Insert the `workspace_lease_supersessions` receipt, replace the lease with a new random token, generation+1, new holder/owner, and insert the new holder row (server-side holder, current boot ID). Commit.

There is no TTL and no liveness-only path; suspect never authorizes `Supersede`. `Release` is exact token/generation/owner (a stale release returns `ErrResourceFenced` and changes nothing). P3 T13 passes one process-lifetime `uuid.NewString()` boot ID created at startup and builds exactly one repo shared by sync, group, recovery, token issuer and committers.

**Consumers:** P3 T6 `BeginAttempt` uses `ClaimJob(ctx, "run:<uuid>", JobHolder(a.Job), a.Fence)`. // domain/runner/resource_lease.go
```go
package runner

import (
	"context"
	"errors"
	"fmt"

	"github.com/arbitron/arbitron/domain/engine"
)

// LeaseRecord is the durable state of one active resource claim.
type LeaseRecord struct {
	Fence  engine.ResourceFenceRef // exact active key/owner/generation/token
	Holder string                  // durable operation identity
	Job    *Fence                  // exact P1 ledger fence of the writing job; nil for server-side holders
	BootID string                  // server boot that took a server-side (Job == nil) claim; "" for job claims
}

// SupersedeKind names the evidence that lets recovery take over a claim.
type SupersedeKind string

const (
	SupersedeRunnerLost    SupersedeKind = "runner_lost"    // remote owner: runners.liveness = 'lost'
	SupersedeRevoked       SupersedeKind = "revoked"        // remote owner: runner_keys.revoked_at IS NOT NULL
	SupersedeStopped       SupersedeKind = "stopped"        // cancellation + confirmed stop of the old job's process
	SupersedeServerRestart SupersedeKind = "server_restart" // server-side holder from an earlier boot (design D7)
)

// SupersedeProof is the caller's claim of why the old holder can no longer
// write. The store re-reads every fact in its own transaction; the proof only
// selects which evidence must hold.
type SupersedeProof struct {
	Kind   SupersedeKind
	OldJob *Fence // must equal LeaseRecord.Job exactly when the lease has a job; nil otherwise
}

// ResourceLeaseStore is the single-writer gate over a resource such as a
// run workspace ("run:<uuid>"). There is no TTL and no liveness-only
// takeover: a suspect owner keeps its claim until Supersede proves loss,
// revocation, a confirmed stop or a server restart.
type ResourceLeaseStore interface {
	// Claim takes a free resource for a server-side holder (group mutation,
	// drain/maintenance, recovery restore) and records the current boot ID.
	Claim(ctx context.Context, key, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
	// ClaimJob takes a free resource for a dispatched job whose exact fence is
	// active; owner = job.RunnerID. The same exact job fence and holder
	// re-claiming returns the existing ref (adoption/idempotent retry).
	ClaimJob(ctx context.Context, key, holder string, job Fence) (engine.ResourceFenceRef, error)
	Check(ctx context.Context, f engine.ResourceFenceRef) error
	Active(ctx context.Context, key string) (LeaseRecord, bool, error)
	Release(ctx context.Context, f engine.ResourceFenceRef) error
	Supersede(ctx context.Context, old engine.ResourceFenceRef, proof SupersedeProof, holder string, owner RunnerID) (engine.ResourceFenceRef, error)
}

// JobHolder is the durable holder identity of a dispatched job's claim.
func JobHolder(j Job) string {
	return fmt.Sprintf("job:%s/inv:%s/op:%s/attempt:%d", j.ID, j.Key.InvocationID, j.Key.OperationID, j.Key.Attempt)
}

var (
	ErrResourceBusy      = errors.New("runner: resource is held by another writer")
	ErrResourceFenced    = errors.New("runner: stale or unknown resource claim")
	ErrSupersedeUnproven = errors.New("runner: resource takeover is not proven by durable evidence")
)
```

```go
// adapter/sqlite/resource_lease_repo.go
package sqlite

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

// ResourceLeaseRepo implements runner.ResourceLeaseStore over 044
// workspace_leases (current claim) and workspace_lease_holders (durable
// operation association per generation). Every check and write runs in one
// transaction on the shared single-connection DB.
type ResourceLeaseRepo struct {
	db     *sql.DB
	bootID string
	now    func() time.Time
}

// NewResourceLeaseRepo builds the repo. bootID identifies this server process
// lifetime (P3 T13 passes one uuid.NewString() created at startup); server-side
// claims record it so a restart can prove their holder is gone.
func NewResourceLeaseRepo(db *sql.DB, bootID string) *ResourceLeaseRepo {
	return &ResourceLeaseRepo{db: db, bootID: bootID, now: func() time.Time { return time.Now().UTC() }}
}

type leaseRow struct {
	ref    engine.ResourceFenceRef
	holder string
	active bool
}

func readLease(ctx context.Context, q groupQueryer, key string) (leaseRow, bool, error) {
	var lr leaseRow
	var token string
	var active int
	err := q.QueryRowContext(ctx, `SELECT holder, owner, generation, token, active FROM workspace_leases WHERE resource_key = ?`, key).
		Scan(&lr.holder, &lr.ref.Owner, &lr.ref.Generation, &token, &active)
	if errors.Is(err, sql.ErrNoRows) {
		return leaseRow{}, false, nil
	}
	if err != nil {
		return leaseRow{}, false, fmt.Errorf("resource lease: read %s: %w", key, err)
	}
	if lr.ref.Token, err = parseUUID(token); err != nil {
		return leaseRow{}, false, err
	}
	lr.ref.Key, lr.active = key, active == 1
	return lr, true, nil
}

// readHolder loads the durable association of one claimed generation.
func readHolder(ctx context.Context, q groupQueryer, f engine.ResourceFenceRef) (runner.LeaseRecord, bool, error) {
	rec := runner.LeaseRecord{Fence: f}
	var jobID, jobRunner sql.NullString
	var jobGen sql.NullInt64
	err := q.QueryRowContext(ctx, `SELECT holder, job_id, job_runner_id, job_generation, boot_id FROM workspace_lease_holders
		WHERE resource_key = ? AND generation = ? AND token = ?`, f.Key, f.Generation, f.Token.String()).
		Scan(&rec.Holder, &jobID, &jobRunner, &jobGen, &rec.BootID)
	if errors.Is(err, sql.ErrNoRows) {
		return runner.LeaseRecord{}, false, nil
	}
	if err != nil {
		return runner.LeaseRecord{}, false, fmt.Errorf("resource lease: read holder: %w", err)
	}
	if jobID.Valid {
		id, err := parseUUID(jobID.String)
		if err != nil {
			return runner.LeaseRecord{}, false, err
		}
		rec.Job = &runner.Fence{JobID: id, RunnerID: runner.RunnerID(jobRunner.String), Generation: jobGen.Int64}
	}
	return rec, true, nil
}

// checkResourceFenceTx is THE resource fence: f must be the exact active claim
// (key, owner, generation, token). Committers (P3 T2/T5/T7/T13, P4 T6) call it
// with their own *sql.Tx, never the *sql.DB, so a single-connection DB cannot
// deadlock.
func checkResourceFenceTx(ctx context.Context, q groupQueryer, f engine.ResourceFenceRef) error {
	if err := f.Validate(); err != nil {
		return fmt.Errorf("%w: %v", runner.ErrResourceFenced, err)
	}
	lr, ok, err := readLease(ctx, q, f.Key)
	if err != nil {
		return err
	}
	if !ok || !lr.active || lr.ref != f {
		return fmt.Errorf("%w: %s generation %d is not the active claim", runner.ErrResourceFenced, f.Key, f.Generation)
	}
	return nil
}

// releaseResourceTx releases exactly f inside the caller's transaction; a stale
// or already released ref changes nothing and returns ErrResourceFenced.
func releaseResourceTx(ctx context.Context, q groupQueryer, f engine.ResourceFenceRef) error {
	if err := f.Validate(); err != nil {
		return fmt.Errorf("%w: %v", runner.ErrResourceFenced, err)
	}
	res, err := q.ExecContext(ctx, `UPDATE workspace_leases SET active = 0
		WHERE resource_key = ? AND owner = ? AND generation = ? AND token = ? AND active = 1`,
		f.Key, f.Owner, f.Generation, f.Token.String())
	if err != nil {
		return fmt.Errorf("resource lease: release: %w", err)
	}
	if n, err := res.RowsAffected(); err != nil || n != 1 {
		return fmt.Errorf("%w: %s generation %d is not the active claim", runner.ErrResourceFenced, f.Key, f.Generation)
	}
	return nil
}

// grant writes a new active claim (generation+1, fresh token) and its holder
// row. The caller has verified the resource is free.
func (r *ResourceLeaseRepo) grant(ctx context.Context, tx *sql.Tx, key, holder, owner string, prevGen int64, job *runner.Fence, bootID string) (engine.ResourceFenceRef, error) {
	ref := engine.ResourceFenceRef{Key: key, Owner: owner, Generation: prevGen + 1, Token: uuid.New()}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_leases(resource_key, holder, owner, generation, token, active) VALUES (?, ?, ?, ?, ?, 1)
		ON CONFLICT(resource_key) DO UPDATE SET holder = excluded.holder, owner = excluded.owner,
		generation = excluded.generation, token = excluded.token, active = 1`,
		key, holder, owner, ref.Generation, ref.Token.String()); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: claim %s: %w", key, err)
	}
	var jobID, jobRunner any
	var jobGen any
	if job != nil {
		jobID, jobRunner, jobGen = uuidToString(job.JobID), string(job.RunnerID), job.Generation
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_lease_holders(resource_key, generation, token, holder, owner,
		job_id, job_runner_id, job_generation, boot_id, claimed_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
		key, ref.Generation, ref.Token.String(), holder, owner, jobID, jobRunner, jobGen, bootID, timeToString(r.now())); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: record holder of %s: %w", key, err)
	}
	return ref, nil
}

// lockLease starts a transaction whose first statement takes the SQLite write
// lock, so the following reads cannot race another writer.
func (r *ResourceLeaseRepo) lockLease(ctx context.Context, key string) (*sql.Tx, error) {
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return nil, fmt.Errorf("resource lease: begin: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_leases SET active = active WHERE resource_key = ?`, key); err != nil {
		_ = tx.Rollback()
		return nil, fmt.Errorf("resource lease: lock: %w", err)
	}
	return tx, nil
}

func (r *ResourceLeaseRepo) Claim(ctx context.Context, key, holder string, owner runner.RunnerID) (engine.ResourceFenceRef, error) {
	if key == "" || holder == "" || owner == "" || r.bootID == "" {
		return engine.ResourceFenceRef{}, errors.New("resource lease: claim needs key, holder, owner and a boot ID")
	}
	tx, err := r.lockLease(ctx, key)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	defer func() { _ = tx.Rollback() }()
	cur, ok, err := readLease(ctx, tx, key)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if ok && cur.active {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: %s is held by %q", runner.ErrResourceBusy, key, cur.holder)
	}
	ref, err := r.grant(ctx, tx, key, holder, string(owner), cur.ref.Generation, nil, r.bootID)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if err := tx.Commit(); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: commit: %w", err)
	}
	return ref, nil
}

func (r *ResourceLeaseRepo) ClaimJob(ctx context.Context, key, holder string, job runner.Fence) (engine.ResourceFenceRef, error) {
	if key == "" || holder == "" || job.JobID == uuid.Nil || job.RunnerID == "" || job.Generation < 1 {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: claim needs key, holder and an exact job fence", runner.ErrFenced)
	}
	tx, err := r.lockLease(ctx, key)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	defer func() { _ = tx.Rollback() }()
	if err := fenceErr(ctx, tx, job); err != nil {
		if errors.Is(err, runner.ErrJobNotFound) {
			return engine.ResourceFenceRef{}, fmt.Errorf("%w: %w", runner.ErrFenced, err)
		}
		return engine.ResourceFenceRef{}, err
	}
	cur, ok, err := readLease(ctx, tx, key)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if ok && cur.active {
		rec, found, err := readHolder(ctx, tx, cur.ref)
		if err != nil {
			return engine.ResourceFenceRef{}, err
		}
		if found && rec.Job != nil && *rec.Job == job && rec.Holder == holder {
			return cur.ref, tx.Commit() // the same exact job re-claiming: adopt its claim
		}
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: %s is held by %q", runner.ErrResourceBusy, key, cur.holder)
	}
	ref, err := r.grant(ctx, tx, key, holder, string(job.RunnerID), cur.ref.Generation, &job, "")
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if err := tx.Commit(); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: commit: %w", err)
	}
	return ref, nil
}

func (r *ResourceLeaseRepo) Check(ctx context.Context, f engine.ResourceFenceRef) error {
	return checkResourceFenceTx(ctx, r.db, f)
}

func (r *ResourceLeaseRepo) Active(ctx context.Context, key string) (runner.LeaseRecord, bool, error) {
	cur, ok, err := readLease(ctx, r.db, key)
	if err != nil || !ok || !cur.active {
		return runner.LeaseRecord{}, false, err
	}
	rec, found, err := readHolder(ctx, r.db, cur.ref)
	if err != nil {
		return runner.LeaseRecord{}, false, err
	}
	if !found {
		return runner.LeaseRecord{}, false, fmt.Errorf("resource lease: active claim %s generation %d has no holder record", key, cur.ref.Generation)
	}
	return rec, true, nil
}

func (r *ResourceLeaseRepo) Release(ctx context.Context, f engine.ResourceFenceRef) error {
	tx, err := r.lockLease(ctx, f.Key)
	if err != nil {
		return err
	}
	defer func() { _ = tx.Rollback() }()
	if err := releaseResourceTx(ctx, tx, f); err != nil {
		return err
	}
	return tx.Commit()
}
```

```go
// adapter/sqlite/resource_lease_supersede.go
package sqlite

import (
	"context"
	"errors"
	"fmt"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
)

var _ runner.ResourceLeaseStore = (*ResourceLeaseRepo)(nil)

// Supersede hands a claim to a new server-side holder only on durable proof
// that the old writer can no longer write, all inside ONE transaction:
//  1. old is the exact active claim (else ErrResourceFenced);
//  2. a job-held claim names proof.OldJob exactly and the ledger no longer
//     authorizes that job fence (the caller fenced it first); a server-side
//     claim requires proof.OldJob == nil;
//  3. the kind's evidence holds now (lost runner, revoked key, confirmed stop,
//     or a server-side claim from an earlier boot);
//  4. a supersession receipt is written and the claim moves to generation+1
//     with a fresh token for holder/owner, recorded under this boot.
//
// Suspect/offline liveness never authorizes it; there is no TTL path. Any
// failure changes nothing.
func (r *ResourceLeaseRepo) Supersede(ctx context.Context, old engine.ResourceFenceRef, proof runner.SupersedeProof, holder string, owner runner.RunnerID) (engine.ResourceFenceRef, error) {
	if holder == "" || owner == "" || r.bootID == "" {
		return engine.ResourceFenceRef{}, errors.New("resource lease: supersede needs holder, owner and a boot ID")
	}
	if err := old.Validate(); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: %v", runner.ErrResourceFenced, err)
	}
	tx, err := r.lockLease(ctx, old.Key)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	defer func() { _ = tx.Rollback() }()
	if err := checkResourceFenceTx(ctx, tx, old); err != nil {
		return engine.ResourceFenceRef{}, err
	}
	rec, found, err := readHolder(ctx, tx, old)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if !found {
		return engine.ResourceFenceRef{}, fmt.Errorf("%w: claim %s generation %d has no holder record", runner.ErrSupersedeUnproven, old.Key, old.Generation)
	}
	if err := r.proveOldJobStopped(ctx, tx, rec, proof); err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if err := r.proveKind(ctx, tx, rec, proof.Kind); err != nil {
		return engine.ResourceFenceRef{}, err
	}
	var jobID, jobGen any
	if rec.Job != nil {
		jobID, jobGen = uuidToString(rec.Job.JobID), rec.Job.Generation
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_lease_supersessions(resource_key, old_generation, old_token,
		new_generation, kind, job_id, job_generation, superseded_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?)`,
		old.Key, old.Generation, old.Token.String(), old.Generation+1, string(proof.Kind), jobID, jobGen, timeToString(r.now())); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: supersession receipt: %w", err)
	}
	ref, err := r.grant(ctx, tx, old.Key, holder, string(owner), old.Generation, nil, r.bootID)
	if err != nil {
		return engine.ResourceFenceRef{}, err
	}
	if err := tx.Commit(); err != nil {
		return engine.ResourceFenceRef{}, fmt.Errorf("resource lease: commit: %w", err)
	}
	return ref, nil
}

func (r *ResourceLeaseRepo) proveOldJobStopped(ctx context.Context, tx groupQueryer, rec runner.LeaseRecord, proof runner.SupersedeProof) error {
	if rec.Job == nil {
		if proof.OldJob != nil {
			return fmt.Errorf("%w: claim %s has no job but the proof names one", runner.ErrSupersedeUnproven, rec.Fence.Key)
		}
		return nil
	}
	if proof.OldJob == nil || *proof.OldJob != *rec.Job {
		return fmt.Errorf("%w: proof does not name the claim's job %s generation %d", runner.ErrSupersedeUnproven, rec.Job.JobID, rec.Job.Generation)
	}
	var live int
	if err := tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM runner_jobs WHERE id = ? AND generation = ? AND runner_id = ? AND state IN ('offered', 'running')`,
		uuidToString(rec.Job.JobID), rec.Job.Generation, string(rec.Job.RunnerID)).Scan(&live); err != nil {
		return fmt.Errorf("resource lease: old job fence: %w", err)
	}
	if live != 0 {
		return fmt.Errorf("%w: job %s generation %d is still authorized; fence it first", runner.ErrSupersedeUnproven, rec.Job.JobID, rec.Job.Generation)
	}
	return nil
}

func (r *ResourceLeaseRepo) proveKind(ctx context.Context, tx groupQueryer, rec runner.LeaseRecord, kind runner.SupersedeKind) error {
	owner := rec.Fence.Owner
	remote := owner != string(runner.BuiltInRunnerID)
	var ok int
	var err error
	switch {
	case kind == runner.SupersedeRunnerLost && remote:
		err = tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM runners WHERE id = ? AND liveness = 'lost'`, owner).Scan(&ok)
	case kind == runner.SupersedeRevoked && remote:
		err = tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM runner_keys WHERE runner_id = ? AND revoked_at IS NOT NULL`, owner).Scan(&ok)
	case kind == runner.SupersedeStopped && rec.Job != nil && !remote:
		err = tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM builtin_processes WHERE job_id = ? AND generation = ? AND state = 'stopped'`,
			uuidToString(rec.Job.JobID), rec.Job.Generation).Scan(&ok)
	case kind == runner.SupersedeStopped && rec.Job != nil && remote:
		err = tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM runner_inbox_cursors WHERE job_id = ? AND generation = ? AND result_received = 1`,
			uuidToString(rec.Job.JobID), rec.Job.Generation).Scan(&ok)
	case kind == runner.SupersedeServerRestart && rec.Job == nil:
		if rec.BootID != r.bootID {
			ok = 1
		}
	}
	if err != nil {
		return fmt.Errorf("resource lease: %s evidence: %w", kind, err)
	}
	if ok == 0 {
		return fmt.Errorf("%w: no durable %q evidence for claim %s generation %d (owner %q)", runner.ErrSupersedeUnproven, kind, rec.Fence.Key, rec.Fence.Generation, owner)
	}
	return nil
}
```
