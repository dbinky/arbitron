# Remote Runners — Phase 3 Task 14: Runner detail homed workspaces

**Goal:** `runner_get` (MCP) and `GET /api/v1/runners/{id}` (REST) list the workspaces homed on that runner as `homes[{runId, hidden, generation, dirty}]`. A caller who cannot view a run sees the home with `runId: null` and `hidden: true`.

**Architecture:**
- `domain/runner/service_homes.go` adds `HomeView` and `(*Service).homeViews`. `ServiceDeps` gains an optional `Homes HomeStore` (contracts §16). `Service.Get` calls `HomeStore.ListByRunner(id)` and applies `Visibility.CanView` to each run, exactly as it already does for assignments.
- The REST DTO (`adapter/http/runner_dto.go`) and the MCP DTO (`adapter/mcp/runner_dto.go`) replace the P1 T15 `homes` `json.RawMessage` placeholder with typed items carrying identical json tags. The DTO never renders a run id for a hidden item, even if one were set.
- The composition root (`cmd/arbitron/runner_wiring.go:newRunnerStack`) passes the `*adaptsqlite.WorkspaceHomeRepo` that P3 T13 already threads in as `runnerStackDeps.Homes`. A nil repo is kept a nil interface, so no typed-nil panics.

**Tech Stack:** Go 1.25.5, testify, chi v5, mark3labs mcp-go, the real `initDomain`/`Start` composition root with the P3 T13 workspace-runner harness (real WebSocket agent, real transfer client).

**Spec / Design:**
- Spec `docs/specs/2026-11-19-remote-runners-spec.md`:
  - "Live views → Runner detail … assigned workspaces";
  - "Administration and visibility": runs a user cannot view never appear.
- Design `docs/designs/2026-11-19-remote-runners-design-phase-3.md`:
  - §3.1: homes, generation, single owner;
  - §8 Success: "homes released" (drain progress is P3 T12; this task makes homes inspectable).
- Design `docs/designs/2026-11-19-remote-runners-design-phase-5.md`:
  - §3.2 "Assignments: homed workspaces (linked to runs)";
  - §8 "hidden-run links/events never render".
- Contracts `docs/plans/remote-runners/2026-11-20-contracts.md`:
  - §7 (`Home`);
  - §14 (`ServiceDeps`, `RunnerDetail`, `RunVisibility`, DTO rules, `runner_get`, `GET /runners/{id}`);
  - §16 (`HomeStore.ListByRunner`, `WorkspaceHomeRepo`).

package runner

import (
	"context"
	"fmt"

	"github.com/google/uuid"
)

// HomeView is one workspace homed on a runner, as the runner detail shows
// it. When the caller cannot view the run, RunID is nil and Hidden is true;
// the generation and dirty flag remain, so the runner's load stays
// explainable without naming the run.
type HomeView struct {
	RunID      *uuid.UUID
	Hidden     bool
	Generation int64
	Dirty      bool
}

// homeViews lists the workspaces homed on runner id. A nil home store
// (Phase 1/2 wiring) yields an empty, non-nil list. A store error fails the
// read: an unreadable store is never reported as "no homes".
func (s *Service) homeViews(ctx context.Context, id RunnerID) ([]HomeView, error) {
	out := []HomeView{}
	if s.d.Homes == nil {
		return out, nil
	}
	homes, err := s.d.Homes.ListByRunner(ctx, id)
	if err != nil {
		return nil, fmt.Errorf("runner: list homes of %s: %w", id, err)
	}
	for _, h := range homes {
		v := HomeView{Generation: h.Generation, Dirty: h.Dirty}
		if s.d.Visibility.CanView(ctx, h.RunID) {
			run := h.RunID
			v.RunID = &run
		} else {
			v.Hidden = true
		}
		out = append(out, v)
	}
	return out, nil
}
