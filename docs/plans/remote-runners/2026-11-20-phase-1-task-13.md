# Remote Runners — Phase 1 Task 13: Source inventory, probers, HealthMonitor and logged-out notification

**Goal:** The built-in runner advertises its credential sources from real host and connection data, and source health stays current automatically:
- Read-only probes run on a timer and cost no slots.
- Recovery after exhaustion goes through a single probation, confirmed by one success.
- When nothing else confirms recovery, a bounded, slot-counted confirmation probe runs through the dispatcher.
- A logged-out source raises exactly one notification (Teams included) and one event.

**Architecture:**
- `domain/runner/inventory.go:BuiltInSources` is a pure mapping from `InventoryInput` to `[]Source`. `adapter/runner/inventory.DetectLocal` produces that input from the binaries on the server host and from `ConnectionStore.List`.
- `domain/runner/health.go:HealthMonitor` owns the source state machine. It is driven by:
  - `ApplyOutcome`: the dispatcher's classified failures, plus successes reported by `NewHealthReportingRunnerSet`.
  - `Tick`: the periodic pass, tested under a fake clock.
- The prober adapters live in `adapter/runner/probe`. `DispatchConfirmer` sends a 1-token exact-model chat through the `StepDispatcher` under a synthetic `OperationProbe` identity, so the probe reserves a slot like any other step.
- `adapter/notification/source_alerts.go` creates the instance-less `source_logged_out` notification and sends the Teams card.

**Tech Stack:** Go 1.25, testify, `math/rand/v2`, existing `claudecli.CommandRunner` / `codex` / `adapter/probe` seams.

**RR-03 decision (cost policy):** this is decidable, so no escalation is needed. A Claude source exhausted with an unknown reset moves to probation after one `ProbeInterval`. If nothing else is in flight on a probation source, `DispatchConfirmer` sends one 1-token chat on the exact model in SourceHealth.ConfirmationModel, at most once per `ProbeInterval` per source. The chat goes through the dispatcher, so it holds a slot and cannot oversubscribe the runner. OpenAI subscriptions confirm through `ordinaryUsageAllowed` instead. For them `Confirm` returns `runner.ErrConfirmationUnsupported`, and the next real step on probation decides.

DECISION (2026-11-22, RR-03): The `claude auth status` contract is taken from the observed Claude Code 2.1.329 output recorded in `docs/evidence/remote-runners/claude-auth-status.md`, which is the producer of this task's auth-status fixtures (copied verbatim, redactions kept). `ClaudeAuthProber` reads only the boolean `loggedIn` key: `loggedIn: true` **and** exit 0 → auth ok; `loggedIn: false` **and** a non-zero exit (exit 1 observed) → logged out, which flows through `HealthMonitor` exactly like a classified logged-out run outcome (source parked, `SourceLoggedOut` notification); everything else (no JSON, missing or non-boolean `loggedIn`, the `logged_in` alias, exit 0 with `loggedIn: false`, non-zero exit with `loggedIn: true`, timeout, spawn failure) → auth unknown, which never parks and never recovers a source. A bare zero exit without JSON is **not** auth ok. Logged-out detection therefore comes from both classified run outcomes (`authentication_failed`, P1 T11) and this probe; recovery comes from an auth-ok probe. Real per-version capture certification is a Non-Goal (same decision as P1 T11).

DECISION (2026-11-22, RR-03): `CodexProber` consumes `codex.RateLimitsRead` (P1 T12), which per `docs/evidence/remote-runners/codex-app-server.md` runs its own stdio session with `codex app-server` (stdin held open until the id-1 answer) rather than a `claudecli.CommandRunner` script. Any id-1 `error` (including the observed `-32600` "authentication required" answer), EOF before id 1, timeout or malformed output returns `codex.ErrRateLimitsUnavailable`, which this prober reports as capacity **unknown**; it never derives logged-out from that error's prose. Codex auth comes only from `codex.Readiness` (`codex login status`) and, at run time, from classified rollout outcomes (P1 T12). The prober tests fake `RateLimitsRead` through the `CodexProber.readLimits` seam, not through `CommandRunner` scripts.

// BuiltInSources maps the inventory to the built-in runner's sources. Every
// subscription and local-harness source is ALWAYS registered (a missing or
// unsupported binary blocks eligibility via UnavailableReason), so unavailable harnesses remain visible while placement blocks them with a clear capacity reason.
// Initial health: auth unknown, capacity available.
func BuiltInSources(in InventoryInput) []Source {
	known := modelidentity.KnownFamilies()
	withUnresolved := append(append([]modelidentity.Family(nil), known...), modelidentity.FamilyUnresolved)
	var out []Source
	add := func(kind CredentialKind, ref string, fams []modelidentity.Family, backends []string, detail string) {
		out = append(out, Source{
			ID: MakeSourceID(BuiltInRunnerID, kind, ref), RunnerID: BuiltInRunnerID, Kind: kind, CredentialRef: ref,
			Families: fams, Backends: backends,
			UnavailableReason: detail,
			Health: SourceHealth{Auth: AuthUnknown, Capacity: CapacityAvailable},
		})
	}
	add(CredAnthropicSubscription, "", []modelidentity.Family{"anthropic"}, []string{"", "claude-code"}, presenceDetail(in.ClaudeCLI))
	add(CredOpenAISubscription, "", []modelidentity.Family{"openai"}, []string{"codex"}, presenceDetail(in.Codex))

// AuthObservation is one auth-only probe result.
type AuthObservation struct{ State AuthState }

// CapacityObservation is what a read-only probe could observe about capacity.
// OrdinaryUsageAllowed is authoritative when non-nil (Codex); nil is unknown.
type CapacityObservation struct {
	State                CapacityState
	ResetAt              *time.Time
	OrdinaryUsageAllowed *bool
	Windows              []LimitWindow
	Headroom             *float64
}

// ProbeResult is a read-only probe's verdict. Capacity nil = not observable.
type ProbeResult struct {
	Auth     AuthState
	Capacity *CapacityObservation
}

// SourceProber is read-only: it spends no tokens and holds no slot.
type SourceProber interface {
	Probe(ctx context.Context, s Source) (ProbeResult, error)
}

// ConfirmationProber spends a bounded number of tokens through the dispatcher
// (so it reserves a slot). nil error = capacity confirmed.
type ConfirmationProber interface {
	Confirm(ctx context.Context, s Source) error
}

// SourceAlertNotifier raises operator alerts on auth transitions.
type SourceAlertNotifier interface {
	SourceLoggedOut(ctx context.Context, s Source) error
	SourceRecovered(ctx context.Context, s Source) error
}

// MonitorDeps wires the HealthMonitor.
type MonitorDeps struct {
	Registry         Registry
	Probers          map[CredentialKind]SourceProber
	Confirm          ConfirmationProber
	Alerts           SourceAlertNotifier
	Events           *EventRecorder
	Notifier         *PoolNotifier
	Clock            func() time.Time
	Interval, Jitter time.Duration
	Rand             func() float64
}

// ErrConfirmationUnsupported is returned by a ConfirmationProber for a source
// kind it cannot confirm; probation then waits for the next real step.
var ErrConfirmationUnsupported = errors.New("runner: confirmation probe unsupported for this source kind")

// HealthMonitor owns per-source health transitions. All read-modify-write of a
// source's health happens under mu; probes and confirmations run outside it.
type HealthMonitor struct {
	d           MonitorDeps
	mu          sync.Mutex
	lastProbe   map[SourceID]time.Time
	lastConfirm map[SourceID]time.Time
	exhaustedAt map[SourceID]time.Time
	jitter      map[SourceID]time.Duration
	held        map[SourceID]bool // ordinaryUsageAllowed=false: keep exhausted past reset
	confirming  map[SourceID]bool
	wg          sync.WaitGroup
	loop sync.WaitGroup
	startOnce sync.Once
}

// NewHealthMonitor validates the wiring; any missing dependency panics at boot.
func NewHealthMonitor(d MonitorDeps) *HealthMonitor {
	if d.Registry == nil || d.Events == nil || d.Notifier == nil || d.Alerts == nil || d.Confirm == nil || d.Clock == nil || d.Interval <= 0 {
		panic("runner: NewHealthMonitor requires Registry, Events, Notifier, Alerts, Confirm, Clock and a positive Interval")
	}
	if d.Rand == nil {
		d.Rand = rand.Float64
	}
	if d.Jitter < 0 {
		d.Jitter = 0
	}
	if d.Probers == nil {
		d.Probers = map[CredentialKind]SourceProber{}
	}
	return &HealthMonitor{
		d: d, lastProbe: map[SourceID]time.Time{}, lastConfirm: map[SourceID]time.Time{},
		exhaustedAt: map[SourceID]time.Time{}, jitter: map[SourceID]time.Duration{},
		held: map[SourceID]bool{}, confirming: map[SourceID]bool{},
	}
}

// Start runs Tick periodically until ctx ends.
func (m *HealthMonitor) Start(ctx context.Context) {
	m.startOnce.Do(func() {
		m.loop.Add(1)
		go func() {
			defer m.loop.Done()
			every := m.d.Interval / 4
			if every < time.Second { every = time.Second }
			ticker := time.NewTicker(every)
			defer ticker.Stop()
			for {
				if err := m.Tick(ctx); err != nil && ctx.Err() == nil { slog.Warn("runner health tick failed", "error", err) }
				select { case <-ctx.Done(): return; case <-ticker.C: }
			}
		}()
	})
}

// Wait is called after lifecycle cancellation; no new ticks can add confirmations after loop exit.
func (m *HealthMonitor) Wait() { m.loop.Wait(); m.wg.Wait() }

// ApplyOutcome folds one classified outcome (failure from the dispatcher, or
// success from the health-reporting runner set) into the source's health.
func (m *HealthMonitor) ApplyOutcome(ctx context.Context, id SourceID, o SourceOutcome) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	src, err := m.d.Registry.GetSource(ctx, id)
	if err != nil {
		return err
	}
	now := m.d.Clock()
	h := src.Health
	switch o.Class {
	case OutcomeNone:
		h.Auth = AuthOK
		if h.Capacity == CapacityProbation {
			h.Capacity, h.ResetAt = CapacityAvailable, nil
			m.clearEpisode(id)
		}
		h.Congested, h.CongestedUntil = false, nil
		if o.HeadroomHint != nil {
			v := *o.HeadroomHint
			h.Headroom = &v
		}
		if len(o.Windows) > 0 {
			h.Windows = o.Windows
		}
	case OutcomeLoggedOut:
		h.Auth = AuthLoggedOut
	case OutcomeExhausted:
		if o.Model != "" { h.ConfirmationModel = o.Model }
		if hmIsSubscription(src.Kind) {
			m.markExhausted(&h, id, o.ResetAt, now, false)
			if len(o.Windows) > 0 {
				h.Windows = o.Windows
			}
		} else {
			hmMarkCongested(&h, now, o.RetryAfter, m.d.Interval)
		}
	case OutcomeTransient:
		hmMarkCongested(&h, now, o.RetryAfter, m.d.Interval)
	}
	h.LastOutcome = o.Class
	return m.commit(ctx, src, h, Cause{Kind: CauseOutcome, Outcome: o.Class}, now)
}

// Tick is one pass: due read-only probes, reset-driven probation, bounded
// confirmations and congestion expiry.
func (m *HealthMonitor) Tick(ctx context.Context) error {
	snap, err := m.d.Registry.Snapshot(ctx)
	if err != nil {
		return err
	}
	now := m.d.Clock()
	for _, s := range snap.Sources {
		if ctx.Err() != nil {
			return ctx.Err()
		}
		if _, err := m.probe(ctx, s, now, false); err != nil && !errors.Is(err, ErrSourceNotFound) {
			slog.Warn("runner health probe failed", "source", string(s.ID), "error", err)
		}
		if err := m.advance(ctx, s.ID, snap.SourceInFlight[s.ID], now); err != nil && !errors.Is(err, ErrSourceNotFound) {
			slog.Warn("runner health advance failed", "source", string(s.ID), "error", err)
		}
	}
	return nil
}

// ProbeNow runs the read-only probe immediately (operator action).
func (m *HealthMonitor) ProbeNow(ctx context.Context, id SourceID) (SourceHealth, error) {
	src, err := m.d.Registry.GetSource(ctx, id)
	if err != nil {
		return SourceHealth{}, err
	}
	return m.probe(ctx, src, m.d.Clock(), true)
}

func (m *HealthMonitor) probe(ctx context.Context, s Source, now time.Time, force bool) (SourceHealth, error) {
	prober := m.d.Probers[s.Kind]
	if prober == nil {
		return s.Health, nil
	}
	m.mu.Lock()
	last, seen := m.lastProbe[s.ID]
	due := force || !seen || now.Sub(last) >= m.d.Interval
	if due {
		m.lastProbe[s.ID] = now
	}
	m.mu.Unlock()
	if !due {
		return s.Health, nil
	}
	res, perr := prober.Probe(ctx, s)

	m.mu.Lock()
	defer m.mu.Unlock()
	cur, err := m.d.Registry.GetSource(ctx, s.ID)
	if err != nil {
		return SourceHealth{}, err
	}
	h := cur.Health
	t := now
	h.LastProbeAt = &t
	if perr == nil {
		switch res.Auth {
		case AuthOK, AuthLoggedOut:
			h.Auth = res.Auth
		}
		if c := res.Capacity; c != nil {
			if len(c.Windows) > 0 {
				h.Windows = c.Windows
			}
			if c.Headroom != nil {
				v := *c.Headroom
				h.Headroom = &v
			}
			switch {
			case c.OrdinaryUsageAllowed == nil:
				delete(m.held, s.ID) // unknown: never infer recovery from percentages
			case *c.OrdinaryUsageAllowed:
				delete(m.held, s.ID)
				if h.Capacity != CapacityAvailable {
					h.Capacity, h.ResetAt = CapacityAvailable, nil
					m.clearEpisode(s.ID)
				}
			case hmIsSubscription(cur.Kind):
				reset := c.ResetAt
				if reset == nil {
					reset = h.ResetAt
				}
				m.markExhausted(&h, s.ID, reset, now, true)
			}
		}
	}
	return h, m.commit(ctx, cur, h, Cause{Kind: CauseSystem}, now)
}

func (m *HealthMonitor) advance(ctx context.Context, id SourceID, inFlight int, now time.Time) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	cur, err := m.d.Registry.GetSource(ctx, id)
	if err != nil {
		return err
	}
	h := cur.Health
	switch h.Capacity {
	case CapacityExhausted:
		if m.held[id] {
			break
		}
		if h.ResetAt != nil {
			if !now.Before(h.ResetAt.Add(m.jitterFor(id))) {
				h.Capacity = CapacityProbation
			}
		} else {
			since, ok := m.exhaustedAt[id]
			if !ok {
				m.exhaustedAt[id] = now // learned after a restart: start the interval now
			} else if now.Sub(since) >= m.d.Interval {
				h.Capacity = CapacityProbation
			}
		}
	case CapacityProbation:
		last, seen := m.lastConfirm[id]
		if inFlight == 0 && !m.confirming[id] && (!seen || now.Sub(last) >= m.d.Interval) {
			m.lastConfirm[id] = now
			m.confirming[id] = true
			m.wg.Add(1)
			src := cur
			go func() {
				defer m.wg.Done()
				m.finishConfirm(ctx, src, m.d.Confirm.Confirm(ctx, src))
			}()
		}
	}
	if h.Congested && h.CongestedUntil != nil && !now.Before(*h.CongestedUntil) {
		h.Congested, h.CongestedUntil = false, nil
	}
	return m.commit(ctx, cur, h, Cause{Kind: CauseSystem}, now)
}

func (m *HealthMonitor) finishConfirm(ctx context.Context, src Source, err error) {
	m.mu.Lock()
	delete(m.confirming, src.ID)
	m.mu.Unlock()
	switch {
	case err == nil:
		_ = m.ApplyOutcome(ctx, src.ID, SourceOutcome{Class: OutcomeNone})
	case errors.Is(err, ErrConfirmationUnsupported):
		// probation stays; the next real step decides
	default:
		if o := ClassifyError(err); o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut {
			_ = m.ApplyOutcome(ctx, src.ID, o)
		}
	}
}

// markExhausted starts (or refreshes) an exhaustion episode. held=true comes
// from ordinaryUsageAllowed=false and keeps the source exhausted past its reset.
func (m *HealthMonitor) markExhausted(h *SourceHealth, id SourceID, reset *time.Time, now time.Time, held bool) {
	zero := 0.0
	h.Headroom = &zero
	h.ResetAt = hmCopyTime(reset)
	if _, ok := m.exhaustedAt[id]; !ok || h.Capacity != CapacityExhausted {
		m.exhaustedAt[id] = now
		m.jitter[id] = time.Duration(m.d.Rand() * float64(m.d.Jitter))
	}
	if held {
		m.held[id] = true
		h.Capacity = CapacityExhausted
		return
	}
	if reset != nil && !reset.After(now) {
		h.Capacity = CapacityProbation // a reset already past goes straight to probation
		return
	}
	h.Capacity = CapacityExhausted
}

func (m *HealthMonitor) jitterFor(id SourceID) time.Duration {
	if j, ok := m.jitter[id]; ok {
		return j
	}
	j := time.Duration(m.d.Rand() * float64(m.d.Jitter))
	m.jitter[id] = j
	return j
}

func (m *HealthMonitor) clearEpisode(id SourceID) {
	delete(m.exhaustedAt, id)
	delete(m.jitter, id)
	delete(m.held, id)
}

// commit persists h when anything changed, and emits events/alerts only on
// material transitions (never for a bare LastProbeAt refresh).
func (m *HealthMonitor) commit(ctx context.Context, src Source, h SourceHealth, cause Cause, now time.Time) error {
	prev := src.Health
	if reflect.DeepEqual(prev, h) {
		return nil
	}
	if err := m.d.Registry.RecordHealth(ctx, src.ID, h); err != nil {
		return err
	}
	if !hmMaterial(prev, h) {
		return nil
	}
	m.d.Notifier.Notify()
	m.record(ctx, src, EventSourceHealthChanged, cause, h, now)
	if prev.Auth != AuthLoggedOut && h.Auth == AuthLoggedOut {
		m.record(ctx, src, EventSourceLoggedOut, cause, h, now)
		if err := m.d.Alerts.SourceLoggedOut(ctx, src); err != nil {
			slog.Warn("runner source logged-out alert failed", "source", string(src.ID), "error", err)
		}
	}
	authBack := prev.Auth == AuthLoggedOut && h.Auth == AuthOK
	capBack := prev.Capacity != CapacityAvailable && h.Capacity == CapacityAvailable
	if authBack || capBack {
		m.record(ctx, src, EventSourceRecovered, cause, h, now)
	}
	if authBack {
		if err := m.d.Alerts.SourceRecovered(ctx, src); err != nil {
			slog.Warn("runner source recovered alert failed", "source", string(src.ID), "error", err)
		}
	}
	return nil
}

func (m *HealthMonitor) record(ctx context.Context, src Source, kind string, cause Cause, h SourceHealth, now time.Time) {
	detail := map[string]any{"auth": string(h.Auth), "capacity": string(h.Capacity), "congested": h.Congested}
	if h.ResetAt != nil {
		detail["resetAt"] = h.ResetAt.UTC().Format(time.RFC3339)
	}
	m.d.Events.Record(ctx, PoolEvent{ID: uuid.New(), At: now, Kind: kind, RunnerID: src.RunnerID, SourceID: src.ID, Cause: cause, Detail: detail})
}

func hmMaterial(a, b SourceHealth) bool {
	return a.Auth != b.Auth || a.Capacity != b.Capacity || a.Congested != b.Congested ||
		a.LastOutcome != b.LastOutcome || !hmSameTime(a.ResetAt, b.ResetAt) || !hmSameFloat(a.Headroom, b.Headroom)
}

func hmIsSubscription(k CredentialKind) bool {
	return k == CredAnthropicSubscription || k == CredOpenAISubscription
}

func hmMarkCongested(h *SourceHealth, now time.Time, retryAfter, fallback time.Duration) {
	d := retryAfter
	if d <= 0 {
		d = fallback
	}
	until := now.Add(d)
	h.Congested, h.CongestedUntil = true, &until
}

func hmCopyTime(t *time.Time) *time.Time {
	if t == nil {
		return nil
	}
	v := *t
	return &v
}

func hmSameTime(a, b *time.Time) bool {
	if a == nil || b == nil {
		return a == nil && b == nil
	}
	return a.Equal(*b)
}

func hmSameFloat(a, b *float64) bool {
	if a == nil || b == nil {
		return a == nil && b == nil
	}
	return *a == *b
}

package runner

import (
	"context"

// NewHealthReportingRunnerSet wraps every StepRunner so a SUCCESSFUL model step
// reports OutcomeNone (plus any adapter headroom hint) to h. This is what moves
// a probation source to available after one successful step. Failures stay the
// dispatcher's job (it classifies and applies them); process jobs hold a slot
// only and carry no source health.
func NewHealthReportingRunnerSet(inner RunnerSet, h HealthTransitioner) RunnerSet {
	if inner == nil || h == nil {
		panic("runner: NewHealthReportingRunnerSet requires an inner set and a transitioner")
	}
	return healthReportingSet{inner: inner, h: h}
}

type healthReportingSet struct {
	inner RunnerSet
	h     HealthTransitioner
}

func (s healthReportingSet) For(id RunnerID) (StepRunner, bool) {
	r, ok := s.inner.For(id)
	if !ok {
		return nil, false
	}
	return healthReportingRunner{inner: r, h: s.h}, true
}

type healthReportingRunner struct {
	inner StepRunner
	h     HealthTransitioner
}

func (r healthReportingRunner) Run(ctx context.Context, a Assignment, job StepJob) (StepOutput, error) {
	if job.Op == OpProcess || a.Job.SourceID == "" {
		return r.inner.Run(ctx, a, job)
	}
	var mu sync.Mutex
	var seen SourceOutcome
	obsCtx := ContextWithOutcomeObserver(ctx, func(o SourceOutcome) {
		mu.Lock()
		defer mu.Unlock()
		if o.HeadroomHint != nil {
			seen.HeadroomHint = o.HeadroomHint
		}
		if len(o.Windows) > 0 {
			seen.Windows = o.Windows
		}
	})
	out, err := r.inner.Run(obsCtx, a, job)
	if err != nil {
		return out, err
	}
	report := func() {
		mu.Lock()
		o := SourceOutcome{Class: OutcomeNone, Model: job.Binding.Model, HeadroomHint: seen.HeadroomHint, Windows: seen.Windows}
		mu.Unlock()
		if herr := r.h.ApplyOutcome(context.WithoutCancel(ctx), a.Job.SourceID, o); herr != nil {
			slog.Warn("runner success health report failed", "source", string(a.Job.SourceID), "error", herr)
		}
	}
	if out.Stream == nil {
		report()
		return out, nil
	}
	fwd := make(chan engine.ChatChunk)
	src := out.Stream
	go func() {
		defer close(fwd)
		failed := false
		for {
			var c engine.ChatChunk
			var ok bool
			select { case c, ok = <-src: if !ok { return }; case <-ctx.Done(): return }
			if c.Error != nil { failed = true }
			if c.Done && !failed { report() }
			select { case fwd <- c: case <-ctx.Done(): return }
			if c.Done { return }
		}
	}()
	out.Stream = fwd
	return out, nil
}

func NewSourceAlerts(repo notification.Repository, external notification.ExternalNotifier, logger *slog.Logger, now func() time.Time) *SourceAlerts {
	if repo == nil {
		panic("notification: NewSourceAlerts requires a repository")
	}

	}
	if now == nil {
		now = time.Now
	}

// SourceLoggedOut records the notification and fires the external card.
func (a *SourceAlerts) SourceLoggedOut(ctx context.Context, s runner.Source) error {
	n := &notification.Notification{
		ID:           uuid.New(),
		WorkflowName: fmt.Sprintf("runner %s source %s", s.RunnerID, s.Kind),
		Type:         notification.TypeSourceLoggedOut,
		CreatedAt:    a.now(),
	}
	if err := a.repo.Create(ctx, n); err != nil {
		return fmt.Errorf("source logged-out notification: %w", err)
	}
	if a.external != nil {
		a.wg.Add(1)
		go func() {
			defer a.wg.Done()
			if err := a.external.Notify(context.WithoutCancel(ctx), n); err != nil {
				a.logger.Warn("source logged-out external notification failed", "source", string(s.ID), "error", err)
			}
		}()
	}
	return nil
}

	a.logger.Info("runner source recovered", "source", string(s.ID))
	return nil
}

func (a *SourceAlerts) Wait() { a.wg.Wait() }

// Probe implements the observed contract (docs/evidence/remote-runners/claude-auth-status.md):
// loggedIn:true + exit 0 = ok; loggedIn:false + non-zero exit = logged out;
// anything else = unknown (never parks, never recovers).
func (p *ClaudeAuthProber) Probe(ctx context.Context, s runner.Source) (runner.ProbeResult, error) {
	if s.Kind != runner.CredAnthropicSubscription {
		return runner.ProbeResult{Auth: runner.AuthUnknown}, nil
	}
	ctx, cancel := context.WithTimeout(ctx, probeTimeout)
	defer cancel()
	lines, wait, err := p.runner.Run(ctx, claudecli.RunSpec{
		Bin: p.bin, Args: []string{"auth", "status"}, Env: withoutVar(procenv.BaseEnv(), "ANTHROPIC_API_KEY"), MaxResponseBytes: 64 << 10,
	})

		return runner.ProbeResult{Auth: runner.AuthUnknown}, nil

	var out []string
	for l := range lines {
		out = append(out, l)
	}
	werr := wait()
	loggedIn, ok := parseLoggedIn(strings.Join(out, "\n"))
	switch {
	case ok && loggedIn && werr == nil:
		return runner.ProbeResult{Auth: runner.AuthOK}, nil
	case ok && !loggedIn && werr != nil:
		return runner.ProbeResult{Auth: runner.AuthLoggedOut}, nil
	default:
		return runner.ProbeResult{Auth: runner.AuthUnknown}, nil
	}
}

// parseLoggedIn reads only the boolean `loggedIn` key of a JSON object; other
// keys (email, org, plan) are never read, stored or logged.
func parseLoggedIn(s string) (loggedIn bool, ok bool) {
	var m map[string]json.RawMessage
	if json.Unmarshal([]byte(strings.TrimSpace(s)), &m) != nil {
		return false, false
	}
	raw, present := m["loggedIn"]
	if !present || json.Unmarshal(raw, &loggedIn) != nil {
		return false, false
	}
	return loggedIn, true
}

func withoutVar(env []string, name string) []string {
	out := env[:0:0]
	for _, kv := range env {
		if !strings.HasPrefix(kv, name+"=") {
			out = append(out, kv)
		}
	}
	return out
}

			obs.ResetAt = latestExhaustedReset(snap.Windows)
		}
	}
	res.Capacity = obs
	return res, nil
}

// headroomOf = 1 - (highest used% / 100); nil when no window reports usage.
func headroomOf(ws []runner.LimitWindow) *float64 {
	var maxUsed *float64
	for _, w := range ws {
		if w.UsedPercent != nil && (maxUsed == nil || *w.UsedPercent > *maxUsed) {
			v := *w.UsedPercent
			maxUsed = &v
		}
	}
	if maxUsed == nil {
		return nil
	}
	h := 1 - *maxUsed/100
	if h < 0 {
		h = 0
	}
	if h > 1 {
		h = 1
	}
	return &h
}

func latestExhaustedReset(ws []runner.LimitWindow) *time.Time {
	var out *time.Time
	for _, w := range ws {
		if w.UsedPercent != nil && *w.UsedPercent >= 100 && w.ResetAt != nil && (out == nil || w.ResetAt.After(*out)) {
			t := *w.ResetAt
			out = &t
		}
	}
	return out
}

func NewDispatchConfirmer(profiles ProfileLister, workDir string, timeout time.Duration) *DispatchConfirmer {

		panic("probe: NewDispatchConfirmer requires profiles, a work dir and a positive timeout")

// Attach wires the dispatcher after it is built (the dispatcher depends on the
// monitor, which depends on this confirmer).
func (c *DispatchConfirmer) Attach(d Dispatcher) {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.d = d
}

func (c *DispatchConfirmer) withDispatcher(d Dispatcher) *DispatchConfirmer { c.Attach(d); return c }

func (c *DispatchConfirmer) Confirm(ctx context.Context, s runner.Source) error {
	if s.Kind != runner.CredAnthropicSubscription {
		return runner.ErrConfirmationUnsupported
	}
	c.mu.RLock()
	d := c.d
	c.mu.RUnlock()
	if d == nil {
		return ErrConfirmerNotAttached
	}
	b, group, err := c.pick(ctx, s)
	if err != nil {
		return err
	}
	if err := os.MkdirAll(c.workDir, 0o700); err != nil {
		return fmt.Errorf("probe: confirmation work dir: %w", err)
	}
	ctx, cancel := context.WithTimeout(ctx, c.timeout)
	defer cancel()
	id := engine.StepIdentity{
		RunID: uuid.NewSHA1(confirmNamespace, []byte(s.ID)), NodeID: "probe:" + string(s.ID),
		InvocationID: uuid.New(), OperationID: "probe/confirm", Kind: engine.OperationProbe, Attempt: 1,
	}
	ctx = engine.ContextWithStepIdentity(ctx, id)
	req := runner.ExecRequirements{
		Group: group, Model: b.Model, Op: runner.OpChat, Affinity: runner.AffinityBuiltIn,
		RunID: id.RunID, PinnedRunner: s.RunnerID, RequiredSource: s.ID,
	}
	chat := engine.ChatRequest{Model: b.Model, Prompt: "Reply with OK.", MaxTokens: 1, WorkDir: c.workDir, SuppressTools: true}
	_, err = d.Dispatch(ctx, req, runner.StepJob{Op: runner.OpChat, Binding: b, Chat: &chat})
	return err
}

// pick chooses the first (alias-sorted) no-connection profile whose exact model
// is the source's persisted ConfirmationModel and whose group matches the source.
func (c *DispatchConfirmer) pick(ctx context.Context, s runner.Source) (provider.ResolvedBinding, runner.ModelGroup, error) {
	ps, err := c.profiles.List(ctx)
	if err != nil {
		return provider.ResolvedBinding{}, runner.ModelGroup{}, fmt.Errorf("probe: list profiles: %w", err)
	}
	sort.Slice(ps, func(i, j int) bool { return ps[i].Alias < ps[j].Alias })
	for _, p := range ps {
		if p.ConnectionRef != "" || p.Model == "" || s.Health.ConfirmationModel == "" || p.Model != s.Health.ConfirmationModel {
			continue
		}
		b := provider.ResolvedBinding{Kind: provider.ProfileKindChat, Provider: "claude-cli", Model: p.Model, AllowedTools: append([]string(nil), p.AllowedTools...), ContextWindow: p.ContextWindow, Effort: p.Effort}
		g, err := runner.GroupFor(b, runner.OpChat)
		if err != nil || g.Kind != s.Kind {
			continue
		}
		for _, f := range s.Families {
			if f == g.Family {
				return b, g, nil
			}
		}
	}
	return provider.ResolvedBinding{}, runner.ModelGroup{}, ErrNoConfirmationModel
}
