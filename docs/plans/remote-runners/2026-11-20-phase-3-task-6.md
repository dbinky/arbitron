# Remote Runners — Phase 3 Task 6: Workspace attempts and exact prepared completion receipts

## Resolution amendment — RR-08 non-portable homes (decision 2026-11-22)

Decision (recorded in P3 T2 "Portable Git producer" and the Phase 3 design RR-08 row): Arbitron never fetches promisor objects over the network. A run whose repository has required promisor objects missing locally gets a **non-portable home**: it is pinned to the built-in runner, excluded from remote placement and load moves, and its steps keep running on the built-in runner as today, with no step failure. The marker clears automatically when a later built-in checkpoint attempt finds all objects present. Partial clones are a Non-Goal for remote execution. This amendment is authoritative over conflicting text below, except where "Recovery base — DECISION RR-17: B" supersedes it.

**This task (detection producer and attempt consumer).** `ErrPromisorObjectsMissing` comes from P3 T2. The marker is written through P3 T3 `HomeStore.SetNonPortable` (already landed, see Cycle 0).
- `EnsureBaseline`: if the bootstrap store path returns `errors.Is(err, runner.ErrPromisorObjectsMissing)`, call `SetNonPortable(runID, NonPortablePromisorReason)`. This task returns `nil` there (no catalog baseline, dispatch proceeds). P3 T16 Cycle 5 replaces that `return nil` with `LocalCheckpoints.Bootstrap`, whose failure fails preparation visibly.
- `BeginAttempt` on a home whose `NonPortableReason != ""`:
  - requires the assignment's runner to be `BuiltInRunnerID` (any other runner gives `ErrHomeOwned`);
  - does **not** require a committed catalog baseline, and does not restore the working copy (RR-17 B: its committed local checkpoint matches it; failure and recovery restore that local checkpoint through P3 T16's branches of `FinishFailure`/`RestoreBuiltIn`);
  - still claims the `run:<uuid>` resource and marks dirty.
- `CommitBuiltIn`/`FinishSuccess`: when `StageBuiltIn` returns `ErrPromisorObjectsMissing`, call `SetNonPortable` (idempotent) and record no candidate. This task returns the interim receipt `WorkspaceCompletion{NonPortable: true, Resource: <exact claim>}` (accepted by P3 T5's RR-08 `Record` rule). P3 T16 Cycle 5 replaces it with `WorkspaceCompletion{NonPortable: true, LocalRef: <prepared local checkpoint>, Resource}` from `LocalCheckpoints.Take`. When `StageBuiltIn` succeeds for a marked home, the normal candidate flows on, and P3 T5's promotion clears the marker.
- A promisor miss is never a step failure, never a pull/preparation outcome and never an exhaustion signal. The dispatcher never sends a non-portable home to a remote runner (P3 T4, landed: `placement_tiers.go`).

## Recovery base — DECISION RR-17: B

**DECISION (2026-11-22) RR-17: B** (contracts §22/§24; owner P3 T16, `2026-11-20-phase-3-task-16.md`). A non-portable home takes a **local checkpoint** after each workspace-changing step completes: a plain copy of its directory on the server's own disk, with no portable-Git materialization. The step transaction commits it as `workspace_homes.local_checkpoint` via `WorkspaceCompletion.LocalRef`, and only the latest committed copy is kept. PoolRecovery restores it and re-runs the interrupted step under the same fences. With no local copy, recovery uses the home's initial state. With no base at all, `runner.ErrNoRecoveryBase` produces the durable `job.recovery_blocked` blocker. This supersedes the RR-08 amendment where they conflict.

**Goal:** Prepare the right committed workspace under one durable writer claim, execute there, retain a recoverable candidate, and feed its exact identity to the engine's validated commit. Failed/uncommitted edits never become the recovery base. A pull or preparation failure re-places the step without spending workflow retries or exhausting a source.

**Architecture:**
- `domain/runner/baseline.go` — `BaselineInitializer`, the domain service behind the engine port `engine.WorkspaceBaselineInitializer` (`domain/engine/workspace_baseline.go`). `Engine.prepareWorkspace` calls it after `EnsureInstanceDir` and before the run loop dispatches anything; it is the ONLY caller of the bootstrap store path (`CheckpointStore.Commit`).
- `domain/runner/sync.go` — `WorkspaceSync`, a pure domain service over `CheckpointStore`, `HomeStore`, `ResourceLeaseStore`, `Ledger`, `TransferTokens`, `EventRecorder`, `ExecutionStatusProjector` and `WorkspaceSizer`. The dispatcher calls it through the narrow `StepWorkspace` port around each reserved attempt (`BeginAttempt` → runner → `FinishSuccess`/`FinishFailure`); the hub (P3 T8) calls `PreparePull`; the transfer handler (P3 T7) calls `AcceptPush` and `ReportProgress`; PoolRecovery (P3 T10) calls `RestoreBuiltIn`.
- `domain/runner/transfer.go` — `TransferScope`, `TransferToken`, `TransferTokens` declarations (P3 T7 appends the service to this file).
- `domain/runner/dispatcher_workspace.go` — dispatcher integration: requirement normalisation, `SetWorkspace`, attempt begin/finish, deferred completion receipts, `ReleaseCompletions`, per-operation runner exclusion for pull/preparation failures.
- Wire/hub vocabulary: `OutcomePullFailed`, `OutcomePreparationFailed`, `Reject.Code` (`runnerproto`, `adapter/http`, `runneragent`, `wsclient`, `Hub.handleJob`).
- Hexagonal: `domain/engine` imports no runner/adapters; `domain/runner` imports no adapters. Tests in `package runner_test` / `package engine_test` use the real SQLite and checkpoint adapters (precedent: `domain/runner/hub_inbox_test.go`, `domain/engine/group_launcher_test.go`).

**Tech Stack:** Go 1.25.5, `github.com/google/uuid`, testify, file-backed SQLite (migration 044, no new migration), `adapter/runner/hubtest` (real ledger/registry/events), P3 T2 `adapter/checkpoint`.

**Spec / Design:** spec "Workspace mobility" and "Recovery and session continuity"; `docs/designs/2026-11-19-remote-runners-design-phase-3.md` §3.1–§3.3, §3.5, §4 ("a workspace step that moves"), §7 (push/pull failure, disk full), §8 (Error: "a pull failure re-places the step", "an interrupted upload never marks the step done"; regressions: "built-in interrupted edits roll back", "failed pushes restore the previous checkpoint before retry", "two workspace writers cannot overlap"). package runner

import (
	"context"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/google/uuid"

// Transfer directions (migration 044 transfer_sessions.direction). P4 T12
// adds its own session direction.
const (
	TransferPull   = "pull"
	TransferPush   = "push"
	TransferBundle = "bundle"
)

// DefaultTransferTokenTTL is the token lifetime when SyncDeps.TokenTTL <= 0.
const DefaultTransferTokenTTL = 15 * time.Minute

// TransferScope is the exact authority one transfer token carries. It names
// exactly ONE active job fence, or ONE durable maintenance operation
// (MaintenanceOperationID with a fence that carries only the target runner).
// BaseRef pins the committed checkpoint a pull/push works against, BundleHash
// pins one script bundle, and Resource is the exact writer claim. P3 T7
// rejects any other shape; nothing here is a wildcard.
type TransferScope struct {
	Fence                  Fence
	MaintenanceOperationID string
	RunID                  uuid.UUID
	Direction              string
	BaseRef                string
	BundleHash             string
	Resource               engine.ResourceFenceRef
}

// TransferToken is an issued token and the scope it was issued for (contracts §16).
type TransferToken struct {
	Token                  string
	MaintenanceOperationID string
	JobID                  uuid.UUID
	Generation             int64
	RunnerID               RunnerID
	RunID                  uuid.UUID
	Direction              string
	BaseRef                string
	Resource               engine.ResourceFenceRef
	BundleHash             string
	ExpiresAt              time.Time
}

// Scope is the scope this token was issued for.
func (t TransferToken) Scope() TransferScope {
	return TransferScope{
		Fence:                  Fence{JobID: t.JobID, RunnerID: t.RunnerID, Generation: t.Generation},
		MaintenanceOperationID: t.MaintenanceOperationID,
		RunID:                  t.RunID,
		Direction:              t.Direction,
		BaseRef:                t.BaseRef,
		BundleHash:             t.BundleHash,
		Resource:               t.Resource,
	}
}

// TransferTokens issues and validates transfer tokens. P3 T7's
// TransferTokenService implements it and is constructed with the shared
// ResourceLeaseStore, so Issue and every Validate re-check the exact live job
// fence AND resource claim.
type TransferTokens interface {
	Issue(ctx context.Context, scope TransferScope, ttl time.Duration) (TransferToken, error)
	Validate(ctx context.Context, token string, runner RunnerID) (TransferToken, error)
}

import (
	"context"

// ErrBaselineBlocked: a run has an active operation but no committed
// baseline. The initializer fails closed rather than snapshot interrupted edits.
var ErrBaselineBlocked = errors.New("runner: workspace baseline cannot be created while an operation of the run is active")

// BaselineDeps are the BaselineInitializer's collaborators (all required).
type BaselineDeps struct {
	Checkpoints CheckpointStore
	Ledger      Ledger
	Leases      ResourceLeaseStore
	Homes       HomeStore // RR-08 SetNonPortable
}

// BaselineInitializer is the only caller of the bootstrap store path.
type BaselineInitializer struct{ d BaselineDeps }

var _ engine.WorkspaceBaselineInitializer = (*BaselineInitializer)(nil)

// NewWorkspaceBaselineInitializer validates deps; a missing collaborator panics.
func NewWorkspaceBaselineInitializer(d BaselineDeps) *BaselineInitializer {
	var missing []string
	if d.Checkpoints == nil {
		missing = append(missing, "Checkpoints")
	}
	if d.Ledger == nil {
		missing = append(missing, "Ledger")
	}
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if len(missing) > 0 {
		panic("runner: NewWorkspaceBaselineInitializer requires " + strings.Join(missing, ", "))
	}
	return &BaselineInitializer{d: d}
}

// EnsureBaseline commits the run's canonical directory as its first committed
// checkpoint. An existing committed baseline is reused and never re-snapshotted.
func (i *BaselineInitializer) EnsureBaseline(ctx context.Context, runID uuid.UUID, dir string) error {
	if runID == uuid.Nil {
		return errors.New("runner: baseline requires a run id")
	}
	clean := filepath.Clean(dir)
	if !filepath.IsAbs(clean) || filepath.Base(clean) != runID.String() {
		return fmt.Errorf("runner: baseline directory %q is not run %s's canonical workspace", dir, runID)
	}
	if _, ok, err := i.d.Checkpoints.Latest(ctx, runID); err != nil {
		return fmt.Errorf("runner: read committed baseline of run %s: %w", runID, err)
	} else if ok {
		return nil // committed baseline exists: never re-snapshot (restart copies may be dirty)
	}
	jobs, err := i.d.Ledger.ListByRun(ctx, runID)
	if err != nil {
		return fmt.Errorf("runner: read operations of run %s: %w", runID, err)
	}
	for _, j := range jobs {
		if j.State.Active() {
			return fmt.Errorf("%w: run %s job %s (%s) is %s", ErrBaselineBlocked, runID, j.ID, j.NodeID, j.State)
		}
	}
	_, _, err = i.d.Checkpoints.Commit(ctx, runID, clean)
	if errors.Is(err, ErrPromisorObjectsMissing) {
		// RR-08: no network fetch; the run stays on the built-in runner.
		// P3 T16 Cycle 5 replaces this return with LocalCheckpoints.Bootstrap.
		if err := i.d.Homes.SetNonPortable(ctx, runID, NonPortablePromisorReason); err != nil {
			return fmt.Errorf("runner: mark run %s non-portable: %w", runID, err)
		}
		return nil
	}
	if err != nil {
		if _, ok, lerr := i.d.Checkpoints.Latest(ctx, runID); lerr == nil && ok {
			return nil // a concurrent initializer committed first; its baseline stands
		}
		return fmt.Errorf("runner: create baseline checkpoint of run %s: %w", runID, err)
	}
	return nil
}

// BeginAttempt claims the run's workspace for this exact job fence, moves the
// home if needed (with the exact operation cause), restores the built-in copy
// when it is not the committed base, and marks the home dirty. It NEVER
// bootstraps: a missing committed baseline is ErrCheckpointNotFound.
func (s *WorkspaceSync) BeginAttempt(ctx context.Context, a Assignment, req ExecRequirements, dec Decision, job *StepJob) (WorkspaceAttempt, error) {
	runID, workDir := a.Job.Key.RunID, jobWorkDir(job)
	if runID == uuid.Nil || (req.RunID != uuid.Nil && req.RunID != runID) {
		return WorkspaceAttempt{}, fmt.Errorf("%w: assignment run %s does not match request run %s", ErrNoWorkspace, runID, req.RunID)
	}
	if workDir == "" {
		return WorkspaceAttempt{}, fmt.Errorf("%w: run %s", ErrNoWorkspace, runID)
	}
	if a.Fence != a.Job.Fence() || !a.Job.Key.Valid() {
		return WorkspaceAttempt{}, fmt.Errorf("%w: assignment fence does not match its job", ErrFenced)
	}
	if err := s.d.Ledger.FenceCheck(ctx, a.Fence); err != nil {
		return WorkspaceAttempt{}, err
	}
	home, err := s.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: read workspace home of run %s: %w", runID, err)
	}
	nonPortable := home.NonPortableReason != ""
	if nonPortable && a.Fence.RunnerID != BuiltInRunnerID {
		return WorkspaceAttempt{}, fmt.Errorf("%w: run %s is non-portable (%s) and runs only on %s",
			ErrHomeOwned, runID, home.NonPortableReason, BuiltInRunnerID)
	}
	claim, err := s.d.Leases.ClaimJob(ctx, runKey(runID), JobHolder(a.Job), a.Fence)
	if err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: claim workspace of run %s: %w", runID, err)
	}
	att, err := s.prepareAttempt(ctx, a, req, dec, home, claim, workDir, nonPortable)
	if err != nil {
		if rerr := s.d.Leases.Release(context.WithoutCancel(ctx), claim); rerr != nil {
			slog.Error("runner: releasing a failed attempt's workspace claim", "run", runID, "error", rerr)
		}
		return WorkspaceAttempt{}, err
	}
	return att, nil
}

func (s *WorkspaceSync) prepareAttempt(ctx context.Context, a Assignment, req ExecRequirements, dec Decision, home Home,
	claim engine.ResourceFenceRef, workDir string, nonPortable bool) (WorkspaceAttempt, error) {
	runID, target := a.Job.Key.RunID, a.Fence.RunnerID
	base, ok, err := s.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: read committed checkpoint of run %s: %w", runID, err)
	}
	if !ok && !nonPortable {
		return WorkspaceAttempt{}, fmt.Errorf("%w: run %s has no committed baseline (BeginAttempt never bootstraps)", ErrCheckpointNotFound, runID)
	}
	prevOwner, prevDirty := home.RunnerID, home.Dirty
	moved := false
	switch {
	case prevOwner == target:
	case prevOwner == ServerHome && target == BuiltInRunnerID:
		if home, err = s.d.Homes.AcquireResource(ctx, runID, target, home.Generation); err != nil {
			return WorkspaceAttempt{}, fmt.Errorf("runner: acquire workspace of run %s: %w", runID, err)
		}
	default:
		reason := dec.Reason
		if dec.Tier != "" && !strings.HasPrefix(reason, dec.Tier) {
			reason = dec.Tier + ": " + reason
		}
		bytes := req.WorkspaceBytes
		if bytes < 0 {
			bytes = 0
		}
		jobID, invID := a.Job.ID, a.Job.Key.InvocationID
		cause := HomeMoveCause{TargetJobID: &jobID, InvocationID: &invID, NodeID: a.Job.NodeID, OperationID: a.Job.Key.OperationID,
			FromGeneration: home.Generation, ToGeneration: home.Generation + 1}
		s.d.Status.PublishMove(ctx, a.Job, target, instance.MoveProgress{BytesTotal: bytes})
		if home, err = s.d.Homes.HandOff(ctx, runID, target, reason, bytes, home.Generation, cause); err != nil {
			return WorkspaceAttempt{}, fmt.Errorf("runner: move workspace of run %s to %s: %w", runID, target, err)
		}
		moved = true
		rid := runID
		s.d.Events.Record(ctx, PoolEvent{Kind: EventWorkspaceMoved, RunnerID: target, RunID: &rid, Cause: Cause{Kind: CausePlacement},
			Detail: map[string]any{"from": string(prevOwner), "to": string(target), "reason": reason, "tier": dec.Tier, "bytes": bytes,
				"generation": home.Generation, "jobId": jobID.String(), "invocationId": invID.String(),
				"nodeId": a.Job.NodeID, "operationId": a.Job.Key.OperationID}})
	}
	if err := s.d.Homes.MarkDirty(ctx, runID, true); err != nil {
		return WorkspaceAttempt{}, fmt.Errorf("runner: mark workspace of run %s dirty: %w", runID, err)
	}
	if target == BuiltInRunnerID && !nonPortable && (!isServerLocal(prevOwner) || prevDirty || home.CheckpointVersion != base.Version) {
		if err := s.d.Checkpoints.Restore(ctx, base, workDir); err != nil {
			return WorkspaceAttempt{}, fmt.Errorf("runner: restore committed base of run %s: %w", runID, err)
		}
	}
	return WorkspaceAttempt{RunID: runID, WorkDir: workDir, Runner: target, Base: base, Resource: claim, Moved: moved}, nil
}

// WorkspaceBytes is the move-size input for placement: the server-local size
// for server/built-in homes, the committed manifest size for remote homes,
// WorkspaceBytesUnknown (with a visible diagnostic) on any error.
func (s *WorkspaceSync) WorkspaceBytes(ctx context.Context, runID uuid.UUID) int64 {
	home, err := s.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return s.sizeUnknown(ctx, runID, "home", err)
	}
	if !isServerLocal(home.RunnerID) {
		ref, ok, err := s.d.Checkpoints.Latest(ctx, runID)
		if err == nil && !ok {
			err = ErrCheckpointNotFound
		}
		if err != nil {
			return s.sizeUnknown(ctx, runID, "checkpoint", err)
		}
		m, err := s.d.Checkpoints.Manifest(ctx, ref)
		if err != nil {
			return s.sizeUnknown(ctx, runID, "manifest", err)
		}
		return m.TotalBytes()
	}
	if s.d.Sizes == nil {
		return s.sizeUnknown(ctx, runID, "sizer", errors.New("no workspace sizer configured"))
	}
	b, _, err := s.d.Sizes.InstanceDirStats(runID)
	if err != nil {
		return s.sizeUnknown(ctx, runID, "instance_dir", err)
	}
	return b
}

func (s *WorkspaceSync) sizeUnknown(ctx context.Context, runID uuid.UUID, source string, err error) int64 {

	rid := runID
	s.d.Events.Record(ctx, PoolEvent{Kind: EventWorkspaceSizeUnknown, RunID: &rid, Cause: Cause{Kind: CauseSystem},
		Detail: map[string]any{"source": source}})
	return WorkspaceBytesUnknown
}

// StepWorkspace is the dispatcher's port onto workspace sync.
type StepWorkspace interface {
	WorkspaceBytes(ctx context.Context, runID uuid.UUID) int64
	BeginAttempt(ctx context.Context, a Assignment, req ExecRequirements, dec Decision, job *StepJob) (WorkspaceAttempt, error)
	FinishSuccess(ctx context.Context, a Assignment, att WorkspaceAttempt) (engine.WorkspaceCompletion, error)
	FinishFailure(ctx context.Context, a Assignment, att WorkspaceAttempt) error
}

var _ StepWorkspace = (*WorkspaceSync)(nil)

func (s *WorkspaceSync) storePrepared(p preparedPush) {
	s.mu.Lock()
	defer s.mu.Unlock()
	s.prepared[p.fence.JobID] = p
}

func (s *WorkspaceSync) takePrepared(f Fence) (preparedPush, bool) {
	s.mu.Lock()
	defer s.mu.Unlock()
	p, ok := s.prepared[f.JobID]
	if !ok || p.fence != f {
		return preparedPush{}, false
	}
	delete(s.prepared, f.JobID)
	return p, true
}

// prepareBuiltIn stages the built-in working copy as a PREPARED candidate
// under the exact job and resource fences. On a promisor miss it marks the
// home non-portable and returns the ErrPromisorObjectsMissing error.
func (s *WorkspaceSync) prepareBuiltIn(ctx context.Context, f Fence, runID uuid.UUID, dir string, resource engine.ResourceFenceRef) (CheckpointRef, error) {
	if f.RunnerID != BuiltInRunnerID {
		return CheckpointRef{}, fmt.Errorf("%w: built-in preparation for runner %q", ErrHomeOwned, f.RunnerID)
	}
	if err := resource.Validate(); err != nil {
		return CheckpointRef{}, fmt.Errorf("%w: %v", ErrResourceFenced, err)
	}
	if err := s.d.Ledger.FenceCheck(ctx, f); err != nil {
		return CheckpointRef{}, err
	}
	if err := s.d.Leases.Check(ctx, resource); err != nil {
		return CheckpointRef{}, err
	}
	home, err := s.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return CheckpointRef{}, fmt.Errorf("runner: read workspace home of run %s: %w", runID, err)
	}
	if !isServerLocal(home.RunnerID) {
		return CheckpointRef{}, fmt.Errorf("%w: run %s is homed on %q", ErrHomeOwned, runID, home.RunnerID)
	}
	ref, _, err := s.d.Checkpoints.StageBuiltIn(ctx, runID, dir, f, resource)
	if errors.Is(err, ErrPromisorObjectsMissing) {
		if serr := s.d.Homes.SetNonPortable(ctx, runID, NonPortablePromisorReason); serr != nil {
			return CheckpointRef{}, fmt.Errorf("runner: mark run %s non-portable: %w", runID, serr)
		}
		return CheckpointRef{}, err
	}
	if err != nil {
		return CheckpointRef{}, fmt.Errorf("runner: prepare built-in checkpoint of run %s: %w", runID, err)
	}
	return ref, nil
}

// CommitBuiltIn keeps its contract name but PREPARES only: it looks up this
// operation's exact active claim and stages a candidate under it.
func (s *WorkspaceSync) CommitBuiltIn(ctx context.Context, f Fence, runID uuid.UUID, dir string) (CheckpointRef, error) {
	rec, ok, err := s.d.Leases.Active(ctx, runKey(runID))
	if err != nil {
		return CheckpointRef{}, fmt.Errorf("runner: read workspace claim of run %s: %w", runID, err)
	}
	if !ok || rec.Job == nil || *rec.Job != f {
		return CheckpointRef{}, fmt.Errorf("%w: job %s generation %d does not hold run %s's workspace", ErrResourceFenced, f.JobID, f.Generation, runID)
	}
	return s.prepareBuiltIn(ctx, f, runID, dir, rec.Fence)
}

// FinishSuccess returns the exact prepared candidate of THIS attempt. It never
// publishes, clears dirty, completes the job or consults Latest.
func (s *WorkspaceSync) FinishSuccess(ctx context.Context, a Assignment, att WorkspaceAttempt) (engine.WorkspaceCompletion, error) {
	f := a.Job.Fence()
	if att.RunID == uuid.Nil || att.RunID != a.Job.Key.RunID {
		return engine.WorkspaceCompletion{}, fmt.Errorf("%w: attempt run %s does not match its job", ErrNoWorkspace, att.RunID)
	}
	if att.Runner == BuiltInRunnerID {
		ref, err := s.prepareBuiltIn(ctx, f, att.RunID, att.WorkDir, att.Resource)
		if errors.Is(err, ErrPromisorObjectsMissing) {
			// RR-08: SetNonPortable has run. P3 T16 Cycle 5 replaces this
			// interim receipt with LocalCheckpoints.Take's LocalRef.
			return engine.WorkspaceCompletion{NonPortable: true, Resource: att.Resource}, nil
		}
		if err != nil {
			return engine.WorkspaceCompletion{}, err
		}
		return engine.WorkspaceCompletion{Ref: ref.String(), Resource: att.Resource}, nil
	}
	if err := s.d.Ledger.FenceCheck(ctx, f); err != nil {
		return engine.WorkspaceCompletion{}, err
	}
	if err := s.d.Leases.Check(ctx, att.Resource); err != nil {
		return engine.WorkspaceCompletion{}, err
	}
	// The durable catalog row for THIS job fence + resource is the authority
	// (an adopted job after a server restart commits its pushed candidate);
	// the in-memory staged cache is only used to discard staging on failure.
	ref, ok, err := s.d.Checkpoints.PreparedFor(ctx, att.RunID, f, att.Resource)
	if err != nil {
		return engine.WorkspaceCompletion{}, fmt.Errorf("runner: read prepared push of run %s: %w", att.RunID, err)
	}
	if !ok {
		return engine.WorkspaceCompletion{}, fmt.Errorf("%w: run %s job %s generation %d", ErrPushMissing, att.RunID, f.JobID, f.Generation)
	}
	if ref.RunID != att.RunID || ref.Version <= att.Base.Version {
		return engine.WorkspaceCompletion{}, fmt.Errorf("%w: prepared candidate %s does not follow base %s", ErrPushMissing, ref, att.Base)
	}
	if p, cached := s.takePrepared(f); cached && p.ref != ref {
		return engine.WorkspaceCompletion{}, fmt.Errorf("%w: cached push %s disagrees with the durable candidate %s", ErrCheckpointConflict, p.ref, ref)
	}
	return engine.WorkspaceCompletion{Ref: ref.String(), Resource: att.Resource}, nil
}

// FinishFailure rolls back this attempt after its process stopped: discard
// its unconsumed push, restore the built-in copy to the committed base (a
// remote copy stays dirty and is restored before reuse), then release ONLY
// this attempt's exact claim.
func (s *WorkspaceSync) FinishFailure(ctx context.Context, a Assignment, att WorkspaceAttempt) error {
	f := a.Job.Fence()
	var errs []error
	if p, ok := s.takePrepared(f); ok {
		if err := s.d.Checkpoints.Discard(ctx, p.staged); err != nil {
			errs = append(errs, fmt.Errorf("runner: discard push of run %s: %w", att.RunID, err))
		}
	}
	if att.Runner == BuiltInRunnerID {

			errs = append(errs, fmt.Errorf("runner: release workspace claim of run %s: %w", att.RunID, err))

	}

// restoreCommitted rewrites dir to the run's committed checkpoint and clears

// AcceptPush prepares a remote candidate for the exact job fence and the run's

func (s *WorkspaceSync) acceptPush(ctx context.Context, f Fence, runID uuid.UUID, staged StagedCheckpoint) (CheckpointRef, error) {
	if staged.RunID != runID {
		return CheckpointRef{}, fmt.Errorf("%w: staged checkpoint is for run %s, not %s", ErrCheckpointConflict, staged.RunID, runID)
	}
	if err := staged.Resource.Validate(); err != nil {
		return CheckpointRef{}, fmt.Errorf("%w: %v", ErrResourceFenced, err)
	}
	if err := s.d.Ledger.FenceCheck(ctx, f); err != nil {
		return CheckpointRef{}, err
	}
	rec, ok, err := s.d.Leases.Active(ctx, runKey(runID))
	if err != nil {
		return CheckpointRef{}, fmt.Errorf("runner: read workspace claim of run %s: %w", runID, err)
	}
	if !ok || rec.Fence != staged.Resource || rec.Job == nil || *rec.Job != f {
		return CheckpointRef{}, fmt.Errorf("%w: job %s generation %d is not run %s's active writer", ErrResourceFenced, f.JobID, f.Generation, runID)
	}
	ref, err := s.d.Checkpoints.Publish(ctx, staged, f)
	if err != nil {
		return CheckpointRef{}, fmt.Errorf("runner: prepare pushed checkpoint of run %s: %w", runID, err)
	}
	s.storePrepared(preparedPush{fence: f, ref: ref, base: staged.Base, resource: staged.Resource, staged: staged})
	return ref, nil
}

// PreparePull returns the pull plan of a remote attempt: the committed ref
// read once under the held claim, pinned with the claim into both tokens.
func (s *WorkspaceSync) PreparePull(ctx context.Context, a Assignment, runID uuid.UUID) (PullPlan, error) {
	if s.d.Tokens == nil {
		return PullPlan{}, ErrNoTransferTokens
	}
	f := a.Fence
	if runID != a.Job.Key.RunID {
		return PullPlan{}, fmt.Errorf("%w: assignment run %s is not %s", ErrNoWorkspace, a.Job.Key.RunID, runID)
	}
	if err := s.d.Ledger.FenceCheck(ctx, f); err != nil {
		return PullPlan{}, err
	}
	rec, ok, err := s.d.Leases.Active(ctx, runKey(runID))
	if err != nil {
		return PullPlan{}, fmt.Errorf("runner: read workspace claim of run %s: %w", runID, err)
	}
	if !ok || rec.Job == nil || *rec.Job != f {
		return PullPlan{}, fmt.Errorf("%w: job %s generation %d does not hold run %s's workspace", ErrResourceFenced, f.JobID, f.Generation, runID)
	}
	if err := s.d.Leases.Check(ctx, rec.Fence); err != nil {
		return PullPlan{}, err
	}
	home, err := s.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return PullPlan{}, fmt.Errorf("runner: read workspace home of run %s: %w", runID, err)
	}
	if home.RunnerID != f.RunnerID {
		return PullPlan{}, fmt.Errorf("%w: run %s is homed on %q, not %q", ErrHomeOwned, runID, home.RunnerID, f.RunnerID)
	}
	ref, ok, err := s.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return PullPlan{}, fmt.Errorf("runner: read committed checkpoint of run %s: %w", runID, err)
	}
	if !ok {
		return PullPlan{}, fmt.Errorf("%w: run %s", ErrCheckpointNotFound, runID)
	}
	scope := TransferScope{Fence: f, RunID: runID, BaseRef: ref.String(), Resource: rec.Fence}
	pull, push := scope, scope
	pull.Direction, push.Direction = TransferPull, TransferPush
	pullTok, err := s.d.Tokens.Issue(ctx, pull, s.d.TokenTTL)
	if err != nil {
		return PullPlan{}, fmt.Errorf("runner: issue pull token for run %s: %w", runID, err)
	}
	pushTok, err := s.d.Tokens.Issue(ctx, push, s.d.TokenTTL)
	if err != nil {
		return PullPlan{}, fmt.Errorf("runner: issue push token for run %s: %w", runID, err)
	}
	return PullPlan{RunID: runID, Ref: ref, Home: home, Resource: rec.Fence, PullToken: pullTok, PushToken: pushTok}, nil
}

	bg := context.WithoutCancel(ctx)
outer:
	for {
		a, dec, err := s.acquire(ctx, j, req)
		if err != nil {
			return Assignment{}, StepOutput{}, nil, err
		}
		r, ok := s.d.Runners.For(a.Job.RunnerID)
		if !ok {
			s.fact(sink, a, string(OutcomeOther))
			s.release(bg, a, OutcomeOther)
			return Assignment{}, StepOutput{}, nil, fmt.Errorf("runner: no step runner for %q", a.Job.RunnerID)
		}
		if err := s.d.Ledger.MarkRunning(ctx, a.Fence); err != nil {
			s.release(bg, a, OutcomeOther)
			return Assignment{}, StepOutput{}, nil, fmt.Errorf("runner: mark running %s: %w", a.Job.ID, err)
		}
		s.d.Status.Publish(ctx, a.Job, instance.ExecRunning)
		att, err := s.beginWorkspace(ctx, a, req, dec, &job)
		if err != nil {
			s.fact(sink, a, string(OutcomeOther))
			s.release(bg, a, OutcomeOther)
			return Assignment{}, StepOutput{}, nil, err
		}
		for try := 1; ; try++ {
			*tries = try
			out, runErr := r.Run(ctx, a, job)
			if runErr == nil {
				if !validOutput(job.Op, out) {
					s.fact(sink, a, string(OutcomeOther))
					s.failWorkspace(bg, a, att)
					s.release(bg, a, OutcomeOther)
					return Assignment{}, StepOutput{}, nil, errors.New("runner: malformed step output")
				}
				return a, out, att, nil
			}
			o := ClassifyError(runErr)
			o.Model = req.Model
			switch o.Class {
			case OutcomeTransient:

				if try >= s.d.TransientMaxAttempts {

					s.release(bg, a, OutcomeTransient)
					return Assignment{}, StepOutput{}, nil, runErr
				}

					return Assignment{}, StepOutput{}, nil, err

// SetWorkspace installs the workspace service on a dispatcher the composition
// root built before the workspace stack existed (P3 T13 calls it before the
// first Dispatch). It ends legacy built-in-only handling. nil panics: it would
// silently disable the protocol.
// G1 (resolved 2026-11-23): P3 T5's engine calls this on executor-validation
// or commit failure; P3 T13 wires it with eng.SetStepCompletionReleaser.
var _ engine.StepCompletionReleaser = (*StepDispatcher)(nil)

func (s *StepDispatcher) SetWorkspace(w StepWorkspace) {
	if w == nil {
		panic("runner: SetWorkspace requires a StepWorkspace")
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	s.d.Workspace = w
	s.d.LegacyBuiltInWorkspace = false
}

func (s *StepDispatcher) workspace() (StepWorkspace, bool) {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.d.Workspace, s.d.LegacyBuiltInWorkspace
}

// normalizeWorkspace runs before EnsureIntent: it fills the size input for
// placement, or explicitly downgrades in legacy mode, or fails closed.
func (s *StepDispatcher) normalizeWorkspace(ctx context.Context, req ExecRequirements, job StepJob) (ExecRequirements, error) {
	if req.Affinity != AffinityWorkspace {
		return req, nil
	}
	if job.Op == OpChat || job.Op == OpStream {
		return req, fmt.Errorf("%w: %s operations never write a workspace in Phase 3", ErrNoWorkspace, job.Op)
	}
	w, legacy := s.workspace()
	if w == nil {
		if legacy {
			req.Affinity = AffinityBuiltIn
			return req, nil
		}
		return req, fmt.Errorf("%w: no workspace service is installed", ErrNoWorkspace)
	}
	if jobWorkDir(&job) == "" {
		return req, fmt.Errorf("%w: the operation has no working directory", ErrNoWorkspace)
	}
	req.WorkspaceBytes = w.WorkspaceBytes(ctx, req.RunID)
	return req, nil
}

func (s *StepDispatcher) beginWorkspace(ctx context.Context, a Assignment, req ExecRequirements, dec Decision, job *StepJob) (*WorkspaceAttempt, error) {
	if req.Affinity != AffinityWorkspace {
		return nil, nil
	}
	w, _ := s.workspace()
	att, err := w.BeginAttempt(ctx, a, req, dec, job)
	if err != nil {
		return nil, fmt.Errorf("runner: prepare workspace for %s: %w", a.Job.ID, err)
	}
	if att.Moved && att.Runner == BuiltInRunnerID {
		s.d.Status.Publish(ctx, a.Job, instance.ExecRunning) // the built-in move (restore) is done
	}
	return &att, nil
}

// failWorkspace rolls back an attempt whose process has stopped (the runner
// call returned). Errors are logged: the job is failed/requeued regardless and
// a dirty home is restored by the next attempt.
func (s *StepDispatcher) failWorkspace(ctx context.Context, a Assignment, att *WorkspaceAttempt) {
	if att == nil {
		return
	}
	w, _ := s.workspace()
	if err := w.FinishFailure(ctx, a, *att); err != nil {
		slog.Error("runner: rolling back a workspace attempt", "job", a.Job.ID, "run", att.RunID, "error", err)
	}
}

// retryWorkspace gives a transient retry a fresh attempt from the committed base.
func (s *StepDispatcher) retryWorkspace(ctx context.Context, a Assignment, req ExecRequirements, dec Decision, job *StepJob, att *WorkspaceAttempt) (*WorkspaceAttempt, error) {
	if att == nil {
		return nil, nil
	}
	s.failWorkspace(context.WithoutCancel(ctx), a, att)
	return s.beginWorkspace(ctx, a, req, dec, job)
}

// completeStep turns a successful runner call into a receipt. Under a node
// completion sink the ledger job stays running until P3 T5's transaction and
// the dispatcher (never the routed selectors) records the receipt once. With
// no sink, only the synthetic quota probe (its own P3 T5 owner) and
// earlier-phase dispatchers without a workspace service complete immediately;
// in production Phase 3 mode (Workspace installed) every other operation
// fails closed.
func (s *StepDispatcher) completeStep(ctx context.Context, a Assignment, att *WorkspaceAttempt, out *StepOutput, sink *engine.PlacementSink) error {
	bg := context.WithoutCancel(ctx)
	fail := func(err error) error {
		s.fact(sink, a, string(OutcomeOther))
		s.failWorkspace(bg, a, att)
		s.release(bg, a, OutcomeOther)
		return err
	}
	csink, deferred := engine.StepCompletionSinkFromContext(ctx)
	if !deferred {
		id, _ := engine.StepIdentityFromContext(ctx)
		w, _ := s.workspace()
		if att != nil || (w != nil && id.Kind != engine.OperationProbe) {
			return fail(ErrNoCompletionSink)
		}
		return s.complete(ctx, a, sink)
	}
	rec := engine.StepCompletion{JobFence: engine.JobFenceRef{JobID: a.Fence.JobID, RunnerID: string(a.Fence.RunnerID), Generation: a.Fence.Generation}}
	if att != nil {
		w, _ := s.workspace()
		wc, err := w.FinishSuccess(bg, a, *att)
		if err != nil {
			return fail(fmt.Errorf("runner: prepare the workspace result of %s: %w", a.Job.ID, err))
		}
		rec.Workspace = &wc
	}
	if err := csink.Record(rec); err != nil {
		return fail(fmt.Errorf("runner: record the receipt of %s: %w", a.Job.ID, err))
	}
	out.Completion = &rec
	s.retain(a, att)
	s.fact(sink, a, "completed")
	return nil
}

// retain keeps the uncommitted operation for ReleaseCompletions. An earlier
// invocation of the same run has been committed or released by now, so its
// entries are dropped.
func (s *StepDispatcher) retain(a Assignment, att *WorkspaceAttempt) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if s.pending == nil {
		s.pending = map[uuid.UUID]pendingStep{}
	}
	for id, p := range s.pending {
		if p.a.Job.Key.RunID == a.Job.Key.RunID && p.a.Job.Key.InvocationID != a.Job.Key.InvocationID {
			delete(s.pending, id)
		}
	}
	s.pending[a.Fence.JobID] = pendingStep{a: a, att: att}
}

func (s *StepDispatcher) takePending(f engine.JobFenceRef) (pendingStep, bool) {
	s.mu.Lock()
	defer s.mu.Unlock()
	p, ok := s.pending[f.JobID]
	if !ok || string(p.a.Fence.RunnerID) != f.RunnerID || p.a.Fence.Generation != f.Generation {
		return pendingStep{}, false
	}
	delete(s.pending, f.JobID)
	return p, true
}

// ReleaseCompletions rolls back operations whose receipts were NOT committed
// (executor validation failed or the step transaction failed): restore/discard
// each workspace attempt, release its exact claim and fail its job. After a
// durable commit it is harmless: the restore re-materializes the committed
// ref and the completed job is not failed.
func (s *StepDispatcher) ReleaseCompletions(ctx context.Context, completions []engine.StepCompletion, cause error) error {
	bg := context.WithoutCancel(ctx)
	var errs []error
	for _, c := range completions {
		p, ok := s.takePending(c.JobFence)
		if !ok {
			errs = append(errs, fmt.Errorf("%w: job %s generation %d", ErrUnknownReceipt, c.JobFence.JobID, c.JobFence.Generation))
			continue
		}
		slog.Info("runner: releasing an uncommitted operation", "job", p.a.Job.ID, "node", p.a.Job.NodeID, "cause", cause)
		s.failWorkspace(bg, p.a, p.att)
		if err := s.d.Ledger.Fail(bg, p.a.Fence, OutcomeOther); err != nil && !errors.Is(err, ErrFenced) {
			errs = append(errs, fmt.Errorf("runner: fail uncommitted job %s: %w", p.a.Job.ID, err))
		}
	}
	s.wake()
	return errors.Join(errs...)
}
