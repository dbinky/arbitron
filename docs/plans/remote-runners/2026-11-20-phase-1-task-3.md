# Remote Runners — Phase 1 Task 3: Pool vocabulary, `GroupFor` and outcomes

**Goal:** Create the pure `domain/runner` vocabulary: runners, capacity sources and their health, execution requirements, the model-group derivation `GroupFor`, and the classified-outcome types with a `ClassifyError` that never reads provider prose.

**Architecture:** A new domain package `domain/runner` with three files and no I/O: `model.go` (runner/source/health/requirements types plus state constants), `modelgroup.go` (`ModelGroup`, `GroupFor` implementing design §3.6's ordered rules) and `outcome.go` (`OutcomeClass`, `SourceOutcome`, `OutcomeError`, `WithOutcome`, `ClassifyError`). It imports only `domain/provider`, `domain/modelidentity`, `domain/workflow` (backend constants) and the standard library; every later runner task builds on it.

**Tech Stack:** Go 1.25.5, `github.com/google/uuid`, testify (table tests).

**Spec / Design:** spec "Execution and placement" (model groups, family never crossed, server connections built-in only), "Capacity exhaustion and source health" (classified outcomes, transient ≠ exhaustion); design phase 1 §3.1 (pool model, source identity), §3.6 (group derivation rules), §3.10 (classification fails closed, never reads prose), §7 (classification fails closed to *other*), §8 Edge "LunaRoute busy is never treated as exhaustion", "ASCII `'` versus U+2019 makes no difference", cross-phase "LunaRoute-on-codex is never classified as subscription". Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §6 (pool vocabulary, GroupFor, Outcomes).

This plan types every one explicitly as `OutcomeClass`, which is assignment-compatible with every use in the contracts and stops a stray `string` from being passed where a class is meant.

`GroupFor` decision table (design §3.6, contracts §6 rules 1–5, in this order):

| # | Condition | Group | Family rule |
|---|---|---|---|
| 0 | `op == OpProcess` | `{Kind: CredNone}` (`String() == "none"`) | none |
| 1 | `provider.IsLunaRoute(b.Provider)` (any backend — codex/pi LunaRoute is **never** a subscription) | `{CredLunaRoute, b.ConnectionRef, family}` | unresolved ⇒ `ErrUnresolvedFamily` |
| 2 | other non-empty `b.ConnectionRef` | `{CredServerConnection, b.ConnectionRef, family}` | unresolved allowed (built-in only) |
| 3 | no connection; backend `claude-code`, or op `chat`/`stream` with backend `""` | `{CredAnthropicSubscription, "", family}` | unresolved ⇒ `ErrUnresolvedFamily` |
| 4 | no connection; backend `codex` | `{CredOpenAISubscription, "", family}` | unresolved ⇒ `ErrUnresolvedFamily` |
| 5 | no connection; backend `pi`/`opencode` | `{CredLocalHarness, backend, family}` | unresolved allowed (built-in only; RR-02 decision in contracts) |
| – | no connection; op `agent` with backend `""`, or any other backend | — | `ErrUnresolvedBackend` (fail closed: the agent executor / interactive selector floors `""` to the deployment default before routing — P1 T10) |

// Package runner is the Remote Runners pool domain: runners, capacity sources,
// placement, the job ledger ports and the step dispatcher. It never imports
// adapter packages.
package runner

import (
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/modelidentity"
	"github.com/arbitron/arbitron/domain/provider"
	"github.com/google/uuid"
)

// RunnerID names a runner. The server's own runner is BuiltInRunnerID.
type RunnerID string

// BuiltInRunnerID is the runner inside the Arbitron server process.
const BuiltInRunnerID RunnerID = "builtin"

// Liveness is the connection state of a runner.
type Liveness string

const (
	LivenessOnline  Liveness = "online"
	LivenessSuspect Liveness = "suspect"
	LivenessLost    Liveness = "lost"
	LivenessOffline Liveness = "offline"
)

// CompatState is the result of the version/protocol compatibility check.
type CompatState string

const (
	CompatCompatible   CompatState = "compatible"
	CompatIncompatible CompatState = "incompatible"
	CompatChatOnly     CompatState = "chat_only" // accepts only hermetic (AffinityNone) work
)

// Compatibility is a runner's compatibility state and its operator-readable reason.
type Compatibility struct {
	State  CompatState
	Reason string
}

// Runner is one machine in the pool.
type Runner struct {
	ID              RunnerID
	Name            string
	BuiltIn         bool
	StepLimit       int
	Labels          map[string]string
	Cordoned        bool
	Draining        bool
	Compat          Compatibility
	Liveness        Liveness
	LastContact     *time.Time
	OS              string
	RunnerVersion   string
	HarnessVersions map[string]string
	WorkspaceRoot   string
	CreatedAt       time.Time
}

// CredentialKind is how a capacity source authenticates to its provider.
type CredentialKind string

const (
	CredAnthropicSubscription CredentialKind = "anthropic_subscription"
	CredOpenAISubscription    CredentialKind = "openai_subscription"
	CredLunaRoute             CredentialKind = "lunaroute"
	CredServerConnection      CredentialKind = "server_connection" // built-in only
	CredLocalHarness          CredentialKind = "local_harness"     // pi/opencode no-connection paths; built-in only (RR-02 decision)
	CredNone                  CredentialKind = "none"              // process steps: slot only
)

// SourceID identifies a capacity source: "<runner>/<kind>/<ref>".
type SourceID string

// MakeSourceID builds the source identity (runner, credential kind, credential
// reference). An empty (or blank) reference renders as "-". Two connections
// therefore never share an ID — and so never share health.
func MakeSourceID(r RunnerID, k CredentialKind, ref string) SourceID {
	ref = strings.TrimSpace(ref)
	if ref == "" {
		ref = "-"
	}
	return SourceID(string(r) + "/" + string(k) + "/" + ref)
}

// AuthState is a source's authentication observation.
type AuthState string

const (
	AuthUnknown   AuthState = "unknown"
	AuthOK        AuthState = "ok"
	AuthLoggedOut AuthState = "logged_out"
)

// CapacityState is a source's capacity observation, separate from auth.
type CapacityState string

const (
	CapacityAvailable CapacityState = "available"
	CapacityExhausted CapacityState = "exhausted"
	CapacityProbation CapacityState = "probation"
)

// SourceHealth is the health of one capacity source. Auth and capacity are
// separate observations: logged out blocks eligibility without erasing a known
// exhaustion/reset.
type SourceHealth struct {
	ConfirmationModel string // exact exhausted model used by confirmation probe
	Auth           AuthState
	Capacity       CapacityState
	ResetAt        *time.Time // nil = unknown reset (only meaningful when exhausted)
	Headroom       *float64   // 0..1 remaining; nil = unknown (NEVER treated as 0 or 1)
	Windows        []LimitWindow
	Congested      bool
	CongestedUntil *time.Time // transient pressure, never exhaustion
	LastProbeAt    *time.Time
	LastOutcome    OutcomeClass
	Detail         string // class/reset only, never provider prose
}

// Source is a capacity source on a runner.
// Phase 2 populates these from actual local capability/version evidence.
type ExecutionCapability struct {
	Op OpType
	Backend, Provider, EndpointFingerprint string
	Families []modelidentity.Family
	Models []string
	ContextWindows []provider.ContextWindow
	Efforts []provider.Effort
	Tools []string
	ExecutedModel bool
}

type Source struct {
	ID            SourceID
	RunnerID      RunnerID
	Kind          CredentialKind
	CredentialRef string
	UnavailableReason string // missing/unsupported harness; independent of mutable health
	Families      []modelidentity.Family // advertised served families; empty = none proven
	Backends      []string               // e.g. "claude-code","codex"; chat paths use ""
	Models        []string               // optional exact-model allowlist; empty = any model of the family
	Capabilities []ExecutionCapability // remote empty => ineligible; P2 produces facts
	Health        SourceHealth
}

// OpType is the kind of dispatched operation.
type OpType string

const (
	OpChat    OpType = "chat"
	OpStream  OpType = "stream"
	OpAgent   OpType = "agent"
	OpProcess OpType = "process"
)

// Affinity says where an operation's state lives and therefore where it may run.
type Affinity string

const (
	AffinityNone      Affinity = "none"      // hermetic chat (Phase 2+)
	AffinityBuiltIn   Affinity = "builtin"   // Phase 1 everything; server-local staging
	AffinityWorkspace Affinity = "workspace" // Phase 3
	AffinitySession   Affinity = "session"   // Phase 4
)

// ExecRequirements is the complete resolved request a placement must honour.
// Group is only a capacity grouping key; eligibility also enforces Model,
// Backend and Tools exactly.
type ExecRequirements struct {
	Provider string
	EndpointFingerprint string
	ContextWindow provider.ContextWindow
	Effort provider.Effort
	Group                ModelGroup
	Model                string
	Backend              string
	Op                   OpType
	Affinity             Affinity
	RunID                uuid.UUID
	WorkspaceBytes       int64
	PinnedRunner         RunnerID // Phase 4 session pin; "" = none
	RequireExecutedModel bool
	Tools                []string

	RequiredSource SourceID // synthetic OperationProbe only; exact credential source
}

package runner

import (
	"errors"
	"fmt"
	"strings"

	"github.com/arbitron/arbitron/domain/modelidentity"
	"github.com/arbitron/arbitron/domain/provider"
	"github.com/arbitron/arbitron/domain/workflow"
)

// ModelGroup is a capacity aggregation key: credential kind (+ connection for
// connection-backed kinds) and model family. It is never the complete
// eligibility key — ExecRequirements carries the exact request.
type ModelGroup struct {
	Kind          CredentialKind
	ConnectionRef string
	Family        modelidentity.Family
}

// String renders "kind:family", "kind:ref:family", or "none" for slot-only work.
func (g ModelGroup) String() string {
	if g.Kind == CredNone {
		return "none"
	}
	if g.ConnectionRef != "" {
		return string(g.Kind) + ":" + g.ConnectionRef + ":" + string(g.Family)
	}
	return string(g.Kind) + ":" + string(g.Family)
}

// ErrUnresolvedFamily refuses placement of a model whose vendor cannot be proved.
var ErrUnresolvedFamily = errors.New("runner: model family unresolved; refusing remote placement")

// ErrUnresolvedBackend refuses an agent/no-connection binding whose effective
// backend was not floored (or is unknown). Routing never guesses a subscription.
var ErrUnresolvedBackend = errors.New("runner: agent backend unresolved; the executor must floor it before routing")

// GroupFor derives the model group from a resolved binding (design P1 §3.6).
// The order matters: LunaRoute is recognised by canonical provider BEFORE any
// backend rule, so LunaRoute on codex/pi is never mistaken for a subscription.
func GroupFor(b provider.ResolvedBinding, op OpType) (ModelGroup, error) {
	if op == OpProcess {
		return ModelGroup{Kind: CredNone}, nil
	}
	family := modelidentity.ClassifyFamily(b.Provider, b.Model)
	ref := strings.TrimSpace(b.ConnectionRef)
	backend := strings.TrimSpace(b.Backend)

	var g ModelGroup
	switch {
	case provider.IsLunaRoute(b.Provider):
		g = ModelGroup{Kind: CredLunaRoute, ConnectionRef: ref, Family: family}
	case ref != "":
		// Built-in only; an opaque deployment name keeps FamilyUnresolved and
		// matches only its own connection source.
		return ModelGroup{Kind: CredServerConnection, ConnectionRef: ref, Family: family}, nil
	case backend == workflow.BackendClaudeCode,
		backend == workflow.BackendUnset && (op == OpChat || op == OpStream):
		g = ModelGroup{Kind: CredAnthropicSubscription, Family: family}
	case backend == workflow.BackendCodex:
		g = ModelGroup{Kind: CredOpenAISubscription, Family: family}
	case backend == workflow.BackendPi, backend == workflow.BackendOpencode:
		return ModelGroup{Kind: CredLocalHarness, ConnectionRef: backend, Family: family}, nil
	default:
		return ModelGroup{}, fmt.Errorf("%w: op %s backend %q", ErrUnresolvedBackend, op, backend)
	}
	if family == modelidentity.FamilyUnresolved {
		return ModelGroup{}, fmt.Errorf("%w: model %q on %s", ErrUnresolvedFamily, b.Model, g.Kind)
	}
	return g, nil
}

package runner

import (
	"errors"
	"net/http"
	"strconv"
	"time"

	"github.com/arbitron/arbitron/domain/provider"
)

// OutcomeClass is the classified result of a dispatched operation against a
// capacity source.
type OutcomeClass string

const (
	OutcomeNone       OutcomeClass = ""
	OutcomeExhausted  OutcomeClass = "exhausted"
	OutcomeLoggedOut  OutcomeClass = "logged_out"
	OutcomeTransient  OutcomeClass = "transient"
	OutcomeRunnerLost OutcomeClass = "runner_lost"
	OutcomeOther      OutcomeClass = "other"
)

// LimitWindow is one provider rate-limit window (keyed by limit id + duration;
// same-duration per-model buckets are separate windows).
type LimitWindow struct {
	LimitID      string
	ModelScope   string
	DurationMins int
	UsedPercent  *float64
	ResetAt      *time.Time
}

// SourceOutcome is a structured classification attached by an adapter.
type SourceOutcome struct {
	Model string // exact requested model stamped by dispatcher, never inferred from error prose
	Class        OutcomeClass
	ResetAt      *time.Time
	RetryAfter   time.Duration
	Windows      []LimitWindow
	HeadroomHint *float64
}

// OutcomeError carries a SourceOutcome alongside the adapter error. It adds no
// text: Error() is the wrapped error's text, so sanitizing/redaction above it
// is unchanged.
type OutcomeError struct {
	Outcome SourceOutcome
	Err     error
}

func (e *OutcomeError) Error() string {
	if e.Err == nil {
		return "runner: " + string(e.Outcome.Class) + " outcome"
	}
	return e.Err.Error()
}

func (e *OutcomeError) Unwrap() error { return e.Err }

// WithOutcome attaches o to err. A nil err stays nil.
func WithOutcome(err error, o SourceOutcome) error {
	if err == nil {
		return nil
	}
	return &OutcomeError{Outcome: o, Err: err}
}

// ErrRunnerLost marks an operation whose runner disappeared mid-flight.
var ErrRunnerLost = errors.New("runner: runner lost")

// ClassifyError maps an error to an outcome using STRUCTURE only (typed
// errors and sentinels), never message text: unknown shapes fail closed to
// OutcomeOther, which can never park a source.
func ClassifyError(err error) SourceOutcome {
	return classifyErrorAt(err, time.Now())
}

func classifyErrorAt(err error, now time.Time) SourceOutcome {
	if err == nil {
		return SourceOutcome{Class: OutcomeNone}
	}
	var oe *OutcomeError
	if errors.As(err, &oe) && oe.Outcome.Class != OutcomeNone {
		return oe.Outcome
	}
	if errors.Is(err, provider.ErrLunaRouteBusy) {
		o := SourceOutcome{Class: OutcomeTransient}
		var lf *provider.LunaRouteFailure
		if errors.As(err, &lf) {
			o.RetryAfter = parseRetryAfter(lf.RetryAfter, now)
		}
		return o
	}
	if errors.Is(err, ErrRunnerLost) {
		return SourceOutcome{Class: OutcomeRunnerLost}
	}
	return SourceOutcome{Class: OutcomeOther}
}

// parseRetryAfter reads the provider's normalized Retry-After: delta-seconds
// digits or an HTTP date. Anything else, or a past date, yields 0.
func parseRetryAfter(v string, now time.Time) time.Duration {
	if v == "" {
		return 0
	}
	if secs, err := strconv.ParseUint(v, 10, 32); err == nil {
		return time.Duration(secs) * time.Second
	}
	if at, err := http.ParseTime(v); err == nil {
		if d := at.Sub(now); d > 0 {
			return d
		}
	}
	return 0
}
