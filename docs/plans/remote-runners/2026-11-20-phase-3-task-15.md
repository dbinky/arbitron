# Remote Runners — Phase 3 Task 15: Advertised native agent sources and local execution rules

**Goal:** Real installed Claude/Codex accounts can receive remote workspace work, and advertised model/axis/tool support exactly matches what the runner actually launches. Codex agent code cannot remain unreachable behind a Phase-2 chat-only inventory.

**Architecture:** This is a closure task. It adds no second executor, inventory or capability matcher. It extends the producers that already exist or are owned by earlier tasks:
- `adapter/codex` gains one read-only helper, `LocalAccountModels`, that shares the bounded `models_cache.json` reader with the existing `accountListsModel` and reads the same codex home (`codexEnv()`) that execution uses.
- The native agent adapters (`adapter/claudecli`, `adapter/codex`) return their own executed-model evidence for pinned subscription runs, so the runner can gate a push on it.
- The hub admits `agent` capability evidence for the two native remote backends (`claude-code`, `codex`) and nothing else.
- The P3 T9 transfer client clones the runner's `ExtraHeaders` and preserves every value.
- The P2 T9 source inventory (`adapter/runneragent/sources`) gains `NativeExecutionInput`. `Discover` builds one `openai_subscription` source from Codex version evidence and the local account model list, adds `claude-code`/`agent` support to the existing Claude source, and re-runs on the probe cadence so a harness install/upgrade or a Codex cache refresh changes eligibility without a server restart.
- The P3 T9 `WorkspaceJobs` rechecks the advertised predicate at accept time against that same inventory and the same loaded rules, rebuilds the binding from the source's verified local provider, and refuses to push or commit when strict executed-model evidence is missing or wrong.
- `cmd/arbitron-runner/build.go:buildAgent` (P2 T9) loads rules once and passes the same rules, binaries and enabled flags to `WorkspaceJobs` and `Discover`.
- The server side consumes P3 T8's `Factory.EffectiveAgentTools` through `runner.AgentToolPolicy`, which P3 T13 wires. This task proves the effective scope reaches placement and the native argv.

**Tech Stack:** Go 1.25.5, testify, stdlib `os/exec`/`net/http/httptest`/`reflect`, `nhooyr.io/websocket` (unchanged), POSIX-shell fake `codex`/`claude` binaries, the real `arbitron-runner` binary built by the root test, file-backed SQLite through the P3 T13 phase-root harness.

**Spec / Design:** spec "Execution and placement" (runners use their own local accounts; the exact model and the existing controls apply). **Decisions taken from the current prose (not new product decisions):**
1. Codex `chat`/`stream`-chat is never advertised and never routed; no model-family substitution.
2. Source identity stays one per local credential kind: the Claude source carries chat AND agent capabilities; the Codex source carries agent (and, when linked, confirm; when P4 enables it, stream) capabilities.
3. A missing/malformed/empty Codex model cache is a visible `UnavailableReason`, never an empty (unrestricted) allowlist. More than 32 models are split across several capabilities (the per-capability bound is `maxCapabilities = 32`); they are never truncated.
4. Axes are advertised per model group from the loaded rules' backend list and its `ModelOverrides`. The accept check also calls `rules.Validate` and refuses a request that `Validate` would floor to a different value.
5. Tools (G2, decided by the user 2026-11-23): every agent capability declares `ToolPolicy`. Claude Code advertises `allowlist`: a request must carry a non-empty effective scope (the local adapter would otherwise fall back to its own default and widen it), and every requested tool must appear in the capability's non-empty `Tools`; an empty advertised list never means "all tools". Codex advertises `unrestricted` (fixed bypass posture, no `Tools`): it accepts only the empty effective scope and never a restrictive one, so a restrictive scope can never run where the real CLI argv could not carry it. P3 T8 also rejects restricted Codex requests before dispatch. Placement, atomic `Reserve` and the runner's accept check share `runner.ToolScopeSatisfied` (Cycle 3b).
6. Strict model proof: when `RequireExecutedModel` is set, at least one `reported_execution` record must name the requested model (`[1m]` suffix ignored, as `claudecli.executedModelMatches` does). `AgentResult.Model` (a label) is never proof. The check runs before `Syncer.Push`.

// readAccountModels returns every `.models[].slug` of the account's
// models_cache.json in the codex home env selects. A missing, unreadable,
// oversized or malformed list refuses with ErrModelEvidence. Errors never echo
// the file path or contents.
func readAccountModels(env []string) ([]string, error) {
	home, err := resolveCodexHome(env)
	if err != nil {
		return nil, err
	}
	f, err := os.Open(filepath.Join(home, modelsCacheFile))
	if err != nil {
		return nil, fmt.Errorf("%w: account model list unavailable", ErrModelEvidence)
	}
	defer f.Close()
	data, err := io.ReadAll(io.LimitReader(f, maxModelsCacheBytes+1))
	if err != nil || len(data) > maxModelsCacheBytes {
		return nil, fmt.Errorf("%w: account model list unreadable", ErrModelEvidence)
	}
	var list struct {
		Models []struct {
			Slug string `json:"slug"`
		} `json:"models"`
	}
	dec := json.NewDecoder(bytes.NewReader(data))
	if err := dec.Decode(&list); err != nil || dec.More() {
		return nil, fmt.Errorf("%w: account model list malformed", ErrModelEvidence)
	}
	if _, err := dec.Token(); err != io.EOF {
		return nil, fmt.Errorf("%w: account model list malformed", ErrModelEvidence)
	}
	out := make([]string, 0, len(list.Models))
	for _, m := range list.Models {
		out = append(out, m.Slug)
	}
	return out, nil
}

// accountListsModel admits a usability probe of model only when the account's
// models_cache.json (in the same codex home the launch env selects) lists it as
// an exact `.models[].slug` (D4). An unprovable listing is never a listing.
func accountListsModel(env []string, model string) error {
	if model == "" {
		return fmt.Errorf("%w: empty model", ErrModelEvidence)
	}
	slugs, err := readAccountModels(env)
	if err != nil {
		return err
	}
	for _, s := range slugs {
		if s == model {
			return nil
		}
	}
	return fmt.Errorf("%w: model not in the account model list", ErrModelEvidence)
}

// LocalAccountModels is the runner inventory's exact Codex model allowlist: the
// non-blank, unpadded slugs of the account model list in the codex home a
// launched codex uses (codexEnv preserves CODEX_HOME exactly as execution does),
// de-duplicated in file order. An unprovable or empty list is an error, never
// an empty slice: callers must not treat it as "any model".
func LocalAccountModels() ([]string, error) {
	slugs, err := readAccountModels(codexEnv())
	if err != nil {
		return nil, err
	}
	seen := make(map[string]bool, len(slugs))
	var out []string
	for _, s := range slugs {
		if s == "" || strings.TrimSpace(s) != s || seen[s] {
			continue
		}
		seen[s] = true
		out = append(out, s)
	}
	if len(out) == 0 {
		return nil, fmt.Errorf("%w: account model list is empty", ErrModelEvidence)
	}
	return out, nil
}

**Decided semantics (user, 2026-11-23; consistent with decision 5):**
- `allowlist` (claude-code): the harness launches with exactly the requested tools. The effective scope must be non-empty: an empty scope is unresolved, never "all tools". Every requested tool must be in `Tools`, and `Tools` must be non-empty.
- `unrestricted` (codex only, the one backend that cannot restrict): the capability advertises no `Tools` and accepts only the empty effective scope. A restrictive (non-empty) scope is refused, because the real CLI argv could not carry it.
- `""` (chat/stream/confirm evidence): keeps P2 T6 Cycle 2c's subset rule unchanged, including "empty request matches". Landed and planned chat fixtures (`hubtest.Capability`) stay valid.
- Admission: an `agent` capability must carry `allowlist` (backend ≠ codex, non-empty `Tools`) or `unrestricted` (backend codex, empty `Tools`). Any non-agent capability must leave `ToolPolicy` empty (P4 T13 may extend this for interactive `stream`). An unknown value is malformed.

func NewClient(serverURL, runnerKey string, hc *http.Client, extraHeaders http.Header) *Client {

// NativeExecutionInput is what the runner's native agent sources are built
// from. Codex uses the same config, command runner and environment as
// execution and auth; Rules are the same loaded rules WorkspaceJobs enforces.
type NativeExecutionInput struct {
	Codex            codex.Config
	Rules            provider.CapabilityRules
	WorkspaceEnabled bool
	SessionsEnabled  bool
	CodexInteractive bool
}

const (
	ReasonCodexModelInventory    = "codex account model list unavailable; run codex once so it refreshes models_cache.json"
	ReasonCodexWorkspaceDisabled = "codex agent jobs need workspace execution on this runner"
	ReasonNativeRulesMissing     = "capability rules for this backend are not loaded"

	MaxCapabilityModels = 32

var openAIFamily = []modelidentity.Family{"openai"}

// discoverCodex builds the single openai_subscription source. A missing
// binary advertises nothing; an installed one is always visible, with an
// UnavailableReason until version, rules, workspace execution and the local
// account model list all prove it.
func discoverCodex(ctx context.Context, in DiscoverInput) (Spec, string, bool) {
	n := in.Native
	version, compatible, reason, err := codex.VersionEvidence(ctx, n.Codex)
	if errors.Is(err, codex.ErrCodexMissing) {
		return Spec{}, "", false
	}
	src := runneragent.Source{Kind: runner.CredOpenAISubscription, Families: append([]modelidentity.Family(nil), openAIFamily...), Backends: []string{workflow.BackendCodex}}
	switch {
	case err != nil:
		src.UnavailableReason = "codex version unknown"
	case !compatible:
		src.UnavailableReason = reason
	case !n.WorkspaceEnabled:
		src.UnavailableReason = ReasonCodexWorkspaceDisabled
	default:
		models, merr := codex.LocalAccountModels()
		if merr != nil {
			src.UnavailableReason = ReasonCodexModelInventory
			break
		}
		caps, cerr := CodexAgentCapabilities(n.Rules, models, in.Confirmations != nil, n.SessionsEnabled && n.CodexInteractive)
		if cerr != nil {
			src.UnavailableReason = ReasonNativeRulesMissing
			break
		}
		src.Models, src.Capabilities = models, caps
	}
	return Spec{Source: src, Prober: runnerprobe.NewCodexProber(n.Codex)}, version, true
}

// CodexAgentCapabilities advertises exactly what WorkspaceJobs launches for a
// codex subscription: the agent op (plus confirm/stream when enabled), the
// no-connection codex route, every listed model, the rules' axes per model
// group, no tool restriction (codex has none) and executed-model proof.
func CodexAgentCapabilities(rules provider.CapabilityRules, models []string, confirm, stream bool) ([]runner.ExecutionCapability, error) {
	ops := []runner.OpType{runner.OpAgent}
	if confirm {
		ops = append(ops, runner.OpConfirm)
	}
	if stream {
		ops = append(ops, runner.OpStream)
	}
	return nativeCapabilities(rules, workflow.BackendCodex, openAIFamily, models, nil, ops)

// ClaudeAgentCapabilities adds claude-code agent support to the Claude source.
// Models and tools are exactly those P2 T9 BuildCapabilities proved for the
// same harness's chat capabilities; axes come from the rules' claude-code list.
func ClaudeAgentCapabilities(rules provider.CapabilityRules, chat []runner.ExecutionCapability, confirm, stream bool) ([]runner.ExecutionCapability, error) {
	var models, tools []string
	var fams []modelidentity.Family
	for _, c := range chat {
		if c.Op != runner.OpChat {
			continue
		}
		for _, m := range c.Models {
			if !slices.Contains(models, m) {
				models = append(models, m)
			}
		}
		for _, tool := range c.Tools {
			if !slices.Contains(tools, tool) {
				tools = append(tools, tool)
			}
		}
		for _, f := range c.Families {
			if !slices.Contains(fams, f) {
				fams = append(fams, f)
			}
		}
	}
	if len(models) == 0 {
		return nil, errors.New("sources: no proven claude models to extend to agent work")
	}
	if len(tools) == 0 {
		// allowlist (G2): an empty advertised list never means "all tools".
		return nil, errors.New("sources: no proven claude tools for an allowlist agent capability")
	}
	ops := []runner.OpType{runner.OpAgent}
	if confirm {
		ops = append(ops, runner.OpConfirm)
	}
	if stream {
		ops = append(ops, runner.OpStream)
	}
	return nativeCapabilities(rules, workflow.BackendClaudeCode, fams, models, tools, ops)
}

type axesGroup struct {
	tiers  []provider.ContextWindow
	levels []provider.Effort
	models []string
}

func nativeCapabilities(rules provider.CapabilityRules, backend string, fams []modelidentity.Family, models, tools []string, ops []runner.OpType) ([]runner.ExecutionCapability, error) {
	if rules.Empty() || !rules.Has(backend) {
		return nil, fmt.Errorf("sources: %s", ReasonNativeRulesMissing)
	}
	fp, err := runner.EndpointFingerprint(provider.ResolvedBinding{Provider: providersadapter.ProviderClaudeCLI, Backend: backend})
	if err != nil {
		return nil, err
	}
	bc := rules.Describe()[backend]
	var groups []*axesGroup
	for _, m := range models {
		tiers, levels := bc.ContextTiers, bc.EffortLevels
		if o, ok := bc.ModelOverrides[m]; ok {
			if o.ContextTiers != nil {
				tiers = o.ContextTiers
			}
			if o.EffortLevels != nil {
				levels = o.EffortLevels
			}
		}
		var g *axesGroup
		for _, cand := range groups {

	}

var (
	// ErrCapabilityUnavailable is the P3 T9 typed reject code for a request this
	// runner does not advertise right now.
	ErrCapabilityUnavailable = errors.New("capability_unavailable")
	// ErrExecutedModelUnproven: a strict request whose native record does not
	// name the requested model. The step is not pushed.
	ErrExecutedModelUnproven = errors.New("executed model not proven")

// MatchNativeAgent re-checks, immediately before accept, the same predicate
// the runner advertised: an available, logged-in source of the requested
// credential kind with an agent capability for the exact route, backend,
// model, axes, tools and model proof. It never floors a request.
func MatchNativeAgent(sources []runneragent.Source, a *runneragent.AgentJob, rules provider.CapabilityRules) (runneragent.Source, runner.ExecutionCapability, error) {
	fail := func(why string) (runneragent.Source, runner.ExecutionCapability, error) {
		return runneragent.Source{}, runner.ExecutionCapability{}, fmt.Errorf("%w: %s", ErrCapabilityUnavailable, why)
	}
	if a == nil {
		return fail("agent dispatch without payload")
	}
	if rules.Empty() {
		return fail("capability rules not loaded")
	}
	reqCtx, reqEffort := provider.ContextWindow(a.ContextWindow), provider.Effort(a.Effort)
	if reqCtx == "" {
		reqCtx = provider.ContextDefault
	}
	if reqEffort == "" {
		reqEffort = provider.EffortDefault
	}
	effCtx, effEffort, err := rules.Validate(a.Backend, a.Model, reqCtx, reqEffort)
	if err != nil || effCtx != reqCtx || effEffort != reqEffort {
		return fail("requested context/effort is not supported exactly")
	}
	for _, s := range sources {
		if string(s.Kind) != a.CredentialKind || s.UnavailableReason != "" || s.Health.Auth == runner.AuthLoggedOut {
			continue
		}
		for _, c := range s.Capabilities {
			if c.Op != runner.OpAgent || c.Backend != a.Backend || provider.Canonicalize(c.Provider) != provider.Canonicalize(a.Provider) ||
				!slices.Contains(c.Models, a.Model) || (a.RequireExecutedModel && !c.ExecutedModel) {
				continue
			}
			if !slices.Contains(c.ContextWindows, reqCtx) {
				continue
			}
			// none is universal (handled by Validate, never listed per backend).
			if reqEffort != provider.EffortNone && !slices.Contains(c.Efforts, reqEffort) {
				continue
			}
			// The same predicate placement and Reserve use (Cycle 3b): allowlist
			// needs a resolved non-empty scope within Tools; unrestricted (codex)
			// accepts only the empty scope; no posture is never accepted for agent work.
			if c.ToolPolicy == "" || !runner.ToolScopeSatisfied(c, a.ToolScope) {
				continue
			}
			return s, c, nil
		}
	}
	return fail(fmt.Sprintf("no available %s source advertises %s/%s for model %q", a.CredentialKind, a.Provider, a.Backend, a.Model))
}

// VerifyExecutedModel requires a reported-execution record naming want (the

// result's own Model label is never proof.
func VerifyExecutedModel(want string, r *engine.AgentResult) error {
	if r != nil {

				return nil
			}
		}
	}

}

func stubHelloHub(t *testing.T) (*httptest.Server, chan stubResult) {
	t.Helper()
	done := make(chan stubResult, 1)
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.URL.Path != wsclient.ConnectPath {
			http.NotFound(w, r)
			return
		}
		out := stubResult{auth: r.Header.Get("Authorization")}
		c, err := websocket.Accept(w, r, nil)
		if err != nil {
			return
		}
		defer c.CloseNow()
		ctx := r.Context()
		send := func(e runnerproto.Envelope, err error) {
			require.NoError(t, err)
			b, err := runnerproto.Encode(e)
			require.NoError(t, err)
			_ = c.Write(ctx, websocket.MessageText, b)
		}
		recv := func() (runnerproto.Envelope, bool) {
			_, b, err := c.Read(ctx)
			if err != nil {
				return runnerproto.Envelope{}, false
			}
			e, err := runnerproto.Decode(b)
			return e, err == nil
		}
		keyID := uuid.NewString()
		nonce := make([]byte, 32)
		_, _ = rand.Read(nonce)
		send(runnerproto.NewEnvelope(runnerproto.KindChallenge, runnerproto.Challenge{KeyID: keyID, Nonce: base64.StdEncoding.EncodeToString(nonce)}))
		e, ok := recv()
		if !ok || e.Kind != runnerproto.KindChallengeResponse {
			return
		}
		var cr runnerproto.ChallengeResponse
		require.NoError(t, runnerproto.DecodePayload(e, &cr))
		pub, sig, err := cr.Decoded()
		require.NoError(t, err)
		out.sigOK = ed25519.Verify(pub, runneragent.ChallengeMessage(keyID, nonce), sig)
		if e, ok = recv(); !ok || e.Kind != runnerproto.KindHello {
			return
		}
		require.NoError(t, runnerproto.DecodePayload(e, &out.hello))
		send(runnerproto.NewEnvelope(runnerproto.KindAdmitted, runnerproto.Admitted{RunnerID: "mac-test", HeartbeatSeconds: 1, ProtocolVersion: runnerproto.ProtocolVersion}))
		select {
		case done <- out:
		default:
		}
		for {
			if _, ok := recv(); !ok {
				return
			}
		}
	}))
	t.Cleanup(srv.Close)
	return srv, done
}
