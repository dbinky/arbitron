# Remote Runners — Phase 4 Task 11: Group-resolution staging resource

**Goal:** Make a group conflict-resolution session's staging directory a named, checkpointed workspace resource keyed by its `GroupResolutionIdentity`, not the parent's run workspace. The autonomous first turn (`StartResolution`), later operator turns, End/Abandon and between-turn recovery all share the resolution turn lease and the session mover. A staging session moves only under the allowed triggers (exhausted, logged_out, drain, runner_lost). A move restores only the staging directory from the resource's committed checkpoint and never touches the parent or task directories. The gather cannot proceed, either by `StartResolution` returning a session ref or by a sentinel/End completion reaching the completer, until the turn's staged checkpoint has committed together with the session record.

**Architecture:** `engine.ResolutionResourceID(id)` derives a deterministic resource UUID (SHA-1 name-based under the group run id) from `(GroupRunID, MergeIndex, Attempt)`, the same fields `ResolutionLeaseKey` (P4 T2) uses. The P4 T6 `turnCheckpointPlan` gains `resourceID`. When it is set, `checkpointAndCommit` stages the group session's staging dir under that resource through `TurnWorkspaceCheckpointer` (P4 T6 → P3 checkpoint store and home row). Group sessions are pinned to the built-in runner: the staging dir is server-local and a remote runner cannot reach the gather's backing repository (RR-11). The P4 T7 routed stream selector therefore places resolution turns with `AffinitySession` pinned to `builtin`, so an exhausted or logged-out built-in source interrupts the turn (P4 T9 `interruptSession`) instead of being transparently re-placed. `SessionMoveRequest`/`MoveRequest` gain `BuiltInOnly`. For such moves the mover (P4 T8) places with `AffinityBuiltIn`, restores the staging resource only, never hands the resource's home off, and waits visibly when no built-in source of the group is eligible. `GroupResolutionBridge` gains `SetTurnIntents`, `SetSessionMover` and `SetSessionCheckpoints`. `StartResolution` takes a pre-turn baseline checkpoint of the staging dir, persists a first-turn intent (exact prompt and nonce), runs the first turn through a move-and-rerun loop under the held resolution lease, and commits the record only through `checkpointAndCommit`. A retry after an interrupted attempt restores the staging dir to the baseline and resends the persisted prompt and nonce. `conversationHandler.HandleMessage` (P4 T9 `turnRun`) and `RecoverSession` (P4 T10) pass the resource, the staging dir and `BuiltInOnly` to the mover.

**Tech Stack:** Go 1.25.5, testify, google/uuid.

**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` (Recovery and session continuity; group conflict resolution keeps its staging identity); `docs/designs/2026-11-19-remote-runners-design-phase-4.md` §2 row "Group sessions", §3.5 "Group-staging sessions", §3.6 row "Matching workspace/session checkpoints and group staging identity" (UNRESOLVED DEPENDENCY RR-08/RR-11), §8 (group-staging Edge case and durable-session regression). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §3 (`StepIdentityFromContext`, `WithSubOperation`, `OperationResolution`), §7 (`Affinity`, `Place`), §16 (`WorkspaceSync.RestoreBuiltIn`, `HomeStore`), §17 (`TurnLease`, `TurnIntentStore`, `engine.SessionMover`).

ESCALATION: RR-11: Remote mobility of group-resolution staging is missing. The Phase 3 pull/push/transfer paths (P3 T6/T7/T9) are keyed by a run's workspace home and have no resource-keyed staging transfer, and a remote runner cannot reach the gather's server-side backing repository. Until both exist, staging sessions are pinned to the built-in runner. They are checkpointed every turn under `ResolutionResourceID(identity)`, and they move only between built-in sources of the same group under the allowed triggers, restoring the staging dir from its resource checkpoint. When no built-in source of the group is eligible they wait visibly (`SessionWaitError` / `waiting_capacity`) and never fall back to a remote runner.

import (

// ResolutionResourceID names the workspace resource of a group conflict-
// resolution session's staging directory. It is derived from the same
// (group run, merge, attempt) triple as ResolutionLeaseKey, so every writer
// (StartResolution, later turns, recovery) addresses one checkpoint line that
// is never the parent's run workspace.
func ResolutionResourceID(id GroupResolutionIdentity) uuid.UUID {
	return uuid.NewSHA1(id.GroupRunID, []byte(fmt.Sprintf("resolution-staging/%d/%d", id.MergeIndex, id.Attempt)))
}

// into dir. *runner.WorkspaceSync (P3 T6, RestoreBuiltIn) satisfies it.

// requireBuiltInTarget checks, before a built-in-only first-turn move fences
// and restores anything, that some built-in source of the group can run the
// re-run. Otherwise the session waits visibly instead of reaching a remote
// runner (there is no session record yet, so no move job is recorded).
func (m *SessionMover) requireBuiltInTarget(ctx context.Context, req MoveRequest) error {
	snap, err := m.d.Registry.Snapshot(ctx)
	if err != nil {
		return fmt.Errorf("session move: pool snapshot: %w", err)
	}
	if m.d.Telemetry != nil {
		snap.Telemetry = m.d.Telemetry.Latest()
	}
	snap.Now = m.d.Clock()
	placeReq := req.Requirements
	placeReq.Op, placeReq.Affinity, placeReq.RunID, placeReq.PinnedRunner = OpType("stream"), AffinityBuiltIn, req.RunID, ""
	dec := Place(placeReq, snap, m.d.Policy)
	if dec.Placed {

// runResolutionFirstTurn streams the first turn. On a session interruption it
// discards the partial output, publishes interactive.turn_restarted, moves the
// session between built-in sources under the HELD resolution lease (restoring
// the staging resource) and re-runs the same prompt and nonce, at most
// maxMoves times.
func (b *GroupResolutionBridge) runResolutionFirstTurn(ctx context.Context, t *resolutionTurn) (firstTurnOutput, error) {
	attemptCtx := ctx
	for moves := 0; ; moves++ {
		out, err := b.streamResolutionTurn(attemptCtx, t, t.hold.Lease().Generation)
		if err == nil {
			return out, nil
		}
		var mv *SessionMoveRequiredError
		if b.mover == nil || !errors.As(err, &mv) {
			return firstTurnOutput{}, err
		}
		if moves >= b.maxMoves {
			return firstTurnOutput{}, fmt.Errorf("group resolution %q: first turn not recovered after %d moves: %w: %v", t.nodeID, moves, ErrSessionRestoreFailed, err)
		}
		PublishTurnRestarted(t.bus, t.parentID, t.nodeID, 1, t.hold.Lease().Generation+1)
		var invocation uuid.UUID
		if id, ok := StepIdentityFromContext(ctx); ok {
			invocation = id.InvocationID
		}
		res, merr := b.mover.MoveSession(ctx, t.hold.Lease(), SessionMoveRequest{
			RunID: t.parentID, InvocationID: invocation, NodeID: t.nodeID, TurnIndex: 1, Reason: mv.Reason, From: mv.From,
			Binding: t.binding, WorkDir: t.req.WorkDir, ResourceID: t.resource,
			RestoreWorkspace: true, BuiltInOnly: true, FirstTurn: true,
		})
		if merr != nil {
			return firstTurnOutput{}, fmt.Errorf("group resolution %q: recover interrupted first turn: %w", t.nodeID, merr)
		}
		l := t.hold.Lease()
		l.Generation = res.Generation
		t.hold.Adopt(l)
		attemptCtx = WithSubOperation(ctx, fmt.Sprintf("g%d", res.Generation), OperationResolution)
	}
}

// streamResolutionTurn is the original StartResolution consume loop (same
// error messages), with each token tagged by the attempt's lease generation.
func (b *GroupResolutionBridge) streamResolutionTurn(ctx context.Context, t *resolutionTurn, generation int64) (firstTurnOutput, error) {
	stream, err := t.provider.StreamChat(ctx, t.req)
	if err != nil {
		return firstTurnOutput{}, fmt.Errorf("group resolution %q: stream call: %w", t.nodeID, err)
	}
	var response strings.Builder
	var out firstTurnOutput
	for sawDone := false; !sawDone; {
		// Prefer cancellation even when a buffered Done or EOF is also ready.
		if err := ctx.Err(); err != nil {
			return firstTurnOutput{}, fmt.Errorf("group resolution %q: autonomous turn: %w", t.nodeID, err)
		}
		var chunk ChatChunk
		select {
		case <-ctx.Done():
			return firstTurnOutput{}, fmt.Errorf("group resolution %q: autonomous turn: %w", t.nodeID, ctx.Err())
		case next, ok := <-stream:
			if !ok {
				if err := ctx.Err(); err != nil {
					return firstTurnOutput{}, fmt.Errorf("group resolution %q: autonomous turn: %w", t.nodeID, err)
				}
				return firstTurnOutput{}, fmt.Errorf("group resolution %q: stream closed without completion", t.nodeID)
			}
			chunk = next
		}
		if chunk.Error != nil {
			return firstTurnOutput{}, fmt.Errorf("group resolution %q: stream error: %w", t.nodeID, chunk.Error)
		}
		if chunk.SessionID != "" {
			out.sessionID = chunk.SessionID
		}
		if chunk.Token != "" {
			response.WriteString(chunk.Token)
			t.bus.Publish(t.parentID, Event{Type: EventTypeInteractiveToken, Timestamp: time.Now(),
				Data: map[string]any{"token": chunk.Token, "generation": generation}})
		}
		if chunk.Done {
			out.tokensIn, out.tokensOut, sawDone = chunk.TokensIn, chunk.TokensOut, true
		}
	}
	out.response = response.String()
	return out, nil
}
