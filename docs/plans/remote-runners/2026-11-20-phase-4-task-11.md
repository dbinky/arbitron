## Portable git algorithm

1. Under the existing gather gate and resolution lease, validate `GroupResolutionIdentity` against the stored gather handle and resolve its trusted staging directory. Prepare a private copy beneath `<workspaceRoot>/.runner-resources/resolutions/<resourceUUID>` on the server; remote roots use the same relative resource path. Do not ask a remote runner to open the server backing path.
2. `WorkingArea.ExportResolution` copies working files, permissions, empty dirs and required `.git` state (index with stages 1/2/3, HEAD/refs, MERGE_HEAD/MERGE_MSG/ORIG_HEAD and objects) into that private copy. Call the P3 helper `adapter/checkpoint/git.go:MaterializePortableGit(ctx, stagingDir, dstDir)` for the complete object closure; add resolution-specific MERGE_HEAD/ORIG_HEAD and every unmerged index-stage object to its root set. The helper materializes verified backing/alternate objects into the COPY and removes alternates there. Do not create a second object-closure implementation. Preserve unresolved index and merge state exactly. Never run clean/smudge hooks or overwrite source `.git`. Validate allowed alternate roots, bound expanded bytes, reject cycles/symlinks/path escapes, seal copied config/hooks and run sanitized git connectivity checks in the copy. A standalone `git rev-parse HEAD`, `cat-file MERGE_HEAD`, `ls-files -u` and merge-base read must work with the server backing tree made unavailable.
3. Register the resolution resource and baseline immutable checkpoint before dispatch. Persist original rendered prompt+nonce+accepted binding, exact invocation and resource ref. Execute first turn in the canonical private WorkDir, with prompt WorkDir rendered to that path. Existing source staging remains the gather's destination; neither parent nor task trees are shipped.
4. Placement is `AffinitySession`: first pin chosen from eligible same-group sources, later pin read by exact session invocation. No built-in override for OperationResolution. P4 T8 recovery fences old job/resource owner before handoff and restores the last COMMITTED resolution checkpoint. P4 T12 transfer routes authorize actual RunID + descriptor resource ID + job/resource generation; runner confines paths to its resource root and validates standalone git state before launching the harness.
5. P4 T6 atomically commits the resource candidate together with bundle, messages, session pin/generation and intent. After SQL commit, `MaterializeResolution` restores that exact checkpoint into the trusted original staging dir under the gather gate, re-seals git metadata, verifies identity/generation, and records materialization completion durably. A crash or disk failure here retries materialization on startup; it does not rerun a committed turn. `StartResolution` returns its session ref and End/sentinel invokes the completer only AFTER this gate. The existing gatherer then checks conflicts and applies/continues through its own WorkingArea API.
6. Mid-turn retry restores the baseline/last committed private copy, discards interrupted edits, reuses exact prompt+nonce or exact user message, and clears old tokens via P4 T9. End/Abandon and recovery hold `ResolutionLeaseKey` and use the recorded resource/identity. Closing or replacing an attempt fences pending materialization so it cannot touch a new attempt.

```go
package engine

import (
	"context"
	"errors"
	"fmt"
	"path/filepath"

	"github.com/google/uuid"
)

// ResolutionResourceID names the workspace resource of one group
// conflict-resolution session (P4 T11). It is derived from the same
// (group run, merge, attempt) triple as ResolutionLeaseKey, so the first turn,
// later turns, End/Abandon and recovery address one checkpoint line that is
// never the parent's or a task's workspace.
func ResolutionResourceID(id GroupResolutionIdentity) uuid.UUID {
	return uuid.NewSHA1(id.GroupRunID, []byte(fmt.Sprintf("resolution-staging/%d/%d", id.MergeIndex, id.Attempt)))
}

// ResolutionResourceKey is the resource-lease key of a resolution resource.
func ResolutionResourceKey(resourceID uuid.UUID) string { return "resolution:" + resourceID.String() }

var (
	// ErrMissingResolutionResource: a resolution operation without its resource
	// descriptor must never launch (fail closed, RR-11).
	ErrMissingResolutionResource = errors.New("engine: resolution operation has no staging resource")
	// ErrObsoleteResolutionAttempt: the attempt is no longer the gather's
	// current attempt; nothing may materialize into the staging area for it.
	ErrObsoleteResolutionAttempt = errors.New("engine: resolution attempt is no longer current")
	// ErrResolutionNotCommitted: only a committed checkpoint is materialized.
	ErrResolutionNotCommitted = errors.New("engine: resolution checkpoint is not committed")
)

// ResolutionResource is the durable staging resource of a resolution session.
// SourceDir is the trusted server-local gather staging area (the gather's
// destination); it is never serialized to a runner. WorkDir is the canonical
// private copy beneath the runner resource root, where every turn executes.
type ResolutionResource struct {
	ID        uuid.UUID
	Identity  GroupResolutionIdentity
	SourceDir string
	WorkDir   string
}

// Validate rejects a resource whose ID is not derived from its identity or
// whose directories are not distinct absolute paths (WorkDir named by ID).
func (r ResolutionResource) Validate() error {
	switch {
	case r.Identity.GroupRunID == uuid.Nil:
		return errors.New("resolution resource: identity has no group run")
	case r.ID != ResolutionResourceID(r.Identity):
		return errors.New("resolution resource: id is not derived from its identity")
	case !filepath.IsAbs(r.SourceDir) || !filepath.IsAbs(r.WorkDir):
		return errors.New("resolution resource: source and work dirs must be absolute")
	case filepath.Clean(r.SourceDir) == filepath.Clean(r.WorkDir):
		return errors.New("resolution resource: the work dir must be a private copy, not the staging area")
	case filepath.Base(filepath.Clean(r.WorkDir)) != r.ID.String():
		return errors.New("resolution resource: work dir is not named by the resource id")
	}
	return nil
}

// StagingRestorer restores a resource's latest COMMITTED checkpoint into dir.
type StagingRestorer interface {
	RestoreBuiltIn(ctx context.Context, resourceID uuid.UUID, dir string) error
}

type resolutionResourceCtxKey struct{}

// ContextWithResolutionResource tags a resolution operation with its resource;
// the runner's session selector turns it into the job's ResourceDescriptor.
func ContextWithResolutionResource(ctx context.Context, r ResolutionResource) context.Context {
	return context.WithValue(ctx, resolutionResourceCtxKey{}, r)
}

// ResolutionResourceFromContext returns the resource of a resolution operation.
func ResolutionResourceFromContext(ctx context.Context) (ResolutionResource, bool) {
	r, ok := ctx.Value(resolutionResourceCtxKey{}).(ResolutionResource)
	return r, ok
}
```

package git

import (
	"bufio"
	"context"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"strings"

	"github.com/google/uuid"
)

// DefaultResolutionMaxBytes bounds one exported resolution copy.
const DefaultResolutionMaxBytes int64 = 2 << 30

var (
	// ErrResolutionPortability marks a refused export/import: foreign or cyclic
	// alternates, symlinks or path escapes, an untrusted source or destination.
	ErrResolutionPortability = errors.New("git working area: resolution staging is not portable")
	// ErrResolutionTooLarge marks a copy over the configured byte bound.
	ErrResolutionTooLarge = errors.New("git working area: resolution copy exceeds the size bound")
)

const portableRootRefs = "refs/arbitron/portable"

// ResolutionResourceRoot is <workspace root>/.runner-resources/resolutions.
// A remote runner uses the same relative path under its own resource root.
func (a *WorkingArea) ResolutionResourceRoot() string {
	return filepath.Join(a.root, ".runner-resources", "resolutions")
}

func (a *WorkingArea) maxResolutionBytes() int64 {
	if a.resolutionMaxBytes > 0 {
		return a.resolutionMaxBytes
	}
	return DefaultResolutionMaxBytes
}

// ExportResolution makes dstDir a STANDALONE copy of a gather staging area:
// working files, permissions, empty dirs and the complete .git state (index
// with every conflict stage, HEAD/refs, MERGE_HEAD/MERGE_MSG/ORIG_HEAD and the
// full object closure, without alternates). The source .git is only read.
// The copy is built beside dstDir and renamed into place; any failure
// publishes nothing.
func (a *WorkingArea) ExportResolution(ctx context.Context, stagingDir, dstDir string) error {
	if a.portableGit == nil {
		return fmt.Errorf("%w: no portable git materializer configured", ErrResolutionPortability)
	}
	src, err := a.trustedStaging(stagingDir)
	if err != nil {
		return err
	}
	dst, err := a.resolutionDst(dstDir)
	if err != nil {
		return err
	}
	if err := a.checkAlternates(filepath.Join(src, ".git", "objects")); err != nil {
		return err
	}
	tmp := dst + ".partial-" + uuid.NewString()
	defer os.RemoveAll(tmp)
	if err := copyResolutionTree(src, tmp, a.maxResolutionBytes(), true); err != nil {
		return err
	}
	if err := sealStaging(tmp); err != nil {
		return err
	}
	if err := pinResolutionRoots(tmp); err != nil {
		return err
	}
	if err := a.portableGit(ctx, src, tmp); err != nil {
		return fmt.Errorf("git working area: export resolution: materialize objects: %w", err)
	}
	if err := os.RemoveAll(filepath.Join(tmp, ".git", filepath.FromSlash(portableRootRefs))); err != nil {
		return err
	}
	if err := a.verifyStandalone(ctx, tmp); err != nil {
		return err
	}
	if err := os.RemoveAll(dst); err != nil {
		return err
	}
	return os.Rename(tmp, dst)
}

// ImportResolution restores a committed standalone copy (srcDir) into the
// trusted gather staging area: objects are added (content-addressed, never
// rewritten), index/HEAD/refs/merge state and the work tree are replaced, and
// the staging repository keeps its own alternates/config and is re-sealed.
func (a *WorkingArea) ImportResolution(ctx context.Context, srcDir, stagingDir string) error {
	staging, err := a.trustedStaging(stagingDir)
	if err != nil {
		return err
	}
	src, err := resolveDir(srcDir)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrResolutionPortability, err)
	}
	if _, err := os.Lstat(filepath.Join(src, ".git", "objects", "info", "alternates")); err == nil {
		return fmt.Errorf("%w: imported copy still has alternates", ErrResolutionPortability)
	}
	if err := a.verifyStandalone(ctx, src); err != nil {
		return err
	}
	if err := copyResolutionObjects(filepath.Join(src, ".git", "objects"), filepath.Join(staging, ".git", "objects")); err != nil {
		return err
	}
	gitDir := filepath.Join(staging, ".git")
	for _, name := range []string{"MERGE_HEAD", "MERGE_MSG", "MERGE_MODE", "ORIG_HEAD"} {
		if err := os.RemoveAll(filepath.Join(gitDir, name)); err != nil {
			return err
		}
	}
	entries, err := os.ReadDir(filepath.Join(src, ".git"))
	if err != nil {
		return err
	}
	for _, e := range entries {
		switch e.Name() {
		case "objects", "config", "hooks", "info", "config.worktree", "commondir":
			continue
		}
		if err := os.RemoveAll(filepath.Join(gitDir, e.Name())); err != nil {
			return err
		}
		if err := copyResolutionTree(filepath.Join(src, ".git", e.Name()), filepath.Join(gitDir, e.Name()), a.maxResolutionBytes(), false); err != nil {
			return err
		}
	}
	if err := replaceWorkTree(src, staging, a.maxResolutionBytes()); err != nil {
		return err
	}
	if err := sealStaging(staging); err != nil {
		return err
	}
	if _, err := a.git.Run(ctx, Command{Args: []string{"rev-parse", "--verify", "HEAD"}, Dir: staging}); err != nil {
		return fmt.Errorf("git working area: import resolution: %w", err)
	}
	return nil
}

// trustedStaging accepts only a gather staging work tree of this area.
func (a *WorkingArea) trustedStaging(dir string) (string, error) {
	p, err := resolveDir(dir)
	if err != nil {
		return "", fmt.Errorf("%w: %v", ErrResolutionPortability, err)
	}
	rel, err := filepath.Rel(a.backing, p)
	if err != nil || strings.Contains(rel, string(filepath.Separator)) || rel == "." || strings.HasPrefix(rel, "..") || !strings.Contains(rel, "-gather-") {
		return "", fmt.Errorf("%w: %s is not a gather staging area", ErrResolutionPortability, dir)
	}
	info, err := os.Lstat(filepath.Join(p, ".git"))
	if err != nil || !info.IsDir() {
		return "", fmt.Errorf("%w: %s has no staging repository", ErrResolutionPortability, dir)
	}
	return p, nil
}

// resolutionDst accepts only <ResolutionResourceRoot>/<uuid>.
func (a *WorkingArea) resolutionDst(dir string) (string, error) {
	if !filepath.IsAbs(dir) || filepath.Clean(dir) != dir {
		return "", fmt.Errorf("%w: destination %q must be a clean absolute path", ErrResolutionPortability, dir)
	}
	if filepath.Dir(dir) != a.ResolutionResourceRoot() {
		return "", fmt.Errorf("%w: destination %q is outside the resource root", ErrResolutionPortability, dir)
	}
	if _, err := uuid.Parse(filepath.Base(dir)); err != nil {
		return "", fmt.Errorf("%w: destination %q is not named by a resource id", ErrResolutionPortability, dir)
	}
	if err := os.MkdirAll(filepath.Dir(dir), 0o700); err != nil {
		return "", err
	}
	return dir, nil
}

// checkAlternates follows the alternates chain from objectsDir: every entry
// must be a real directory inside this area's backing root, and no store may
// be visited twice (cycle).
func (a *WorkingArea) checkAlternates(objectsDir string) error {
	seen := map[string]bool{}
	var walk func(dir string) error
	walk = func(dir string) error {
		if seen[dir] {
			return fmt.Errorf("%w: alternate cycle through %s", ErrResolutionPortability, dir)
		}
		seen[dir] = true
		f, err := os.Open(filepath.Join(dir, "info", "alternates"))
		if errors.Is(err, fs.ErrNotExist) {
			return nil
		}
		if err != nil {
			return err
		}
		defer f.Close()
		sc := bufio.NewScanner(f)
		for sc.Scan() {
			line := strings.TrimSpace(sc.Text())
			if line == "" || strings.HasPrefix(line, "#") {
				continue
			}
			if !filepath.IsAbs(line) || filepath.Clean(line) != line {
				return fmt.Errorf("%w: alternate %q is not a clean absolute path", ErrResolutionPortability, line)
			}
			rel, err := filepath.Rel(a.backing, line)
			if err != nil || rel == ".." || strings.HasPrefix(rel, ".."+string(filepath.Separator)) {
				return fmt.Errorf("%w: alternate %q is outside the backing root", ErrResolutionPortability, line)
			}
			info, err := os.Lstat(line)
			if err != nil || !info.IsDir() {
				return fmt.Errorf("%w: alternate %q is not a directory", ErrResolutionPortability, line)
			}
			if err := walk(line); err != nil {
				return err
			}
		}
		return sc.Err()
	}
	return walk(objectsDir)
}

// pinResolutionRoots adds MERGE_HEAD, ORIG_HEAD and every index-entry object
// (all conflict stages) as temporary refs of the COPY, so P3 T2's closure
// (refs + HEAD + index) includes them. Written as files: the objects are not
// in the copy yet, so update-ref would refuse them.
func pinResolutionRoots(dir string) error {
	gitDir := filepath.Join(dir, ".git")
	shas := map[string]bool{}
	for _, name := range []string{"MERGE_HEAD", "ORIG_HEAD"} {
		raw, err := os.ReadFile(filepath.Join(gitDir, name))
		if errors.Is(err, fs.ErrNotExist) {
			continue
		}
		if err != nil {
			return err
		}
		for _, l := range strings.Fields(string(raw)) {
			shas[l] = true
		}
	}
	idx, err := readIndexObjects(filepath.Join(gitDir, "index"))
	if err != nil {
		return err
	}
	for _, s := range idx {
		shas[s] = true
	}
	refDir := filepath.Join(gitDir, filepath.FromSlash(portableRootRefs))
	if err := os.MkdirAll(refDir, 0o700); err != nil {
		return err
	}
	for s := range shas {
		if len(s) != 40 && len(s) != 64 {
			return fmt.Errorf("%w: malformed object id %q", ErrResolutionPortability, s)
		}
		if err := os.WriteFile(filepath.Join(refDir, s), []byte(s+"\n"), 0o600); err != nil {
			return err
		}
	}
	return nil
}

// verifyStandalone proves dir needs nothing outside itself: HEAD, MERGE_HEAD,
// every index object and connectivity resolve with alternates disabled.
func (a *WorkingArea) verifyStandalone(ctx context.Context, dir string) error {
	noAlt := []string{"GIT_ALTERNATE_OBJECT_DIRECTORIES="}
	run := func(args ...string) (string, error) {
		res, err := a.git.Run(ctx, Command{Args: args, Dir: dir, Env: noAlt})
		return res.Stdout, err
	}
	if _, err := run("rev-parse", "--verify", "HEAD^{commit}"); err != nil {
		return fmt.Errorf("git working area: standalone HEAD: %w", err)
	}
	if _, err := os.Stat(filepath.Join(dir, ".git", "MERGE_HEAD")); err == nil {
		if _, err := run("cat-file", "-e", "MERGE_HEAD^{commit}"); err != nil {
			return fmt.Errorf("git working area: standalone MERGE_HEAD: %w", err)
		}
	}
	idx, err := readIndexObjects(filepath.Join(dir, ".git", "index"))
	if err != nil {
		return err
	}
	for _, s := range idx {
		if _, err := run("cat-file", "-e", s); err != nil {
			return fmt.Errorf("git working area: standalone index object %s: %w", s, err)
		}
	}
	if _, err := run("fsck", "--connectivity-only", "--no-dangling", "--no-progress"); err != nil {
		return fmt.Errorf("git working area: standalone connectivity: %w", err)
	}
	return nil
}

// readIndexObjects returns the object id of every index entry (all stages) by
// parsing "git ls-files -s"-equivalent data straight from the index file is
// avoided; we shell out through a throwaway reader instead.
func readIndexObjects(index string) ([]string, error) {
	if _, err := os.Stat(index); errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	return listIndexObjects(index)
}

// copyResolutionTree copies src to dst preserving modes, empty dirs and work
// tree symlinks. withGit=true copies the .git directory too, except hooks and
// objects/info/alternates; any symlink inside .git is refused. Expanded bytes
// are bounded.
func copyResolutionTree(src, dst string, max int64, withGit bool) error {
	var total int64
	return filepath.WalkDir(src, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		rel, _ := filepath.Rel(src, p)
		relSlash := filepath.ToSlash(rel)
		inGit := relSlash == ".git" || strings.HasPrefix(relSlash, ".git/")
		if inGit && !withGit {
			if d.IsDir() {
				return filepath.SkipDir
			}
			return nil
		}
		if relSlash == ".git/hooks" || relSlash == ".git/objects/info/alternates" {
			if d.IsDir() {
				return filepath.SkipDir
			}
			return nil
		}
		target := filepath.Join(dst, rel)
		info, err := d.Info()
		if err != nil {
			return err
		}
		switch {
		case d.Type()&fs.ModeSymlink != 0:
			if inGit || isGitDirOf(src, p) {
				return fmt.Errorf("%w: symlink %s inside repository metadata", ErrResolutionPortability, relSlash)
			}
			link, err := os.Readlink(p)
			if err != nil {
				return err
			}
			return os.Symlink(link, target)
		case d.IsDir():
			return os.MkdirAll(target, info.Mode().Perm()|0o700)
		case info.Mode().IsRegular():
			total += info.Size()
			if total > max {
				return fmt.Errorf("%w: more than %d bytes", ErrResolutionTooLarge, max)
			}
			return copyRegular(p, target, info.Mode().Perm())
		default:
			return fmt.Errorf("%w: unsupported file type at %s", ErrResolutionPortability, relSlash)
		}
	})
}

func isGitDirOf(root, p string) bool { return filepath.Base(p) == ".git" && filepath.Dir(p) == root }

func copyRegular(src, dst string, perm fs.FileMode) error {
	in, err := os.Open(src)
	if err != nil {
		return err
	}
	defer in.Close()
	if err := os.MkdirAll(filepath.Dir(dst), 0o700); err != nil {
		return err
	}
	out, err := os.OpenFile(dst, os.O_CREATE|os.O_EXCL|os.O_WRONLY, perm)
	if err != nil {
		return err
	}
	if _, err := io.Copy(out, in); err != nil {
		out.Close()
		return err
	}
	if err := out.Sync(); err != nil {
		out.Close()
		return err
	}
	if err := out.Close(); err != nil {
		return err
	}
	return os.Chmod(dst, perm)
}

// copyResolutionObjects adds every object file (loose or pack) of src to dst
// when absent; existing content-addressed files are never rewritten.
func copyResolutionObjects(src, dst string) error {
	return filepath.WalkDir(src, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		rel, _ := filepath.Rel(src, p)
		if rel == "info" {
			return filepath.SkipDir
		}
		if d.Type()&fs.ModeSymlink != 0 {
			return fmt.Errorf("%w: symlink in imported objects", ErrResolutionPortability)
		}
		if d.IsDir() {
			return os.MkdirAll(filepath.Join(dst, rel), 0o755)
		}
		target := filepath.Join(dst, rel)
		if _, err := os.Lstat(target); err == nil {
			return nil
		}
		return copyRegular(p, target, 0o444)
	})
}

// replaceWorkTree makes staging's work tree (everything but .git) equal src's.
func replaceWorkTree(src, staging string, max int64) error {
	entries, err := os.ReadDir(staging)
	if err != nil {
		return err
	}
	for _, e := range entries {
		if e.Name() == ".git" {
			continue
		}
		if err := os.RemoveAll(filepath.Join(staging, e.Name())); err != nil {
			return err
		}
	}
	return copyResolutionTree(src, staging, max, false)
}

type ResolutionResourceRepo struct {

// NewResolutionResourceRepo builds the registry over the shared DB.
func NewResolutionResourceRepo(db *sql.DB) *ResolutionResourceRepo {
	return &ResolutionResourceRepo{db: db, now: time.Now}
}

func (r *ResolutionResourceRepo) EnsureResolution(ctx context.Context, res engine.ResolutionResource) error {
	if err := res.Validate(); err != nil {
		return err
	}
	now := r.now().UnixMilli()
	if _, err := r.db.ExecContext(ctx, `INSERT INTO resolution_resources
(id, group_run_id, merge_index, attempt, task_key, source_dir, work_dir, created_at, updated_at)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?) ON CONFLICT (id) DO NOTHING`,
		uuidToString(res.ID), uuidToString(res.Identity.GroupRunID), res.Identity.MergeIndex, res.Identity.Attempt,
		res.Identity.TaskKey, res.SourceDir, res.WorkDir, now, now); err != nil {
		return fmt.Errorf("ensure resolution resource: %w", err)
	}
	got, err := r.GetResolution(ctx, res.ID)
	if err != nil {
		return err
	}
	want := res
	want.Identity.Open = true
	if got != want {
		return fmt.Errorf("%w: %s", runner.ErrResolutionResourceConflict, res.ID)
	}
	return nil
}

func (r *ResolutionResourceRepo) GetResolution(ctx context.Context, id uuid.UUID) (engine.ResolutionResource, error) {
	var gid, task, src, work string
	var merge, attempt int
	err := r.db.QueryRowContext(ctx, `SELECT group_run_id, merge_index, attempt, task_key, source_dir, work_dir
FROM resolution_resources WHERE id = ?`, uuidToString(id)).Scan(&gid, &merge, &attempt, &task, &src, &work)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.ResolutionResource{}, fmt.Errorf("resolution resource %s: %w", id, instance.ErrNotFound)
	}
	if err != nil {
		return engine.ResolutionResource{}, fmt.Errorf("get resolution resource: %w", err)
	}
	groupRun, err := parseUUID(gid)
	if err != nil {
		return engine.ResolutionResource{}, err
	}
	return engine.ResolutionResource{ID: id, SourceDir: src, WorkDir: work, Identity: engine.GroupResolutionIdentity{
		GroupRunID: groupRun, MergeIndex: merge, Attempt: attempt, TaskKey: task, Open: true}}, nil
}

func (r *ResolutionResourceRepo) MarkMaterialized(ctx context.Context, id uuid.UUID, c engine.WorkspaceCompletion) error {
	if c.Ref == "" || c.Resource.Key != engine.ResolutionResourceKey(id) {
		return fmt.Errorf("mark materialized %s: receipt does not name this resource", id)
	}
	res, err := r.db.ExecContext(ctx, `UPDATE resolution_resources SET materialized_ref = ?, updated_at = ?
WHERE id = ? AND state = 'open'`, c.Ref, r.now().UnixMilli(), uuidToString(id))
	if err != nil {
		return fmt.Errorf("mark materialized: %w", err)
	}
	if n, _ := res.RowsAffected(); n == 1 {
		return nil
	}
	return r.missingOrClosed(ctx, id)
}

func (r *ResolutionResourceRepo) MaterializedRef(ctx context.Context, id uuid.UUID) (string, error) {
	var ref string
	err := r.db.QueryRowContext(ctx, `SELECT materialized_ref FROM resolution_resources WHERE id = ?`, uuidToString(id)).Scan(&ref)
	if errors.Is(err, sql.ErrNoRows) {
		return "", fmt.Errorf("resolution resource %s: %w", id, instance.ErrNotFound)
	}
	if err != nil {
		return "", fmt.Errorf("read materialized ref: %w", err)
	}
	return ref, nil
}

func (r *ResolutionResourceRepo) CloseResolution(ctx context.Context, id uuid.UUID) error {
	res, err := r.db.ExecContext(ctx, `UPDATE resolution_resources SET state = 'closed', updated_at = ? WHERE id = ?`,
		r.now().UnixMilli(), uuidToString(id))
	if err != nil {
		return fmt.Errorf("close resolution resource: %w", err)
	}
	if n, _ := res.RowsAffected(); n == 0 {
		return fmt.Errorf("resolution resource %s: %w", id, instance.ErrNotFound)
	}
	return nil
}

func (r *ResolutionResourceRepo) missingOrClosed(ctx context.Context, id uuid.UUID) error {
	var state string
	err := r.db.QueryRowContext(ctx, `SELECT state FROM resolution_resources WHERE id = ?`, uuidToString(id)).Scan(&state)
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("resolution resource %s: %w", id, instance.ErrNotFound)
	}
	if err != nil {
		return err
	}
	return fmt.Errorf("resolution resource %s: %w", id, runner.ErrResolutionClosed)
}

// PrepareResolution exports the trusted staging into the private copy,
// registers the resource and bootstraps its baseline checkpoint. An existing
// registration with a committed baseline is reused unchanged.
func (r *resolutionResources) PrepareResolution(ctx context.Context, id engine.GroupResolutionIdentity, stagingDir string) (engine.ResolutionResource, error) {
	id.Open = true
	rid := engine.ResolutionResourceID(id)
	res := engine.ResolutionResource{ID: rid, Identity: id, SourceDir: filepath.Clean(stagingDir), WorkDir: r.workDir(rid)}
	if err := res.Validate(); err != nil {
		return engine.ResolutionResource{}, err
	}
	if existing, err := r.d.Registry.GetResolution(ctx, rid); err == nil {
		if existing != res {
			return engine.ResolutionResource{}, fmt.Errorf("%w: %s", ErrResolutionResourceConflict, rid)
		}
		if _, ok, err := r.d.Checkpoints.Latest(ctx, rid); err != nil {
			return engine.ResolutionResource{}, err
		} else if ok {
			return existing, nil
		}
	} else if !errors.Is(err, instance.ErrNotFound) {
		return engine.ResolutionResource{}, err
	}
	if err := r.d.Git.ExportResolution(ctx, res.SourceDir, res.WorkDir); err != nil {
		return engine.ResolutionResource{}, fmt.Errorf("prepare resolution %s: %w", rid, err)
	}
	if err := r.d.Registry.EnsureResolution(ctx, res); err != nil {
		return engine.ResolutionResource{}, err
	}
	if _, _, err := r.d.Checkpoints.Commit(ctx, rid, res.WorkDir); err != nil { // bootstrap baseline only (contracts §16)
		return engine.ResolutionResource{}, fmt.Errorf("prepare resolution %s: baseline: %w", rid, err)
	}
	return res, nil
}

// MaterializeResolution restores the exact COMMITTED checkpoint into the
// trusted gather staging and records it durably. Idempotent per ref.
func (r *resolutionResources) MaterializeResolution(ctx context.Context, res engine.ResolutionResource, committed engine.WorkspaceCompletion) error {
	stored, err := r.d.Registry.GetResolution(ctx, res.ID)
	if err != nil {
		return err
	}
	if stored != res {
		return fmt.Errorf("%w: %s", ErrResolutionResourceConflict, res.ID)
	}
	if committed.Resource.Key != engine.ResolutionResourceKey(res.ID) {
		return fmt.Errorf("materialize %s: receipt names resource %q", res.ID, committed.Resource.Key)
	}
	ref, err := parseResolutionCheckpointRef(committed.Ref)
	if err != nil || ref.RunID != res.ID {
		return fmt.Errorf("materialize %s: ref %q does not name this resource", res.ID, committed.Ref)
	}
	latest, ok, err := r.d.Checkpoints.Latest(ctx, res.ID)
	if err != nil {
		return err
	}
	if !ok || latest != ref {
		return fmt.Errorf("materialize %s: %w (%s)", res.ID, engine.ErrResolutionNotCommitted, committed.Ref)
	}
	if done, err := r.d.Registry.MaterializedRef(ctx, res.ID); err != nil {
		return err
	} else if done == committed.Ref {
		return nil
	}
	fence, err := r.d.Resources.Claim(ctx, engine.ResolutionResourceKey(res.ID), "materialize", BuiltInRunnerID)
	if err != nil {
		return fmt.Errorf("materialize %s: claim resource: %w", res.ID, err)
	}
	defer func() { _ = r.d.Resources.Release(context.WithoutCancel(ctx), fence) }()
	tmp := filepath.Join(r.d.Root, ".runner-resources", "materialize", res.ID.String()+"-"+uuid.NewString())
	defer os.RemoveAll(tmp)
	if err := r.d.Checkpoints.Restore(ctx, ref, tmp); err != nil {
		return fmt.Errorf("materialize %s: restore: %w", res.ID, err)
	}
	if err := r.d.Git.ImportResolution(ctx, tmp, res.SourceDir); err != nil {
		return fmt.Errorf("materialize %s: import: %w", res.ID, err)
	}
	return r.d.Registry.MarkMaterialized(ctx, res.ID, committed)
}

// RestoreBuiltIn restores the latest committed checkpoint into the resource's
// own private WorkDir only — never the gather staging, parent or a task dir.
func (r *resolutionResources) RestoreBuiltIn(ctx context.Context, resourceID uuid.UUID, dir string) error {
	stored, err := r.d.Registry.GetResolution(ctx, resourceID)
	if err != nil {
		return err
	}
	if filepath.Clean(dir) != stored.WorkDir {
		return fmt.Errorf("restore resolution %s: %q is not its private work dir", resourceID, dir)
	}
	ref, ok, err := r.d.Checkpoints.Latest(ctx, resourceID)
	if err != nil {
		return err
	}
	if !ok {
		return fmt.Errorf("restore resolution %s: %w", resourceID, engine.ErrResolutionNotCommitted)
	}
	return r.d.Checkpoints.Restore(ctx, ref, stored.WorkDir)
}

func (r *resolutionResources) GetResolution(ctx context.Context, id uuid.UUID) (engine.ResolutionResource, error) {
	return r.d.Registry.GetResolution(ctx, id)
}

func (r *resolutionResources) CloseResolution(ctx context.Context, id uuid.UUID) error {
	return r.d.Registry.CloseResolution(ctx, id)
}

// parseResolutionCheckpointRef parses CheckpointRef.String()
// ("<uuid>@<version>:<manifestHash>"). If P3 T2 exports a parser, use it
// instead and delete this helper.
func parseResolutionCheckpointRef(s string) (CheckpointRef, error) {
	at := strings.IndexByte(s, '@')
	colon := strings.LastIndexByte(s, ':')
	if at <= 0 || colon <= at {
		return CheckpointRef{}, fmt.Errorf("malformed checkpoint ref %q", s)
	}
	id, err := uuid.Parse(s[:at])
	if err != nil {
		return CheckpointRef{}, err
	}
	v, err := strconv.ParseInt(s[at+1:colon], 10, 64)
	if err != nil || v < 1 {
		return CheckpointRef{}, fmt.Errorf("malformed checkpoint version in %q", s)
	}
	return CheckpointRef{RunID: id, Version: v, ManifestHash: s[colon+1:]}, nil
}

import (

)

const (
	ResourceKindWorkspace  = "workspace"
	ResourceKindResolution = "resolution"
)

// ErrMissingResourceDescriptor: a resource-scoped job without a valid
// descriptor must never launch.
var ErrMissingResourceDescriptor = errors.New("runner: job has no valid resource descriptor")

// ResourceDescriptor names the resource a job mutates. Fence and
// CheckpointRef are filled by the dispatcher's P3 workspace attempt (resource
// lease claim on Fence.Key) and P4 T12 transfer; the source staging directory
// is never part of it.
type ResourceDescriptor struct {
	ID            uuid.UUID
	Kind          string
	WorkDir       string
	Fence         engine.ResourceFenceRef
	CheckpointRef string
}

// ResolutionDescriptor is the job descriptor of a resolution resource.
func ResolutionDescriptor(r engine.ResolutionResource) *ResourceDescriptor {
	return &ResourceDescriptor{ID: r.ID, Kind: ResourceKindResolution, WorkDir: r.WorkDir}
}

// Validate rejects a missing or incomplete descriptor. A set Fence must be valid.
func (d *ResourceDescriptor) Validate() error {
	if d == nil {
		return ErrMissingResourceDescriptor
	}
	if d.ID == uuid.Nil || (d.Kind != ResourceKindWorkspace && d.Kind != ResourceKindResolution) || !filepath.IsAbs(d.WorkDir) {
		return fmt.Errorf("%w: id/kind/workdir", ErrMissingResourceDescriptor)
	}
	if d.Fence != (engine.ResourceFenceRef{}) {
		if err := d.Fence.Validate(); err != nil {
			return fmt.Errorf("%w: %v", ErrMissingResourceDescriptor, err)
		}
	}
	return nil
}

// WorkspaceResourceID is the resource the dispatcher's P3 workspace attempt
// (BeginAttempt/FinishSuccess, checkpoint and resource lease) must use:
// the descriptor's resource when present, else the run's workspace.
func WorkspaceResourceID(er ExecRequirements, job StepJob) uuid.UUID {
	if job.Resource != nil {
		return job.Resource.ID
	}
	return er.RunID
}

// PinForResolution reads the pin of the exact resolution session: same session
// invocation AND same (group run, merge, attempt); newest generation wins.
func (r *SessionPinRepo) PinForResolution(ctx context.Context, invocationID uuid.UUID, id engine.GroupResolutionIdentity) (runner.RunnerID, bool, error) {
	var pin sql.NullString
	err := r.execs.db.QueryRowContext(ctx, `SELECT session_pin_runner FROM node_executions
WHERE session_invocation_id = ?
  AND json_extract(llm_conversation, '$.kind') = 'group_resolution'
  AND json_extract(llm_conversation, '$.groupRunId') = ?
  AND CAST(json_extract(llm_conversation, '$.mergeIndex') AS INTEGER) = ?
  AND CAST(json_extract(llm_conversation, '$.attempt') AS INTEGER) = ?
ORDER BY session_generation DESC, started_at DESC, rowid DESC LIMIT 1`,
		uuidToString(invocationID), id.GroupRunID.String(), id.MergeIndex, id.Attempt).Scan(&pin)
	if errors.Is(err, sql.ErrNoRows) {
		return "", false, nil
	}
	if err != nil {
		return "", false, fmt.Errorf("resolution session pin: %w", err)
	}
	if !pin.Valid || pin.String == "" {
		return "", false, nil
	}
	return runner.RunnerID(pin.String), true, nil
}

func requireCurrentAttempt(ctx context.Context, groups instance.GroupRunRepository, id GroupResolutionIdentity) error {
	run, err := groups.Get(ctx, id.GroupRunID)

// ResumeFirstTurn re-runs an interrupted resolution first turn from its
// durable intent: it reloads the group run, parent, gather handle and attempt,
// then StartResolution reuses the pending intent's exact prompt and nonce.
func (b *GroupResolutionBridge) ResumeFirstTurn(ctx context.Context, in TurnIntent) error {
	var gid uuid.UUID
	var merge, attempt int
	if in.Kind != TurnIntentFirst || !strings.HasPrefix(in.LeaseKey, "resolution:") {
		return fmt.Errorf("group resolution: intent %s is not a resolution first turn", in.ID)
	}
	parts := strings.Split(strings.TrimPrefix(in.LeaseKey, "resolution:"), "/")
	if len(parts) != 3 {
		return fmt.Errorf("group resolution: malformed lease key %q", in.LeaseKey)
	}
	var err error
	if gid, err = uuid.Parse(parts[0]); err != nil {
		return err
	}
	if merge, err = strconv.Atoi(parts[1]); err != nil {
		return err
	}
	if attempt, err = strconv.Atoi(parts[2]); err != nil {
		return err
	}
	run, err := b.groups.Get(ctx, gid)
	if err != nil || run == nil || run.Gather == nil {
		return fmt.Errorf("group resolution: resume %s: %w", in.ID, ErrObsoleteResolutionAttempt)
	}
	handle, ok := GatherHandleFromReport(run.Gather)
	if !ok {
		return fmt.Errorf("group resolution: resume %s: no staged gather", in.ID)
	}
	parent, err := b.instances.Get(ctx, run.ParentInstanceID)
	if err != nil {
		return err
	}
	for _, a := range run.Gather.Attempts {
		if a.MergeIndex == merge && a.Attempt == attempt && a.EndedAt == nil {
			_, err := b.StartResolution(ctx, run, parent, ResolutionRequest{Handle: handle, MergeIndex: merge, Attempt: attempt,
				TaskKey: a.TaskKey, ConflictPaths: a.ConflictPaths})
			return err
		}
	}
	return fmt.Errorf("group resolution: resume %s: %w", in.ID, ErrObsoleteResolutionAttempt)
}
