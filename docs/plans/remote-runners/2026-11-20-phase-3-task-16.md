# Remote Runners — Phase 3 Task 16: Local checkpoints for non-portable homes (RR-17 decision B)

## Decision being implemented — RR-17: B (2026-11-22)

RR-08 (P3 T2) gives a repository with missing promisor objects a **non-portable home** (`Home.NonPortableReason`, `HomeStore.SetNonPortable`), pinned to the built-in runner and never fetched over the network. Alone, that left the home with no last-successful checkpoint, so PoolRecovery could not restore it (contracts §24, formerly UNRESOLVED DEPENDENCY RR-17). The human chose **option B**:

- A non-portable home takes a **local checkpoint** at the same point where a portable home takes its checkpoint: after each workspace-changing step completes, and before the step is committed. A node is not done until its checkpoint lands. The checkpoint is a plain copy of the home's directory on the server's own disk. No portable-Git materialization is done, because these homes never leave the built-in runner.
- The copy is staged as a **prepared** local checkpoint. It becomes the recovery base only inside the same P3 T5 step transaction that commits the step's result (`workspace_homes.local_checkpoint`). A failed copy produces no receipt, so the step is not done.
- PoolRecovery restores a non-portable home from its latest committed local checkpoint and re-runs the interrupted step, exactly as it does for a portable home. The same ledger generation and resource fences apply, and the same `BuiltInRestorer` port (`WorkspaceSync.RestoreBuiltIn`) is used.
- **Retention:** each home keeps only its latest committed local checkpoint, plus the in-progress one until it commits atomically.
- **No local checkpoint yet** (for example, a crash on the first step): recovery restores the home's initial state if one exists. That is either the local baseline taken by `EnsureBaseline` for a run that was non-portable from the start, or the last committed portable checkpoint for a home that became non-portable mid-run. If neither exists, recovery fails closed with `ErrNoRecoveryBase`, and P3 T10 shows it as the visible recovery blocker.

This task is authoritative over every earlier "Recovery acceptance blocker — RR-17" paragraph and over the "sets `dirty = 1`" rule in P3 T5's RR-08 amendment.

**Goal:** Non-portable (partial-clone) homes become recoverable. Every completed workspace-changing step on such a home commits a server-local copy of the working directory. The copy is written atomically through a temp directory and rename, and only the latest one is retained. Restart recovery restores that copy and repeats the interrupted step under the existing fences. When no base exists at all, recovery reports a durable, visible blocker.

**Architecture:** Hexagonal, extending the existing Phase 3 checkpoint vocabulary rather than adding a parallel service.
- The domain port `runner.LocalCheckpointStore` sits next to `CheckpointStore` in `domain/runner/checkpoint.go`, with `runner.LocalCheckpointRef` and `runner.ErrNoRecoveryBase`. Its adapter `checkpoint.LocalStore` (`adapter/checkpoint/local.go`) lives in the same package as `checkpoint.Store` and `checkpoint.BundleStore`, rooted at `<cfg.Runners.CheckpointDir>/local`. This mirrors how the bundle store is rooted at `<CheckpointDir>/bundles`.
- The domain service `runner.LocalCheckpoints` (`domain/runner/local_checkpoint.go`) holds the policy: take, bootstrap, restore and fallback. `WorkspaceSync` (P3 T6) and `BaselineInitializer` (P3 T6) delegate to it, so `PoolRecovery` keeps using the unchanged `BuiltInRestorer` port.
- Commit is the existing P3 T5 step transaction. `engine.WorkspaceCompletion` gains `LocalRef`, and `StepCommitRepo` promotes it into `workspace_homes.local_checkpoint`.
- Retention after commit uses a `StepCommitter` decorator, `runner.LocalCheckpointRetention`.
- Wiring is added in the composition root `cmd/arbitron/runner_mobility.go:buildWorkspaceMobility` and `main.go`, which P3 T13 created.

**Tech Stack:** Go 1.25.5, stdlib `os`/`io/fs`/`path/filepath`/`crypto/sha256`/`encoding/json`, `github.com/google/uuid`, testify, SQLite migration 044 (extended, no new number), the P3 T13 phase-root harness (`bootP3Stack`, `crashAndRestart`).

```go
// LocalCheckpointRef identifies a plain server-disk copy of a NON-PORTABLE
// home (RR-17 decision B, P3 T16). It never names a catalog artifact and is
// never pulled, pushed or restored on another runner.
type LocalCheckpointRef struct {
	RunID        uuid.UUID
	Version      int64
	ManifestHash string
}

const localCheckpointRefPrefix = "local:"

func (r LocalCheckpointRef) IsZero() bool {
	return r.RunID == uuid.Nil && r.Version == 0 && r.ManifestHash == ""
}

func (r LocalCheckpointRef) String() string {
	if r.IsZero() {
		return ""
	}
	return fmt.Sprintf("%s%s@%d:%s", localCheckpointRefPrefix, r.RunID, r.Version, r.ManifestHash)
}

// ParseLocalCheckpointRef is the exact inverse of String.
func ParseLocalCheckpointRef(s string) (LocalCheckpointRef, error) {
	bad := fmt.Errorf("runner: malformed local checkpoint ref %q", s)
	rest, ok := strings.CutPrefix(s, localCheckpointRefPrefix)
	if !ok {
		return LocalCheckpointRef{}, bad
	}
	runPart, tail, ok := strings.Cut(rest, "@")
	if !ok {
		return LocalCheckpointRef{}, bad
	}
	verPart, hash, ok := strings.Cut(tail, ":")
	if !ok || hash == "" || strings.Trim(hash, "0123456789abcdef") != "" {
		return LocalCheckpointRef{}, bad
	}
	run, err := uuid.Parse(runPart)
	if err != nil || run == uuid.Nil {
		return LocalCheckpointRef{}, bad
	}
	v, err := strconv.ParseInt(verPart, 10, 64)
	if err != nil || v < 1 {
		return LocalCheckpointRef{}, bad
	}
	return LocalCheckpointRef{RunID: run, Version: v, ManifestHash: hash}, nil
}

// LocalCheckpointStore keeps server-local copies of non-portable homes. Staging
// prepares only; the P3 T5 step transaction (or HomeStore.BootstrapLocalCheckpoint
// for the initial state) makes a ref the committed recovery base.
type LocalCheckpointStore interface {
	StageLocal(ctx context.Context, runID uuid.UUID, srcDir string, version int64) (LocalCheckpointRef, error)
	RestoreLocal(ctx context.Context, ref LocalCheckpointRef, dstDir string) error
	PruneLocal(ctx context.Context, runID uuid.UUID, keep LocalCheckpointRef) error
	Delete(ctx context.Context, runID uuid.UUID) error
}

// ErrNoRecoveryBase: a non-portable home has neither a committed local
// checkpoint nor an initial state to roll back to. P3 T10 turns it into the
// durable recovery blocker; nothing may re-run the step on the dirty copy.
var ErrNoRecoveryBase = errors.New("runner: no recoverable checkpoint for this workspace")
```

```go
type lsFile struct {
	body string
	mode os.FileMode
	link string // non-empty: a symlink to this target
}

func lsWrite(t *testing.T, root string, files map[string]lsFile, emptyDirs ...string) {
	t.Helper()
	for rel, f := range files {
		p := filepath.Join(root, filepath.FromSlash(rel))
		require.NoError(t, os.MkdirAll(filepath.Dir(p), 0o700))
		if f.link != "" {
			require.NoError(t, os.Symlink(f.link, p))
			continue
		}
		require.NoError(t, os.WriteFile(p, []byte(f.body), f.mode))
		require.NoError(t, os.Chmod(p, f.mode))
	}
	for _, d := range emptyDirs {
		require.NoError(t, os.MkdirAll(filepath.Join(root, d), 0o700))
	}
}

// lsRead returns rel -> "body|mode" or "-> target" for every non-directory entry.
func lsRead(t *testing.T, root string) map[string]string {
	t.Helper()
	out := map[string]string{}
	require.NoError(t, filepath.WalkDir(root, func(p string, d os.DirEntry, err error) error {
		require.NoError(t, err)
		rel, _ := filepath.Rel(root, p)
		info, err := d.Info()
		require.NoError(t, err)
		switch {
		case info.Mode()&os.ModeSymlink != 0:
			l, err := os.Readlink(p)
			require.NoError(t, err)
			out[filepath.ToSlash(rel)] = "-> " + l
		case info.Mode().IsRegular():
			b, err := os.ReadFile(p)
			require.NoError(t, err)
			out[filepath.ToSlash(rel)] = string(b) + "|" + info.Mode().Perm().String()
		}
		return nil
	}))
	return out
}

func lsVersions(t *testing.T, dir string, run uuid.UUID) []string {
	t.Helper()
	es, err := os.ReadDir(filepath.Join(dir, run.String()))
	if errors.Is(err, os.ErrNotExist) {
		return nil
	}
	require.NoError(t, err)
	var names []string
	for _, e := range es {
		names = append(names, e.Name())
	}
	sort.Strings(names)
	return names
}

// Happy path: the copy round-trips bytes, modes, symlinks (not followed),
// promisor Git metadata verbatim and empty directories.
func TestLocalStore_RoundTripPreservesTheHomeVerbatim(t *testing.T) {
	ctx := context.Background()
	store := checkpoint.NewLocalStore(t.TempDir())
	ws := filepath.Join(t.TempDir(), "ws")
	lsWrite(t, ws, lsFixture(), "empty")
	want := lsRead(t, ws)
	run := uuid.New()

	ref, err := store.StageLocal(ctx, run, ws, 1)
	require.NoError(t, err)
	assert.Equal(t, run, ref.RunID)
	assert.Equal(t, int64(1), ref.Version)
	assert.NotEmpty(t, ref.ManifestHash)

	// the failed/next step dirties the copy
	require.NoError(t, os.WriteFile(filepath.Join(ws, "a.txt"), []byte("half-written"), 0o644))
	require.NoError(t, os.Remove(filepath.Join(ws, "bin", "run.sh")))
	require.NoError(t, os.WriteFile(filepath.Join(ws, "junk.txt"), []byte("x"), 0o600))

	require.NoError(t, store.RestoreLocal(ctx, ref, ws))
	assert.Equal(t, want, lsRead(t, ws), "SINK: the restored home is byte- and mode-identical to the checkpoint")
	assert.DirExists(t, filepath.Join(ws, "empty"))
	siblings, err := os.ReadDir(filepath.Dir(ws))
	require.NoError(t, err)
	assert.Len(t, siblings, 1, "no restore staging or swapped-out copy is left next to the workspace")
}
```

```go
package checkpoint

import (
	"context"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"

	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

// Layout under dir (production: <cfg.Runners.CheckpointDir>/local):
//
//	<runID>/v<version:020>-<manifestHash>/manifest.json   committed or prepared copy
//	<runID>/v<version:020>-<manifestHash>/tree/...        the home's files
//	<runID>/.staging-*                                    in-progress copy (never restored)
//
// A version directory appears only by an atomic rename of a fully written and
// fsynced staging directory, so a crash leaves either nothing or a complete
// copy. Which version is the recovery base is decided by the database
// (workspace_homes.local_checkpoint), never by directory listing.
const (
	localTreeDir       = "tree"
	localManifestFile  = "manifest.json"
	localStagingPrefix = ".staging-"
)

// LocalStore implements runner.LocalCheckpointStore with plain copies on the
// server's disk for NON-PORTABLE homes (RR-17 decision B). Unlike Store it does
// no tar/gzip and no portable-Git materialization: these copies never leave
// the built-in runner.
type LocalStore struct {
	dir    string
	create func(path string, perm os.FileMode) (io.WriteCloser, error)
}

type LocalOption func(*LocalStore)

// WithLocalFileCreator replaces file creation (tests inject disk-full).
func WithLocalFileCreator(fn func(path string, perm os.FileMode) (io.WriteCloser, error)) LocalOption {
	return func(s *LocalStore) { s.create = fn }
}

func NewLocalStore(dir string, opts ...LocalOption) *LocalStore {
	s := &LocalStore{dir: dir, create: createSyncedFile}
	for _, o := range opts {
		o(s)
	}
	return s
}

var _ runner.LocalCheckpointStore = (*LocalStore)(nil)

type syncedFile struct{ *os.File }

func (f syncedFile) Close() error {
	if err := f.File.Sync(); err != nil {
		_ = f.File.Close()
		return err
	}
	return f.File.Close()
}

func createSyncedFile(path string, perm os.FileMode) (io.WriteCloser, error) {
	f, err := os.OpenFile(path, os.O_WRONLY|os.O_CREATE|os.O_EXCL, perm)
	if err != nil {
		return nil, err
	}
	return syncedFile{f}, nil
}

func syncDir(path string) error {
	d, err := os.Open(path)
	if err != nil {
		return err
	}
	defer d.Close()
	return d.Sync()
}

func (s *LocalStore) runDir(runID uuid.UUID) string { return filepath.Join(s.dir, runID.String()) }

func localVersionDir(ref runner.LocalCheckpointRef) string {
	return fmt.Sprintf("v%020d-%s", ref.Version, ref.ManifestHash)
}

func (s *LocalStore) StageLocal(ctx context.Context, runID uuid.UUID, srcDir string, version int64) (runner.LocalCheckpointRef, error) {
	if runID == uuid.Nil || version < 1 {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: local stage of run %s version %d: invalid identity", runID, version)
	}
	runDir := s.runDir(runID)
	if err := os.MkdirAll(runDir, 0o700); err != nil {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: local stage of run %s: %w", runID, err)
	}
	staging, err := os.MkdirTemp(runDir, localStagingPrefix)
	if err != nil {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: local stage of run %s: %w", runID, err)
	}
	published := false
	defer func() {
		if !published {
			_ = os.RemoveAll(staging)
		}
	}()
	entries, err := copyTree(ctx, srcDir, filepath.Join(staging, localTreeDir), s.create)
	if err != nil {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: local copy of run %s: %w", runID, err)
	}
	m := runner.NewManifest(version, entries)
	if err := writeLocalManifest(filepath.Join(staging, localManifestFile), m, s.create); err != nil {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: local manifest of run %s: %w", runID, err)
	}
	if err := syncDir(staging); err != nil {
		return runner.LocalCheckpointRef{}, err
	}
	ref := runner.LocalCheckpointRef{RunID: runID, Version: version, ManifestHash: m.Hash}
	final := filepath.Join(runDir, localVersionDir(ref))
	if _, err := os.Stat(final); err == nil {
		return ref, nil // identical bytes at this version already prepared: idempotent retry
	}
	if err := os.Rename(staging, final); err != nil {
		return runner.LocalCheckpointRef{}, fmt.Errorf("checkpoint: publish local copy of run %s: %w", runID, err)
	}
	published = true
	if err := syncDir(runDir); err != nil {
		return runner.LocalCheckpointRef{}, err
	}
	return ref, nil
}

func (s *LocalStore) RestoreLocal(ctx context.Context, ref runner.LocalCheckpointRef, dstDir string) error {
	if ref.IsZero() {
		return fmt.Errorf("checkpoint: restore of an empty local ref: %w", runner.ErrCheckpointNotFound)
	}
	versionDir := filepath.Join(s.runDir(ref.RunID), localVersionDir(ref))
	m, err := readLocalManifest(filepath.Join(versionDir, localManifestFile))
	if errors.Is(err, fs.ErrNotExist) {
		return fmt.Errorf("checkpoint: local %s: %w", ref, runner.ErrCheckpointNotFound)
	}
	if err != nil {
		return fmt.Errorf("checkpoint: local %s: %w: %w", ref, runner.ErrCorruptCheckpoint, err)
	}
	if m.Version != ref.Version || m.Hash != ref.ManifestHash || m.Verify() != nil {
		return fmt.Errorf("checkpoint: local %s: manifest mismatch: %w", ref, runner.ErrCorruptCheckpoint)
	}
	parent := filepath.Dir(dstDir)
	if err := os.MkdirAll(parent, 0o700); err != nil {
		return err
	}
	staging, err := os.MkdirTemp(parent, "."+filepath.Base(dstDir)+".restore-")
	if err != nil {
		return err
	}
	swapped := false
	defer func() {
		if !swapped {
			_ = os.RemoveAll(staging)
		}
	}()
	entries, err := copyTree(ctx, filepath.Join(versionDir, localTreeDir), staging, s.create)
	if errors.Is(err, fs.ErrNotExist) {
		return fmt.Errorf("checkpoint: local %s: tree missing: %w", ref, runner.ErrCorruptCheckpoint)
	}
	if err != nil {
		return fmt.Errorf("checkpoint: restore local %s: %w", ref, err)
	}
	if got := runner.NewManifest(ref.Version, entries); got.Hash != ref.ManifestHash {
		return fmt.Errorf("checkpoint: local %s: restored bytes differ from the manifest: %w", ref, runner.ErrCorruptCheckpoint)
	}
	// Swap at the ownership boundary: the caller holds the run's resource claim
	// and the old writer is stopped (P3 T10), so nothing writes dstDir now.
	old := ""
	if _, err := os.Lstat(dstDir); err == nil {
		old = staging + ".old"
		if err := os.Rename(dstDir, old); err != nil {
			return fmt.Errorf("checkpoint: restore local %s: %w", ref, err)
		}
	} else if !errors.Is(err, fs.ErrNotExist) {
		return err
	}
	if err := os.Rename(staging, dstDir); err != nil {
		if old != "" {
			_ = os.Rename(old, dstDir)
		}
		return fmt.Errorf("checkpoint: restore local %s: %w", ref, err)
	}
	swapped = true
	if old != "" {
		_ = os.RemoveAll(old)
	}
	return syncDir(parent)
}

func (s *LocalStore) PruneLocal(_ context.Context, runID uuid.UUID, keep runner.LocalCheckpointRef) error {
	if !keep.IsZero() && keep.RunID != runID {
		return fmt.Errorf("checkpoint: prune run %s keeping %s: run mismatch", runID, keep)
	}
	runDir := s.runDir(runID)
	entries, err := os.ReadDir(runDir)
	if errors.Is(err, fs.ErrNotExist) {
		return nil
	}
	if err != nil {
		return err
	}
	keepName := ""
	if !keep.IsZero() {
		keepName = localVersionDir(keep)
	}
	var errs []error
	for _, e := range entries {
		if e.Name() == keepName {
			continue
		}
		if err := os.RemoveAll(filepath.Join(runDir, e.Name())); err != nil {
			errs = append(errs, err)
		}
	}
	return errors.Join(errs...)
}

func (s *LocalStore) Delete(_ context.Context, runID uuid.UUID) error {
	return os.RemoveAll(s.runDir(runID))
}

// copyTree copies src into dst without following symlinks, fsyncing every file
// and directory, and returns the manifest entries of the regular files and
// symlinks it copied. Directories keep their permission bits plus owner rwx
// (so retention can always delete them); file modes are exact.
func copyTree(ctx context.Context, src, dst string, create func(string, os.FileMode) (io.WriteCloser, error)) ([]runner.ManifestEntry, error) {
	var entries []runner.ManifestEntry
	var dirs []string
	err := filepath.WalkDir(src, func(path string, d fs.DirEntry, walkErr error) error {
		if walkErr != nil {
			return walkErr
		}
		if err := ctx.Err(); err != nil {
			return err
		}
		rel, err := filepath.Rel(src, path)
		if err != nil {
			return err
		}
		target := filepath.Join(dst, rel)
		info, err := d.Info()
		if err != nil {
			return err
		}
		slashRel := filepath.ToSlash(rel)
		mode := info.Mode()
		switch {
		case mode.IsDir():
			if err := os.MkdirAll(target, 0o700); err != nil {
				return err
			}
			if err := os.Chmod(target, mode.Perm()|0o700); err != nil {
				return err
			}
			dirs = append(dirs, target)
			return nil
		case mode&fs.ModeSymlink != 0:
			link, err := os.Readlink(path)
			if err != nil {
				return err
			}
			e, err := runner.EntryFromInfo(slashRel, info, "", link)
			if err != nil {
				return err
			}
			if err := os.Symlink(link, target); err != nil {
				return err
			}
			entries = append(entries, e)
			return nil
		case mode.IsRegular():
			sum, err := copyRegular(path, target, mode.Perm(), create)
			if err != nil {
				return err
			}
			e, err := runner.EntryFromInfo(slashRel, info, sum, "")
			if err != nil {
				return err
			}
			entries = append(entries, e)
			return nil
		default:
			return fmt.Errorf("%s: %w", slashRel, runner.ErrUnsupportedFileType)
		}
	})
	if err != nil {
		return nil, err
	}
	for i := len(dirs) - 1; i >= 0; i-- {
		if err := syncDir(dirs[i]); err != nil {
			return nil, err
		}
	}
	return entries, nil
}

func copyRegular(src, dst string, perm fs.FileMode, create func(string, os.FileMode) (io.WriteCloser, error)) (string, error) {
	in, err := os.Open(src)
	if err != nil {
		return "", err
	}
	defer in.Close()
	out, err := create(dst, perm)
	if err != nil {
		return "", err
	}
	h := sha256.New()
	if _, err := io.Copy(io.MultiWriter(out, h), in); err != nil {
		_ = out.Close()
		return "", err
	}
	if err := out.Close(); err != nil {
		return "", err
	}
	if err := os.Chmod(dst, perm); err != nil { // creation is umask-filtered
		return "", err
	}
	return hex.EncodeToString(h.Sum(nil)), nil
}

func writeLocalManifest(path string, m runner.Manifest, create func(string, os.FileMode) (io.WriteCloser, error)) error {
	b, err := json.Marshal(m)
	if err != nil {
		return err
	}
	w, err := create(path, 0o600)
	if err != nil {
		return err
	}
	if _, err := w.Write(b); err != nil {
		_ = w.Close()
		return err
	}
	return w.Close()
}

func readLocalManifest(path string) (runner.Manifest, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return runner.Manifest{}, err
	}
	var m runner.Manifest
	if err := json.Unmarshal(b, &m); err != nil {
		return runner.Manifest{}, err
	}
```

```go
func (r *WorkspaceHomeRepo) BootstrapLocalCheckpoint(ctx context.Context, runID uuid.UUID, ref string) error {
	parsed, err := runner.ParseLocalCheckpointRef(ref)
	if err != nil {
		return err
	}
	if parsed.RunID != runID || parsed.Version != 1 {
		return fmt.Errorf("sqlite: local baseline %s for run %s: %w", ref, runID, runner.ErrCheckpointConflict)
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return err
	}
	defer func() { _ = tx.Rollback() }()
	var cur, reason string
	err = tx.QueryRowContext(ctx,
		`SELECT local_checkpoint, non_portable_reason FROM workspace_homes WHERE run_id = ?`, runID.String()).Scan(&cur, &reason)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && reason == "") {
		return fmt.Errorf("sqlite: local baseline for run %s: home is portable", runID)
	}
	if err != nil {
		return err
	}
	if cur == ref {
		return tx.Commit()
	}
	if cur != "" {
		return fmt.Errorf("sqlite: local baseline for run %s already %s: %w", runID, cur, runner.ErrCheckpointConflict)
	}
	var active int
	if err := tx.QueryRowContext(ctx,
		`SELECT COUNT(*) FROM workspace_leases WHERE resource_key = ? AND active = 1`, "run:"+runID.String()).Scan(&active); err != nil {
		return err
	}
	if active > 0 {
		return fmt.Errorf("sqlite: local baseline for run %s: an active writer holds the workspace: %w", runID, runner.ErrCheckpointConflict)
	}
	if _, err := tx.ExecContext(ctx,
		`UPDATE workspace_homes SET local_checkpoint = ?, dirty = 0 WHERE run_id = ?`, ref, runID.String()); err != nil {
		return err
	}
	return tx.Commit()
```

```go
import (
	"context"
```

```go
// LocalCheckpointDeps are the ports the non-portable checkpoint policy needs.
type LocalCheckpointDeps struct {
	Local       LocalCheckpointStore
	Homes       HomeStore
	Checkpoints CheckpointStore
	Leases      ResourceLeaseStore
}

// LocalCheckpoints is the RR-17 decision B policy for non-portable homes:
// every completed step stages a local copy (committed by the step
// transaction), recovery restores the newest committed base, and a missing
// base is ErrNoRecoveryBase.
type LocalCheckpoints struct{ d LocalCheckpointDeps }

func NewLocalCheckpoints(d LocalCheckpointDeps) (*LocalCheckpoints, error) {
	var missing []string
	if d.Local == nil {
		missing = append(missing, "Local")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if d.Checkpoints == nil {
		missing = append(missing, "Checkpoints")
	}
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: local checkpoints: missing %s", strings.Join(missing, ", "))
	}
	return &LocalCheckpoints{d: d}, nil
}

func committedLocal(h Home) (LocalCheckpointRef, error) {
	if h.LocalCheckpoint == "" {
		return LocalCheckpointRef{}, nil
	}
	return ParseLocalCheckpointRef(h.LocalCheckpoint)
}

// Take stages the completed step's working directory as the successor of the
// committed local copy. It returns a PREPARED ref; only the step transaction
// makes it the recovery base. Any error means the step has no receipt.
func (l *LocalCheckpoints) Take(ctx context.Context, runID uuid.UUID, dir string, resource engine.ResourceFenceRef) (LocalCheckpointRef, error) {
	if err := l.d.Leases.Check(ctx, resource); err != nil {
		return LocalCheckpointRef{}, fmt.Errorf("runner: local checkpoint of run %s: %w", runID, err)
	}
	home, err := l.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return LocalCheckpointRef{}, err
	}
	if home.NonPortableReason == "" {
		return LocalCheckpointRef{}, fmt.Errorf("runner: local checkpoint of run %s: home is portable", runID)
	}
	cur, err := committedLocal(home)
	if err != nil {
		return LocalCheckpointRef{}, err
	}
	if err := l.d.Local.PruneLocal(ctx, runID, cur); err != nil {
		return LocalCheckpointRef{}, fmt.Errorf("runner: reclaim local checkpoints of run %s: %w", runID, err)
	}
	ref, err := l.d.Local.StageLocal(ctx, runID, dir, cur.Version+1)
	if err != nil {
		return LocalCheckpointRef{}, fmt.Errorf("runner: local checkpoint of non-portable run %s: %w", runID, err)
	}
	return ref, nil
}

// Bootstrap commits the initial local copy of a run that is non-portable from
// its first preparation (EnsureBaseline, before any job or claim exists).
func (l *LocalCheckpoints) Bootstrap(ctx context.Context, runID uuid.UUID, dir string) error {
	home, err := l.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return err
	}
	if home.LocalCheckpoint != "" {
		return nil // never re-snapshot a committed base
	}
	if home.NonPortableReason == "" {
		return fmt.Errorf("runner: local baseline of run %s: home is portable", runID)
	}
	ref, err := l.d.Local.StageLocal(ctx, runID, dir, 1)
	if err != nil {
		return fmt.Errorf("runner: local baseline of non-portable run %s: %w", runID, err)
	}
	if err := l.d.Homes.BootstrapLocalCheckpoint(ctx, runID, ref.String()); err != nil {
		if errors.Is(err, ErrCheckpointConflict) {
			if again, gerr := l.d.Homes.GetHome(ctx, runID); gerr == nil && again.LocalCheckpoint != "" {
				return nil // a concurrent initializer committed first; its base stands
			}
		}
		return fmt.Errorf("runner: record local baseline of run %s: %w", runID, err)
	}
	return nil
}

// Restore puts the newest committed base of a NON-PORTABLE home into dir:
// its committed local copy, else its initial state (the committed portable
// checkpoint it had before turning non-portable), else ErrNoRecoveryBase.
func (l *LocalCheckpoints) Restore(ctx context.Context, runID uuid.UUID, dir string) error {
	home, err := l.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return err
	}
	cur, err := committedLocal(home)
	if err != nil {
		return fmt.Errorf("%w: run %s: %w", ErrNoRecoveryBase, runID, err)
	}
	if !cur.IsZero() {
		if err := l.d.Local.RestoreLocal(ctx, cur, dir); err != nil {
			if errors.Is(err, ErrCheckpointNotFound) || errors.Is(err, ErrCorruptCheckpoint) {
				return fmt.Errorf("%w: run %s (%s): local checkpoint %s is unusable: %w",
					ErrNoRecoveryBase, runID, home.NonPortableReason, cur, err)
			}
			return fmt.Errorf("runner: restore local checkpoint %s: %w", cur, err)
		}
		// Retention only; the restore already succeeded. A failure here is
		// retried by the next Take.
		_ = l.d.Local.PruneLocal(ctx, runID, cur)
		return nil
	}
	ref, ok, err := l.d.Checkpoints.Latest(ctx, runID)
	if err != nil {
		return err
	}
	if ok {
		return l.d.Checkpoints.Restore(ctx, ref, dir)
	}
	return fmt.Errorf("%w: run %s (%s)", ErrNoRecoveryBase, runID, home.NonPortableReason)
}

// LocalCheckpointRetention decorates the durable step committer: after a
// commit succeeds it keeps only the newly committed local copy (or removes
// every local copy once a portable checkpoint is promoted). Retention is
// best-effort; it never fails a durable commit, and Take reclaims leftovers.
type LocalCheckpointRetention struct {
	inner engine.StepCommitter
	local LocalCheckpointStore
}

var _ engine.StepCommitter = (*LocalCheckpointRetention)(nil)

func NewLocalCheckpointRetention(inner engine.StepCommitter, local LocalCheckpointStore) (*LocalCheckpointRetention, error) {
	if inner == nil || local == nil {
		return nil, errors.New("runner: local checkpoint retention needs a step committer and a local store")
	}
	return &LocalCheckpointRetention{inner: inner, local: local}, nil
}

func (r *LocalCheckpointRetention) CommitStep(ctx context.Context, c engine.StepCommit) error {
	if err := r.inner.CommitStep(ctx, c); err != nil {
		return err
	}
	for _, comp := range c.Completions {
		w := comp.Workspace
		switch {
		case w == nil:
		case w.NonPortable:
			if ref, err := ParseLocalCheckpointRef(w.LocalRef); err == nil {
				_ = r.local.PruneLocal(ctx, ref.RunID, ref)
			}
		case w.Ref != "":
			_ = r.local.Delete(ctx, c.RunID)
		}
	}
	return nil
}

func (r *LocalCheckpointRetention) CommittedResult(ctx context.Context, invocationID uuid.UUID) (*engine.StepCommit, bool, error) {
	return r.inner.CommittedResult(ctx, invocationID)
}
```
