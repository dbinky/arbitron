# Remote Runners — Phase 2 Task 13: Fresh remote health and source-bound quota confirmation

**Goal:** An operator check measures the selected runner now, and an exhausted subscription returns automatically only after confirmation on that exact credential source. No server-local credential, old heartbeat, other same-family source or elapsed timer can make a remote source healthy.

**Architecture:**
- **Read-only remote checks.** `Hub.ProbeSource` (new `domain/runner/hub_probe.go`) sends a UUID-correlated `probe` to the source's current session, waits a bounded time for the exact reply, and stamps the reply with the revision captured in its pending entry. `RemoteSourceProber` (new `domain/runner/remote_prober.go`) adapts it to `SourceProber`; the existing `HealthMonitor.SetRemoteProber` installs it. Both operator `ProbeNow` and the monitor's periodic cadence use it, asynchronously, one in flight per source. A remote source is never probed with server credentials and never answered from cached health.
- **Heartbeat observations.** `SourceReport` gains `Observation *ProbeResult`, `ObservationSeq`, `SampleAgeMs`. The hub drops `applyReportedHealth` (direct `RecordHealth` plus the mutually exclusive auth/exhaustion switch). Only fresh, ordered, bounded-age observations reach `HealthMonitor.ObserveProbe`, and an uncorrelated heartbeat can never recover capacity.
- **Native confirmation.** New `OpConfirm` operation. `DispatchConfirmer` dispatches it through the normal dispatcher: slot-counted, `RequiredSource` + `PinnedRunner`, `AffinityNone`. The built-in runner and the remote runner executor run it with `HarnessConfirmationExecutor` (new `adapter/runner/probe/execution.go`). That executor clones an agent-kind binding and calls the adapter's existing `ProbeExecutedModel` (claudecli/codex). It never calls `RunAgent`. Only exact requested == executed model evidence counts.

**Tech Stack:** Go 1.25, testify, real SQLite (`adapter/runner/hubtest`), real WebSocket/root fixtures.

import (

// OpConfirm is the token-spending, source-bound native quota confirmation. It
// is ordinary slot-counted execution, never a read-only probe.
const OpConfirm OpType = "confirm"

// ConfirmationPrompt is the fixed bounded prompt every native verifier gets.
const ConfirmationPrompt = "Reply with OK."

// ConfirmationRequest is the server-side execution descriptor. WorkDir is the
// built-in runner's scratch parent; remote runners replace it with their own.
type ConfirmationRequest struct{ WorkDir string }

// ConfirmationResult is the native harness's own evidence for one turn.
type ConfirmationResult struct{ RequestedModel, ExecutedModel, SessionID string }

// ConfirmationExecutor runs one native exact-model check for binding in workDir.
type ConfirmationExecutor interface {
	Confirm(ctx context.Context, binding provider.ResolvedBinding, workDir string) (ConfirmationResult, error)
}

var (
	ErrConfirmationNoProfile     = errors.New("runner: no authorized profile for the confirmation model")
	ErrConfirmationModelMismatch = errors.New("runner: confirmation did not prove the exact model")
)

// VerifyConfirmation accepts only exact native evidence for want.
func VerifyConfirmation(want string, res *ConfirmationResult) error {
	switch {
	case res == nil:
		return fmt.Errorf("%w: no evidence", ErrConfirmationModelMismatch)
	case want == "" || res.RequestedModel != want || res.ExecutedModel != want:
		return fmt.Errorf("%w: requested %q executed %q", ErrConfirmationModelMismatch, res.RequestedModel, res.ExecutedModel)
	case res.SessionID == "":
		return fmt.Errorf("%w: no harness session", ErrConfirmationModelMismatch)
	}
	return nil
}

// HarnessConfirmationExecutor runs a subscription source's native exact-model
// check through the inner (undecorated) agent selector. It builds an agent-kind
// clone of the binding and calls the adapter's ProbeExecutedModel, which keeps
// the adapter's own tool restrictions, bounded execution and local
// account/model evidence. It never calls RunAgent.
type HarnessConfirmationExecutor struct{ inner engine.AgentProviderSelector }

var _ runner.ConfirmationExecutor = (*HarnessConfirmationExecutor)(nil)

// NewConfirmationExecutor panics on a nil or typed-nil selector: a half-wired
// verifier would silently refuse every recovery.
func NewConfirmationExecutor(inner engine.AgentProviderSelector) *HarnessConfirmationExecutor {
	if isNilDep(inner) {
		panic("probe: NewConfirmationExecutor requires the inner agent selector")
	}
	return &HarnessConfirmationExecutor{inner: inner}
}

func isNilDep(v any) bool {
	if v == nil {
		return true
	}
	rv := reflect.ValueOf(v)
	switch rv.Kind() {
	case reflect.Pointer, reflect.Map, reflect.Slice, reflect.Func, reflect.Interface, reflect.Chan:
		return rv.IsNil()
	}

// probeRemoteNow performs one fresh correlated remote check. Errors never
// return cached health and never write health.
func (m *HealthMonitor) probeRemoteNow(ctx context.Context, s Source) (SourceHealth, error) {
	m.mu.Lock()
	prober := m.remote
	m.mu.Unlock()
	if prober == nil {
		return SourceHealth{}, &RemoteProbeError{Err: ErrRemoteProberNotWired}
	}
	res, err := prober.Probe(ctx, s)
	if err != nil {
		return SourceHealth{}, &RemoteProbeError{Err: err}
	}
	res.HealthRevision = s.Health.Revision // captured before I/O: the fence

// scheduleRemote starts the periodic remote check at the normal cadence, off
// the tick goroutine, one in flight per source, joined by Wait.
func (m *HealthMonitor) scheduleRemote(ctx context.Context, s Source, now time.Time) {
	m.mu.Lock()
	defer m.mu.Unlock()
	if m.remote == nil || m.remoteBusy[s.ID] {
		return
	}
	if last, ok := m.remoteAttempt[s.ID]; ok && now.Sub(last) < m.d.Interval {
		return
	}
	m.remoteAttempt[s.ID], m.remoteBusy[s.ID] = now, true
	m.wg.Add(1)
	go func() {
		defer m.wg.Done()
		defer func() { m.mu.Lock(); delete(m.remoteBusy, s.ID); m.mu.Unlock() }()
		if _, err := m.probeRemoteNow(ctx, s); err != nil && ctx.Err() == nil {
			slog.Debug("runner remote health check failed", "source", string(s.ID), "error", err)
		}
	}()
}

// noteProbation records why a probation source is still waiting (Detail is
// persisted and shown by REST/MCP; it is not a material transition).
func (m *HealthMonitor) noteProbation(ctx context.Context, id SourceID, detail string) {
	m.mu.Lock()
	defer m.mu.Unlock()
	cur, err := m.d.Registry.GetSource(ctx, id)
	if err != nil || cur.Health.Capacity != CapacityProbation {
		return
	}
	h := cur.Health
	h.Detail = detail
	_ = m.commit(ctx, cur, h, Cause{Kind: CauseSystem}, m.d.Clock())
}

func (m *HealthMonitor) finishConfirm(ctx context.Context, src Source, err error) {
	m.mu.Lock()
	delete(m.confirming, src.ID)
	m.mu.Unlock()
	if err == nil {
		_ = m.ApplyOutcome(ctx, src.ID, SourceOutcome{Class: OutcomeNone, Model: src.Health.ConfirmationModel})
		return
	}
	if o := ClassifyError(err); o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut {
		_ = m.ApplyOutcome(ctx, src.ID, o)
		return
	}
	m.noteProbation(ctx, src.ID, confirmationDetail(err))
}

	Model               string `json:"model"`
	Backend             string `json:"backend"`
	Provider            string `json:"provider"`
	EndpointFingerprint string `json:"endpointFingerprint,omitempty"`
	ContextWindow       string `json:"contextWindow,omitempty"`
	Effort              string `json:"effort,omitempty"`
}

func (c *WireConfirmation) Validate() error {
	for name, v := range map[string]string{"model": c.Model, "backend": c.Backend, "provider": c.Provider,
		"contextWindow": c.ContextWindow, "effort": c.Effort} {
		if len(v) > maxConfirmationField {
			return fmt.Errorf("confirmation.%s longer than %d bytes", name, maxConfirmationField)
		}
	}
	switch {
	case c.Model == "":
		return errors.New("confirmation.model is required (exact model, never substituted)")
	case c.Backend != "claude-code" && c.Backend != "codex":
		return fmt.Errorf("confirmation.backend %q has no native verifier", c.Backend)

			return errors.New("confirmation.endpointFingerprint must be SHA-256 hex")
		}
	}
	return nil

// DefaultRemoteProbeTimeout bounds one correlated read-only remote check.
const DefaultRemoteProbeTimeout = 10 * time.Second

type pendingProbe struct {
	runner   RunnerID
	serial   uint64
	source   SourceID
	kind     CredentialKind
	ref      string
	revision uint64
	sentAt   time.Time
	done     chan probeOutcome // buffered 1; written once under h.mu
}

type probeOutcome struct {
	res ProbeResult
	err error
}

type observationMark struct{ serial, seq uint64 }

// ProbeSource asks the owning runner's current session for a fresh read-only
// probe and waits for the exact correlated reply. It spends no tokens and no
// slot, and never returns cached health.
func (h *Hub) ProbeSource(ctx context.Context, id SourceID) (ProbeResult, error) {
	src, err := h.reg.GetSource(ctx, id)
	if err != nil {
		return ProbeResult{}, err
	}
	if src.RunnerID == BuiltInRunnerID || !remoteKind(src.Kind) {
		return ProbeResult{}, fmt.Errorf("%w: %s is not a remote source", ErrRemoteProbeUnavailable, id)
	}
	timeout := h.cfg.ProbeTimeout
	if timeout <= 0 {
		timeout = DefaultRemoteProbeTimeout
	}
	pctx, cancel := context.WithTimeout(ctx, timeout)
	defer cancel()
	reqID := uuid.New()
	h.mu.Lock()
	s := h.sessions[src.RunnerID]
	if h.closed || s == nil || h.revoked[src.RunnerID] {
		h.mu.Unlock()
		return ProbeResult{}, fmt.Errorf("%w: runner %s has no live session", ErrRemoteProbeUnavailable, src.RunnerID)
	}
	p := &pendingProbe{runner: src.RunnerID, serial: s.serial, source: id, kind: src.Kind, ref: src.CredentialRef,
		revision: src.Health.Revision, sentAt: h.now(), done: make(chan probeOutcome, 1)}
	h.probes[reqID] = p // registered before send
	h.mu.Unlock()
	defer h.dropProbe(reqID)
	msg := Outbound{Kind: MsgProbe, Probe: &ProbePayload{RequestID: reqID, HealthRevision: p.revision, SourceKind: src.Kind, CredentialRef: src.CredentialRef}}
	if err := s.conn.Send(pctx, msg); err != nil {
		return ProbeResult{}, fmt.Errorf("%w: send: %v", ErrRemoteProbeUnavailable, err)
	}
	select {
	case o := <-p.done:
		return o.res, o.err
	case <-pctx.Done():
		if ctx.Err() != nil {
			return ProbeResult{}, ctx.Err() // caller cancellation wins
		}
		return ProbeResult{}, ErrRemoteProbeTimeout
	}
}

// PendingProbes reports outstanding correlated checks.
func (h *Hub) PendingProbes() int {
	h.mu.Lock()
	defer h.mu.Unlock()
	return len(h.probes)
}

func (h *Hub) dropProbe(id uuid.UUID) {
	h.mu.Lock()
	defer h.mu.Unlock()
	delete(h.probes, id)
}

// failProbesLocked completes and removes every matching pending probe. Caller holds h.mu.
func (h *Hub) failProbesLocked(match func(*pendingProbe) bool, err error) {
	for id, p := range h.probes {
		if match(p) {
			p.done <- probeOutcome{err: err}
			delete(h.probes, id)
		}
	}
}

func (h *Hub) closeProbes() {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.closed = true
	h.failProbesLocked(func(*pendingProbe) bool { return true }, fmt.Errorf("%w: hub stopped", ErrRemoteProbeUnavailable))
}

// handleProbeResult fulfils only the exact pending request of this session
// with a sample taken after the request. Anything else is ignored.
func (h *Hub) handleProbeResult(ctx context.Context, s *Session, r *ProbeReply, now time.Time) error {
	if r == nil {
		return fmt.Errorf("%w: probe_result without payload", ErrMalformedMessage)
	}
	if err := validateSourceReports([]SourceReport{r.Source}); err != nil {
		return err
	}
	h.mu.Lock()
	defer h.mu.Unlock()
	p, ok := h.probes[r.RequestID]
	if !ok || p.runner != s.RunnerID || p.serial != s.serial || p.kind != r.Source.Kind ||
		p.ref != r.Source.CredentialRef || p.revision != r.HealthRevision {
		return nil // unsolicited, duplicate, wrong source/credential/revision
	}
	obs := r.Source.Observation
	var out probeOutcome
	if obs == nil {
		out.err = fmt.Errorf("%w: runner reported %q", ErrRemoteProbeUnavailable, r.Source.UnavailableReason)
	} else {
		age := time.Duration(r.Source.SampleAgeMs) * time.Millisecond
		if r.Source.SampleAgeMs < 0 || now.Add(-age).Before(p.sentAt) {
			return nil // sampled before the request: not an answer
		}
		res := ProbeResult{Auth: obs.Auth, HealthRevision: p.revision} // stamped from the pending entry
		if obs.Capacity != nil {
			c := *obs.Capacity
			res.Capacity = &c
		}
		out.res = res
		if m := h.observed[p.source]; m.serial != s.serial || r.Source.ObservationSeq > m.seq {
			h.observed[p.source] = observationMark{serial: s.serial, seq: r.Source.ObservationSeq}
		}
	}
	delete(h.probes, r.RequestID)
	p.done <- out
	return nil
}

// applyObservations merges only fresh, ordered, bounded-age samples through the
// monitor. SourceReport.Health is a runner-side projection and never changes
// server health. Heartbeat samples are initial/auth/headroom/exhaustion hints:
// they are stamped with the current revision but can never recover capacity.
func (h *Hub) applyObservations(ctx context.Context, s *Session, reps []SourceReport) error {
	maxAge := 3 * h.cfg.Heartbeat
	for _, rep := range reps {
		if !remoteKind(rep.Kind) || rep.Observation == nil || rep.ObservationSeq == 0 {
			continue
		}
		age := time.Duration(rep.SampleAgeMs) * time.Millisecond
		if rep.SampleAgeMs < 0 || age > maxAge {
			continue
		}
		sid := MakeSourceID(s.RunnerID, rep.Kind, rep.CredentialRef)
		if !h.advanceObservation(sid, s.serial, rep.ObservationSeq) {
			continue
		}
		cur, err := h.reg.GetSource(ctx, sid)
		if err != nil {
			return fmt.Errorf("hub: read source %s: %w", sid, err)
		}
		if _, err := h.health.ObserveProbe(ctx, sid, heartbeatHint(*rep.Observation, cur.Health)); err != nil {
			return err
		}
	}
	return nil
}

	if ok && (m.serial > serial || m.serial == serial && seq <= m.seq) {

	}
	h.observed[sid] = observationMark{serial: serial, seq: seq}
	return true
}

// startProbe runs one fresh check per source asynchronously, bounded by the
// session context, and replies with the exact request id/revision. A second
// request for a source already in flight gets a typed unavailable reply.
func (a *Agent) startProbe(ctx context.Context, sess Session, req ProbeRequest) {
	key := string(req.SourceKind) + "/" + req.CredentialRef
	reply := func(src Source) {
		_ = sess.Send(ctx, Outbound{Kind: KindProbeResult, RequestID: req.RequestID, HealthRevision: req.HealthRevision, ProbeResult: &src})
	}
	fresh, ok := a.d.Sources.(FreshSourceProber)
	a.probeMu.Lock()
	if !ok || a.probing[key] {
		a.probeMu.Unlock()
		reason := "probe_in_flight"
		if !ok {
			reason = "fresh_probe_unsupported"
		}
		reply(Source{Kind: req.SourceKind, CredentialRef: req.CredentialRef, UnavailableReason: reason})
		return
	}
	a.probing[key] = true
	a.probeMu.Unlock()
	a.probeWG.Add(1)
	go func() {
		defer a.probeWG.Done()
		defer func() { a.probeMu.Lock(); delete(a.probing, key); a.probeMu.Unlock() }()
		src, err := fresh.ProbeSource(ctx, req.SourceKind, req.CredentialRef)
		if ctx.Err() != nil {
			return // session gone: the reply belongs to a dead session
		}
		if err != nil {
			src = Source{Kind: req.SourceKind, CredentialRef: req.CredentialRef, UnavailableReason: "probe_failed"}
		}
		reply(src)
	}()
}

## Alignment requirements (checklist)

- [ ] **Operator probes are fresh.** An operator probe (REST and MCP) runs a fresh UUID-correlated check on the owning runner now.
  - Cached heartbeat health, offline, unsupported, timeout (10 s, caller cancellation wins), cancel and wrong/old-session replies each return an error and leave stored health unchanged.
  - No server-local probe ever runs for a remote source.
- [ ] **Reply matching and revision fence.**
  - A reply fulfils only its exact pending RequestID, source kind/ref, session and revision, and must be sampled after the request.
  - The hub stamps the accepted result with the pending entry's revision.
  - A classified outcome that wins during I/O forces a new check.
- [ ] **Pending lifecycle.** Pending entries are registered before send and removed on every completion, timeout, cancel, session replacement/loss, revocation and hub shutdown. `PendingProbes()==0` afterwards.
- [ ] **Periodic remote checks** use the remote prober at the normal cadence. They run asynchronously with one in flight per source and are joined by `HealthMonitor.Wait`.
- [ ] **Heartbeat/hello observations.**
  - They are ordered per session and source by `ObservationSeq`, with bounded age (≤ 3 heartbeats) and server receipt time.
  - Repeats never refresh `LastProbeAt`.
  - Projections never change health.
  - Hints never recover capacity.
- [ ] **Merge rules.**
  - Auth-only success clears logout and preserves exhaustion/reset.
  - Combined logout+exhaustion persists both and raises one notification.
  - Null/false/true and model scope survive every mirror.
  - A global Codex allowed flag cannot clear a separately scoped model window.
  - Unknown capacity never proves recovery.
- [ ] **Refreshed `LastProbeAt`** is persisted even when nothing else changes, and is exposed by REST/MCP.
- [ ] **Native confirmation.**
  - `OpConfirm` is slot-counted, with `OperationProbe`, `RequiredSource`, `PinnedRunner` and `AffinityNone`.
  - It obeys cordon/compatibility/logged-out/slot/probation single-flight.
  - It waits cancellably when the runner is full and never oversubscribes.
- [ ] **Exact verifier.**
  - The confirmer uses an exact persisted `ConfirmationModel` and a no-connection profile of the matching native backend. It never switches model or fabricates a cross-backend binding.
  - The native verifier is `ProbeExecutedModel` on a cloned agent binding; `RunAgent` is never called.
  - Only exact requested == executed model with a harness session counts.
  - There is no one-token promise.
- [ ] **No false recovery.**
  - A missing profile, unsupported verifier, transport loss, timeout, wrong model or quota failure keeps probation (or a new exhaustion) with a visible `Detail` reason, and never recovers.
  - A later real exact-model success may still recover.
- [ ] **Built-in runner** confirms in a per-job directory under its configured scratch. **Remote runners** replace the server path with a per-job directory under their own scratch, and no server path crosses the wire.
- [ ] **Wire descriptor.** `WireConfirmation`/`WireConfirmationResult` are bounded, secret-free and allowlisted. `OpConfirm` capability is advertised only for an installed, supported native verifier (P2 T9). Codex is advertised only from P3 T15; no remote Codex source is invented before then.
- [ ] **Slow probes** never block runner heartbeats or liveness.
- [ ] **Fail-closed wiring.**
  - Nil/typed-nil verifier or remote-prober wiring fails production initialization.
  - Monitor, hub and runner shutdown cancel and join every pending probe and confirmation before the DB closes.
