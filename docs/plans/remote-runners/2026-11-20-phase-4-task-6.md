# Remote Runners — Phase 4 Task 6: Atomic session/workspace turn checkpoints


**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` (Recovery and session continuity); `docs/designs/2026-11-19-remote-runners-design-phase-4.md` §3.2, §3.3, §3.6, §7–8; shared `docs/plans/remote-runners/2026-11-20-contracts.md` §16–17, §20–21, §24.

**Goal:** A successful turn is durable only when its exact session bundle, workspace candidate (when mutable), messages, accepted binding, pin, intent and every dispatched completion commit together. Artifact upload never advances the committed workspace pointer. A crash retains the previous complete pair.

## Transaction and call order

1. First turn and every later turn already hold P4 T2's lease and P4 T3's durable intent. Install operation-scoped placement and completion sinks before the decorated stream call. Resolve the effective backend before acceptance. Require valid invocation, intent, lease token and exact completion receipt in production; missing provenance returns an error before any success event/advance. Legacy unit tests explicitly supply memory stores and receipts.
2. Consume the successful stream's receipt. Its job is still commit-pending, fenced and resource-owned until `CommitTurn`. Export the harness bundle from that receipt's runner, validate backend/session/workdir identity, checksum and size, then store it. Stateless API chat has no native bundle; its transcript is still committed and its stream job is still fenced.
3. For a mutable session, validate and reuse the already-prepared workspace under the SAME job/resource receipt. The dispatcher retains P3 WorkspaceAttempt from BeginAttempt through the stream; on terminal success it calls FinishSuccess (builtin StageBuiltIn / remote exact pushed candidate), records the full receipt before forwarding Done, and never prepares twice. StageTurn checks candidate, job, resource and manifest agreement. Never discover it through Latest, a home version, or a runner-global last result. Resolution staging uses its own resource, P4 T11.
4. Pass the candidate's `WorkspaceCompletion` in the stream `StepCompletion` to `CommitTurn`. One SQLite transaction validates intent invocation/turn, lease token and generation, every current job fence, resource owner/token/generation and open-session CAS; inserts/updates the execution; advances the authoritative committed resource pointer; attaches the workspace and session refs plus accepted binding and ConversationKeyTurnIdentity (from exact committed intent/lease); updates pin/generation; completes the exact intent and jobs. A missing/empty fence or candidate rejects the whole transaction. `setSessionStateTx` alone is not the ownership boundary.
5. Only after commit publish the assistant message or ended event, release execution slots/resource ownership, and let the engine/gather continue. No later fallible pointer publication exists. P4 T11 materializes the committed staging checkpoint before gather verification, with a durable retry if that local copy fails. A sentinel follows this same gate. Job completion inside the transaction is what frees the slot; resource-lease release after commit is P3 T6 `WorkspaceSync`'s attempt finisher (a failed release is cleanup debt, never a rollback).
6. End/Abandon without a new stream use their durable operation intent and held lease plus the already committed pair; completion/state transition remains idempotent and fenced. They never manufacture an empty stream fence. A turn write failure keeps the prior pair and a retryable intent; no assistant success leaks.

package runner

import "github.com/arbitron/arbitron/domain/engine"

// SessionPortabilityRegistry maps a harness backend ("claude-code", "codex")
// to its session adapter on THIS machine (the built-in runner in the server,
// or the runner agent's own copy). It never invents a backend.
type SessionPortabilityRegistry struct {
	byBackend map[string]engine.SessionPortability
}

// NewSessionPortabilityRegistry copies byBackend, dropping nil adapters and
// empty backend names.
func NewSessionPortabilityRegistry(byBackend map[string]engine.SessionPortability) *SessionPortabilityRegistry {
	m := make(map[string]engine.SessionPortability, len(byBackend))
	for k, v := range byBackend {
		if k != "" && v != nil {
			m[k] = v
		}
	}
	return &SessionPortabilityRegistry{byBackend: m}
}

// For returns the adapter for backend. A nil registry has no adapters.
func (r *SessionPortabilityRegistry) For(backend string) (engine.SessionPortability, bool) {
	if r == nil {
		return nil, false
	}
	p, ok := r.byBackend[backend]
	return p, ok
}

// Package checkpoint holds filesystem stores for runner checkpoints.
package checkpoint

import (
	"context"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"
	"sync"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/google/uuid"
)

var _ engine.SessionCheckpointStore = (*SessionStore)(nil)

const sessionRefPrefix = "session:"

// DefaultMaxSessionBundleBytes bounds one stored bundle.
const DefaultMaxSessionBundleBytes int64 = 512 << 20

// ErrSessionBundleTooLarge means a bundle exceeds the store's byte bound.
var ErrSessionBundleTooLarge = errors.New("checkpoint: session bundle exceeds the size limit")

// SessionStore keeps session bundles under <dir>/<run>/<invocation>/ as
// <turn>-<checksum>.data plus a .meta.json written last (its presence marks a
// complete bundle).
type SessionStore struct {
	dir      string
	retain   int
	maxBytes int64
	mu       sync.Mutex
}

// NewSessionStore opens (creating) the store; retain >= 1 bundles are kept
// per invocation (the committed one plus retain-1 older turns).
func NewSessionStore(dir string, retain int) (*SessionStore, error) {
	if dir == "" {
		return nil, errors.New("checkpoint: session store requires a directory")
	}
	if retain < 1 {
		return nil, fmt.Errorf("checkpoint: session bundle retention must be >= 1 (got %d)", retain)
	}
	if err := os.MkdirAll(dir, 0o700); err != nil {
		return nil, fmt.Errorf("checkpoint: session store: %w", err)
	}
	return &SessionStore{dir: dir, retain: retain, maxBytes: DefaultMaxSessionBundleBytes}, nil
}

// SetMaxBundleBytes overrides the per-bundle byte bound (n >= 1).
func (s *SessionStore) SetMaxBundleBytes(n int64) {
	if n >= 1 {
		s.mu.Lock()
		s.maxBytes = n
		s.mu.Unlock()
	}
}

type sessionMeta struct {
	Backend        string `json:"backend"`
	SessionID      string `json:"sessionId"`
	HarnessVersion string `json:"harnessVersion"`
	OriginWorkDir  string `json:"originWorkDir"`
	Checksum       string `json:"checksum"`
}

type sessionRef struct {
	run, inv uuid.UUID
	turn     int
	checksum string
}

func (r sessionRef) String() string {
	return fmt.Sprintf("%s%s/%s/%d/%s", sessionRefPrefix, r.run, r.inv, r.turn, r.checksum)
}

func (r sessionRef) base() string { return fmt.Sprintf("%06d-%s", r.turn, r.checksum) }

func validChecksum(s string) bool {
	if len(s) != 64 || strings.ToLower(s) != s {
		return false
	}
	_, err := hex.DecodeString(s)
	return err == nil
}

func parseSessionRef(ref string) (sessionRef, error) {
	rest, ok := strings.CutPrefix(ref, sessionRefPrefix)
	parts := strings.Split(rest, "/")
	if !ok || len(parts) != 4 {
		return sessionRef{}, fmt.Errorf("checkpoint: malformed session ref %q", ref)
	}
	run, err1 := uuid.Parse(parts[0])
	inv, err2 := uuid.Parse(parts[1])
	turn, err3 := strconv.Atoi(parts[2])
	if err1 != nil || err2 != nil || err3 != nil || turn < 1 || !validChecksum(parts[3]) ||
		run.String() != parts[0] || inv.String() != parts[1] {
		return sessionRef{}, fmt.Errorf("checkpoint: malformed session ref %q", ref)
	}
	return sessionRef{run: run, inv: inv, turn: turn, checksum: parts[3]}, nil
}

func (s *SessionStore) invDir(run, inv uuid.UUID) string {
	return filepath.Join(s.dir, run.String(), inv.String())
}

func (s *SessionStore) paths(r sessionRef) (data, meta string) {
	base := filepath.Join(s.invDir(r.run, r.inv), r.base())
	return base + ".data", base + ".meta.json"
}

// ensureRealDir creates dir (and its run parent) and refuses symlinks on the
// path below the store root.
func (s *SessionStore) ensureRealDir(run, inv uuid.UUID) error {
	for _, p := range []string{filepath.Join(s.dir, run.String()), s.invDir(run, inv)} {
		if err := os.Mkdir(p, 0o700); err != nil && !errors.Is(err, fs.ErrExist) {
			return err
		}
		fi, err := os.Lstat(p)
		if err != nil {
			return err
		}
		if fi.Mode()&fs.ModeSymlink != 0 || !fi.IsDir() {
			return fmt.Errorf("checkpoint: %s is not a plain directory", p)
		}
	}
	return nil
}

func writeFileAtomic(path string, data []byte) error {
	tmp, err := os.CreateTemp(filepath.Dir(path), ".tmp-")
	if err != nil {
		return err
	}
	name := tmp.Name()
	fail := func(err error) error {
		tmp.Close()
		os.Remove(name)
		return err
	}
	if _, err := tmp.Write(data); err != nil {
		return fail(err)
	}
	if err := tmp.Sync(); err != nil {
		return fail(err)
	}
	if err := tmp.Close(); err != nil {
		os.Remove(name)
		return err
	}
	if err := os.Rename(name, path); err != nil {
		os.Remove(name)
		return err
	}
	return nil
}

func readRegular(path string) ([]byte, error) {
	fi, err := os.Lstat(path)
	if err != nil {
		return nil, err
	}
	if !fi.Mode().IsRegular() {
		return nil, fmt.Errorf("checkpoint: %s is not a regular file", path)
	}
	return os.ReadFile(path)
}

// Put implements engine.SessionCheckpointStore.
func (s *SessionStore) Put(_ context.Context, key engine.SessionKey, b engine.SessionBundle) (string, error) {
	if key.RunID == uuid.Nil || key.TurnIndex < 1 {
		return "", fmt.Errorf("checkpoint: invalid session key %+v", key)
	}
	if err := b.Verify(); err != nil {
		return "", err
	}
	r := sessionRef{run: key.RunID, inv: key.InvocationID, turn: key.TurnIndex, checksum: b.Checksum}
	meta, err := json.Marshal(sessionMeta{Backend: b.Backend, SessionID: b.SessionID, HarnessVersion: b.HarnessVersion,
		OriginWorkDir: b.OriginWorkDir, Checksum: b.Checksum})
	if err != nil {
		return "", err
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	if int64(len(b.Data)) > s.maxBytes {
		return "", fmt.Errorf("%w: %d > %d bytes", ErrSessionBundleTooLarge, len(b.Data), s.maxBytes)
	}
	if err := s.ensureRealDir(r.run, r.inv); err != nil {
		return "", fmt.Errorf("checkpoint: put session: %w", err)
	}
	dataPath, metaPath := s.paths(r)
	if err := writeFileAtomic(dataPath, b.Data); err != nil {
		return "", fmt.Errorf("checkpoint: put session: %w", err)
	}
	if err := writeFileAtomic(metaPath, meta); err != nil {
		os.Remove(dataPath)
		return "", fmt.Errorf("checkpoint: put session: %w", err)
	}
	return r.String(), nil
}

// Get implements engine.SessionCheckpointStore.
func (s *SessionStore) Get(_ context.Context, ref string) (engine.SessionBundle, error) {
	r, err := parseSessionRef(ref)
	if err != nil {
		return engine.SessionBundle{}, err
	}
	dataPath, metaPath := s.paths(r)
	s.mu.Lock()
	defer s.mu.Unlock()
	rawMeta, err := readRegular(metaPath)
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("checkpoint: get session %s: %w", ref, err)
	}
	var m sessionMeta
	if err := json.Unmarshal(rawMeta, &m); err != nil {
		return engine.SessionBundle{}, fmt.Errorf("checkpoint: get session %s: %w", ref, err)
	}
	data, err := readRegular(dataPath)
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("checkpoint: get session %s: %w", ref, err)
	}
	b := engine.SessionBundle{Backend: m.Backend, SessionID: m.SessionID, HarnessVersion: m.HarnessVersion,
		OriginWorkDir: m.OriginWorkDir, Checksum: m.Checksum, Data: data}
	if b.Checksum != r.checksum {
		return engine.SessionBundle{}, fmt.Errorf("%w: stored metadata does not match ref", engine.ErrBundleChecksum)
	}
	if err := b.Verify(); err != nil {
		return engine.SessionBundle{}, err
	}
	return b, nil
}

// Prune implements engine.SessionCheckpointStore.
func (s *SessionStore) Prune(_ context.Context, runID, invocationID uuid.UUID, keepRef string) error {
	keep, err := parseSessionRef(keepRef)
	if err != nil {
		return err
	}
	if keep.run != runID || keep.inv != invocationID {
		return fmt.Errorf("checkpoint: keep ref %s does not belong to %s/%s", keepRef, runID, invocationID)
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	dir := s.invDir(runID, invocationID)
	if _, metaPath := s.paths(keep); !fileExists(metaPath) {
		return fmt.Errorf("checkpoint: keep ref %s is not stored; refusing to prune", keepRef)
	}
	entries, err := os.ReadDir(dir)
	if err != nil {
		return fmt.Errorf("checkpoint: prune sessions: %w", err)
	}
	bases := map[string]int{}
	for _, e := range entries {
		name := e.Name()
		if strings.HasPrefix(name, ".tmp-") {
			continue // CollectGarbage reclaims stale temp files by age
		}
		base := strings.TrimSuffix(strings.TrimSuffix(name, ".meta.json"), ".data")
		turnPart, _, ok := strings.Cut(base, "-")
		turn, err := strconv.Atoi(turnPart)
		if !ok || err != nil {
			continue
		}
		bases[base] = turn
	}
	type stored struct {
		base string
		turn int
	}
	var older []stored
	for base, turn := range bases {
		if base != keep.base() && turn < keep.turn {
			older = append(older, stored{base: base, turn: turn})
		}
	}
	sort.Slice(older, func(i, j int) bool {
		if older[i].turn != older[j].turn {
			return older[i].turn > older[j].turn
		}
		return older[i].base > older[j].base
	})
	retained := map[string]bool{keep.base(): true}
	for i := 0; i < len(older) && i < s.retain-1; i++ {
		retained[older[i].base] = true
	}
	for base := range bases {
		if retained[base] {
			continue
		}
		_ = os.Remove(filepath.Join(dir, base+".meta.json")) // meta first: a half-deleted bundle reads as missing
		_ = os.Remove(filepath.Join(dir, base+".data"))
	}
	return nil
}

// CollectGarbage removes complete bundles whose ref is not live and whose
// metadata is older than olderThan, plus temp files older than olderThan. It is
// the startup GC for abandoned uploads; live covers committed refs and
// pending intents/moves (composed by P4 T13 from the database).
func (s *SessionStore) CollectGarbage(ctx context.Context, live func(ref string) bool, olderThan time.Time) (int, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	removed := 0
	err := filepath.WalkDir(s.dir, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if ctx.Err() != nil {
			return ctx.Err()
		}
		if d.IsDir() {
			return nil
		}
		info, err := d.Info()
		if err != nil {
			return err
		}
		name := d.Name()
		if strings.HasPrefix(name, ".tmp-") {
			if info.ModTime().Before(olderThan) {
				_ = os.Remove(path)
			}
			return nil
		}
		base, ok := strings.CutSuffix(name, ".meta.json")
		if !ok || !info.ModTime().Before(olderThan) {
			return nil
		}
		rel, err := filepath.Rel(s.dir, filepath.Dir(path))
		if err != nil {
			return err
		}
		parts := strings.Split(rel, string(filepath.Separator))
		turnPart, sum, found := strings.Cut(base, "-")
		if len(parts) != 2 || !found {
			return nil
		}
		turn, err := strconv.Atoi(turnPart)
		if err != nil {
			return nil
		}
		ref := fmt.Sprintf("%s%s/%s/%d/%s", sessionRefPrefix, parts[0], parts[1], turn, sum)
		if _, perr := parseSessionRef(ref); perr != nil || live(ref) {
			return nil
		}
		_ = os.Remove(path)
		_ = os.Remove(filepath.Join(filepath.Dir(path), base+".data"))
		removed++
		return nil
	})
	return removed, err
}

func fileExists(p string) bool {
	_, err := os.Stat(p)
	return err == nil
}

// sessionBackend names the harness of a turn and whether it has a native,
// portable session bundle (claude-code, codex). Connection-backed API chat is
// stateless ("", false). Unknown agent backends are an error.
func sessionBackend(b provider.ResolvedBinding, defaultAgent string) (string, bool, error) {
	switch b.Kind {
	case provider.ProfileKindAgent:
		be := strings.TrimSpace(b.Backend)
		if be == "" {
			be = strings.TrimSpace(defaultAgent)
		}
		if be == "" || !workflow.IsValidAgentBackend(be) {
			return "", false, fmt.Errorf("%w: %q", ErrUnknownSessionBackend, be)
		}

	case provider.ProfileKindChat:
		if b.ConnectionRef == "" {
			return workflow.BackendClaudeCode, true, nil
		}
	}
	return "", false, nil
}

func (p turnCheckpointPlan) validate() error {
	switch {
	case p.intentID == uuid.Nil, p.requestID == uuid.Nil:
		return fmt.Errorf("%w: no persisted turn intent", ErrMissingTurnReceipt)
	case p.invocationID == uuid.Nil:
		return fmt.Errorf("%w: no session invocation", ErrMissingTurnReceipt)

		return fmt.Errorf("%w: no held durable turn lease", ErrMissingTurnReceipt)

	return nil

// streamReceipt returns the single exact completion of this turn's stream.
func (p turnCheckpointPlan) streamReceipt(ctx context.Context) (StepCompletion, error) {
	comps := p.completions
	if comps == nil {
		sink, ok := StepCompletionSinkFromContext(ctx)
		if !ok {
			return StepCompletion{}, fmt.Errorf("%w: no completion sink", ErrMissingTurnReceipt)
		}
		comps = sink.Completions()
	}
	if len(comps) != 1 {
		return StepCompletion{}, fmt.Errorf("%w: want exactly one stream receipt, got %d", ErrMissingTurnReceipt, len(comps))
	}
	c := comps[0]
	if c.JobFence.JobID == uuid.Nil || c.JobFence.RunnerID == "" || c.JobFence.Generation < 1 {
		return StepCompletion{}, fmt.Errorf("%w: incomplete job fence", ErrMissingTurnReceipt)
	}
	return c, nil
}

	return out

// checkpointAndCommit makes a finished turn durable: export + store the harness
// session under the stream's own fence, validate the prepared workspace
// candidate (mutable sessions), then ONE fenced commit. Any failure before the
// commit leaves every durable record and the caller's exec unchanged.
func (d *SessionCheckpointDeps) checkpointAndCommit(ctx context.Context, exec *instance.NodeExecution, p turnCheckpointPlan) error {
	if err := p.validate(); err != nil {
		return err
	}
	backend, native, err := sessionBackend(p.binding, d.DefaultAgentBackend)
	if err != nil {
		return err
	}
	stream, err := p.streamReceipt(ctx)
	if err != nil {
		return err
	}
	mutable := p.binding.Kind == provider.ProfileKindAgent && p.workDir != ""
	resource := exec.InstanceID
	if p.resourceID != uuid.Nil {
		resource = p.resourceID
	} else if p.group && mutable {
		return fmt.Errorf("%w: group staging session has no resolution resource", ErrMissingTurnReceipt)
	}
	if mutable && stream.Workspace == nil {
		return fmt.Errorf("%w: mutable turn has no workspace receipt", ErrMissingTurnReceipt)
	}
	runnerID := stream.JobFence.RunnerID

	var ref string
	if native {
		sid := SessionID(exec.LLMConversation)
		if sid == "" {
			return fmt.Errorf("%w: harness returned no session id", ErrMissingTurnReceipt)
		}
		req := SessionExportRequest{RunnerID: runnerID, Backend: backend, SessionID: sid, WorkDir: p.workDir, JobFence: stream.JobFence}
		if stream.Workspace != nil {
			r := stream.Workspace.Resource
			req.Resource = &r
		}
		b, err := d.Exporter.ExportSession(ctx, req)
		if err != nil {
			return fmt.Errorf("checkpoint session: export: %w", err)
		}
		if err := b.Verify(); err != nil {
			return fmt.Errorf("checkpoint session: export: %w", err)
		}
		if b.Backend != backend || b.SessionID != sid {
			return fmt.Errorf("checkpoint session: exported %s/%s, want %s/%s", b.Backend, b.SessionID, backend, sid)
		}
		if ref, err = d.Store.Put(ctx, SessionKey{RunID: exec.InstanceID, InvocationID: p.invocationID, TurnIndex: p.turnIndex}, b); err != nil {
			return fmt.Errorf("checkpoint session: store: %w", err)
		}

		staged, err := d.Workspace.StageTurn(ctx, TurnWorkspaceRequest{RunID: resource, RunnerID: runnerID, WorkDir: p.workDir, Completion: stream})
		if err != nil {
			return fmt.Errorf("checkpoint workspace: %w", err)
		}
		w := staged.Completion
		stream.Workspace = &w
		conv[ConversationKeyWorkspaceCheckpointRef] = staged.Ref
	}
	conv[ConversationKeyAcceptedTurnBinding] = p.accepted
	conv[ConversationKeyTurnIdentity] = InteractiveTurnIdentity{RunID: exec.InstanceID, NodeID: exec.NodeID,
		InvocationID: p.invocationID, RequestID: p.requestID, TurnIndex: p.turnIndex, Generation: p.lease.Generation}

	commitExec := *exec
	commitExec.LLMConversation = conv
	if err := d.Committer.CommitTurn(ctx, TurnCommit{
		Execution: &commitExec, Create: p.create, RequireOpenSession: p.group, RequireWorkspace: mutable,
		CheckpointRef: ref, PinRunner: runnerID, SessionGeneration: p.lease.Generation,
		LeaseKey: p.lease.Key, LeaseToken: p.lease.Token, IntentID: p.intentID, RequestID: p.requestID,
		InvocationID: p.invocationID, TurnIndex: p.turnIndex, ResourceRunID: resource,
		AcceptedBinding: p.accepted, Completions: []StepCompletion{stream},
	}); err != nil {
		return fmt.Errorf("commit turn: %w", err)
	}
	*exec = commitExec
	if ref != "" {
		// Retention only: a failed prune is cleanup debt for CollectGarbage.
		_ = d.Store.Prune(context.WithoutCancel(ctx), exec.InstanceID, p.invocationID, ref)
	}
	return nil
}

package sqlite

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"strconv"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/instance"
	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

var _ engine.TurnCommitter = (*TurnCommitRepo)(nil)

// TurnCommitRepo commits a turn's conversation, session state, workspace
// candidate promotion, intent completion and job completion in ONE
// transaction, after validating lease, intent, prior pair, job and resource
// fences inside that same transaction (contracts §21).
type TurnCommitRepo struct {
	db     *sql.DB
	now    func() time.Time
	execs  *NodeExecutionRepo
	ledger *RunnerLedgerRepo
}

// NewTurnCommitRepo builds the committer over the server database.
func NewTurnCommitRepo(db *sql.DB) *TurnCommitRepo {
	return &TurnCommitRepo{db: db, now: time.Now, execs: NewNodeExecutionRepo(db), ledger: NewRunnerLedgerRepo(db)}
}

// SetClock overrides the clock (tests).
func (r *TurnCommitRepo) SetClock(now func() time.Time) { r.now, r.ledger.now = now, now }

type storedIntent struct {
	leaseKey, runID, invocationID, requestID, kind, prior string
	turnIndex                                           int
	generation                                          int64
	completed                                           bool
}

func loadIntentTx(ctx context.Context, tx *sql.Tx, id uuid.UUID) (storedIntent, error) {
	var in storedIntent
	var completed sql.NullInt64
	err := tx.QueryRowContext(ctx, `SELECT lease_key, run_id, invocation_id, request_id, kind, prior_checkpoint_ref, turn_index, session_generation, completed_at
		FROM turn_intents WHERE id = ?`, id.String()).Scan(&in.leaseKey, &in.runID, &in.invocationID, &in.requestID, &in.kind, &in.prior,
		&in.turnIndex, &in.generation, &completed)
	if errors.Is(err, sql.ErrNoRows) {
		return in, fmt.Errorf("%w: intent %s not found", engine.ErrTurnFenced, id)
	}
	in.completed = completed.Valid
	return in, err
}

type storedSession struct {
	exists          bool
	ref, pin, inv   string
	generation      int64
}

func loadSessionTx(ctx context.Context, tx *sql.Tx, execID uuid.UUID) (storedSession, error) {
	var s storedSession
	err := tx.QueryRowContext(ctx, `SELECT COALESCE(session_checkpoint_ref, ''), COALESCE(session_pin_runner, ''), COALESCE(session_invocation_id, ''), session_generation
		FROM node_executions WHERE id = ?`, uuidToString(execID)).Scan(&s.ref, &s.pin, &s.inv, &s.generation)
	if errors.Is(err, sql.ErrNoRows) {
		return s, nil
	}
	s.exists = err == nil
	return s, err
}

// CommitTurn implements engine.TurnCommitter.
func (r *TurnCommitRepo) CommitTurn(ctx context.Context, c engine.TurnCommit) error {
	if c.Execution == nil || c.IntentID == uuid.Nil || c.LeaseToken == uuid.Nil || c.InvocationID == uuid.Nil {
		return fmt.Errorf("%w: execution, intent, lease token and invocation are required", engine.ErrMissingTurnReceipt)
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("turn commit: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()

	in, err := loadIntentTx(ctx, tx, c.IntentID)
	if err != nil {
		return err
	}
	cur, err := loadSessionTx(ctx, tx, c.Execution.ID)
	if err != nil {
		return fmt.Errorf("turn commit: read session: %w", err)
	}
	if in.completed {
		// Exact idempotent retry: the committed outcome is exactly this commit.
		if cur.exists && cur.ref == c.CheckpointRef && cur.inv == c.InvocationID.String() &&
			cur.generation == c.SessionGeneration && in.requestID == c.RequestID.String() {
			return nil
		}
		return fmt.Errorf("%w: intent %s already committed a different outcome", engine.ErrTurnFenced, c.IntentID)
	}
	if in.leaseKey != c.LeaseKey || in.runID != c.Execution.InstanceID.String() || in.invocationID != c.InvocationID.String() ||
		in.requestID != c.RequestID.String() || in.turnIndex != c.TurnIndex || in.generation > c.SessionGeneration {
		return fmt.Errorf("%w: intent %s does not match this turn", engine.ErrTurnFenced, c.IntentID)
	}
	if err := checkLeaseTx(ctx, tx, c); err != nil {
		return err
	}
	if err := checkPriorPairTx(ctx, tx, c, in, cur); err != nil {
		return err
	}
	operationOnly := in.kind == engine.TurnIntentEnd || in.kind == engine.TurnIntentAbandon
	switch {
	case operationOnly && (len(c.Completions) > 0 || c.CheckpointRef != cur.ref):
		return fmt.Errorf("%w: end/abandon commits the existing pair without a stream receipt", engine.ErrInvalidStepCompletion)
	case !operationOnly && len(c.Completions) == 0:
		return fmt.Errorf("%w: turn has no completion receipt", engine.ErrInvalidStepCompletion)
	}
	resourceRun := c.ResourceRunID
	if resourceRun == uuid.Nil {
		resourceRun = c.Execution.InstanceID
	}
	sawWorkspace := false
	for _, comp := range c.Completions {
		if err := checkJobFenceTx(ctx, tx, comp.JobFence, c); err != nil {
			return err
		}
		w := comp.Workspace
		if w == nil {
			continue
		}
		sawWorkspace = true
		if err := checkResourceTx(ctx, tx, w.Resource); err != nil {
			return err
		}
		runID := resourceRun
		if err := promoteCandidateTx(ctx, tx, runID, comp.JobFence, *w, r.now()); err != nil {
			return err
		}
	}
	if c.RequireWorkspace && !sawWorkspace {
		return fmt.Errorf("%w: mutable turn has no workspace receipt", engine.ErrInvalidStepCompletion)
	}

	switch {
	case c.Create:
		err = r.execs.createTx(ctx, tx, c.Execution)
	case c.RequireOpenSession:
		var written bool
		written, err = r.execs.updateIfSessionOpenTx(ctx, tx, c.Execution)
		if err == nil && !written {
			err = fmt.Errorf("session %s was closed during this turn: %w", c.Execution.ID, instance.ErrNotInteractiveWait)
		}
	default:
		err = r.execs.updateTx(ctx, tx, c.Execution)
	}
	if err != nil {
		return fmt.Errorf("turn commit: %w", err)
	}
	st := instance.SessionState{Generation: c.SessionGeneration, InvocationID: c.InvocationID}
	if c.CheckpointRef != "" {
		ref := c.CheckpointRef
		st.CheckpointRef = &ref
	}
	if c.PinRunner != "" {
		pin := c.PinRunner
		st.PinRunner = &pin
	}
	if err := setSessionStateTx(ctx, tx, c.Execution.ID, st); err != nil {
		return fmt.Errorf("turn commit: %w", err)
	}
	if err := completeIntentTx(ctx, tx, c.IntentID, r.now()); err != nil {
		return fmt.Errorf("turn commit: %w", err)
	}
	for _, comp := range c.Completions {
		f := runner.Fence{JobID: comp.JobFence.JobID, RunnerID: runner.RunnerID(comp.JobFence.RunnerID), Generation: comp.JobFence.Generation}
		if err := r.ledger.fencedUpdate(ctx, tx, f, `state = 'completed', result_ref = ?, lease_until = NULL`, c.CheckpointRef); err != nil {
			return fmt.Errorf("%w: complete job %s: %v", engine.ErrTurnFenced, f.JobID, err)
		}
		if err := r.ledger.closeAttempt(ctx, tx, f, "completed"); err != nil {
			return err
		}
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("turn commit: %w", err)
	}
	return nil
}

func checkLeaseTx(ctx context.Context, tx *sql.Tx, c engine.TurnCommit) error {
	var token sql.NullString
	var gen int64
	err := tx.QueryRowContext(ctx, `SELECT token, generation FROM turn_leases WHERE key = ?`, c.LeaseKey).Scan(&token, &gen)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && (!token.Valid || token.String != c.LeaseToken.String() || gen != c.SessionGeneration)) {
		return fmt.Errorf("%w: lease %s", engine.ErrTurnFenced, c.LeaseKey)
	}
	if err != nil {
		return fmt.Errorf("turn commit: read lease: %w", err)
	}
	return nil
}

// checkPriorPairTx is the monotonic-turn CAS: an update must start from exactly
// the pair the intent was accepted against; a create must be the visit's first.
func checkPriorPairTx(ctx context.Context, tx *sql.Tx, c engine.TurnCommit, in storedIntent, cur storedSession) error {
	if c.Create {
		var n int
		if err := tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM node_executions WHERE session_invocation_id = ?`, c.InvocationID.String()).Scan(&n); err != nil {
			return err
		}
		if n > 0 || cur.exists || in.prior != "" {
			return fmt.Errorf("%w: invocation %s already has a committed session", engine.ErrTurnFenced, c.InvocationID)
		}
		return nil
	}
	if !cur.exists {
		return fmt.Errorf("turn commit: execution %s: %w", c.Execution.ID, instance.ErrNotFound)
	}
	if cur.generation > c.SessionGeneration {
		return fmt.Errorf("turn commit: %w", instance.ErrStaleSessionGeneration)
	}
	if cur.inv != "" && cur.inv != uuid.Nil.String() && cur.inv != c.InvocationID.String() {
		return fmt.Errorf("%w: session belongs to invocation %s", engine.ErrTurnFenced, cur.inv)
	}
	if cur.ref != in.prior {
		return fmt.Errorf("%w: prior checkpoint %q is not the accepted %q", engine.ErrTurnFenced, cur.ref, in.prior)
	}
	return nil
}

func checkJobFenceTx(ctx context.Context, tx *sql.Tx, f engine.JobFenceRef, c engine.TurnCommit) error {
	var run, inv string
	err := tx.QueryRowContext(ctx, `SELECT run_id, invocation_id FROM runner_jobs WHERE `+fencedWhere,
		f.JobID.String(), f.RunnerID, f.Generation).Scan(&run, &inv)
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("%w: job %s generation %d is not live on %s", engine.ErrTurnFenced, f.JobID, f.Generation, f.RunnerID)
	}
	if err != nil {
		return err
	}
	if run != c.Execution.InstanceID.String() || inv != c.InvocationID.String() {
		return fmt.Errorf("%w: job %s belongs to another run/invocation", engine.ErrTurnFenced, f.JobID)
	}
	return nil
}

func checkResourceTx(ctx context.Context, tx *sql.Tx, res engine.ResourceFenceRef) error {
	if err := res.Validate(); err != nil {
		return fmt.Errorf("%w: %v", engine.ErrInvalidStepCompletion, err)
	}
	var n int
	if err := tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM workspace_leases WHERE resource_key = ? AND owner = ? AND generation = ? AND token = ? AND active = 1`,
		res.Key, res.Owner, res.Generation, res.Token.String()).Scan(&n); err != nil {
		return err
	}
	if n != 1 {
		return fmt.Errorf("%w: resource %s generation %d is not held", engine.ErrTurnFenced, res.Key, res.Generation)
	}
	return nil
}

// parseWorkspaceRef parses "<resourceUUID>@<version>:<manifestHash>" (runner.FormatTurnWorkspaceRef).
func parseWorkspaceRef(ref string) (uuid.UUID, int64, string, error) {
	run, rest, ok1 := strings.Cut(ref, "@")
	ver, hash, ok2 := strings.Cut(rest, ":")
	id, err1 := uuid.Parse(run)
	v, err2 := strconv.ParseInt(ver, 10, 64)
	if !ok1 || !ok2 || err1 != nil || err2 != nil || v < 1 || len(hash) != 64 {
		return uuid.Nil, 0, "", fmt.Errorf("%w: malformed workspace ref %q", engine.ErrInvalidStepCompletion, ref)
	}
	return id, v, hash, nil
}

// promoteCandidateTx commits the exact prepared candidate the job produced and
// advances the resource's committed pointer (successor of the current version).
func promoteCandidateTx(ctx context.Context, tx *sql.Tx, runID uuid.UUID, job engine.JobFenceRef, w engine.WorkspaceCompletion, now time.Time) error {
	if w.NonPortable || w.LocalRef != "" {
		return fmt.Errorf("%w: non-portable receipts are promoted by promoteLocalCheckpointTx (Cycle 8)", engine.ErrInvalidStepCompletion)
	}
	run, version, hash, err := parseWorkspaceRef(w.Ref)
	if err != nil {
		return err
	}
	if run != runID {
		return fmt.Errorf("%w: candidate %s is not resource %s", engine.ErrInvalidStepCompletion, w.Ref, runID)
	}
	res, err := tx.ExecContext(ctx, `UPDATE workspace_checkpoints SET state = 'committed'
		WHERE run_id = ? AND version = ? AND manifest_hash = ? AND state = 'prepared' AND job_id = ? AND job_generation = ?
		AND resource_key = ? AND resource_owner = ? AND resource_generation = ? AND resource_token = ?`,
		run.String(), version, hash, job.JobID.String(), job.Generation, w.Resource.Key, w.Resource.Owner, w.Resource.Generation, w.Resource.Token.String())
	if err != nil {
		return err
	}
	if n, _ := res.RowsAffected(); n != 1 {
		return fmt.Errorf("%w: no prepared candidate %s for job %s", engine.ErrInvalidStepCompletion, w.Ref, job.JobID)
	}
	res, err = tx.ExecContext(ctx, `UPDATE workspace_homes SET checkpoint_version = ?, dirty = 0, updated_at = ? WHERE run_id = ? AND checkpoint_version < ?`,
		version, timeToString(now), run.String(), version)
	if err != nil {
		return err
	}
	if n, _ := res.RowsAffected(); n != 1 {
		return fmt.Errorf("%w: candidate %s is not a successor of the committed workspace", engine.ErrInvalidStepCompletion, w.Ref)
	}
	return nil
}

package runner

import (
	"context"

	"github.com/google/uuid"

var _ engine.TurnWorkspaceCheckpointer = (*TurnWorkspaceCheckpointer)(nil)

// TurnWorkspaceCheckpointer validates and reuses the exact prepared candidate
// a mutable turn's stream receipt names. It never prepares a candidate,
// never reads Latest and never moves a committed pointer (TurnCommitRepo does,
// inside its transaction).
type TurnWorkspaceCheckpointer struct {
	cp    CheckpointStore
	homes HomeStore
}

// NewTurnWorkspaceCheckpointer builds the checkpointer.
func NewTurnWorkspaceCheckpointer(cp CheckpointStore, homes HomeStore) *TurnWorkspaceCheckpointer {
	return &TurnWorkspaceCheckpointer{cp: cp, homes: homes}
}

// FormatTurnWorkspaceRef renders "<resourceUUID>@<version>:<manifestHash>".
func FormatTurnWorkspaceRef(ref CheckpointRef) string {
	return fmt.Sprintf("%s@%d:%s", ref.RunID, ref.Version, ref.ManifestHash)
}

// ParseTurnWorkspaceRef parses FormatTurnWorkspaceRef output.
func ParseTurnWorkspaceRef(s string) (CheckpointRef, error) {
	run, rest, ok1 := strings.Cut(s, "@")
	ver, hash, ok2 := strings.Cut(rest, ":")
	id, err1 := uuid.Parse(run)
	v, err2 := strconv.ParseInt(ver, 10, 64)
	if !ok1 || !ok2 || err1 != nil || err2 != nil || v < 1 || len(hash) != 64 {
		return CheckpointRef{}, fmt.Errorf("%w: malformed workspace ref %q", engine.ErrInvalidStepCompletion, s)
	}
	return CheckpointRef{RunID: id, Version: v, ManifestHash: hash}, nil
}

// StageTurn implements engine.TurnWorkspaceCheckpointer.
func (t *TurnWorkspaceCheckpointer) StageTurn(ctx context.Context, req engine.TurnWorkspaceRequest) (engine.StagedTurnWorkspace, error) {
	w := req.Completion.Workspace
	if w == nil {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: mutable turn on %s has no prepared workspace receipt", engine.ErrInvalidStepCompletion, req.RunnerID)
	}
	if req.Completion.JobFence.RunnerID != req.RunnerID || w.Resource.Owner != req.RunnerID {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: receipt job/resource are not owned by %s", engine.ErrInvalidStepCompletion, req.RunnerID)
	}
	ref, err := ParseTurnWorkspaceRef(w.Ref)
	if err != nil {
		return engine.StagedTurnWorkspace{}, err
	}
	if ref.RunID != req.RunID {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: candidate %s is not resource %s", engine.ErrInvalidStepCompletion, w.Ref, req.RunID)
	}
	home, err := t.homes.GetHome(ctx, req.RunID)
	if err != nil {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("runner: workspace home: %w", err)
	}
	if ref.Version <= home.CheckpointVersion {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: candidate v%d is not newer than committed v%d", engine.ErrInvalidStepCompletion, ref.Version, home.CheckpointVersion)
	}
	m, err := t.cp.Manifest(ctx, ref)
	if err != nil {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("runner: candidate manifest: %w", err)
	}
	if m.Hash != ref.ManifestHash || m.Version != ref.Version {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: candidate manifest does not match %s", engine.ErrInvalidStepCompletion, w.Ref)
	}
	return engine.StagedTurnWorkspace{RunID: req.RunID, RunnerID: req.RunnerID, Version: ref.Version, Ref: FormatTurnWorkspaceRef(ref), Completion: *w}, nil
}

// promoteLocalCheckpointTx makes a non-portable home's prepared local checkpoint
// (RR-17 B) its committed recovery base inside the caller's step/turn transaction.
// Only the immediate successor of the committed local version is accepted.
func promoteLocalCheckpointTx(ctx context.Context, tx *sql.Tx, runID uuid.UUID, localRef string) error {
	local, err := runner.ParseLocalCheckpointRef(localRef)
	if err != nil || local.RunID != runID {
		return fmt.Errorf("%w: local checkpoint %q for run %s", engine.ErrInvalidStepCompletion, localRef, runID)
	}
	var cur, reason string
	if err := tx.QueryRowContext(ctx,
		`SELECT local_checkpoint, non_portable_reason FROM workspace_homes WHERE run_id = ?`, runID.String()).Scan(&cur, &reason); err != nil {
		return err
	}
	if reason == "" {
		return fmt.Errorf("%w: run %s is portable", engine.ErrInvalidStepCompletion, runID)
	}
	next := int64(1)
	if cur != "" {
		prev, err := runner.ParseLocalCheckpointRef(cur)
		if err != nil {
			return err
		}
		next = prev.Version + 1
	}
	if local.Version != next {
		return fmt.Errorf("%w: local checkpoint %s is not the successor of %q", engine.ErrInvalidStepCompletion, local, cur)
	}
	_, err = tx.ExecContext(ctx,
		`UPDATE workspace_homes SET local_checkpoint = ?, dirty = 0 WHERE run_id = ?`, localRef, runID.String())
	return err
}

// stageNonPortable validates and reuses the dispatcher's local checkpoint
// receipt (P3 T16 FinishSuccess); it never copies or stages again.
func (t *TurnWorkspaceCheckpointer) stageNonPortable(ctx context.Context, req engine.TurnWorkspaceRequest, w engine.WorkspaceCompletion) (engine.StagedTurnWorkspace, error) {
	if !w.NonPortable || w.LocalRef == "" || w.Ref != "" {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: LocalRef must be set exactly when NonPortable", engine.ErrInvalidStepCompletion)
	}
	ref, err := ParseLocalCheckpointRef(w.LocalRef)
	if err != nil || ref.RunID != req.RunID {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: local checkpoint %q for run %s", engine.ErrInvalidStepCompletion, w.LocalRef, req.RunID)
	}
	if RunnerID(req.RunnerID) != BuiltInRunnerID {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("runner: non-portable run %s turn on %s: %w", req.RunID, req.RunnerID, ErrHomeOwned)
	}
	home, err := t.homes.GetHome(ctx, req.RunID)
	if err != nil {
		return engine.StagedTurnWorkspace{}, err
	}
	if home.NonPortableReason == "" {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: run %s is portable", engine.ErrInvalidStepCompletion, req.RunID)
	}
	cur, err := committedLocal(home)
	if err != nil {
		return engine.StagedTurnWorkspace{}, err
	}
	if ref.Version != cur.Version+1 {
		return engine.StagedTurnWorkspace{}, fmt.Errorf("%w: local checkpoint %s is not the successor of %q", engine.ErrInvalidStepCompletion, ref, home.LocalCheckpoint)
	}
	return engine.StagedTurnWorkspace{RunID: req.RunID, RunnerID: req.RunnerID, Version: ref.Version, Ref: w.LocalRef, Completion: w}, nil
}
