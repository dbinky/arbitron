# Remote Runners — Phase 4 Task 14: Runner detail pinned sessions

**Goal:** `runner_get` (MCP) and `GET /api/v1/runners/{id}` (REST) list the live interactive sessions pinned to that runner as `sessions[{runId, nodeId, hidden, generation}]`. A caller who cannot view the run sees the session with `runId: null`, `nodeId: ""` and `hidden: true`.

**Architecture:**
- `domain/runner/service_sessions.go` adds three things:
  - `SessionPinView`, the view type named in contracts §14 `RunnerDetail.Sessions /*P4*/`;
  - the read port `RunnerSessionIndex` (`ListByRunner(ctx, id) ([]RunnerSession, error)`);
  - `(*Service).sessionViews`.
- `ServiceDeps` gains an optional `Sessions RunnerSessionIndex`. `Service.Get` lists the runner's pinned sessions and applies `Visibility.CanView` to each, as it already does for assignments and homes.
- The P4 T10 adapter `adaptsqlite.SessionPinIndex` (over `node_executions.session_pin_runner`, migration 045) gains `ListByRunner`, so the pin index stays one adapter. P4 T10's `PinnedSessionIndex.ListPinned` only lists waiting sessions and has no generation, so it cannot serve this read.
  - A session is pinned to runner R when the newest record of its node has `session_pin_runner = R`, the run is not terminal, and the run is still at that node.
- The REST and MCP detail DTOs replace the P1 T15 `sessions` `json.RawMessage` placeholder with typed items carrying identical json tags. A hidden item never renders a run id or node id.
- `cmd/arbitron/runner_wiring.go:newRunnerStack` gains the input `runnerStackDeps.PinnedSessions`. `main.go` feeds it `adaptsqlite.NewSessionPinIndex(db)`, built next to P4 T13's `sessionPins`.

**Tech Stack:** Go 1.25.5, testify, modernc SQLite (hand-written SQL), chi v5, mark3labs mcp-go, the real `initDomain`/`Start` composition root with the P4 T13 session harness (fake built-in `claude`).

**Spec / Design:**
- Spec `docs/specs/2026-11-19-remote-runners-spec.md`:
  - "Live views": interactive-session assignments are shown;
  - "Administration and visibility": runs a user cannot view never appear.
- Design `docs/designs/2026-11-19-remote-runners-design-phase-4.md`:
  - §3.4: the pinned placement a session keeps;
  - §8 Happy path: "a multi-turn `interactive_agent` session stays pinned to one runner" (this task makes the pin inspectable on the runner).
- Design `docs/designs/2026-11-19-remote-runners-design-phase-5.md`:
  - §3.2 "Assignments: … pinned interactive sessions";
  - §8 "hidden-run links/events never render".
- Contracts `docs/plans/remote-runners/2026-11-20-contracts.md`:
  - §1 (migration 045 `node_executions.session_pin_runner`, `session_generation`);
  - §14 (`ServiceDeps`, `RunnerDetail.Sessions []SessionPinView`, `RunVisibility`, DTO rules, `runner_get`, `GET /runners/{id}`);

package runner

import (

// RunnerSession is one live interactive session whose newest record is
// pinned to a runner.
type RunnerSession struct {
	RunID      uuid.UUID
	NodeID     string
	Generation int64 // session generation of the newest record (node_executions.session_generation)

// RunnerSessionIndex lists the live interactive sessions pinned to one
// runner: the run is not terminal, the run is still at the session's node,
// and the node's newest record is pinned to id.
type RunnerSessionIndex interface {
	ListByRunner(ctx context.Context, id RunnerID) ([]RunnerSession, error)
}

// ListByRunner lists the live interactive sessions pinned to runner id, for
// the runner detail view. A session counts when its run is not terminal, the
// run is still at the session's node, and the NEWEST record of that node
// (highest attempt, then latest start) carries session_pin_runner = id. The
// state filter is wider than ListPinned's: a session mid-turn is pinned too.
func (x *SessionPinIndex) ListByRunner(ctx context.Context, id runner.RunnerID) ([]runner.RunnerSession, error) {
	rows, err := x.db.QueryContext(ctx, `
SELECT ne.instance_id, ne.node_id, ne.session_generation
FROM node_executions ne
JOIN instances i ON i.id = ne.instance_id
WHERE ne.session_pin_runner = ?
  AND i.state NOT IN ('completed', 'failed', 'cancelled')
  AND i.current_node_id = ne.node_id
  AND ne.id = (SELECT x.id FROM node_executions x
               WHERE x.instance_id = ne.instance_id AND x.node_id = ne.node_id
               ORDER BY x.attempt DESC, x.started_at DESC LIMIT 1)
ORDER BY ne.instance_id, ne.node_id`, string(id))
	if err != nil {
		return nil, fmt.Errorf("listing sessions pinned to %s: %w", id, err)
	}
	defer rows.Close()
	out := []runner.RunnerSession{}
	for rows.Next() {
		var run, node string
		var gen int64
		if err := rows.Scan(&run, &node, &gen); err != nil {
			return nil, fmt.Errorf("scanning session pinned to %s: %w", id, err)
		}
		runID, err := parseUUID(run)
		if err != nil {
			return nil, err
		}
		out = append(out, runner.RunnerSession{RunID: runID, NodeID: node, Generation: gen})
	}
	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("listing sessions pinned to %s: %w", id, err)
	}
	return out, nil
}
