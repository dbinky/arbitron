# Remote Runners — Phase 4 Task 9: Mid-turn recovery (turn restart, automatic resend, first-turn re-run)


## Alignment correction — exact replay receipt, persistent retries and client identity

Every turn uses P4 T3's durable request/accepted binding and P4 T6's exact completion sink. A retry creates a fresh attempt sink; failed/import/export jobs cannot become the turn's completion. `turnLeaseHold.Adopt` refreshes context and token generation used by all exporters/commits; do not leave the old `ContextWithTurnLease` value in attempt contexts. A move result does not by itself supply the completed stream job fence.

Bounded recovery count limits one synchronous worker pass. Exhausted pass budget leaves the same intent pending with durable `recovering` or `waiting_capacity` projection and yields to P4 T10's retry worker; it does not complete/drop the user's accepted message or convert capacity exhaustion into permanent restoration failure. First-turn replay is rescheduled through its durable invocation, including resolution startup, and never requires re-entering prompt/nonce.

Consume P4 T8's provisional native import marker. A deterministic first-resume refusal (provider/adapter failure on that provisional session) clears the marker through one fenced fallback, restores last committed workspace, rebuilds original prompt+transcript and sends exact intent message once. A second deterministic failure is a visible restoration error; never loop unboundedly or silently truncate context. Backend/family/tools remain accepted values throughout.

All `interactive.token`, `interactive.message`, `interactive.turn_restarted`, `interactive.context_notice` and history metadata carry `nodeId`, `invocationId`, `turnIndex`, `requestId` and `generation`. Producers are `InteractiveExecutor.streamFirstTurn`, handler `streamChatResponse`, group-resolution streaming and publish helpers (this task and P4 T11); P4 T12 transports/history hydrates them, P5 T7 consumes them. Restart generation is the actual reserved generation returned by mover, not a guessed `old+1`. Clear partial output as soon as interruption is known, then publish the authoritative generation before new tokens. Publish user message once per request ID; replay does not duplicate the user's transcript/visible message.

**Goal:** When a pinned session's turn is interrupted by classified exhaustion, logout or runner loss, discard the partial turn, publish `interactive.turn_restarted`, move the session under the SAME held lease, and resend the SAME user message automatically. A first turn interrupted the same way re-runs the whole step elsewhere with a fresh session that reuses the original prompt and nonce.

**Architecture:** The dispatcher no longer re-places session-affinity work transparently. For `AffinitySession`, a classified exhausted/logged_out/runner_lost outcome fails the job, which fences the old owner, and the dispatcher returns `engine.SessionMoveRequiredError` (`runner.ErrSessionMoveRequired` is the same sentinel). `conversationHandler.HandleMessage` and `InteractiveExecutor.Execute` already hold the turn lease through P4 T2's `turnLeaseHold`. Each wraps its stream in a bounded recovery loop that calls `engine.SessionMover` (P4 T8) with `hold.Lease()`, adopts the bumped generation through `(*turnLeaseHold).Adopt`, and resends under a new operation id (`…/g<generation>`). Every `interactive.token` carries the generation that produced it, so clients can drop tokens from a superseded generation.

**Tech Stack:** Go 1.25.5, testify, google/uuid.

```go
// domain/engine/session_interruption.go
package engine

import (
	"errors"
	"fmt"
)

// ErrSessionMoveRequired marks a session-affinity turn interrupted by a
// classified exhaustion, logout or runner loss: the caller must move the
// session (SessionMover) and resend, never retry on the same pin.
var ErrSessionMoveRequired = errors.New("engine: interactive session must move to another runner")

// SessionMoveRequiredError carries the move reason (MoveReason*), the runner
// and source that held the session, and the classified cause.
type SessionMoveRequiredError struct {
	Reason string
	From   string
	Source string
	Err    error
}

func (e *SessionMoveRequiredError) Error() string {
	return fmt.Sprintf("session must move from runner %s (%s): %v", e.From, e.Reason, e.Err)
}

func (e *SessionMoveRequiredError) Unwrap() error { return e.Err }

func (e *SessionMoveRequiredError) Is(target error) bool { return target == ErrSessionMoveRequired }
```

Append to `domain/engine/turn_lease.go` directly after `func (h *turnLeaseHold) Lease() TurnLease { … }`:

```go
// Adopt takes a lease returned by BumpGeneration for the SAME token (the
// session mover reserving the next generation mid-turn). Leases of another
// token or an older generation are ignored.
func (h *turnLeaseHold) Adopt(l TurnLease) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if l.Token == h.lease.Token && l.Key == h.lease.Key && l.Generation >= h.lease.Generation {
		h.lease = l
	}
}
```

```go
func sessionMoveReason(c OutcomeClass) (string, bool) {
	switch c {
	case OutcomeExhausted:
		return engine.MoveReasonExhausted, true
	case OutcomeLoggedOut:
		return engine.MoveReasonLoggedOut, true
	case OutcomeRunnerLost:
		return engine.MoveReasonRunnerLost, true
	}
	return "", false
}

// NewSessionMoveRequired wraps cause (outcome attached) for the session's caller.
func NewSessionMoveRequired(a Assignment, o SourceOutcome, cause error) error {
	reason, _ := sessionMoveReason(o.Class)
	return &engine.SessionMoveRequiredError{Reason: reason, From: string(a.Job.RunnerID), Source: string(a.Job.SourceID), Err: WithOutcome(cause, o)}
}

// interruptSession handles a classified outcome of a session-affinity job.
// It marks the source (exhaustion/logout), FAILS the attempt so its fence goes
// stale and its slot is released, and returns the move-required error.
// ok=false leaves the Phase 1 handling in place: transient backoff on the same
// source, other failures, and transparent re-placement of non-session work.
func interruptSession(ctx context.Context, health HealthTransitioner, ledger Ledger, req ExecRequirements, a Assignment, o SourceOutcome, cause error) (error, bool) {
	if req.Affinity != AffinitySession {
		return nil, false
	}
	if _, ok := sessionMoveReason(o.Class); !ok {
		return nil, false
	}
	if o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut {
		if err := health.ApplyOutcome(ctx, a.Job.SourceID, o); err != nil {
			return fmt.Errorf("dispatch: apply %s to %s: %w", o.Class, a.Job.SourceID, err), true
		}
	}
	if err := ledger.Fail(ctx, a.Fence, o.Class); err != nil && !errors.Is(err, ErrFenced) {
		return fmt.Errorf("dispatch: fence interrupted session attempt: %w", err), true
	}
	return NewSessionMoveRequired(a, o, cause), true
}
```
