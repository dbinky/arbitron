# Remote Runners — Phase 4 Task 9: Mid-turn recovery (turn restart, automatic resend, first-turn re-run)


## Alignment correction — exact replay receipt, persistent retries and client identity

Every turn uses P4 T3's durable request/accepted binding and P4 T6's exact completion sink. A retry creates a fresh attempt sink; failed/import/export jobs cannot become the turn's completion. `turnLeaseHold.Adopt` refreshes context and token generation used by all exporters/commits; do not leave the old `ContextWithTurnLease` value in attempt contexts. A move result does not by itself supply the completed stream job fence.

Bounded recovery count limits one synchronous worker pass. Exhausted pass budget leaves the same intent pending with durable `recovering` or `waiting_capacity` projection and yields to P4 T10's retry worker; it does not complete/drop the user's accepted message or convert capacity exhaustion into permanent restoration failure. First-turn replay is rescheduled through its durable invocation, including resolution startup, and never requires re-entering prompt/nonce.

Consume P4 T8's provisional native import marker (decision (d), unstick 2026-11-24: this task writes its OWN fenced conversation patch and the mover stays move-only; steps in Cycle 3b). A deterministic first-resume refusal (provider/adapter failure on that provisional session) clears the marker through one fenced fallback, restores last committed workspace, rebuilds original prompt+transcript and sends exact intent message once. A second deterministic failure is a visible restoration error; never loop unboundedly or silently truncate context. Backend/family/tools remain accepted values throughout.

All `interactive.token`, `interactive.message`, `interactive.turn_restarted`, `interactive.context_notice` and history metadata carry `nodeId`, `invocationId`, `turnIndex`, `requestId` and `generation`. Producers are `InteractiveExecutor.streamFirstTurn`, handler `streamChatResponse`, group-resolution streaming and publish helpers (this task and P4 T11); P4 T12 transports/history hydrates them, P5 T7 consumes them. Restart generation is the actual reserved generation returned by mover, not a guessed `old+1`. Clear partial output as soon as interruption is known, then publish the authoritative generation before new tokens. Publish user message once per request ID; replay does not duplicate the user's transcript/visible message.

**Goal:** When a pinned session's turn is interrupted by classified exhaustion, logout or runner loss, discard the partial turn, publish `interactive.turn_restarted`, move the session under the SAME held lease, and resend the SAME user message automatically. A first turn interrupted the same way re-runs the whole step elsewhere with a fresh session that reuses the original prompt and nonce.

**Architecture:** The dispatcher no longer re-places session-affinity work transparently. For `AffinitySession`, a classified exhausted/logged_out/runner_lost outcome fails the job, which fences the old owner, and the dispatcher returns `engine.SessionMoveRequiredError` (`runner.ErrSessionMoveRequired` is the same sentinel). `conversationHandler.HandleMessage` and `InteractiveExecutor.Execute` already hold the turn lease through P4 T2's `turnLeaseHold`. Each wraps its stream in a bounded recovery loop that calls `engine.SessionMover` (P4 T8) with `hold.Lease()`, adopts the bumped generation through `(*turnLeaseHold).Adopt`, and resends under a new operation id (`…/g<generation>`). Every `interactive.token` carries the generation that produced it, so clients can drop tokens from a superseded generation.

```go
// domain/engine/session_interruption.go
```
```go
package engine

import (
	"errors"
	"fmt"
```

```go
// ErrSessionMoveRequired marks a session-affinity turn interrupted by a
// classified exhaustion, logout or runner loss: the caller must move the
// session (SessionMover) and resend, never retry on the same pin.
var ErrSessionMoveRequired = errors.New("engine: interactive session must move to another runner")

// SessionMoveRequiredError carries the move reason (MoveReason*), the runner
// and source that held the session, and the classified cause.
type SessionMoveRequiredError struct {
	Reason string
	From   string
	Source string
	Err    error
}

func (e *SessionMoveRequiredError) Error() string {
	return fmt.Sprintf("session must move from runner %s (%s): %v", e.From, e.Reason, e.Err)
}

func (e *SessionMoveRequiredError) Unwrap() error { return e.Err }

func (e *SessionMoveRequiredError) Is(target error) bool { return target == ErrSessionMoveRequired }
```

```go
// Adopt takes a lease returned by BumpGeneration for the SAME token (the
// session mover reserving the next generation mid-turn). Leases of another
// token or an older generation are ignored.
func (h *turnLeaseHold) Adopt(l TurnLease) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if l.Token == h.lease.Token && l.Key == h.lease.Key && l.Generation >= h.lease.Generation {
		h.lease = l
	}
}
```

```go
func (s *dsStreamRunner) Run(_ context.Context, a runner.Assignment, _ runner.StepJob) (runner.StepOutput, error) {
	s.mu.Lock()
	s.assigns = append(s.assigns, a)
	s.mu.Unlock()
	if a.Job.RunnerID != s.id {

	ch := make(chan engine.ChatChunk, len(s.chunks))

		ch <- c
	}
	close(ch)
	return runner.StepOutput{Stream: ch}, nil
}
```

```go
// ErrSessionMoveRequired is engine.ErrSessionMoveRequired (one sentinel for both layers).
var ErrSessionMoveRequired = engine.ErrSessionMoveRequired

func sessionMoveReason(c OutcomeClass) (string, bool) {
	switch c {
	case OutcomeExhausted:
		return engine.MoveReasonExhausted, true
	case OutcomeLoggedOut:
		return engine.MoveReasonLoggedOut, true
	case OutcomeRunnerLost:
		return engine.MoveReasonRunnerLost, true
	}
	return "", false
}

// NewSessionMoveRequired wraps cause (outcome attached) for the session's caller.
func NewSessionMoveRequired(a Assignment, o SourceOutcome, cause error) error {
	reason, _ := sessionMoveReason(o.Class)
	return &engine.SessionMoveRequiredError{Reason: reason, From: string(a.Job.RunnerID), Source: string(a.Job.SourceID), Err: WithOutcome(cause, o)}
}

// interruptSession handles a classified outcome of a session-affinity job.
// It marks the source (exhaustion/logout), FAILS the attempt so its fence goes
// stale and its slot is released, and returns the move-required error.
// ok=false leaves the Phase 1 handling in place: transient backoff on the same
// source, other failures, and transparent re-placement of non-session work.
func interruptSession(ctx context.Context, health HealthTransitioner, ledger Ledger, req ExecRequirements, a Assignment, o SourceOutcome, cause error) (error, bool) {
	if req.Affinity != AffinitySession {
		return nil, false
	}
	if _, ok := sessionMoveReason(o.Class); !ok {
		return nil, false
	}
	if o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut {
		if err := health.ApplyOutcome(ctx, a.Job.SourceID, o); err != nil {
			return fmt.Errorf("dispatch: apply %s to %s: %w", o.Class, a.Job.SourceID, err), true
		}
	}
	if err := ledger.Fail(ctx, a.Fence, o.Class); err != nil && !errors.Is(err, ErrFenced) {
		return fmt.Errorf("dispatch: fence interrupted session attempt: %w", err), true
	}
	return NewSessionMoveRequired(a, o, cause), true
}
```

```go
// ErrRecoveryBudgetExhausted: this synchronous pass used its move budget. The
// accepted message stays PENDING for P4 T10's retry worker; it is never
// completed or dropped.
var ErrRecoveryBudgetExhausted = errors.New("engine: session recovery budget for this pass is exhausted")

// turnRun is one accepted turn's recovery state.
type turnRun struct {
	instanceID       uuid.UUID
	nodeID           string
	exec             *instance.NodeExecution
	binding          provider.ResolvedBinding // the accepted binding; never re-resolved on resend
	provider         ChatProvider
	req              ChatRequest // the exact durable request; Prompt/SessionID change only by move or rebuild
	bus              EventBus
	hold             *turnLeaseHold
	message          string
	turnIndex        int
	requestID        uuid.UUID
	workDir          string
	resourceID       uuid.UUID // P4 T11: the resolution resource of a group session
	restoreWorkspace bool
}

// identity is the turn identity at the CURRENT held generation.
func (run *turnRun) identity(ctx context.Context) InteractiveTurnIdentity {
	inv := uuid.Nil
	if id, ok := StepIdentityFromContext(ctx); ok {
		inv = id.InvocationID
	}
	return InteractiveTurnIdentity{RunID: run.instanceID, NodeID: run.nodeID, InvocationID: inv,
		RequestID: run.requestID, TurnIndex: run.turnIndex, Generation: run.hold.Lease().Generation}
}

// runTurnWithRecovery streams one accepted turn. A classified interruption
// moves the session under the HELD lease (at most h.maxMoves times in this
// pass), adopts the reserved generation and resends the SAME message under
// operation ".../g<generation>". A refused provisional native resume takes
// Cycle 3b's single fenced fallback.
func (h *conversationHandler) runTurnWithRecovery(ctx context.Context, run *turnRun) (string, string, error) {
	moves, fellBack := 0, false
	for {
		turn := run.identity(ctx)
		attemptCtx := ContextWithTurnLease(ctx, run.hold.Lease()) // Adopt refreshes what every attempt sees
		if moves > 0 || fellBack {
			attemptCtx = WithSubOperation(attemptCtx, fmt.Sprintf("g%d", turn.Generation), OperationTurn)
		}
		attemptSink := NewStepCompletionSink() // fresh per dispatch
		attemptCtx = ContextWithStepCompletionSink(attemptCtx, attemptSink)

		resp, sid, err := h.streamChatResponse(attemptCtx, run.instanceID, run.provider, run.req, run.bus, turn.Generation)
		if err == nil {
			if outer, ok := StepCompletionSinkFromContext(ctx); ok {
				for _, c := range attemptSink.Completions() {
					if rerr := outer.Record(c); rerr != nil {
						return "", "", rerr
					}
				}
			}
			return resp, sid, nil
		}

		// P4 T9 Cycle 3b: one fenced fallback for a refused provisional native resume.
		if !fellBack && isProvisionalResumeRefusal(ctx, run.exec.LLMConversation, err) {
			fellBack = true
			if run.req, err = h.provisionalResumeFallback(ctx, run, turn, err); err != nil {
				return "", "", err
			}
			continue // resend the SAME message once: same generation, no move
		}
		if fellBack && !errors.Is(err, ErrSessionMoveRequired) && ctx.Err() == nil {
			return "", "", fmt.Errorf("%w: rebuilt session failed again: %w", ErrSessionRestoreFailed, err)
		}

		var interrupted *SessionMoveRequiredError
		if !errors.As(err, &interrupted) || h.mover == nil || ctx.Err() != nil {
			return "", "", err
		}
		if moves >= h.maxMoves {
			return "", "", fmt.Errorf("%w: %w: %d moves in this pass: %w", ErrSessionRestoreFailed, ErrRecoveryBudgetExhausted, moves, err)
		}
		moves++
		res, merr := h.mover.MoveSession(ctx, run.hold.Lease(), SessionMoveRequest{
			RunID: run.instanceID, InvocationID: turn.InvocationID, ExecutionID: run.exec.ID, NodeID: run.nodeID,
			TurnIndex: run.turnIndex, Reason: interrupted.Reason, From: interrupted.From, Binding: run.binding,
			WorkDir: run.workDir, ResourceID: run.resourceID, RestoreWorkspace: run.restoreWorkspace, RequestID: run.requestID,
		})
		if merr != nil {
			return "", "", merr // a SessionWaitError (ErrNoSessionTarget) keeps the intent pending, see (e)
		}
		lease := run.hold.Lease()
		lease.Generation = res.Generation // the ACTUAL reserved generation, never old+1
		run.hold.Adopt(lease)
		if run.hold.Lease().Generation != res.Generation {
			return "", "", fmt.Errorf("session move: reserved generation %d not adopted: %w", res.Generation, ErrTurnFenced)
		}
		run.req.Prompt, run.req.SessionID = run.message, res.SessionID
		if res.PendingRebuild {
			primer, perr := BuildRebuildPrompt(run.exec.LLMConversation, run.message, RebuildLimitBytes(run.binding.ContextWindow))
			if perr != nil {
				return "", "", fmt.Errorf("%w: %w", ErrSessionRestoreFailed, perr)
			}
			run.req.Prompt, run.req.SessionID = primer, ""
		}
		restarted := run.identity(ctx)
		PublishTurnRestarted(run.bus, restarted)
		if res.Lossy {
			PublishContextNotice(run.bus, restarted, res.Notice)
		}
	}
}
```

**Prerequisites:** Cycle 3 (the `rrHarness`, `turnRun` and `runTurnWithRecovery` loop) and P4 T8 Cycle 3b (`engine.ConversationKeyProvisionalResume`, which the mover sets when it commits a native import).

**Decision (d), user 2026-11-24, recorded in contracts "Decisions (unstick 2026-11-24)".** The mover stays move-only. When the FIRST resume of a provisionally imported native session is refused, this task writes its OWN conversation patch, fenced by the exact session generation the turn holds. It does not call the mover again, and it does not use the unfenced `PatchSessionFields`. The single fallback then does the following, in order:
1. One generation-fenced patch: `provisionalResume` → deleted, `sessionId` → deleted, `pendingRebuild` → `true`. A stale generation (another writer moved the session) or a closed session writes nothing and surfaces `engine.ErrTurnFenced`.
2. For agent turns that restore their workspace (`turnRun.restoreWorkspace`, Cycle 3), restore the last committed workspace.
3. Rebuild the original prompt (same nonce) plus the transcript with `BuildRebuildPrompt`, publish the lossy context notice, and resend the exact intent message ONCE, under the same generation, with no move.

A second deterministic failure is a visible `engine.ErrSessionRestoreFailed`; the loop never runs a third attempt. Backend, family and tools stay the accepted values (the request is the turn's own `run.req`).

```go
// refusedThen: call 1 is the harness refusing the provisional native resume;
// call 2 streams the rebuilt reply, or fails with second.
func refusedThen(reply string, second error) func(context.Context, engine.ChatRequest) (<-chan engine.ChatChunk, error) {
	var mu sync.Mutex
	calls := 0
	return func(_ context.Context, _ engine.ChatRequest) (<-chan engine.ChatChunk, error) {
		mu.Lock()
		calls++
		n := calls
		mu.Unlock()
		ch := make(chan engine.ChatChunk, 2)
		switch {
		case n == 1:
			ch <- engine.ChatChunk{Error: errors.New("No conversation found with session ID: sid-b")}
		case second != nil:
			ch <- engine.ChatChunk{Error: second}
		default:
			ch <- engine.ChatChunk{Token: reply}
			ch <- engine.ChatChunk{Done: true, SessionID: "sid-c"}
		}
		close(ch)
		return ch, nil
	}
}
```

```go
// firstTurnResult is the successful first turn's stream outcome.
type firstTurnResult struct {
	response, sessionID string
	tokensIn, tokensOut int
}

// streamFirstTurnWithRecovery streams the first turn. A classified
// interruption has the mover fence the old owner and restore the workspace
// (FirstTurn: no session record, no import), adopts the reserved generation,
// and re-runs the WHOLE step with a fresh session and the same prompt/nonce,
// at most e.maxMoves times in this pass.
func (e *InteractiveExecutor) streamFirstTurnWithRecovery(ctx context.Context, node workflow.Node, instanceID uuid.UUID,
	p ChatProvider, req ChatRequest, binding provider.ResolvedBinding, workDir string, hold *turnLeaseHold, requestID uuid.UUID) (firstTurnResult, error) {
	identity := func() InteractiveTurnIdentity {
		inv := uuid.Nil
		if id, ok := StepIdentityFromContext(ctx); ok {
			inv = id.InvocationID
		}
		return InteractiveTurnIdentity{RunID: instanceID, NodeID: node.ID, InvocationID: inv, RequestID: requestID,
			TurnIndex: 1, Generation: hold.Lease().Generation}
	}
	moves := 0
	for {
		turn := identity()
		attemptCtx := ContextWithTurnLease(ctx, hold.Lease())
		if moves > 0 {
			attemptCtx = WithSubOperation(attemptCtx, fmt.Sprintf("g%d", turn.Generation), OperationTurn)
		}
		attemptSink := NewStepCompletionSink() // fresh per dispatch
		attemptCtx = ContextWithStepCompletionSink(attemptCtx, attemptSink)

		res, err := e.streamFirstTurn(attemptCtx, node, instanceID, p, req, turn.Generation)
		if err == nil {
			if outer, ok := StepCompletionSinkFromContext(ctx); ok {
				for _, c := range attemptSink.Completions() {
					if rerr := outer.Record(c); rerr != nil {
						return firstTurnResult{}, rerr
					}
				}
			}
			return res, nil
		}
		var interrupted *SessionMoveRequiredError
		if !errors.As(err, &interrupted) || e.mover == nil || ctx.Err() != nil {
			return firstTurnResult{}, err
		}
		if moves >= e.maxMoves {
			return firstTurnResult{}, fmt.Errorf("interactive %q: %w: %w: %d moves in this pass: %w",
				node.ID, ErrSessionRestoreFailed, ErrRecoveryBudgetExhausted, moves, err)
		}
		moves++
		moved, merr := e.mover.MoveSession(ctx, hold.Lease(), SessionMoveRequest{
			RunID: instanceID, InvocationID: turn.InvocationID, NodeID: node.ID, TurnIndex: 1,
			Reason: interrupted.Reason, From: interrupted.From, Binding: binding, WorkDir: workDir,
			RestoreWorkspace: binding.Kind == provider.ProfileKindAgent, FirstTurn: true, RequestID: requestID,
		})
		if merr != nil {
			return firstTurnResult{}, merr // a SessionWaitError keeps the first-turn intent pending, see (c)
		}
		lease := hold.Lease()
		lease.Generation = moved.Generation // the ACTUAL reserved generation
		hold.Adopt(lease)
		if hold.Lease().Generation != moved.Generation {
			return firstTurnResult{}, fmt.Errorf("interactive %q: reserved generation %d not adopted: %w", node.ID, moved.Generation, ErrTurnFenced)
		}
		req.SessionID = "" // fresh session: no bundle exists before the first success; Prompt (and nonce) unchanged
		PublishTurnRestarted(e.eventBus, identity())
	}
}

// streamFirstTurn is the original stream call and consume loop (steps 7-8),
// unchanged except that every token carries the producing attempt's generation.
func (e *InteractiveExecutor) streamFirstTurn(ctx context.Context, node workflow.Node, instanceID uuid.UUID,
	p ChatProvider, req ChatRequest, generation int64) (firstTurnResult, error) {
	stream, err := p.StreamChat(ctx, req)
	if err != nil {
		return firstTurnResult{}, fmt.Errorf("interactive %q: stream call: %w", node.ID, err)
	}
	if stream == nil {
		return firstTurnResult{}, fmt.Errorf("interactive %q: stream closed without completion (nil stream)", node.ID)
	}
	var out firstTurnResult
	var responseBuilder strings.Builder
	sawDone := false
	for !sawDone {
		var chunk ChatChunk
		var open bool
		select {
		case <-ctx.Done():
			return firstTurnResult{}, fmt.Errorf("interactive %q: stream cancelled: %w", node.ID, ctx.Err())
		case chunk, open = <-stream:
		}
		// A buffered chunk or channel closure can win the select even after
		// cancellation. Never treat that as a successfully completed turn.
		if err := ctx.Err(); err != nil {
			return firstTurnResult{}, fmt.Errorf("interactive %q: stream cancelled: %w", node.ID, err)
		}
		if !open {
			break
		}
		if chunk.Error != nil {
			return firstTurnResult{}, fmt.Errorf("interactive %q: stream error: %w", node.ID, chunk.Error)
		}
		if chunk.SessionID != "" {
			out.sessionID = chunk.SessionID
		}
		if chunk.Token != "" {
			responseBuilder.WriteString(chunk.Token)
			e.eventBus.Publish(instanceID, Event{
				Type:      EventTypeInteractiveToken,

			})
		}
		if chunk.Done {
			out.tokensIn, out.tokensOut, sawDone = chunk.TokensIn, chunk.TokensOut, true
		}
	}
	// Publishing the last token can itself race cancellation. Check again
	// before reporting success.
	if err := ctx.Err(); err != nil {
		return firstTurnResult{}, fmt.Errorf("interactive %q: stream cancelled: %w", node.ID, err)
	}
	// DATA INTEGRITY (PR #18): a stream that closed without a terminal Done
	// chunk was truncated; it is never a completed success.
	if !sawDone {
		return firstTurnResult{}, fmt.Errorf("interactive %q: stream closed without completion", node.ID)
	}
	out.response = responseBuilder.String()
	return out, nil
}
```
