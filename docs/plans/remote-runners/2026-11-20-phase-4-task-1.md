# Remote Runners — Phase 4 Task 1: Session config, migration 045 and NodeExecution session state


## Alignment correction — invocation identity and monotonic turn commits

Migration 045 also adds `node_executions.session_invocation_id TEXT` and durable turn identity (`request_id TEXT`, `accepted_binding TEXT NOT NULL DEFAULT '{}'`) to turn intents. P4 T3 owns accepted-binding serialization; P4 T11 owns resolution resource rows and P4 T12 widens session transfer direction. Include all additions in this migration's up/down and migration tests; do not allocate competing migration numbers.

`SessionState` and `NodeExecution` gain `InvocationID uuid.UUID` / `SessionInvocationID uuid.UUID`; trace JSON exposes `sessionInvocationId`. `TurnCommitRepo.CommitTurn` (P4 T6) writes the exact `StepIdentity.InvocationID`; `SessionMoveRepo` (P4 T8) preserves/checks it. Every pin/recovery/detail query in P4 T7/T10/T14 selects the live session invocation/execution, never `MAX(attempt)` across node visits. Attempt counters reset on a back-edge. A lease's same generation does not authorize overwriting a newer committed turn: CommitTurn also CAS-checks expected prior checkpoint/intent turn and is idempotent by request ID. `SetSessionState` is an internal transaction helper, not an alternate unfenced production writer.

**Required red/green tests** (`go test ./adapter/sqlite ./adapter/http ./domain/config ./adapter/config -run 'Session|Migration045|Phase4' -count=1`): Happy `TestNodeExecutionSession_SetAndReadBack`; Success `TestInstanceHandler_GetTrace_ExposesSessionState`; Failure `TestNodeExecutionSession_StaleGenerationRejected`; Error `TestSessionState_ClosedDatabasePropagatesReadError`; Edge **add** `TestSessionState_NewInvocationWinsOverOlderHigherAttempt` and `TestSessionState_OldTurnSameGenerationCannotOverwriteNewCheckpoint`. Drive the latter through P4 T6's transaction. Production root P4 T13 must create a real first-turn row and REST trace nonempty identity/ref/pin; removing setter/receipt wiring makes the sink assertion fail.

**Goal:** Add the Phase 4 runner config keys, migration `045_interactive_sessions`, and the durable per-session state (checkpoint ref, pinned runner, session generation, move history) on `instance.NodeExecution`, readable through the trace DTOs.

**Architecture:** Session state lives in three new `node_executions` columns plus a `session_moves` table (decision: **columns, not LLMConversation JSON keys** — contracts §1 migration 045). `LLMConversation.messages` stays the source of truth for the transcript. The columns are written ONLY through the new hand-written `instance.SessionStateStore` methods (generation-CAS fenced), never by the sqlc `Create`/`Update` paths, so no legacy writer can clobber a pin or roll a generation back. Readers (`GetByInstanceAndNode`, `ListByInstance`) attach the columns and the move history, so the HTTP trace DTO and MCP `trace_get` (which marshals `instance.NodeExecution` directly) expose them.

**Tech Stack:** Go 1.25, SQLite (modernc), hand-written SQL, koanf defaults, testify.

**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` (Recovery and session continuity); `docs/designs/2026-11-19-remote-runners-design-phase-4.md` §2 (Conversation record row), §3.2, §3.3, §5 (Turn lease/renewal row; Lease TTL row), "Deferred to plans" (SQLite migrations, Config). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §1 (045), §2 (Phase 4 config), §17.

```sql
-- Remote Runners Phase 4: durable interactive sessions.
-- Times in these tables are unix milliseconds (INTEGER) so lease expiry and
-- intent ordering compare exactly (timeToString is second-granular).

-- One row per session lease key ("run:<id>" or "resolution:<run>/<merge>/<attempt>").
-- token NULL = released. generation is the session generation: it only grows.
CREATE TABLE turn_leases (
    key        TEXT PRIMARY KEY,
    token      TEXT,
    generation INTEGER NOT NULL DEFAULT 1,
    expires_at INTEGER NOT NULL DEFAULT 0,
    holder     TEXT NOT NULL DEFAULT ''
);

-- An accepted interactive operation, persisted before dispatch/ack and
-- completed only with the turn commit (RR-12).
CREATE TABLE turn_intents (
    id                   TEXT PRIMARY KEY,
    request_id           TEXT NOT NULL UNIQUE,
    accepted_binding     TEXT NOT NULL DEFAULT '{}',
    lease_key            TEXT NOT NULL,
    run_id               TEXT NOT NULL,
    invocation_id        TEXT NOT NULL,
    node_id              TEXT NOT NULL,
    turn_index           INTEGER NOT NULL,
    kind                 TEXT NOT NULL CHECK (kind IN ('first', 'message', 'end', 'abandon', 'move')),
    prompt               TEXT NOT NULL DEFAULT '',
    system_prompt        TEXT NOT NULL DEFAULT '',
    nonce                TEXT NOT NULL DEFAULT '',
    message              TEXT NOT NULL DEFAULT '',
    model                TEXT NOT NULL DEFAULT '',
    tools                TEXT NOT NULL DEFAULT '[]',
    prior_checkpoint_ref TEXT NOT NULL DEFAULT '',
    session_generation   INTEGER NOT NULL DEFAULT 0,
    operation_id         TEXT NOT NULL DEFAULT '',
    created_at           INTEGER NOT NULL,
    completed_at         INTEGER
);
CREATE INDEX idx_turn_intents_pending ON turn_intents (completed_at, lease_key, created_at);

-- Committed session moves (never for load).
CREATE TABLE session_moves (
    id            TEXT PRIMARY KEY,
    run_id        TEXT NOT NULL,
    invocation_id TEXT NOT NULL,
    node_id       TEXT NOT NULL,
    from_runner   TEXT NOT NULL,
    to_runner     TEXT NOT NULL,
    reason        TEXT NOT NULL CHECK (reason IN ('exhausted', 'logged_out', 'drain', 'runner_lost')),
    lossy         INTEGER NOT NULL DEFAULT 0,
    notice        TEXT NOT NULL DEFAULT '',
    generation    INTEGER NOT NULL,
    at            INTEGER NOT NULL
);
CREATE INDEX idx_session_moves_run ON session_moves (run_id, node_id, at);

ALTER TABLE node_executions ADD COLUMN session_invocation_id TEXT;
ALTER TABLE node_executions ADD COLUMN session_checkpoint_ref TEXT;
ALTER TABLE node_executions ADD COLUMN session_pin_runner TEXT;
ALTER TABLE node_executions ADD COLUMN session_generation INTEGER NOT NULL DEFAULT 0;
```

	"context"

	"time"

	"github.com/arbitron/arbitron/domain/instance"

var _ instance.SessionStateStore = (*NodeExecutionRepo)(nil)

// sqlExecQuerier is satisfied by *sql.DB and *sql.Tx so the same fenced
// statements run standalone or inside a turn-commit transaction.
type sqlExecQuerier interface {
	ExecContext(ctx context.Context, query string, args ...any) (sql.Result, error)
	QueryRowContext(ctx context.Context, query string, args ...any) *sql.Row
}

// setSessionStateTx writes the session columns iff st.Generation is not older
// than the stored generation.
func setSessionStateTx(ctx context.Context, q sqlExecQuerier, execID uuid.UUID, st instance.SessionState) error {
	res, err := q.ExecContext(ctx, `UPDATE node_executions
SET session_checkpoint_ref = ?, session_pin_runner = ?, session_generation = ?
WHERE id = ? AND session_generation <= ?`,
		ptrToNullString(st.CheckpointRef), ptrToNullString(st.PinRunner), st.Generation, uuidToString(execID), st.Generation)
	if err != nil {
		return fmt.Errorf("setting session state: %w", err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return fmt.Errorf("setting session state: %w", err)
	}
	if n == 1 {
		return nil
	}
	return missingOrStale(ctx, q, execID)
}

func missingOrStale(ctx context.Context, q sqlExecQuerier, execID uuid.UUID) error {
	var count int
	if err := q.QueryRowContext(ctx, `SELECT COUNT(*) FROM node_executions WHERE id = ?`, uuidToString(execID)).Scan(&count); err != nil {
		return fmt.Errorf("checking node execution %s: %w", execID, err)
	}
	if count == 0 {
		return fmt.Errorf("node execution %s: %w", execID, instance.ErrNotFound)
	}
	return fmt.Errorf("node execution %s: %w", execID, instance.ErrStaleSessionGeneration)
}

// SetSessionState implements instance.SessionStateStore.
func (r *NodeExecutionRepo) SetSessionState(ctx context.Context, execID uuid.UUID, st instance.SessionState) error {
	return setSessionStateTx(ctx, r.db, execID, st)
}

// RecordSessionMove implements instance.SessionStateStore: the pin/generation
// update and the move row commit together or not at all.
func (r *NodeExecutionRepo) RecordSessionMove(ctx context.Context, execID uuid.UUID, m instance.SessionMoveRecord) error {
	if m.ID == uuid.Nil {
		m.ID = uuid.New()
	}
	if m.At.IsZero() {
		m.At = time.Now().UTC()
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("begin session move: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	res, err := tx.ExecContext(ctx, `UPDATE node_executions SET session_pin_runner = ?, session_generation = ?
WHERE id = ? AND session_generation < ?`, m.ToRunner, m.Generation, uuidToString(execID), m.Generation)
	if err != nil {
		return fmt.Errorf("recording session move: %w", err)
	}
	n, err := res.RowsAffected()
	if err != nil {
		return fmt.Errorf("recording session move: %w", err)
	}
	if n != 1 {
		return missingOrStale(ctx, tx, execID)
	}
	lossy := 0
	if m.Lossy {
		lossy = 1
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO session_moves
(id, run_id, invocation_id, node_id, from_runner, to_runner, reason, lossy, notice, generation, at)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
		uuidToString(m.ID), uuidToString(m.RunID), uuidToString(m.InvocationID), m.NodeID, m.FromRunner, m.ToRunner,
		m.Reason, lossy, m.Notice, m.Generation, m.At.UTC().UnixMilli()); err != nil {
		return fmt.Errorf("inserting session move: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("commit session move: %w", err)
	}
	return nil
}

// LatestSessionState implements instance.SessionStateStore using the same
// "newest attempt" ordering as GetByInstanceAndNode.
func (r *NodeExecutionRepo) LatestSessionState(ctx context.Context, runID uuid.UUID, nodeID string) (instance.SessionState, bool, error) {
	var ref, pin sql.NullString
	var gen int64
	err := r.db.QueryRowContext(ctx, `SELECT session_checkpoint_ref, session_pin_runner, session_generation
FROM node_executions WHERE instance_id = ? AND node_id = ? ORDER BY attempt DESC LIMIT 1`,
		uuidToString(runID), nodeID).Scan(&ref, &pin, &gen)
	if errors.Is(err, sql.ErrNoRows) {
		return instance.SessionState{}, false, nil
	}
	if err != nil {
		return instance.SessionState{}, false, fmt.Errorf("reading session state: %w", err)
	}
	return instance.SessionState{CheckpointRef: nullStringToPtr(ref), PinRunner: nullStringToPtr(pin), Generation: gen}, true, nil
}

// attachSessionState fills the session columns and move history on execs (all
// records of instanceID). A move belongs to the record of its node with the
// greatest StartedAt not after the move.
func (r *NodeExecutionRepo) attachSessionState(ctx context.Context, instanceID uuid.UUID, execs []*instance.NodeExecution) error {
	if len(execs) == 0 {
		return nil
	}
	byID := make(map[uuid.UUID]*instance.NodeExecution, len(execs))
	for _, e := range execs {
		byID[e.ID] = e
	}
	rows, err := r.db.QueryContext(ctx, `SELECT id, session_checkpoint_ref, session_pin_runner, session_generation
FROM node_executions WHERE instance_id = ?`, uuidToString(instanceID))
	if err != nil {
		return fmt.Errorf("reading session columns: %w", err)
	}
	for rows.Next() {
		var idStr string
		var ref, pin sql.NullString
		var gen int64
		if err := rows.Scan(&idStr, &ref, &pin, &gen); err != nil {
			rows.Close()
			return fmt.Errorf("scanning session columns: %w", err)
		}
		id, err := parseUUID(idStr)
		if err != nil {
			rows.Close()
			return err
		}
		if e, ok := byID[id]; ok {
			e.SessionCheckpointRef = nullStringToPtr(ref)
			e.SessionPinRunner = nullStringToPtr(pin)
			e.SessionGeneration = gen
		}
	}
	if err := rows.Err(); err != nil {
		rows.Close()
		return fmt.Errorf("iterating session columns: %w", err)
	}
	rows.Close()

	mrows, err := r.db.QueryContext(ctx, `SELECT id, run_id, invocation_id, node_id, from_runner, to_runner, reason, lossy, notice, generation, at
FROM session_moves WHERE run_id = ? ORDER BY at, generation`, uuidToString(instanceID))
	if err != nil {
		return fmt.Errorf("reading session moves: %w", err)
	}
	defer mrows.Close()
	for mrows.Next() {
		var idStr, runStr, invStr string
		var m instance.SessionMoveRecord
		var lossy int
		var atMs int64
		if err := mrows.Scan(&idStr, &runStr, &invStr, &m.NodeID, &m.FromRunner, &m.ToRunner, &m.Reason, &lossy, &m.Notice, &m.Generation, &atMs); err != nil {
			return fmt.Errorf("scanning session move: %w", err)
		}
		if m.ID, err = parseUUID(idStr); err != nil {
			return err
		}
		if m.RunID, err = parseUUID(runStr); err != nil {
			return err
		}
		if m.InvocationID, err = parseUUID(invStr); err != nil {
			return err
		}
		m.Lossy = lossy == 1
		m.At = time.UnixMilli(atMs).UTC()
		var owner *instance.NodeExecution
		for _, e := range execs {
			if e.NodeID != m.NodeID || e.StartedAt.After(m.At) {
				continue
			}
			if owner == nil || e.StartedAt.After(owner.StartedAt) {
				owner = e
			}
		}
		if owner != nil {
			owner.SessionMoves = append(owner.SessionMoves, m)
		}
	}
	return mrows.Err()
}
