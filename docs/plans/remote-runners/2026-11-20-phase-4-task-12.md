## Alignment correction — prepared receipts, resolution resources and stream identity

P3/P4 T6's atomic candidate contract supersedes any earlier push/Latest publication: the runner pushes a PREPARED candidate under exact job + ResourceFenceRef; remote Result and StepOutput carry that receipt, and Hub records it into the operation StepCompletionSink. Only TurnCommitRepo publishes the authoritative workspace/resource pointer. A successful stream result without its required prepared receipt fails; never use a global Latest or home version. Adoption returns the same receipt to P4 T10 and never fabricates a completed job from response text.

Add `Resource *ResourceDescriptor` to domain/protocol/runner stream and session-op payloads; use P4 T11's ID/kind/canonical path/fence/committed ref shape, retaining actual parent RunID for visibility. Stream transfer tokens include both actual run and resource identity/generation, validated against ResolutionResourceRepo/resource lease. Resolution resources pull/push portable git state under their confined private resource root, not the parent's workspace or server backing directory. Every mirror/translator roundtrip and executor must preserve these fields; nil descriptor or resource mismatch prevents harness launch. P4 T13 links real `WorkingArea` resolution portability and the resource registry into transfer/runner execution; do not stop at accepting an unused field.

Expand event DTOs and all publish helpers/history hydration with `nodeId,invocationId,turnIndex,requestId,generation`; token also carries token, message carries role/content, restarted carries actual reserved generation, context notice carries notice/lossy. Persisted history supplies current identity/generation plus notices. P5 T7 uses the generation even after reconnect. No required field is inferred from token arrival order. Add bounded cleanup for SessionBlobs on success/failure/cancel/timeout/revoke; crash-restart safely retransfers from durable session store/candidate refs rather than relying on in-memory blobs.

**Goal:** Remote runners host interactive sessions end to end:
- Each turn streams its tokens back through the hub at the session's stable workdir. An `interactive_agent` turn pulls the run workspace first and pushes it after success.
- A turn from a superseded generation is fenced, never delivered.
- Session bundles are exported from, and imported into, the runner that holds the session. Export/upload completes inside the originating stream assignment under its fence; import uses a fenced `session_import` move job. Bytes travel over the Phase 3 transfer endpoints (direction `session`).
- A restarted server adopts a still-live remote turn instead of repeating it.
- The dashboard/API shapes of `interactive.turn_restarted` and `interactive.context_notice` are fixed as Go DTOs.

**Architecture:**
- **Protocol.** `adapter/runnerproto/session.go` adds the single session envelope kind `KindSessionImport` (unstick 2026-11-23: there is no `KindSessionExport`; export runs inside the originating stream, contracts §24). It carries a `Dispatch` whose `Op` equals the kind, with a `WireSessionOp` payload. Stream dispatches gain `NativeCheckpoint`/`SessionExportToken` and `Dispatch.Resource` (`WireResource`, mirroring P4 T11's `ResourceDescriptor`); the stream result's `WireChatResult.Session` carries the uploaded bundle descriptor. `Result` gains `WireSessionResult`. `WireChat` gains the session `WorkDir` and `ProfileKind`; they are set only on stream ops.
- **Hub (`domain/runner/hub_session.go`).**
  - `Hub.Run` routes session ops to `runSession`. For an import, `runSession` issues a `session`-direction transfer token and stages the bundle bytes in the persistent `SessionBlobs` (keyed by the job fence) before the offer. For an export, it reads the uploaded bytes after the result and verifies them against the reported checksum and size.
  - Stream dispatches copy the stable `WorkDir` and `ProfileKind`. Agent-kind streams attach the Phase 3 workspace plan (`workspacePlan`, P3 T8).
  - `Hub.ExportSession` implements `runner.RemoteSessionExporter` (P4 T6): it reads the exact durable parent-turn result and prepared bundle, with no additional reservation (contracts §24).
  - `Hub.AdoptTurn` implements `runner.TurnAdopter` (P4 T10) on top of the P3 T10 `AdoptionBook`.
- **HTTP (`adapter/http`).**
  - `RunnerTransferHandler` gains `PUT`/`GET /sessions/{jobId}`, authorised by the `session` token of exactly that job generation.
  - The connect translators map the new fields and choose the session envelope kinds.
  - `session_events.go` defines the event DTOs, and history hydration adds persisted lossy notices.
- **Runner side.**
  - `domain/runneragent` mirrors the new payloads, and `wsclient` translates them. The transfer client gains `PutSession`/`GetSession`.
  - The executor runs session streams at a stable local directory through the interactive stream selector. Session export/import go through the linked `SessionPortabilityRegistry`; P4 T13 wires the claudecli and codex adapters into `cmd/arbitron-runner`.
- `domain/*` imports no adapter.

**Tech Stack:** Go 1.25.5, testify, modernc SQLite, chi, `net/http/httptest`, `github.com/coder/websocket` (existing stream tests).

package runnerproto

import (
	"encoding/hex"
	"errors"
	"fmt"
	"path"

	"github.com/google/uuid"
)

// KindSessionImport is the only session envelope kind (contracts §15/§24).
// Session export is NOT a separate kind: it runs inside the originating stream
// assignment and its bundle descriptor rides that stream's Result.
const KindSessionImport = "session_import"

// OpSessionImport is Dispatch.Op on a session_import frame.
const OpSessionImport = "session_import"

// SessionChecksumHeader carries the lowercase hex SHA-256 of a session bundle
// on the transfer endpoints (PUT request, GET response).
const SessionChecksumHeader = "X-Session-SHA256"

const maxSessionField = 512

// SessionKindForOp returns the envelope kind of a session op.
func SessionKindForOp(op string) (string, bool) {
	if op == OpSessionImport {
		return KindSessionImport, true
	}
	return "", false
}

// WireSessionBundle describes bundle bytes moved over the transfer endpoint.
type WireSessionBundle struct {
	Backend        string `json:"backend"`
	SessionID      string `json:"sessionId"`
	HarnessVersion string `json:"harnessVersion,omitempty"`
	OriginWorkDir  string `json:"originWorkDir,omitempty"`
	Checksum       string `json:"checksum"`
	Size           int64  `json:"size"`
}

func (b *WireSessionBundle) Validate() error {
	sum, err := hex.DecodeString(b.Checksum)
	switch {
	case b.Backend == "" || len(b.Backend) > 64:
		return errors.New("bundle.backend is required")
	case b.SessionID == "" || len(b.SessionID) > maxSessionField:
		return errors.New("bundle.sessionId is required")
	case err != nil || len(sum) != 32 || b.Checksum != hex.EncodeToString(sum):
		return errors.New("bundle.checksum must be lowercase hex SHA-256")
	case b.Size < 1:
		return errors.New("bundle.size must be positive")
	case len(b.OriginWorkDir) > maxSessionField || len(b.HarnessVersion) > 64:
		return errors.New("bundle descriptor field too long")
	}
	return nil
}

// WireResource mirrors runner.ResourceDescriptor (P4 T11 Cycle 5): the
// separately owned resource a session works in. The actual parent run stays
// in the job key; the resource never substitutes for it.
type WireResource struct {
	ID              string `json:"id"`
	Kind            string `json:"kind"` // workspace | resolution
	WorkDir         string `json:"workDir"`
	FenceKey        string `json:"fenceKey"`
	FenceOwner      string `json:"fenceOwner"`
	FenceGeneration int64  `json:"fenceGeneration"`
	FenceToken      string `json:"fenceToken"`
	CheckpointRef   string `json:"checkpointRef,omitempty"`
}

func (r *WireResource) Validate() error {
	if _, err := uuid.Parse(r.ID); err != nil {
		return errors.New("resource.id must be a UUID")
	}
	if tok, err := uuid.Parse(r.FenceToken); err != nil || tok == uuid.Nil {
		return errors.New("resource.fenceToken must be a nonzero UUID")
	}
	switch {
	case r.Kind != "workspace" && r.Kind != "resolution":
		return fmt.Errorf("resource.kind %q is not workspace or resolution", r.Kind)
	case r.WorkDir == "" || !path.IsAbs(r.WorkDir) || path.Clean(r.WorkDir) != r.WorkDir || len(r.WorkDir) > maxSessionField:
		return errors.New("resource.workDir must be a clean absolute path")
	case r.FenceKey == "" || r.FenceOwner == "" || r.FenceGeneration < 1:
		return errors.New("resource fence requires key, owner and positive generation")
	case len(r.CheckpointRef) > maxSessionField:
		return errors.New("resource.checkpointRef too long")
	}
	return nil
}

// WireSessionOp is a session_import job (a move target). TransferToken is the
// job generation's "session" transfer token for the bundle bytes.
type WireSessionOp struct {
	Backend       string             `json:"backend"`
	SessionID     string             `json:"sessionId,omitempty"`
	WorkDir       string             `json:"workDir"`
	TransferToken string             `json:"transferToken"`
	Bundle        *WireSessionBundle `json:"bundle"`
}

func (o *WireSessionOp) Validate() error {
	switch {
	case o.Backend == "" || len(o.Backend) > 64:
		return errors.New("session.backend is required")
	case o.WorkDir == "" || !path.IsAbs(o.WorkDir) || len(o.WorkDir) > maxSessionField:
		return errors.New("session.workDir must be an absolute path")
	case o.TransferToken == "" || len(o.TransferToken) > maxSessionField:
		return errors.New("session.transferToken is required")
	case o.Bundle == nil:
		return errors.New("session_import carries the bundle descriptor")
	}
	if err := o.Bundle.Validate(); err != nil {
		return err
	}
	if o.Bundle.Backend != o.Backend {
		return fmt.Errorf("bundle backend %q does not match session backend %q", o.Bundle.Backend, o.Backend)
	}
	return nil
}

// WireSessionResult is a session_import result: the resumable session id.
type WireSessionResult struct {
	SessionID string `json:"sessionId"`
}

func (r *WireSessionResult) Validate() error {
	if r.SessionID == "" || len(r.SessionID) > maxSessionField {
		return errors.New("session result names the resumable session")
	}
	return nil
}

func (d *Dispatch) validateSession() error {
	if d.Session == nil {
		return fmt.Errorf("%s dispatch carries the session payload", d.Op)
	}
	if d.Chat != nil || d.Agent != nil || d.Process != nil {
		return fmt.Errorf("%s dispatch carries only the session payload", d.Op)
	}
	return d.Session.Validate()
}

package runner

import (
	"errors"
	"sync"
)

// TransferSessionData is the transfer-token direction for session bundle
// bytes (PUT/GET /api/v1/runners/transfers/sessions/{jobId}).
const TransferSessionData = "session"

var (
	ErrSessionBlobTooLarge = errors.New("runner: session bundle exceeds the transfer limit")
	ErrSessionBlobsFull    = errors.New("runner: session bundle staging is full")
)

// SessionBlobs stages session bundle bytes in memory, keyed by the exact job
// fence that may read or write them. The hub stages imports before the offer
// and deletes them when the op ends; the transfer handler stages exports.
type SessionBlobs struct {
	mu      sync.Mutex
	perBlob int64
	total   int64
	used    int64
	m       map[Fence][]byte
}

// NewSessionBlobs bounds one bundle to perBlob bytes and all staged bundles
// together to total bytes.
func NewSessionBlobs(perBlob, total int64) *SessionBlobs {
	if perBlob <= 0 || total <= 0 || perBlob > total {
		panic("runner: NewSessionBlobs requires 0 < perBlob <= total")
	}
	return &SessionBlobs{perBlob: perBlob, total: total, m: map[Fence][]byte{}}
}

func (b *SessionBlobs) Put(f Fence, data []byte) error {
	n := int64(len(data))
	if n > b.perBlob {
		return ErrSessionBlobTooLarge
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	old := int64(len(b.m[f]))
	if b.used-old+n > b.total {
		return ErrSessionBlobsFull
	}
	b.m[f] = data
	b.used += n - old
	return nil
}

func (b *SessionBlobs) Get(f Fence) ([]byte, bool) {
	b.mu.Lock()
	defer b.mu.Unlock()
	d, ok := b.m[f]
	return d, ok
}

func (b *SessionBlobs) Delete(f Fence) {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.used -= int64(len(b.m[f]))
	delete(b.m, f)
}

package http

import (
	"errors"
	"io"
	"log/slog"
	"net/http"
	"strconv"

	"github.com/go-chi/chi/v5"

	"github.com/arbitron/arbitron/adapter/runnerproto"
	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
)

// SessionBlobStore stages session bundle bytes by job fence (*runner.SessionBlobs).
type SessionBlobStore interface {
	Put(f runner.Fence, data []byte) error
	Get(f runner.Fence) ([]byte, bool)
}

// sessionScope authorises a /sessions/{jobId} request: runner key, a
// "session" token, and the token's job must be the job in the path.
func (h *RunnerTransferHandler) sessionScope(w http.ResponseWriter, r *http.Request) (runner.Fence, bool) {
	if h.d.Sessions == nil {
		WriteError(w, http.StatusServiceUnavailable, "UNAVAILABLE", "session transfers are not enabled on this server")
		return runner.Fence{}, false
	}
	sess, _, ok := h.authorize(w, r, runner.TransferSessionData)
	if !ok {
		return runner.Fence{}, false
	}
	if chi.URLParam(r, "jobId") != sess.JobID.String() {
		WriteError(w, http.StatusForbidden, "FORBIDDEN", "transfer token is not valid for this job")
		return runner.Fence{}, false
	}
	h.extendDeadlines(w)
	return fenceOf(sess), true
}

func (h *RunnerTransferHandler) putSession(w http.ResponseWriter, r *http.Request) {
	f, ok := h.sessionScope(w, r)
	if !ok {
		return
	}
	data, err := io.ReadAll(io.LimitReader(r.Body, h.d.PartBytes+1))
	if err != nil {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", "session bundle upload interrupted")
		return
	}
	if int64(len(data)) > h.d.PartBytes {
		WriteError(w, http.StatusRequestEntityTooLarge, "SESSION_BUNDLE_TOO_LARGE", "session bundle exceeds the transfer part limit")
		return
	}
	if r.Header.Get(runnerproto.SessionChecksumHeader) != engine.BundleChecksum(data) {
		WriteError(w, http.StatusBadRequest, "CHECKSUM_MISMATCH", "session bundle checksum does not match its bytes")
		return
	}
	if err := h.d.Sessions.Put(f, data); err != nil {
		if errors.Is(err, runner.ErrSessionBlobTooLarge) {
			WriteError(w, http.StatusRequestEntityTooLarge, "SESSION_BUNDLE_TOO_LARGE", err.Error())
			return
		}
		slog.Warn("session bundle staging refused", "job", f.JobID, "error", err)
		WriteError(w, http.StatusServiceUnavailable, "UNAVAILABLE", "session bundle staging is full")
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

func (h *RunnerTransferHandler) getSession(w http.ResponseWriter, r *http.Request) {
	f, ok := h.sessionScope(w, r)
	if !ok {
		return
	}
	data, ok := h.d.Sessions.Get(f)
	if !ok {
		WriteError(w, http.StatusNotFound, "NOT_FOUND", "no session bundle is staged for this job")
		return
	}
	w.Header().Set("Content-Type", "application/octet-stream")
	w.Header().Set("Content-Length", strconv.Itoa(len(data)))
	w.Header().Set(runnerproto.SessionChecksumHeader, engine.BundleChecksum(data))
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write(data)
}

// ErrSessionBundleMissing: no uploaded bytes exist for the fence, or a staged
// ref does not resolve.
var ErrSessionBundleMissing = errors.New("runner: session bundle was not uploaded")

// SessionStaging stages session bundle bytes by exact job fence and seals a
// verified upload into an immutable ref that survives restart (contracts §24).
type SessionStaging interface {
	Put(f Fence, data []byte) error
	Get(f Fence) ([]byte, bool)
	Delete(f Fence)
	Seal(f Fence, checksum string, size int64) (ref string, err error)
	Open(ref string) ([]byte, error)
	GC(ctx context.Context, before time.Time, keep func(ref string) bool) (int, error)
}

// StagedBundleRef names a sealed bundle: staged:<jobID>/<generation>/<checksum>.
func StagedBundleRef(f Fence, checksum string) string {
	return fmt.Sprintf("staged:%s/%d/%s", f.JobID, f.Generation, checksum)
}

// ParseStagedBundleRef validates and splits a staged ref.
func ParseStagedBundleRef(ref string) (uuid.UUID, int64, string, error) {
	rest, ok := strings.CutPrefix(ref, "staged:")
	parts := strings.Split(rest, "/")
	if !ok || len(parts) != 3 {
		return uuid.Nil, 0, "", fmt.Errorf("%w: malformed staged ref %q", ErrSessionBundleMissing, ref)
	}
	job, err := uuid.Parse(parts[0])
	gen, gerr := strconv.ParseInt(parts[1], 10, 64)
	if err != nil || gerr != nil || gen < 1 || len(parts[2]) != 64 || strings.Trim(parts[2], "0123456789abcdef") != "" {
		return uuid.Nil, 0, "", fmt.Errorf("%w: malformed staged ref %q", ErrSessionBundleMissing, ref)
	}
	return job, gen, parts[2], nil
}

// Seal (memory test double) verifies the upload and keeps it under its ref.
func (b *SessionBlobs) Seal(f Fence, checksum string, size int64) (string, error) {
	ref := StagedBundleRef(f, checksum)
	b.mu.Lock()
	defer b.mu.Unlock()
	if b.sealed == nil {
		b.sealed = map[string][]byte{}
	}
	if _, ok := b.sealed[ref]; ok {
		return ref, nil
	}
	data, ok := b.m[f]
	if !ok {
		return "", ErrSessionBundleMissing
	}
	if int64(len(data)) != size || engine.BundleChecksum(data) != checksum {
		return "", engine.ErrBundleChecksum
	}
	b.sealed[ref] = data
	delete(b.m, f)
	return ref, nil
}

func (b *SessionBlobs) Open(ref string) ([]byte, error) {
	if _, _, _, err := ParseStagedBundleRef(ref); err != nil {
		return nil, err
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	data, ok := b.sealed[ref]
	if !ok {
		return nil, ErrSessionBundleMissing
	}
	return data, nil
}

// GC (memory test double) drops sealed refs that keep does not retain.
func (b *SessionBlobs) GC(_ context.Context, _ time.Time, keep func(string) bool) (int, error) {
	b.mu.Lock()
	defer b.mu.Unlock()
	n := 0
	for ref, data := range b.sealed {
		if !keep(ref) {
			b.used -= int64(len(data))
			delete(b.sealed, ref)
			n++
		}
	}
	return n, nil
}

package checkpoint

import (
	"context"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"sync"
	"time"

	"github.com/arbitron/arbitron/domain/engine"

// SessionBlobs is the durable session staging store (contracts §24): uploads
// land in pending/<job>-<gen>; a verified upload is sealed into
// sealed/<job>-<gen>-<checksum>, which survives restart until GC.
type SessionBlobs struct {
	mu             sync.Mutex
	dir            string
	perBlob, total int64
	used           int64
}

var _ runner.SessionStaging = (*SessionBlobs)(nil)

// OpenSessionBlobs opens (creating) dir and recounts staged bytes.
func OpenSessionBlobs(dir string, perBlob, total int64) (*SessionBlobs, error) {
	if perBlob <= 0 || total <= 0 || perBlob > total {
		return nil, errors.New("checkpoint: session staging requires 0 < perBlob <= total")
	}
	b := &SessionBlobs{dir: dir, perBlob: perBlob, total: total}
	for _, sub := range []string{"pending", "sealed"} {
		if err := os.MkdirAll(filepath.Join(dir, sub), 0o700); err != nil {
			return nil, fmt.Errorf("checkpoint: session staging: %w", err)
		}
		entries, err := os.ReadDir(filepath.Join(dir, sub))
		if err != nil {
			return nil, err
		}
		for _, e := range entries {
			if strings.HasPrefix(e.Name(), ".tmp-") {
				_ = os.Remove(filepath.Join(dir, sub, e.Name())) // torn write from a crash
				continue
			}
			if info, err := e.Info(); err == nil && info.Mode().IsRegular() {
				b.used += info.Size()
			}
		}
	}
	return b, nil
}

func (b *SessionBlobs) pendingPath(f runner.Fence) string {
	return filepath.Join(b.dir, "pending", fmt.Sprintf("%s-%d", f.JobID, f.Generation))
}

func (b *SessionBlobs) sealedPath(ref string) (string, error) {
	job, gen, sum, err := runner.ParseStagedBundleRef(ref)
	if err != nil {
		return "", err
	}
	return filepath.Join(b.dir, "sealed", fmt.Sprintf("%s-%d-%s", job, gen, sum)), nil
}

// writeAtomic writes data to a temp file in dir, fsyncs it and renames it
// into place, then fsyncs the directory.
func writeAtomic(path string, data []byte) error {
	tmp, err := os.CreateTemp(filepath.Dir(path), ".tmp-")
	if err != nil {
		return err
	}
	defer os.Remove(tmp.Name())
	if _, err := tmp.Write(data); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Sync(); err != nil {
		tmp.Close()
		return err
	}
	if err := tmp.Close(); err != nil {
		return err
	}
	if err := os.Rename(tmp.Name(), path); err != nil {
		return err
	}
	return syncDir(filepath.Dir(path))
}

func syncDir(dir string) error {
	d, err := os.Open(dir)
	if err != nil {
		return err
	}
	defer d.Close()
	return d.Sync()
}

func fileSize(path string) int64 {
	if info, err := os.Stat(path); err == nil {
		return info.Size()
	}
	return 0
}

func (b *SessionBlobs) Put(f runner.Fence, data []byte) error {
	n := int64(len(data))
	if n > b.perBlob {
		return runner.ErrSessionBlobTooLarge
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	p := b.pendingPath(f)
	old := fileSize(p)
	if b.used-old+n > b.total {
		return runner.ErrSessionBlobsFull
	}
	if err := writeAtomic(p, data); err != nil {
		return fmt.Errorf("checkpoint: stage session bundle: %w", err)
	}
	b.used += n - old
	return nil
}

func (b *SessionBlobs) Get(f runner.Fence) ([]byte, bool) {
	data, err := os.ReadFile(b.pendingPath(f))
	return data, err == nil
}

func (b *SessionBlobs) Delete(f runner.Fence) {
	b.mu.Lock()
	defer b.mu.Unlock()
	p := b.pendingPath(f)
	n := fileSize(p)
	if os.Remove(p) == nil {
		b.used -= n
	}
}

// Seal verifies the pending upload against the reported checksum and size
// and renames it into its immutable sealed path. Idempotent per ref.
func (b *SessionBlobs) Seal(f runner.Fence, checksum string, size int64) (string, error) {
	ref := runner.StagedBundleRef(f, checksum)
	dst, err := b.sealedPath(ref)
	if err != nil {
		return "", err
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	if _, err := os.Stat(dst); err == nil {
		return ref, nil
	}
	data, err := os.ReadFile(b.pendingPath(f))
	if err != nil {
		return "", runner.ErrSessionBundleMissing
	}
	if int64(len(data)) != size || engine.BundleChecksum(data) != checksum {
		return "", engine.ErrBundleChecksum
	}
	if err := os.Rename(b.pendingPath(f), dst); err != nil {
		return "", fmt.Errorf("checkpoint: seal session bundle: %w", err)
	}
	if err := syncDir(filepath.Dir(dst)); err != nil {
		return "", err
	}
	return ref, nil
}

// Open returns the sealed bytes, re-verifying them against the ref checksum.
func (b *SessionBlobs) Open(ref string) ([]byte, error) {
	p, err := b.sealedPath(ref)
	if err != nil {
		return nil, err
	}
	data, err := os.ReadFile(p)
	if err != nil {
		return nil, fmt.Errorf("%w: %s", runner.ErrSessionBundleMissing, ref)
	}
	if _, _, sum, _ := runner.ParseStagedBundleRef(ref); engine.BundleChecksum(data) != sum {
		return nil, engine.ErrBundleChecksum
	}
	return data, nil
}

// GC removes sealed bundles that keep does not retain and pending uploads
// older than before. keep must consult every live reference: retained inbox
// results, pending turn intents, in-progress moves and committed sessions.
func (b *SessionBlobs) GC(ctx context.Context, before time.Time, keep func(ref string) bool) (int, error) {
	b.mu.Lock()
	defer b.mu.Unlock()
	removed := 0
	sealed, err := os.ReadDir(filepath.Join(b.dir, "sealed"))
	if err != nil {
		return 0, err
	}
	for _, e := range sealed {
		if err := ctx.Err(); err != nil {
			return removed, err
		}
		// <uuid: 5 dash groups>-<gen>-<sum>
		parts := strings.SplitN(e.Name(), "-", 6)
		if len(parts) != 6 {
			continue
		}
		rest := strings.SplitN(parts[5], "-", 2)
		if len(rest) != 2 {
			continue
		}
		ref := fmt.Sprintf("staged:%s/%s/%s", strings.Join(parts[:5], "-"), rest[0], rest[1])
		if keep(ref) {
			continue
		}
		p := filepath.Join(b.dir, "sealed", e.Name())
		n := fileSize(p)
		if os.Remove(p) == nil {
			b.used -= n
			removed++
		}
	}
	pending, err := os.ReadDir(filepath.Join(b.dir, "pending"))
	if err != nil {
		return removed, err
	}
	for _, e := range pending {
		info, err := e.Info()
		if err != nil || !info.ModTime().Before(before) {
			continue
		}
		p := filepath.Join(b.dir, "pending", e.Name())
		if os.Remove(p) == nil {
			b.used -= info.Size()
			removed++
		}
	}
	return removed, nil
}

const defaultSessionTokenTTL = 10 * time.Minute

// ErrSessionJobsUnavailable: SetSessionJobs was never called.
var ErrSessionJobsUnavailable = errors.New("runner: remote session operations are not configured")

// SessionBundleMeta describes bundle bytes moved over the transfer endpoint.
type SessionBundleMeta struct {
	Backend, SessionID, HarnessVersion, OriginWorkDir, Checksum string
	Size                                                       int64
}

// SessionDispatch is the hub-side session_import payload.
type SessionDispatch struct {
	Backend, SessionID, WorkDir, TransferToken string
	Bundle                                     *SessionBundleMeta
}

// RemoteSessionResult is a session_import result from a runner.
type RemoteSessionResult struct {
	SessionID string
}

// SessionJobDeps enables remote session ops.
type SessionJobDeps struct {
	Tokens   BundleTokenIssuer
	Blobs    SessionStaging // Cycle 2b port; production: checkpoint.OpenSessionBlobs
	TokenTTL time.Duration
}

// SetSessionJobs enables session_import dispatch and in-turn session checkpoints (Cycle 3b). Call before Start.
func (h *Hub) SetSessionJobs(d SessionJobDeps) {
	if d.Tokens == nil || d.Blobs == nil {
		panic("runner: SetSessionJobs requires Tokens and Blobs")
	}
	if d.TokenTTL <= 0 {
		d.TokenTTL = defaultSessionTokenTTL
	}
	h.sessJobs.Store(&d)
}

func bundleMeta(b engine.SessionBundle) *SessionBundleMeta {
	return &SessionBundleMeta{Backend: b.Backend, SessionID: b.SessionID, HarnessVersion: b.HarnessVersion,
		OriginWorkDir: b.OriginWorkDir, Checksum: b.Checksum, Size: int64(len(b.Data))}
}

func otherFailure(err error) (StepOutput, error) {
	return StepOutput{}, WithOutcome(err, SourceOutcome{Class: OutcomeOther})
}

// runSession runs one fenced session_import on the assignment's runner.
// Bundle bytes never ride the socket: they are staged in Blobs for the
// runner's GET under the job generation's "session" transfer token.
func (h *Hub) runSession(ctx context.Context, a Assignment, job StepJob) (StepOutput, error) {
	d := h.sessJobs.Load()
	if d == nil {
		return otherFailure(ErrSessionJobsUnavailable)
	}
	if job.Session == nil {
		return otherFailure(fmt.Errorf("runner: %s job without a session payload", job.Op))
	}
	op := *job.Session
	tok, err := d.Tokens.Issue(ctx, a.Fence, a.Job.Key.RunID, TransferSessionData, d.TokenTTL)
	if err != nil {
		return otherFailure(fmt.Errorf("runner: session transfer token: %w", err))
	}
	sd := &SessionDispatch{Backend: op.Backend, SessionID: op.SessionID, WorkDir: op.WorkDir, TransferToken: tok.Token}
	defer d.Blobs.Delete(a.Fence)
	if op.Bundle == nil {
		return otherFailure(errors.New("runner: session_import without a bundle"))
	}
	if err := op.Bundle.Verify(); err != nil {
		return otherFailure(err)
	}
	if err := d.Blobs.Put(a.Fence, op.Bundle.Data); err != nil {
		return otherFailure(err)
	}
	sd.Bundle = bundleMeta(*op.Bundle)

	res, err := h.await(ctx, a, DispatchPayload{Op: job.Op, Session: sd, LeaseUntil: h.now().Add(h.cfg.LostAfter)})
	if err != nil {
		return StepOutput{}, err
	}
	if res == nil {
		return otherFailure(fmt.Errorf("%w: empty result", ErrRemoteStepFailed))
	}
	if !res.OK {
		return StepOutput{}, remoteError(res)
	}
	if res.Session == nil || res.Session.SessionID == "" {
		return otherFailure(fmt.Errorf("%w: result carries no session payload", ErrRemoteStepFailed))
	}
	return StepOutput{Session: &SessionOpResult{SessionID: res.Session.SessionID}}, nil
}

// await offers one non-streaming dispatch and waits for its terminal result.
func (h *Hub) await(ctx context.Context, a Assignment, d DispatchPayload) (*RemoteResult, error) {
	id := a.Fence.RunnerID
	if id == "" || id == BuiltInRunnerID {
		return nil, fmt.Errorf("runner: hub cannot execute on runner %q", id)
	}
	j := &remoteJob{ctx: ctx, a: a, dispatch: d, offeredAt: h.now(), acceptedCh: make(chan struct{}), done: make(chan struct{})}
	h.mu.Lock()
	if h.revoked[id] {
		h.mu.Unlock()
		return nil, WithOutcome(fmt.Errorf("%w: %s", ErrRunnerRevoked, id), SourceOutcome{Class: OutcomeRunnerLost})
	}
	h.jobs[a.Fence.JobID] = j
	s := h.sessions[id]
	h.mu.Unlock()
	h.send(ctx, s, dispatchMsg(j))
	select {
	case <-j.done:
	case <-ctx.Done():
		h.abandon(ctx, j, ctx.Err())
		return nil, ctx.Err()
	}
	h.mu.Lock()
	res, err := j.result, j.err
	h.mu.Unlock()
	return res, err
}

// streamWorkspace is the workspace plan of an agent session turn: the runner
// pulls the run workspace before the turn and pushes it after success.
func (h *Hub) streamWorkspace(ctx context.Context, a Assignment, job StepJob) (*WorkspaceDispatch, error) {
	d := h.wsJobs.Load()
	if d == nil || d.Sync == nil {
		return nil, ErrWorkspaceJobsUnavailable
	}
	if job.Chat == nil || job.Chat.WorkDir == "" {
		return nil, errors.New("runner: an agent session turn needs its workspace directory")
	}
	return workspacePlan(ctx, d, a, a.Job.Key.RunID, job.Chat.WorkDir)
}

// ErrMissingPreparedReceipt: a mutable turn has no exact prepared candidate
// for its job fence (or one owned by another resource fence).
var ErrMissingPreparedReceipt = errors.New("runner: turn has no exact prepared workspace candidate")

// PreparedWorkspaceReceipts finds the prepared candidate a job generation
// pushed (exact fence; never Latest). adapter/sqlite PreparedReceiptRepo.
type PreparedWorkspaceReceipts interface {
	PreparedFor(ctx context.Context, f Fence) (engine.WorkspaceCompletion, bool, error)
}

var (

	_ TurnAdopter           = (*Hub)(nil)

// nativeSession: the harness keeps a resumable session whose bytes are
// exported each turn. Stateless API chat commits only its transcript.
func nativeSession(b provider.ResolvedBinding) bool {
	switch b.Backend {
	case workflow.BackendClaudeCode, workflow.BackendCodex:
		return true
	case "":
		return b.Provider == "claude-cli"
	}
	return false

		return workflow.BackendClaudeCode

func jobFenceRef(f Fence) engine.JobFenceRef {
	return engine.JobFenceRef{JobID: f.JobID, RunnerID: string(f.RunnerID), Generation: f.Generation}
}

// prepareStreamCheckpoint decorates a session stream dispatch with its
// in-assignment export token and resource descriptor.
func (h *Hub) prepareStreamCheckpoint(ctx context.Context, a Assignment, job StepJob, d *DispatchPayload) error {
	d.Resource = job.Resource
	if d.Chat == nil || d.Chat.WorkDir == "" || !nativeSession(job.Binding) {
		return nil
	}
	deps := h.sessJobs.Load()
	if deps == nil {
		return ErrSessionJobsUnavailable // never silently downgrade a native session to stateless
	}
	tok, err := deps.Tokens.Issue(ctx, a.Fence, a.Job.Key.RunID, TransferSessionData, deps.TokenTTL)
	if err != nil {
		return fmt.Errorf("runner: session export token: %w", err)
	}
	d.Chat.NativeCheckpoint, d.Chat.SessionExportToken = true, tok.Token
	return nil
}

// sealTurn runs before the terminal result is persisted/ACKed. A successful
// session turn keeps success only when its exact receipts exist: the
// prepared workspace candidate (mutable turns) and the sealed bundle (native
// turns). Any gap becomes a failed turn; the parent job is not completed.
func (h *Hub) sealTurn(ctx context.Context, j *remoteJob, res RemoteResult) RemoteResult {
	c := j.dispatch.Chat
	if !res.OK || j.dispatch.Op != OpStream || c == nil || c.WorkDir == "" {
		return res
	}
	f := j.a.Fence
	deps := h.sessJobs.Load()
	fail := func(err error) RemoteResult {
		if deps != nil {
			deps.Blobs.Delete(f)
		}
		return RemoteResult{OK: false, Outcome: SourceOutcome{Class: OutcomeOther}, ErrorText: "turn checkpoint: " + err.Error()}
	}
	if res.Chat == nil {
		return fail(fmt.Errorf("%w: result carries no chat payload", ErrRemoteStepFailed))
	}
	comp := &engine.StepCompletion{JobFence: jobFenceRef(f)}
	if c.ProfileKind == string(provider.ProfileKindAgent) || j.dispatch.Resource != nil {
		if deps == nil || deps.Receipts == nil {
			return fail(ErrSessionJobsUnavailable)
		}
		w, ok, err := deps.Receipts.PreparedFor(ctx, f)
		if err != nil {
			return fail(err)
		}
		if !ok {
			return fail(ErrMissingPreparedReceipt)
		}
		if r := j.dispatch.Resource; r != nil && w.Resource != r.Fence {
			return fail(fmt.Errorf("%w: candidate belongs to resource fence %s/%d", ErrMissingPreparedReceipt, w.Resource.Key, w.Resource.Generation))
		}
		comp.Workspace = &w
	}
	chat := *res.Chat
	if c.NativeCheckpoint {
		m := chat.Session
		switch {
		case deps == nil:
			return fail(ErrSessionJobsUnavailable)
		case m == nil:
			return fail(ErrSessionBundleMissing)
		case m.SessionID != chat.SessionID || effectiveBackend(m.Backend) != effectiveBackend(c.Backend):
			return fail(fmt.Errorf("%w: bundle %s/%s does not belong to turn session %s", engine.ErrBundleChecksum, m.Backend, m.SessionID, chat.SessionID))
		}
		ref, err := deps.Blobs.Seal(f, m.Checksum, m.Size)
		if err != nil {
			return fail(err)
		}
		meta := *m
		meta.PreparedBundleRef = ref
		chat.Session = &meta
	} else {
		chat.Session = nil // stateless chat: no bundle can be invented
	}
	res.Chat, res.Completion = &chat, comp
	return res
}

// ExportSession returns the bundle the remote runner exported and uploaded
// inside the originating stream assignment: the exact retained inbox result
// for req.JobFence and its sealed bytes. It sends nothing and reserves nothing.
func (h *Hub) ExportSession(ctx context.Context, id RunnerID, req engine.SessionExportRequest) (engine.SessionBundle, error) {
	deps := h.sessJobs.Load()
	if deps == nil {
		return engine.SessionBundle{}, ErrSessionJobsUnavailable
	}
	f := Fence{JobID: req.JobFence.JobID, RunnerID: RunnerID(req.JobFence.RunnerID), Generation: req.JobFence.Generation}
	if f.RunnerID != id || RunnerID(req.RunnerID) != id {
		return engine.SessionBundle{}, fmt.Errorf("%w: export from %s for a turn on %s", ErrSessionBundleMissing, id, f.RunnerID)
	}
	receipt, ok, err := h.receipt(ctx, f)
	if err != nil {
		return engine.SessionBundle{}, err
	}
	if !ok || receipt.Result == nil || !receipt.Result.OK || receipt.Result.Chat == nil || receipt.Result.Chat.Session == nil {
		return engine.SessionBundle{}, fmt.Errorf("%w: no sealed turn result for job %s generation %d", ErrSessionBundleMissing, f.JobID, f.Generation)
	}
	m := receipt.Result.Chat.Session
	if m.PreparedBundleRef == "" || m.SessionID != req.SessionID || effectiveBackend(m.Backend) != effectiveBackend(req.Backend) || m.OriginWorkDir != req.WorkDir {
		return engine.SessionBundle{}, fmt.Errorf("%w: retained bundle does not match the requested session", ErrSessionBundleMissing)
	}
	if req.Resource != nil && (receipt.Result.Completion == nil || receipt.Result.Completion.Workspace == nil ||
		receipt.Result.Completion.Workspace.Resource != *req.Resource) {
		return engine.SessionBundle{}, fmt.Errorf("%w: resource receipt mismatch", ErrMissingPreparedReceipt)
	}
	data, err := deps.Blobs.Open(m.PreparedBundleRef)
	if err != nil {
		return engine.SessionBundle{}, err
	}
	b := engine.SessionBundle{Backend: m.Backend, SessionID: m.SessionID, HarnessVersion: m.HarnessVersion,
		OriginWorkDir: m.OriginWorkDir, Checksum: m.Checksum, Data: data}
	return b, b.Verify()
}

// AdoptTurn returns a remote stream turn whose sealed terminal result was
// persisted before a server restart: response, session, the original
// receipts and PreparedBundleRef. ok=false (resend after fencing) for a failed,
// non-stream, built-in or unsealed turn. It never completes the job.
func (h *Hub) AdoptTurn(ctx context.Context, job Job) (engine.AdoptedTurn, bool, error) {
	if err := ctx.Err(); err != nil {
		return engine.AdoptedTurn{}, false, err
	}
	if job.Op != OpStream || job.RunnerID == "" || job.RunnerID == BuiltInRunnerID {
		return engine.AdoptedTurn{}, false, nil
	}
	f := Fence{JobID: job.ID, RunnerID: job.RunnerID, Generation: job.Generation}
	receipt, ok, err := h.receipt(ctx, f)
	if errors.Is(err, ErrFenced) {
		return engine.AdoptedTurn{}, false, nil
	}
	if err != nil || !ok || receipt.Result == nil || !receipt.Result.OK || receipt.Result.Chat == nil || receipt.Result.Completion == nil {
		return engine.AdoptedTurn{}, false, err
	}
	r := receipt.Result
	out := engine.AdoptedTurn{Response: r.Chat.Output, SessionID: r.Chat.SessionID, Completions: []engine.StepCompletion{*r.Completion}}
	if r.Chat.Session != nil {
		out.PreparedBundleRef = r.Chat.Session.PreparedBundleRef
	}
	return out, true, nil
}

package sqlite

import (
	"context"
	"database/sql"
	"fmt"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
)

// PreparedReceiptRepo reads the prepared workspace candidate a job generation
// pushed (P3 T2 rows). It never falls back to the newest committed version.
type PreparedReceiptRepo struct{ db *sql.DB }

var _ runner.PreparedWorkspaceReceipts = (*PreparedReceiptRepo)(nil)

func NewPreparedReceiptRepo(db *sql.DB) *PreparedReceiptRepo { return &PreparedReceiptRepo{db: db} }

func (r *PreparedReceiptRepo) PreparedFor(ctx context.Context, f runner.Fence) (engine.WorkspaceCompletion, bool, error) {
	rows, err := r.db.QueryContext(ctx, `SELECT run_id, version, manifest_hash, resource_key, resource_owner, resource_generation, resource_token
FROM workspace_checkpoints WHERE job_id = ? AND job_generation = ? AND state = 'prepared'`, f.JobID.String(), f.Generation)
	if err != nil {
		return engine.WorkspaceCompletion{}, false, fmt.Errorf("prepared receipt: %w", err)
	}
	defer rows.Close()
	var out []engine.WorkspaceCompletion
	for rows.Next() {
		var run, hash, key, owner, tok string
		var version, gen int64
		if err := rows.Scan(&run, &version, &hash, &key, &owner, &gen, &tok); err != nil {
			return engine.WorkspaceCompletion{}, false, err
		}
		runID, err := parseUUID(run)
		if err != nil {
			return engine.WorkspaceCompletion{}, false, err
		}
		token, err := parseUUID(tok)
		if err != nil {
			return engine.WorkspaceCompletion{}, false, err
		}
		out = append(out, engine.WorkspaceCompletion{
			Ref:      runner.CheckpointRef{RunID: runID, Version: version, ManifestHash: hash}.String(),
			Resource: engine.ResourceFenceRef{Key: key, Owner: owner, Generation: gen, Token: token},
		})
	}
	if err := rows.Err(); err != nil {
		return engine.WorkspaceCompletion{}, false, err
	}
	switch len(out) {
	case 0:
		return engine.WorkspaceCompletion{}, false, nil
	case 1:

	Pull(ctx context.Context, ws runneragent.WorkspaceJob) (string, error)
	MarkDirty(ctx context.Context, ws runneragent.WorkspaceJob) error

	GetSession(ctx context.Context, token, jobID string, size int64) ([]byte, error)

func isSessionOp(op string) bool { return op == runneragent.OpSessionImport }

// isSessionStream: an interactive turn carries its stable session workdir.
func isSessionStream(d runneragent.Dispatch) bool {

func sessionBackend(b string) string {
	if b == "" {
		return workflow.BackendClaudeCode

func (e *Executor) supportsSessionOp(d runneragent.Dispatch) (bool, string) {
	s := d.Session
	switch {
	case s == nil:
		return false, "session operation without a session payload"
	case e.cfg.Sessions == nil:
		return false, "session portability is not configured on this runner"
	case e.cfg.Transfer == nil:
		return false, "session bundle transfer is not configured on this runner"
	case s.Bundle == nil:
		return false, "session import without a bundle"
	}
	if _, ok := e.cfg.Sessions.For(sessionBackend(s.Backend)); !ok {
		return false, fmt.Sprintf("no session portability for backend %q on this runner", s.Backend)
	}
	return true, ""
}

func (e *Executor) supportsSessionStream(d runneragent.Dispatch) (bool, string) {
	c := d.Chat
	if e.cfg.Streams == nil {
		return false, "interactive session streams are not configured on this runner"
	}
	if d.Workspace != nil && e.cfg.Syncer == nil {
		return false, "workspace sync is not configured on this runner"
	}
	if c.NativeCheckpoint {
		if e.cfg.Sessions == nil || e.cfg.Transfer == nil {
			return false, "native session checkpoints need session portability and the transfer client"
		}
		if _, ok := e.cfg.Sessions.For(sessionBackend(c.Backend)); !ok {
			return false, fmt.Sprintf("no session portability for backend %q on this runner", c.Backend)
		}
	}
	agent := c.ProfileKind == string(provider.ProfileKindAgent)
	switch runner.CredentialKind(c.CredentialKind) {
	case runner.CredAnthropicSubscription:
		if c.Backend != "" && c.Backend != workflow.BackendClaudeCode {
			return false, fmt.Sprintf("anthropic_subscription sessions run only on the claude harness, not %q", c.Backend)
		}
	case runner.CredOpenAISubscription:
		if !agent || c.Backend != workflow.BackendCodex {
			return false, "openai_subscription sessions run only as codex interactive agents"
		}
	case runner.CredLunaRoute:

			return false, "LunaRoute agent profiles have no interactive streaming path"
		}
		if e.cfg.LunaRoute == nil {
			return false, "no LunaRoute key is configured on this runner"
		}
	default:

// sessionDir is the stable local directory of a session: the runner's copy
// of the server workdir when it lies under this runner's workspace root,
// otherwise a per-workdir directory under the scratch root that is never
// removed between turns.
func (e *Executor) sessionDir(workDir string) (string, error) {
	if e.cfg.Syncer != nil {
		if p, err := e.cfg.Syncer.LocalPath(workDir); err == nil {
			return p, os.MkdirAll(p, 0o755)
		}
	}
	sum := sha256.Sum256([]byte(workDir))
	p := filepath.Join(e.cfg.ScratchRoot, "sessions", hex.EncodeToString(sum[:16]))
	return p, os.MkdirAll(p, 0o700)
}

// sessionStream runs one interactive turn at the session's stable workdir.
// Agent turns pull the run workspace first and push it after success; a
// failed or interrupted turn is never pushed. A native-checkpoint turn then
// exports and uploads its session before the result is returned (§24).
func (e *Executor) sessionStream(ctx context.Context, d runneragent.Dispatch, emit runneragent.EmitFunc) runneragent.Result {
	c := d.Chat
	var dir string
	var err error
	if d.Workspace != nil {
		if dir, err = e.cfg.Syncer.Pull(ctx, *d.Workspace); err != nil {
			return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace pull failed: "+err.Error())
		}
		if err := e.cfg.Syncer.MarkDirty(ctx, *d.Workspace); err != nil {
			return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace copy state: "+err.Error())
		}
	} else if dir, err = e.sessionDir(c.WorkDir); err != nil {
		return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "session directory unavailable")
	}
	b := e.binding(c)
	if c.ProfileKind == string(provider.ProfileKindAgent) {
		b.Kind, b.Backend = provider.ProfileKindAgent, c.Backend
	}
	p, err := e.cfg.Streams.StreamProviderFor(b)
	if err != nil {
		return e.errResult(err)
	}
	req := engine.ChatRequest{Model: c.Model, SystemPrompt: c.SystemPrompt, Prompt: c.Prompt, MaxTokens: c.MaxTokens,
		Temperature: c.Temperature, WorkDir: dir, SessionID: c.SessionID, ToolScope: c.Tools, RequireExecutedModel: c.RequireExecutedModel}
	res := e.stream(ctx, p, req, emit)
	if !res.OK {
		return res
	}
	if d.Workspace != nil {
		if _, err := e.cfg.Syncer.Push(ctx, *d.Workspace); err != nil {
			return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace push failed: "+err.Error())
		}
	}
	if c.NativeCheckpoint {
		return e.exportTurn(ctx, d, dir, res)
	}
	return res
}

// exportTurn exports the harness session after the turn finished and its
// workspace was pushed, uploads it under the parent assignment's session
// token, and only then reports success with the bundle descriptor
// (contracts §24). Any failure is a failed turn.
func (e *Executor) exportTurn(ctx context.Context, d runneragent.Dispatch, dir string, res runneragent.Result) runneragent.Result {
	c := d.Chat
	other := runner.SourceOutcome{Class: runner.OutcomeOther}
	p, ok := e.cfg.Sessions.For(sessionBackend(c.Backend))
	if !ok || res.Chat == nil || res.Chat.SessionID == "" {
		return failure(other, "session export: no resumable session for this turn")
	}
	b, err := p.Export(ctx, res.Chat.SessionID, dir)
	if err != nil {
		return failure(other, "session export: "+err.Error())
	}
	if err := b.Verify(); err != nil || b.SessionID != res.Chat.SessionID {
		return failure(other, "session export: exported bundle does not verify for the turn session")
	}
	b.OriginWorkDir = c.WorkDir // the server-side identity of the session workdir
	if err := e.cfg.Transfer.PutSession(ctx, c.SessionExportToken, d.JobID, b.Data); err != nil {
		return failure(other, "session bundle upload: "+err.Error())
	}
	res.Chat.Session = &runneragent.SessionBundleMeta{Backend: b.Backend, SessionID: b.SessionID, HarnessVersion: b.HarnessVersion,
		OriginWorkDir: b.OriginWorkDir, Checksum: b.Checksum, Size: int64(len(b.Data))}
	return res
}

// sessionOp imports a session bundle (a move target) through the linked
// portability adapter; bytes move over the job's session transfer token.
func (e *Executor) sessionOp(ctx context.Context, d runneragent.Dispatch) runneragent.Result {
	s := d.Session
	other := runner.SourceOutcome{Class: runner.OutcomeOther}
	p, _ := e.cfg.Sessions.For(sessionBackend(s.Backend))
	dir, err := e.sessionDir(s.WorkDir)
	if err != nil {
		return failure(other, "session directory unavailable")
	}
	m := s.Bundle
	data, err := e.cfg.Transfer.GetSession(ctx, s.TransferToken, d.JobID, m.Size)
	if err != nil {
		return failure(other, "session bundle download: "+err.Error())
	}
	b := engine.SessionBundle{Backend: m.Backend, SessionID: m.SessionID, HarnessVersion: m.HarnessVersion,
		OriginWorkDir: m.OriginWorkDir, Checksum: m.Checksum, Data: data}
	if err := b.Verify(); err != nil {
		return failure(other, "session import: "+err.Error())
	}
	id, err := p.Import(ctx, b, dir)
	if err != nil {
		return failure(other, "session import: "+err.Error())
	}
	return runneragent.Result{OK: true, Session: &runneragent.SessionResult{SessionID: id}}
}

// checkResource enforces the job's resource descriptor before any launch:
// an agent workspace turn must name its resource, the pulled workspace must
// be that resource (never the parent run), the turn's workdir is the
// descriptor's, and the fence is complete.
func checkResource(d runneragent.Dispatch) error {
	r := d.Resource
	if d.Workspace == nil {
		if r != nil && d.Chat != nil && d.Chat.WorkDir != r.WorkDir {
			return errors.New("turn workdir is not the resource's workdir")
		}
		return nil
	}
	switch {
	case r == nil:
		return errors.New("an agent workspace turn carries no resource descriptor")
	case r.ID != d.Workspace.RunID:
		return fmt.Errorf("pulled workspace %s is not resource %s", d.Workspace.RunID, r.ID)
	case d.Chat == nil || d.Chat.WorkDir != r.WorkDir || d.Workspace.WorkDir != r.WorkDir || path.Clean(r.WorkDir) != r.WorkDir:
		return errors.New("turn workdir is not the resource's canonical workdir")
	case r.Kind != "workspace" && r.Kind != "resolution":
		return fmt.Errorf("resource kind %q", r.Kind)
	case r.FenceKey == "" || r.FenceOwner == "" || r.FenceGeneration < 1:
		return errors.New("resource fence is incomplete")
	}
	if tok, err := uuid.Parse(r.FenceToken); err != nil || tok == uuid.Nil {
		return errors.New("resource fence token is invalid")
	}
	return nil
}

package http

import (
	"github.com/google/uuid"

	"github.com/arbitron/arbitron/domain/instance"

// TurnRestartedEventDTO is the data of interactive.turn_restarted: the
// client clears the partial tokens of TurnIndex and ignores interactive.token
// events whose generation is below Generation.
type TurnRestartedEventDTO struct {
	InstanceID string `json:"instanceId"`
	NodeID     string `json:"nodeId"`
	TurnIndex  int    `json:"turnIndex"`
	Generation int64  `json:"generation"`

    InvocationID string `json:"invocationId"`
    RequestID string `json:"requestId"`
}

// ContextNoticeEventDTO is the data of interactive.context_notice, and one
// entry of interactive.history's "notices" (persisted lossy session moves).
type ContextNoticeEventDTO struct {
	InstanceID string `json:"instanceId"`
	NodeID     string `json:"nodeId"`
	Notice     string `json:"notice"`
	Lossy      bool   `json:"lossy"`

    InvocationID string `json:"invocationId"`
    RequestID string `json:"requestId"`
    TurnIndex int `json:"turnIndex"`
    Generation int64 `json:"generation"`
}

// contextNotices lists the persisted loss notices of one node's session moves.
func contextNotices(instanceID uuid.UUID, nodeID string, moves []instance.SessionMoveRecord) []ContextNoticeEventDTO {
	var out []ContextNoticeEventDTO
	for _, m := range moves {
		if !m.Lossy || m.Notice == "" || (m.NodeID != "" && m.NodeID != nodeID) {
			continue
		}
		out = append(out, ContextNoticeEventDTO{InstanceID: instanceID.String(), NodeID: nodeID, InvocationID: m.InvocationID.String(), RequestID: m.RequestID.String(), TurnIndex: m.TurnIndex, Generation: m.Generation, Notice: m.Notice, Lossy: true})
	}
	return out
}
