## Alignment correction — prepared receipts, resolution resources and stream identity

P3/P4 T6's atomic candidate contract supersedes any earlier push/Latest publication: the runner pushes a PREPARED candidate under exact job + ResourceFenceRef; remote Result and StepOutput carry that receipt, and Hub records it into the operation StepCompletionSink. Only TurnCommitRepo publishes the authoritative workspace/resource pointer. A successful stream result without its required prepared receipt fails; never use a global Latest or home version. Adoption returns the same receipt to P4 T10 and never fabricates a completed job from response text.

Add `Resource *ResourceDescriptor` to domain/protocol/runner stream and session-op payloads; use P4 T11's ID/kind/canonical path/fence/committed ref shape, retaining actual parent RunID for visibility. Stream transfer tokens include both actual run and resource identity/generation, validated against ResolutionResourceRepo/resource lease. Resolution resources pull/push portable git state under their confined private resource root, not the parent's workspace or server backing directory. Every mirror/translator roundtrip and executor must preserve these fields; nil descriptor or resource mismatch prevents harness launch. P4 T13 links real `WorkingArea` resolution portability and the resource registry into transfer/runner execution; do not stop at accepting an unused field.

Expand event DTOs and all publish helpers/history hydration with `nodeId,invocationId,turnIndex,requestId,generation`; token also carries token, message carries role/content, restarted carries actual reserved generation, context notice carries notice/lossy. Persisted history supplies current identity/generation plus notices. P5 T7 uses the generation even after reconnect. No required field is inferred from token arrival order. Add bounded cleanup for SessionBlobs on success/failure/cancel/timeout/revoke; crash-restart safely retransfers from durable session store/candidate refs rather than relying on in-memory blobs.

**Goal:** Remote runners host interactive sessions end to end:
- Each turn streams its tokens back through the hub at the session's stable workdir. An `interactive_agent` turn pulls the run workspace first and pushes it after success.
- A turn from a superseded generation is fenced, never delivered.
- Session bundles are exported from, and imported into, the runner that holds the session. Export/upload completes inside the originating stream assignment under its fence; import uses a fenced `session_import` move job. Bytes travel over the Phase 3 transfer endpoints (direction `session`).
- A restarted server adopts a still-live remote turn instead of repeating it.
- The dashboard/API shapes of `interactive.turn_restarted` and `interactive.context_notice` are fixed as Go DTOs.

**Architecture:**
- **Protocol.** `adapter/runnerproto/session.go` adds the two contract envelope kinds (`KindSessionExport`, `KindSessionImport`). Each carries a `Dispatch` whose `Op` equals the kind, with a `WireSessionOp` payload. `Result` gains `WireSessionResult`. `WireChat` gains the session `WorkDir` and `ProfileKind`; they are set only on stream ops.
- **Hub (`domain/runner/hub_session.go`).**
  - `Hub.Run` routes session ops to `runSession`. For an import, `runSession` issues a `session`-direction transfer token and stages the bundle bytes in the persistent `SessionBlobs` (keyed by the job fence) before the offer. For an export, it reads the uploaded bytes after the result and verifies them against the reported checksum and size.
  - Stream dispatches copy the stable `WorkDir` and `ProfileKind`. Agent-kind streams attach the Phase 3 workspace plan (`workspacePlan`, P3 T8).
  - `Hub.ExportSession` implements `runner.RemoteSessionExporter` (P4 T6): it reads the exact durable parent-turn result and prepared bundle, with no additional reservation (contracts §24).
  - `Hub.AdoptTurn` implements `runner.TurnAdopter` (P4 T10) on top of the P3 T10 `AdoptionBook`.
- **HTTP (`adapter/http`).**
  - `RunnerTransferHandler` gains `PUT`/`GET /sessions/{jobId}`, authorised by the `session` token of exactly that job generation.
  - The connect translators map the new fields and choose the session envelope kinds.
  - `session_events.go` defines the event DTOs, and history hydration adds persisted lossy notices.
- **Runner side.**
  - `domain/runneragent` mirrors the new payloads, and `wsclient` translates them. The transfer client gains `PutSession`/`GetSession`.
  - The executor runs session streams at a stable local directory through the interactive stream selector. Session export/import go through the linked `SessionPortabilityRegistry`; P4 T13 wires the claudecli and codex adapters into `cmd/arbitron-runner`.
- `domain/*` imports no adapter.

	for _, op := range []string{OpSessionExport, OpSessionImport} {
		d := sessionDispatch(op)

// Session envelope kinds (contracts §15, Phase 4). A session frame carries a
// Dispatch whose Op equals the kind.
const (
	KindSessionExport = "session_export"
	KindSessionImport = "session_import"
)

// Session ops (Dispatch.Op on a session frame).
const (
	OpSessionExport = "session_export"
	OpSessionImport = "session_import"
)

// SessionChecksumHeader carries the lowercase hex SHA-256 of a session bundle
// on the transfer endpoints (PUT request, GET response).
const SessionChecksumHeader = "X-Session-SHA256"

const maxSessionField = 512

// SessionKindForOp returns the envelope kind of a session op.
func SessionKindForOp(op string) (string, bool) {
	switch op {
	case OpSessionExport:
		return KindSessionExport, true
	case OpSessionImport:
		return KindSessionImport, true
	}
	return "", false
}

// WireSessionBundle describes bundle bytes moved over the transfer endpoint.
type WireSessionBundle struct {
	Backend        string `json:"backend"`
	SessionID      string `json:"sessionId"`
	HarnessVersion string `json:"harnessVersion,omitempty"`
	OriginWorkDir  string `json:"originWorkDir,omitempty"`
	Checksum       string `json:"checksum"`
	Size           int64  `json:"size"`
}

func (b *WireSessionBundle) Validate() error {
	sum, err := hex.DecodeString(b.Checksum)
	switch {
	case b.Backend == "" || len(b.Backend) > 64:
		return errors.New("bundle.backend is required")
	case b.SessionID == "" || len(b.SessionID) > maxSessionField:
		return errors.New("bundle.sessionId is required")
	case err != nil || len(sum) != 32 || b.Checksum != hex.EncodeToString(sum):
		return errors.New("bundle.checksum must be lowercase hex SHA-256")
	case b.Size < 1:
		return errors.New("bundle.size must be positive")
	case len(b.OriginWorkDir) > maxSessionField || len(b.HarnessVersion) > 64:
		return errors.New("bundle descriptor field too long")
	}
	return nil
}

// WireSessionOp is a session_export / session_import job. TransferToken is
// the job generation's "session" transfer token for the bundle bytes.
type WireSessionOp struct {
	Backend       string             `json:"backend"`
	SessionID     string             `json:"sessionId,omitempty"`
	WorkDir       string             `json:"workDir"`
	TransferToken string             `json:"transferToken"`
	Bundle        *WireSessionBundle `json:"bundle,omitempty"`
}

func (o *WireSessionOp) validate(op string) error {
	switch {
	case o.Backend == "" || len(o.Backend) > 64:
		return errors.New("session.backend is required")
	case o.WorkDir == "" || !path.IsAbs(o.WorkDir) || len(o.WorkDir) > maxSessionField:
		return errors.New("session.workDir must be an absolute path")
	case o.TransferToken == "" || len(o.TransferToken) > maxSessionField:
		return errors.New("session.transferToken is required")
	}
	switch op {
	case OpSessionExport:
		if o.SessionID == "" {
			return errors.New("session_export names the session to export")
		}
		if o.Bundle != nil {
			return errors.New("session_export carries no bundle")
		}
	case OpSessionImport:
		if o.Bundle == nil {
			return errors.New("session_import carries the bundle descriptor")
		}
		if err := o.Bundle.Validate(); err != nil {
			return err
		}
		if o.Bundle.Backend != o.Backend {
			return fmt.Errorf("bundle backend %q does not match session backend %q", o.Bundle.Backend, o.Backend)
		}
	default:
		return fmt.Errorf("op %q is not a session op", op)
	}
	return nil
}

// Validate checks the payload without its op; Dispatch.Validate checks it
// against the op.
func (o *WireSessionOp) Validate() error {
	if o.Bundle != nil {
		return o.validate(OpSessionImport)
	}
	return o.validate(OpSessionExport)
}

// WireSessionResult is a session op's result: the resumable session id, plus
// (export) the descriptor of the bytes uploaded under the job's token.
type WireSessionResult struct {
	SessionID string             `json:"sessionId"`
	Bundle    *WireSessionBundle `json:"bundle,omitempty"`
}

func (r *WireSessionResult) Validate() error {
	if r.SessionID == "" || len(r.SessionID) > maxSessionField {
		return errors.New("session result names the resumable session")
	}
	if r.Bundle != nil {
		return r.Bundle.Validate()
	}
	return nil
}

func (d *Dispatch) validateSession() error {
	if d.Session == nil {
		return fmt.Errorf("%s dispatch carries the session payload", d.Op)
	}
	if d.Chat != nil || d.Agent != nil || d.Process != nil || d.Workspace != nil {
		return fmt.Errorf("%s dispatch carries only the session payload", d.Op)
	}
	return d.Session.validate(d.Op)
}

package runner

import (
	"errors"
	"sync"
)

// TransferSessionData is the transfer-token direction for session bundle
// bytes (PUT/GET /api/v1/runners/transfers/sessions/{jobId}).
const TransferSessionData = "session"

var (
	ErrSessionBlobTooLarge = errors.New("runner: session bundle exceeds the transfer limit")
	ErrSessionBlobsFull    = errors.New("runner: session bundle staging is full")
)

// SessionBlobs stages session bundle bytes in memory, keyed by the exact job
// fence that may read or write them. The hub stages imports before the offer
// and deletes them when the op ends; the transfer handler stages exports.
type SessionBlobs struct {
	mu      sync.Mutex
	perBlob int64
	total   int64
	used    int64
	m       map[Fence][]byte
}

// NewSessionBlobs bounds one bundle to perBlob bytes and all staged bundles
// together to total bytes.
func NewSessionBlobs(perBlob, total int64) *SessionBlobs {
	if perBlob <= 0 || total <= 0 || perBlob > total {
		panic("runner: NewSessionBlobs requires 0 < perBlob <= total")
	}
	return &SessionBlobs{perBlob: perBlob, total: total, m: map[Fence][]byte{}}
}

func (b *SessionBlobs) Put(f Fence, data []byte) error {
	n := int64(len(data))
	if n > b.perBlob {
		return ErrSessionBlobTooLarge
	}
	b.mu.Lock()
	defer b.mu.Unlock()
	old := int64(len(b.m[f]))
	if b.used-old+n > b.total {
		return ErrSessionBlobsFull
	}
	b.m[f] = data
	b.used += n - old
	return nil
}

func (b *SessionBlobs) Get(f Fence) ([]byte, bool) {
	b.mu.Lock()
	defer b.mu.Unlock()
	d, ok := b.m[f]
	return d, ok
}

func (b *SessionBlobs) Delete(f Fence) {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.used -= int64(len(b.m[f]))
	delete(b.m, f)
}

// SessionBlobStore stages session bundle bytes by job fence (*runner.SessionBlobs).
type SessionBlobStore interface {
	Put(f runner.Fence, data []byte) error
	Get(f runner.Fence) ([]byte, bool)
}

// sessionScope authorises a /sessions/{jobId} request: runner key, a
// "session" token, and the token's job must be the job in the path.
func (h *RunnerTransferHandler) sessionScope(w http.ResponseWriter, r *http.Request) (runner.Fence, bool) {
	if h.d.Sessions == nil {
		WriteError(w, http.StatusServiceUnavailable, "UNAVAILABLE", "session transfers are not enabled on this server")
		return runner.Fence{}, false
	}
	sess, _, ok := h.authorize(w, r, runner.TransferSessionData)
	if !ok {
		return runner.Fence{}, false
	}
	if chi.URLParam(r, "jobId") != sess.JobID.String() {
		WriteError(w, http.StatusForbidden, "FORBIDDEN", "transfer token is not valid for this job")
		return runner.Fence{}, false
	}
	h.extendDeadlines(w)
	return fenceOf(sess), true
}

func (h *RunnerTransferHandler) putSession(w http.ResponseWriter, r *http.Request) {
	f, ok := h.sessionScope(w, r)
	if !ok {
		return
	}
	data, err := io.ReadAll(io.LimitReader(r.Body, h.d.PartBytes+1))
	if err != nil {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", "session bundle upload interrupted")
		return
	}
	if int64(len(data)) > h.d.PartBytes {
		WriteError(w, http.StatusRequestEntityTooLarge, "SESSION_BUNDLE_TOO_LARGE", "session bundle exceeds the transfer part limit")
		return
	}
	if r.Header.Get(runnerproto.SessionChecksumHeader) != engine.BundleChecksum(data) {
		WriteError(w, http.StatusBadRequest, "CHECKSUM_MISMATCH", "session bundle checksum does not match its bytes")
		return
	}
	if err := h.d.Sessions.Put(f, data); err != nil {
		if errors.Is(err, runner.ErrSessionBlobTooLarge) {
			WriteError(w, http.StatusRequestEntityTooLarge, "SESSION_BUNDLE_TOO_LARGE", err.Error())
			return
		}
		slog.Warn("session bundle staging refused", "job", f.JobID, "error", err)
		WriteError(w, http.StatusServiceUnavailable, "UNAVAILABLE", "session bundle staging is full")
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

func (h *RunnerTransferHandler) getSession(w http.ResponseWriter, r *http.Request) {
	f, ok := h.sessionScope(w, r)
	if !ok {
		return
	}
	data, ok := h.d.Sessions.Get(f)
	if !ok {
		WriteError(w, http.StatusNotFound, "NOT_FOUND", "no session bundle is staged for this job")
		return
	}
	w.Header().Set("Content-Type", "application/octet-stream")
	w.Header().Set("Content-Length", strconv.Itoa(len(data)))
	w.Header().Set(runnerproto.SessionChecksumHeader, engine.BundleChecksum(data))
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write(data)
}

func otherFailure(err error) (StepOutput, error) {
	return StepOutput{}, WithOutcome(err, SourceOutcome{Class: OutcomeOther})
}

// runSession runs one fenced session op on the assignment's runner. Bundle
// bytes never ride the socket: imports are staged in Blobs for the runner's
// GET, exports are read from Blobs after the runner's PUT, both under the
// job generation's "session" transfer token.
func (h *Hub) runSession(ctx context.Context, a Assignment, job StepJob) (StepOutput, error) {
	d := h.sessJobs.Load()
	if d == nil {
		return otherFailure(ErrSessionJobsUnavailable)
	}
	if job.Session == nil {
		return otherFailure(fmt.Errorf("runner: %s job without a session payload", job.Op))
	}
	op := *job.Session
	tok, err := d.Tokens.Issue(ctx, a.Fence, a.Job.Key.RunID, TransferSessionData, d.TokenTTL)
	if err != nil {
		return otherFailure(fmt.Errorf("runner: session transfer token: %w", err))
	}
	sd := &SessionDispatch{Backend: op.Backend, SessionID: op.SessionID, WorkDir: op.WorkDir, TransferToken: tok.Token}
	defer d.Blobs.Delete(a.Fence)
	if job.Op == OpSessionImport {
		if op.Bundle == nil {
			return otherFailure(errors.New("runner: session_import without a bundle"))
		}
		if err := op.Bundle.Verify(); err != nil {
			return otherFailure(err)
		}
		if err := d.Blobs.Put(a.Fence, op.Bundle.Data); err != nil {
			return otherFailure(err)
		}
		sd.Bundle = bundleMeta(*op.Bundle)
	}

	res, err := h.await(ctx, a, DispatchPayload{Op: job.Op, Session: sd, LeaseUntil: h.now().Add(h.cfg.LostAfter)})
	if err != nil {
		return StepOutput{}, err
	}
	if res == nil {
		return otherFailure(fmt.Errorf("%w: empty result", ErrRemoteStepFailed))
	}
	if !res.OK {
		return StepOutput{}, remoteError(res)
	}
	if res.Session == nil || res.Session.SessionID == "" {
		return otherFailure(fmt.Errorf("%w: result carries no session payload", ErrRemoteStepFailed))
	}
	if job.Op == OpSessionImport {
		return StepOutput{Session: &SessionOpResult{SessionID: res.Session.SessionID}}, nil
	}
	m := res.Session.Bundle
	if m == nil {
		return otherFailure(ErrSessionBundleMissing)
	}
	data, ok := d.Blobs.Get(a.Fence)
	if !ok {
		return otherFailure(ErrSessionBundleMissing)
	}
	if int64(len(data)) != m.Size {
		return otherFailure(fmt.Errorf("%w: uploaded %d bytes, reported %d", engine.ErrBundleChecksum, len(data), m.Size))
	}
	b := engine.SessionBundle{Backend: m.Backend, SessionID: m.SessionID, HarnessVersion: m.HarnessVersion,
		OriginWorkDir: m.OriginWorkDir, Checksum: m.Checksum, Data: data}
	if err := b.Verify(); err != nil {
		return otherFailure(err)
	}
	return StepOutput{Session: &SessionOpResult{SessionID: b.SessionID, Bundle: &b}}, nil
}

// await offers one non-streaming dispatch and waits for its terminal result.
func (h *Hub) await(ctx context.Context, a Assignment, d DispatchPayload) (*RemoteResult, error) {
	id := a.Fence.RunnerID
	if id == "" || id == BuiltInRunnerID {
		return nil, fmt.Errorf("runner: hub cannot execute on runner %q", id)
	}
	j := &remoteJob{ctx: ctx, a: a, dispatch: d, offeredAt: h.now(), acceptedCh: make(chan struct{}), done: make(chan struct{})}
	h.mu.Lock()
	if h.revoked[id] {
		h.mu.Unlock()
		return nil, WithOutcome(fmt.Errorf("%w: %s", ErrRunnerRevoked, id), SourceOutcome{Class: OutcomeRunnerLost})
	}
	h.jobs[a.Fence.JobID] = j
	s := h.sessions[id]
	h.mu.Unlock()
	h.send(ctx, s, dispatchMsg(j))
	select {
	case <-j.done:
	case <-ctx.Done():
		h.abandon(ctx, j, ctx.Err())
		return nil, ctx.Err()
	}
	h.mu.Lock()
	res, err := j.result, j.err
	h.mu.Unlock()
	return res, err
}

	resp, err := c.do(ctx, http.MethodPut, "/sessions/"+url.PathEscape(jobID), token, data,
		map[string]string{runnerproto.SessionChecksumHeader: engine.BundleChecksum(data), "Content-Type": "application/octet-stream"})
	if err != nil {
		return err
	}
	return resp.Body.Close()
}

// GetSession downloads exactly size bytes of the staged session bundle.
func (c *Client) GetSession(ctx context.Context, token, jobID string, size int64) ([]byte, error) {
	resp, err := c.do(ctx, http.MethodGet, "/sessions/"+url.PathEscape(jobID), token, nil, nil)
	if err != nil {
		return nil, err
	}
	defer resp.Body.Close()
	data, err := io.ReadAll(io.LimitReader(resp.Body, size+1))
	if err != nil {
		return nil, fmt.Errorf("transfer session download: %w", err)
	}
	if int64(len(data)) != size {
		return nil, fmt.Errorf("transfer session download: got %d bytes, announced %d", len(data), size)
	}
	return data, nil
}

import (

// SessionSyncer is the slice of the P3 T9 workspace syncer sessions use.
type SessionSyncer interface {
	LocalPath(workDir string) (string, error)
	Pull(ctx context.Context, ws runneragent.WorkspaceJob) (string, error)
	MarkDirty(ctx context.Context, ws runneragent.WorkspaceJob) error
	Push(ctx context.Context, ws runneragent.WorkspaceJob) (runner.CheckpointRef, error)
}

// SessionTransfer moves session bundle bytes (P3 T9 transfer client).
type SessionTransfer interface {
	PutSession(ctx context.Context, token, jobID string, data []byte) error
	GetSession(ctx context.Context, token, jobID string, size int64) ([]byte, error)
}

func isSessionOp(op string) bool {
	return op == runneragent.OpSessionExport || op == runneragent.OpSessionImport
}

// isSessionStream: an interactive turn carries its stable session workdir.
func isSessionStream(d runneragent.Dispatch) bool {
	return d.Op == runneragent.OpStream && d.Chat != nil && d.Chat.WorkDir != ""
}

func sessionBackend(b string) string {
	if b == "" {
		return workflow.BackendClaudeCode
	}
	return b
}

func (e *Executor) supportsSessionOp(d runneragent.Dispatch) (bool, string) {
	s := d.Session
	switch {
	case s == nil:
		return false, "session operation without a session payload"
	case e.cfg.Sessions == nil:
		return false, "session portability is not configured on this runner"
	case e.cfg.Transfer == nil:
		return false, "session bundle transfer is not configured on this runner"
	case d.Op == runneragent.OpSessionImport && s.Bundle == nil:
		return false, "session import without a bundle"
	}
	if _, ok := e.cfg.Sessions.For(sessionBackend(s.Backend)); !ok {
		return false, fmt.Sprintf("no session portability for backend %q on this runner", s.Backend)
	}
	return true, ""
}

func (e *Executor) supportsSessionStream(d runneragent.Dispatch) (bool, string) {
	c := d.Chat
	if e.cfg.Streams == nil {
		return false, "interactive session streams are not configured on this runner"
	}
	if d.Workspace != nil && e.cfg.Syncer == nil {
		return false, "workspace sync is not configured on this runner"
	}
	agent := c.ProfileKind == string(provider.ProfileKindAgent)
	switch runner.CredentialKind(c.CredentialKind) {
	case runner.CredAnthropicSubscription:
		if c.Backend != "" && c.Backend != workflow.BackendClaudeCode {
			return false, fmt.Sprintf("anthropic_subscription sessions run only on the claude harness, not %q", c.Backend)
		}
	case runner.CredOpenAISubscription:
		if !agent || c.Backend != workflow.BackendCodex {
			return false, "openai_subscription sessions run only as codex interactive agents"
		}
	case runner.CredLunaRoute:
		if agent {
			return false, "LunaRoute agent profiles have no interactive streaming path"
		}
		if e.cfg.LunaRoute == nil {
			return false, "no LunaRoute key is configured on this runner"
		}
	default:
		return false, fmt.Sprintf("credential kind %q cannot run on this runner", c.CredentialKind)
	}
	return true, ""
}

// sessionDir is the stable local directory of a session: the runner's copy
// of the server workdir when it lies under this runner's workspace root,
// otherwise a per-workdir directory under the scratch root that is never
// removed between turns.
func (e *Executor) sessionDir(workDir string) (string, error) {
	if e.cfg.Syncer != nil {
		if p, err := e.cfg.Syncer.LocalPath(workDir); err == nil {
			return p, os.MkdirAll(p, 0o755)
		}
	}
	sum := sha256.Sum256([]byte(workDir))
	p := filepath.Join(e.cfg.ScratchRoot, "sessions", hex.EncodeToString(sum[:16]))
	return p, os.MkdirAll(p, 0o700)
}

// sessionStream runs one interactive turn at the session's stable workdir.
// Agent turns pull the run workspace first and push it after success; a
// failed or interrupted turn is never pushed.
func (e *Executor) sessionStream(ctx context.Context, d runneragent.Dispatch, emit runneragent.EmitFunc) runneragent.Result {
	c := d.Chat
	var dir string
	var err error
	if d.Workspace != nil {
		if dir, err = e.cfg.Syncer.Pull(ctx, *d.Workspace); err != nil {
			return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace pull failed: "+err.Error())
		}
		if err := e.cfg.Syncer.MarkDirty(ctx, *d.Workspace); err != nil {
			return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace copy state: "+err.Error())
		}
	} else if dir, err = e.sessionDir(c.WorkDir); err != nil {
		return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "session directory unavailable")
	}
	b := e.binding(c)
	if c.ProfileKind == string(provider.ProfileKindAgent) {
		b.Kind, b.Backend = provider.ProfileKindAgent, c.Backend
	}
	p, err := e.cfg.Streams.StreamProviderFor(b)
	if err != nil {
		return e.errResult(err)
	}
	req := engine.ChatRequest{Model: c.Model, SystemPrompt: c.SystemPrompt, Prompt: c.Prompt, MaxTokens: c.MaxTokens,
		Temperature: c.Temperature, WorkDir: dir, SessionID: c.SessionID, ToolScope: c.Tools, RequireExecutedModel: c.RequireExecutedModel}
	res := e.stream(ctx, p, req, emit)
	if !res.OK || d.Workspace == nil {
		return res
	}
	if _, err := e.cfg.Syncer.Push(ctx, *d.Workspace); err != nil {
		return failure(runner.SourceOutcome{Class: runner.OutcomeOther}, "workspace push failed: "+err.Error())
	}
	return res
}

// sessionOp exports or imports a session through the linked portability

func (e *Executor) sessionOp(ctx context.Context, d runneragent.Dispatch) runneragent.Result {
	s := d.Session
	other := runner.SourceOutcome{Class: runner.OutcomeOther}
	p, _ := e.cfg.Sessions.For(sessionBackend(s.Backend))
	dir, err := e.sessionDir(s.WorkDir)
	if err != nil {
		return failure(other, "session directory unavailable")
	}
	if d.Op == runneragent.OpSessionExport {
		b, err := p.Export(ctx, s.SessionID, dir)
		if err != nil {
			return failure(other, "session export: "+err.Error())
		}
		if err := e.cfg.Transfer.PutSession(ctx, s.TransferToken, d.JobID, b.Data); err != nil {
			return failure(other, "session bundle upload: "+err.Error())
		}
		return runneragent.Result{OK: true, Session: &runneragent.SessionResult{SessionID: b.SessionID, Bundle: &runneragent.SessionBundleMeta{
			Backend: b.Backend, SessionID: b.SessionID, HarnessVersion: b.HarnessVersion, OriginWorkDir: b.OriginWorkDir,
			Checksum: b.Checksum, Size: int64(len(b.Data))}}}
	}
	m := s.Bundle
	data, err := e.cfg.Transfer.GetSession(ctx, s.TransferToken, d.JobID, m.Size)
	if err != nil {
		return failure(other, "session bundle download: "+err.Error())
	}
	b := engine.SessionBundle{Backend: m.Backend, SessionID: m.SessionID, HarnessVersion: m.HarnessVersion,
		OriginWorkDir: m.OriginWorkDir, Checksum: m.Checksum, Data: data}
	if err := b.Verify(); err != nil {
		return failure(other, "session import: "+err.Error())
	}
	id, err := p.Import(ctx, b, dir)
	if err != nil {
		return failure(other, "session import: "+err.Error())
	}
	return runneragent.Result{OK: true, Session: &runneragent.SessionResult{SessionID: id}}
}

package http

import (
	"github.com/google/uuid"

	"github.com/arbitron/arbitron/domain/instance"

// TurnRestartedEventDTO is the data of interactive.turn_restarted: the
// client clears the partial tokens of TurnIndex and ignores interactive.token
// events whose generation is below Generation.
type TurnRestartedEventDTO struct {
	InstanceID string `json:"instanceId"`
	NodeID     string `json:"nodeId"`
	TurnIndex  int    `json:"turnIndex"`
	Generation int64  `json:"generation"`

    InvocationID string `json:"invocationId"`
    RequestID string `json:"requestId"`
}

// ContextNoticeEventDTO is the data of interactive.context_notice, and one
// entry of interactive.history's "notices" (persisted lossy session moves).
type ContextNoticeEventDTO struct {
	InstanceID string `json:"instanceId"`
	NodeID     string `json:"nodeId"`
	Notice     string `json:"notice"`
	Lossy      bool   `json:"lossy"`

    InvocationID string `json:"invocationId"`
    RequestID string `json:"requestId"`
    TurnIndex int `json:"turnIndex"`
    Generation int64 `json:"generation"`
}

// contextNotices lists the persisted loss notices of one node's session moves.
func contextNotices(instanceID uuid.UUID, nodeID string, moves []instance.SessionMoveRecord) []ContextNoticeEventDTO {
	var out []ContextNoticeEventDTO
	for _, m := range moves {
		if !m.Lossy || m.Notice == "" || (m.NodeID != "" && m.NodeID != nodeID) {
			continue
		}
		out = append(out, ContextNoticeEventDTO{InstanceID: instanceID.String(), NodeID: nodeID, InvocationID: m.InvocationID.String(), RequestID: m.RequestID.String(), TurnIndex: m.TurnIndex, Generation: m.Generation, Notice: m.Notice, Lossy: true})
	}
	return out
}
