# Remote Runners — Phase 1 Task 8: `StepDispatcher`

**Goal:** Turn "run this operation on a source of group G" into a recorded, placed, executed and classified result: require the step identity, persist the queued intent before anything runs, wait visibly (queued · slot / waiting · capacity) until placement succeeds or the run is cancelled, reserve a slot atomically, invoke the runner's `StepRunner`, and react to the classified outcome — re-place on exhausted/logged-out/runner-lost without spending workflow retries, back off on transient errors, fail on everything else — while recording every attempt's placement fact into the context `PlacementSink`.

**Architecture:** `domain/runner/dispatcher.go` holds the runner port types (`StepJob`, `Assignment`, `StepOutput`, `StepRunner`, `RunnerSet`, `StaticRunnerSet`, `HealthTransitioner`, `TelemetrySource`, `DispatcherDeps`) and `StepDispatcher`. It depends only on ports: `Registry.Snapshot` + `Place` (P1 T4/T5) to decide, `Ledger` (P1 T6) to record and fence, `HealthTransitioner` (P1 T13) to transition sources, `EventRecorder`/`ExecutionStatusProjector` (P1 T7) to surface, and an injectable sleep/clock for bounded backoff. Waiters block on an internal close-and-replace broadcast channel that fires on the dispatcher's own slot releases and on every `DispatcherDeps.Wake` signal (the `PoolNotifier`), so the ninth step starts as soon as any slot frees. Streams are wrapped: the slot is held until the terminal chunk, and an exhausted/logged-out/runner-lost error before the first token re-places transparently.

**Tech Stack:** Go 1.25.5, `context`, `sync`, `log/slog`, testify; in-memory fakes that enforce the ledger's slot/generation/fence rules, a fake clock whose sleep advances time, and per-runner scripted `StepRunner`s.

**Spec / Design:** spec "Execution and placement" (eight concurrent steps; queued · slot; waiting · capacity), "Capacity exhaustion and source health" (exhausted re-routes without spending retries; transient ≠ exhaustion; LunaRoute busy), "Recovery and session continuity" (stale results rejected); design phase 1 §3.5 (flow steps 1–6, idempotency key), §3.6 (exact model/tools/requirements preserved), §4 (data flow), §7 (missing identity typed error; classification fails closed; capacity waits end on cancel; ledger write failure fails the step; secrets), §8 (Success: exhausted re-place; Failure: waits · capacity naming group and reset; Error: missing identity rejected, ledger write failure, cancel ends wait; Edge: ninth step queues · slot and starts when a slot frees; cross-phase: exact model pins/tool scope survive re-placement). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §11 (port types, DispatcherDeps, flow, stream semantics), §3/§4 (identity, sink), §6–§10.

**Prerequisites (merge order):** P1 T2 (identity, sink), T3, T4, T5 (`Registry`), T6 (`Ledger`, `IntentAbandoner`), T7 (recorder, notifier, projector), and P1 T9's `domain/engine/process_runner.go` (`engine.ProcessSpec`, `engine.ProcessResult`, referenced by `StepJob.Process`/`StepOutput.Process`).

Behaviour decisions (the T13 / T16 / T10 contract this task fixes):
- **Identity:** `!ok || !id.Valid()` ⇒ `engine.ErrMissingStepIdentity` before any ledger write. `JobKey = {RunID, InvocationID, OperationID, Attempt}` from the identity; `nodeID` = `id.NodeID`; `req.RunID` defaults to `id.RunID`.
- **Intent first:** `EnsureIntent` failure returns `"runner: record intent …: %w"` and nothing runs. An intent found **offered/running** (orphaned by a crash) is `Requeue`d as `runner_lost` before placement.
- **Waits:** `SetWait` then `Status.Publish(queued_slot | waiting_capacity)` (only when the state or detail changes), then block on the broadcast/`ctx`/30 s safety recheck. Cancellation abandons the queued intent (`IntentAbandoner.Abandon`, so a cancelled run never shows a stale wait) and returns `ctx.Err()`.
- **Reserve:** limit = the chosen runner's `StepLimit` from the snapshot; `ErrSlotTaken` ⇒ place again; lease = clock + 10 min (recorded; enforced from Phase 2). Then `MarkRunning` and `Status.Publish(running)`.
- **Outcomes (per `ClassifyError`):** success ⇒ fact `completed`, `Complete(resultRef = job ID)`. Successes (including the probation step) reach health through P1 T13's `NewHealthReportingRunnerSet`, which wraps `DispatcherDeps.Runners`; the dispatcher reports only failures. `exhausted`/`logged_out` ⇒ fact, `Health.ApplyOutcome(src, o)` (failure ⇒ `Fail` + error), `Requeue(class)`, run-scoped `job.rerouted` event, re-place — the engine attempt and the `JobKey` never change. `runner_lost` ⇒ fact, `Requeue`, event, re-place (no health change). `transient` ⇒ fact per try, sleep `min(max(BackoffMin·2^(n-1), RetryAfter), BackoffMax)` on the **same** assignment, up to `TransientMaxAttempts` tries, then `Fail(transient)` and return the provider error. Anything else ⇒ fact `other`, `Fail(other)`, return the provider error unchanged.
- **Cleanup writes** after a call use `context.WithoutCancel(ctx)`, so a cancelled run still releases its slot. Every release wakes waiters.
- **Streams:** the dispatcher returns a wrapping channel; facts and ledger completion are written **before** the terminal chunk is forwarded (so the executor sees the facts when the stream ends).

// memPool is an in-memory Registry + Ledger + IntentAbandoner with the same
// slot, generation and fence rules as the SQLite repos (P1 T5/T6). Registry and
// Ledger methods the dispatcher never calls fall through to the nil embedded
// interfaces and panic, proving they are unused.
type memPool struct {
	runner.Registry
	runner.Ledger

	mu        sync.Mutex
	runners   []runner.Runner
	sources   []runner.Source
	jobs      map[uuid.UUID]*runner.Job
	byKey     map[runner.JobKey]uuid.UUID
	attempts  map[uuid.UUID][]runner.Attempt
	abandoned []uuid.UUID
	ensureErr error
	now       func() time.Time
}

func newMemPool(now func() time.Time, runners []runner.Runner, sources []runner.Source) *memPool {
	return &memPool{runners: runners, sources: sources, jobs: map[uuid.UUID]*runner.Job{},
		byKey: map[runner.JobKey]uuid.UUID{}, attempts: map[uuid.UUID][]runner.Attempt{}, now: now}
}

func (p *memPool) Snapshot(context.Context) (runner.PoolSnapshot, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	snap := runner.PoolSnapshot{Runners: append([]runner.Runner(nil), p.runners...), Sources: append([]runner.Source(nil), p.sources...),
		SlotsInUse: map[runner.RunnerID]int{}, SourceInFlight: map[runner.SourceID]int{},
		Telemetry: map[runner.RunnerID]runner.Telemetry{}, Homes: map[uuid.UUID]runner.Home{}}
	for _, j := range p.jobs {
		if j.State.HoldsSlot() {
			snap.SlotsInUse[j.RunnerID]++
			if j.SourceID != "" {
				snap.SourceInFlight[j.SourceID]++
			}
		}
	}
	return snap, nil
}

func (p *memPool) sourceLocked(id runner.SourceID) *runner.Source {
	for i := range p.sources {
		if p.sources[i].ID == id {
			return &p.sources[i]
		}
	}
	return nil
}

func (p *memPool) RecordHealth(_ context.Context, id runner.SourceID, h runner.SourceHealth) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	s := p.sourceLocked(id)
	if s == nil {
		return runner.ErrSourceNotFound
	}
	s.Health = h
	return nil
}

func (p *memPool) health(id runner.SourceID) runner.SourceHealth {
	p.mu.Lock()
	defer p.mu.Unlock()
	return p.sourceLocked(id).Health
}

func (p *memPool) EnsureIntent(_ context.Context, key runner.JobKey, nodeID string, req runner.ExecRequirements) (runner.Job, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	if p.ensureErr != nil {
		return runner.Job{}, p.ensureErr
	}
	if id, ok := p.byKey[key]; ok {
		j := p.jobs[id]
		if !j.State.Active() {
			j.State, j.Generation, j.RunnerID, j.SourceID, j.Reason, j.Wait = runner.JobQueued, j.Generation+1, "", "", "", nil
		}
		return *j, nil
	}
	j := &runner.Job{ID: uuid.New(), Key: key, NodeID: nodeID, Op: req.Op, Group: req.Group, Model: req.Model, State: runner.JobQueued, CreatedAt: p.now()}
	p.jobs[j.ID], p.byKey[key] = j, j.ID
	return *j, nil
}

func (p *memPool) SetWait(_ context.Context, id uuid.UUID, w *runner.WaitReason) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, ok := p.jobs[id]
	if !ok {
		return runner.ErrJobNotFound
	}
	if j.State != runner.JobQueued {
		return runner.ErrFenced
	}
	j.Wait = w
	return nil
}

func (p *memPool) Reserve(_ context.Context, id uuid.UUID, d runner.Decision, limit int, lease time.Time) (runner.Job, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, ok := p.jobs[id]
	if !ok {
		return runner.Job{}, runner.ErrJobNotFound
	}
	if j.State != runner.JobQueued {
		return runner.Job{}, runner.ErrFenced
	}
	used := 0
	for _, o := range p.jobs {
		if o.State.HoldsSlot() && o.RunnerID == d.Runner {
			used++
		}
	}
	if used >= limit {
		return runner.Job{}, runner.ErrSlotTaken
	}
	l := lease
	j.State, j.RunnerID, j.SourceID, j.Reason, j.Wait, j.LeaseUntil = runner.JobOffered, d.Runner, d.Source, d.Reason, nil, &l
	j.Generation++
	p.attempts[id] = append(p.attempts[id], runner.Attempt{JobID: id, Generation: j.Generation, RunnerID: d.Runner, SourceID: d.Source, Reason: d.Reason, StartedAt: p.now()})
	return *j, nil
}

func (p *memPool) fenceLocked(f runner.Fence) (*runner.Job, error) {
	j, ok := p.jobs[f.JobID]
	if !ok {
		return nil, runner.ErrJobNotFound
	}
	if !j.State.HoldsSlot() || j.Generation != f.Generation || j.RunnerID != f.RunnerID {
		return j, runner.ErrFenced
	}
	return j, nil
}

func (p *memPool) closeAttemptLocked(f runner.Fence, outcome string) {
	as := p.attempts[f.JobID]
	for i := range as {
		if as[i].Generation == f.Generation && as[i].EndedAt == nil {
			now := p.now()
			as[i].Outcome, as[i].EndedAt = outcome, &now
		}
	}
}

func (p *memPool) MarkRunning(_ context.Context, f runner.Fence) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, err := p.fenceLocked(f)
	if err != nil {
		return err
	}
	j.State = runner.JobRunning
	return nil
}

func (p *memPool) finish(f runner.Fence, state runner.JobState, outcome, ref string) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, err := p.fenceLocked(f)
	if errors.Is(err, runner.ErrFenced) && j.State == state && j.Generation == f.Generation && j.RunnerID == f.RunnerID {
		return nil
	}
	if err != nil {
		return err
	}
	j.State, j.ResultRef = state, ref
	p.closeAttemptLocked(f, outcome)
	return nil
}

func outcomeString(c runner.OutcomeClass) string {
	if c == runner.OutcomeNone {
		return string(runner.OutcomeOther)
	}
	return string(c)
}

func (p *memPool) Complete(_ context.Context, f runner.Fence, ref string) error {
	return p.finish(f, runner.JobCompleted, "completed", ref)
}

func (p *memPool) Fail(_ context.Context, f runner.Fence, c runner.OutcomeClass) error {
	return p.finish(f, runner.JobFailed, outcomeString(c), "")
}

func (p *memPool) Requeue(_ context.Context, f runner.Fence, c runner.OutcomeClass) (runner.Job, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, err := p.fenceLocked(f)
	if err != nil {
		return runner.Job{}, err
	}
	p.closeAttemptLocked(f, outcomeString(c))
	j.State, j.RunnerID, j.SourceID, j.Reason, j.LeaseUntil = runner.JobQueued, "", "", "", nil
	j.Generation++
	return *j, nil
}

func (p *memPool) FenceCheck(_ context.Context, f runner.Fence) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	_, err := p.fenceLocked(f)
	return err
}

func (p *memPool) Get(_ context.Context, id uuid.UUID) (runner.Job, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	j, ok := p.jobs[id]
	if !ok {
		return runner.Job{}, runner.ErrJobNotFound
	}
	return *j, nil
}

func (p *memPool) ListActive(context.Context) ([]runner.Job, error) {
	p.mu.Lock()
	defer p.mu.Unlock()
	var out []runner.Job
	for _, j := range p.jobs {
		if j.State.Active() {
			out = append(out, *j)
		}
	}
	return out, nil
}

func (p *memPool) Abandon(_ context.Context, id uuid.UUID) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	if j, ok := p.jobs[id]; ok && j.State == runner.JobQueued {
		j.State, j.Wait = runner.JobFailed, nil
		p.abandoned = append(p.abandoned, id)
	}
	return nil
}

func (p *memPool) jobFor(run uuid.UUID) runner.Job {
	p.mu.Lock()
	defer p.mu.Unlock()
	for _, j := range p.jobs {
		if j.Key.RunID == run {
			return *j
		}
	}
	return runner.Job{}
}

func (p *memPool) attemptsOf(id uuid.UUID) []runner.Attempt {
	p.mu.Lock()
	defer p.mu.Unlock()
	return append([]runner.Attempt(nil), p.attempts[id]...)
}

func (p *memPool) jobCount() int {
	p.mu.Lock()
	defer p.mu.Unlock()
	return len(p.jobs)
}

// fakeHealth transitions the pool's source health the way HealthMonitor does
// for the classes the dispatcher reports, and records every call.
type appliedOutcome struct {
	src runner.SourceID
	o   runner.SourceOutcome
}

type fakeHealth struct {

	mu      sync.Mutex
	applied []appliedOutcome
	err     error
}

func (h *fakeHealth) ApplyOutcome(_ context.Context, src runner.SourceID, o runner.SourceOutcome) error {
	h.mu.Lock()
	h.applied = append(h.applied, appliedOutcome{src, o})
	err := h.err
	h.mu.Unlock()
	if err != nil {
		return err

	h.pool.mu.Lock()
	defer h.pool.mu.Unlock()

		return runner.ErrSourceNotFound

	case runner.OutcomeExhausted:
		s.Health.Capacity, s.Health.ResetAt = runner.CapacityExhausted, o.ResetAt
	case runner.OutcomeLoggedOut:
		s.Health.Auth = runner.AuthLoggedOut
	}
	return nil
}

func (h *fakeHealth) outcomes() []appliedOutcome {
	h.mu.Lock()
	defer h.mu.Unlock()
	return append([]appliedOutcome(nil), h.applied...)
}

// fakeClock gates time: Sleep advances Now by exactly the requested duration.

// scriptedRunner is a StepRunner for ONE runner ID. It records every call and
// plays a per-source script; an assignment for another runner is an error.
type runCall struct {
	a   runner.Assignment
	job runner.StepJob
	id  engine.StepIdentity
}

type runStep func(ctx context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error)

type scriptedRunner struct {
	id       runner.RunnerID
	mu       sync.Mutex
	calls    []runCall
	script   map[runner.SourceID][]runStep
	fallback runStep
}

func (r *scriptedRunner) Run(ctx context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error) {
	sid, _ := engine.StepIdentityFromContext(ctx)
	r.mu.Lock()
	r.calls = append(r.calls, runCall{a: a, job: job, id: sid})
	step := r.fallback
	if q := r.script[a.Job.SourceID]; len(q) > 0 {
		step, r.script[a.Job.SourceID] = q[0], q[1:]
	}
	r.mu.Unlock()
	if a.Job.RunnerID != r.id {
		return runner.StepOutput{}, fmt.Errorf("assignment for %s delivered to %s", a.Job.RunnerID, r.id)
	}
	if step == nil {
		return succeed("ok")(ctx, a, job)
	}
	return step(ctx, a, job)
}

func (r *scriptedRunner) callList() []runCall {
	r.mu.Lock()
	defer r.mu.Unlock()
	return append([]runCall(nil), r.calls...)
}

func succeed(text string) runStep {
	return func(_ context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error) {
		return runner.StepOutput{Chat: &engine.ChatResponse{Output: text + "@" + string(a.Job.RunnerID), Model: job.Chat.Model}}, nil
	}
}

func failWith(err error) runStep {
	return func(context.Context, runner.Assignment, runner.StepJob) (runner.StepOutput, error) { return runner.StepOutput{}, err }
}

// StepJob is the operation payload. Binding is server-side only and is NEVER
// serialized to remote runners.
type StepJob struct {
	Op      OpType
	Binding provider.ResolvedBinding
	Chat    *engine.ChatRequest // chat & stream
	Agent   *engine.AgentMission
	Process *engine.ProcessSpec
}

// Assignment is a reserved, fenced job handed to a StepRunner.
type Assignment struct {
	Job   Job
	Fence Fence
}

// StepOutput is a StepRunner's result; exactly one field is set.
type StepOutput struct {
	Chat    *engine.ChatResponse
	Stream  <-chan engine.ChatChunk
	Agent   *engine.AgentResult
	Process *engine.ProcessResult
}

// StepRunner executes an assignment on one runner. Errors carry a classified
// outcome via WithOutcome when the adapter knows one.
type StepRunner interface {
	Run(ctx context.Context, a Assignment, job StepJob) (StepOutput, error)
}

// RunnerSet resolves a runner ID to its StepRunner.
type RunnerSet interface {
	For(id RunnerID) (StepRunner, bool)
}

// StaticRunnerSet is a fixed RunnerSet (Phase 1: just the built-in runner).
type StaticRunnerSet map[RunnerID]StepRunner

// For returns the runner registered for id.
func (s StaticRunnerSet) For(id RunnerID) (StepRunner, bool) {
	r, ok := s[id]
	return r, ok && r != nil
}

// HealthTransitioner applies a classified outcome to a source (HealthMonitor).
type HealthTransitioner interface {
	ApplyOutcome(ctx context.Context, src SourceID, o SourceOutcome) error
}

// TelemetrySource supplies the latest machine telemetry per runner.
type TelemetrySource interface {
	Latest() map[RunnerID]Telemetry
}

// EmptyTelemetry is the Phase 1 TelemetrySource: nothing is known, and
// placement treats unknown telemetry as neutral.
type EmptyTelemetry struct{}

// Latest returns an empty map.
func (EmptyTelemetry) Latest() map[RunnerID]Telemetry { return map[RunnerID]Telemetry{} }

// DispatcherDeps wires a StepDispatcher.
type DispatcherDeps struct {
	Registry  Registry
	Ledger    Ledger
	Runners   RunnerSet
	Events    *EventRecorder
	Status    *ExecutionStatusProjector
	Health    HealthTransitioner
	Telemetry TelemetrySource
	Policy    PlacementPolicy
	Clock     func() time.Time

	TransientMaxAttempts   int
	BackoffMin, BackoffMax time.Duration

	Wake <-chan struct{} // pool-change notifications (PoolNotifier.Subscribe)
	// Sleep waits d or until ctx ends. nil => a real timer. Tests inject a fake
	// clock's sleep so backoff is observable and time is actually gated.
	Sleep func(ctx context.Context, d time.Duration) error
}

const (
	// assignmentLease is recorded on every reservation; enforced from Phase 2.
	assignmentLease = 10 * time.Minute
	// waitRecheck bounds a wait even if a wake is missed.
	waitRecheck = 30 * time.Second
)

// StepDispatcher places, records, executes and classifies dispatched operations.
type StepDispatcher struct {
	d      DispatcherDeps
	mu     sync.Mutex
	wakeCh chan struct{} // closed and replaced on every pool change
}

// NewStepDispatcher validates deps and starts the wake fan-out.
func NewStepDispatcher(d DispatcherDeps) *StepDispatcher {
	if d.Registry == nil || d.Ledger == nil || d.Runners == nil || d.Events == nil || d.Status == nil || d.Health == nil {
		panic("runner: NewStepDispatcher requires Registry, Ledger, Runners, Events, Status and Health")
	}
	if d.TransientMaxAttempts < 1 {
		panic("runner: NewStepDispatcher requires TransientMaxAttempts >= 1")
	}
	if d.BackoffMin <= 0 || d.BackoffMax < d.BackoffMin {
		panic("runner: NewStepDispatcher requires 0 < BackoffMin <= BackoffMax")
	}
	if d.Telemetry == nil {
		d.Telemetry = EmptyTelemetry{}
	}
	if d.Clock == nil {
		d.Clock = time.Now
	}
	if d.Sleep == nil {
		d.Sleep = sleepCtx
	}
	if d.Status.attachedBus() == nil {
		d.Status.AttachBus(d.Events.Bus())
	}
	s := &StepDispatcher{d: d, wakeCh: make(chan struct{})}
	if d.Wake != nil {
		go func() {
			for range d.Wake {
				s.wake()
			}
		}()
	}
	return s
}

func sleepCtx(ctx context.Context, d time.Duration) error {
	t := time.NewTimer(d)
	defer t.Stop()
	select {
	case <-ctx.Done():
		return ctx.Err()
	case <-t.C:
		return nil
	}
}

func (s *StepDispatcher) waitChan() <-chan struct{} {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.wakeCh
}

// wake releases every current waiter.
func (s *StepDispatcher) wake() {
	s.mu.Lock()
	defer s.mu.Unlock()
	close(s.wakeCh)
	s.wakeCh = make(chan struct{})
}

// Dispatch runs job under the identity on ctx. See the package flow (design P1 §3.5).
func (s *StepDispatcher) Dispatch(ctx context.Context, req ExecRequirements, job StepJob) (StepOutput, error) {
	id, ok := engine.StepIdentityFromContext(ctx)
	if !ok || !id.Valid() {
		return StepOutput{}, engine.ErrMissingStepIdentity
	}
	if req.RunID == uuid.Nil {
		req.RunID = id.RunID
	}
	if req.Op == "" {
		req.Op = job.Op
	}
	key := JobKey{RunID: id.RunID, InvocationID: id.InvocationID, OperationID: id.OperationID, Attempt: id.Attempt}
	j, err := s.d.Ledger.EnsureIntent(ctx, key, id.NodeID, req)
	if err != nil {
		return StepOutput{}, fmt.Errorf("runner: record intent for %s/%s: %w", id.NodeID, id.OperationID, err)
	}
	if j.State.HoldsSlot() {
		// Left offered/running by a crashed server or lost runner: close it first.
		orphan := j.ID
		if j, err = s.d.Ledger.Requeue(context.WithoutCancel(ctx), j.Fence(), OutcomeRunnerLost); err != nil {
			return StepOutput{}, fmt.Errorf("runner: recover orphaned job %s: %w", orphan, err)
		}
		s.wake()
	}
	sink, _ := engine.PlacementSinkFromContext(ctx)
	a, out, err := s.runOnce(ctx, &j, req, job, sink)
	if err != nil {
		return StepOutput{}, err
	}
	if job.Op == OpStream && out.Stream != nil {
		ch := make(chan engine.ChatChunk)
		go s.pump(ctx, j, a, req, job, out.Stream, sink, ch)
		return StepOutput{Stream: ch}, nil
	}
	if err := s.complete(ctx, a, sink); err != nil {
		return StepOutput{}, err
	}
	return out, nil
}

// runOnce places and runs until a runner call returns without error (the
// assignment is returned, still running) or the operation fails terminally.
func (s *StepDispatcher) runOnce(ctx context.Context, j *Job, req ExecRequirements, job StepJob, sink *engine.PlacementSink) (Assignment, StepOutput, error) {
	bg := context.WithoutCancel(ctx)
outer:
	for {
		a, err := s.acquire(ctx, j, req)
		if err != nil {
			return Assignment{}, StepOutput{}, err
		}
		r, ok := s.d.Runners.For(a.Job.RunnerID)
		if !ok {
			s.fact(sink, a, string(OutcomeOther))
			s.release(bg, a, OutcomeOther)
			return Assignment{}, StepOutput{}, fmt.Errorf("runner: no step runner for %q", a.Job.RunnerID)
		}
		if err := s.d.Ledger.MarkRunning(ctx, a.Fence); err != nil {
			s.release(bg, a, OutcomeOther)
			return Assignment{}, StepOutput{}, fmt.Errorf("runner: mark running %s: %w", a.Job.ID, err)
		}
		s.d.Status.Publish(ctx, a.Job, instance.ExecRunning)

		for try := 1; ; try++ {
			out, runErr := r.Run(ctx, a, job)
			if runErr == nil {
				return a, out, nil
			}
			o := ClassifyError(runErr)
			switch o.Class {
			case OutcomeTransient:
				s.fact(sink, a, string(OutcomeTransient))
				if try >= s.d.TransientMaxAttempts {
					s.release(bg, a, OutcomeTransient)
					return Assignment{}, StepOutput{}, runErr
				}
				if err := s.d.Sleep(ctx, s.backoff(try, o.RetryAfter)); err != nil {
					s.release(bg, a, OutcomeOther)
					return Assignment{}, StepOutput{}, err
				}
				continue
			case OutcomeExhausted, OutcomeLoggedOut, OutcomeRunnerLost:
				s.fact(sink, a, string(o.Class))
				if err := s.reroute(ctx, j, a, o); err != nil {
					return Assignment{}, StepOutput{}, err
				}
				continue outer
			default:
				s.fact(sink, a, string(OutcomeOther))
				s.release(bg, a, OutcomeOther)
				return Assignment{}, StepOutput{}, runErr
			}
		}
	}
}

// acquire places the job, waiting visibly until it can be reserved.
func (s *StepDispatcher) acquire(ctx context.Context, j *Job, req ExecRequirements) (Assignment, error) {
	var lastState instance.ExecutionState
	var lastDetail string
	for {
		wakeCh := s.waitChan() // taken BEFORE the snapshot: no lost wake-ups
		snap, err := s.d.Registry.Snapshot(ctx)
		if err != nil {
			s.abandon(ctx, *j)
			return Assignment{}, fmt.Errorf("runner: read pool: %w", err)
		}
		snap.Now = s.d.Clock()
		snap.Telemetry = s.d.Telemetry.Latest()
		dec := Place(req, snap, s.d.Policy)
		if !dec.Placed {
			if err := s.d.Ledger.SetWait(ctx, j.ID, dec.Wait); err != nil {
				s.abandon(ctx, *j)
				return Assignment{}, fmt.Errorf("runner: record wait: %w", err)
			}
			j.Wait = dec.Wait
			state := instance.ExecQueuedSlot
			if dec.Wait.Kind == WaitCapacity {
				state = instance.ExecWaitingCapacity
			}
			if state != lastState || dec.Wait.Detail != lastDetail {
				s.d.Status.Publish(ctx, *j, state)
				lastState, lastDetail = state, dec.Wait.Detail
			}
			t := time.NewTimer(waitRecheck)
			select {
			case <-wakeCh:
			case <-t.C:
			case <-ctx.Done():
				t.Stop()
				s.abandon(ctx, *j)
				return Assignment{}, ctx.Err()
			}
			t.Stop()
			continue
		}
		reserved, err := s.d.Ledger.Reserve(ctx, j.ID, dec, stepLimitOf(snap, dec.Runner), s.d.Clock().Add(assignmentLease))
		if errors.Is(err, ErrSlotTaken) {
			continue
		}
		if err != nil {
			s.abandon(ctx, *j)
			return Assignment{}, fmt.Errorf("runner: reserve slot: %w", err)
		}
		*j = reserved
		return Assignment{Job: reserved, Fence: reserved.Fence()}, nil
	}
}

func stepLimitOf(snap PoolSnapshot, id RunnerID) int {
	for _, r := range snap.Runners {
		if r.ID == id {
			return r.StepLimit
		}
	}
	return 0
}

// reroute transitions the source (not for runner_lost), requeues with a new
// generation and records a run-scoped job.rerouted event.
func (s *StepDispatcher) reroute(ctx context.Context, j *Job, a Assignment, o SourceOutcome) error {
	bg := context.WithoutCancel(ctx)
	if o.Class != OutcomeRunnerLost && a.Job.SourceID != "" {
		if err := s.d.Health.ApplyOutcome(bg, a.Job.SourceID, o); err != nil {
			s.release(bg, a, o.Class)
			return fmt.Errorf("runner: record %s on %s: %w", o.Class, a.Job.SourceID, err)
		}
	}
	nj, err := s.d.Ledger.Requeue(bg, a.Fence, o.Class)
	if err != nil {
		return fmt.Errorf("runner: requeue %s: %w", a.Job.ID, err)
	}
	*j = nj
	run := nj.Key.RunID
	s.d.Events.Record(bg, PoolEvent{Kind: EventJobRerouted, RunnerID: a.Job.RunnerID, SourceID: a.Job.SourceID, RunID: &run,
		Cause: Cause{Kind: CauseOutcome, Outcome: o.Class},
		Detail: map[string]any{"jobId": nj.ID.String(), "nodeId": nj.NodeID, "operationId": nj.Key.OperationID,
			"fromGeneration": a.Fence.Generation, "group": nj.Group.String()}})
	s.wake()
	return nil
}

// complete records success. A completion write failure fails the step: the
// result would otherwise be unrecorded. Success is reported to health by the
// RunnerSet wrapper (P1 T13 NewHealthReportingRunnerSet), not here.
func (s *StepDispatcher) complete(ctx context.Context, a Assignment, sink *engine.PlacementSink) error {
	s.fact(sink, a, "completed")
	err := s.d.Ledger.Complete(context.WithoutCancel(ctx), a.Fence, a.Job.ID.String())
	s.wake()
	if err != nil {
		return fmt.Errorf("runner: complete %s: %w", a.Job.ID, err)
	}
	return nil
}

func (s *StepDispatcher) release(ctx context.Context, a Assignment, class OutcomeClass) {
	if err := s.d.Ledger.Fail(ctx, a.Fence, class); err != nil {
		slog.Error("runner: releasing failed job", "job", a.Job.ID, "error", err)
	}
	s.wake()
}

func (s *StepDispatcher) abandon(ctx context.Context, j Job) {
	if ab, ok := s.d.Ledger.(IntentAbandoner); ok {
		if err := ab.Abandon(context.WithoutCancel(ctx), j.ID); err != nil {
			slog.Warn("runner: abandoning queued intent", "job", j.ID, "error", err)
		}
	}
}

func (s *StepDispatcher) fact(sink *engine.PlacementSink, a Assignment, outcome string) {
	if sink == nil {
		return
	}
	sink.Record(engine.PlacementFact{JobID: a.Job.ID, RunnerID: string(a.Job.RunnerID), SourceID: string(a.Job.SourceID),
		Reason: a.Job.Reason, Generation: a.Fence.Generation, Outcome: outcome, At: s.d.Clock()})
}

// backoff is min·2^(n-1), raised to RetryAfter, capped at BackoffMax.
func (s *StepDispatcher) backoff(try int, retryAfter time.Duration) time.Duration {
	d := s.d.BackoffMin
	for i := 1; i < try && d < s.d.BackoffMax; i++ {
		d *= 2
	}
	if retryAfter > d {
		d = retryAfter

// pump forwards a stream, holding the slot until the terminal chunk. A
// re-placeable error before the first token re-places transparently; after a
// token the outcome is applied to the source and the error is forwarded.
func (s *StepDispatcher) pump(ctx context.Context, j Job, a Assignment, req ExecRequirements, job StepJob, in <-chan engine.ChatChunk, sink *engine.PlacementSink, out chan<- engine.ChatChunk) {
	defer close(out)
	bg := context.WithoutCancel(ctx)
	forwarded := false
	for {
		var chunk engine.ChatChunk
		var ok bool
		select {
		case chunk, ok = <-in:
		case <-ctx.Done():
			go drain(in)
			s.fact(sink, a, string(OutcomeOther))
			s.release(bg, a, OutcomeOther)
			return
		}
		if !ok {
			if err := s.complete(ctx, a, sink); err != nil {
				slog.Error("runner: stream completion not recorded", "error", err)
			}
			return
		}
		if chunk.Error != nil {
			o := ClassifyError(chunk.Error)
			replaceable := o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut || o.Class == OutcomeRunnerLost
			if replaceable && !forwarded {
				go drain(in)
				s.fact(sink, a, string(o.Class))
				if err := s.reroute(ctx, &j, a, o); err != nil {
					send(ctx, out, engine.ChatChunk{Error: err, Done: true})
					return
				}
				na, nout, err := s.runOnce(ctx, &j, req, job, sink)
				if err != nil {
					send(ctx, out, engine.ChatChunk{Error: err, Done: true})
					return
				}
				if nout.Stream == nil {
					if err := s.complete(ctx, na, sink); err != nil {
						send(ctx, out, engine.ChatChunk{Error: err, Done: true})
						return
					}
					send(ctx, out, engine.ChatChunk{Done: true})
					return
				}
				a, in = na, nout.Stream
				continue
			}
			go drain(in)
			s.fact(sink, a, string(classOrOther(o.Class)))
			if o.Class == OutcomeExhausted || o.Class == OutcomeLoggedOut {
				if err := s.d.Health.ApplyOutcome(bg, a.Job.SourceID, o); err != nil {
					slog.Error("runner: applying stream outcome", "source", a.Job.SourceID, "error", err)
				}
			}
			s.release(bg, a, classOrOther(o.Class))
			send(ctx, out, chunk)
			return
		}
		if chunk.Done {
			// Facts and completion land BEFORE the terminal chunk is visible.
			if err := s.complete(ctx, a, sink); err != nil {
				send(ctx, out, engine.ChatChunk{Error: err, Done: true})
				go drain(in)
				return
			}
			send(ctx, out, chunk)
			go drain(in)
			return
		}
		if !send(ctx, out, chunk) {
			go drain(in)
			s.fact(sink, a, string(OutcomeOther))
			s.release(bg, a, OutcomeOther)
			return
		}
		if chunk.Token != "" {
			forwarded = true
		}
	}
}
