## Supported fallback and verification boundary

RR-13/RR-14 research uncertainty does not block required continuity: native import is provisional, and the first resumed turn's deterministic restoration refusal must trigger one visible transcript rebuild under the same held lease, exact accepted binding and restored workspace (P4 T8/T9). An import that merely writes a file is not proof that the harness resumed it. Always preserve the original prompt/nonce and successful transcript; no unverified account fingerprint is accepted as identity evidence. Codex version and home values are produced on the executing machine by the same launch configuration used by its harness; nil/empty versions reject native import, never advertise support.

The OPTIONAL NATIVE-FIDELITY RESEARCH paragraphs below describe optional native-fidelity evidence, not permission to omit automatic fallback or leave the required replay unimplemented. P4 T13 must exercise foreign-home import refusal and resume refusal through the real adapter → mover → replay → visible notice sink. Required tests here: **Happy** `TestSessionPortability_ExportRoundTrip`; **Success** `TestSessionPortability_ImportPreservesSupportedContext`; **Failure** `TestSessionPortability_UnsupportedNativeStateRequiresRebuild`; **Error** `TestSessionPortability_MissingVersionOrDiskFailureFailsClosed`; **Edge** `TestSessionPortability_ForeignHomeAndReasoningLossAreVisible`. Map these names to existing equivalent concrete tests below where present; add the missing behavior test, not a duplicate mirrored assertion. Run red/green `go test ./adapter/codex -run 'SessionPortability|SessionBundle' -count=1`.

**Goal:** Export a Codex rollout into a checksummed bundle and import it on a target so `codex exec resume <id>` finds it — always stripping reasoning items and encrypted reasoning content, refusing compaction state and harness version skew (`engine.ErrBundleRequiresRebuild`), and declaring every Codex move lossy.

**Architecture:** `adapter/codex/session_portability.go` reuses the verifier's own locators (`resolveCodexHome`, `findRollout`, the bounded `readRolloutFrom`) so the exporter reads the same home and file the harness wrote. Bundle `Data` is the raw rollout. `Import` streams the rollout record by record (bounded), drops every `response_item` whose payload is `reasoning`, deletes `encrypted_content` from any other payload, refuses `compacted`/`compaction` records or any `replacement_history` (org-bound, likely encrypted), verifies the `session_meta` id, and writes the result under `$CODEX_HOME/sessions/YYYY/MM/DD/rollout-<ts>-<id>.jsonl` (or overwrites the single existing rollout for that thread so the glob never sees two). Codex re-indexes it on resume. A new optional engine interface `LossyImporter` lets the mover (P4 T8) emit the loss notice even on a successful Codex import.

**Tech Stack:** Go 1.25 stdlib, testify, JSONL fixtures.

**Spec / Design:** spec non-goal "guaranteed preservation of hidden reasoning across accounts" and "visible notice whenever recovery loses context detail"; design phase 4 §3.1 (Codex bullet), §5 rows "Codex session file and account home", "Optional same-account fingerprint" (keep unconditional stripping), §7 (Version skew; Loss notices: every Codex reasoning-stripping move emits a notice), §8 Edge "Codex reasoning is stripped, checked against fixture rollouts", "A Codex compaction item forces the fallback", regression "successful Codex import after stripping still shows the loss notice". Evidence §2.2, §2.3, §4(a). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §17 (adapter path, "strips reasoning; compaction => ErrBundleRequiresRebuild").

OPTIONAL NATIVE-FIDELITY RESEARCH (RR-14): Whether `codex exec resume` enforces `creator_account_id`/`account_scoped` for a rollout created under another ChatGPT account is unverified (one account was available). This task never rewrites those fields; if a real two-account rig shows resume refusal, the resume failure surfaces as an import/resume error and the mover (P4 T8) takes the visible rebuild fallback. Every Codex move is reported lossy meanwhile.

package codex

import (
	"bytes"
	"context"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/workflow"
)

var (
	_ engine.SessionPortability = (*SessionPortability)(nil)
	_ engine.LossyImporter      = (*SessionPortability)(nil)
)

// SessionPortabilityOptions configures the Codex session adapter.
type SessionPortabilityOptions struct {
	Env            []string
	HarnessVersion func(ctx context.Context) (string, error)
	Now            func() time.Time
}

// SessionPortability exports and imports Codex rollouts. Reasoning items are
// ALWAYS stripped on import: encrypted reasoning is org-bound and a foreign
// org fails resume with a hard 400, and no account fingerprint proves the
// accounts match (RR-14).
type SessionPortability struct {
	env     []string
	version func(ctx context.Context) (string, error)
	now     func() time.Time
}

// NewSessionPortability builds the adapter; a version source is required.
func NewSessionPortability(o SessionPortabilityOptions) (*SessionPortability, error) {
	if o.HarnessVersion == nil {
		return nil, errors.New("codex: session portability requires a harness version source")
	}
	env := o.Env
	if env == nil {
		env = codexEnv()
	}
	now := o.Now
	if now == nil {
		now = time.Now
	}
	return &SessionPortability{env: env, version: o.HarnessVersion, now: now}, nil
}

// AlwaysLossy implements engine.LossyImporter: every Codex move strips reasoning.
func (*SessionPortability) AlwaysLossy() bool { return true }

func (p *SessionPortability) home() (string, error) {
	home, err := resolveCodexHome(p.env)
	if err != nil {
		return "", errors.New("codex: cannot resolve codex home (no CODEX_HOME or HOME)")
	}
	return home, nil
}

// Export implements engine.SessionPortability: the rollout's raw bytes.
func (p *SessionPortability) Export(ctx context.Context, sessionID, workDir string) (engine.SessionBundle, error) {
	if !threadIDPattern.MatchString(sessionID) {
		return engine.SessionBundle{}, errors.New("codex: malformed thread id")
	}
	if workDir == "" || !filepath.IsAbs(workDir) {
		return engine.SessionBundle{}, errors.New("codex: session workdir must be an absolute path")
	}
	home, err := p.home()
	if err != nil {
		return engine.SessionBundle{}, err
	}
	path, err := findRollout(home, sessionID)
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("codex: export session: %w", err)
	}
	f, err := os.Open(path)
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("codex: export session: %w", err)
	}
	defer f.Close()
	data, err := io.ReadAll(io.LimitReader(f, maxRolloutBytes+1))
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("codex: export session: %w", err)
	}
	if len(data) > maxRolloutBytes {
		return engine.SessionBundle{}, fmt.Errorf("codex: rollout exceeds %d bytes", maxRolloutBytes)
	}
	ev, err := readRolloutFrom(bytes.NewReader(data), maxRolloutBytes, maxRolloutRecordBytes)
	if err != nil {
		return engine.SessionBundle{}, fmt.Errorf("codex: export session: %w", err)
	}
	if ev.ThreadID != sessionID {
		return engine.SessionBundle{}, errors.New("codex: rollout belongs to another thread")
	}
	version, err := p.version(ctx)
	if err != nil || strings.TrimSpace(version) == "" {
		return engine.SessionBundle{}, fmt.Errorf("codex: harness version unavailable: %v", err)
	}
	return engine.SessionBundle{
		Backend: workflow.BackendCodex, SessionID: sessionID, HarnessVersion: strings.TrimSpace(version),
		OriginWorkDir: workDir, Checksum: engine.BundleChecksum(data), Data: data,
	}, nil
}

// Import refuses every bundle until Cycle 2 implements stripping.
func (p *SessionPortability) Import(ctx context.Context, b engine.SessionBundle, workDir string) (string, error) {
	return "", engine.ErrBundleRequiresRebuild
}

// stripRollout returns the rollout without reasoning items or any
// encrypted_content, refusing compaction state. Every record must be JSON with
// a type; the session_meta id must equal threadID.
func stripRollout(data []byte, threadID string) ([]byte, error) {
	if len(data) > maxRolloutBytes {
		return nil, rebuild("rollout exceeds %d bytes", maxRolloutBytes)
	}
	br := bufio.NewReader(bytes.NewReader(data))
	var out bytes.Buffer
	sawMeta := false
	for {
		line, err := readRolloutRecord(br, maxRolloutRecordBytes)
		if err == errRolloutRecordTooLarge {
			return nil, rebuild("rollout record exceeds %d bytes", maxRolloutRecordBytes)
		}
		if err != nil && err != io.EOF {
			return nil, rebuild("unreadable rollout")
		}
		if trimmed := bytes.TrimSpace(line); len(trimmed) > 0 {
			kept, keep, perr := stripRecord(trimmed, threadID, &sawMeta)
			if perr != nil {
				return nil, perr
			}
			if keep {
				out.Write(kept)
				out.WriteByte('\n')
			}
		}
		if err == io.EOF {
			break
		}
	}
	if !sawMeta {
		return nil, rebuild("rollout has no session_meta")
	}
	return out.Bytes(), nil
}

func stripRecord(line []byte, threadID string, sawMeta *bool) ([]byte, bool, error) {
	var rec map[string]json.RawMessage
	if err := json.Unmarshal(line, &rec); err != nil {
		return nil, false, rebuild("malformed rollout record")
	}
	var typ string
	if err := json.Unmarshal(rec["type"], &typ); err != nil || typ == "" {
		return nil, false, rebuild("rollout record without a type")
	}
	if typ == "compacted" || bytes.Contains(line, []byte(`"replacement_history"`)) {
		return nil, false, rebuild("rollout contains compaction state")
	}
	var payload map[string]json.RawMessage
	if raw, ok := rec["payload"]; ok && len(raw) > 0 && raw[0] == '{' {
		if err := json.Unmarshal(raw, &payload); err != nil {
			return nil, false, rebuild("malformed rollout payload")
		}
	}
	var ptype string
	if payload != nil {
		_ = json.Unmarshal(payload["type"], &ptype)
	}
	switch {
	case typ == "session_meta":
		var id string
		if err := json.Unmarshal(payload["id"], &id); err != nil || id != threadID {
			return nil, false, rebuild("rollout session_meta does not name the bundle's thread")
		}
		*sawMeta = true
	case typ == "response_item" && ptype == "reasoning":
		return nil, false, nil // dropped whole: org-bound, and store=false ids cannot be dereferenced
	case typ == "response_item" && (ptype == "compaction" || ptype == "compaction_summary"):
		return nil, false, rebuild("rollout contains compaction state")
	}
	if payload != nil {
		if _, has := payload["encrypted_content"]; has {
			delete(payload, "encrypted_content")
			newPayload, err := json.Marshal(payload)
			if err != nil {
				return nil, false, err
			}
			rec["payload"] = newPayload
			rewritten, err := json.Marshal(rec)
			if err != nil {
				return nil, false, err
			}
			return rewritten, true, nil
		}
	}
	return line, true, nil
}
