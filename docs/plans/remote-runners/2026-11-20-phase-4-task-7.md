# Remote Runners — Phase 4 Task 7: Interactive placement pinning

**Spec / Design references:** `docs/specs/2026-11-19-remote-runners-spec.md`; `docs/designs/2026-11-19-remote-runners-design-phase-4.md` (sections mapped below).


## Alignment correction — proven eligibility and session identity

Use P4 T1's exact `SessionInvocationID`/session execution as pin identity; `PinFor(run,node)` must resolve the active invocation through the stored current session, never highest attempt across visits. P4 T11 replaces the temporary resolution built-in affinity with ordinary session affinity plus its resource descriptor.

`Source.UnavailableReason` (P1 T3/T13) is a hard eligibility exclusion, distinct from health. An absent matching source is unknown/unavailable capacity, NOT proof of logout. `placeSession` must wait on the existing pin for unknown auth/capacity, missing inventory, unsupported software, cordon, suspect, offline or slot pressure. Only the P1 eligibility predicate (`available`, or single-flight `probation`, authorized auth state, no unavailableReason, compatible model/backend/tools) may enter `usable`; the existing catch-all default branch that admits unknown capacity is retired. Reuse the P1 rank comparator so unknown headroom has the same documented middle rank; never silently rank it below all measured values.

Add **Happy** `TestPlaceSession_EligiblePinStays`; **Success** `TestSessionPins_CurrentInvocationWinsAfterLoop`; **Failure** `TestPlaceSession_UnknownOrUnavailableSourceWaitsWithoutFabricatingLogout`; **Error** `TestSessionPinRepo_ReadErrorPreventsDispatch`; **Edge** `TestPlaceSession_HeadroomUnknownUsesSharedRankAndOnlyAllowedTriggersMove`. Run red/green `go test ./domain/runner ./adapter/sqlite -run 'PlaceSession|SessionPin|SessionStream' -count=1`. P4 T13 must prove removal of SessionPins injection fails the second-turn runner assertion. No fallback silently turns a session into hermetic chat.

**Goal:** Keep every interactive session on the runner that holds it: interactive turns are placed with `AffinitySession` and the session's pin; the pin is used only while it can serve the turn; slot pressure, cordon, suspect liveness and transient congestion make the turn WAIT on the pin (never move for load); exhaustion, logout, drain and runner loss produce a `must_move` decision flagged `MoveRequired` that the mover path (P4 T8–T10) acts on.

**Architecture:** `domain/runner/session_pins.go` defines the `SessionPins` lookup port and the `SessionPinMoveError` the dispatcher returns for a must-move decision. `adapter/sqlite/session_pin_repo.go` reads the pin from the newest `node_executions` record of the node (P4 T1 `LatestSessionState`). The routed stream selector (P1 T10) gains a session-aware variant, chosen by `NewRoutingStreamSelector` when `DispatcherDeps.SessionPins` is wired: it builds `ExecRequirements{Affinity: AffinitySession, PinnedRunner: <pin>}` (first turn: no pin; a pre-Phase-4 session with a provider session id but no pin: the built-in runner; stateless API/LunaRoute chat: `AffinityNone`; group-resolution turns stay `AffinityBuiltIn` until P4 T11). `Place` (P1 T4, pure) routes `AffinitySession` to `placeSession`: no pin ⇒ placed exactly like a workspace step; a pin ⇒ that runner only. `Decision` gains `MoveRequired`/`MoveReason`. `StepDispatcher.Dispatch` returns `*SessionPinMoveError` for a must-move decision instead of waiting or re-placing.

**Tech Stack:** Go 1.25, testify, SQLite (modernc).

**Spec / Design:** spec "Placement" (interactive sessions stay where they are; capacity exhaustion, logout, drain and loss are the only reasons to move a session) and "Recovery and session continuity"; design phase 4 §3.4 (placement: pinned session waits for its slot; never moved for load; first turn placed like a workspace step / session-capable chat at a stable workdir), §5 (Decision tiers), §7 (pinned runner cordoned/suspect: wait, not move), §8 Edge "cordon, suspect liveness and slot pressure never move a pinned session". Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §6 (`Affinity`, `AffinitySession`, `ExecRequirements.PinnedRunner`, `Liveness`, `Source`, `SourceHealth`), §7 (`Place`, `Decision{…Tier…}`, `WaitReason`, reason string format), §11 (`DispatcherDeps`, `NewRoutingStreamSelector`, `StepDispatcher.Dispatch`), §3 (`StepIdentityFromContext`).

package runner

import (
	"fmt"
	"slices"
	"sort"
)

// placeSession places an interactive turn. No pin (first turn): exactly a
// workspace placement. A pin: that runner only — eligible ⇒ placed ("stay");
// operator state, liveness doubt, slot pressure or congestion ⇒ wait on the
// pin; exhaustion, logout, drain or loss ⇒ must_move. Load never moves a pin.
func placeSession(req ExecRequirements, snap PoolSnapshot, policy PlacementPolicy) Decision {
	if req.PinnedRunner == "" {
		first := req
		first.Affinity = AffinityWorkspace
		return Place(first, snap, policy)
	}
	pin := req.PinnedRunner
	var r *Runner
	for i := range snap.Runners {
		if snap.Runners[i].ID == pin {
			r = &snap.Runners[i]
			break
		}
	}
	switch {
	case r == nil || r.Liveness == Liveness("lost"):
		return mustMove(pin, "runner_lost")
	case r.Draining:
		return mustMove(pin, "drain")
	case r.Liveness == Liveness("offline"):
		return waitOnPin(req, WaitKind("slot"), "offline")
	case r.Liveness == Liveness("suspect"):
		return waitOnPin(req, WaitKind("slot"), "suspect")
	case r.Cordoned:
		return waitOnPin(req, WaitKind("slot"), "cordoned")
	case r.Compat.State == CompatState("incompatible"):
		return waitOnPin(req, WaitKind("slot"), "incompatible: "+r.Compat.Reason)
	}

	var matching []Source
	for _, s := range snap.Sources {
		if s.RunnerID == pin && sessionSourceMatches(req, s) {
			matching = append(matching, s)
		}
	}
	if len(matching) == 0 {
		return waitOnPin(req, WaitKind("capacity"), "source inventory unavailable")
	}
	var usable []Source
	loggedOut, exhausted, busy, congested := 0, 0, 0, 0
	for _, s := range matching {
		h := s.Health
		switch {
		case s.UnavailableReason != "":
			busy++ // unavailable capability waits on pin; it does not prove logout
		case h.Capacity != CapacityState("available") && h.Capacity != CapacityState("probation") && h.Capacity != CapacityState("exhausted"):
			busy++
		case h.Auth == AuthState("logged_out"):
			loggedOut++
		case h.Capacity == CapacityState("exhausted"):
			exhausted++
		case h.Capacity == CapacityState("probation") && snap.SourceInFlight[s.ID] > 0:
			busy++
		case h.Congested && (h.CongestedUntil == nil || h.CongestedUntil.After(snap.Now)):
			congested++
		default:
			usable = append(usable, s)
		}
	}
	if len(usable) == 0 {
		switch {
		case loggedOut == len(matching):
			return mustMove(pin, "logged_out")
		case exhausted > 0 && busy == 0 && congested == 0:
			return mustMove(pin, "exhausted")
		case congested > 0:
			return waitOnPin(req, WaitKind("capacity"), "congested")
		default:
			return waitOnPin(req, WaitKind("capacity"), "probation")
		}
	}
	used := snap.SlotsInUse[pin]
	if used >= r.StepLimit {
		return waitOnPin(req, WaitKind("slot"), fmt.Sprintf("slots %d/%d", used, r.StepLimit))
	}
	sort.SliceStable(usable, func(i, j int) bool {
		hi, hj := usable[i].Health.Headroom, usable[j].Health.Headroom
		switch {
		case hi != nil && hj != nil && *hi != *hj:
			return *hi > *hj
		case (hi == nil) != (hj == nil):
			return hi != nil
		}
		return usable[i].ID < usable[j].ID
	})
	best := usable[0]
	headroom := "unknown"
	if best.Health.Headroom != nil {
		headroom = fmt.Sprintf("%.2f", *best.Health.Headroom)
	}
	return Decision{
		Placed: true, Runner: pin, Source: best.ID, Tier: "stay",
		Reason: fmt.Sprintf("session_pin: runner=%s source=%s headroom=%s slots=%d/%d", pin, best.ID, headroom, used, r.StepLimit),
	}
}

func mustMove(pin RunnerID, reason string) Decision {
	return Decision{Tier: "must_move", MoveRequired: true, MoveReason: reason,
		Reason: fmt.Sprintf("must_move: pinned runner=%s reason=%s", pin, reason)}
}

func waitOnPin(req ExecRequirements, kind WaitKind, detail string) Decision {
	return Decision{Tier: "stay", Wait: &WaitReason{Kind: kind, Group: req.Group, Model: req.Model,
		Detail: fmt.Sprintf("session pinned to %s: %s", req.PinnedRunner, detail)}}
}

// sessionSourceMatches applies the contracts §7 source rules (kind, connection
// for LunaRoute/server/local kinds, family never crossed, backend, model list)
// to the pinned runner's sources.
func sessionSourceMatches(req ExecRequirements, s Source) bool {
	if s.Kind != req.Group.Kind {
		return false
	}
	switch s.Kind {
	case CredLunaRoute, CredServerConnection, CredLocalHarness:
		if s.CredentialRef != req.Group.ConnectionRef {
			return false
		}
	}
	if !slices.Contains(s.Families, req.Group.Family) {
		return false
	}
	if !slices.Contains(s.Backends, req.Backend) {
		return false
	}
	return len(s.Models) == 0 || slices.Contains(s.Models, req.Model)
}

	return fmt.Sprintf("runner: session pinned to %s must move (%s)", e.Runner, e.Reason)
}

// Is makes errors.Is(err, ErrSessionPinUnavailable) true.
func (e *SessionPinMoveError) Is(target error) bool { return target == ErrSessionPinUnavailable }

// streamSelectorFor returns the session-aware routed stream selector when a
// pin lookup is wired, else the Phase 1 selector (AffinityBuiltIn).
func streamSelectorFor(inner engine.InteractiveStreamSelector, d dispatcher, pins SessionPins) engine.InteractiveStreamSelector {
	if pins == nil {
		return newRoutingStreamSelector(inner, d)
	}
	if inner == nil || d == nil {
		panic("runner: session routing stream selector requires inner selector and dispatcher")
	}
	return &sessionRoutingStreamSelector{inner: inner, d: d, pins: pins}
}

type sessionRoutingStreamSelector struct {
	inner engine.InteractiveStreamSelector
	d     dispatcher
	pins  SessionPins
}

func (s *sessionRoutingStreamSelector) StreamProviderFor(b provider.ResolvedBinding) (engine.ChatProvider, error) {
	if _, err := s.inner.StreamProviderFor(b); err != nil {
		return nil, err
	}
	return &sessionRoutedStream{routedChat: routedChat{d: s.d, b: b, affinity: AffinitySession}, pins: s.pins}, nil
}

// sessionRoutedStream is routedChat whose StreamChat places on the session pin.
type sessionRoutedStream struct {
	routedChat
	pins SessionPins
}

func (p *sessionRoutedStream) StreamChat(ctx context.Context, req engine.ChatRequest) (<-chan engine.ChatChunk, error) {
	er, err := requirementsFor(ctx, p.b, OpType("stream"), AffinitySession, req.RequireExecutedModel, req.ToolScope)
	if err != nil {
		return nil, err
	}
	if er, err = sessionStreamRequirements(ctx, p.pins, p.b, er, req); err != nil {
		return nil, err
	}
	r := req
	out, err := p.d.Dispatch(ctx, er, StepJob{Op: OpType("stream"), Binding: p.b, Chat: &r})
	if err != nil {
		return nil, err
	}
	if out.Stream == nil {
		return nil, errMissingStepOutput
	}
	return out.Stream, nil
}

// sessionStreamRequirements sets the session affinity and pin of one turn.
func sessionStreamRequirements(ctx context.Context, pins SessionPins, b provider.ResolvedBinding, er ExecRequirements, req engine.ChatRequest) (ExecRequirements, error) {
	if b.Kind == provider.ProfileKindChat && b.ConnectionRef != "" {
		er.Affinity = AffinityNone // API / LunaRoute chat: no harness session file
		return er, nil
	}
	si, ok := engine.StepIdentityFromContext(ctx)
	if !ok {
		return er, engine.ErrMissingStepIdentity
	}
	if strings.HasPrefix(si.OperationID, "resolution/") {
		er.Affinity = AffinityBuiltIn // staging-resource pinning: P4 T11
		return er, nil

	pin, found, err := pins.PinFor(ctx, si.RunID, si.NodeID)
	if err != nil {
		return er, fmt.Errorf("route interactive turn: %w", err)

	er.Affinity = AffinitySession

	case found:
		er.PinnedRunner = pin
	case req.SessionID != "":
		er.PinnedRunner = BuiltInRunnerID // pre-Phase-4 session: its file is on the server
	}
	return er, nil
}
