# Remote Runners — Phase 3 Task 12: Drain, revocation home release and workspace home history

## Alignment repair — required replacement work (2026-11-20)

**Drain requires recoverable target readiness, not ownership-only success.** The supplied controller hands off and deletes the old copy before the target has pulled. Replace that branch with a persistent drain item `moving`: claim the resource, choose a compatible target using the run's complete most-recent execution requirements, issue a pull-only transfer for the exact committed ref, and wait for target `transfer_ready` with manifest hash and resource generation. Then atomically finalize the handoff and delete the drained copy; failure or dry capacity remains visibly blocked/moving with the old committed checkpoint retained. Moving bytes consumes no execution slot, but must not ignore target disk/capability evidence. The producer is P3 T9 `Syncer.Pull`, coordinated through hub transfer messages extended by P3 T8 and persisted by this controller; P3 T13 wires it.

Phase 3 already has built-in interactive sessions, so `DrainProgress.Sessions = 0` is not inherently true. Add `PinnedSessions interface { CountPinned(ctx context.Context, id RunnerID) (int,error) }`; producer `domain/engine/session_inventory.go:InteractiveSessionInventory` reads active `interactive_agent`/`interactive_llm` states and current resolution sessions, assigning them to `builtin` in Phase 3. P3 T13 supplies this required collaborator; Phase 4 replaces it with durable pins. A built-in interactive session is a blocker until it reaches an allowed terminal boundary; Phase 3 does not move it.

Revocation fences jobs/resources before releasing homes. Do not independently `Release` an active resource or clear a newer dirty bit. Before implementation add `TestDrain_TargetPullFailureCannotReportCompleteOrDeleteSource`, `TestDrain_TransferReadyCompletesAtExactGeneration`, `TestDrain_BuiltInInteractiveSessionBlocks`, and `TestRevocation_StaleReleaseCannotClearRecoveredHome`; root tests assert actual target files/readiness and session blockers, not owner-row changes alone.

**Goal:** An admin can drain a runner (`runner_drain` on MCP, `POST /api/v1/runners/{id}/drain` on REST, audited `runner.drain`): no new placements; active steps finish; every homed workspace is moved at a committed boundary to an eligible runner (after the target has pulled and verified the exact committed checkpoint) and the drained copy is deleted. A workspace with no eligible target stays as a persistent, visible blocked drain item that names the missing capacity, and the drain is never reported complete. Progress shows on `runner_get`. Revoking a runner key also releases that runner's homes. Instance and trace reads show each run's workspace home history.

**Architecture:** `domain/runner/drain.go:DrainController` runs one idempotent pass per draining runner (`Step`), driven by the service call, a ticker and pool wake-ups (`Start`/`Tick`). It picks targets with the pure `Place` function on a pool snapshot in which the draining runner is excluded (`Draining`) and slot use is ignored (moving ownership takes no slot), using the requirements of the run's most recent workspace job. Moves are `HomeStore.HandOff` CAS calls on the copy-tracking home store (P3 T11), so the old copy's `delete_copy` follows automatically. Items persist in `drain_items` (migration 044) through `adapter/sqlite/drain_item_repo.go`. `(*Service).Drain` (P1 T15 service) owns authorization, audit, `SetDraining` and the `runner.draining` event; the controller emits `runner.drained` once a pass finds nothing left. `NewRevocationHomeReleaser` decorates the hub's `SessionRevoker`. Home history reuses the T10 read-time pattern: an engine port (`WorkspaceHistorySource`) filled by `runner.NewWorkspaceHistorySource(homes)`.

**Tech Stack:** Go 1.25.5, hand-written SQL, chi v5, mark3labs mcp-go, testify, `adapter/runner/hubtest` (P2 T4).

// adapter/sqlite/drain_item_repo.go
package sqlite

import (
	"context"
	"database/sql"
	"fmt"

	"github.com/arbitron/arbitron/domain/runner"
)

// DrainItemRepo implements runner.DrainStore over drain_items (044).
type DrainItemRepo struct{ db *sql.DB }

func NewDrainItemRepo(db *sql.DB) *DrainItemRepo { return &DrainItemRepo{db: db} }

func (r *DrainItemRepo) Upsert(ctx context.Context, it runner.DrainItem) error {
	const q = `INSERT INTO drain_items (runner_id, kind, run_id, group_key, state, reason, updated_at)
	           VALUES (?, ?, ?, ?, ?, ?, ?)
	           ON CONFLICT (runner_id, kind, run_id) DO UPDATE SET
	             group_key = excluded.group_key, state = excluded.state, reason = excluded.reason, updated_at = excluded.updated_at`
	if _, err := r.db.ExecContext(ctx, q, string(it.RunnerID), it.Kind, uuidToString(it.RunID), it.GroupKey, string(it.State), it.Reason, timeToString(it.UpdatedAt)); err != nil {
		return fmt.Errorf("upserting drain item: %w", err)
	}
	return nil
}

func (r *DrainItemRepo) List(ctx context.Context, id runner.RunnerID) ([]runner.DrainItem, error) {
	rows, err := r.db.QueryContext(ctx, `SELECT runner_id, kind, run_id, group_key, state, reason, updated_at
	                                     FROM drain_items WHERE runner_id = ? ORDER BY kind, run_id`, string(id))
	if err != nil {
		return nil, fmt.Errorf("listing drain items: %w", err)
	}
	defer rows.Close()
	var out []runner.DrainItem
	for rows.Next() {
		var rid, runID, state, updated string
		var it runner.DrainItem
		if err := rows.Scan(&rid, &it.Kind, &runID, &it.GroupKey, &state, &it.Reason, &updated); err != nil {
			return nil, fmt.Errorf("scanning drain item: %w", err)
		}
		if it.RunID, err = parseUUID(runID); err != nil {
			return nil, err
		}
		if it.UpdatedAt, err = parseTime(updated); err != nil {
			return nil, err
		}
		it.RunnerID, it.State = runner.RunnerID(rid), runner.DrainItemState(state)
		out = append(out, it)
	}
	return out, rows.Err()
}

func (r *DrainItemRepo) Clear(ctx context.Context, id runner.RunnerID) error {
	if _, err := r.db.ExecContext(ctx, `DELETE FROM drain_items WHERE runner_id = ?`, string(id)); err != nil {
		return fmt.Errorf("clearing drain items: %w", err)
	}
	return nil
}

type drainPull struct {
	Run        uuid.UUID
	Target     runner.RunnerID
	Ref        runner.CheckpointRef
	Resource   engine.ResourceFenceRef
	HomeAtPull runner.RunnerID

// drainPuller stands in for the WorkspacePullCoordinator: it records what the
// controller asked for and where the home was at that moment.
type drainPuller struct {
	mu     sync.Mutex
	homes  runner.HomeStore
	calls  []drainPull
	fail   error
	tamper func(*runner.PullReceipt)
}

func (p *drainPuller) PullCommitted(ctx context.Context, run uuid.UUID, target runner.RunnerID, ref runner.CheckpointRef, res engine.ResourceFenceRef) (runner.PullReceipt, error) {
	h, err := p.homes.GetHome(ctx, run)
	if err != nil {
		return runner.PullReceipt{}, err
	}
	p.mu.Lock()
	defer p.mu.Unlock()
	p.calls = append(p.calls, drainPull{Run: run, Target: target, Ref: ref, Resource: res, HomeAtPull: h.RunnerID})
	if p.fail != nil {
		return runner.PullReceipt{}, p.fail
	}
	rc := runner.PullReceipt{OperationID: "pull-" + run.String(), RunnerID: target, Ref: ref, Resource: res}
	if p.tamper != nil {
		p.tamper(&rc)
	}
	return rc, nil
}

func (p *drainPuller) pulls() []drainPull {
	p.mu.Lock()
	defer p.mu.Unlock()
	return append([]drainPull(nil), p.calls...)
}

func TestDrainController_WaitsForActiveStepsThenMovesHomeAndCompletes(t *testing.T) {
	ctx := context.Background()
	r := newDrainRig(t)
	r.online(t, "mac-1")
	r.online(t, "mac-2")
	run, a := r.homedRun(t)
	r.startDrain(t, "mac-1")

	p, err := r.ctrl.Step(ctx, "mac-1")
	require.NoError(t, err)
	assert.Equal(t, 1, p.ActiveSteps, "the active step is left to finish")
	assert.Equal(t, 1, p.HomedWorkspaces)
	assert.False(t, p.Complete)
	assert.Empty(t, r.puller.pulls(), "nothing is pulled while the step runs")
	h, _ := r.repo.GetHome(ctx, run)
	assert.Equal(t, runner.RunnerID("mac-1"), h.RunnerID, "a home with an active step does not move")

	require.NoError(t, r.pool.Ledger.Complete(ctx, a.Fence, "result"))
	p, err = r.ctrl.Step(ctx, "mac-1")
	require.NoError(t, err)
	assert.Equal(t, runner.DrainProgress{}.Blocked, p.Blocked)
	assert.Zero(t, p.ActiveSteps)
	assert.Zero(t, p.HomedWorkspaces, "the home was released from the drained runner")
	assert.True(t, p.Complete)

	pulls := r.puller.pulls()
	require.Len(t, pulls, 1)
	assert.Equal(t, runner.RunnerID("mac-2"), pulls[0].Target)
	assert.Equal(t, runner.RunnerID("mac-1"), pulls[0].HomeAtPull, "the target pulls BEFORE the handoff")
	assert.Equal(t, int64(3), pulls[0].Ref.Version, "the exact committed checkpoint")
	assert.Equal(t, "mac-2", pulls[0].Resource.Owner, "the pull runs under the drain's claim for the target")
	assert.False(t, r.claimActive(t, run), "the drain claim is released after the handoff")

	h, _ = r.repo.GetHome(ctx, run)
	assert.Equal(t, runner.RunnerID("mac-2"), h.RunnerID)
	hist, err := r.repo.History(ctx, run)
	require.NoError(t, err)
	assert.Contains(t, hist[len(hist)-1].Reason, "drain")
	assert.Equal(t, 1, r.deletesTo("mac-1"), "the drained copy is deleted after the handoff")

	_, err = r.ctrl.Step(ctx, "mac-1")
	require.NoError(t, err)
	n := 0
	for _, k := range r.pool.EventKinds(t) {
		if k == runner.EventRunnerDrained {
			n++
		}
	}
	assert.Equal(t, 1, n, "runner.drained is announced once")
}

// Begin starts a fresh drain record for id (Service.Drain calls it after SetDraining).
func (c *DrainController) Begin(ctx context.Context, id RunnerID) error {
	c.mu.Lock()
	delete(c.drained, id)
	c.mu.Unlock()
	return c.d.Store.Clear(ctx, id)
}

// Step runs one pass for a draining runner.
func (c *DrainController) Step(ctx context.Context, id RunnerID) (DrainProgress, error) {
	r, _, err := c.d.Registry.GetRunner(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	if !r.Draining {
		return DrainProgress{}, fmt.Errorf("%w: %s", ErrNotDraining, id)
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	active, err := c.d.Ledger.ListActiveByRunner(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	busy := make(map[uuid.UUID]bool, len(active))
	for _, j := range active {
		busy[j.Key.RunID] = true
	}
	homes, err := c.d.Homes.ListByRunner(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	for _, h := range homes {
		if busy[h.RunID] {
			if err := c.upsert(ctx, id, h.RunID, "", DrainItemPending, "waiting for the active step to finish"); err != nil {
				return DrainProgress{}, err
			}
			continue
		}
		if err := c.moveHome(ctx, id, h); err != nil {
			return DrainProgress{}, err
		}
	}
	p, err := c.progress(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	if p.Complete && !c.drained[id] {
		c.drained[id] = true
		c.d.Events.Record(ctx, PoolEvent{At: c.d.Clock(), Kind: EventRunnerDrained, RunnerID: id, Cause: Cause{Kind: "system", Actor: string(id)}})
		c.d.Notifier.Notify()
	}
	return p, nil
}

// Progress reports the runner's drain state without moving anything.
func (c *DrainController) Progress(ctx context.Context, id RunnerID) (DrainProgress, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.progress(ctx, id)
}

// Tick runs one pass for every draining runner.
func (c *DrainController) Tick(ctx context.Context) error {
	rs, err := c.d.Registry.ListRunners(ctx)
	if err != nil {
		return err
	}
	var errs []error
	for _, r := range rs {
		if r.Draining {
			if _, err := c.Step(ctx, r.ID); err != nil {
				errs = append(errs, fmt.Errorf("drain %s: %w", r.ID, err))
			}
		}
	}
	return errors.Join(errs...)
}

// Start drives Tick on the interval and on pool wake-ups until ctx ends.
func (c *DrainController) Start(ctx context.Context) {
	wake, cancel := c.d.Notifier.Subscribe()
	go func() {
		defer cancel()
		t := time.NewTicker(c.d.Interval)
		defer t.Stop()
		for {
			select {
			case <-ctx.Done():
				return
			case <-t.C:
			case <-wake:
			}
			if err := c.Tick(ctx); err != nil {
				slog.Warn("drain pass", "error", err)
			}
		}
	}()
}

func (c *DrainController) upsert(ctx context.Context, id RunnerID, run uuid.UUID, group string, st DrainItemState, reason string) error {
	return c.d.Store.Upsert(ctx, DrainItem{RunnerID: id, Kind: DrainKindWorkspace, RunID: run, GroupKey: group, State: st, Reason: reason, UpdatedAt: c.d.Clock()})
}

// moveHome returns an error only for storage failures; every expected
// failure is a persisted item that keeps the drain incomplete.
func (c *DrainController) moveHome(ctx context.Context, id RunnerID, h Home) error {
	if h.NonPortableReason != "" {
		return c.upsert(ctx, id, h.RunID, "", DrainItemBlocked, "non_portable: "+h.NonPortableReason+"; recoverable from its local checkpoint but never movable")
	}
	req, found, err := c.lastRequirements(ctx, h.RunID)
	if err != nil {
		return err
	}
	target, owner, group := ServerHome, BuiltInRunnerID, ""
	if found {
		group = req.Group.String()
		d, err := c.place(ctx, req)
		if err != nil {
			return err
		}
		if !d.Placed {
			return c.upsert(ctx, id, h.RunID, group, DrainItemBlocked, fmt.Sprintf("no eligible runner for %s: %s", group, d.Reason))
		}
		target, owner = d.Runner, d.Runner
	}
	claim, err := c.d.Leases.Claim(ctx, runKey(h.RunID), fmt.Sprintf("drain:%s:%s@%d", id, h.RunID, h.Generation), owner)
	if errors.Is(err, ErrResourceBusy) {
		return c.upsert(ctx, id, h.RunID, group, DrainItemPending, "waiting: the workspace resource is held by another writer")
	}
	if err != nil {
		return err
	}
	defer func() {
		if err := c.d.Leases.Release(context.WithoutCancel(ctx), claim); err != nil {
			slog.Warn("releasing drain claim", "run", h.RunID, "error", err)
		}
	}()
	if target == ServerHome {
		// No workspace step ever ran on this home: the server checkpoint is the whole state.
		if err := c.d.Homes.Release(ctx, h.RunID, h.Generation); err != nil {
			return c.upsert(ctx, id, h.RunID, group, DrainItemPending, "home changed during the drain; retrying: "+err.Error())
		}
		return c.upsert(ctx, id, h.RunID, group, DrainItemDone, "released to server storage")
	}
	ref, _, err := c.d.Checkpoints.Latest(ctx, h.RunID)
	if err != nil {
		return err
	}
	if err := c.upsert(ctx, id, h.RunID, group, DrainItemMoving, fmt.Sprintf("target %s pulling committed checkpoint %d", target, ref.Version)); err != nil {
		return err
	}
	rc, err := c.d.Pulls.PullCommitted(ctx, h.RunID, target, ref, claim)
	if err != nil {
		return c.upsert(ctx, id, h.RunID, group, DrainItemBlocked, fmt.Sprintf("target pull failed on %s: %v; the committed checkpoint and the source copy are kept", target, err))
	}
	if rc.OperationID == "" || rc.RunnerID != target || rc.Ref != ref || rc.Resource != claim {
		return c.upsert(ctx, id, h.RunID, group, DrainItemBlocked, fmt.Sprintf("target %s returned a receipt that does not match this drain transfer", target))
	}
	if err := c.d.Leases.Check(ctx, claim); err != nil {
		return c.upsert(ctx, id, h.RunID, group, DrainItemBlocked, "drain claim lost before the handoff: "+err.Error())
	}
	var bytes int64
	if c.d.Sizes != nil {
		bytes = c.d.Sizes.WorkspaceBytes(ctx, h.RunID)
	}
	cause := HomeMoveCause{OperationID: rc.OperationID, FromGeneration: h.Generation, ToGeneration: h.Generation + 1}
	if _, err := c.d.Homes.HandOff(ctx, h.RunID, target, fmt.Sprintf("drain: %s -> %s", id, target), bytes, h.Generation, cause); err != nil {
		if errors.Is(err, ErrHomeGenerationConflict) {
			return c.upsert(ctx, id, h.RunID, group, DrainItemPending, "home changed during the transfer; retrying next pass")
		}
		return err
	}
	return c.upsert(ctx, id, h.RunID, group, DrainItemDone, "moved to "+string(target))
}

// lastRequirements returns the complete requirements of the run's most
// recent workspace job, re-aimed at choosing a new home.
func (c *DrainController) lastRequirements(ctx context.Context, run uuid.UUID) (ExecRequirements, bool, error) {
	jobs, err := c.d.Ledger.ListByRun(ctx, run)
	if err != nil {
		return ExecRequirements{}, false, err
	}
	var last *Job
	for i := range jobs {
		j := &jobs[i]
		if j.Op != OpAgent && j.Op != OpProcess {
			continue
		}
		if last == nil || j.CreatedAt.After(last.CreatedAt) {
			last = j
		}
	}
	if last == nil {
		return ExecRequirements{}, false, nil
	}
	req, err := c.d.Requirements.Requirements(ctx, last.ID)
	if err != nil {
		return ExecRequirements{}, false, err
	}
	req.RunID, req.PinnedRunner = run, ""
	if req.Affinity == AffinityWorkspace {
		req.Affinity = AffinityNone // the current home is the drained runner; rank a new one
	}
	if c.d.Sizes != nil {
		req.WorkspaceBytes = c.d.Sizes.WorkspaceBytes(ctx, run)
	}
	return req, true, nil
}

// place ranks targets on a fresh snapshot. Moving a home takes no execution
// slot, so slot use is ignored; capability, health, disk telemetry and the
// Draining/Cordoned flags still apply.
func (c *DrainController) place(ctx context.Context, req ExecRequirements) (Decision, error) {
	snap, err := c.d.Registry.Snapshot(ctx)
	if err != nil {
		return Decision{}, err
	}
	snap.Now = c.d.Clock()
	snap.Telemetry = c.d.Telemetry.Latest()
	snap.SlotsInUse, snap.SourceInFlight = nil, nil
	return Place(req, snap, c.d.Policy), nil
}

func (c *DrainController) progress(ctx context.Context, id RunnerID) (DrainProgress, error) {
	active, err := c.d.Ledger.ListActiveByRunner(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	homes, err := c.d.Homes.ListByRunner(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	sessions, err := c.d.Sessions.CountPinned(ctx, id)
	if err != nil {
		return DrainProgress{}, fmt.Errorf("drain %s: session inventory unavailable: %w", id, err)
	}
	items, err := c.d.Store.List(ctx, id)
	if err != nil {
		return DrainProgress{}, err
	}
	homed := make(map[uuid.UUID]bool, len(homes))
	for _, h := range homes {
		homed[h.RunID] = true
	}
	var blocked []DrainBlocker
	for _, it := range items {
		if it.Kind == DrainKindWorkspace && it.State == DrainItemBlocked && homed[it.RunID] {
			run := it.RunID
			blocked = append(blocked, DrainBlocker{Kind: DrainKindWorkspace, RunID: &run, Group: it.GroupKey, Reason: it.Reason})
		}
	}
	if sessions > 0 {
		blocked = append(blocked, DrainBlocker{Kind: DrainKindSession,
			Reason: fmt.Sprintf("%d interactive session(s) pinned to %s; waiting for each to reach a terminal boundary", sessions, id)})
	}
	return DrainProgress{ActiveSteps: len(active), HomedWorkspaces: len(homes), Sessions: sessions, Blocked: blocked,
		Complete: len(active) == 0 && len(homes) == 0 && sessions == 0 && len(blocked) == 0}, nil
}

#### Cycle 2b — `WorkspacePullCoordinator`: a fenced, verified pull-only maintenance transfer (unstick 2026-11-24)

Producer of `DrainPuller` (Cycle 2) and of the "Pull-only drain operation" section below. The operation ID is derived from the drain's resource claim (`pull:<key>@<generation>/<target>`), so a receipt the runner replays after a reconnect matches the waiting call, and a claim from an earlier pass or boot can never satisfy a new one. The pull token is a P3 T7 maintenance-scoped token (`Fence{RunnerID: target}`, `MaintenanceOperationID`, `Direction: TransferPull`, `BaseRef`, `Resource`), so it is resource-checked on every transfer request and no runner-job ID is fabricated. A zero ref (no checkpoint yet: an empty workspace) needs no transfer and returns its receipt without contacting the runner. The runner records the copy at `home.Generation+1`, the generation the drain's `HandOff` will create, so the copy keeper treats it as the new home's copy. Server-side receipt state is in memory: after a server restart the drain claim's generation changes, so every pull is re-issued.

import (
	"context"
	"errors"

// Pull-only maintenance transfer messages (hub ↔ runner).
const (
	MsgPullWorkspace  = "pull_workspace"   // hub → runner
	MsgPullReceipt    = "pull_receipt"     // runner → hub (live, or replayed in hello)
	MsgPullReceiptAck = "pull_receipt_ack" // hub → runner: stop replaying
)

// PullWorkspacePayload asks a runner to fetch and verify exactly Ref under Resource.
type PullWorkspacePayload struct {
	OperationID    string
	RunID          uuid.UUID
	WorkDir        string
	HomeGeneration int64
	Ref            CheckpointRef
	Resource       engine.ResourceFenceRef
	PullToken      string
	PartBytes      int64
}

// PullReceiptPayload is a runner's terminal answer to one PullWorkspacePayload.
type PullReceiptPayload struct {
	OperationID string
	RunID       uuid.UUID
	Ref         CheckpointRef
	Resource    engine.ResourceFenceRef
	OK          bool
	Error       string
}

// PullRequester is the hub's send side (*Hub implements it, Cycle 2c).
type PullRequester interface {
	RequestPull(ctx context.Context, target RunnerID, p PullWorkspacePayload) error
	AckPullReceipt(ctx context.Context, target RunnerID, operationID string)
}

// PullTokenIssuer is the slice of P3 T7's TransferTokenService used here.
type PullTokenIssuer interface {
	Issue(ctx context.Context, scope TransferScope, ttl time.Duration) (TransferToken, error)
}

var (
	ErrPullScope           = errors.New("runner: maintenance pull claim does not cover this run and target")
	ErrPullTargetOffline   = errors.New("runner: maintenance pull target is not connected")
	ErrPullFailed          = errors.New("runner: target runner could not pull the workspace")
	ErrPullReceiptMismatch = errors.New("runner: pull receipt does not match the requested transfer")
	ErrPullTimeout         = errors.New("runner: timed out waiting for the target's pull receipt")
)

const maxEarlyPullReceipts = 256

// PullOperationID is the durable identity of the pull authorized by claim:
// identical for a replay, different for any later claim.
func PullOperationID(claim engine.ResourceFenceRef) string {
	return fmt.Sprintf("pull:%s@%d/%s", claim.Key, claim.Generation, claim.Owner)
}

// PullCoordinatorDeps: all required except Clock (time.Now), Timeout (10 min),
// TokenTTL (Timeout) and PartBytes (8 MiB).
type PullCoordinatorDeps struct {
	Hub        PullRequester
	Tokens     PullTokenIssuer
	Leases     ResourceLeaseStore
	Homes      HomeStore
	Workspaces engine.WorkspaceManager
	Clock      func() time.Time
	Timeout    time.Duration
	TokenTTL   time.Duration
	PartBytes  int64
}

type pullWaiter struct {
	target RunnerID
	ch     chan PullReceiptPayload
}

type earlyPull struct {
	from RunnerID
	rc   PullReceiptPayload
}

// WorkspacePullCoordinator implements DrainPuller.
type WorkspacePullCoordinator struct {
	d       PullCoordinatorDeps
	mu      sync.Mutex
	waiting map[string]pullWaiter
	early   map[string]earlyPull
}

func NewWorkspacePullCoordinator(d PullCoordinatorDeps) (*WorkspacePullCoordinator, error) {
	var missing []string
	if d.Hub == nil {
		missing = append(missing, "Hub")
	}
	if d.Tokens == nil {
		missing = append(missing, "Tokens")
	}
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if d.Workspaces == nil {
		missing = append(missing, "Workspaces")
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: NewWorkspacePullCoordinator missing %s", strings.Join(missing, ", "))
	}
	if d.Clock == nil {
		d.Clock = time.Now
	}
	if d.Timeout <= 0 {
		d.Timeout = 10 * time.Minute
	}
	if d.TokenTTL <= 0 {
		d.TokenTTL = d.Timeout
	}
	if d.PartBytes <= 0 {
		d.PartBytes = 8 << 20
	}
	return &WorkspacePullCoordinator{d: d, waiting: map[string]pullWaiter{}, early: map[string]earlyPull{}}, nil
}

// PullCommitted makes target fetch and verify exactly ref while claim (owned
// by target) is live, and returns only a receipt matching that request.
func (c *WorkspacePullCoordinator) PullCommitted(ctx context.Context, runID uuid.UUID, target RunnerID, ref CheckpointRef, claim engine.ResourceFenceRef) (PullReceipt, error) {
	if claim.Key != runKey(runID) || claim.Owner != string(target) || (!ref.IsZero() && ref.RunID != runID) {
		return PullReceipt{}, ErrPullScope
	}
	if err := c.d.Leases.Check(ctx, claim); err != nil {
		return PullReceipt{}, err
	}
	opID := PullOperationID(claim)
	want := PullReceipt{OperationID: opID, RunnerID: target, Ref: ref, Resource: claim}
	if ref.IsZero() {
		return want, nil // an empty workspace: nothing to fetch
	}
	ch, stored := c.wait(opID, target)
	defer c.forget(opID)
	if !stored {
		if err := c.request(ctx, runID, target, ref, claim, opID); err != nil {
			return PullReceipt{}, err
		}
	}
	timer := time.NewTimer(c.d.Timeout)
	defer timer.Stop()
	select {
	case rc := <-ch:
		if !rc.OK {
			return PullReceipt{}, fmt.Errorf("%w: %s", ErrPullFailed, rc.Error)
		}
		if rc.RunID != runID || rc.Ref != ref || rc.Resource != claim {
			return PullReceipt{}, ErrPullReceiptMismatch
		}
		if err := c.d.Leases.Check(ctx, claim); err != nil {
			return PullReceipt{}, err
		}
		return want, nil
	case <-timer.C:
		return PullReceipt{}, fmt.Errorf("%w (%s on %s)", ErrPullTimeout, opID, target)
	case <-ctx.Done():
		return PullReceipt{}, ctx.Err()
	}
}

func (c *WorkspacePullCoordinator) request(ctx context.Context, runID uuid.UUID, target RunnerID, ref CheckpointRef, claim engine.ResourceFenceRef, opID string) error {
	home, err := c.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return err
	}
	workDir, err := c.d.Workspaces.EnsureInstanceDir(runID)
	if err != nil {
		return err
	}
	tok, err := c.d.Tokens.Issue(ctx, TransferScope{Fence: Fence{RunnerID: target}, MaintenanceOperationID: opID, RunID: runID,
		Direction: TransferPull, BaseRef: ref.String(), Resource: claim}, c.d.TokenTTL)
	if err != nil {
		return err
	}
	return c.d.Hub.RequestPull(ctx, target, PullWorkspacePayload{OperationID: opID, RunID: runID, WorkDir: workDir,
		HomeGeneration: home.Generation + 1, Ref: ref, Resource: claim, PullToken: tok.Token, PartBytes: c.d.PartBytes})
}

// wait registers the waiter; stored reports that a receipt was already there.
func (c *WorkspacePullCoordinator) wait(opID string, target RunnerID) (<-chan PullReceiptPayload, bool) {
	c.mu.Lock()
	defer c.mu.Unlock()
	ch := make(chan PullReceiptPayload, 1)
	if e, ok := c.early[opID]; ok && e.from == target {
		delete(c.early, opID)
		ch <- e.rc
		return ch, true
	}
	c.waiting[opID] = pullWaiter{target: target, ch: ch}
	return ch, false
}

func (c *WorkspacePullCoordinator) forget(opID string) {
	c.mu.Lock()
	defer c.mu.Unlock()
	delete(c.waiting, opID)
}

// Receive takes every pull receipt the hub reads (live, or replayed in
// hello) and always acknowledges it. A receipt for an operation nobody waits
// for is kept (bounded) for the pass that retries it.
func (c *WorkspacePullCoordinator) Receive(ctx context.Context, from RunnerID, rc PullReceiptPayload) {
	defer c.d.Hub.AckPullReceipt(ctx, from, rc.OperationID)
	c.mu.Lock()
	defer c.mu.Unlock()
	if w, ok := c.waiting[rc.OperationID]; ok {
		if w.target == from {
			select {
			case w.ch <- rc:
			default:
			}
		}
		return
	}
	if len(c.early) >= maxEarlyPullReceipts {
		for k := range c.early {
			delete(c.early, k)
			break
		}
	}
	c.early[rc.OperationID] = earlyPull{from: from, rc: rc}
}

package runner

import (
	"context"
	"fmt"
)

// PullReceiver takes pull receipts read from runners (*WorkspacePullCoordinator).
type PullReceiver interface {
	Receive(ctx context.Context, from RunnerID, rc PullReceiptPayload)
}

// SetPullReceiver installs the coordinator that owns pull receipts.
func (h *Hub) SetPullReceiver(r PullReceiver) {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.pulls = r
}

// RequestPull sends pull_workspace to target's live session.
func (h *Hub) RequestPull(ctx context.Context, target RunnerID, p PullWorkspacePayload) error {
	s := h.session(target)
	if s == nil {
		return fmt.Errorf("%w: %s", ErrPullTargetOffline, target)
	}
	if err := s.conn.Send(ctx, Outbound{Kind: MsgPullWorkspace, PullWorkspace: &p}); err != nil {
		return fmt.Errorf("%w: %s: %v", ErrPullTargetOffline, target, err)
	}
	return nil
}

// AckPullReceipt tells target to stop replaying operationID (best effort).
func (h *Hub) AckPullReceipt(ctx context.Context, target RunnerID, operationID string) {
	h.send(ctx, h.session(target), Outbound{Kind: MsgPullReceiptAck, PullReceiptAck: operationID})
}

func (h *Hub) deliverPullReceipt(ctx context.Context, s *Session, rc PullReceiptPayload) error {
	if rc.OperationID == "" {
		return fmt.Errorf("%w: pull receipt without an operation", ErrMalformedMessage)
	}
	h.mu.Lock()
	r := h.pulls
	h.mu.Unlock()
	if r == nil {
		h.AckPullReceipt(ctx, s.RunnerID, rc.OperationID) // nothing can use it: stop the replay
		return nil
	}
	r.Receive(ctx, s.RunnerID, rc)
	return nil
}

// PendingPullReceipts lists the receipts not yet acknowledged, oldest operation first.
func (a *Agent) PendingPullReceipts() []PullReceipt {
	a.mu.Lock()
	defer a.mu.Unlock()
	out := make([]PullReceipt, 0, len(a.pullReceipts))
	for _, r := range a.pullReceipts {
		out = append(out, r)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].OperationID < out[j].OperationID })
	return out
}

// onPullWorkspace runs one maintenance pull off the receive loop and answers
// with a receipt; the receipt is kept until the server acknowledges it.
func (a *Agent) onPullWorkspace(ctx context.Context, s Session, p PullWorkspace) {
	go func() {
		rc := PullReceipt{OperationID: p.OperationID, RunID: p.Job.RunID, BaseRef: p.Job.BaseRef, FenceKey: p.Job.FenceKey,
			FenceOwner: p.Job.FenceOwner, FenceGeneration: p.Job.FenceGeneration, FenceToken: p.Job.FenceToken}
		switch {
		case a.deps.Pulls == nil:
			rc.Error = "workspace transfers are not configured on this runner"
		default:
			if _, err := a.deps.Pulls.Pull(a.runContext(ctx), p.Job); err != nil {
				rc.Error = err.Error()
			} else {
				rc.OK = true
			}
		}
		a.mu.Lock()
		a.pullReceipts[rc.OperationID] = rc
		a.mu.Unlock()
		_ = s.Send(ctx, Outbound{Kind: KindPullReceipt, PullReceipt: &rc}) // a lost send is replayed in the next hello
	}()
}

func (a *Agent) ackPullReceipt(opID string) {
	a.mu.Lock()
	defer a.mu.Unlock()
	delete(a.pullReceipts, opID)
}

import (

type revocationHomeReleaser struct {
	inner  SessionRevoker
	homes  HomeStore
	leases ResourceLeaseStore
}

// NewRevocationHomeReleaser decorates the hub's SessionRevoker. After the hub
// has marked the runner lost (fencing its jobs), each home it owned is taken
// over by durable proof (Supersede: revoked key, else lost runner) or a free
// claim, released to server storage at the read generation, and the claim is
// given back. A hub failure releases nothing; an unproven takeover leaves the
// home owned; a home that moved meanwhile is never clobbered.
func NewRevocationHomeReleaser(inner SessionRevoker, homes HomeStore, leases ResourceLeaseStore) SessionRevoker {
	if inner == nil || homes == nil || leases == nil {
		panic("runner: NewRevocationHomeReleaser requires a SessionRevoker, a HomeStore and a ResourceLeaseStore")
	}
	return &revocationHomeReleaser{inner: inner, homes: homes, leases: leases}
}

func (r *revocationHomeReleaser) RevokeRunner(ctx context.Context, id RunnerID) error {
	if err := r.inner.RevokeRunner(ctx, id); err != nil {
		return fmt.Errorf("revoking %s: %w; its workspace homes stay owned until its jobs are fenced", id, err)
	}
	homes, err := r.homes.ListByRunner(ctx, id)
	if err != nil {
		return err
	}
	var errs []error
	for _, h := range homes {
		if err := r.release(ctx, id, h); err != nil {
			errs = append(errs, fmt.Errorf("run %s: %w", h.RunID, err))
		}
	}
	return errors.Join(errs...)
}

func (r *revocationHomeReleaser) release(ctx context.Context, id RunnerID, h Home) error {
	key, holder := runKey(h.RunID), "revoke:"+string(id)
	rec, active, err := r.leases.Active(ctx, key)
	if err != nil {
		return err
	}
	var claim engine.ResourceFenceRef
	if active {
		if rec.Fence.Owner != string(id) {
			return fmt.Errorf("%w: claimed by %q, not the revoked runner", ErrResourceBusy, rec.Fence.Owner)
		}
		if claim, err = r.supersede(ctx, rec, holder); err != nil {
			return err
		}
	} else if claim, err = r.leases.Claim(ctx, key, holder, BuiltInRunnerID); err != nil {
		return err
	}
	defer func() {
		if err := r.leases.Release(context.WithoutCancel(ctx), claim); err != nil {
			slog.Warn("releasing revocation claim", "run", h.RunID, "error", err)
		}
	}()
	cause := HomeMoveCause{OperationID: holder, FromGeneration: h.Generation, ToGeneration: h.Generation + 1}
	_, err = r.homes.HandOff(ctx, h.RunID, ServerHome, "revoked: "+string(id), 0, h.Generation, cause)
	if errors.Is(err, ErrHomeGenerationConflict) {
		return nil // recovery or another move already won; never clobber it
	}
	return err
}

func (r *revocationHomeReleaser) supersede(ctx context.Context, rec LeaseRecord, holder string) (engine.ResourceFenceRef, error) {
	var errs []error
	for _, kind := range []SupersedeKind{SupersedeRevoked, SupersedeRunnerLost} {
		ref, err := r.leases.Supersede(ctx, rec.Fence, SupersedeProof{Kind: kind, OldJob: rec.Job}, holder, BuiltInRunnerID)
		if err == nil {
			return ref, nil
		}
		if !errors.Is(err, ErrSupersedeUnproven) {
			return engine.ResourceFenceRef{}, err
		}
		errs = append(errs, err)
	}
	return engine.ResourceFenceRef{}, errors.Join(errs...)
}

// movesDuring returns the moves made while ex was executing (a move happens
// when its step is placed, inside the attempt).
func movesDuring(all []instance.WorkspaceMove, ex instance.NodeExecution) []instance.WorkspaceMove {
	var out []instance.WorkspaceMove
	for _, m := range all {
		if m.At.Before(ex.StartedAt) {
			continue
		}
		if ex.CompletedAt != nil && m.At.After(*ex.CompletedAt) {
			continue
		}
		out = append(out, m)
	}
	return out
}
