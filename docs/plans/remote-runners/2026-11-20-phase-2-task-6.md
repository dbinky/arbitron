**Goal:** Make `llm_call` chat and spawn-workflow child-input preparation eligible for any runner (`AffinityNone`) while every other operation stays on the built-in runner. Remote assignments then reach the hub through a remote `StepRunner` that hands over only a hermetic copy of the job. The tests prove end to end, through the real `StepDispatcher`, the SQLite pool and in-memory remote runners, that:
- fan-out respects each runner's step limit and source families;
- LunaRoute steps run only on a runner that advertises its own LunaRoute source;
- a lost runner, an unaccepted offer or a revoked key re-places the step at the next generation without spending a workflow retry;
- a late result from the old generation is fenced.

**Architecture:**
- `domain/runner/hermetic.go` adds `HermeticChatAffinity`, the binding-level affinity function that P2 T10 passes to `NewRoutingChatSelector`. It also adds `hermeticCallAffinity`, which narrows that per call from the step identity stamped on the context (P1 T2) and from the request.
- `routedChat.Chat` and `routedChat.StreamChat` in `domain/runner/selectors.go` (P1 T10) call `hermeticCallAffinity` instead of using the selector-time affinity directly.
- `domain/runner/hubrunnerset.go`: `NewHubRunnerSet` maps the built-in ID to the built-in `StepRunner` and every other registered, non-built-in runner to the remote `StepRunner`.
- `adapter/runner/remote/runner.go`: `remote.Runner` refuses built-in or unassigned assignments, strips every server-only field from a copy of the job (key closure, base URL, extras, work dir), and calls `Hub.Run` (P2 T4).
- The dispatcher's runner-lost branch already exists. In P1 T8, `StepDispatcher.runOnce` handles `case OutcomeExhausted, OutcomeLoggedOut, OutcomeRunnerLost:` by calling `reroute`, which does `Ledger.Requeue` (generation+1), records the fact and records a run-scoped `job.rerouted` event. This task wires the hub behind it and proves the branch end to end. It does not duplicate the code.

Hermetic placement rule (exact):
- `HermeticChatAffinity(b)` returns `AffinityNone` for `provider.ProfileKindChat` bindings and `AffinityBuiltIn` for anything else. The routing stream selector stays hard-wired to `AffinityBuiltIn` (P1 T10), and the agent selector and routed process runner are unchanged.
- Per call, `hermeticCallAffinity` keeps `AffinityNone` only when all of these hold:
  - the step identity on the context has `Kind == engine.OperationNode` or `engine.OperationChildInput`;
  - `req.SessionID == ""`;
  - the call carries no tools: `req.SuppressTools` is true, or both `req.ToolScope` and `b.AllowedTools` are empty.
- In every other case the call is `AffinityBuiltIn`. That covers interactive turns (`OperationTurn`), conflict resolution (`OperationResolution`), probes (`OperationProbe`), calls without an identity, tool-bearing chat, and session resumes.
- `OperationNode` identifies `llm_call` because `LLMCallExecutor` (`domain/engine/executor_llm.go:78`) is the only node executor that selects a `ChatProvider`. The only other chat-selector caller in the engine is the child-input preparer (`domain/engine/child_input_preparer.go:110`), which stamps `OperationChildInput`.
- The interactive stream selector's chat path (`adapter/provider/interactive_stream_selector.go:73`) runs under `OperationTurn`.

```go
// domain/runner/hermetic.go
package runner

import (
	"context"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/provider"
)

// HermeticChatAffinity is the Phase 2 chat affinity function for
// NewRoutingChatSelector: a chat-kind (tool-suppressed) binding may run on any
// runner; every other kind stays on the built-in runner. Each call is narrowed
// further by hermeticCallAffinity.
func HermeticChatAffinity(b provider.ResolvedBinding) Affinity {
	if b.Kind == provider.ProfileKindChat {
		return AffinityNone
	}
	return AffinityBuiltIn
}

// hermeticCallAffinity decides one chat call's affinity. Only the two hermetic
// call sites may leave the server: an llm_call node (OperationNode;
// LLMCallExecutor is the only node executor that selects a ChatProvider) and
// spawn_workflow child-input preparation (OperationChildInput). Even then the
// call must need nothing from the server: no tools (they would act on a
// workspace) and no session to resume (sessions stay on the server until
// Phase 4). Interactive turns, resolutions, probes and calls without an
// identity stay built-in.
func hermeticCallAffinity(ctx context.Context, base Affinity, b provider.ResolvedBinding, req engine.ChatRequest) Affinity {
	if base != AffinityNone {
		return base
	}
	id, ok := engine.StepIdentityFromContext(ctx)
	if !ok || (id.Kind != engine.OperationNode && id.Kind != engine.OperationChildInput) {
		return AffinityBuiltIn
	}
	if req.SessionID != "" {
		return AffinityBuiltIn
	}
	if !req.SuppressTools && (len(req.ToolScope) > 0 || len(b.AllowedTools) > 0) {
		return AffinityBuiltIn
	}
	return AffinityNone
}
```

```go
func sourceRequestMatches(s Source, req ExecRequirements) bool {
	// … existing checks unchanged …
	if len(s.Models) > 0 && !slices.Contains(s.Models, req.Model) {
		return false
	}
	return s.RunnerID == BuiltInRunnerID || slices.ContainsFunc(s.Capabilities, func(c ExecutionCapability) bool { return capabilitySatisfies(c, req) })
}

// capabilitySatisfies is the exact remote eligibility predicate (design P2 §3
// "Eligibility evidence"). Built-in sources keep factory validation instead.
func capabilitySatisfies(c ExecutionCapability, req ExecRequirements) bool {
	if c.Op != req.Op || c.Backend != req.Backend || c.EndpointFingerprint != req.EndpointFingerprint ||
		provider.Canonicalize(c.Provider) != provider.Canonicalize(req.Provider) ||
		!slices.Contains(c.Families, req.Group.Family) || !slices.Contains(c.Models, req.Model) {
		return false
	}
	if req.ContextWindow != "" && req.ContextWindow != provider.ContextDefault && !slices.Contains(c.ContextWindows, req.ContextWindow) {
		return false
	}
	if req.Effort != "" && req.Effort != provider.EffortDefault && !slices.Contains(c.Efforts, req.Effort) {
		return false
	}
	for _, t := range req.Tools {
		if !slices.Contains(c.Tools, t) {
			return false
		}
	}
	return !req.RequireExecutedModel || c.ExecutedModel
}
```

```go
// builtinRunner stands in for the built-in StepRunner: it executes only
// built-in assignments, can hold work until released, and records each job.
type builtinRunner struct {
	mu       sync.Mutex
	hold     bool
	gate     chan struct{}
	jobs     []runner.StepJob
	inflight int
	max      int
}

func newBuiltinRunner() *builtinRunner { return &builtinRunner{gate: make(chan struct{})} }

func (b *builtinRunner) SetHold(v bool) {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.hold = v
}

// ReleaseAll stops holding and lets every held job finish.
func (b *builtinRunner) ReleaseAll() {
	b.mu.Lock()
	defer b.mu.Unlock()
	b.hold = false
	close(b.gate)
	b.gate = make(chan struct{})
}

func (b *builtinRunner) Run(ctx context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error) {
	if a.Fence.RunnerID != runner.BuiltInRunnerID {
		return runner.StepOutput{}, fmt.Errorf("built-in runner handed an assignment for %q", a.Fence.RunnerID)
	}
	b.mu.Lock()
	rec := job
	if job.Chat != nil {
		c := *job.Chat
		rec.Chat = &c
	}
	b.jobs = append(b.jobs, rec)
	b.inflight++
	if b.inflight > b.max {
		b.max = b.inflight
	}
	hold, gate := b.hold, b.gate
	b.mu.Unlock()
	defer func() {
		b.mu.Lock()
		b.inflight--
		b.mu.Unlock()
	}()
	if hold {
		select {
		case <-gate:
		case <-ctx.Done():
			return runner.StepOutput{}, ctx.Err()
		}
	}
	return runner.StepOutput{Chat: &engine.ChatResponse{Output: "builtin:" + job.Chat.Model, Model: job.Chat.Model}}, nil
}

	b.mu.Lock()
	defer b.mu.Unlock()
	return append([]runner.StepJob(nil), b.jobs...)
}

	defer b.mu.Unlock()
	return b.inflight
```

```go
// adapter/runner/remote/runner.go

// Package remote is the server-side StepRunner for remote runners. It hands
// hermetic work to the hub, which offers it over the runner channel, and
// guarantees that no server-only binding field or server path reaches that
// path.
package remote

import (
	"context"
	"fmt"

	"github.com/arbitron/arbitron/domain/runner"
)

// hubRunner is the slice of *runner.Hub this adapter drives.
type hubRunner interface {
	Run(ctx context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error)
}

// Runner executes assignments placed on remote runners.
type Runner struct {
	hub hubRunner
}

// New returns the remote StepRunner over h. It panics on a nil hub.
func New(h *runner.Hub) *Runner {
	if h == nil {
		panic("remote: New requires a hub")
	}
	return &Runner{hub: h}
}

// Run implements runner.StepRunner. Built-in or unassigned assignments are a
// placement bug and fail as OutcomeOther without touching the hub.
func (r *Runner) Run(ctx context.Context, a runner.Assignment, job runner.StepJob) (runner.StepOutput, error) {
	if a.Fence.RunnerID == "" || a.Fence.RunnerID == runner.BuiltInRunnerID {
		return runner.StepOutput{}, runner.WithOutcome(
			fmt.Errorf("remote: assignment %s is for runner %q, not a remote runner", a.Job.ID, a.Fence.RunnerID),
			runner.SourceOutcome{Class: runner.OutcomeOther})
	}
	return r.hub.Run(ctx, a, hermetic(job))
}

// hermetic returns a copy of job without the server-only fields: the key
// closure, gateway URL and extras (the runner uses its own credentials) and
// the server work dir (the runner uses a per-job scratch dir). The caller's
// job is untouched because a re-placed built-in attempt still needs them.
func hermetic(job runner.StepJob) runner.StepJob {
	out := job
	out.Binding.RevealKey = nil
	out.Binding.BaseURL = ""
	out.Binding.Extras = nil
	if job.Chat != nil {
		c := *job.Chat
		c.WorkDir = ""
		out.Chat = &c
	}
	return out
}
```
