# Remote Runners — Phase 3 Task 2: Immutable checkpoint artifacts and prepared candidates

**Goal:** Produce recoverable, immutable tar+gzip artifacts with verified manifests and portable Git metadata. A prepared artifact becomes committed progress only through the validated step/resource/turn transaction; uploading bytes never changes the recovery base.

**Architecture:** Pure manifest vocabulary, hash and diff live in `domain/runner` (`checkpoint.go`, `manifest.go`), so the server store and the runner agent (P3 T9) share one algorithm. `adapter/checkpoint.Store` owns the filesystem layout (immutable archives and manifests, version reservations, verified read cache, private staging) and registers artifacts with a `runner.CheckpointCatalog`. The SQLite `CheckpointCatalogRepo` stores **prepared** rows tagged with the exact job and resource receipts; the committed pointer is `workspace_homes.checkpoint_version`, which only `Bootstrap` (here) and the P3 T5 / P3 T13 / P4 T6 transactions move. `Latest` reads only that pointer.

**Tech Stack:** Go 1.25.5 stdlib `archive/tar`, `compress/gzip` (RR-15 decision: gzip, no new dependency), `os.Root` for traversal-safe extraction, the system `git` CLI (offline: `GIT_NO_LAZY_FETCH=1`, `protocol.allow=never`) for portable Git, modernc SQLite (migration 044, no new migration), testify.

**Spec/design:** remote-runners spec "Recovery and session continuity"; Phase 3 design §3.3 (Manifest, Push, Built-in runner, Completion boundary), §5 rows "Committed checkpoint, manifest…" (RR-08) and "Archive compression" (RR-15), §7 (partial uploads never applied; disk full keeps the previous checkpoint), §8 regressions (chmod/deletion/symlink/Git round-trip; two successful steps publish distinct manifests). Shared contracts `2026-11-20-contracts.md` §8 (`Fence`, `ErrFenced`), §16 (checkpoint names), §21 (fenced completion receipts) and "Checkpoint catalog candidate (P3 T2)", §22 (RR-08, RR-17 rows), §24 (RR-17 decision). This task replaces the previous checkpoint plan in full: immediate latest-row publication and nil-fence built-in success are removed.

**Dependencies:** P3 T1 (migration 044, `engine.ResourceFenceRef`), P1 T5/T6 (ledger `runner_jobs` and the single fence rule). P3 T3 (resource lease) is a **peer contract**: only Cycle 4 consumes it. P3 T5 (step transaction) consumes this task's prepared rows; P3 T6/T7/T9/T11/T13/T16 and P4 T6/T11 consume its store.

**Current code (2026-11-23):** none of this task is implemented on the branch. `domain/runner/checkpoint.go`, `domain/runner/manifest.go`, `adapter/checkpoint/` and `adapter/sqlite/checkpoint_catalog_repo.go` do not exist. Migration 044 already has every column used here (`workspace_checkpoints` with `state`, `base_ref`, `resource_*`; `workspace_leases`; `workspace_homes.non_portable_reason`), and `workspace_homes.checkpoint_version` exists since 041. This task adds **no** schema. No step is pre-checked.

## Candidate and publication semantics

- `StageBuiltIn` and `Publish` fsync the complete archive, its manifest and the run directory **before** registering the `CheckpointCandidate`. `CheckpointCatalogRepo.Publish` validates, in ONE SQLite transaction: the exact active job fence (sqlite `fenceErr`, unknown job ⇒ `ErrFenced`), the exact active resource claim (P3 T3 `checkResourceFenceTx`), that a job-held claim is held by this exact job (`workspace_lease_holders`), and that `Base` equals the committed pointer. Then it inserts `state='prepared'` with both fences and `base_ref`. Inserting a row does **not** update `workspace_homes.checkpoint_version` or clear dirty.
- `Latest` resolves that authoritative committed pointer and requires the row it names to be committed; a pointer at a missing/prepared row is `ErrCorruptCheckpoint`. No `ORDER BY version DESC` query substitutes for the pointer. `Get` returns committed rows only, so `Restore`, `Manifest`, `ReadFile` and `StageDelta` bases never serve a prepared candidate. Prepared rows stay queryable by exact operation for validation inside P3 T5's transaction (it reads them by `(run_id, version)` with their job/resource columns).
- `Commit` is **bootstrap only**, called by P3 T6 `WorkspaceBaselineInitializer.EnsureBaseline` through `Engine.prepareWorkspace` before dispatcher intent/reservation/resource claim. `Bootstrap` atomically verifies no prior committed checkpoint (pointer or committed row), no active `run:<uuid>` row in `workspace_leases` and no offered/running job of the run, then records the baseline row and the pointer. A competing baseline gets `ErrCheckpointConflict` (P3 T6 re-reads instead of overwriting). It is not used for dispatched steps, server group mutations or interactive turns. A first `BeginAttempt` requires this baseline and cannot create it after claiming. Group branch `ForkTask` must finish before the child baseline hook runs (P3 T6). P3 T5's step transaction, P3 T13's resource transaction and P4's turn transaction perform their respective progress publication.
- Bootstrap rows carry provenance-only resource columns (`resource_key='run:<uuid>'`, `resource_owner='bootstrap'`, generation 1, a random token) because 044 makes those columns `NOT NULL`. They are never compared as authorization; only prepared rows carry real claims.
- Candidate version allocation is unique transactionally even under concurrent preparation or retried requests: the store reserves versions with an exclusive-create marker (`v<N>.reserved`), and the catalog's primary key `(run_id, version)` rejects any second registration (`ErrCheckpointConflict`). A matching idempotency identity (same ref, base, job, resource, path, size) returns the same candidate. Ref/job/resource/base mismatch is a conflict. Abandoned versions leave gaps.
- The prior artifact is preserved until durable result/continuation publication: this task deletes no artifact except through `Delete(runID)` (workspace removal). Crash after artifact creation leaves an unreferenced artifact; crash after prepared insertion leaves a prepared row; neither changes the recovery base. A catalog error after install leaves the installed files in place as unreferenced orphans (the outcome of a failed DB commit is not assumed). Garbage collection may prune only unreferenced expired artifacts, never committed/replay refs or active candidates; no GC is implemented here (see "Open contract gaps").
- **Server-side resource mutations (contracts §25, decision for former gap 1 = option c):** `StageResource(runID, srcDir, base)` writes the immutable archive and manifest at a freshly reserved version through the same strict walk **and portable Git materialization** as `StageBuiltIn` (group workspaces may be linked worktrees) and registers **no** catalog row; `Latest` is unchanged. RR-08 `ErrPromisorObjectsMissing` (wrapped with `ErrUnsupportedGit`) and every other walker error (`ErrUnsupportedFileType`, …) propagate unchanged. The returned `StagedCheckpoint` has an empty `Dir` (its `ArchivePath` is already the immutable artifact), so `Publish`/`Discard` do not apply. P3 T13 `ResourceCommitRepo.CommitResource(ctx, claim, staged)` inserts the row directly as committed and moves the pointer in its own transaction.
- **Exact prepared lookup (contracts §25):** `CheckpointCatalog.PreparedFor(runID, job, resource)` returns the single `state='prepared'` row whose `job_id`/`job_generation` and `resource_key`/`resource_owner`/`resource_generation`/`resource_token` match exactly, with the runner checked through the claim's `workspace_lease_holders` row. Committed rows never match; two matches are `ErrCheckpointConflict` (never a newest-row guess). `Store.PreparedFor` delegates. P3 T6 `FinishSuccess` uses it so an adopted remote job can commit its pushed candidate after a server restart.
- Remote pushes: `StageDelta` returns a `StagedCheckpoint` with a zero `Resource`; P3 T7 assigns `staged.Resource` from the durable transfer session before `WorkspaceSync.AcceptPush` calls `Publish`. A zero resource is `ErrInvalidCandidate`.

## Archive and manifest safety

Sort normalized relative paths; include file modes, directories, symlinks, deletions and required Git data in deterministic hashing. Reject absolute/traversal/backslash/empty/NUL paths and unsupported devices/sockets/FIFOs (`ErrUnsupportedFileType`). Never write an entry beneath a symlink (even one inside the root), bound decompressed bytes, entry count and path length (`Limits`), and reject duplicate archive names, non-zero data after the tar end, any trailing part after the gzip member and hash/manifest mismatches (`ErrCorruptCheckpoint`). Extract through `os.Root` into a private staging tree; workspace paths that overlap the store directory are refused, so there is no symlink traversal into execution or checkpoint roots. Verify every changed file's declared size/hash and the full resulting manifest before candidate preparation (`ErrManifestMismatch`). `Restore` extracts into a private sibling staging directory and verifies it before replacing the destination's contents; a failed or partial restore leaves the destination and the prior recoverable artifact intact. The safe ownership boundary for the swap (exact claim, process stopped) is the caller's (P3 T6/T10).

`ReadFile` opens only a manifest-listed regular file of the exact referenced committed snapshot, from a verified extraction of that immutable archive. It never serves a mutable work dir, a prepared candidate, a directory, or a symlink. `StageDelta` applies declared deletions and changes to the pinned committed base in private staging, verifies the full next manifest and does not mutate the base.

Symlink link text is preserved verbatim (a workspace may hold absolute links such as `.venv/bin/python`); containment is enforced on every operation instead: no extraction, deletion or read follows a symlink. See "Open contract gaps" (symlink containment) for the alternative.

## Portable Git producer

`adapter/checkpoint/git.go:MaterializePortableGit` operates only on a PRIVATE checkpoint copy, preserving the user's original working tree/repository byte for byte. It resolves linked-worktree common metadata and materializes self-contained object/ref/index data; dirty/untracked files and executable bits come from the normal walk; HEAD/ORIG_HEAD/MERGE_HEAD/CHERRY_PICK_HEAD/REVERT_HEAD/REBASE_HEAD/AUTO_MERGE, reflogs and unmerged index stages are kept. The required object closure is computed from `--all --reflog --indexed-objects` plus those pseudo-heads, not `--all` refs alone. The private copy temporarily lists the source object directory as an alternate, packs the closure into private storage with `git pack-objects` (lazy network fetch disabled with `GIT_NO_LAZY_FETCH=1` and every transport disabled with `-c protocol.allow=never`), removes the private alternate and any gitdir backlinks, and re-verifies the closure there with no alternate. Tests verify restore with the original repository removed and network disabled. External paths are never copied as dangling metadata. P4 T11's resolution portability adapter reuses this helper, so merge/conflict state has the same fixture contract.

Alternates that can be materialized locally are supported; auto-repacking the user's repository is neither necessary nor authorized by this task. A repository whose own objects are missing (not a partial clone) returns `ErrUnsupportedGit` naming the cause, preserving prior progress. It cannot silently complete in place without a recoverable snapshot.

**DECISION (2026-11-22, RR-08):** Arbitron never performs a network fetch to build a checkpoint (Git runs with `GIT_NO_LAZY_FETCH=1`; no `git fetch`, no credential helper). Partial-clone/promisor repositories are a **Non-Goal for remote execution**. When required promisor objects are absent locally, `MaterializePortableGit` returns an error wrapping `ErrUnsupportedGit` **and** the sentinel `ErrPromisorObjectsMissing` (declared in `domain/runner/checkpoint.go` beside `ErrUnsupportedGit`), and `StageBuiltIn`/`Commit` propagate it unchanged without registering any candidate. This is **not** a step failure: the consumer P3 T6 `WorkspaceSync` (`EnsureBaseline` and `CommitBuiltIn`) treats `errors.Is(err, ErrPromisorObjectsMissing)` by calling the P3 T3 producer `HomeStore.SetNonPortable(ctx, runID, NonPortablePromisorReason)` and continuing in built-in-only mode (no catalog checkpoint is created for that step; per RR-17 decision B, P3 T16 takes a server-local checkpoint instead. See "Recovery base — DECISION RR-17: B" below). `NonPortablePromisorReason` is the exact visible string "partial clone: required promisor objects missing locally; use a full clone or run git fetch --refetch" (declared in `domain/runner/homes.go`, already on the branch). P3 T4 `Place` pins such a home to the built-in runner (`AffinityBuiltIn`) and excludes it from remote placement and load moves. The marker clears automatically: the next successful `StageBuiltIn` for that run (all objects present) produces a normal candidate, and P3 T5 clears `non_portable_reason` in the same transaction that promotes it. A home that was non-portable from the start has no committed catalog checkpoint, so that first normal candidate is prepared on the zero `Base` (the catalog accepts a zero base exactly when the committed pointer is 0). Full non-portable semantics (baseline exception, no restore, `NonPortable` completion receipt, recovery) are specified in the RR-08 amendments of P3 T1/T3/T4/T5/T6/T10. Other `ErrUnsupportedGit` causes (not promisor) keep their existing visible-failure behaviour.

## Recovery base — DECISION RR-17: B

**DECISION (2026-11-22) RR-17: B** (contracts §22/§24; owner P3 T16, `2026-11-20-phase-3-task-16.md`). A non-portable home takes a **local checkpoint** after each workspace-changing step completes: a plain copy of its directory on the server's own disk, with no portable-Git materialization. The step transaction commits it as `workspace_homes.local_checkpoint` via `WorkspaceCompletion.LocalRef`, and only the latest committed copy is kept. PoolRecovery restores it and re-runs the interrupted step under the same fences. With no local copy, recovery uses the home's initial state. With no base at all, `runner.ErrNoRecoveryBase` produces the durable `job.recovery_blocked` blocker. **This task:** `ErrPromisorObjectsMissing` is still the signal. P3 T6/T16 now answer it with a local checkpoint rather than a checkpoint-less receipt. The non-portable copy is made by `checkpoint.LocalStore` (P3 T16), never by `MaterializePortableGit`, and never enters the catalog or transfer paths. P3 T16 consumes `EntryFromInfo`, `NewManifest`, `Manifest.Verify`, `ErrCheckpointNotFound`, `ErrCheckpointConflict`, `ErrUnsupportedFileType`, `ErrCorruptCheckpoint`, `ErrPromisorObjectsMissing`, `CheckpointRef`, `CheckpointStore.Latest`/`Restore` (the "last committed portable checkpoint" fallback) exactly as produced here, and lives in the same `adapter/checkpoint` package. This task's unexported helpers do not collide with P3 T16's `copyTree`, `copyRegular` or `createSyncedFile` (this task uses `copyGitMeta`, `copyGitFile`, `finish`); this task declares `syncDir(dir string) error`, which P3 T16 already says it reuses instead of redeclaring.

// Manifest lists one immutable checkpoint of a run's workspace. Hash covers the
// version and every entry, so two checkpoints of identical content at different
// versions are distinct manifests.
type Manifest struct {
	Version int64           `json:"version"`
	Entries []ManifestEntry `json:"entries"`
	Hash    string          `json:"hash"`
}

// ManifestEntry is one path. Mode carries fs.FileMode type bits (ModeDir,
// ModeSymlink) plus permission bits; regular files carry Size and SHA256,
// symlinks carry their link text. Deleted is used only in diffs.
type ManifestEntry struct {
	Path    string `json:"path"`
	Size    int64  `json:"size"`
	Mode    uint32 `json:"mode"`
	SHA256  string `json:"sha256,omitempty"`
	Symlink string `json:"symlink,omitempty"`
	Deleted bool   `json:"deleted,omitempty"`
}

// CheckpointRef names one immutable checkpoint artifact. The zero value
// (Version 0) means "no checkpoint": an empty workspace.
type CheckpointRef struct {
	RunID        uuid.UUID `json:"runId"`
	Version      int64     `json:"version"`
	ManifestHash string    `json:"manifestHash"`
}

// IsZero reports whether r names no checkpoint.
func (r CheckpointRef) IsZero() bool { return r.Version == 0 }

// String renders "<runID>@<version>:<manifestHash>" ("" for the zero ref).
func (r CheckpointRef) String() string {
	if r.IsZero() {
		return ""
	}
	return fmt.Sprintf("%s@%d:%s", r.RunID, r.Version, r.ManifestHash)
}

// ParseCheckpointRef parses String's output. "" is the zero ref.
func ParseCheckpointRef(s string) (CheckpointRef, error) {
	if s == "" {
		return CheckpointRef{}, nil
	}
	at := strings.IndexByte(s, '@')
	colon := strings.LastIndexByte(s, ':')
	if at <= 0 || colon <= at+1 || colon == len(s)-1 {
		return CheckpointRef{}, fmt.Errorf("runner: malformed checkpoint ref %q", s)
	}
	id, err := uuid.Parse(s[:at])
	if err != nil || id == uuid.Nil {
		return CheckpointRef{}, fmt.Errorf("runner: malformed checkpoint ref %q", s)
	}
	v, err := strconv.ParseInt(s[at+1:colon], 10, 64)
	if err != nil || v < 1 {
		return CheckpointRef{}, fmt.Errorf("runner: malformed checkpoint ref version %q", s)
	}
	hash := s[colon+1:]
	if !validManifestHash(hash) {
		return CheckpointRef{}, fmt.Errorf("runner: malformed checkpoint ref hash %q", s)
	}
	return CheckpointRef{RunID: id, Version: v, ManifestHash: hash}, nil
}

func validManifestHash(h string) bool {
	if len(h) != 64 {
		return false
	}
	for _, c := range h {
		if (c < '0' || c > '9') && (c < 'a' || c > 'f') {
			return false
		}
	}
	return true
}

// CheckpointCandidate is one immutable artifact offered to the catalog. A
// prepared candidate carries the exact job and resource receipts of the
// operation that produced it and the committed base it was built on; it never
// moves the committed pointer (P3 T5/P3 T13/P4 T6 transactions promote it).
type CheckpointCandidate struct {
	Ref, Base   CheckpointRef
	Job         *Fence
	Resource    engine.ResourceFenceRef
	ArchivePath string
	SizeBytes   int64
}

// ValidatePrepared rejects a candidate whose evidence is incomplete. Missing
// job or resource evidence is never a wildcard.
func (c CheckpointCandidate) ValidatePrepared() error {
	if err := c.validateArtifact(); err != nil {
		return err
	}
	if c.Job == nil || c.Job.JobID == uuid.Nil || c.Job.RunnerID == "" || c.Job.Generation < 1 {
		return fmt.Errorf("%w: prepared candidate %s has no exact job fence", ErrInvalidCandidate, c.Ref)
	}
	if err := c.Resource.Validate(); err != nil {
		return fmt.Errorf("%w: prepared candidate %s: %v", ErrInvalidCandidate, c.Ref, err)
	}
	if !c.Base.IsZero() && c.Base.RunID != c.Ref.RunID {
		return fmt.Errorf("%w: candidate %s has a base from another run", ErrInvalidCandidate, c.Ref)
	}
	if c.Ref.Version <= c.Base.Version {
		return fmt.Errorf("%w: candidate %s does not follow base %q", ErrInvalidCandidate, c.Ref, c.Base)
	}
	return nil
}

// ValidateBootstrap rejects a bootstrap candidate that carries operation
// evidence: a baseline is recorded before any job or resource claim exists.
func (c CheckpointCandidate) ValidateBootstrap() error {
	if err := c.validateArtifact(); err != nil {
		return err
	}
	if c.Job != nil || c.Resource != (engine.ResourceFenceRef{}) || !c.Base.IsZero() {
		return fmt.Errorf("%w: bootstrap %s must carry no job, resource or base", ErrInvalidCandidate, c.Ref)
	}
	return nil
}

func (c CheckpointCandidate) validateArtifact() error {
	if c.Ref.RunID == uuid.Nil || c.Ref.Version < 1 || !validManifestHash(c.Ref.ManifestHash) {
		return fmt.Errorf("%w: malformed ref %+v", ErrInvalidCandidate, c.Ref)
	}
	if c.ArchivePath == "" || c.SizeBytes < 0 {
		return fmt.Errorf("%w: candidate %s has no artifact", ErrInvalidCandidate, c.Ref)
	}
	return nil
}

// StagedCheckpoint is a fully built, verified next artifact that is not yet
// registered. Dir is owned by the store; Publish or Discard removes it.
// Resource is assigned by the caller from the durable transfer session
// (P3 T7), never from the uploaded archive.
type StagedCheckpoint struct {
	RunID       uuid.UUID
	Base        CheckpointRef
	Version     int64
	Manifest    Manifest
	Dir         string
	ArchivePath string
	SizeBytes   int64
	Resource    engine.ResourceFenceRef

type DeltaControl struct {
	Deleted  []string        `json:"deleted"`
	Expected []ManifestEntry `json:"expected"`
}

// CheckpointStore keeps immutable checkpoint artifacts. Only Commit (bootstrap)
// records committed progress; every other writer prepares a candidate.
type CheckpointStore interface {
	Commit(ctx context.Context, runID uuid.UUID, srcDir string) (CheckpointRef, Manifest, error) // bootstrap ONLY
	StageBuiltIn(ctx context.Context, runID uuid.UUID, srcDir string, f Fence, resource engine.ResourceFenceRef) (CheckpointRef, Manifest, error)
	StageDelta(ctx context.Context, runID uuid.UUID, base CheckpointRef, delta io.Reader) (StagedCheckpoint, error)
	Publish(ctx context.Context, staged StagedCheckpoint, f Fence) (CheckpointRef, error) // PREPARE only
	// StageResource writes an immutable artifact for a server-side resource
	// mutation (P3 T13 group mutation) and registers nothing; P3 T13
	// ResourceCommitRepo.CommitResource inserts it as committed.
	StageResource(ctx context.Context, runID uuid.UUID, srcDir string, base CheckpointRef) (StagedCheckpoint, error)
	// PreparedFor returns the exact prepared candidate of one job fence and
	// resource claim (P3 T6 FinishSuccess, including after a restart).
	PreparedFor(ctx context.Context, runID uuid.UUID, job Fence, resource engine.ResourceFenceRef) (CheckpointRef, bool, error)
	Restore(ctx context.Context, ref CheckpointRef, dstDir string) error
	Manifest(ctx context.Context, ref CheckpointRef) (Manifest, error)
	Latest(ctx context.Context, runID uuid.UUID) (CheckpointRef, bool, error) // COMMITTED only
	ReadFile(ctx context.Context, ref CheckpointRef, path string) (io.ReadCloser, error)
	Discard(ctx context.Context, staged StagedCheckpoint) error
	Delete(ctx context.Context, runID uuid.UUID) error

	DeleteRun(ctx context.Context, runID uuid.UUID) error

}

// domain/runner/manifest.go
package runner

import (
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"io/fs"
	"path"
	"sort"
	"strings"
)

// CleanRelPath validates a slash-separated workspace-relative path and returns
// it unchanged. Absolute paths, "..", empty/"." paths, redundant separators,
// backslashes and NUL bytes are rejected.
func CleanRelPath(p string) (string, error) {
	if p == "" || strings.HasPrefix(p, "/") || strings.ContainsAny(p, "\\\x00") {
		return "", fmt.Errorf("runner: invalid workspace path %q", p)
	}
	c := path.Clean(p)
	if c != p || c == "." || c == ".." || strings.HasPrefix(c, "../") {
		return "", fmt.Errorf("runner: invalid workspace path %q", p)
	}
	return c, nil
}

// EntryFromInfo maps a Lstat result to a manifest entry. Only directories,
// regular files and symlinks are portable; devices, sockets, named pipes and
// irregular files are rejected explicitly.
func EntryFromInfo(rel string, info fs.FileInfo, sha256Hex, link string) (ManifestEntry, error) {
	m := info.Mode()
	switch {
	case m.IsDir():
		return ManifestEntry{Path: rel, Mode: uint32(fs.ModeDir | m.Perm())}, nil
	case m.IsRegular():
		return ManifestEntry{Path: rel, Size: info.Size(), Mode: uint32(m.Perm()), SHA256: sha256Hex}, nil
	case m&fs.ModeSymlink != 0:
		return ManifestEntry{Path: rel, Mode: uint32(fs.ModeSymlink | 0o777), Symlink: link}, nil
	default:
		return ManifestEntry{}, fmt.Errorf("%w: %s (%s)", ErrUnsupportedFileType, rel, m.Type())
	}
}

func sortedEntries(es []ManifestEntry) []ManifestEntry {
	out := append([]ManifestEntry(nil), es...)
	sort.Slice(out, func(i, j int) bool { return out[i].Path < out[j].Path })
	return out
}

// ManifestHash is the SHA-256 over the version and the sorted entries.
func ManifestHash(version int64, entries []ManifestEntry) string {
	h := sha256.New()
	fmt.Fprintf(h, "arbitron-manifest-v1\nversion %d\n", version)
	for _, e := range sortedEntries(entries) {
		fmt.Fprintf(h, "%q %d %o %s %q %t\n", e.Path, e.Size, e.Mode, e.SHA256, e.Symlink, e.Deleted)
	}
	return hex.EncodeToString(h.Sum(nil))
}

// NewManifest sorts entries and computes the hash.
func NewManifest(version int64, entries []ManifestEntry) Manifest {
	s := sortedEntries(entries)
	return Manifest{Version: version, Entries: s, Hash: ManifestHash(version, s)}
}

// Verify recomputes the hash.
func (m Manifest) Verify() error {
	if got := ManifestHash(m.Version, m.Entries); got != m.Hash {
		return fmt.Errorf("%w: manifest v%d hash %s != recorded %s", ErrCorruptCheckpoint, m.Version, got, m.Hash)
	}
	return nil
}

// TotalBytes sums regular-file sizes (the move-size input for remote homes).
func (m Manifest) TotalBytes() int64 {
	var n int64
	for _, e := range m.Entries {
		n += e.Size
	}
	return n
}

// SameEntry compares two entries ignoring Deleted.
func SameEntry(a, b ManifestEntry) bool {
	return a.Path == b.Path && a.Size == b.Size && a.Mode == b.Mode && a.SHA256 == b.SHA256 && a.Symlink == b.Symlink
}

// SameEntries compares two entry sets regardless of order.
func SameEntries(a, b []ManifestEntry) bool {
	if len(a) != len(b) {
		return false
	}
	sa, sb := sortedEntries(a), sortedEntries(b)
	for i := range sa {
		if !SameEntry(sa[i], sb[i]) {
			return false
		}
	}
	return true
}

// DiffManifests returns the entries of `to` that are absent from or differ in
// `from` (to fetch on pull / to send on push), and the sorted paths of `from`
// absent from `to` (to delete).
func DiffManifests(from, to []ManifestEntry) (changed []ManifestEntry, deleted []string) {
	old := make(map[string]ManifestEntry, len(from))
	for _, e := range from {
		old[e.Path] = e
	}
	seen := make(map[string]bool, len(to))
	for _, e := range sortedEntries(to) {
		seen[e.Path] = true
		if o, ok := old[e.Path]; !ok || !SameEntry(o, e) {
			changed = append(changed, e)
		}
	}
	for _, e := range sortedEntries(from) {
		if !seen[e.Path] {
			deleted = append(deleted, e.Path)
		}
	}
	return changed, deleted
}

	mu        sync.Mutex
	rows      map[uuid.UUID]map[int64]*memRow
	pointer   map[uuid.UUID]int64
	jobs      map[runner.Fence]bool
	resources map[engine.ResourceFenceRef]bool
	onPublish func(c runner.CheckpointCandidate)
}

func newMemCatalog() *memCatalog {
	return &memCatalog{rows: map[uuid.UUID]map[int64]*memRow{}, pointer: map[uuid.UUID]int64{},
		jobs: map[runner.Fence]bool{}, resources: map[engine.ResourceFenceRef]bool{}}
}

// activate makes a job fence and a resource claim current, as the ledger and
// the P3 T3 lease would.
func (c *memCatalog) activate(f runner.Fence, r engine.ResourceFenceRef) {
	c.mu.Lock()
	defer c.mu.Unlock()
	c.jobs[f], c.resources[r] = true, true
}

func (c *memCatalog) deactivate(f runner.Fence, r engine.ResourceFenceRef) {
	c.mu.Lock()
	defer c.mu.Unlock()
	delete(c.jobs, f)
	delete(c.resources, r)
}

func (c *memCatalog) Publish(_ context.Context, cand runner.CheckpointCandidate) error {
	if err := cand.ValidatePrepared(); err != nil {
		return err
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.onPublish != nil {
		c.onPublish(cand)
	}
	if !c.jobs[*cand.Job] {
		return fmt.Errorf("%w: job %s gen %d", runner.ErrFenced, cand.Job.JobID, cand.Job.Generation)
	}
	if !c.resources[cand.Resource] {
		return errStaleResource
	}
	if cur := c.committedLocked(cand.Ref.RunID); cur != cand.Base {
		return fmt.Errorf("%w: base %q is not committed %q", runner.ErrCheckpointConflict, cand.Base, cur)
	}
	runRows := c.rows[cand.Ref.RunID]
	if runRows == nil {
		runRows = map[int64]*memRow{}
		c.rows[cand.Ref.RunID] = runRows
	}
	if have, ok := runRows[cand.Ref.Version]; ok {
		if have.state == "prepared" && sameCandidate(have.c, cand) {
			return nil
		}
		return fmt.Errorf("%w: v%d exists", runner.ErrCheckpointConflict, cand.Ref.Version)
	}
	runRows[cand.Ref.Version] = &memRow{c: cand, state: "prepared"}
	return nil
}

func sameCandidate(a, b runner.CheckpointCandidate) bool {
	return a.Ref == b.Ref && a.Base == b.Base && *a.Job == *b.Job && a.Resource == b.Resource &&
		a.ArchivePath == b.ArchivePath && a.SizeBytes == b.SizeBytes
}

func (c *memCatalog) Bootstrap(_ context.Context, cand runner.CheckpointCandidate) error {
	if err := cand.ValidateBootstrap(); err != nil {
		return err
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.pointer[cand.Ref.RunID] != 0 {
		return fmt.Errorf("%w: run already has committed progress", runner.ErrCheckpointConflict)
	}
	for r := range c.resources {
		if r.Key == "run:"+cand.Ref.RunID.String() {
			return fmt.Errorf("%w: an active writer holds the run", runner.ErrCheckpointConflict)
		}
	}
	runRows := c.rows[cand.Ref.RunID]
	if runRows == nil {
		runRows = map[int64]*memRow{}
		c.rows[cand.Ref.RunID] = runRows
	}
	if _, ok := runRows[cand.Ref.Version]; ok {
		return fmt.Errorf("%w: v%d exists", runner.ErrCheckpointConflict, cand.Ref.Version)
	}
	runRows[cand.Ref.Version] = &memRow{c: cand, state: "committed"}
	c.pointer[cand.Ref.RunID] = cand.Ref.Version
	return nil
}

// commit is the test's validated publisher (the P3 T5 transaction's
// promotion): only an exact prepared candidate on the committed base moves
// the pointer.
func (c *memCatalog) commit(ref runner.CheckpointRef) error {
	c.mu.Lock()
	defer c.mu.Unlock()
	row, ok := c.rows[ref.RunID][ref.Version]
	if !ok || row.state != "prepared" || row.c.Ref != ref {
		return fmt.Errorf("%w: no prepared candidate %s", runner.ErrCheckpointNotFound, ref)
	}
	if c.committedLocked(ref.RunID) != row.c.Base {
		return runner.ErrCheckpointConflict
	}
	row.state = "committed"
	c.pointer[ref.RunID] = ref.Version
	return nil
}

func (c *memCatalog) committedLocked(run uuid.UUID) runner.CheckpointRef {
	v := c.pointer[run]
	if v == 0 {
		return runner.CheckpointRef{}
	}
	return c.rows[run][v].c.Ref
}

func (c *memCatalog) prepared(run uuid.UUID) []runner.CheckpointRef {
	c.mu.Lock()
	defer c.mu.Unlock()
	var out []runner.CheckpointRef
	for _, r := range c.rows[run] {
		if r.state == "prepared" {
			out = append(out, r.c.Ref)
		}
	}
	return out
}

func (c *memCatalog) Latest(_ context.Context, run uuid.UUID) (runner.CheckpointRef, string, bool, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	v := c.pointer[run]
	if v == 0 {
		return runner.CheckpointRef{}, "", false, nil
	}
	row := c.rows[run][v]
	return row.c.Ref, row.c.ArchivePath, true, nil
}

func (c *memCatalog) Get(_ context.Context, run uuid.UUID, v int64) (runner.CheckpointRef, string, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	row, ok := c.rows[run][v]
	if !ok || row.state != "committed" {
		return runner.CheckpointRef{}, "", fmt.Errorf("%w: %s v%d", runner.ErrCheckpointNotFound, run, v)
	}
	return row.c.Ref, row.c.ArchivePath, nil
}

func (c *memCatalog) DeleteRun(_ context.Context, run uuid.UUID) error {
	c.mu.Lock()
	defer c.mu.Unlock()
	delete(c.rows, run)
	delete(c.pointer, run)
	return nil
}

func (c *memCatalog) PreparedFor(_ context.Context, run uuid.UUID, job runner.Fence, res engine.ResourceFenceRef) (runner.CheckpointRef, bool, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	var found []runner.CheckpointRef
	for _, r := range c.rows[run] {
		if r.state == "prepared" && r.c.Job != nil && *r.c.Job == job && r.c.Resource == res {
			found = append(found, r.c.Ref)
		}
	}
	switch len(found) {
	case 0:
		return runner.CheckpointRef{}, false, nil
	case 1:
		return found[0], true, nil
	default:
		return runner.CheckpointRef{}, false, fmt.Errorf("%w: %d prepared candidates", runner.ErrCheckpointConflict, len(found))
	}
}

// commitResource is the test's stand-in for P3 T13 ResourceCommitRepo: it
// inserts a staged server-side artifact directly as committed on its base.
func (c *memCatalog) commitResource(staged runner.StagedCheckpoint) (runner.CheckpointRef, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.committedLocked(staged.RunID) != staged.Base {
		return runner.CheckpointRef{}, runner.ErrCheckpointConflict
	}
	ref := runner.CheckpointRef{RunID: staged.RunID, Version: staged.Version, ManifestHash: staged.Manifest.Hash}
	if c.rows[staged.RunID] == nil {
		c.rows[staged.RunID] = map[int64]*memRow{}
	}
	c.rows[staged.RunID][ref.Version] = &memRow{c: runner.CheckpointCandidate{Ref: ref, Base: staged.Base, ArchivePath: staged.ArchivePath, SizeBytes: staged.SizeBytes}, state: "committed"}
	c.pointer[staged.RunID] = ref.Version
	return ref, nil
}

func ckWrite(t *testing.T, root, rel, body string, perm os.FileMode) {
	t.Helper()
	p := filepath.Join(root, filepath.FromSlash(rel))
	require.NoError(t, os.MkdirAll(filepath.Dir(p), 0o755))
	require.NoError(t, os.WriteFile(p, []byte(body), perm))
	require.NoError(t, os.Chmod(p, perm))
}

// ckTree renders a directory as sorted "path mode [content|->link]" lines.
func ckTree(t *testing.T, root string) []string {
	t.Helper()
	var out []string
	require.NoError(t, filepath.Walk(root, func(p string, info os.FileInfo, err error) error {
		require.NoError(t, err)
		if p == root {
			return nil
		}
		rel, _ := filepath.Rel(root, p)
		rel = filepath.ToSlash(rel)
		switch {
		case info.Mode()&os.ModeSymlink != 0:
			l, _ := os.Readlink(p)
			out = append(out, rel+" link ->"+l)
		case info.IsDir():
			out = append(out, fmt.Sprintf("%s dir %o", rel, info.Mode().Perm()))
		default:
			b, _ := os.ReadFile(p)
			out = append(out, fmt.Sprintf("%s %o %s", rel, info.Mode().Perm(), b))
		}
		return nil
	}))
	sort.Strings(out)
	return out
}

// enospcWriter simulates a full disk after `left` bytes.
type enospcWriter struct {
	f    *os.File
	left int
}

func (w *enospcWriter) Write(p []byte) (int, error) {
	if len(p) > w.left {
		n, _ := w.f.Write(p[:w.left])
		w.left = 0
		return n, syscall.ENOSPC
	}
	n, err := w.f.Write(p)
	w.left -= n
	return n, err
}
func (w *enospcWriter) Close() error { return w.f.Close() }

// adapter/checkpoint/store.go

// Package checkpoint stores immutable, versioned workspace checkpoint
// artifacts as tar+gzip archives with verified manifests (remote runners
// Phase 3). Artifacts are registered with a runner.CheckpointCatalog: only
// Commit (bootstrap) records committed progress; every other writer prepares a
// candidate that a validated transaction later promotes.
package checkpoint

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"sync"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"

// Limits bound what an archive may expand to.
type Limits struct {
	MaxEntries   int
	MaxBytes     int64
	MaxPathBytes int
}

// DefaultLimits are the production bounds.
var DefaultLimits = Limits{MaxEntries: 1 << 20, MaxBytes: 64 << 30, MaxPathBytes: 4096}

// Store lays artifacts out as
//
//	<dir>/runs/<run>/v<NNNNNNNNNN>.reserved        version reservation (O_EXCL)
//	<dir>/runs/<run>/v<NNNNNNNNNN>.tar.gz          immutable archive
//	<dir>/runs/<run>/v<NNNNNNNNNN>.manifest.json   its manifest
//	<dir>/cache/<run>/v<NNNNNNNNNN>/               verified read cache (ReadFile)
//	<dir>/staging/op-*/                            StageDelta output
//	<dir>/tmp/op-*/                                Commit/StageBuiltIn scratch
//
// Immutable artifacts never share a directory with mutable execution roots or
// staging. Nothing here deletes an artifact except Delete (workspace removal).
type Store struct {
	dir      string
	catalog  runner.CheckpointCatalog
	create   func(path string, perm os.FileMode) (io.WriteCloser, error)
	limits   Limits
	cacheMu  sync.Mutex
	runMu    sync.Mutex
	runLocks map[uuid.UUID]*sync.Mutex
}

// Option configures a Store.
type Option func(*Store)

// WithCatalog sets the durable catalog. Without it every operation that reads
// or records checkpoints fails with runner.ErrNoCheckpointCatalog.
func WithCatalog(c runner.CheckpointCatalog) Option { return func(s *Store) { s.catalog = c } }

// WithFileCreator replaces the exclusive-create used for archives and
// manifests (fault injection). A returned writer with Sync() is fsynced
// before it is closed.
func WithFileCreator(fn func(path string, perm os.FileMode) (io.WriteCloser, error)) Option {
	return func(s *Store) { s.create = fn }
}

// WithLimits replaces DefaultLimits.
func WithLimits(l Limits) Option { return func(s *Store) { s.limits = l } }

// NewStore returns a store rooted at dir. Production wiring MUST pass
// WithCatalog(sqlite.NewCheckpointCatalogRepo(db)).
func NewStore(dir string, opts ...Option) *Store {
	abs, err := filepath.Abs(dir)
	if err != nil {
		abs = filepath.Clean(dir)
	}
	s := &Store{dir: abs, create: createExclusive, limits: DefaultLimits, runLocks: map[uuid.UUID]*sync.Mutex{}}
	for _, o := range opts {
		o(s)
	}
	return s
}

func createExclusive(path string, perm os.FileMode) (io.WriteCloser, error) {
	return os.OpenFile(path, os.O_CREATE|os.O_EXCL|os.O_WRONLY, perm)
}

func (s *Store) lockRun(id uuid.UUID) func() {
	s.runMu.Lock()
	m, ok := s.runLocks[id]
	if !ok {
		m = &sync.Mutex{}
		s.runLocks[id] = m
	}
	s.runMu.Unlock()
	m.Lock()
	return m.Unlock
}

func (s *Store) runDir(id uuid.UUID) string { return filepath.Join(s.dir, "runs", id.String()) }
func (s *Store) versionBase(id uuid.UUID, v int64) string {
	return filepath.Join(s.runDir(id), fmt.Sprintf("v%010d", v))
}
func (s *Store) archivePath(id uuid.UUID, v int64) string { return s.versionBase(id, v) + ".tar.gz" }
func (s *Store) manifestPath(id uuid.UUID, v int64) string {
	return s.versionBase(id, v) + ".manifest.json"
}

func (s *Store) scratch(kind string) (string, error) {
	base := filepath.Join(s.dir, kind)
	if err := os.MkdirAll(base, 0o700); err != nil {
		return "", fmt.Errorf("checkpoint: %s dir: %w", kind, err)
	}
	return os.MkdirTemp(base, "op-")
}

// refuseStorePath rejects a workspace path inside (or containing) the store,
// so execution roots and immutable artifacts never alias.
func (s *Store) refuseStorePath(p string) error {
	abs, err := filepath.Abs(p)
	if err != nil {
		return err
	}
	if within(s.dir, abs) || within(abs, s.dir) {
		return fmt.Errorf("checkpoint: workspace %s overlaps the checkpoint store", p)
	}
	return nil
}

// reserve allocates the next unused version for runID by exclusively creating
// its reservation marker. Versions are never reused; abandoned ones are gaps.
func (s *Store) reserve(ctx context.Context, runID uuid.UUID) (int64, error) {
	unlock := s.lockRun(runID)
	defer unlock()
	dir := s.runDir(runID)
	if err := os.MkdirAll(dir, 0o700); err != nil {
		return 0, fmt.Errorf("checkpoint: run dir: %w", err)
	}
	next := int64(1)
	if latest, _, ok, err := s.catalog.Latest(ctx, runID); err != nil {
		return 0, fmt.Errorf("checkpoint: latest: %w", err)
	} else if ok {
		next = latest.Version + 1
	}
	es, err := os.ReadDir(dir)
	if err != nil {
		return 0, err
	}
	for _, e := range es {
		var v int64
		if _, err := fmt.Sscanf(e.Name(), "v%010d", &v); err == nil && v >= next {
			next = v + 1
		}
	}
	for ; ; next++ {
		f, err := os.OpenFile(s.versionBase(runID, next)+".reserved", os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)
		if errors.Is(err, fs.ErrExist) {
			continue
		}
		if err != nil {
			return 0, fmt.Errorf("checkpoint: reserve v%d: %w", next, err)
		}
		if err := f.Close(); err != nil {
			return 0, err
		}
		return next, nil
	}
}

type artifact struct {
	ref      runner.CheckpointRef
	manifest runner.Manifest
	archive  string
	size     int64
}

// build snapshots srcDir into an immutable,
// fsynced artifact at a freshly reserved version. Nothing is registered.
func (s *Store) build(ctx context.Context, runID uuid.UUID, srcDir string, portableGit bool) (artifact, error) {
	if err := s.refuseStorePath(srcDir); err != nil {
		return artifact{}, err
	}
	tmp, err := s.scratch("tmp")
	if err != nil {
		return artifact{}, err
	}
	defer forceRemoveAll(tmp)
	items, err := s.collect(ctx, srcDir, portableGit, tmp)
	if err != nil {
		return artifact{}, err
	}
	archive := filepath.Join(tmp, "archive.tar.gz")
	entries, size, err := s.writeArchiveFile(archive, items)
	if err != nil {
		return artifact{}, fmt.Errorf("checkpoint: write archive: %w", err)
	}
	version, err := s.reserve(ctx, runID)
	if err != nil {
		return artifact{}, err
	}
	m := runner.NewManifest(version, entries)
	if err := s.install(runID, m, archive); err != nil {
		return artifact{}, err
	}
	return artifact{
		ref:      runner.CheckpointRef{RunID: runID, Version: version, ManifestHash: m.Hash},
		manifest: m, archive: s.archivePath(runID, version), size: size,
	}, nil
}

// install writes the manifest next to an already fsynced archive, hard-links
// both to their immutable names and fsyncs the run directory.
func (s *Store) install(runID uuid.UUID, m runner.Manifest, archive string) error {
	mtmp := archive + ".manifest.json"
	if err := s.writeJSON(mtmp, m); err != nil {
		return fmt.Errorf("checkpoint: write manifest: %w", err)
	}
	if err := os.Link(archive, s.archivePath(runID, m.Version)); err != nil {
		return fmt.Errorf("checkpoint: link archive: %w", err)
	}
	if err := os.Link(mtmp, s.manifestPath(runID, m.Version)); err != nil {
		return fmt.Errorf("checkpoint: link manifest: %w", err)
	}
	return syncDir(s.runDir(runID))
}

func (s *Store) writeJSON(path string, v any) error {
	b, err := json.Marshal(v)
	if err != nil {
		return err
	}
	w, err := s.create(path, 0o600)
	if err != nil {
		return err
	}
	_, werr := w.Write(b)
	return finish(w, werr)
}

// finish fsyncs (when supported) and closes w, reporting the first error.
func finish(w io.WriteCloser, werr error) error {
	if werr == nil {
		if sy, ok := w.(interface{ Sync() error }); ok {
			werr = sy.Sync()
		}
	}
	cerr := w.Close()
	if werr != nil {
		return werr
	}
	return cerr
}

func syncDir(dir string) error {
	d, err := os.Open(dir)
	if err != nil {
		return err
	}
	defer d.Close()
	if err := d.Sync(); err != nil {
		return fmt.Errorf("checkpoint: fsync %s: %w", dir, err)
	}
	return nil
}

// Commit is BOOTSTRAP ONLY (P3 T6 EnsureBaseline before any dispatch): it
// records srcDir as the run's first committed baseline. The catalog rejects it
// when committed progress or an active writer exists.
func (s *Store) Commit(ctx context.Context, runID uuid.UUID, srcDir string) (runner.CheckpointRef, runner.Manifest, error) {
	if s.catalog == nil {
		return runner.CheckpointRef{}, runner.Manifest{}, runner.ErrNoCheckpointCatalog
	}
	art, err := s.build(ctx, runID, srcDir, true)
	if err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	c := runner.CheckpointCandidate{Ref: art.ref, ArchivePath: art.archive, SizeBytes: art.size}
	if err := c.ValidateBootstrap(); err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	if err := s.catalog.Bootstrap(ctx, c); err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	return art.ref, art.manifest, nil
}

// StageBuiltIn prepares srcDir as a candidate under the exact job and resource
// fences, based on the run's committed checkpoint. It never moves Latest.
func (s *Store) StageBuiltIn(ctx context.Context, runID uuid.UUID, srcDir string, f runner.Fence, resource engine.ResourceFenceRef) (runner.CheckpointRef, runner.Manifest, error) {
	if s.catalog == nil {
		return runner.CheckpointRef{}, runner.Manifest{}, runner.ErrNoCheckpointCatalog
	}
	if f.JobID == uuid.Nil || f.RunnerID == "" || f.Generation < 1 {
		return runner.CheckpointRef{}, runner.Manifest{}, fmt.Errorf("%w: built-in staging needs an exact job fence", runner.ErrInvalidCandidate)
	}
	if err := resource.Validate(); err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, fmt.Errorf("%w: %v", runner.ErrInvalidCandidate, err)
	}
	base, _, _, err := s.catalog.Latest(ctx, runID)
	if err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, fmt.Errorf("checkpoint: latest: %w", err)
	}
	art, err := s.build(ctx, runID, srcDir, true)
	if err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	job := f
	c := runner.CheckpointCandidate{Ref: art.ref, Base: base, Job: &job, Resource: resource, ArchivePath: art.archive, SizeBytes: art.size}
	if err := c.ValidatePrepared(); err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	if err := s.catalog.Publish(ctx, c); err != nil {
		return runner.CheckpointRef{}, runner.Manifest{}, err
	}
	return art.ref, art.manifest, nil
}

// Latest returns the run's COMMITTED checkpoint (the catalog's pointer).
func (s *Store) Latest(ctx context.Context, runID uuid.UUID) (runner.CheckpointRef, bool, error) {
	if s.catalog == nil {
		return runner.CheckpointRef{}, false, runner.ErrNoCheckpointCatalog
	}
	ref, _, ok, err := s.catalog.Latest(ctx, runID)
	if err != nil {
		return runner.CheckpointRef{}, false, fmt.Errorf("checkpoint: latest: %w", err)
	}
	return ref, ok, nil
}

// Manifest returns a committed checkpoint's verified manifest. The zero ref is
// the empty manifest.
func (s *Store) Manifest(ctx context.Context, ref runner.CheckpointRef) (runner.Manifest, error) {
	if ref.IsZero() {
		return runner.Manifest{}, nil
	}
	_, m, err := s.resolve(ctx, ref)
	return m, err
}

func (s *Store) readManifest(ref runner.CheckpointRef) (runner.Manifest, error) {
	b, err := os.ReadFile(s.manifestPath(ref.RunID, ref.Version))
	if errors.Is(err, fs.ErrNotExist) {
		return runner.Manifest{}, fmt.Errorf("%w: manifest for %s", runner.ErrCheckpointNotFound, ref)
	}
	if err != nil {
		return runner.Manifest{}, fmt.Errorf("checkpoint: read manifest: %w", err)
	}
	var m runner.Manifest
	if err := json.Unmarshal(b, &m); err != nil {
		return runner.Manifest{}, fmt.Errorf("%w: %s: %v", runner.ErrCorruptCheckpoint, ref, err)
	}
	if m.Version != ref.Version || m.Hash != ref.ManifestHash {
		return runner.Manifest{}, fmt.Errorf("%w: manifest differs from ref %s", runner.ErrCorruptCheckpoint, ref)
	}
	if err := m.Verify(); err != nil {
		return runner.Manifest{}, err
	}
	return m, nil
}

// resolve maps a COMMITTED ref to its archive and verified manifest. Prepared
// candidates are not served (catalog Get returns committed rows only).
func (s *Store) resolve(ctx context.Context, ref runner.CheckpointRef) (string, runner.Manifest, error) {
	if s.catalog == nil {
		return "", runner.Manifest{}, runner.ErrNoCheckpointCatalog
	}
	got, path, err := s.catalog.Get(ctx, ref.RunID, ref.Version)
	if err != nil {
		return "", runner.Manifest{}, err
	}
	if got.ManifestHash != ref.ManifestHash {
		return "", runner.Manifest{}, fmt.Errorf("%w: catalog hash differs for %s", runner.ErrCorruptCheckpoint, ref)
	}
	if path != s.archivePath(ref.RunID, ref.Version) {
		return "", runner.Manifest{}, fmt.Errorf("%w: catalog path %q is not this store's artifact", runner.ErrCorruptCheckpoint, path)
	}
	m, err := s.readManifest(ref)
	if err != nil {
		return "", runner.Manifest{}, err
	}
	if _, err := os.Stat(path); err != nil {
		return "", runner.Manifest{}, fmt.Errorf("%w: archive for %s: %v", runner.ErrCheckpointNotFound, ref, err)
	}
	return path, m, nil
}

// Restore extracts a committed checkpoint into a private sibling staging tree,
// verifies it against its manifest and only then replaces dstDir's contents.
// A failed or partial extraction leaves dstDir untouched. The zero ref
// restores an empty workspace.
func (s *Store) Restore(ctx context.Context, ref runner.CheckpointRef, dstDir string) error {
	if err := s.refuseStorePath(dstDir); err != nil {
		return err
	}
	if err := os.MkdirAll(dstDir, 0o755); err != nil {
		return fmt.Errorf("checkpoint: restore dir: %w", err)
	}
	if ref.IsZero() {
		return wipeDir(dstDir)
	}
	path, m, err := s.resolve(ctx, ref)
	if err != nil {
		return err
	}
	clean := filepath.Clean(dstDir)
	tmp, err := os.MkdirTemp(filepath.Dir(clean), "."+filepath.Base(clean)+".restore-")
	if err != nil {
		return fmt.Errorf("checkpoint: restore staging: %w", err)
	}
	defer forceRemoveAll(tmp)
	if err := extractVerified(path, tmp, m, s.limits); err != nil {
		return err
	}
	if err := wipeDir(clean); err != nil {
		return fmt.Errorf("checkpoint: clear %s: %w", clean, err)
	}
	es, err := os.ReadDir(tmp)
	if err != nil {
		return err
	}
	for _, e := range es {
		if err := os.Rename(filepath.Join(tmp, e.Name()), filepath.Join(clean, e.Name())); err != nil {
			return fmt.Errorf("checkpoint: install %s: %w", e.Name(), err)
		}
	}
	return nil
}

// Delete removes every artifact and catalog row of a run (workspace removal,
// P3 T11 CheckpointDeleter).
func (s *Store) Delete(ctx context.Context, runID uuid.UUID) error {
	if s.catalog == nil {
		return runner.ErrNoCheckpointCatalog
	}
	unlock := s.lockRun(runID)
	defer unlock()
	if err := s.catalog.DeleteRun(ctx, runID); err != nil {
		return fmt.Errorf("checkpoint: delete catalog rows: %w", err)
	}
	forceRemoveAll(s.runDir(runID))
	forceRemoveAll(filepath.Join(s.dir, "cache", runID.String()))
	return nil
}

func wipeDir(dir string) error {
	es, err := os.ReadDir(dir)
	if err != nil {
		return err
	}
	for _, e := range es {
		p := filepath.Join(dir, e.Name())
		forceRemoveAll(p)
		if _, err := os.Lstat(p); err == nil {
			return fmt.Errorf("checkpoint: could not remove %s", p)
		}
	}
	return nil
}

// forceRemoveAll makes directories writable first so read-only trees (git
// objects, 0555 dirs) can be removed. It never follows symlinks.
func forceRemoveAll(p string) {
	_ = filepath.WalkDir(p, func(q string, d fs.DirEntry, err error) error {
		if err == nil && d.IsDir() {
			_ = os.Chmod(q, 0o700)
		}
		return nil
	})
	_ = os.RemoveAll(p)
}

const maxDeltaControlBytes = 64 << 20

type countingWriter struct {
	w io.Writer
	n int64
}

func (c *countingWriter) Write(p []byte) (int, error) {
	n, err := c.w.Write(p)
	c.n += int64(n)
	return n, err
}

// writeArchiveFile writes items to a new file through the store's creator and
// fsyncs it before close.
func (s *Store) writeArchiveFile(path string, items []item) ([]runner.ManifestEntry, int64, error) {
	w, err := s.create(path, 0o600)
	if err != nil {
		return nil, 0, err
	}
	cw := &countingWriter{w: w}
	entries, werr := writeArchive(cw, items)
	if err := finish(w, werr); err != nil {
		return nil, 0, err
	}
	return entries, cw.n, nil
}

func writeArchive(w io.Writer, items []item) ([]runner.ManifestEntry, error) {
	gz := gzip.NewWriter(w)
	tw := tar.NewWriter(gz)
	entries := make([]runner.ManifestEntry, 0, len(items))
	for _, it := range items {
		e, err := writeItem(tw, it)
		if err != nil {
			return nil, err
		}
		entries = append(entries, e)
	}
	if err := tw.Close(); err != nil {
		return nil, err
	}
	if err := gz.Close(); err != nil {
		return nil, err
	}
	return entries, nil
}

func writeItem(tw *tar.Writer, it item) (runner.ManifestEntry, error) {
	m := it.info.Mode()
	hdr := &tar.Header{Name: it.rel, ModTime: it.info.ModTime(), Format: tar.FormatPAX}
	switch {
	case m.IsDir():
		hdr.Typeflag, hdr.Name, hdr.Mode = tar.TypeDir, it.rel+"/", int64(m.Perm())
	case m.IsRegular():
		hdr.Typeflag, hdr.Mode, hdr.Size = tar.TypeReg, int64(m.Perm()), it.info.Size()
	case m&fs.ModeSymlink != 0:
		hdr.Typeflag, hdr.Linkname, hdr.Mode = tar.TypeSymlink, it.link, 0o777
	default:
		return runner.ManifestEntry{}, fmt.Errorf("%w: %s (%s)", runner.ErrUnsupportedFileType, it.rel, m.Type())
	}
	if err := tw.WriteHeader(hdr); err != nil {
		return runner.ManifestEntry{}, err
	}
	sum := ""
	if m.IsRegular() {
		f, err := os.Open(it.abs)
		if err != nil {
			return runner.ManifestEntry{}, err
		}
		h := sha256.New()
		n, err := io.Copy(io.MultiWriter(tw, h), f)
		f.Close()
		if err != nil {
			return runner.ManifestEntry{}, fmt.Errorf("checkpoint: archive %s: %w", it.rel, err)
		}
		if n != hdr.Size {
			return runner.ManifestEntry{}, fmt.Errorf("checkpoint: %s changed while archiving", it.rel)
		}
		sum = hex.EncodeToString(h.Sum(nil))
	}
	return runner.EntryFromInfo(it.rel, it.info, sum, it.link)
}

// budget enforces Limits across one extraction.
type budget struct {
	l       Limits
	entries int
	bytes   int64
}

func (b *budget) admit(name string, size int64) error {
	b.entries++
	b.bytes += size
	switch {
	case len(name) > b.l.MaxPathBytes:
		return fmt.Errorf("%w: path longer than %d bytes", runner.ErrCorruptCheckpoint, b.l.MaxPathBytes)
	case b.entries > b.l.MaxEntries:
		return fmt.Errorf("%w: more than %d entries", runner.ErrCorruptCheckpoint, b.l.MaxEntries)
	case size < 0 || b.bytes > b.l.MaxBytes:
		return fmt.Errorf("%w: expands beyond %d bytes", runner.ErrCorruptCheckpoint, b.l.MaxBytes)
	}
	return nil
}

// openGzip reads exactly one gzip member and reports trailing data.
func openGzip(r io.Reader) (*gzip.Reader, *bufio.Reader, error) {
	br := bufio.NewReader(r)
	gz, err := gzip.NewReader(br)
	if err != nil {
		return nil, nil, fmt.Errorf("%w: gzip: %v", runner.ErrCorruptCheckpoint, err)
	}
	gz.Multistream(false)
	return gz, br, nil
}

// endOfArchive accepts only zero padding after the tar end and nothing after
// the gzip member.
func endOfArchive(gz *gzip.Reader, br *bufio.Reader) error {
	rest, err := io.ReadAll(io.LimitReader(gz, 1<<20))
	if err != nil {
		return fmt.Errorf("%w: archive tail: %v", runner.ErrCorruptCheckpoint, err)
	}
	for _, c := range rest {
		if c != 0 {
			return fmt.Errorf("%w: unexpected data after archive end", runner.ErrCorruptCheckpoint)
		}
	}
	if _, err := br.Peek(1); !errors.Is(err, io.EOF) {
		return fmt.Errorf("%w: unexpected trailing part after archive", runner.ErrCorruptCheckpoint)
	}
	return nil
}

// extractVerified extracts an archive into dst and checks it reproduces m
// exactly (truncated, tampered or extra entries fail with ErrCorruptCheckpoint).
func extractVerified(archive, dst string, m runner.Manifest, l Limits) error {
	root, err := os.OpenRoot(dst)
	if err != nil {
		return err
	}
	defer root.Close()
	modes, err := extractInto(archive, root, m, l)
	if err != nil {
		return err
	}
	return applyDirModes(root, modes)
}

func extractInto(archive string, root *os.Root, m runner.Manifest, l Limits) (map[string]fs.FileMode, error) {
	f, err := os.Open(archive)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	gz, br, err := openGzip(f)
	if err != nil {
		return nil, err
	}
	defer gz.Close()
	modes := map[string]fs.FileMode{}
	seen, err := applyTar(tar.NewReader(gz), root, false, modes, &budget{l: l})
	if err != nil {
		return nil, err
	}
	if err := endOfArchive(gz, br); err != nil {
		return nil, err
	}
	if len(seen) != len(m.Entries) {
		return nil, fmt.Errorf("%w: archive has %d entries, manifest %d", runner.ErrCorruptCheckpoint, len(seen), len(m.Entries))
	}
	for _, e := range m.Entries {
		got, ok := seen[e.Path]
		if !ok || !runner.SameEntry(got, e) {
			return nil, fmt.Errorf("%w: %s", runner.ErrCorruptCheckpoint, e.Path)
		}
	}
	return modes, nil
}

// noSymlinkAncestor refuses to write beneath a symlink, even one that stays
// inside root (classic tar symlink-then-child attack).
func noSymlinkAncestor(root *os.Root, name string) error {
	parts := strings.Split(name, "/")
	for i := 1; i < len(parts); i++ {
		p := strings.Join(parts[:i], "/")
		fi, err := root.Lstat(p)
		if errors.Is(err, fs.ErrNotExist) {
			return nil
		}
		if err != nil {
			return err
		}
		if fi.Mode()&fs.ModeSymlink != 0 {
			return fmt.Errorf("%w: %s lies beneath symlink %s", runner.ErrCorruptCheckpoint, name, p)
		}
	}
	return nil
}

// applyTar writes entries under root (os.Root refuses escapes). Directories are
// created 0700 and their recorded modes collected for applyDirModes, so
// read-only directories never block their children.
func applyTar(tr *tar.Reader, root *os.Root, overwrite bool, modes map[string]fs.FileMode, b *budget) (map[string]runner.ManifestEntry, error) {
	seen := map[string]runner.ManifestEntry{}
	for {
		hdr, err := tr.Next()
		if errors.Is(err, io.EOF) {
			return seen, nil
		}
		if err != nil {
			return nil, fmt.Errorf("%w: read archive: %v", runner.ErrCorruptCheckpoint, err)
		}
		name, err := runner.CleanRelPath(strings.TrimSuffix(hdr.Name, "/"))
		if err != nil {
			return nil, err
		}
		if _, dup := seen[name]; dup {
			return nil, fmt.Errorf("%w: duplicate archive entry %s", runner.ErrCorruptCheckpoint, name)
		}
		if err := b.admit(name, hdr.Size); err != nil {
			return nil, err
		}
		if err := noSymlinkAncestor(root, name); err != nil {
			return nil, err
		}
		if overwrite {
			if err := removeExisting(root, name, hdr.Typeflag == tar.TypeDir); err != nil {
				return nil, err
			}
		}
		if dir := path.Dir(name); dir != "." {
			if err := root.MkdirAll(dir, 0o700); err != nil {
				return nil, fmt.Errorf("checkpoint: mkdir %s: %w", dir, err)
			}
		}
		perm := fs.FileMode(hdr.Mode).Perm()
		switch hdr.Typeflag {
		case tar.TypeDir:
			if err := root.MkdirAll(name, 0o700); err != nil {
				return nil, fmt.Errorf("checkpoint: mkdir %s: %w", name, err)
			}
			modes[name] = perm
			seen[name] = runner.ManifestEntry{Path: name, Mode: uint32(fs.ModeDir | perm)}
		case tar.TypeReg:
			f, err := root.OpenFile(name, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)
			if err != nil {
				return nil, fmt.Errorf("checkpoint: create %s: %w", name, err)
			}
			h := sha256.New()
			n, cpErr := io.Copy(io.MultiWriter(f, h), tr)
			clErr := f.Close()
			if cpErr != nil {
				return nil, fmt.Errorf("checkpoint: write %s: %w", name, cpErr)
			}
			if clErr != nil {
				return nil, fmt.Errorf("checkpoint: close %s: %w", name, clErr)
			}
			if err := root.Chmod(name, perm); err != nil {
				return nil, err
			}
			seen[name] = runner.ManifestEntry{Path: name, Size: n, Mode: uint32(perm), SHA256: hex.EncodeToString(h.Sum(nil))}
		case tar.TypeSymlink:
			if err := root.Symlink(hdr.Linkname, name); err != nil {
				return nil, fmt.Errorf("checkpoint: symlink %s: %w", name, err)
			}
			seen[name] = runner.ManifestEntry{Path: name, Mode: uint32(fs.ModeSymlink | 0o777), Symlink: hdr.Linkname}
		default:
			return nil, fmt.Errorf("%w: archive entry %s has type %q", runner.ErrUnsupportedFileType, name, hdr.Typeflag)
		}
	}
}

func removeExisting(root *os.Root, name string, wantDir bool) error {
	fi, err := root.Lstat(name)
	if errors.Is(err, fs.ErrNotExist) {
		return nil
	}
	if err != nil {
		return err
	}
	if wantDir && fi.IsDir() {
		return nil
	}
	return root.RemoveAll(name)
}

func applyDirModes(root *os.Root, modes map[string]fs.FileMode) error {
	names := make([]string, 0, len(modes))
	for n := range modes {
		names = append(names, n)
	}
	sort.Sort(sort.Reverse(sort.StringSlice(names))) // children before parents
	for _, n := range names {
		if err := root.Chmod(n, modes[n]); err != nil {
			return fmt.Errorf("checkpoint: chmod %s: %w", n, err)
		}
	}
	return nil
}

// adapter/checkpoint/walk.go
package checkpoint

import (
	"context"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"sort"
	"strings"

	"github.com/arbitron/arbitron/domain/runner"
)

type item struct {
	rel  string // slash-separated, workspace-relative
	abs  string // where the bytes are read from (may be a materialized git dir)
	info fs.FileInfo
	link string
}

// collect walks root without following symlinks and returns its portable
// items sorted by path. A `.git` file whose gitdir lies inside root is kept
// verbatim; one pointing outside root is ErrUnsupportedGit (portable Git
// materialization, which consumes materialize and tmp, arrives in cycle 6).
// Sockets/fifos inside git directories are runtime artefacts (fsmonitor) and
// skipped; anywhere else they are ErrUnsupportedFileType.
func (s *Store) collect(ctx context.Context, root string, materialize bool, tmp string) ([]item, error) {
	abs, err := filepath.Abs(root)
	if err != nil {
		return nil, err
	}
	real, err := filepath.EvalSymlinks(abs)
	if err != nil {
		return nil, fmt.Errorf("checkpoint: workspace %s: %w", root, err)
	}
	if fi, err := os.Stat(real); err != nil || !fi.IsDir() {
		return nil, fmt.Errorf("checkpoint: workspace %s is not a directory", root)
	}
	var items []item
	err = filepath.WalkDir(real, func(p string, d fs.DirEntry, werr error) error {
		if werr != nil {
			return werr
		}
		if err := ctx.Err(); err != nil {
			return err
		}
		if p == real {
			return nil
		}
		relOS, err := filepath.Rel(real, p)
		if err != nil {
			return err
		}
		rel := filepath.ToSlash(relOS)
		info, err := os.Lstat(p)
		if err != nil {
			return err
		}
		mode := info.Mode()
		portable := mode.IsDir() || mode.IsRegular() || mode&fs.ModeSymlink != 0
		if !portable && insideGitDir(rel) {
			return nil
		}
		if d.Name() == ".git" && mode.IsRegular() {
			target, err := readGitFile(p)
			if err != nil {
				return fmt.Errorf("%w: %s: %v", runner.ErrUnsupportedGit, rel, err)
			}
			if !within(real, target) {
				return fmt.Errorf("%w: %s links to a git directory outside the workspace", runner.ErrUnsupportedGit, rel)
			}
		}
		if !portable {
			return fmt.Errorf("%w: %s (%s)", runner.ErrUnsupportedFileType, rel, mode.Type())
		}
		link := ""
		if mode&fs.ModeSymlink != 0 {
			if link, err = os.Readlink(p); err != nil {
				return err
			}
		}
		items = append(items, item{rel: rel, abs: p, info: info, link: link})
		return nil
	})
	if err != nil {
		return nil, err
	}
	sort.Slice(items, func(i, j int) bool { return items[i].rel < items[j].rel })
	return items, nil
}

// walkPlain lists a materialized git directory under the workspace path rel.
func walkPlain(dir, rel string) ([]item, error) {
	var out []item
	err := filepath.WalkDir(dir, func(p string, d fs.DirEntry, werr error) error {
		if werr != nil {
			return werr
		}
		info, err := os.Lstat(p)
		if err != nil {
			return err
		}
		sub, err := filepath.Rel(dir, p)
		if err != nil {
			return err
		}
		name := rel
		if sub != "." {
			name = rel + "/" + filepath.ToSlash(sub)
		}
		mode := info.Mode()
		switch {
		case mode.IsDir(), mode.IsRegular():
			out = append(out, item{rel: name, abs: p, info: info})
		case mode&fs.ModeSymlink != 0:
			l, err := os.Readlink(p)
			if err != nil {
				return err
			}
			out = append(out, item{rel: name, abs: p, info: info, link: l})
		}
		return nil
	})
	return out, err
}

func insideGitDir(rel string) bool {
	return strings.HasPrefix(rel, ".git/") || strings.Contains(rel, "/.git/")
}

// readGitFile resolves a `.git` file's "gitdir:" target.
func readGitFile(p string) (string, error) {
	b, err := os.ReadFile(p)
	if err != nil {
		return "", err
	}
	line := strings.TrimSpace(strings.SplitN(string(b), "\n", 2)[0])
	if !strings.HasPrefix(line, "gitdir:") {
		return "", fmt.Errorf("not a gitdir file")
	}
	target := strings.TrimSpace(strings.TrimPrefix(line, "gitdir:"))
	if !filepath.IsAbs(target) {
		target = filepath.Join(filepath.Dir(p), target)
	}
	return filepath.EvalSymlinks(filepath.Clean(target))
}

// within reports whether target is root or below it.
func within(root, target string) bool {
	rel, err := filepath.Rel(root, target)
	return err == nil && rel != ".." && !strings.HasPrefix(rel, ".."+string(filepath.Separator)) && !filepath.IsAbs(rel)
}

// bootstrapResourceOwner marks the provenance-only resource columns of a
// bootstrap baseline row (044 requires them). It is never an authorization:
// prepared rows carry the exact P3 T3 claim instead.
const bootstrapResourceOwner = "bootstrap"

// CheckpointCatalogRepo indexes immutable checkpoint artifacts
// (workspace_checkpoints, migration 044). The committed pointer is
// workspace_homes.checkpoint_version; only Bootstrap here and the P3 T5/P3 T13/
// P4 T6 transactions move it.
type CheckpointCatalogRepo struct {
	db  *sql.DB
	now func() time.Time
}

// NewCheckpointCatalogRepo creates the repo.
func NewCheckpointCatalogRepo(db *sql.DB) *CheckpointCatalogRepo {
	return &CheckpointCatalogRepo{db: db, now: func() time.Time { return time.Now().UTC() }}
}

func runResourceKey(runID uuid.UUID) string { return "run:" + runID.String() }

// committedRef reads the committed pointer and its row inside q. A pointer to a
// missing or non-committed row is corruption, never "no checkpoint".
func committedRef(ctx context.Context, q groupQueryer, runID uuid.UUID) (runner.CheckpointRef, string, bool, error) {
	var version int64
	var hash, path, state sql.NullString
	err := q.QueryRowContext(ctx, `SELECT h.checkpoint_version, c.manifest_hash, c.archive_path, c.state
		FROM workspace_homes h
		LEFT JOIN workspace_checkpoints c ON c.run_id = h.run_id AND c.version = h.checkpoint_version
		WHERE h.run_id = ?`, uuidToString(runID)).Scan(&version, &hash, &path, &state)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && version == 0) {
		return runner.CheckpointRef{}, "", false, nil
	}
	if err != nil {
		return runner.CheckpointRef{}, "", false, fmt.Errorf("checkpoint catalog: committed pointer: %w", err)
	}
	if !hash.Valid || state.String != "committed" {
		return runner.CheckpointRef{}, "", false, fmt.Errorf("%w: run %s committed pointer v%d names no committed checkpoint",
			runner.ErrCorruptCheckpoint, runID, version)
	}
	return runner.CheckpointRef{RunID: runID, Version: version, ManifestHash: hash.String}, path.String, true, nil
}

// Latest returns the COMMITTED checkpoint named by the home pointer. Prepared
// rows, however new, are never returned.
func (r *CheckpointCatalogRepo) Latest(ctx context.Context, runID uuid.UUID) (runner.CheckpointRef, string, bool, error) {
	return committedRef(ctx, r.db, runID)
}

// Get returns one COMMITTED checkpoint; prepared candidates are not found.
func (r *CheckpointCatalogRepo) Get(ctx context.Context, runID uuid.UUID, version int64) (runner.CheckpointRef, string, error) {
	var hash, path string
	err := r.db.QueryRowContext(ctx, `SELECT manifest_hash, archive_path FROM workspace_checkpoints
		WHERE run_id = ? AND version = ? AND state = 'committed'`, uuidToString(runID), version).Scan(&hash, &path)
	if errors.Is(err, sql.ErrNoRows) {
		return runner.CheckpointRef{}, "", fmt.Errorf("%w: run %s v%d", runner.ErrCheckpointNotFound, runID, version)
	}
	if err != nil {
		return runner.CheckpointRef{}, "", fmt.Errorf("checkpoint catalog: get: %w", err)
	}
	return runner.CheckpointRef{RunID: runID, Version: version, ManifestHash: hash}, path, nil
}

// Bootstrap records the run's first committed baseline. In one transaction it
// rejects prior committed progress, an active run:<uuid> lease and an active
// job of the run, inserts the committed row and sets the home pointer.
func (r *CheckpointCatalogRepo) Bootstrap(ctx context.Context, c runner.CheckpointCandidate) error {
	if err := c.ValidateBootstrap(); err != nil {
		return err
	}
	run := uuidToString(c.Ref.RunID)
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("checkpoint catalog: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	// First statement takes the SQLite write lock before anything is read.
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_homes SET updated_at = updated_at WHERE run_id = ?`, run); err != nil {
		return fmt.Errorf("checkpoint catalog: lock: %w", err)
	}
	var pointer, committed, leases, jobs int64
	if err := tx.QueryRowContext(ctx, `SELECT
		COALESCE((SELECT checkpoint_version FROM workspace_homes WHERE run_id = ?), 0),
		(SELECT COUNT(*) FROM workspace_checkpoints WHERE run_id = ? AND state = 'committed'),
		(SELECT COUNT(*) FROM workspace_leases WHERE resource_key = ? AND active = 1),
		(SELECT COUNT(*) FROM runner_jobs WHERE run_id = ? AND state IN ('offered', 'running'))`,
		run, run, runResourceKey(c.Ref.RunID), run).Scan(&pointer, &committed, &leases, &jobs); err != nil {
		return fmt.Errorf("checkpoint catalog: bootstrap preconditions: %w", err)
	}
	switch {
	case pointer != 0 || committed != 0:
		return fmt.Errorf("%w: run %s already has committed progress", runner.ErrCheckpointConflict, c.Ref.RunID)
	case leases != 0:
		return fmt.Errorf("%w: run %s has an active resource writer", runner.ErrCheckpointConflict, c.Ref.RunID)
	case jobs != 0:
		return fmt.Errorf("%w: run %s has an active job", runner.ErrCheckpointConflict, c.Ref.RunID)
	}
	now := timeToString(r.now())
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_checkpoints
		(run_id, version, manifest_hash, archive_path, size_bytes, job_id, job_generation, state, base_ref,
		 resource_key, resource_owner, resource_generation, resource_token, created_at)
		VALUES (?, ?, ?, ?, ?, NULL, NULL, 'committed', '', ?, ?, 1, ?, ?)`,
		run, c.Ref.Version, c.Ref.ManifestHash, c.ArchivePath, c.SizeBytes,
		runResourceKey(c.Ref.RunID), bootstrapResourceOwner, uuid.NewString(), now); err != nil {
		if isUniqueViolation(err) {
			return fmt.Errorf("%w: run %s v%d already registered", runner.ErrCheckpointConflict, c.Ref.RunID, c.Ref.Version)
		}
		return fmt.Errorf("checkpoint catalog: insert baseline: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_homes(run_id, checkpoint_version, updated_at)
		VALUES (?, ?, strftime('%Y-%m-%dT%H:%M:%fZ','now'))
		ON CONFLICT(run_id) DO UPDATE SET checkpoint_version = excluded.checkpoint_version, updated_at = excluded.updated_at`,
		run, c.Ref.Version); err != nil {
		return fmt.Errorf("checkpoint catalog: set baseline pointer: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("checkpoint catalog: commit: %w", err)
	}
	return nil
}

// DeleteRun removes every row of a run and clears its committed pointer, so
// Latest reports "no checkpoint" rather than a dangling pointer.
func (r *CheckpointCatalogRepo) DeleteRun(ctx context.Context, runID uuid.UUID) error {
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("checkpoint catalog: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	if _, err := tx.ExecContext(ctx, `DELETE FROM workspace_checkpoints WHERE run_id = ?`, uuidToString(runID)); err != nil {
		return fmt.Errorf("checkpoint catalog: delete: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_homes SET checkpoint_version = 0 WHERE run_id = ?`, uuidToString(runID)); err != nil {
		return fmt.Errorf("checkpoint catalog: clear pointer: %w", err)
	}
	return tx.Commit()
}

	ctx := context.Background()

	var state, jobID, key, token, baseRef string
	var jobGen, resGen int64
	require.NoError(t, db.QueryRow(`SELECT state, job_id, job_generation, resource_key, resource_generation, resource_token, base_ref
		FROM workspace_checkpoints WHERE run_id = ? AND version = ?`, run.String(), prepared.Version).

	assert.Equal(t, res.Generation, resGen)

	assert.Equal(t, base.String(), baseRef)

	latest, _, err = store.Latest(ctx, run)
	require.NoError(t, err)
	assert.Equal(t, prepared, latest, "only the validated transaction moves Latest")
}

	errs := make([]error, len(hashes))
	var wg sync.WaitGroup
	for i, h := range hashes {
		wg.Add(1)
		go func(i int, h string) {
			defer wg.Done()
			errs[i] = cat.Publish(ctx, ckPrepared(run, 2, ckHash(h), base, job, res))
		}(i, h)
	}
	wg.Wait()
	won := 0
	for _, err := range errs {
		if err == nil {
			won++
		} else {
			require.ErrorIs(t, err, runner.ErrCheckpointConflict)
		}
	}
	assert.Equal(t, 1, won, "exactly one candidate owns a version")

	for i := range hashes {
		wg.Add(1)
		go func(i int) {
			defer wg.Done()
			errs[i] = cat.Publish(ctx, ckPrepared(run, int64(3+i), ckHash(hashes[i]), base, job, res))
		}(i)
	}
	wg.Wait()
	for _, err := range errs {
		require.NoError(t, err)
	}
	assert.Equal(t, 1+1+len(hashes), ckRows(t, db, run))
	assert.Equal(t, int64(1), ckPointer(t, db, run))

var _ runner.CheckpointCatalog = (*CheckpointCatalogRepo)(nil)

// Publish registers a PREPARED candidate. In one transaction it validates the
// exact active job fence (fenceErr), the exact active resource claim
// (checkResourceFenceTx, P3 T3) and, when that claim is held by a job, that it
// is this job; then that Base is the run's committed pointer. An identical
// re-registration is idempotent; any other row at that version is a conflict.
// It never touches workspace_homes.
func (r *CheckpointCatalogRepo) Publish(ctx context.Context, c runner.CheckpointCandidate) error {
	if err := c.ValidatePrepared(); err != nil {
		return err
	}
	f, res := *c.Job, c.Resource
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("checkpoint catalog: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	// First statement takes the SQLite write lock before anything is read.
	if _, err := tx.ExecContext(ctx, `UPDATE runner_jobs SET updated_at = updated_at WHERE id = ?`, uuidToString(f.JobID)); err != nil {
		return fmt.Errorf("checkpoint catalog: lock: %w", err)
	}
	if err := fenceErr(ctx, tx, f); err != nil {
		if errors.Is(err, runner.ErrJobNotFound) {
			return fmt.Errorf("%w: %w", runner.ErrFenced, err)
		}
		return err
	}
	if err := checkResourceFenceTx(ctx, tx, res); err != nil {
		return err
	}
	var holderJob, holderRunner sql.NullString
	var holderGen sql.NullInt64
	err = tx.QueryRowContext(ctx, `SELECT job_id, job_runner_id, job_generation FROM workspace_lease_holders
		WHERE resource_key = ? AND generation = ? AND token = ?`, res.Key, res.Generation, res.Token.String()).
		Scan(&holderJob, &holderRunner, &holderGen)
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("%w: claim %s gen %d has no holder record", runner.ErrResourceFenced, res.Key, res.Generation)
	}
	if err != nil {
		return fmt.Errorf("checkpoint catalog: lease holder: %w", err)
	}
	if holderJob.Valid && (holderJob.String != uuidToString(f.JobID) || holderRunner.String != string(f.RunnerID) || holderGen.Int64 != f.Generation) {
		return fmt.Errorf("%w: claim %s gen %d is held by another job", runner.ErrResourceFenced, res.Key, res.Generation)
	}
	base, _, _, err := committedRef(ctx, tx, c.Ref.RunID)
	if err != nil {
		return err
	}
	if base != c.Base {
		return fmt.Errorf("%w: candidate base %q is not the committed %q", runner.ErrCheckpointConflict, c.Base, base)
	}
	run := uuidToString(c.Ref.RunID)
	var have struct {
		hash, path, state, jobID, baseRef, key, owner, token string
		size, jobGen, resGen                                 int64
	}
	err = tx.QueryRowContext(ctx, `SELECT manifest_hash, archive_path, size_bytes, state, COALESCE(job_id, ''),
		COALESCE(job_generation, 0), base_ref, resource_key, resource_owner, resource_generation, resource_token
		FROM workspace_checkpoints WHERE run_id = ? AND version = ?`, run, c.Ref.Version).
		Scan(&have.hash, &have.path, &have.size, &have.state, &have.jobID, &have.jobGen, &have.baseRef,
			&have.key, &have.owner, &have.resGen, &have.token)
	switch {
	case err == nil:
		if have.state == "prepared" && have.hash == c.Ref.ManifestHash && have.path == c.ArchivePath &&
			have.size == c.SizeBytes && have.jobID == uuidToString(f.JobID) && have.jobGen == f.Generation &&
			have.baseRef == c.Base.String() && have.key == res.Key && have.owner == res.Owner &&
			have.resGen == res.Generation && have.token == res.Token.String() {
			return tx.Commit() // identical retry: the same candidate
		}
		return fmt.Errorf("%w: run %s v%d is already registered differently", runner.ErrCheckpointConflict, c.Ref.RunID, c.Ref.Version)
	case !errors.Is(err, sql.ErrNoRows):
		return fmt.Errorf("checkpoint catalog: existing candidate: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_checkpoints
		(run_id, version, manifest_hash, archive_path, size_bytes, job_id, job_generation, state, base_ref,
		 resource_key, resource_owner, resource_generation, resource_token, created_at)
		VALUES (?, ?, ?, ?, ?, ?, ?, 'prepared', ?, ?, ?, ?, ?, ?)`,
		run, c.Ref.Version, c.Ref.ManifestHash, c.ArchivePath, c.SizeBytes, uuidToString(f.JobID), f.Generation,
		c.Base.String(), res.Key, res.Owner, res.Generation, res.Token.String(), timeToString(r.now())); err != nil {
		if isUniqueViolation(err) {
			return fmt.Errorf("%w: run %s v%d already registered", runner.ErrCheckpointConflict, c.Ref.RunID, c.Ref.Version)
		}
		return fmt.Errorf("checkpoint catalog: insert candidate: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("checkpoint catalog: commit: %w", err)
	}
	return nil
}



// PreparedFor returns the single PREPARED row registered under exactly this
// job fence (id, generation, and runner via the claim's holder record) and
// resource claim (key, owner, generation, token). Committed rows never match.
// More than one match is ErrCheckpointConflict, never a newest-row guess.
func (r *CheckpointCatalogRepo) PreparedFor(ctx context.Context, runID uuid.UUID, job runner.Fence, res engine.ResourceFenceRef) (runner.CheckpointRef, bool, error) {
	rows, err := r.db.QueryContext(ctx, `SELECT c.version, c.manifest_hash FROM workspace_checkpoints c
		JOIN workspace_lease_holders h ON h.resource_key = c.resource_key AND h.generation = c.resource_generation AND h.token = c.resource_token
		WHERE c.run_id = ? AND c.state = 'prepared' AND c.job_id = ? AND c.job_generation = ?
		  AND c.resource_key = ? AND c.resource_owner = ? AND c.resource_generation = ? AND c.resource_token = ?
		  AND (h.job_runner_id IS NULL OR h.job_runner_id = ?)`,
		uuidToString(runID), uuidToString(job.JobID), job.Generation,
		res.Key, res.Owner, res.Generation, res.Token.String(), string(job.RunnerID))
	if err != nil {
		return runner.CheckpointRef{}, false, fmt.Errorf("checkpoint catalog: prepared for: %w", err)
	}
	defer rows.Close()
	var found []runner.CheckpointRef
	for rows.Next() {
		ref := runner.CheckpointRef{RunID: runID}
		if err := rows.Scan(&ref.Version, &ref.ManifestHash); err != nil {
			return runner.CheckpointRef{}, false, fmt.Errorf("checkpoint catalog: prepared for: %w", err)
		}
		found = append(found, ref)
	}
	if err := rows.Err(); err != nil {
		return runner.CheckpointRef{}, false, fmt.Errorf("checkpoint catalog: prepared for: %w", err)
	}
	switch len(found) {
	case 0:
		return runner.CheckpointRef{}, false, nil
	case 1:
		return found[0], true, nil
	default:
		return runner.CheckpointRef{}, false, fmt.Errorf("%w: %d prepared candidates for job %s generation %d", runner.ErrCheckpointConflict, len(found), job.JobID, job.Generation)
	}
}

// syncRecorder records the identity (inode) of every file fsynced through it.
type syncRecorder struct {
	*os.File
	mu     *sync.Mutex
	synced *[]os.FileInfo
}

func (s syncRecorder) Sync() error {
	if err := s.File.Sync(); err != nil {
		return err
	}
	fi, err := s.File.Stat()
	if err != nil {
		return err
	}
	s.mu.Lock()
	*s.synced = append(*s.synced, fi)
	s.mu.Unlock()
	return nil
}

// Publish PREPARES a staged checkpoint: it installs the fsynced artifact and
// registers a candidate carrying the exact job fence f, staged.Resource and
// staged.Base. It never moves Latest. The staging directory is removed whether
// or not registration succeeds; an unregistered installed artifact is an
// unreferenced orphan and never recovery state.
func (s *Store) Publish(ctx context.Context, staged runner.StagedCheckpoint, f runner.Fence) (runner.CheckpointRef, error) {
	if s.catalog == nil {
		return runner.CheckpointRef{}, runner.ErrNoCheckpointCatalog
	}
	if err := s.ownsStaging(staged); err != nil {
		return runner.CheckpointRef{}, err
	}
	defer forceRemoveAll(staged.Dir)
	if staged.Manifest.Version != staged.Version || staged.Manifest.Verify() != nil {
		return runner.CheckpointRef{}, fmt.Errorf("%w: staged manifest does not match v%d", runner.ErrCorruptCheckpoint, staged.Version)
	}
	job := f
	c := runner.CheckpointCandidate{
		Ref:  runner.CheckpointRef{RunID: staged.RunID, Version: staged.Version, ManifestHash: staged.Manifest.Hash},
		Base: staged.Base, Job: &job, Resource: staged.Resource,
		ArchivePath: s.archivePath(staged.RunID, staged.Version), SizeBytes: staged.SizeBytes,
	}
	if err := c.ValidatePrepared(); err != nil {
		return runner.CheckpointRef{}, err
	}
	if err := s.install(staged.RunID, staged.Manifest, staged.ArchivePath); err != nil {
		return runner.CheckpointRef{}, err
	}
	if err := s.catalog.Publish(ctx, c); err != nil {
		return runner.CheckpointRef{}, err
	}
	return c.Ref, nil
}

// ReadFile opens one manifest-listed regular file of a COMMITTED checkpoint,
// served from a verified extraction of that immutable artifact. Directories,
// symlinks, unlisted paths and prepared candidates are refused; the mutable
// work dir is never read.
func (s *Store) ReadFile(ctx context.Context, ref runner.CheckpointRef, p string) (io.ReadCloser, error) {
	clean, err := runner.CleanRelPath(p)
	if err != nil {
		return nil, err
	}
	if ref.IsZero() {
		return nil, fmt.Errorf("%w: empty checkpoint has no %s", runner.ErrCheckpointNotFound, clean)
	}
	path, m, err := s.resolve(ctx, ref)
	if err != nil {
		return nil, err
	}
	var entry *runner.ManifestEntry
	for i := range m.Entries {
		if m.Entries[i].Path == clean {
			entry = &m.Entries[i]
		}
	}
	if entry == nil {
		return nil, fmt.Errorf("%w: %s in %s", runner.ErrCheckpointNotFound, clean, ref)
	}
	if !fs.FileMode(entry.Mode).IsRegular() {
		return nil, fmt.Errorf("checkpoint: %s is not a regular file", clean)
	}
	cache, err := s.ensureCache(ref, path, m)
	if err != nil {
		return nil, err
	}
	root, err := os.OpenRoot(cache)
	if err != nil {
		return nil, err
	}
	fi, err := root.Lstat(clean)
	if err != nil || !fi.Mode().IsRegular() {
		root.Close()
		return nil, fmt.Errorf("%w: cached %s is not a regular file", runner.ErrCorruptCheckpoint, clean)
	}
	f, err := root.Open(clean)
	if err != nil {
		root.Close()
		return nil, err
	}
	return rootFile{File: f, root: root}, nil
}

	*os.File
	root *os.Root

// applyDelta reads the control entry, applies its deletions, then writes every
// changed entry. modes accumulates directory permissions for applyDirModes.
func applyDelta(r io.Reader, root *os.Root, modes map[string]fs.FileMode, l Limits) (runner.DeltaControl, error) {
	gz, br, err := openGzip(r)
	if err != nil {
		return runner.DeltaControl{}, err
	}
	defer gz.Close()
	tr := tar.NewReader(gz)
	hdr, err := tr.Next()
	if err != nil {
		return runner.DeltaControl{}, fmt.Errorf("%w: delta: %v", runner.ErrCorruptCheckpoint, err)
	}
	if hdr.Name != runner.DeltaControlPath || hdr.Typeflag != tar.TypeReg || hdr.Size > maxDeltaControlBytes {
		return runner.DeltaControl{}, fmt.Errorf("%w: delta must start with %s", runner.ErrCorruptCheckpoint, runner.DeltaControlPath)
	}
	b, err := io.ReadAll(io.LimitReader(tr, hdr.Size))
	if err != nil {
		return runner.DeltaControl{}, fmt.Errorf("%w: delta control: %v", runner.ErrCorruptCheckpoint, err)
	}
	var ctl runner.DeltaControl
	if err := json.Unmarshal(b, &ctl); err != nil {
		return runner.DeltaControl{}, fmt.Errorf("%w: delta control: %v", runner.ErrCorruptCheckpoint, err)
	}
	expected := map[string]bool{}
	for _, e := range ctl.Expected {
		if _, err := runner.CleanRelPath(e.Path); err != nil {
			return runner.DeltaControl{}, err
		}
		if expected[e.Path] {
			return runner.DeltaControl{}, fmt.Errorf("%w: duplicate expected path %s", runner.ErrCorruptCheckpoint, e.Path)
		}
		expected[e.Path] = true
	}
	for _, d := range ctl.Deleted {
		clean, err := runner.CleanRelPath(d)
		if err != nil {
			return runner.DeltaControl{}, err
		}
		if err := noSymlinkAncestor(root, clean); err != nil {
			return runner.DeltaControl{}, err
		}
		if err := root.RemoveAll(clean); err != nil {
			return runner.DeltaControl{}, fmt.Errorf("checkpoint: delete %s: %w", clean, err)
		}
		for k := range modes {
			if k == clean || strings.HasPrefix(k, clean+"/") {
				delete(modes, k)
			}
		}
	}
	if _, err := applyTar(tr, root, true, modes, &budget{l: l}); err != nil {
		return runner.DeltaControl{}, err
	}
	if err := endOfArchive(gz, br); err != nil {
		return runner.DeltaControl{}, err
	}
	return ctl, nil
}

// WriteDelta encodes a push: the DeltaControl entry first, then every changed
// path (directories, regular files, symlinks) read from root.
func WriteDelta(w io.Writer, root string, changed []string, ctl runner.DeltaControl) error {
	gz := gzip.NewWriter(w)
	tw := tar.NewWriter(gz)
	b, err := json.Marshal(ctl)
	if err != nil {
		return err
	}
	if err := tw.WriteHeader(&tar.Header{Name: runner.DeltaControlPath, Typeflag: tar.TypeReg, Mode: 0o600, Size: int64(len(b)), Format: tar.FormatPAX}); err != nil {
		return err
	}
	if _, err := tw.Write(b); err != nil {
		return err
	}
	paths := append([]string(nil), changed...)
	sort.Strings(paths)
	for _, p := range paths {
		clean, err := runner.CleanRelPath(p)
		if err != nil {
			return err
		}
		abs := filepath.Join(root, filepath.FromSlash(clean))
		info, err := os.Lstat(abs)
		if err != nil {
			return err
		}
		link := ""
		if info.Mode()&fs.ModeSymlink != 0 {
			if link, err = os.Readlink(abs); err != nil {
				return err
			}
		}
		if _, err := writeItem(tw, item{rel: clean, abs: abs, info: info, link: link}); err != nil {
			return err
		}
	}
	if err := tw.Close(); err != nil {
		return err
	}
	return gz.Close()
}

	require.NoError(t, filepath.WalkDir(root, func(p string, d fs.DirEntry, err error) error {
		require.NoError(t, err)
		info, err := os.Lstat(p)
		require.NoError(t, err)
		rel, _ := filepath.Rel(root, p)
		line := rel + " " + info.Mode().String()
		switch {
		case info.Mode().IsRegular():
			b, err := os.ReadFile(p)
			require.NoError(t, err)
			sum := sha256.Sum256(b)
			line += " " + hex.EncodeToString(sum[:])
		case info.Mode()&fs.ModeSymlink != 0:
			l, _ := os.Readlink(p)
			line += " ->" + l
		}
		lines = append(lines, line)
		return nil
	}))
	sort.Strings(lines)
	io.WriteString(h, strings.Join(lines, "\n"))
	return hex.EncodeToString(h.Sum(nil))
}

func (r *recordingGit) run(ctx context.Context, args ...string) ([]byte, error) {
	r.mu.Lock()
	r.calls = append(r.calls, append([]string(nil), args...))

	cmd := exec.CommandContext(ctx, "git", args...)

	}
	return out, err

package checkpoint

import (
	"bufio"
	"context"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"os/exec"
	"path/filepath"
	"strings"

type gitFunc = func(ctx context.Context, args ...string) ([]byte, error)

// noNetwork is prepended to every git invocation: no transport may run, so a
// promisor lazy fetch or credential prompt cannot happen even on a git that
// predates GIT_NO_LAZY_FETCH.
var noNetwork = []string{"-c", "protocol.allow=never", "-c", "credential.helper=", "-c", "core.fsmonitor=false"}

// scrubbedGitVars are inherited variables that would redirect git away from
// the directories this package names explicitly.
var scrubbedGitVars = []string{"GIT_DIR", "GIT_WORK_TREE", "GIT_INDEX_FILE", "GIT_OBJECT_DIRECTORY",
	"GIT_ALTERNATE_OBJECT_DIRECTORIES", "GIT_COMMON_DIR", "GIT_NAMESPACE", "GIT_CONFIG", "GIT_CONFIG_PARAMETERS"}

// gitEnv returns base without redirecting variables, plus lazy-fetch,
// prompt and system-config suppression.
func gitEnv(base []string) []string {
	out := make([]string, 0, len(base)+5)
	for _, kv := range base {
		name, _, _ := strings.Cut(kv, "=")
		drop := false
		for _, v := range scrubbedGitVars {
			if name == v {
				drop = true
			}
		}
		if !drop {
			out = append(out, kv)
		}
	}
	return append(out, "GIT_NO_LAZY_FETCH=1", "GIT_TERMINAL_PROMPT=0", "GIT_CONFIG_NOSYSTEM=1", "GIT_ASKPASS=", "SSH_ASKPASS=")
}

func runGit(ctx context.Context, args ...string) ([]byte, error) {
	cmd := exec.CommandContext(ctx, "git", args...)
	cmd.Env = gitEnv(os.Environ())
	out, err := cmd.Output()
	if err != nil {
		msg := ""
		var ee *exec.ExitError
		if errors.As(err, &ee) {
			msg = strings.TrimSpace(string(ee.Stderr))
		}
		return out, fmt.Errorf("git %s: %w: %s", strings.Join(args, " "), err, msg)
	}
	return out, nil
}

func gitAt(gitDir string, args ...string) []string {
	return append(append(append([]string{}, noNetwork...), "--git-dir", gitDir), args...)
}

// MaterializePortableGit writes a self-contained `.git` directory for the
// repository whose work tree is srcDir into dstDir/.git (replacing any there).
// It never writes beneath srcDir or its git directories: object closure is
// computed and packed in a private copy that temporarily borrows the source
// objects as an alternate, then the alternate is removed and the closure is
// re-verified with lazy fetch disabled. Required objects that are absent
// locally fail with ErrUnsupportedGit; for a partial clone the error also wraps
// ErrPromisorObjectsMissing. P4 T11 reuses this helper for resolution copies.
func MaterializePortableGit(ctx context.Context, srcDir, dstDir string) error {
	return materializePortableGit(ctx, runGit, srcDir, dstDir)
}

func materializePortableGit(ctx context.Context, git gitFunc, srcDir, dstDir string) error {
	srcAbs, err := filepath.Abs(srcDir)
	if err != nil {
		return err
	}
	dstAbs, err := filepath.Abs(dstDir)
	if err != nil {
		return err
	}
	gitdir, common, err := resolveGitDirs(filepath.Join(srcAbs, ".git"))
	if err != nil {
		return fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
	}
	if dstAbs == srcAbs || within(gitdir, dstAbs) || within(common, dstAbs) || within(filepath.Join(srcAbs, ".git"), dstAbs) {
		return fmt.Errorf("%w: destination %s overlaps the source repository", runner.ErrUnsupportedGit, dstDir)
	}
	if err := os.MkdirAll(dstAbs, 0o700); err != nil {
		return err
	}
	work, err := os.MkdirTemp(dstAbs, ".git-materialize-")
	if err != nil {
		return err
	}
	defer forceRemoveAll(work)
	out := filepath.Join(work, ".git")
	if err := copyGitMeta(common, out, map[string]bool{"objects": true, "worktrees": true}); err != nil {
		return fmt.Errorf("%w: copy common dir: %v", runner.ErrUnsupportedGit, err)
	}
	if gitdir != common {
		if err := copyGitMeta(gitdir, out, map[string]bool{"commondir": true, "gitdir": true, "locked": true}); err != nil {
			return fmt.Errorf("%w: copy worktree dir: %v", runner.ErrUnsupportedGit, err)
		}
	}
	if err := os.MkdirAll(filepath.Join(out, "objects", "pack"), 0o755); err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Join(out, "objects", "info"), 0o755); err != nil {
		return err
	}
	alternates := filepath.Join(out, "objects", "info", "alternates")
	if err := os.WriteFile(alternates, []byte(filepath.Join(common, "objects")+"\n"), 0o600); err != nil {
		return err
	}
	cfg := filepath.Join(out, "config")
	if _, err := git(ctx, append(append([]string{}, noNetwork...), "config", "--file", cfg, "core.bare", "false")...); err != nil {
		return fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
	}
	// Exit status 5 (key not set) is expected for most repositories.
	_, _ = git(ctx, append(append([]string{}, noNetwork...), "config", "--file", cfg, "--unset-all", "core.worktree")...)

	extra, err := pseudoHeadRoots(out)
	if err != nil {
		return fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
	}
	if missing, err := missingObjects(ctx, git, out, extra); err != nil {
		return fmt.Errorf("%w: closure: %v", runner.ErrUnsupportedGit, err)
	} else if len(missing) > 0 {
		if isPartialClone(ctx, git, out, common) {
			return fmt.Errorf("%w: %w: %d required objects are absent locally (first %s); no network fetch is attempted",
				runner.ErrUnsupportedGit, runner.ErrPromisorObjectsMissing, len(missing), missing[0])
		}
		return fmt.Errorf("%w: repository is missing %d required objects (first %s)", runner.ErrUnsupportedGit, len(missing), missing[0])
	}
	// Pin pseudo-heads with temporary refs so --all packs their closure too.
	for i, oid := range extra {
		if _, err := git(ctx, gitAt(out, "update-ref", fmt.Sprintf("refs/arbitron-materialize/root-%d", i), oid)...); err != nil {
			return fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
		}
	}
	if _, err := git(ctx, gitAt(out, "pack-objects", "-q", "--all", "--reflog", "--indexed-objects",
		filepath.Join(out, "objects", "pack", "pack"))...); err != nil {
		return fmt.Errorf("%w: pack closure: %v", runner.ErrUnsupportedGit, err)
	}
	for i := range extra {
		if _, err := git(ctx, gitAt(out, "update-ref", "-d", fmt.Sprintf("refs/arbitron-materialize/root-%d", i))...); err != nil {
			return fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
		}
	}
	_ = os.RemoveAll(filepath.Join(out, "refs", "arbitron-materialize"))
	if err := os.Remove(alternates); err != nil {
		return err
	}
	if missing, err := missingObjects(ctx, git, out, extra); err != nil || len(missing) > 0 {
		return fmt.Errorf("%w: materialized copy is not self-contained (missing %v, %v)", runner.ErrUnsupportedGit, missing, err)
	}
	final := filepath.Join(dstAbs, ".git")
	forceRemoveAll(final)
	return os.Rename(out, final)
}

// resolveGitDirs returns the repository's own git dir and its common dir.
func resolveGitDirs(dotGit string) (gitdir, common string, err error) {
	fi, err := os.Lstat(dotGit)
	if err != nil {
		return "", "", err
	}
	switch {
	case fi.IsDir():
		if gitdir, err = filepath.EvalSymlinks(dotGit); err != nil {
			return "", "", err
		}
	case fi.Mode().IsRegular():
		if gitdir, err = readGitFile(dotGit); err != nil {
			return "", "", err
		}
	default:
		return "", "", fmt.Errorf("%s is neither a directory nor a gitdir file", dotGit)
	}
	common = gitdir
	if b, err := os.ReadFile(filepath.Join(gitdir, "commondir")); err == nil {
		c := strings.TrimSpace(string(b))
		if !filepath.IsAbs(c) {
			c = filepath.Join(gitdir, c)
		}
		if common, err = filepath.EvalSymlinks(filepath.Clean(c)); err != nil {
			return "", "", err
		}
	}
	return gitdir, common, nil
}

// needsMaterialize reports whether a `.git` directory borrows objects
// (alternates) or is a partial clone, so a verbatim copy would not be portable.
func (s *Store) needsMaterialize(ctx context.Context, dotGit string) (bool, error) {
	gitdir, common, err := resolveGitDirs(dotGit)
	if err != nil {
		return false, fmt.Errorf("%w: %v", runner.ErrUnsupportedGit, err)
	}
	if gitdir != common {
		return true, nil
	}
	if _, err := os.Stat(filepath.Join(common, "objects", "info", "alternates")); err == nil {
		return true, nil
	}
	return isPartialClone(ctx, s.git, gitdir, common), nil
}

func isPartialClone(ctx context.Context, git gitFunc, gitDir, common string) bool {
	if ps, _ := filepath.Glob(filepath.Join(common, "objects", "pack", "*.promisor")); len(ps) > 0 {
		return true
	}
	out, _ := git(ctx, gitAt(gitDir, "config", "--get-regexp", `^(extensions\.partialclone|remote\..*\.promisor)$`)...)
	return strings.TrimSpace(string(out)) != ""
}

// pseudoHeadRoots lists object IDs named by in-progress operation heads that
// --all does not reach (merge/cherry-pick/revert/rebase state).
func pseudoHeadRoots(gitDir string) ([]string, error) {
	var oids []string
	for _, name := range []string{"ORIG_HEAD", "MERGE_HEAD", "CHERRY_PICK_HEAD", "REVERT_HEAD", "REBASE_HEAD", "AUTO_MERGE"} {
		f, err := os.Open(filepath.Join(gitDir, name))
		if errors.Is(err, fs.ErrNotExist) {
			continue
		}
		if err != nil {
			return nil, err
		}
		sc := bufio.NewScanner(f)
		for sc.Scan() {
			fields := strings.Fields(sc.Text())
			if len(fields) > 0 && isHexOID(fields[0]) {
				oids = append(oids, fields[0])
			}
		}
		f.Close()
		if err := sc.Err(); err != nil {
			return nil, err
		}
	}
	return oids, nil
}

func isHexOID(s string) bool {
	if len(s) != 40 && len(s) != 64 {
		return false
	}
	for _, c := range s {
		if (c < '0' || c > '9') && (c < 'a' || c > 'f') {
			return false
		}
	}
	return true
}

// missingObjects lists required objects (refs, reflogs, HEAD, every index
// stage and the pseudo-heads) that the repository cannot read locally.
func missingObjects(ctx context.Context, git gitFunc, gitDir string, extra []string) ([]string, error) {
	args := gitAt(gitDir, "rev-list", "--objects", "--missing=print", "--all", "--reflog", "--indexed-objects")
	out, err := git(ctx, append(args, extra...)...)
	if err != nil {
		return nil, err
	}
	var missing []string
	for _, line := range strings.Split(string(out), "\n") {
		if strings.HasPrefix(line, "?") {
			missing = append(missing, strings.TrimPrefix(line, "?"))
		}
	}
	return missing, nil
}

// copyGitMeta copies a git directory's metadata (refs, logs, config, index,
// HEADs, info, hooks…) skipping top-level names in skipTop, lock files and
// runtime sockets/fifos.
func copyGitMeta(src, dst string, skipTop map[string]bool) error {
	return filepath.WalkDir(src, func(p string, d fs.DirEntry, werr error) error {
		if werr != nil {
			return werr
		}
		rel, err := filepath.Rel(src, p)
		if err != nil {
			return err
		}
		if rel == "." {
			return os.MkdirAll(dst, 0o755)
		}
		top := strings.SplitN(filepath.ToSlash(rel), "/", 2)[0]
		if skipTop[top] {
			if d.IsDir() {
				return filepath.SkipDir
			}
			return nil
		}
		if strings.HasSuffix(d.Name(), ".lock") {
			return nil
		}
		target := filepath.Join(dst, rel)
		info, err := os.Lstat(p)
		if err != nil {
			return err
		}
		mode := info.Mode()
		switch {
		case mode.IsDir():
			return os.MkdirAll(target, mode.Perm()|0o700)
		case mode.IsRegular():
			return copyGitFile(p, target, mode.Perm())
		case mode&fs.ModeSymlink != 0:
			l, err := os.Readlink(p)
			if err != nil {
				return err
			}
			if err := os.Remove(target); err != nil && !errors.Is(err, fs.ErrNotExist) {
				return err
			}
			return os.Symlink(l, target)
		default:
			return nil // sockets/fifos (fsmonitor) are runtime artefacts
		}
	})
}

func copyGitFile(src, dst string, perm fs.FileMode) error {
	if err := os.Remove(dst); err != nil && !errors.Is(err, fs.ErrNotExist) {
		return err
	}
	in, err := os.Open(src)
	if err != nil {
		return err
	}
	defer in.Close()
	out, err := os.OpenFile(dst, os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o600)
	if err != nil {
		return err
	}
	if _, err := io.Copy(out, in); err != nil {
		out.Close()
		return err
	}
	if err := out.Close(); err != nil {
		return err
	}
	return os.Chmod(dst, perm)
}
