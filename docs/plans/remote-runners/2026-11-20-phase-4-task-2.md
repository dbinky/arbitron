# Remote Runners — Phase 4 Task 2: Durable turn lease

**Spec / Design references:** `docs/specs/2026-11-19-remote-runners-spec.md`; `docs/designs/2026-11-19-remote-runners-design-phase-4.md` (sections mapped below).


## Alignment correction — expiry is not recovery authority

Ordinary `Acquire` can acquire only a missing or explicitly released row. An occupied expired row returns `ErrInteractiveTurnInProgress`; it MUST NOT steal by `expires_at` or infer that a remote harness stopped. Replace the SQL `WHERE token IS NULL OR expires_at <= ?` with `WHERE token IS NULL`, keeping generation unchanged on clean reacquire; remove its unused time argument. The earlier expired-takeover implementation/tests are retired. Renewal loss cancels the local turn and prevents commit, but does not by itself prove a subprocess on another runner stopped.

Add engine `TurnLeaseRecoveryStore` with `RecoverTurnLease(ctx, old TurnLease, proof TurnRecoveryProof, ttl time.Duration) (TurnLease,error)`, where `TurnRecoveryProof{IntentID uuid.UUID; Adopted bool; Jobs []JobFenceRef; Resource *ResourceFenceRef}`. `sqlite.TurnLeaseRepo` implements it by a transaction that validates exact pending intent/current token/generation and matching job/resource records. P4 T10's controller is the sole caller/producer: adoption proof comes from `Hub.AdoptTurn` for the exact recorded job; replay proof requires confirmed runner loss/revocation or a durable stop acknowledgment and fenced old job/resource. It cannot be constructed from elapsed lease TTL alone. Adopting changes the server holder/token while preserving session/job/resource generation; replay after fencing reserves the next generation. Failed proof changes nothing. P4 T13 injects the same repo as `SessionRecoveryDeps.RecoveryLeases` and supplies TTL.

Add these named behavioral tests and observe red before changing Acquire/recovery SQL: Happy `TestTurnLease_AcquireReleasedAndRenew`; Success `TestTurnLease_AdoptExactLiveJobPreservesGeneration`; Failure `TestTurnLease_ExpiredButLiveOwnerRejectsSecondDispatch`; Error `TestTurnLease_RecoveryCASOrDBFailureLeavesOwnerUntouched`; Edge `TestTurnLease_RecoveryFencesBeforeGenerationChangeAndNeverAcceptsTTLOnlyProof`. Run `go test ./adapter/sqlite ./domain/engine ./domain/runner -run 'TurnLease|RecoveryLease' -race -count=1`. The expired-crash case now goes through RecoverTurnLease and a real persisted fence proof, not Acquire. P4 T13 root test restarts over one DB while fake remote harness remains running and asserts a single harness call/unchanged generation, then separately proves confirmed-loss replay.

**Goal:** Make a durable, renewable, generation-carrying turn lease the overlap guard so at most one interactive operation per session runs across server processes and runners (the process-local `turnInProgress sync.Map` survives only as the unwired fallback).

**Architecture:** `domain/engine/turn_lease.go` defines the port (`TurnLeaseStore`), key helpers, a context carrier (so a mover called mid-turn reuses the held lease instead of re-acquiring) and a private `turnLeaseHold` that renews every TTL/3 and cancels the turn's context (cause `ErrTurnLeaseLost`) if the lease is ever lost — so expiry can never let an overlapping turn commit beside a still-running one. `adapter/sqlite/turn_lease_repo.go` implements it with one atomic UPSERT (insert, or take over only a RELEASED row; an occupied row, expired or not, is refused) plus the proof-gated `RecoverTurnLease` transaction (Cycle 2b) that is the only way to reclaim an occupied row. `conversationHandler` (HandleMessage, EndSession, AbandonSession), `InteractiveExecutor.Execute` (first turn) and `GroupResolutionBridge.StartResolution` all acquire it. Without `SetTurnLeases` nothing changes from today: the handler keeps its in-process `turnInProgress` guard and the first turn / resolution startup run unguarded (legacy unit tests only; production wiring is P4 T13). Cross-task note: P4 T9 (`domain/engine/lease_holder.go`) replaces the HandleMessage guard with its `LeaseHolder` and relies on exactly this nil-store fallback; `RunLeaseKey` is declared HERE, so T9's `lease_holder.go` must reuse it rather than redeclare it.

**Tech Stack:** Go 1.25, SQLite UPSERT + RETURNING (modernc), `context.WithCancelCause`, testify.

**Spec / Design:** spec "Recovery and session continuity" (one active execution owner; concurrent submissions cannot create overlapping turns); design phase 4 §2 (Overlap guard row), §3.3, §6 (Turn lease is the only overlap guard), §7 (concurrent submission; mid-turn recovery must not deadlock on its own lease), §8 (Error: two concurrent submissions across two server processes; Edge: expired lease from a crashed holder is reclaimable; regression: renewal/expiry never overlaps turns). Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §17 (`TurnLease`, `TurnLeaseStore`), §1 (045 `turn_leases`), §2 (`TurnLeaseSeconds`).

// renewSpy wraps the memory store, counts renewals and can be told to lose the lease.
type renewSpy struct {
	TurnLeaseStore
	renewals atomic.Int32
	lose     atomic.Bool
	mu       sync.Mutex
	released []TurnLease
}

func (s *renewSpy) Renew(ctx context.Context, l TurnLease, ttl time.Duration) (TurnLease, error) {
	s.renewals.Add(1)
	if s.lose.Load() {
		return TurnLease{}, ErrTurnLeaseLost
	}
	return s.TurnLeaseStore.Renew(ctx, l, ttl)
}

func (s *renewSpy) Release(ctx context.Context, l TurnLease) error {
	s.mu.Lock()
	s.released = append(s.released, l)
	s.mu.Unlock()
	return s.TurnLeaseStore.Release(ctx, l)
}

package engine

import (
	"context"
	"errors"
	"fmt"
	"sync"
	"time"

	"github.com/arbitron/arbitron/domain/instance"
	"github.com/google/uuid"
)

// ErrInteractiveTurnInProgress is the unchanged overlap contract: the same
// sentinel the HTTP/MCP/WS surfaces already map to 409.
var ErrInteractiveTurnInProgress = instance.ErrInteractiveTurnInProgress

// ErrTurnLeaseLost means another holder took the lease (it expired while this
// holder could not renew). The holder must stop; its results are fenced.
var ErrTurnLeaseLost = errors.New("engine: turn lease lost to another holder")

// DefaultTurnLeaseTTL is the legacy default; production passes
// runners.turnleaseseconds.
const DefaultTurnLeaseTTL = 60 * time.Second

// TurnLease is the single-owner right to run one interactive operation on a
// session. Generation is the session generation: it grows on every move and on
// every takeover of an expired (crashed) holder, never on a clean re-acquire.
type TurnLease struct {
	Key        string // "run:<id>" or "resolution:<identity>"
	Token      uuid.UUID
	Generation int64
	ExpiresAt  time.Time
}

// TurnLeaseStore is the durable lease port.
type TurnLeaseStore interface {
	Acquire(ctx context.Context, key string, ttl time.Duration) (TurnLease, error)
	Renew(ctx context.Context, l TurnLease, ttl time.Duration) (TurnLease, error)
	Release(ctx context.Context, l TurnLease) error
	BumpGeneration(ctx context.Context, l TurnLease) (TurnLease, error)
	Current(ctx context.Context, key string) (TurnLease, bool, error)
}

// RunLeaseKey is the lease key of an ordinary interactive session.
func RunLeaseKey(runID uuid.UUID) string { return "run:" + runID.String() }

// ResolutionLeaseKey is the lease key of a group conflict-resolution session.
func ResolutionLeaseKey(id GroupResolutionIdentity) string {
	return fmt.Sprintf("resolution:%s/%d/%d", id.GroupRunID, id.MergeIndex, id.Attempt)
}

type turnLeaseCtxKey struct{}

// ContextWithTurnLease carries the held lease so a mover called inside the turn
// reuses it instead of acquiring recursively.
func ContextWithTurnLease(ctx context.Context, l TurnLease) context.Context {
	return context.WithValue(ctx, turnLeaseCtxKey{}, l)
}

// TurnLeaseFromContext returns the lease held by the current operation.
func TurnLeaseFromContext(ctx context.Context) (TurnLease, bool) {
	l, ok := ctx.Value(turnLeaseCtxKey{}).(TurnLease)
	return l, ok
}

// memoryTurnLeaseStore reproduces the pre-Phase-4 in-process guard. Leases
// never expire. Production always replaces it via SetTurnLeases.
type memoryTurnLeaseStore struct {
	mu     sync.Mutex
	held   map[string]TurnLease
	gens   map[string]int64
}

// NewMemoryTurnLeaseStore returns the in-process store (legacy unit tests only).
func NewMemoryTurnLeaseStore() TurnLeaseStore {
	return &memoryTurnLeaseStore{held: map[string]TurnLease{}, gens: map[string]int64{}}
}

func (s *memoryTurnLeaseStore) Acquire(_ context.Context, key string, ttl time.Duration) (TurnLease, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if _, busy := s.held[key]; busy {
		return TurnLease{}, fmt.Errorf("turn lease %s: %w", key, ErrInteractiveTurnInProgress)
	}
	gen := s.gens[key]
	if gen == 0 {
		gen = 1
		s.gens[key] = gen
	}
	l := TurnLease{Key: key, Token: uuid.New(), Generation: gen, ExpiresAt: time.Now().Add(ttl)}
	s.held[key] = l
	return l, nil
}

func (s *memoryTurnLeaseStore) Renew(_ context.Context, l TurnLease, ttl time.Duration) (TurnLease, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	cur, ok := s.held[l.Key]
	if !ok || cur.Token != l.Token {
		return TurnLease{}, ErrTurnLeaseLost
	}
	cur.ExpiresAt = time.Now().Add(ttl)
	s.held[l.Key] = cur
	return cur, nil
}

func (s *memoryTurnLeaseStore) Release(_ context.Context, l TurnLease) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	if cur, ok := s.held[l.Key]; ok && cur.Token == l.Token {
		delete(s.held, l.Key)
	}
	return nil
}

func (s *memoryTurnLeaseStore) BumpGeneration(_ context.Context, l TurnLease) (TurnLease, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	cur, ok := s.held[l.Key]
	if !ok || cur.Token != l.Token {
		return TurnLease{}, ErrTurnLeaseLost
	}
	s.gens[l.Key]++
	cur.Generation = s.gens[l.Key]
	s.held[l.Key] = cur
	return cur, nil
}

func (s *memoryTurnLeaseStore) Current(_ context.Context, key string) (TurnLease, bool, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	l, ok := s.held[key]
	return l, ok, nil
}

// turnLeaseHold owns one acquired lease for the duration of an operation: it
// renews every ttl/3 and cancels the operation's context (cause
// ErrTurnLeaseLost) the moment the lease is lost, so a holder that cannot
// prove ownership stops instead of committing beside a new owner.
type turnLeaseHold struct {
	store  TurnLeaseStore
	ttl    time.Duration
	cancel context.CancelCauseFunc
	stop   chan struct{}
	done   chan struct{}
	once   sync.Once
	local  func() // non-nil => no store: no lease, no renewal; Release runs local once

	mu    sync.Mutex
	lease TurnLease
}

// localTurnHold is the hold used when no lease store is wired (legacy tests):
// no token, generation 0, no renewal; Release runs release once.
func localTurnHold(key string, release func()) *turnLeaseHold {
	return &turnLeaseHold{local: release, lease: TurnLease{Key: key}}
}

// holdTurnLease acquires key and starts renewal. A nil store (SetTurnLeases
// never called) yields a local no-op hold: pre-Phase-4 behaviour.
func holdTurnLease(ctx context.Context, store TurnLeaseStore, key string, ttl time.Duration) (context.Context, *turnLeaseHold, error) {
	if store == nil {
		return ctx, localTurnHold(key, func() {}), nil
	}
	l, err := store.Acquire(ctx, key, ttl)
	if err != nil {
		return ctx, nil, err
	}
	turnCtx, cancel := context.WithCancelCause(ctx)
	h := &turnLeaseHold{store: store, ttl: ttl, cancel: cancel, stop: make(chan struct{}), done: make(chan struct{}), lease: l}
	go h.renewLoop(turnCtx)
	return ContextWithTurnLease(turnCtx, l), h, nil
}

func (h *turnLeaseHold) renewLoop(ctx context.Context) {
	defer close(h.done)
	interval := h.ttl / 3
	if interval <= 0 {
		interval = time.Millisecond
	}
	ticker := time.NewTicker(interval)
	defer ticker.Stop()
	for {
		select {
		case <-h.stop:
			return
		case <-ctx.Done():
			return
		case <-ticker.C:
		}
		cur := h.Lease()
		rctx, cancel := context.WithTimeout(context.WithoutCancel(ctx), interval)
		renewed, err := h.store.Renew(rctx, cur, h.ttl)
		cancel()
		switch {
		case err == nil:
			h.mu.Lock()
			h.lease = renewed
			h.mu.Unlock()
		case errors.Is(err, ErrTurnLeaseLost):
			h.cancel(ErrTurnLeaseLost)
			return
		default:
			// A transient store error: keep the turn only while the lease we
			// last proved is unexpired; past it another holder may own it.
			if !time.Now().Before(cur.ExpiresAt) {
				h.cancel(ErrTurnLeaseLost)
				return
			}
		}
	}
}

// Lease returns the currently held lease (renewals refresh ExpiresAt).
func (h *turnLeaseHold) Lease() TurnLease {
	h.mu.Lock()
	defer h.mu.Unlock()
	return h.lease
}

// Release stops renewal and releases the lease. Idempotent.
func (h *turnLeaseHold) Release() {
	if h.local != nil {
		h.once.Do(h.local)
		return
	}
	h.once.Do(func() {
		close(h.stop)
		<-h.done
		ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
		defer cancel()
		_ = h.store.Release(ctx, h.Lease())
		h.cancel(nil)
	})
}

// turnLeaseErr re-labels a turn failure caused by a lost lease so callers can
// tell "fenced" from an ordinary provider error.
func turnLeaseErr(ctx context.Context, err error) error {
	if err == nil {
		return nil
	}
	if cause := context.Cause(ctx); errors.Is(cause, ErrTurnLeaseLost) && !errors.Is(err, ErrTurnLeaseLost) {
		return fmt.Errorf("%w: %v", ErrTurnLeaseLost, err)
	}
	return err
}

import (

// TurnLeaseRepo implements engine.TurnLeaseStore over the turn_leases table
// (migration 045). Hand-written SQL. expires_at is unix milliseconds.
type TurnLeaseRepo struct {
	db     *sql.DB
	holder string
	now    func() time.Time
}

// NewTurnLeaseRepo creates the lease repo. holder identifies this process in
// the row (diagnostics only; ownership is the token).
func NewTurnLeaseRepo(db *sql.DB, holder string) *TurnLeaseRepo {
	return &TurnLeaseRepo{db: db, holder: holder, now: time.Now}
}

// SetClock replaces the clock (tests).
func (r *TurnLeaseRepo) SetClock(now func() time.Time) { r.now = now }

// Acquire inserts the lease or takes over a RELEASED row in one statement. An
// occupied row is never stolen, even when expires_at has passed: expiry alone
// does not prove the holder (possibly a remote harness) stopped. Reclaiming an
// occupied expired row goes only through RecoverTurnLease with a durable proof
// (P4 T10). A clean re-acquire keeps the generation.
func (r *TurnLeaseRepo) Acquire(ctx context.Context, key string, ttl time.Duration) (engine.TurnLease, error) {
	if ttl <= 0 {
		return engine.TurnLease{}, fmt.Errorf("turn lease %s: ttl must be positive", key)
	}
	now := r.now().UTC()
	token := uuid.New()
	exp := now.Add(ttl)
	var gen int64
	err := r.db.QueryRowContext(ctx, `INSERT INTO turn_leases (key, token, generation, expires_at, holder)
VALUES (?, ?, 1, ?, ?)
ON CONFLICT(key) DO UPDATE SET
    token      = excluded.token,
    expires_at = excluded.expires_at,
    holder     = excluded.holder
WHERE turn_leases.token IS NULL
RETURNING generation`, key, token.String(), exp.UnixMilli(), r.holder).Scan(&gen)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, fmt.Errorf("turn lease %s: %w", key, engine.ErrInteractiveTurnInProgress)
	}
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("acquiring turn lease %s: %w", key, err)
	}
	return engine.TurnLease{Key: key, Token: token, Generation: gen, ExpiresAt: time.UnixMilli(exp.UnixMilli()).UTC()}, nil
}

// Renew extends the lease iff the token still owns it (even past expiry, as
// long as nobody took it over).
func (r *TurnLeaseRepo) Renew(ctx context.Context, l engine.TurnLease, ttl time.Duration) (engine.TurnLease, error) {
	exp := r.now().UTC().Add(ttl)
	var gen int64
	err := r.db.QueryRowContext(ctx, `UPDATE turn_leases SET expires_at = ? WHERE key = ? AND token = ? RETURNING generation`,
		exp.UnixMilli(), l.Key, l.Token.String()).Scan(&gen)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, engine.ErrTurnLeaseLost
	}
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("renewing turn lease %s: %w", l.Key, err)
	}
	l.ExpiresAt = time.UnixMilli(exp.UnixMilli()).UTC()
	l.Generation = gen
	return l, nil
}

// Release frees the lease iff the token still owns it; otherwise a no-op.
func (r *TurnLeaseRepo) Release(ctx context.Context, l engine.TurnLease) error {
	if _, err := r.db.ExecContext(ctx, `UPDATE turn_leases SET token = NULL, expires_at = 0, holder = '' WHERE key = ? AND token = ?`,
		l.Key, l.Token.String()); err != nil {
		return fmt.Errorf("releasing turn lease %s: %w", l.Key, err)
	}
	return nil
}

// BumpGeneration reserves the next session generation under the held lease.
func (r *TurnLeaseRepo) BumpGeneration(ctx context.Context, l engine.TurnLease) (engine.TurnLease, error) {
	var gen, exp int64
	err := r.db.QueryRowContext(ctx, `UPDATE turn_leases SET generation = generation + 1 WHERE key = ? AND token = ? RETURNING generation, expires_at`,
		l.Key, l.Token.String()).Scan(&gen, &exp)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, engine.ErrTurnLeaseLost
	}
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("bumping turn lease %s: %w", l.Key, err)
	}
	l.Generation = gen
	l.ExpiresAt = time.UnixMilli(exp).UTC()
	return l, nil
}

// Current returns the held lease for key, if any (possibly expired).
func (r *TurnLeaseRepo) Current(ctx context.Context, key string) (engine.TurnLease, bool, error) {
	var tok string
	var gen, exp int64
	err := r.db.QueryRowContext(ctx, `SELECT token, generation, expires_at FROM turn_leases WHERE key = ? AND token IS NOT NULL`, key).
		Scan(&tok, &gen, &exp)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, false, nil
	}
	if err != nil {
		return engine.TurnLease{}, false, fmt.Errorf("reading turn lease %s: %w", key, err)
	}
	token, err := parseUUID(tok)
	if err != nil {
		return engine.TurnLease{}, false, err
	}
	return engine.TurnLease{Key: key, Token: token, Generation: gen, ExpiresAt: time.UnixMilli(exp).UTC()}, true, nil
}

5. **Replay:** one or more jobs, none of them live at its fence. No live job may remain for the intent's run, invocation and operation. A resource, if present, must no longer be active at that token. The result is a new token at generation+1.
6. A proof with no jobs and no resource is `ErrTurnRecoveryProofInvalid`; elapsed TTL is never proof.
7. Any failed check changes nothing.

// ErrTurnRecoveryProofInvalid rejects a recovery proof that does not establish
// adoption of the exact live owner or a fenced, stopped previous owner.
var ErrTurnRecoveryProofInvalid = errors.New("engine: turn recovery proof is invalid")

// TurnRecoveryProof is built ONLY by P4 T10's TurnRecoveryCoordinator from
// durable job/resource/stop records. Elapsed TTL is never part of it.
type TurnRecoveryProof struct {
	IntentID uuid.UUID
	Adopted  bool
	Jobs     []JobFenceRef
	Resource *ResourceFenceRef
}

// Validate checks the proof's shape; the store re-checks every fact in SQL.
func (p TurnRecoveryProof) Validate() error {
	if p.IntentID == uuid.Nil {
		return fmt.Errorf("%w: no intent", ErrTurnRecoveryProofInvalid)
	}
	if len(p.Jobs) == 0 {
		return fmt.Errorf("%w: no job evidence (expiry alone is not proof)", ErrTurnRecoveryProofInvalid)
	}
	if p.Adopted && len(p.Jobs) != 1 {
		return fmt.Errorf("%w: adoption names exactly one live job", ErrTurnRecoveryProofInvalid)
	}
	for _, j := range p.Jobs {
		if j.JobID == uuid.Nil || j.RunnerID == "" || j.Generation < 1 {
			return fmt.Errorf("%w: incomplete job fence", ErrTurnRecoveryProofInvalid)
		}
	}
	if p.Resource != nil {
		if err := p.Resource.Validate(); err != nil {
			return fmt.Errorf("%w: %v", ErrTurnRecoveryProofInvalid, err)
		}
	}
	return nil
}

// TurnLeaseRecoveryStore reclaims an occupied lease from durable proof only.
// Adoption keeps the generation; replay reserves the next one.
type TurnLeaseRecoveryStore interface {
	RecoverTurnLease(ctx context.Context, old TurnLease, proof TurnRecoveryProof, ttl time.Duration) (TurnLease, error)
}

package sqlite

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"strings"
	"time"

	"github.com/arbitron/arbitron/domain/engine"
	"github.com/google/uuid"

var _ engine.TurnLeaseRecoveryStore = (*TurnLeaseRepo)(nil)

func invalidProof(format string, args ...any) error {
	return fmt.Errorf("%w: "+format, append([]any{engine.ErrTurnRecoveryProofInvalid}, args...)...)
}

// turnOperationMatches: equality or a sub-operation ("turn/1/stream"); never turn/1 vs turn/10.
func turnOperationMatches(jobOp, intentOp string) bool {
	return jobOp == intentOp || strings.HasPrefix(jobOp, intentOp+"/")
}

// RecoverTurnLease validates the proof against the durable intent, job and
// resource records and swaps the lease token in ONE transaction. A failed
// check changes nothing.
func (r *TurnLeaseRepo) RecoverTurnLease(ctx context.Context, old engine.TurnLease, p engine.TurnRecoveryProof, ttl time.Duration) (engine.TurnLease, error) {
	if ttl <= 0 {
		return engine.TurnLease{}, fmt.Errorf("turn lease %s: ttl must be positive", old.Key)
	}
	if err := p.Validate(); err != nil {
		return engine.TurnLease{}, err
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: %w", old.Key, err)
	}
	defer func() { _ = tx.Rollback() }()

	var tok sql.NullString
	var gen int64
	err = tx.QueryRowContext(ctx, `SELECT token, generation FROM turn_leases WHERE key = ?`, old.Key).Scan(&tok, &gen)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, engine.ErrTurnLeaseLost
	}
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: %w", old.Key, err)
	}
	if !tok.Valid || tok.String != old.Token.String() || gen != old.Generation {
		return engine.TurnLease{}, engine.ErrTurnLeaseLost
	}

	var runID, invocationID, opID string
	var intentGen int64
	err = tx.QueryRowContext(ctx, `SELECT run_id, invocation_id, operation_id, session_generation FROM turn_intents
WHERE id = ? AND lease_key = ? AND completed_at IS NULL`, p.IntentID.String(), old.Key).Scan(&runID, &invocationID, &opID, &intentGen)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.TurnLease{}, invalidProof("intent %s is not pending on %s", p.IntentID, old.Key)
	}
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: intent: %w", old.Key, err)
	}
	if intentGen != old.Generation {
		return engine.TurnLease{}, invalidProof("intent %s was accepted at generation %d, lease is at %d", p.IntentID, intentGen, old.Generation)
	}

	for _, j := range p.Jobs {
		var jRun, jInv, jOp, state string
		var jRunner sql.NullString
		var jGen int64
		err := tx.QueryRowContext(ctx, `SELECT run_id, invocation_id, operation_id, runner_id, generation, state FROM runner_jobs WHERE id = ?`,
			j.JobID.String()).Scan(&jRun, &jInv, &jOp, &jRunner, &jGen, &state)
		if errors.Is(err, sql.ErrNoRows) {
			return engine.TurnLease{}, invalidProof("job %s does not exist", j.JobID)
		}
		if err != nil {
			return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: job %s: %w", old.Key, j.JobID, err)
		}
		if jRun != runID || jInv != invocationID || !turnOperationMatches(jOp, opID) {
			return engine.TurnLease{}, invalidProof("job %s belongs to another operation (%s)", j.JobID, jOp)
		}
		live := (state == "offered" || state == "running") && jRunner.String == j.RunnerID && jGen == j.Generation
		if p.Adopted && !live {
			return engine.TurnLease{}, invalidProof("job %s is not live at generation %d", j.JobID, j.Generation)
		}
		if !p.Adopted && live {
			return engine.TurnLease{}, invalidProof("job %s is still live; fence it before replay", j.JobID)
		}
	}
	if !p.Adopted {
		rows, err := tx.QueryContext(ctx, `SELECT operation_id FROM runner_jobs WHERE run_id = ? AND invocation_id = ? AND state IN ('offered', 'running')`,
			runID, invocationID)
		if err != nil {
			return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: live jobs: %w", old.Key, err)
		}
		var liveOp string
		for rows.Next() {
			var op string
			if err := rows.Scan(&op); err != nil {
				rows.Close()
				return engine.TurnLease{}, err
			}
			if turnOperationMatches(op, opID) {
				liveOp = op
			}
		}
		if err := rows.Close(); err != nil {
			return engine.TurnLease{}, err
		}
		if liveOp != "" {
			return engine.TurnLease{}, invalidProof("operation %s still has a live job", liveOp)
		}
	}
	if p.Resource != nil {
		var active int
		var rGen int64
		var rTok string
		err := tx.QueryRowContext(ctx, `SELECT active, generation, token FROM workspace_leases WHERE resource_key = ?`, p.Resource.Key).
			Scan(&active, &rGen, &rTok)
		if err != nil && !errors.Is(err, sql.ErrNoRows) {
			return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: resource: %w", old.Key, err)
		}
		held := err == nil && active == 1 && rGen == p.Resource.Generation && rTok == p.Resource.Token.String()
		if p.Adopted && !held {
			return engine.TurnLease{}, invalidProof("resource %s is no longer held by the adopted job", p.Resource.Key)
		}
		if !p.Adopted && held {
			return engine.TurnLease{}, invalidProof("resource %s is still owned; supersede it before replay", p.Resource.Key)
		}
	}

	next := gen
	if !p.Adopted {
		next = gen + 1
	}
	token := uuid.New()
	exp := r.now().UTC().Add(ttl)
	res, err := tx.ExecContext(ctx, `UPDATE turn_leases SET token = ?, generation = ?, expires_at = ?, holder = ?
WHERE key = ? AND token = ? AND generation = ?`, token.String(), next, exp.UnixMilli(), r.holder, old.Key, old.Token.String(), old.Generation)
	if err != nil {
		return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: %w", old.Key, err)
	}
	if n, _ := res.RowsAffected(); n != 1 {
		return engine.TurnLease{}, engine.ErrTurnLeaseLost
	}
	if err := tx.Commit(); err != nil {
		return engine.TurnLease{}, fmt.Errorf("recovering turn lease %s: commit: %w", old.Key, err)
	}
	return engine.TurnLease{Key: old.Key, Token: token, Generation: next, ExpiresAt: time.UnixMilli(exp.UnixMilli()).UTC()}, nil
}

#### Cycle 2c — stale-holder proof for a crash before dispatch (boot ID)

**Decided (user, 2026-11-23):** this covers a server crash after an intent is persisted but before any job is dispatched, while the lease is still held. Recovery uses a **boot-ID stale-holder proof**. Every server process creates one boot ID at startup (`uuid.NewString()`). It is the same value P3 T13 passes to `NewResourceLeaseRepo(db, bootID)`, as in contracts §25 `server_restart` and design D7 (restart = built-in runner loss). `TurnLeaseRepo` records it on every acquire. `RecoverTurnLease` accepts `TurnRecoveryProof{StaleHolder: true}` only when all of these hold:
- the proof names no job and no resource (and is not an adoption);
- the stored holder boot ID is non-empty;
- the recovering repo's boot ID is non-empty;
- the two boot IDs differ;
- the intent's operation has no `runner_jobs` row at all. A dispatched job must use the Cycle 2b job proof.

On success the repo issues a new token at generation+1 with the current boot ID. A same-boot holder is refused, because it is this process's own live turn. A missing boot ID on either side is refused. Elapsed TTL still never counts. P4 T10 Cycle 4 is the only caller. P4 T13 wires the shared boot ID.

**Prerequisite:** Cycle 2b.

// acquireTurn takes the session's turn lease (after the auth/state gate). The
// returned context is cancelled if the lease is lost; release with hold.Release.
func (h *conversationHandler) acquireTurn(ctx context.Context, instanceID uuid.UUID, group *groupSessionTarget) (context.Context, *turnLeaseHold, error) {
	if h.leases == nil {
		// Unwired fallback: the pre-Phase-4 single-process guard.
		if _, inFlight := h.turnInProgress.LoadOrStore(instanceID, struct{}{}); inFlight {
			return ctx, nil, fmt.Errorf("conversation: instance %s: %w", instanceID, instance.ErrInteractiveTurnInProgress)
		}
		return ctx, localTurnHold(sessionLeaseKey(instanceID, group), func() { h.turnInProgress.Delete(instanceID) }), nil
	}
	turnCtx, hold, err := holdTurnLease(ctx, h.leases, sessionLeaseKey(instanceID, group), h.leaseTTL)
	if errors.Is(err, ErrInteractiveTurnInProgress) {
		return ctx, nil, fmt.Errorf("conversation: instance %s: %w", instanceID, instance.ErrInteractiveTurnInProgress)
	}
	if err != nil {
		return ctx, nil, fmt.Errorf("conversation: instance %s: acquire turn lease: %w", instanceID, err)
	}
	return turnCtx, hold, nil
}
