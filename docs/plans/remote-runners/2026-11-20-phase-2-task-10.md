**Goal:** The production `arbitron` server builds the Phase 2 runner components and runs them. It constructs:
- the runner-key service;
- the connection hub;
- the remote `StepRunner` and the hub-backed runner set that replaces Phase 1's static set;
- the runner connect endpoint;
- the built-in telemetry loop.

All of these are wired into the dispatcher, the operator service, REST, MCP and the runtime lifecycle.

Three things are proven through the real composition root, with an in-memory runner agent connected over a real WebSocket:
- chat steps spread across the built-in runner and remote runners;
- a lost runner's step is re-placed with generation + 1, and its late result is fenced;
- a server with zero runner keys still runs everything locally.

**Architecture:**
- **Wiring function.** `cmd/arbitron/runner_remote_wiring.go:wireRemoteRunners` is the only place that builds the Phase 2 server objects. Its inputs are the Phase 1 locals: registry, ledger, event recorder, health monitor, pool notifier and built-in runner (built by P1 T16).
- **Call site and storage.** `initDomainWithModelDependencies` calls it between the health monitor and the dispatcher. It stores the result on `domainStack.remote`, which `httpDeps`, `mcpDeps` and `startRuntime` read.
- **Monitor change.** The Phase 1 health monitor is changed in one place: it no longer runs this host's read-only probers against sources owned by remote runners. Their health arrives in heartbeats (P2 T4).

**Tech Stack:** Go 1.25.5, chi router (existing), `nhooyr.io/websocket` v1.8.17 (through the P2 T9 `wsclient`), SQLite (existing), testify.

**Decisions:**
1. **The built-in telemetry loop measures disk on the server execution root.** It uses `telemetry.NewForRoot(wsMgr.BasePath())` instead of contracts §15's `telemetry.New()`. `New()` is `NewForRoot(<process working dir>)` (P2 T7). The root form reports free disk for the volume that holds workspaces, which is the value placement and the dashboard need. The constructor is otherwise identical.
2. **The compatibility table comes from the published floors.** `Harness["claude"]` and `Harness["codex"]` are each the published `SupportedVersions` `Min` that passes that package's own `CheckVersion`. Only the highest floor passes every floor. Use contracts §21: server vM.m.p admits `[vM.m.p, vM.(m+1).0)` with the same protocol/capability epoch; unstamped builds remain visible incompatible. No empty minimum/development bypass is accepted. The protocol range is exactly `runnerproto.ProtocolVersion`.
3. **The health monitor skips local probes for remote sources only.**
   - Periodic local `probe` skips a source owned by another runner. Operator-forced probing uses the remote transport and the common observation merger (P2 T13).
   - `advance` (reset → probation, congestion expiry, confirmation) still runs for every source.
   - `ProbeNow` on a remote source requests and awaits a fresh correlated probe through P2 T13; cached heartbeat data is not a successful operator check.
4. **The remote set is wrapped in the existing health-reporting decorator.** `HubRunnerSet` is wrapped in `NewHealthReportingRunnerSet(…, monitor)`, so a successful remote step clears probation on its remote source, exactly as built-in successes do.
5. **The hub starts before crash recovery.** `startRuntime` calls `ds.remote.Hub.Start(ctx)` right after the queue scheduler starts and before `RecoverCrashedInstancesContext`. Recovered steps placed on a remote runner are then supervised by liveness ticks. The built-in telemetry loop starts at the same point.
6. **Call site.** P1 T16 builds the pool inside `cmd/arbitron/runner_wiring.go:newRunnerStack(d runnerStackDeps) *runnerStack`, whose locals are `ledger`, `recorder`, `notifier`, `monitor`, `builtin`, `dispatcher` and `service`; `main.go` calls it as `runnerPool := newRunnerStack(runnerStackDeps{…})`. This task therefore (a) adds `ServerRoot string` and `Logger *slog.Logger` to `runnerStackDeps`, (b) calls `wireRemoteRunners` inside `newRunnerStack` right after `builtin := builtinrunner.New(…)`, (c) adds the field `remote *remoteRunnerStack` to `runnerStack`, (d) changes the signature to `func newRunnerStack(d runnerStackDeps) (*runnerStack, error)` and the `main.go` call site to `runnerPool, err := newRunnerStack(…)` with `if err != nil { return nil, fmt.Errorf("building runner pool: %w", err) }`, and (e) stores `remote: runnerPool.remote` on `domainStack`. Later phases read the remote stack as `runnerPool.remote` (inside `initDomainWithModelDependencies`) and `ds.remote` (on the domain stack).
7. **`adapter/http/server.go` is not modified here.** P2 T5 owns adding `RouterDeps.RunnerConnect` and mounting it outside user auth. `http.Server` already has `WriteTimeout: 0`, and `net/http` clears the `ReadTimeout` deadline on hijack, so long-lived runner sockets need no server change. This task's contract tests fail if the mount is missing: the agent never comes online, and `/api/v1/runners/connect` answers 404 instead of 401.

// remoteCompatTable is the server's admission table: exactly this protocol
// version, the release range from main.version, and the published harness floors.
func remoteCompatTable() (runner.CompatTable, error) {
	claudeMins := make([]string, 0, len(claudecli.SupportedVersions))
	for _, f := range claudecli.SupportedVersions {
		claudeMins = append(claudeMins, f.Min)
	}
	codexMins := make([]string, 0, len(codex.SupportedVersions))
	for _, f := range codex.SupportedVersions {
		codexMins = append(codexMins, f.Min)
	}
	claude := harnessFloor(claudeMins, claudecli.CheckVersion)
	cdx := harnessFloor(codexMins, codex.CheckVersion)
	if claude == "" || cdx == "" {
		return runner.CompatTable{}, fmt.Errorf("remote runners: no harness floor satisfies its own version table (claude %q, codex %q)", claude, cdx)
	}
	minRunner, maxRunner := runner.ReleaseRunnerRange(version)
	return runner.CompatTable{
		ProtocolMin: runnerproto.ProtocolVersion,
		ProtocolMax: runnerproto.ProtocolVersion,
		RunnerMin:   minRunner,
		RunnerMaxExclusive: maxRunner,
		Harness:     map[string]string{"claude": claude, "codex": cdx},
	}, nil
}

// harnessFloor returns the published Min that passes the package's own
// CheckVersion; only the highest floor passes every floor. "" when none does.
func harnessFloor(mins []string, check func(string) (bool, string)) string {
	for _, m := range mins {
		if ok, _ := check(m); ok {
			return m
		}
	}
	return ""
}

// rrExecutor is the remote runner's JobExecutor. It honours the dispatch it
// is given (records it, answers with the dispatched model) and, when block is
// set, finishes only on release — ignoring ctx on purpose, like a partitioned
// machine that completes its work late.
type rrExecutor struct {
	answer      string
	block       bool
	started     chan runneragent.Dispatch
	release     chan struct{}
	once        sync.Once
	mu          sync.Mutex
	inflight    int
	maxInflight int
	got         []runneragent.Dispatch
}

func newRRExecutor(t *testing.T, answer string, block bool) *rrExecutor {
	t.Helper()
	e := &rrExecutor{answer: answer, block: block, started: make(chan runneragent.Dispatch, 32), release: make(chan struct{})}
	t.Cleanup(e.releaseAll)
	return e
}

func (e *rrExecutor) releaseAll() { e.once.Do(func() { close(e.release) }) }

func (e *rrExecutor) Supports(d runneragent.Dispatch) (bool, string) {
	if d.Op != runneragent.OpChat || d.Chat == nil {
		return false, "rr test executor runs chat only"
	}
	return true, ""
}

func (e *rrExecutor) Execute(_ context.Context, d runneragent.Dispatch, _ runneragent.EmitFunc) runneragent.Result {
	e.mu.Lock()
	e.inflight++
	if e.inflight > e.maxInflight {
		e.maxInflight = e.inflight
	}
	e.got = append(e.got, d)
	e.mu.Unlock()
	defer func() {
		e.mu.Lock()
		e.inflight--
		e.mu.Unlock()
	}()
	e.started <- d
	if e.block {
		<-e.release
	}
	return runneragent.Result{OK: true, Chat: &runneragent.ChatResult{
		Output: e.answer, Model: d.Chat.Model, SessionID: "rr", TokensIn: 1, TokensOut: 1}}
}

func (e *rrExecutor) count() int {
	e.mu.Lock()
	defer e.mu.Unlock()
	return len(e.got)
}

func (e *rrExecutor) peak() int {
	e.mu.Lock()
	defer e.mu.Unlock()
	return e.maxInflight
}

func rrAwaitDispatch(t *testing.T, e *rrExecutor) runneragent.Dispatch {
	t.Helper()
	select {
	case d := <-e.started:
		return d
	case <-time.After(30 * time.Second):
		t.Fatal("the remote runner never received a dispatch")
		return runneragent.Dispatch{}
	}
}

// rrConn wraps the real wsclient connection: it records every server message
// and can cut the live socket and hold redials (connection-kill chaos).
type rrConn struct {
	inner runneragent.Connection
	mu    sync.Mutex
	gate  chan struct{}
	cur   runneragent.Session
	seen  []rrInbound
}

func newRRConn(inner runneragent.Connection) *rrConn {
	gate := make(chan struct{})
	close(gate)
	return &rrConn{inner: inner, gate: gate}
}

func (c *rrConn) Dial(ctx context.Context) (runneragent.Session, error) {
	c.mu.Lock()
	gate := c.gate
	c.mu.Unlock()
	select {
	case <-gate:
	case <-ctx.Done():
		return nil, ctx.Err()
	}
	s, err := c.inner.Dial(ctx)
	if err != nil {
		return nil, err
	}
	rs := &rrSession{Session: s, c: c}
	c.mu.Lock()
	c.cur = rs
	c.mu.Unlock()
	return rs, nil
}

// cut closes the live socket and blocks redials until allow.
func (c *rrConn) cut() {
	c.mu.Lock()
	c.gate = make(chan struct{})
	s := c.cur
	c.cur = nil
	c.mu.Unlock()
	if s != nil {
		_ = s.Close()
	}
}

func (c *rrConn) allow() {
	c.mu.Lock()
	defer c.mu.Unlock()
	close(c.gate)
}

func (c *rrConn) received(kind, jobID string, gen int64) bool {
	c.mu.Lock()
	defer c.mu.Unlock()
	for _, in := range c.seen {
		if in.Kind == kind && in.JobID == jobID && in.Generation == gen {
			return true
		}
	}
	return false
}

type rrSession struct {
	runneragent.Session
	c *rrConn
}

func (s *rrSession) Recv(ctx context.Context) (runneragent.Inbound, error) {
	in, err := s.Session.Recv(ctx)
	if err == nil {
		s.c.mu.Lock()
		s.c.seen = append(s.c.seen, rrInbound{Kind: in.Kind, JobID: in.JobID, Generation: in.Generation})
		s.c.mu.Unlock()
	}
	return in, err
}
