**Goal:** The production `arbitron` server builds the Phase 2 runner components and runs them. It constructs:
- the runner-key service;
- the connection hub;
- the remote `StepRunner` and the hub-backed runner set that replaces Phase 1's static set;
- the runner connect endpoint;
- the built-in telemetry loop.

All of these are wired into the dispatcher, the operator service, REST, MCP and the runtime lifecycle.

Three things are proven through the real composition root, with an in-memory runner agent connected over a real WebSocket:
- chat steps spread across the built-in runner and remote runners;
- a lost runner's step is re-placed with generation + 1, and its late result is fenced;
- a server with zero runner keys still runs everything locally.

**Architecture:**
- **Wiring function.** `cmd/arbitron/runner_remote_wiring.go:wireRemoteRunners` is the only place that builds the Phase 2 server objects. Its inputs are the Phase 1 locals: registry, ledger, event recorder, health monitor, pool notifier and built-in runner (built by P1 T16).
- **Call site and storage.** `initDomainWithModelDependencies` calls it between the health monitor and the dispatcher. It stores the result on `domainStack.remote`, which `httpDeps`, `mcpDeps` and `startRuntime` read.
- **Monitor change.** The Phase 1 health monitor is changed in one place: it no longer runs this host's read-only probers against sources owned by remote runners. Their health arrives in heartbeats (P2 T4).

**Tech Stack:** Go 1.25.5, chi router (existing), `nhooyr.io/websocket` v1.8.17 (through the P2 T9 `wsclient`), SQLite (existing), testify.

**Decisions:**
1. **The built-in telemetry loop measures disk on the server execution root.** It uses `telemetry.NewForRoot(wsMgr.BasePath())` instead of contracts §15's `telemetry.New()`. `New()` is `NewForRoot(<process working dir>)` (P2 T7). The root form reports free disk for the volume that holds workspaces, which is the value placement and the dashboard need. The constructor is otherwise identical.
2. **The compatibility table comes from the published floors.** `Harness["claude"]` and `Harness["codex"]` are each the published `SupportedVersions` `Min` that passes that package's own `CheckVersion`. Only the highest floor passes every floor. `RunnerMin` is `""`, as decided in P2 T4: there is no runner release floor yet, and unstamped development builds stay admissible. The protocol range is exactly `runnerproto.ProtocolVersion`.
3. **The health monitor skips local probes for remote sources only.**
   - `probe` returns the stored health unchanged for a source whose `RunnerID` is neither `""` nor `BuiltInRunnerID`.
   - `advance` (reset → probation, congestion expiry, confirmation) still runs for every source.
   - `ProbeNow` on a remote source returns its last heartbeat-reported health.
4. **The remote set is wrapped in the existing health-reporting decorator.** `HubRunnerSet` is wrapped in `NewHealthReportingRunnerSet(…, monitor)`, so a successful remote step clears probation on its remote source, exactly as built-in successes do.
5. **The hub starts before crash recovery.** `startRuntime` calls `ds.remote.Hub.Start(ctx)` right after the queue scheduler starts and before `RecoverCrashedInstancesContext`. Recovered steps placed on a remote runner are then supervised by liveness ticks. The built-in telemetry loop starts at the same point.
6. **Call site.** P1 T16 builds the pool inside `cmd/arbitron/runner_wiring.go:newRunnerStack(d runnerStackDeps) *runnerStack`, whose locals are `ledger`, `recorder`, `notifier`, `monitor`, `builtin`, `dispatcher` and `service`; `main.go` calls it as `runnerPool := newRunnerStack(runnerStackDeps{…})`. This task therefore (a) adds `ServerRoot string` and `Logger *slog.Logger` to `runnerStackDeps`, (b) calls `wireRemoteRunners` inside `newRunnerStack` right after `builtin := builtinrunner.New(…)`, (c) adds the field `remote *remoteRunnerStack` to `runnerStack`, (d) changes the signature to `func newRunnerStack(d runnerStackDeps) (*runnerStack, error)` and the `main.go` call site to `runnerPool, err := newRunnerStack(…)` with `if err != nil { return nil, fmt.Errorf("building runner pool: %w", err) }`, and (e) stores `remote: runnerPool.remote` on `domainStack`. Later phases read the remote stack as `runnerPool.remote` (inside `initDomainWithModelDependencies`) and `ds.remote` (on the domain stack).
7. **`adapter/http/server.go` is not modified here.** P2 T5 owns adding `RouterDeps.RunnerConnect` and mounting it outside user auth. `http.Server` already has `WriteTimeout: 0`, and `net/http` clears the `ReadTimeout` deadline on hijack, so long-lived runner sockets need no server change. This task's contract tests fail if the mount is missing: the agent never comes online, and `/api/v1/runners/connect` answers 404 instead of 401.

// rrConn wraps the real wsclient connection: it records every server message
// and can cut the live socket and hold redials (connection-kill chaos).
type rrConn struct {
	inner runneragent.Connection
	mu    sync.Mutex
	gate  chan struct{}
	cur   runneragent.Session
	seen  []rrInbound
}

func newRRConn(inner runneragent.Connection) *rrConn {
	gate := make(chan struct{})
	close(gate)
	return &rrConn{inner: inner, gate: gate}
}

func (c *rrConn) Dial(ctx context.Context) (runneragent.Session, error) {
	c.mu.Lock()
	gate := c.gate
	c.mu.Unlock()
	select {
	case <-gate:
	case <-ctx.Done():
		return nil, ctx.Err()
	}
	s, err := c.inner.Dial(ctx)
	if err != nil {
		return nil, err
	}
	rs := &rrSession{Session: s, c: c}
	c.mu.Lock()
	c.cur = rs
	c.mu.Unlock()
	return rs, nil
}

// cut closes the live socket and blocks redials until allow.
func (c *rrConn) cut() {
	c.mu.Lock()
	c.gate = make(chan struct{})
	s := c.cur
	c.cur = nil
	c.mu.Unlock()
	if s != nil {
		_ = s.Close()
	}
}

func (c *rrConn) allow() {
	c.mu.Lock()
	defer c.mu.Unlock()
	close(c.gate)
}

func (c *rrConn) received(kind, jobID string, gen int64) bool {
	c.mu.Lock()
	defer c.mu.Unlock()
	for _, in := range c.seen {
		if in.Kind == kind && in.JobID == jobID && in.Generation == gen {
			return true
		}
	}
	return false
}

type rrSession struct {
	runneragent.Session
	c *rrConn
}

func (s *rrSession) Recv(ctx context.Context) (runneragent.Inbound, error) {
	in, err := s.Session.Recv(ctx)
	if err == nil {
		s.c.mu.Lock()
		s.c.seen = append(s.c.seen, rrInbound{Kind: in.Kind, JobID: in.JobID, Generation: in.Generation})
		s.c.mu.Unlock()
	}
	return in, err
}

		req.Header.Set("Content-Type", "application/json")
	}
	resp, err := http.DefaultClient.Do(req)
	require.NoError(t, err)
	defer resp.Body.Close()
	out, err := io.ReadAll(resp.Body)
	require.NoError(t, err)
	return resp.StatusCode, out
}

// rrRunningByRunner counts running runner_jobs per runner; safe inside Eventually.
func rrRunningByRunner(ds *domainStack) map[string]int {
	out := map[string]int{}
	rows, err := ds.db.Query(`SELECT runner_id, COUNT(*) FROM runner_jobs WHERE state = 'running' AND runner_id IS NOT NULL GROUP BY runner_id`)
	if err != nil {
		return out
	}
	defer rows.Close()
	for rows.Next() {
		var id string
		var n int
		if rows.Scan(&id, &n) == nil {
			out[id] = n
		}
	}
	return out
}

func rrStrings(t *testing.T, ds *domainStack, query string, args ...any) []string {
	t.Helper()

	var out []string

		var s string
		require.NoError(t, rows.Scan(&s))
		out = append(out, s)
	}
	require.NoError(t, rows.Err())

}

	execCool := newRRExecutor(t, "cool-answer", false)
	startRemoteAgent(t, st, plainHot, st.workspaceDir, execHot, hot)
	startRemoteAgent(t, st, plainCool, st.workspaceDir, execCool, runner.Telemetry{})
	rrAwaitLiveness(t, st, idHot, "online")
	rrAwaitLiveness(t, st, idCool, "online")
	hotID, coolID := runner.RunnerID(idHot), runner.RunnerID(idCool)
	require.Eventually(t, func() bool {
		tl, ok := st.ds.remote.Hub.Latest()[hotID]
		return ok && tl.MemPressure != nil && *tl.MemPressure == "critical"
	}, 20*time.Second, 50*time.Millisecond, "mac-hot's heartbeat telemetry reached the hub")

	srcCool := runner.MakeSourceID(coolID, runner.CredAnthropicSubscription, "")
	withTelemetry := map[runner.RunnerID]runner.Telemetry{hotID: hot, coolID: {}}
	noTelemetry := map[runner.RunnerID]runner.Telemetry{}

	const wantAdversarial, maxRuns = 3, 40
	adversarial, runs := 0, 0
	for adversarial < wantAdversarial && runs < maxRuns {
		runs++
		id, _, err := st.ds.eng.Trigger(ctx, "rr-single", map[string]any{}, "normal")
		require.NoError(t, err)
		rrRequireCompleted(t, st.ds, id)

		var owner, source, model string
		require.NoError(t, st.ds.db.QueryRow(
			`SELECT COALESCE(runner_id, ''), COALESCE(source_id, ''), model FROM runner_jobs WHERE run_id = ? AND state = 'completed'`,
			id.String()).Scan(&owner, &source, &model))
		require.Equal(t, string(srcCool), source, "the oracle below models the source the runner really advertised")
		require.Equal(t, coolID, rrPlacementOracle(t, id, model, withTelemetry, hotID, coolID),
			"with telemetry the ranking always prefers the healthy machine")
		blind := rrPlacementOracle(t, id, model, noTelemetry, hotID, coolID)
		if blind == hotID {
			adversarial++
		}
		require.Equal(t, idCool, owner,
			"run %s: the telemetry-blind tie-break picks %s; only the hub telemetry penalty places it on mac-cool", id, blind)
	}
	require.GreaterOrEqual(t, adversarial, wantAdversarial,
		"%d runs never produced a run whose fair tie-break favours mac-hot", runs)
	assert.Zero(t, execHot.count(), "no step is placed on the pressured machine")
	assert.Equal(t, runs, execCool.count())
}

// rrPlacementOracle replays the pure P1 T4 ranking for one run over the two
// otherwise-identical remote runners of the telemetry test (online,
// compatible, step limit 1, 0 slots in use, one healthy anthropic source with
// unknown headroom each). tel is the telemetry the dispatcher would see; an
// empty map is what it sees when DispatcherDeps.Telemetry is not wired.
func rrPlacementOracle(t *testing.T, run uuid.UUID, model string, tel map[runner.RunnerID]runner.Telemetry, ids ...runner.RunnerID) runner.RunnerID {
	t.Helper()
	snap := runner.PoolSnapshot{
		SlotsInUse: map[runner.RunnerID]int{}, SourceInFlight: map[runner.SourceID]int{},
		Telemetry: tel, Homes: map[uuid.UUID]runner.Home{}, Now: time.Now().UTC(),
	}
	for _, id := range ids {
		snap.Runners = append(snap.Runners, runner.Runner{ID: id, Name: string(id), StepLimit: 1,
			Compat: runner.Compatibility{State: runner.CompatCompatible}, Liveness: runner.LivenessOnline})
		snap.Sources = append(snap.Sources, runner.Source{ID: runner.MakeSourceID(id, runner.CredAnthropicSubscription, ""),
			RunnerID: id, Kind: runner.CredAnthropicSubscription, Families: []modelidentity.Family{"anthropic"},
			Health: runner.SourceHealth{Auth: runner.AuthOK, Capacity: runner.CapacityAvailable}})
	}
	d := runner.Place(runner.ExecRequirements{
		Group: runner.ModelGroup{Kind: runner.CredAnthropicSubscription, Family: "anthropic"},
		Model: model, Op: runner.OpChat, Affinity: runner.AffinityNone, RunID: run,
	}, snap, runner.PlacementPolicy{})
	require.True(t, d.Placed, d.Reason)
	return d.Runner
}
