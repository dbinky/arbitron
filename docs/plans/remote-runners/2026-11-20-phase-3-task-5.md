# Remote Runners — Phase 3 Task 5: Validated durable completion and replay (RR-10)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A completed node has one durable result/variables/continuation fact linked to every exact dispatched operation and workspace candidate. Restart repeats uncommitted operations from the prior committed checkpoint and replays committed operations without repeating them. A suspended node (awaited spawn) commits its already-validated suboperation receipts without advancing. A workflow retry position survives restart. The synthetic quota probe has its own explicit, fenced completion owner.

**Architecture:** Hexagonal. `domain/engine` owns the receipt vocabulary (`StepCompletion`, `StepCompletionSink`), the commit contract (`StepCommit`, `StepCommitter`), the retry journal port (`RetryProgressStore`) and the engine seams (`commitNodeSuccess`, `commitSuspension`, `committedReplay`, retry resume in `executeWithRetry`). `domain/runner` owns the probe completion port (`ProbeCommitter`). `adapter/sqlite` implements all three ports in single transactions over the server's one `*sql.DB`, reusing `fenceErr` (P1 job fence) and the P3 T3 transaction helpers `checkResourceFenceTx`/`releaseResourceTx` inside the same `*sql.Tx`. The domain never imports an adapter.

**Tech Stack:** Go 1.25.5, `database/sql` + modernc SQLite (hand-written SQL, as `adapter/sqlite/invocation_repo.go`), migration 044 tables (no new migration), `crypto/sha256`, testify.

**Spec / Design:** `docs/specs/2026-11-19-remote-runners-spec.md` "Recovery and session continuity"; `docs/designs/2026-11-19-remote-runners-design-phase-3.md` §3.3 (completion boundary), §3.5 (restart: replay a committed result before creating an invocation), §6, §8 ("crash after result/checkpoint commit but before engine advancement replays without repeating the completed step"; "a stale result after failover is rejected"). Contracts `2026-11-20-contracts.md` §3, §4, §8, §11, §16, §21, §22 (RR-08, RR-17), §23, §24 ("Retry progress and terminal failure replay"; "DECISION RR-17: B"). Resource lease names come from the settled P3 T3 lease contract (2026-11-23). This replaces the previous task text in full: last-placement inference, latest-checkpoint fallback, and dispatcher completion before executor validation are removed.

## Resolution amendment — RR-08 non-portable homes (decision 2026-11-22)

Decision (recorded in P3 T2 "Portable Git producer" and the Phase 3 design RR-08 row): Arbitron never fetches promisor objects over the network. A run whose repository has required promisor objects missing locally gets a **non-portable home**: it is pinned to the built-in runner, excluded from remote placement and load moves, and its steps keep running on the built-in runner as today, with no step failure. The marker clears automatically when a later built-in checkpoint attempt finds all objects present. Partial clones are a Non-Goal for remote execution. This amendment is authoritative over conflicting text below.

**This task (completion consumer):**
- `WorkspaceCompletion` gains `NonPortable bool`. Receipt validation accepts an empty workspace ref **only** when `NonPortable` is true and the resource fence is complete. All other empty-ref receipts are still rejected.
- In the step transaction, a `NonPortable` receipt is valid only when `workspace_homes.non_portable_reason` is non-empty for that run and the home owner is the built-in server home. The transaction then commits result, variables and continuation, completes the job and releases the exact claim. It promotes no candidate and leaves `checkpoint_version` unchanged.
- Promoting a normal built-in candidate for a run whose marker is set also clears `non_portable_reason` in the same transaction.

## Recovery base — DECISION RR-17: B (and how it splits with P3 T16)

**DECISION (2026-11-22) RR-17: B** (contracts §22/§24; owner P3 T16, `2026-11-20-phase-3-task-16.md`). A non-portable home takes a **local checkpoint** after each workspace-changing step completes: a plain copy of its directory on the server's own disk, with no portable-Git materialization. The step transaction commits it as `workspace_homes.local_checkpoint` via `WorkspaceCompletion.LocalRef`, and only the latest committed copy is kept. PoolRecovery restores it and re-runs the interrupted step under the same fences. With no local copy, recovery uses the home's initial state. With no base at all, `runner.ErrNoRecoveryBase` produces the durable `job.recovery_blocked` blocker. This supersedes the RR-08 amendment's "promotes no candidate … sets `dirty = 1`" rule.

Semantics fixed here (consumed by P3 T6/T10/T13/T16, P4 T6):
- `CommitStep` is all-or-nothing in one `*sql.Tx`. A stale job fence returns an error wrapping `runner.ErrFenced`; a stale resource claim wraps `runner.ErrResourceFenced`; anything else unprovable wraps `engine.ErrInvalidStepCompletion`. Nothing is written in any of those cases.
- An exactly identical repeated commit returns nil and writes nothing (that is the only case where a `completed` job is accepted). A different commit for the same invocation is rejected.
- Advance, nonterminal (`NextNodeID != ""`): marks the invocation committed and moves `instances.current_node_id`. Advance, terminal: leaves the invocation **open** and `current_node_id` on the node; the engine closes it after `SetCompleted`.
- Suspend: writes `step_suspensions(invocation_id, operation_id='node')` plus the consumed operations, completes/releases their jobs, writes no `node_executions`/`step_commits` row and keeps the invocation open. A later advance on the same invocation accepts an already-consumed identical receipt without completing it again.
- `CommittedResult` returns full replay data: mode, the full `NodeExecution` (advance), variables, next node, suspension and every persisted receipt in order.

package engine

import (
	"context"
	"errors"
	"fmt"
	"strings"
	"sync"

	"github.com/google/uuid"
)

// ErrInvalidStepCompletion marks a receipt or commit that cannot prove which
// exact operation, job generation or workspace candidate it completes (RR-10).
var ErrInvalidStepCompletion = errors.New("engine: invalid step completion")

// JobFenceRef names the exact ledger job generation a result belongs to. It
// mirrors runner.Fence without importing the runner package.
type JobFenceRef struct {
	JobID      uuid.UUID
	RunnerID   string
	Generation int64
}

// Validate rejects a fence that cannot identify one job generation.
func (f JobFenceRef) Validate() error {
	if f.JobID == uuid.Nil || f.RunnerID == "" || f.Generation < 1 {
		return fmt.Errorf("%w: job fence needs a job id, a runner and a generation >= 1 (got %s/%q/%d)",
			ErrInvalidStepCompletion, f.JobID, f.RunnerID, f.Generation)
	}
	return nil
}

// WorkspaceCompletion is the workspace half of a receipt: the exact prepared
// candidate Ref ("<runID>@<version>:<manifestHash>") written under the exact
// resource claim. NonPortable (RR-08) marks a built-in non-portable home with
// no catalog candidate; its Ref is empty.
type WorkspaceCompletion struct {
	Ref         string
	Resource    ResourceFenceRef
	NonPortable bool
}

// StepCompletion is one dispatched operation's receipt.
type StepCompletion struct {
	JobFence  JobFenceRef
	Workspace *WorkspaceCompletion
}

// Validate applies every rule a receipt satisfies on its own. The RR-08
// empty-ref rule lives here; Record and StepCommit.Validate both call it.
func (c StepCompletion) Validate() error {
	if err := c.JobFence.Validate(); err != nil {
		return err
	}
	w := c.Workspace
	if w == nil {
		return nil
	}
	if err := w.Resource.Validate(); err != nil {
		return fmt.Errorf("%w: job %s workspace receipt: %v", ErrInvalidStepCompletion, c.JobFence.JobID, err)
	}
	switch {
	case w.NonPortable && w.Ref != "":
		return fmt.Errorf("%w: non-portable workspace receipt for job %s carries a catalog ref", ErrInvalidStepCompletion, c.JobFence.JobID)
	case !w.NonPortable && w.Ref == "":
		return fmt.Errorf("%w: workspace receipt for job %s names no checkpoint", ErrInvalidStepCompletion, c.JobFence.JobID)
	case w.NonPortable:
		return nil
	}
	refRun, ok := checkpointRefRun(w.Ref)
	if !ok {
		return fmt.Errorf("%w: workspace receipt for job %s has malformed ref %q", ErrInvalidStepCompletion, c.JobFence.JobID, w.Ref)
	}
	if keyRun, isRun := resourceRun(w.Resource.Key); isRun && keyRun != refRun {
		return fmt.Errorf("%w: checkpoint %s belongs to run %s, not resource %s", ErrInvalidStepCompletion, w.Ref, refRun, w.Resource.Key)
	}
	return nil
}

// checkpointRefRun returns the run named by "<runID>@<version>:<hash>". The
// full parse is runner.ParseCheckpointRef; the engine only needs the owner.
func checkpointRefRun(ref string) (uuid.UUID, bool) {
	runPart, rest, found := strings.Cut(ref, "@")
	if !found || !strings.Contains(rest, ":") {
		return uuid.Nil, false
	}
	id, err := uuid.Parse(runPart)
	return id, err == nil && id != uuid.Nil
}

// resourceRun returns the run of a "run:<uuid>" resource key.
func resourceRun(key string) (uuid.UUID, bool) {
	rest, ok := strings.CutPrefix(key, "run:")
	if !ok {
		return uuid.Nil, false
	}
	id, err := uuid.Parse(rest)
	return id, err == nil && id != uuid.Nil
}

func (c StepCompletion) clone() StepCompletion {
	if c.Workspace != nil {
		w := *c.Workspace
		c.Workspace = &w
	}
	return c
}

func sameCompletion(a, b StepCompletion) bool {
	if a.JobFence != b.JobFence || (a.Workspace == nil) != (b.Workspace == nil) {
		return false
	}
	return a.Workspace == nil || *a.Workspace == *b.Workspace
}

// StepCompletionSink collects every receipt of one workflow retry attempt.
// The engine installs a fresh sink per attempt; dispatch records into it.
type StepCompletionSink struct {
	mu    sync.Mutex
	byJob map[uuid.UUID]int
	list  []StepCompletion
}

// NewStepCompletionSink returns an empty sink.
func NewStepCompletionSink() *StepCompletionSink {
	return &StepCompletionSink{byJob: map[uuid.UUID]int{}}
}

// Record keeps c. An identical repeat is a no-op; a different receipt for a
// job already recorded fails closed and leaves the first one unchanged.
func (s *StepCompletionSink) Record(c StepCompletion) error {
	if err := c.Validate(); err != nil {
		return err
	}
	c = c.clone()
	s.mu.Lock()
	defer s.mu.Unlock()
	if i, ok := s.byJob[c.JobFence.JobID]; ok {
		if sameCompletion(s.list[i], c) {
			return nil
		}
		return fmt.Errorf("%w: conflicting receipts for job %s", ErrInvalidStepCompletion, c.JobFence.JobID)
	}
	s.byJob[c.JobFence.JobID] = len(s.list)
	s.list = append(s.list, c)
	return nil
}

// Completions returns defensive copies of the receipts in record order.
func (s *StepCompletionSink) Completions() []StepCompletion {
	s.mu.Lock()
	defer s.mu.Unlock()
	out := make([]StepCompletion, len(s.list))
	for i, c := range s.list {
		out[i] = c.clone()
	}
	return out
}

type stepCompletionSinkKey struct{}

// ContextWithStepCompletionSink attaches s to ctx.
func ContextWithStepCompletionSink(ctx context.Context, s *StepCompletionSink) context.Context {
	return context.WithValue(ctx, stepCompletionSinkKey{}, s)
}

// StepCompletionSinkFromContext returns the sink installed on ctx.
func StepCompletionSinkFromContext(ctx context.Context) (*StepCompletionSink, bool) {
	s, ok := ctx.Value(stepCompletionSinkKey{}).(*StepCompletionSink)
	return s, ok && s != nil
}

// ErrStepPersistence marks a step whose durable record could not be written.
// The run halts as failed: a step that is not durably recorded is never done,
// and it is never retried, skipped or routed (RR-10).
var ErrStepPersistence = errors.New("engine: step persistence failed")

// StepCommitMode distinguishes a node that finished (advance) from a node that
// consumed validated suboperation receipts and is now waiting (suspend).
type StepCommitMode string

const (
	StepCommitAdvance StepCommitMode = "advance"
	StepCommitSuspend StepCommitMode = "suspend"
)

// StepSuspension names the durable wait a suspend commit records.
type StepSuspension struct {
	Kind        string
	ChildLinkID *uuid.UUID
	State       map[string]any
}

// StepCommit is the single durable fact that a node finished (or suspended):
// its execution record, variables, continuation and every exact receipt.
type StepCommit struct {
	RunID, InvocationID uuid.UUID
	NodeID              string
	Execution           *instance.NodeExecution
	Variables           map[string]any
	NextNodeID          string // "" = the node was the run's last step
	Completions         []StepCompletion
	Mode                StepCommitMode
	Suspension          *StepSuspension
}

// StepCommitter persists StepCommits atomically and answers whether an
// invocation already committed (restart replay).
type StepCommitter interface {
	CommitStep(ctx context.Context, c StepCommit) error
	CommittedResult(ctx context.Context, invocationID uuid.UUID) (*StepCommit, bool, error)
}

// Validate checks the commit's shape before any storage is touched. Advance
// and suspend are distinguished explicitly.
func (c StepCommit) Validate() error {
	if c.RunID == uuid.Nil || c.InvocationID == uuid.Nil || c.NodeID == "" {
		return fmt.Errorf("%w: a step commit needs a run, an invocation and a node", ErrInvalidStepCompletion)
	}
	seen := make(map[uuid.UUID]bool, len(c.Completions))
	for _, comp := range c.Completions {
		if err := comp.Validate(); err != nil {
			return err
		}
		if seen[comp.JobFence.JobID] {
			return fmt.Errorf("%w: job %s appears twice in one commit", ErrInvalidStepCompletion, comp.JobFence.JobID)
		}
		seen[comp.JobFence.JobID] = true
		if w := comp.Workspace; w != nil {
			if run, ok := resourceRun(w.Resource.Key); !ok || run != c.RunID {
				return fmt.Errorf("%w: job %s workspace receipt names resource %q, not run %s",
					ErrInvalidStepCompletion, comp.JobFence.JobID, w.Resource.Key, c.RunID)
			}
		}
	}
	switch c.Mode {
	case StepCommitAdvance:
		x := c.Execution
		if c.Suspension != nil || x == nil || x.ID == uuid.Nil || x.InstanceID != c.RunID || x.NodeID != c.NodeID || x.Status != instance.NodeStatusSucceeded {
			return fmt.Errorf("%w: an advance commit of node %q needs that node's own succeeded execution in run %s and no suspension",
				ErrInvalidStepCompletion, c.NodeID, c.RunID)
		}
	case StepCommitSuspend:
		if c.Execution != nil || c.NextNodeID != "" || c.Suspension == nil || c.Suspension.Kind == "" || len(c.Completions) == 0 {
			return fmt.Errorf("%w: a suspend commit of node %q carries receipts and suspension state, never an execution or a next node",
				ErrInvalidStepCompletion, c.NodeID)
		}
	default:
		return fmt.Errorf("%w: unknown step commit mode %q", ErrInvalidStepCompletion, c.Mode)
	}
	return nil
}

// SetStepCompletionReleaser installs the releaser. The production root must

// releaseAttempt hands an uncommitted attempt's receipts back with a detached
// bounded context. A release failure is ErrStepPersistence: it never triggers
// another provider retry.
func (e *Engine) releaseAttempt(ctx context.Context, nodeID string, completions []StepCompletion, cause error) error {
	if len(completions) == 0 {
		return nil
	}
	r := e.releaser()
	if r == nil {
		return nil // legacy/test engines only; production requires a releaser
	}
	pctx, cancel := persistenceContext(ctx)
	defer cancel()
	if err := r.ReleaseCompletions(pctx, completions, cause); err != nil {
		return &stepPersistenceError{fmt.Errorf("%w: releasing node %q attempt receipts: %w", ErrStepPersistence, nodeID, err)}
	}
	return nil
}

// releaseAfter releases completions after failure and returns failure joined
// with any release error.
func (e *Engine) releaseAfter(ctx context.Context, nodeID string, completions []StepCompletion, failure error) error {
	if rerr := e.releaseAttempt(ctx, nodeID, completions, failure); rerr != nil {
		return errors.Join(failure, rerr)
	}
	return failure
}

// stepCommitTimeout bounds a detached commit: a cancel landing after the node
// finished must not lose its result, but a wedged store must not hang forever.
const stepCommitTimeout = 30 * time.Second

func persistenceContext(ctx context.Context) (context.Context, context.CancelFunc) {
	return context.WithTimeout(context.WithoutCancel(ctx), stepCommitTimeout)
}

// requireReceipts fails closed when a dispatched job completed during the
// attempt but no receipt names it. Placement history is never the authority
// for what to commit; it only detects a missing receipt.
func requireReceipts(exec *instance.NodeExecution, completions []StepCompletion) error {
	if exec == nil {
		return nil
	}
	have := make(map[string]bool, len(completions))
	for _, c := range completions {
		have[c.JobFence.JobID.String()] = true
	}
	for _, p := range exec.PlacementHistory {
		if p.Outcome == "completed" && !have[p.JobID] {
			return fmt.Errorf("%w: dispatched job %s completed without a completion receipt", ErrInvalidStepCompletion, p.JobID)
		}
	}
	return nil
}

// commitNodeSuccess applies a validated, non-wait node result through the
// committer: output into vars, continuation, then one atomic CommitStep with
// the attempt's exact receipts. Any error is an ErrStepPersistence failure.
func (e *Engine) commitNodeSuccess(ctx context.Context, committer StepCommitter, instanceID uuid.UUID, node workflow.Node,
	result *NodeResult, exec *instance.NodeExecution, invocationID uuid.UUID, completions []StepCompletion,
	vars *variable.VariableStore, adj map[string][]edgeTarget) (string, error) {
	if err := requireReceipts(exec, completions); err != nil {
		return "", e.releaseAfter(ctx, node.ID, completions, &stepPersistenceError{fmt.Errorf("%w: node %q: %w", ErrStepPersistence, node.ID, err)})
	}
	if result != nil && result.Output != nil {
		vars.SetNodeOutput(node.ID, result.Output)
	}
	port := ""
	if result != nil {
		port = result.OutputPort
	}
	next := e.findNextNode(node.ID, port, adj)
	pctx, cancel := persistenceContext(ctx)
	defer cancel()
	if err := committer.CommitStep(pctx, StepCommit{
		Mode: StepCommitAdvance, RunID: instanceID, InvocationID: invocationID, NodeID: node.ID,
		Execution: exec, Variables: vars.Snapshot(), NextNodeID: next, Completions: completions,
	}); err != nil {
		return "", e.releaseAfter(ctx, node.ID, completions, &stepPersistenceError{fmt.Errorf("%w: committing node %q: %w", ErrStepPersistence, node.ID, err)})
	}
	e.eventBus.Publish(instanceID, Event{
		Type: EventTypeNodeCompleted, Timestamp: time.Now(),
		Data: map[string]any{"nodeId": node.ID, "nodeType": string(node.Type)},
	})
	return next, nil
}

// publishStepPersistenceFailure makes a persistence failure visible.
func (e *Engine) publishStepPersistenceFailure(instanceID uuid.UUID, node workflow.Node, err error) {
	e.eventBus.Publish(instanceID, Event{
		Type: EventTypeNodeFailed, Timestamp: time.Now(),
		Data: map[string]any{"nodeId": node.ID, "nodeType": string(node.Type), "error": err.Error()},
	})
}

// With a RetryProgressStore it resumes the open invocation's persisted attempt
// and remaining delay, and journals each failed attempt atomically with its
// execution. With a step committer a successful attempt's record is written by
// CommitStep. It returns the successful attempt's exact completion receipts.
func (e *Engine) executeWithRetry(ctx context.Context, instanceID uuid.UUID, node workflow.Node, vars *variable.VariableStore, wf workflow.Workflow) (*NodeResult, *instance.NodeExecution, uuid.UUID, []StepCompletion, error) {
	executor, ok := e.executorFor(node.Type)
	if !ok {
		return nil, nil, uuid.Nil, nil, fmt.Errorf("no executor registered for node type: %s", node.Type)
	}
	inv, err := e.invocationStore().Begin(ctx, instanceID, node.ID)
	if err != nil {
		return nil, nil, uuid.Nil, nil, &stepPersistenceError{fmt.Errorf("%w: begin invocation: %w", ErrStepPersistence, err)}
	}

	eb := resolveErrorBehavior(node, wf)
	maxAttempts := 1
	if eb.Type == "retry" && eb.Retries > 0 {
		maxAttempts = eb.Retries + 1
	}
	delay := time.Duration(eb.RetryDelaySeconds) * time.Second
	committing := e.committer() != nil

	retries := e.retryStore()
	first := 1
	var notBefore *time.Time
	if retries != nil {
		p, err := retries.LoadRetryProgress(ctx, inv.ID)
		if err != nil {
			return nil, nil, inv.ID, nil, &stepPersistenceError{fmt.Errorf("%w: load retry progress of node %q: %w", ErrStepPersistence, node.ID, err)}
		}
		if p.Exhausted {
			return nil, p.LastExecution, inv.ID, nil, exhaustedRetryError(node.ID, p)
		}

			return nil, p.LastExecution, inv.ID, nil, &stepPersistenceError{fmt.Errorf("%w: node %q retry position %d outside 1..%d", ErrStepPersistence, node.ID, p.Attempt, maxAttempts)}
		}
		first, notBefore = p.Attempt, p.RetryNotBefore
	}

	var lastErr error
	var lastExec *instance.NodeExecution

	for attempt := first; attempt <= maxAttempts; attempt++ {
		var wait time.Duration
		switch {
		case attempt == first && notBefore != nil:
			wait = time.Until(*notBefore) // the remaining persisted delay
		case attempt > first:
			wait = delay
		}
		if wait > 0 {
			select {
			case <-ctx.Done():
				return nil, lastExec, inv.ID, nil, ctx.Err()
			case <-time.After(wait):
			}
		}

			OperationID: nodeOperationID, Kind: OperationNode, Attempt: attempt,
		}), sink), receipts)

		var execError map[string]any
		if err != nil {
			execStatus = instance.NodeStatusFailed
			execError = map[string]any{"error": err.Error()}
		}

			} else {

			}
		}

		nodeExec := &instance.NodeExecution{

			InstanceID:     instanceID,
			NodeID:         node.ID,

			Status:         execStatus,

		suspended := err != nil && (errors.As(err, &pendingGather) || errors.As(err, &pendingWait))

		// written: P3 T6 discards its candidate and releases its claim/job.

// commitSuspension consumes a waiting node's validated suboperation receipts
// (e.g. routed child-input preparation) in one suspend commit: their jobs
// complete and release their slots while the invocation stays open. An awaited
// spawn must name its durable child link; a missing link fails closed.
func (e *Engine) commitSuspension(ctx context.Context, committer StepCommitter, instanceID uuid.UUID, node workflow.Node,
	invocationID uuid.UUID, result *NodeResult, completions []StepCompletion) error {
	state := map[string]any{}
	if out, ok := result.Output.(map[string]any); ok {
		for k, v := range out {
			state[k] = v
		}
	}
	s := &StepSuspension{Kind: string(node.Type), State: state}
	if node.Type == workflow.NodeTypeSpawnWorkflow {
		raw, _ := state["childInstanceId"].(string)
		id, err := uuid.Parse(raw)
		if err != nil || id == uuid.Nil {
			return &stepPersistenceError{fmt.Errorf("%w: %w: awaited spawn %q suspended without a durable child link",
				ErrStepPersistence, ErrInvalidStepCompletion, node.ID)}
		}
		s.ChildLinkID = &id
	}
	pctx, cancel := persistenceContext(ctx)
	defer cancel()
	if err := committer.CommitStep(pctx, StepCommit{
		Mode: StepCommitSuspend, RunID: instanceID, InvocationID: invocationID, NodeID: node.ID,
		Completions: completions, Suspension: s,
	}); err != nil {
		return e.releaseAfter(ctx, node.ID, completions, &stepPersistenceError{fmt.Errorf("%w: suspending node %q: %w", ErrStepPersistence, node.ID, err)})
	}
	return nil
}

// LoadRetryProgress returns the persisted retry position of an invocation;
// an invocation with no journaled failure is at attempt 1.
func (r *StepCommitRepo) LoadRetryProgress(ctx context.Context, invocationID uuid.UUID) (engine.RetryProgress, error) {
	var runStr string
	err := r.db.QueryRowContext(ctx, `SELECT run_id FROM node_invocations WHERE id = ?`, uuidToString(invocationID)).Scan(&runStr)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.RetryProgress{}, fmt.Errorf("%w: %s", engine.ErrInvocationNotFound, invocationID)
	}
	if err != nil {
		return engine.RetryProgress{}, fmt.Errorf("reading invocation: %w", err)
	}
	p := engine.RetryProgress{InvocationID: invocationID, Attempt: 1}
	var notBefore, lastExec sql.NullString
	err = r.db.QueryRowContext(ctx,
		`SELECT attempt, retry_not_before, exhausted, last_execution_id FROM node_retry_progress WHERE invocation_id = ?`,
		uuidToString(invocationID)).Scan(&p.Attempt, &notBefore, &p.Exhausted, &lastExec)
	if errors.Is(err, sql.ErrNoRows) {
		return p, nil
	}
	if err != nil {
		return engine.RetryProgress{}, fmt.Errorf("reading retry progress: %w", err)
	}
	if p.RetryNotBefore, err = nullStringToTimePtr(notBefore); err != nil {
		return engine.RetryProgress{}, err
	}
	if lastExec.Valid {
		runID, err := parseUUID(runStr)
		if err != nil {
			return engine.RetryProgress{}, err
		}
		execID, err := parseUUID(lastExec.String)
		if err != nil {
			return engine.RetryProgress{}, err
		}
		if p.LastExecution, err = loadNodeExecution(ctx, r.db, runID, execID); err != nil {
			return engine.RetryProgress{}, err
		}
	}
	return p, nil
}

// CommitRetryFailure writes the failed execution, its failure receipt and the
// next retry position (attempt+1 with retryAt, or exhaustion when retryAt is
// nil) in one transaction, after a CAS on the exact invocation/run/node/attempt.
// An identical replay returns the current position; a conflict writes nothing.
func (r *StepCommitRepo) CommitRetryFailure(ctx context.Context, invocationID uuid.UUID, attempt int,
	x *instance.NodeExecution, retryAt *time.Time) (engine.RetryProgress, error) {
	if x == nil || x.ID == uuid.Nil || attempt < 1 || x.Attempt != attempt || x.Status != instance.NodeStatusFailed {
		return engine.RetryProgress{}, fmt.Errorf("%w: a retry failure needs the failed execution of attempt %d", engine.ErrRetryProgressConflict, attempt)
	}
	hash, err := retryPayloadHash(x, retryAt)
	if err != nil {
		return engine.RetryProgress{}, err
	}
	inv := uuidToString(invocationID)
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	// First statement takes the SQLite write lock before any read.
	if _, err := tx.ExecContext(ctx, `UPDATE node_invocations SET id = id WHERE id = ?`, inv); err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: lock: %w", err)
	}
	var runStr, nodeID string
	var committed sql.NullString
	err = tx.QueryRowContext(ctx, `SELECT run_id, node_id, committed_at FROM node_invocations WHERE id = ?`, inv).Scan(&runStr, &nodeID, &committed)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.RetryProgress{}, fmt.Errorf("%w: %s", engine.ErrInvocationNotFound, invocationID)
	}
	if err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: reading invocation: %w", err)
	}
	if runStr != uuidToString(x.InstanceID) || nodeID != x.NodeID || committed.Valid {
		return engine.RetryProgress{}, fmt.Errorf("%w: execution of %s/%q does not belong to open invocation %s (%s/%q)",
			engine.ErrRetryProgressConflict, x.InstanceID, x.NodeID, invocationID, runStr, nodeID)
	}
	var prevExec, prevHash string
	err = tx.QueryRowContext(ctx, `SELECT execution_id, payload_hash FROM node_retry_failures WHERE invocation_id = ? AND attempt = ?`,
		inv, attempt).Scan(&prevExec, &prevHash)
	switch {
	case err == nil:
		if prevExec == uuidToString(x.ID) && prevHash == hash {
			_ = tx.Rollback() // release the single connection before reading
			return r.LoadRetryProgress(ctx, invocationID)
		}
		return engine.RetryProgress{}, fmt.Errorf("%w: attempt %d of invocation %s is already journaled", engine.ErrRetryProgressConflict, attempt, invocationID)
	case !errors.Is(err, sql.ErrNoRows):
		return engine.RetryProgress{}, fmt.Errorf("retry journal: reading failure: %w", err)
	}
	cur, exhausted := 1, false
	err = tx.QueryRowContext(ctx, `SELECT attempt, exhausted FROM node_retry_progress WHERE invocation_id = ?`, inv).Scan(&cur, &exhausted)
	if err != nil && !errors.Is(err, sql.ErrNoRows) {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: reading progress: %w", err)
	}
	if exhausted || cur != attempt {
		return engine.RetryProgress{}, fmt.Errorf("%w: expected attempt %d, invocation %s is at %d (exhausted=%t)",
			engine.ErrRetryProgressConflict, attempt, invocationID, cur, exhausted)
	}
	if err := insertNodeExecutionTx(ctx, tx, x); err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO node_retry_failures (invocation_id, attempt, execution_id, payload_hash) VALUES (?, ?, ?, ?)`,
		inv, attempt, uuidToString(x.ID), hash); err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: recording failure: %w", err)
	}
	next, exh := attempt, 1
	if retryAt != nil {
		next, exh = attempt+1, 0
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO node_retry_progress (invocation_id, attempt, retry_not_before, exhausted, last_execution_id)
		VALUES (?, ?, ?, ?, ?)
		ON CONFLICT(invocation_id) DO UPDATE SET attempt = excluded.attempt, retry_not_before = excluded.retry_not_before,
			exhausted = excluded.exhausted, last_execution_id = excluded.last_execution_id`,
		inv, next, timeToNullString(retryAt), exh, uuidToString(x.ID)); err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: advancing progress: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return engine.RetryProgress{}, fmt.Errorf("retry journal: commit: %w", err)
	}
	return r.LoadRetryProgress(ctx, invocationID)
}

func retryPayloadHash(x *instance.NodeExecution, retryAt *time.Time) (string, error) {
	at := ""
	if retryAt != nil {
		at = timeToString(*retryAt)
	}
	b, err := json.Marshal(struct {
		Execution string
		Attempt   int
		Error     map[string]any
		Output    map[string]any
		RetryAt   string
	}{uuidToString(x.ID), x.Attempt, x.Error, x.Output, at})
	if err != nil {
		return "", fmt.Errorf("retry journal: hashing payload: %w", err)
	}
	sum := sha256.Sum256(b)
	return hex.EncodeToString(sum[:]), nil
}

// CommitProbe validates the evidence and the job (a "probe/" operation with a
// RequiredSource and the same requested model), then completes the job,
// records the durable result and closes its attempt, releasing the slot, in
// one transaction. Invalid evidence writes nothing.
func (r *ProbeCommitRepo) CommitProbe(ctx context.Context, fr engine.JobFenceRef, res runner.ProbeCompletion) error {
	if err := fr.Validate(); err != nil {
		return err
	}
	if err := res.Validate(); err != nil {
		return err
	}
	f := runner.Fence{JobID: fr.JobID, RunnerID: runner.RunnerID(fr.RunnerID), Generation: fr.Generation}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("probe commit: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	if _, err := tx.ExecContext(ctx, `UPDATE runner_jobs SET updated_at = updated_at WHERE id = ?`, uuidToString(f.JobID)); err != nil {
		return fmt.Errorf("probe commit: lock: %w", err)
	}
	if err := fenceErr(ctx, tx, f); err != nil {
		j, gerr := getJob(ctx, tx, f.JobID)
		if gerr == nil && j.State == runner.JobCompleted && j.Generation == f.Generation && j.RunnerID == f.RunnerID &&
			j.ResultRef == probeResultRef(res.ExecutedModel) {
			return nil // identical repeat
		}
		return fmt.Errorf("probe commit: %w", err)
	}
	j, err := getJob(ctx, tx, f.JobID)
	if err != nil {
		return err
	}
	var raw string
	if err := tx.QueryRowContext(ctx, `SELECT requirements FROM runner_jobs WHERE id = ?`, uuidToString(f.JobID)).Scan(&raw); err != nil {
		return fmt.Errorf("probe commit: reading requirements: %w", err)
	}
	var req runner.ExecRequirements
	if err := json.Unmarshal([]byte(raw), &req); err != nil {
		return fmt.Errorf("probe commit: decoding requirements: %w", err)
	}
	if !strings.HasPrefix(j.Key.OperationID, "probe/") || req.RequiredSource == "" {
		return fmt.Errorf("%w: job %s (%s) is not a synthetic probe", runner.ErrInvalidProbeCompletion, f.JobID, j.Key.OperationID)
	}
	if j.Model != res.RequestedModel {
		return fmt.Errorf("%w: job %s requested %q, the evidence names %q", runner.ErrInvalidProbeCompletion, f.JobID, j.Model, res.RequestedModel)
	}
	if err := completeJobTx(ctx, tx, f, probeResultRef(res.ExecutedModel), "", timeToString(r.now())); err != nil {
		return fmt.Errorf("probe commit: %w", err)
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("probe commit: commit: %w", err)
	}
	return nil
}

// completeJobTx completes one live assignment under its exact fence and closes
// its attempt inside the caller's transaction (shared with StepCommitRepo).

	res, err := tx.ExecContext(ctx,
		`UPDATE runner_jobs SET state = 'completed', result_ref = ?, checkpoint_ref = ?, lease_until = NULL, updated_at = ? WHERE `+fencedWhere,
		resultRef, checkpointRef, now, uuidToString(f.JobID), string(f.RunnerID), f.Generation)
	if err != nil {
		return fmt.Errorf("completing job %s: %w", f.JobID, err)
	}
	if n, _ := res.RowsAffected(); n != 1 {
		return fmt.Errorf("%w: job %s changed concurrently", runner.ErrFenced, f.JobID)
	}
	if _, err := tx.ExecContext(ctx,
		`UPDATE runner_job_attempts SET outcome = 'completed', ended_at = ? WHERE job_id = ? AND generation = ? AND ended_at IS NULL`,
		now, uuidToString(f.JobID), f.Generation); err != nil {
		return fmt.Errorf("closing attempt of job %s: %w", f.JobID, err)
	}
	return nil

// stepState is every row a step commit may touch, so a test can prove that a
// failure changed nothing at all.
type stepState struct {
	Execs, StepCommits, Ops, Suspensions int
	Jobs                                 map[uuid.UUID]string
	Candidates                           map[int64]string
	Pointer                              int64
	Dirty                                bool
	Reason                               string
	Vars, Current                        string
	InvCommitted, LeaseActive            bool
}

func (fx stepFixture) snapshot(t *testing.T) stepState {
	t.Helper()
	s := stepState{Jobs: map[uuid.UUID]string{}, Candidates: map[int64]string{}}
	s.Execs = countRows(t, fx.db, `SELECT COUNT(*) FROM node_executions WHERE instance_id = ?`, fx.run.String())
	s.StepCommits = countRows(t, fx.db, `SELECT COUNT(*) FROM step_commits WHERE run_id = ?`, fx.run.String())
	s.Ops = countRows(t, fx.db, `SELECT COUNT(*) FROM step_commit_operations WHERE invocation_id = ?`, fx.inv.String())
	s.Suspensions = countRows(t, fx.db, `SELECT COUNT(*) FROM step_suspensions WHERE invocation_id = ?`, fx.inv.String())
	rows, err := fx.db.Query(`SELECT id, state FROM runner_jobs WHERE run_id = ?`, fx.run.String())
	require.NoError(t, err)
	for rows.Next() {
		var id, state string
		require.NoError(t, rows.Scan(&id, &state))
		s.Jobs[uuid.MustParse(id)] = state
	}
	require.NoError(t, rows.Close())
	rows, err = fx.db.Query(`SELECT version, state FROM workspace_checkpoints WHERE run_id = ?`, fx.run.String())
	require.NoError(t, err)
	for rows.Next() {
		var v int64
		var state string
		require.NoError(t, rows.Scan(&v, &state))
		s.Candidates[v] = state
	}
	require.NoError(t, rows.Close())
	err = fx.db.QueryRow(`SELECT checkpoint_version, dirty, non_portable_reason FROM workspace_homes WHERE run_id = ?`, fx.run.String()).
		Scan(&s.Pointer, &s.Dirty, &s.Reason)
	if err != sql.ErrNoRows {
		require.NoError(t, err)
	}
	var cur, committed sql.NullString
	require.NoError(t, fx.db.QueryRow(`SELECT variables, current_node_id FROM instances WHERE id = ?`, fx.run.String()).Scan(&s.Vars, &cur))
	s.Current = cur.String
	require.NoError(t, fx.db.QueryRow(`SELECT committed_at FROM node_invocations WHERE id = ?`, fx.inv.String()).Scan(&committed))
	s.InvCommitted = committed.Valid
	s.LeaseActive = countRows(t, fx.db, `SELECT COUNT(*) FROM workspace_leases WHERE resource_key = ? AND active = 1`, fx.key) > 0
	return s
}

func TestStepCommitRepo_CommitIsOneTransactionAndReplayable(t *testing.T) {
	ctx := context.Background()
	fx := newStepFixture(t, setupTestDB(t).DB)
	base := fx.baseline(t)
	j, f := fx.job(t, "node", runner.AffinityWorkspace)
	res := fx.claim(t, j, f)
	ref := fx.candidate(t, 2, 'a', base, f, res)
	receipt := workspaceReceipt(f, ref, res)
	c := fx.advance("B", receipt)

	require.NoError(t, fx.repo.CommitStep(ctx, c))
	s := fx.snapshot(t)
	assert.Equal(t, 1, s.Execs)
	assert.Equal(t, 1, s.StepCommits)
	assert.Equal(t, 1, s.Ops)
	assert.Zero(t, s.Suspensions)
	assert.Equal(t, "completed", s.Jobs[j.ID])
	assert.Equal(t, int64(2), s.Pointer, "the exact candidate is now the committed recovery base")
	assert.False(t, s.Dirty)
	assert.Equal(t, "committed", s.Candidates[2])
	assert.Equal(t, "B", s.Current)
	assert.True(t, s.InvCommitted)
	assert.False(t, s.LeaseActive, "the exact claim is released")
	assert.Contains(t, s.Vars, `"A"`)
	assert.Zero(t, fx.busySlots(t), "the job's slot is released only by this commit")
	got, err := fx.ledger.Get(ctx, j.ID)

	assert.Equal(t, ref.String(), got.CheckpointRef)
	attempts, err := fx.ledger.Attempts(ctx, j.ID)
	require.NoError(t, err)
	require.Len(t, attempts, 1)
	assert.Equal(t, "completed", attempts[0].Outcome)
	assert.NotNil(t, attempts[0].EndedAt)

	replay, ok, err := fx.repo.CommittedResult(ctx, fx.inv)
	require.NoError(t, err)
	require.True(t, ok)
	assert.Equal(t, engine.StepCommitAdvance, replay.Mode)
	assert.Equal(t, fx.run, replay.RunID)
	assert.Equal(t, "A", replay.NodeID)
	assert.Equal(t, "B", replay.NextNodeID)
	require.NotNil(t, replay.Execution, "replay returns the full execution, not an identity stub")
	assert.Equal(t, c.Execution.ID, replay.Execution.ID)
	assert.Equal(t, instance.NodeStatusSucceeded, replay.Execution.Status)
	assert.Equal(t, map[string]any{"answer": "42"}, replay.Execution.Output)
	assert.Equal(t, map[string]any{"answer": "42"}, replay.Variables["A"])
	assert.Equal(t, []engine.StepCompletion{receipt}, replay.Completions)

	require.NoError(t, fx.repo.CommitStep(ctx, c), "an identical replay is idempotent")
	assert.Equal(t, s, fx.snapshot(t), "the replay writes nothing")
	conflict := c
	conflict.NextNodeID = "C"
	require.ErrorIs(t, fx.repo.CommitStep(ctx, conflict), engine.ErrInvalidStepCompletion)
	assert.Equal(t, s, fx.snapshot(t))

	_, ok, err = fx.repo.CommittedResult(ctx, uuid.New())

	assert.False(t, ok)
}

// suspensionOperationID keys a node's own suspension record in step_suspensions.
const suspensionOperationID = "node"

// CommitStep writes c in one transaction or not at all (RR-10, contracts §21):
// validate invocation/run/node and every exact job fence, resource claim and
// prepared candidate; promote candidates and home pointers; complete the jobs
// and release the claims; persist operations, the execution, variables,
// continuation and the step_commits (advance) or step_suspensions (suspend)
// row. An identical repeat returns nil and writes nothing.
func (r *StepCommitRepo) CommitStep(ctx context.Context, c engine.StepCommit) error {
	if err := c.Validate(); err != nil {
		return err
	}
	varsJSON := ""
	if c.Mode == engine.StepCommitAdvance {
		v, err := toJSONString(c.Variables)
		if err != nil {
			return fmt.Errorf("step commit: marshalling variables: %w", err)
		}
		varsJSON = v
	}
	tx, err := r.db.BeginTx(ctx, nil)
	if err != nil {
		return fmt.Errorf("step commit: begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()
	inv := uuidToString(c.InvocationID)
	// First statement takes the SQLite write lock before any read.
	if _, err := tx.ExecContext(ctx, `UPDATE node_invocations SET id = id WHERE id = ?`, inv); err != nil {
		return fmt.Errorf("step commit: lock: %w", err)
	}
	var runStr, nodeID string
	var committedAt sql.NullString
	err = tx.QueryRowContext(ctx, `SELECT run_id, node_id, committed_at FROM node_invocations WHERE id = ?`, inv).Scan(&runStr, &nodeID, &committedAt)
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("step commit: %w: %s", engine.ErrInvocationNotFound, c.InvocationID)
	}
	if err != nil {
		return fmt.Errorf("step commit: reading invocation: %w", err)
	}
	if runStr != uuidToString(c.RunID) || nodeID != c.NodeID {
		return fmt.Errorf("%w: invocation %s is node %q of run %s, not node %q of run %s",
			engine.ErrInvalidStepCompletion, c.InvocationID, nodeID, runStr, c.NodeID, c.RunID)
	}
	replayed, err := sameCommitTx(ctx, tx, c, varsJSON)
	if err != nil {
		return err
	}
	if replayed {
		return nil // already durable; the deferred rollback discards the read-only transaction
	}
	if committedAt.Valid {
		return fmt.Errorf("%w: invocation %s is already committed", engine.ErrInvalidStepCompletion, c.InvocationID)
	}
	now := timeToString(r.now())
	for _, comp := range c.Completions {
		if err := consumeCompletionTx(ctx, tx, c, comp, now); err != nil {
			return err
		}
	}
	switch c.Mode {
	case engine.StepCommitAdvance:
		if err := insertNodeExecutionTx(ctx, tx, c.Execution); err != nil {
			return fmt.Errorf("step commit: %w", err)
		}
		res, err := tx.ExecContext(ctx, `UPDATE instances SET variables = ?, updated_at = strftime('%Y-%m-%dT%H:%M:%SZ') WHERE id = ?`,
			varsJSON, uuidToString(c.RunID))
		if err != nil {
			return fmt.Errorf("step commit: updating variables: %w", err)
		}
		if n, _ := res.RowsAffected(); n != 1 {
			return fmt.Errorf("step commit: run %s not found", c.RunID)
		}
		if c.NextNodeID != "" {
			if _, err := tx.ExecContext(ctx, `UPDATE instances SET current_node_id = ?, updated_at = strftime('%Y-%m-%dT%H:%M:%SZ') WHERE id = ?`,
				c.NextNodeID, uuidToString(c.RunID)); err != nil {
				return fmt.Errorf("step commit: advancing run: %w", err)
			}
			if _, err := tx.ExecContext(ctx, `UPDATE node_invocations SET committed_at = ? WHERE id = ? AND committed_at IS NULL`, now, inv); err != nil {
				return fmt.Errorf("step commit: committing invocation: %w", err)
			}
		}
		if _, err := tx.ExecContext(ctx, `INSERT INTO step_commits (invocation_id, run_id, node_id, execution_id, next_node_id, variables, committed_at)
			VALUES (?, ?, ?, ?, ?, ?, ?)`, inv, uuidToString(c.RunID), c.NodeID, uuidToString(c.Execution.ID), c.NextNodeID, varsJSON, now); err != nil {
			return fmt.Errorf("step commit: recording commit: %w", err)
		}
	case engine.StepCommitSuspend:
		state, err := toJSONString(c.Suspension.State)
		if err != nil {
			return fmt.Errorf("step commit: marshalling suspension state: %w", err)
		}
		var child sql.NullString
		if c.Suspension.ChildLinkID != nil {
			child = sql.NullString{String: uuidToString(*c.Suspension.ChildLinkID), Valid: true}
		}
		if _, err := tx.ExecContext(ctx, `INSERT INTO step_suspensions (invocation_id, operation_id, kind, child_link_id, state, committed_at)
			VALUES (?, ?, ?, ?, ?, ?)`, inv, suspensionOperationID, c.Suspension.Kind, child, state, now); err != nil {
			return fmt.Errorf("step commit: recording suspension: %w", err)
		}
	}
	if err := tx.Commit(); err != nil {
		return fmt.Errorf("step commit: commit: %w", err)
	}
	return nil
}

// sameCommitTx reports whether exactly c is already durable. A different
// commit already recorded for the invocation is a conflict.
func sameCommitTx(ctx context.Context, tx *sql.Tx, c engine.StepCommit, varsJSON string) (bool, error) {
	inv := uuidToString(c.InvocationID)
	conflict := fmt.Errorf("%w: invocation %s already committed a different %s", engine.ErrInvalidStepCompletion, c.InvocationID, c.Mode)
	switch c.Mode {
	case engine.StepCommitAdvance:
		var execStr, next, vars string
		err := tx.QueryRowContext(ctx, `SELECT execution_id, next_node_id, variables FROM step_commits WHERE invocation_id = ?`, inv).Scan(&execStr, &next, &vars)
		if errors.Is(err, sql.ErrNoRows) {
			return false, nil
		}
		if err != nil {
			return false, fmt.Errorf("step commit: reading prior commit: %w", err)
		}
		if execStr != uuidToString(c.Execution.ID) || next != c.NextNodeID || vars != varsJSON {
			return false, conflict
		}
	case engine.StepCommitSuspend:
		var advanced int
		if err := tx.QueryRowContext(ctx, `SELECT COUNT(*) FROM step_commits WHERE invocation_id = ?`, inv).Scan(&advanced); err != nil {
			return false, fmt.Errorf("step commit: reading prior commit: %w", err)
		}
		if advanced > 0 {
			return false, conflict
		}
		var kind, state string
		var child sql.NullString
		err := tx.QueryRowContext(ctx, `SELECT kind, child_link_id, state FROM step_suspensions WHERE invocation_id = ? AND operation_id = ?`,
			inv, suspensionOperationID).Scan(&kind, &child, &state)
		if errors.Is(err, sql.ErrNoRows) {
			return false, nil
		}
		if err != nil {
			return false, fmt.Errorf("step commit: reading prior suspension: %w", err)
		}
		wantState, err := toJSONString(c.Suspension.State)
		if err != nil {
			return false, err
		}
		wantChild := ""
		if c.Suspension.ChildLinkID != nil {
			wantChild = uuidToString(*c.Suspension.ChildLinkID)
		}
		if kind != c.Suspension.Kind || child.String != wantChild || state != wantState {
			return false, conflict
		}
	}
	for _, comp := range c.Completions {
		prev, found, err := readOperationTx(ctx, tx, c.InvocationID, comp.JobFence.JobID)
		if err != nil {
			return false, err
		}
		if !found || !sameReceipt(prev, comp) {
			return false, conflict
		}
	}
	return true, nil
}

// consumeCompletionTx validates one receipt against the exact live job fence,
// resource claim and prepared candidate, then promotes, completes, releases
// and records it. A receipt this invocation already consumed (its suspension)
// is accepted once more without completing anything again.
func consumeCompletionTx(ctx context.Context, tx *sql.Tx, c engine.StepCommit, comp engine.StepCompletion, now string) error {
	prev, found, err := readOperationTx(ctx, tx, c.InvocationID, comp.JobFence.JobID)
	if err != nil {
		return err
	}
	if found {
		if sameReceipt(prev, comp) {
			return nil
		}
		return fmt.Errorf("%w: job %s was already committed with a different receipt", engine.ErrInvalidStepCompletion, comp.JobFence.JobID)
	}
	f := runner.Fence{JobID: comp.JobFence.JobID, RunnerID: runner.RunnerID(comp.JobFence.RunnerID), Generation: comp.JobFence.Generation}
	if err := fenceErr(ctx, tx, f); err != nil {
		return fmt.Errorf("step commit: %w", err)
	}
	job, err := getJob(ctx, tx, f.JobID)
	if err != nil {
		return err
	}
	if job.Key.RunID != c.RunID || job.Key.InvocationID != c.InvocationID {
		return fmt.Errorf("%w: job %s belongs to run %s invocation %s, not %s/%s",
			engine.ErrInvalidStepCompletion, f.JobID, job.Key.RunID, job.Key.InvocationID, c.RunID, c.InvocationID)
	}
	affinity, err := jobAffinityTx(ctx, tx, f.JobID)
	if err != nil {
		return err
	}
	w := comp.Workspace
	checkpointRef := ""
	switch {
	case w == nil && affinity == runner.AffinityWorkspace:
		return fmt.Errorf("%w: workspace operation job %s has no workspace receipt", engine.ErrInvalidStepCompletion, f.JobID)
	case w != nil:
		if err := checkResourceFenceTx(ctx, tx, w.Resource); err != nil {
			return fmt.Errorf("step commit: %w", err)
		}
		if err := requireJobHolderTx(ctx, tx, w.Resource, f); err != nil {
			return err
		}
		if w.NonPortable {
			// RR-08 non-portable branch: Cycle 7.
			return fmt.Errorf("%w: job %s non-portable receipt is not supported yet", engine.ErrInvalidStepCompletion, f.JobID)
		}
		if err := promoteCandidateTx(ctx, tx, c.RunID, f, *w, now); err != nil {
			return err
		}
		checkpointRef = w.Ref
	}
	if err := completeJobTx(ctx, tx, f, "step:"+uuidToString(c.InvocationID), checkpointRef, now); err != nil {
		return fmt.Errorf("step commit: %w", err)
	}
	var ref, key, owner, token sql.NullString
	var resGen sql.NullInt64
	if w != nil {
		if err := releaseResourceTx(ctx, tx, w.Resource); err != nil {
			return fmt.Errorf("step commit: %w", err)
		}
		ref = sql.NullString{String: checkpointRef, Valid: checkpointRef != ""}
		key = sql.NullString{String: w.Resource.Key, Valid: true}
		owner = sql.NullString{String: w.Resource.Owner, Valid: true}
		token = sql.NullString{String: w.Resource.Token.String(), Valid: true}
		resGen = sql.NullInt64{Int64: w.Resource.Generation, Valid: true}
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO step_commit_operations (invocation_id, job_id, job_runner_id, job_generation,
		checkpoint_ref, resource_key, resource_owner, resource_generation, resource_token) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`,
		uuidToString(c.InvocationID), uuidToString(f.JobID), string(f.RunnerID), f.Generation, ref, key, owner, resGen, token); err != nil {
		return fmt.Errorf("step commit: recording operation: %w", err)
	}
	return nil
}

func jobAffinityTx(ctx context.Context, tx groupQueryer, jobID uuid.UUID) (runner.Affinity, error) {
	var raw string
	if err := tx.QueryRowContext(ctx, `SELECT requirements FROM runner_jobs WHERE id = ?`, uuidToString(jobID)).Scan(&raw); err != nil {
		return "", fmt.Errorf("step commit: reading job requirements: %w", err)
	}
	var req runner.ExecRequirements
	if err := json.Unmarshal([]byte(raw), &req); err != nil {
		return "", fmt.Errorf("step commit: decoding job requirements: %w", err)
	}
	return req.Affinity, nil
}

// requireJobHolderTx checks that the exact claim generation is held by this
// exact job generation (P3 T3 workspace_lease_holders).
func requireJobHolderTx(ctx context.Context, tx groupQueryer, res engine.ResourceFenceRef, f runner.Fence) error {
	var jobID, runnerID sql.NullString
	var gen sql.NullInt64
	err := tx.QueryRowContext(ctx, `SELECT job_id, job_runner_id, job_generation FROM workspace_lease_holders
		WHERE resource_key = ? AND generation = ? AND token = ?`, res.Key, res.Generation, res.Token.String()).Scan(&jobID, &runnerID, &gen)
	if err != nil && !errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("step commit: reading claim holder: %w", err)
	}
	if err != nil || !jobID.Valid || jobID.String != uuidToString(f.JobID) || runnerID.String != string(f.RunnerID) || gen.Int64 != f.Generation {
		return fmt.Errorf("%w: claim %s generation %d is not held by job %s generation %d",
			engine.ErrInvalidStepCompletion, res.Key, res.Generation, f.JobID, f.Generation)
	}
	return nil
}

// committedRefTx is the run's committed recovery base ("" before the first).
func committedRefTx(ctx context.Context, tx groupQueryer, runID uuid.UUID) (string, error) {
	var version int64
	err := tx.QueryRowContext(ctx, `SELECT checkpoint_version FROM workspace_homes WHERE run_id = ?`, uuidToString(runID)).Scan(&version)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && version == 0) {
		return "", nil
	}
	if err != nil {
		return "", fmt.Errorf("step commit: reading home pointer: %w", err)
	}
	var hash string
	if err := tx.QueryRowContext(ctx, `SELECT manifest_hash FROM workspace_checkpoints WHERE run_id = ? AND version = ? AND state = 'committed'`,
		uuidToString(runID), version).Scan(&hash); err != nil {
		return "", fmt.Errorf("step commit: committed checkpoint %d of run %s: %w", version, runID, err)
	}
	return runner.CheckpointRef{RunID: runID, Version: version, ManifestHash: hash}.String(), nil
}

// promoteCandidateTx promotes exactly the receipt's prepared candidate: same
// run, same job generation, same resource claim, retained artifact, based on
// the current committed pointer. No newest-row query, no fallback.
func promoteCandidateTx(ctx context.Context, tx groupQueryer, runID uuid.UUID, f runner.Fence, w engine.WorkspaceCompletion, now string) error {
	ref, err := runner.ParseCheckpointRef(w.Ref)
	if err != nil || ref.RunID != runID {
		return fmt.Errorf("%w: checkpoint %q is not a candidate of run %s", engine.ErrInvalidStepCompletion, w.Ref, runID)
	}
	run := uuidToString(runID)
	var state, archive, base, resKey, resOwner, resToken string
	var jobID sql.NullString
	var jobGen sql.NullInt64
	var resGen int64
	err = tx.QueryRowContext(ctx, `SELECT state, archive_path, base_ref, job_id, job_generation, resource_key, resource_owner, resource_generation, resource_token
		FROM workspace_checkpoints WHERE run_id = ? AND version = ? AND manifest_hash = ?`, run, ref.Version, ref.ManifestHash).
		Scan(&state, &archive, &base, &jobID, &jobGen, &resKey, &resOwner, &resGen, &resToken)
	if errors.Is(err, sql.ErrNoRows) {
		return fmt.Errorf("%w: checkpoint %s was never prepared", engine.ErrInvalidStepCompletion, w.Ref)
	}
	if err != nil {
		return fmt.Errorf("step commit: reading candidate: %w", err)
	}
	switch {
	case state != "prepared":
		return fmt.Errorf("%w: checkpoint %s is %s, not a prepared candidate", engine.ErrInvalidStepCompletion, w.Ref, state)
	case archive == "":
		return fmt.Errorf("%w: checkpoint %s has no retained artifact", engine.ErrInvalidStepCompletion, w.Ref)
	case !jobID.Valid || jobID.String != uuidToString(f.JobID) || !jobGen.Valid || jobGen.Int64 != f.Generation:
		return fmt.Errorf("%w: checkpoint %s was prepared by another operation", engine.ErrInvalidStepCompletion, w.Ref)
	case resKey != w.Resource.Key || resOwner != w.Resource.Owner || resGen != w.Resource.Generation || resToken != w.Resource.Token.String():
		return fmt.Errorf("%w: checkpoint %s was prepared under another resource claim", engine.ErrInvalidStepCompletion, w.Ref)
	}
	cur, err := committedRefTx(ctx, tx, runID)
	if err != nil {
		return err
	}
	if base != cur {
		return fmt.Errorf("%w: checkpoint %s is based on %q, but the committed checkpoint is %q", engine.ErrInvalidStepCompletion, w.Ref, base, cur)
	}
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_checkpoints SET state = 'committed' WHERE run_id = ? AND version = ? AND state = 'prepared'`,
		run, ref.Version); err != nil {
		return fmt.Errorf("step commit: promoting candidate: %w", err)
	}
	if _, err := tx.ExecContext(ctx, `INSERT INTO workspace_homes (run_id, updated_at) VALUES (?, ?) ON CONFLICT(run_id) DO NOTHING`, run, now); err != nil {
		return fmt.Errorf("step commit: home row: %w", err)
	}
	// A portable candidate also clears the RR-08 non-portable marker.
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_homes SET checkpoint_version = ?, dirty = 0, non_portable_reason = '', updated_at = ? WHERE run_id = ?`,
		ref.Version, now, run); err != nil {
		return fmt.Errorf("step commit: advancing home pointer: %w", err)
	}
	return nil
}

func readOperationTx(ctx context.Context, q groupQueryer, invocationID, jobID uuid.UUID) (engine.StepCompletion, bool, error) {
	var runnerID string
	var gen int64
	var ref, key, owner, token sql.NullString
	var resGen sql.NullInt64
	err := q.QueryRowContext(ctx, `SELECT job_runner_id, job_generation, checkpoint_ref, resource_key, resource_owner, resource_generation, resource_token
		FROM step_commit_operations WHERE invocation_id = ? AND job_id = ?`, uuidToString(invocationID), uuidToString(jobID)).
		Scan(&runnerID, &gen, &ref, &key, &owner, &resGen, &token)
	if errors.Is(err, sql.ErrNoRows) {
		return engine.StepCompletion{}, false, nil
	}
	if err != nil {
		return engine.StepCompletion{}, false, fmt.Errorf("step commit: reading operation: %w", err)
	}
	c, err := operationFromRow(jobID, runnerID, gen, ref, key, owner, resGen, token)
	return c, err == nil, err
}

// operationFromRow rebuilds a persisted receipt. A NULL checkpoint_ref under a
// resource claim is an RR-08 non-portable receipt; a "local:" ref is RR-17 B's
// (P3 T16 Cycle 3 also sets LocalRef in that branch).
func operationFromRow(jobID uuid.UUID, runnerID string, gen int64, ref, key, owner sql.NullString, resGen sql.NullInt64, token sql.NullString) (engine.StepCompletion, error) {
	c := engine.StepCompletion{JobFence: engine.JobFenceRef{JobID: jobID, RunnerID: runnerID, Generation: gen}}
	if !key.Valid {
		return c, nil
	}
	tok, err := parseUUID(token.String)
	if err != nil {
		return engine.StepCompletion{}, err
	}
	w := &engine.WorkspaceCompletion{Resource: engine.ResourceFenceRef{Key: key.String, Owner: owner.String, Generation: resGen.Int64, Token: tok}}
	switch {
	case !ref.Valid:
		w.NonPortable = true
	case strings.HasPrefix(ref.String, "local:"):
		w.NonPortable = true
	default:
		w.Ref = ref.String
	}
	c.Workspace = w
	return c, nil
}

func sameReceipt(a, b engine.StepCompletion) bool {
	if a.JobFence != b.JobFence || (a.Workspace == nil) != (b.Workspace == nil) {
		return false
	}
	return a.Workspace == nil || *a.Workspace == *b.Workspace
}

func (r *StepCommitRepo) operations(ctx context.Context, invocationID uuid.UUID) ([]engine.StepCompletion, error) {
	rows, err := r.db.QueryContext(ctx, `SELECT job_id, job_runner_id, job_generation, checkpoint_ref, resource_key, resource_owner, resource_generation, resource_token
		FROM step_commit_operations WHERE invocation_id = ? ORDER BY rowid`, uuidToString(invocationID))
	if err != nil {
		return nil, fmt.Errorf("reading step operations: %w", err)
	}
	defer rows.Close()
	var out []engine.StepCompletion
	for rows.Next() {
		var jobStr, runnerID string
		var gen int64
		var ref, key, owner, token sql.NullString
		var resGen sql.NullInt64
		if err := rows.Scan(&jobStr, &runnerID, &gen, &ref, &key, &owner, &resGen, &token); err != nil {
			return nil, err
		}
		jobID, err := parseUUID(jobStr)
		if err != nil {
			return nil, err
		}
		c, err := operationFromRow(jobID, runnerID, gen, ref, key, owner, resGen, token)
		if err != nil {
			return nil, err
		}
		out = append(out, c)
	}
	return out, rows.Err()
}

// CommittedResult returns the durable commit of invocationID with full replay
// data (execution, variables, continuation, receipts), a suspension record when
// the invocation only suspended, or false.
func (r *StepCommitRepo) CommittedResult(ctx context.Context, invocationID uuid.UUID) (*engine.StepCommit, bool, error) {
	inv := uuidToString(invocationID)
	var runStr, nodeID, execStr, next, varsJSON string
	err := r.db.QueryRowContext(ctx, `SELECT run_id, node_id, execution_id, next_node_id, variables FROM step_commits WHERE invocation_id = ?`, inv).
		Scan(&runStr, &nodeID, &execStr, &next, &varsJSON)
	switch {
	case err == nil:
		runID, err := parseUUID(runStr)
		if err != nil {
			return nil, false, err
		}
		execID, err := parseUUID(execStr)
		if err != nil {
			return nil, false, err
		}
		vars, err := fromJSONString(varsJSON)
		if err != nil {
			return nil, false, fmt.Errorf("step commit variables: %w", err)
		}
		exec, err := loadNodeExecution(ctx, r.db, runID, execID)
		if err != nil {
			return nil, false, err
		}
		comps, err := r.operations(ctx, invocationID)
		if err != nil {
			return nil, false, err
		}
		return &engine.StepCommit{Mode: engine.StepCommitAdvance, RunID: runID, InvocationID: invocationID, NodeID: nodeID,
			Execution: exec, Variables: vars, NextNodeID: next, Completions: comps}, true, nil
	case !errors.Is(err, sql.ErrNoRows):
		return nil, false, fmt.Errorf("reading step commit: %w", err)
	}
	var kind, stateJSON string
	var child sql.NullString
	err = r.db.QueryRowContext(ctx, `SELECT s.kind, s.child_link_id, s.state, i.run_id, i.node_id
		FROM step_suspensions s JOIN node_invocations i ON i.id = s.invocation_id
		WHERE s.invocation_id = ? AND s.operation_id = ?`, inv, suspensionOperationID).Scan(&kind, &child, &stateJSON, &runStr, &nodeID)
	if errors.Is(err, sql.ErrNoRows) {
		return nil, false, nil
	}
	if err != nil {
		return nil, false, fmt.Errorf("reading step suspension: %w", err)
	}
	runID, err := parseUUID(runStr)
	if err != nil {
		return nil, false, err
	}
	s := &engine.StepSuspension{Kind: kind}
	if s.State, err = fromJSONString(stateJSON); err != nil {
		return nil, false, fmt.Errorf("step suspension state: %w", err)
	}
	if child.Valid {
		id, err := parseUUID(child.String)
		if err != nil {
			return nil, false, err
		}
		s.ChildLinkID = &id
	}
	comps, err := r.operations(ctx, invocationID)
	if err != nil {
		return nil, false, err
	}
	return &engine.StepCommit{Mode: engine.StepCommitSuspend, RunID: runID, InvocationID: invocationID, NodeID: nodeID,
		Suspension: s, Completions: comps}, true, nil
}

// commitNonPortableTx is the RR-08 branch: the home carries the non-portable
// marker and lives on the built-in server home, and the job ran on the
// built-in runner. No candidate is promoted and checkpoint_version is
// unchanged; dirty = 1 records that the working copy is ahead of the committed
// base. P3 T16 Cycle 3 replaces dirty = 1 with the RR-17 B local-checkpoint
// promotion (local_checkpoint = LocalRef, dirty = 0).
func commitNonPortableTx(ctx context.Context, tx groupQueryer, runID uuid.UUID, f runner.Fence, now string) error {
	var reason, owner string
	err := tx.QueryRowContext(ctx, `SELECT non_portable_reason, runner_id FROM workspace_homes WHERE run_id = ?`, uuidToString(runID)).Scan(&reason, &owner)
	if errors.Is(err, sql.ErrNoRows) || (err == nil && reason == "") {
		return fmt.Errorf("%w: run %s has a portable home; a non-portable receipt is not valid", engine.ErrInvalidStepCompletion, runID)
	}
	if err != nil {
		return fmt.Errorf("step commit: reading home: %w", err)
	}
	if (owner != string(runner.ServerHome) && owner != string(runner.BuiltInRunnerID)) || f.RunnerID != runner.BuiltInRunnerID {
		return fmt.Errorf("%w: non-portable home of run %s is on %q and job %s ran on %q; both must be the built-in server home",
			engine.ErrInvalidStepCompletion, runID, owner, f.JobID, f.RunnerID)
	}
	if _, err := tx.ExecContext(ctx, `UPDATE workspace_homes SET dirty = 1, updated_at = ? WHERE run_id = ?`, now, uuidToString(runID)); err != nil {
		return fmt.Errorf("step commit: marking non-portable home dirty: %w", err)
	}
	return nil
}

// prepareWorkspaceStep does what P3 T6's built-in workspace path does for the
// executing operation: reserve its job, claim the run resource, prepare the
// next candidate on the committed base, and return the exact receipt.
func prepareWorkspaceStep(ctx context.Context, fx stepFixture, base runner.CheckpointRef) (engine.StepCompletion, error) {
	id, ok := engine.StepIdentityFromContext(ctx)
	if !ok {
		return engine.StepCompletion{}, errors.New("no step identity on the executor context")
	}
	key := runner.JobKey{RunID: id.RunID, InvocationID: id.InvocationID, OperationID: id.OperationID, Attempt: id.Attempt}
	j, err := fx.ledger.EnsureIntent(ctx, key, id.NodeID, runner.ExecRequirements{
		Group: runner.ModelGroup{Kind: runner.CredNone}, Op: runner.OpProcess, Affinity: runner.AffinityBuiltIn, RunID: id.RunID})
	if err != nil {
		return engine.StepCompletion{}, err
	}
	if j, err = fx.ledger.Reserve(ctx, j.ID, runner.Decision{Placed: true, Runner: runner.BuiltInRunnerID, Reason: "test"}, 8, time.Now().Add(time.Hour)); err != nil {
		return engine.StepCompletion{}, err
	}
	f := runner.Fence{JobID: j.ID, RunnerID: j.RunnerID, Generation: j.Generation}
	if err := fx.ledger.MarkRunning(ctx, f); err != nil {
		return engine.StepCompletion{}, err
	}
	res, err := fx.leases.ClaimJob(ctx, fx.key, runner.JobHolder(j), f)
	if err != nil {
		return engine.StepCompletion{}, err
	}
	ref := runner.CheckpointRef{RunID: fx.run, Version: base.Version + 1, ManifestHash: stepHash('b')}
	if err := NewCheckpointCatalogRepo(fx.db).Publish(ctx, runner.CheckpointCandidate{
		Ref: ref, Base: base, Job: &f, Resource: res, ArchivePath: "/ckpt/next", SizeBytes: 10}); err != nil {
		return engine.StepCompletion{}, err
	}
	return workspaceReceipt(f, ref, res), nil
}

// committedReplay returns the committed ADVANCE result of the node's open
// invocation, or nil. Begin returns the same open invocation executeWithRetry
// reuses, so asking never creates a second visit. A suspension record is not a
// completion: the node re-enters (an awaited spawn short-circuits on its link).
func (e *Engine) committedReplay(ctx context.Context, committer StepCommitter, instanceID uuid.UUID, nodeID string) (*StepCommit, error) {
	inv, err := e.invocationStore().Begin(ctx, instanceID, nodeID)
	if err != nil {
		return nil, &stepPersistenceError{fmt.Errorf("%w: open invocation of node %q: %w", ErrStepPersistence, nodeID, err)}
	}
	c, ok, err := committer.CommittedResult(ctx, inv.ID)
	if err != nil {
		return nil, &stepPersistenceError{fmt.Errorf("%w: committed result of node %q: %w", ErrStepPersistence, nodeID, err)}
	}
	if !ok || c == nil || c.Mode == StepCommitSuspend {
		return nil, nil
	}
	if c.InvocationID == uuid.Nil {
		c.InvocationID = inv.ID
	}
	return c, nil
}
