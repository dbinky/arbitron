# Remote Runners — Phase 2 Task 11: Runner install scenario and release packaging

**Goal:** `install.sh --runner` installs `arbitron-runner` on a Mac as a per-user launchd agent (`dev.arbitron.runner`, RunAtLoad + KeepAlive) with a config skeleton and 0600 `runner.env`, and `make dist`/`release` ship checksummed (and cosign-covered) darwin `arbitron-runner` artifacts.

**Architecture:** A new self-contained "Runner" branch in `install.sh` (macOS only) reuses the existing fail-closed download/verify gate (`fetch_binary_to` gains an artifact-kind argument), the prompt primitives and the `render_launchd_plist` style. The `Makefile` `dist` target cross-compiles `./cmd/arbitron-runner` for `darwin/amd64` + `darwin/arm64` with the same `DIST_LDFLAGS`, and the `SHA256SUMS` glob is corrected so the runner artifacts are hashed (and therefore covered by the cosign signature over `SHA256SUMS`). The release workflow uploads them.

**Tech Stack:** bash 3.2+/5, bats, shellcheck, GNU make, GitHub Actions.

**Spec / Design:** spec "Execution and placement" (runners start automatically with the machine; vendor credentials stay on the runner), "Outcomes" (existing local operation needs no setup); design `docs/designs/2026-11-19-remote-runners-design-phase-2.md` §3.7 (identity and credentials), §3.8 (install and release), §5 rows "Server URL, runner key…", "Runner binary/version…", "Same execution-root availability…", "launchd plist…". Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md` §15 (runner binary `cmd/arbitron-runner/main.go`; config dir `~/.arbitron-runner/` with `config.yaml`, `runner.env` 0600 keys `ARBITRON_SERVER_URL`, `ARBITRON_RUNNER_KEY`, `LUNAROUTE_API_KEY`, `ARBITRON_EXTRA_HEADERS`; machine key `~/.arbitron-runner/machine_ed25519`).

ESCALATION: RR-05: Unattended start after a reboot using the operator's own harness accounts is unverified — a per-user LaunchAgent (launchd `gui/<uid>` domain) starts only after that user logs in, and a LaunchDaemon would run as root without the user's login keychain and Claude/Codex logins. This plan installs a per-user LaunchAgent (RunAtLoad, KeepAlive), prints the macOS automatic-login requirement (and that FileVault disables automatic login), and never presents the LaunchAgent as proof of unattended boot startup; verifying a launch context on a real rebooted Mac is an operator/hardware decision.

ESCALATION: RR-07: A common absolute execution root on Macs for a Linux-hosted server (e.g. `/var/lib/arbitron/workspaces`) may not be creatable without elevation (SIP/firmlinks; `/var` is root-owned). This plan's installer creates the operator-requested root only when it can do so without sudo; otherwise it writes the runner's own root (`$HOME/.arbitron-runner/workspaces`) into `config.yaml`, the runner advertises that root in `hello`, and the hub's root comparison (P2 T4 `CompatTable.Check`) marks the runner `chat_only` with its reason. A verified macOS layout (admin-created root or `synthetic.conf`) needs an operator decision.

```bash
# select_install_type -> Local | Shared | Runner.
# macOS is Local unless ARBITRON_INSTALL_TYPE=runner (the remote-runner agent,
# macOS-only). On Linux the operator chooses Local (per-user, ~/.arbitron, no
# sudo) or Shared (system-wide under /etc + /var with a dedicated service
# account); a runner is refused there. ARBITRON_INSTALL_TYPE forces the answer
# non-interactively; otherwise we prompt, defaulting to Shared when running as
# root (the elevated-install signal) and Local otherwise.
select_install_type() {
  local os
  os="$(detect_os)" || return 1
  case "$os" in
    macos)
      case "$(printf '%s' "${ARBITRON_INSTALL_TYPE:-}" | tr '[:upper:]' '[:lower:]')" in
        runner) printf 'Runner\n' ;;
        *)      printf 'Local\n' ;;
      esac
      ;;
    linux)
      local forced="${ARBITRON_INSTALL_TYPE:-}"
      if [ -n "$forced" ]; then
        case "$(printf '%s' "$forced" | tr '[:upper:]' '[:lower:]')" in
          local)  printf 'Local\n';  return 0 ;;
          shared) printf 'Shared\n'; return 0 ;;
          runner) log_error "remote runners are macOS-only; install the server on Linux instead"; return 1 ;;
          *)      log_error "unknown ARBITRON_INSTALL_TYPE '$forced' (want local|shared)"; return 1 ;;
        esac
      fi
      local def="local"
      is_elevated && def="shared"
      local choice
      choice="$(prompt_default INSTALL_TYPE 'Install type — local (per-user) or shared (system-wide)' "$def")"
      case "$(printf '%s' "$choice" | tr '[:upper:]' '[:lower:]')" in
        local)  printf 'Local\n' ;;
        shared) printf 'Shared\n' ;;
        *)      log_error "unknown install type '$choice'"; return 1 ;;
      esac
      ;;
    *)     return 1 ;;
  esac
}
```

```bash
# fetch_binary_to <dest> [server|runner] — resolve version + os/arch, fetch the
# artifact of the given kind (default server) and its SHA256SUMS, verify, and
# place the verified binary at <dest>. Aborts (non-zero, no artifact at <dest>)
# on any download or checksum failure. Shared with the system install
# (install_binary_system) and the runner install so the verify contract is
# identical.
fetch_binary_to() {
  local dest="$1" kind="${2:-server}" tmpdir rc
  tmpdir="$(mktemp -d "${TMPDIR:-/tmp}/arbitron-bin.XXXXXX")" || return 1
  # Clean the temp dir up on a SIGINT/SIGTERM mid-download (Ctrl-C during a slow
  # curl). We deliberately do NOT use a RETURN trap: callers (notably bats) may
  # run under functrace (set -T), where a RETURN trap is inherited by the nested
  # verify_download/verify_signature calls and fires on THEIR return — deleting
  # the temp dir before the binary is moved into place. Cleanup is centralised
  # here on the single path every return in _fetch_binary_to funnels back to.
  trap 'rm -rf "${tmpdir:-}"' INT TERM
  _fetch_binary_to "$dest" "$tmpdir" "$kind"
  rc=$?
  trap - INT TERM
  rm -rf "$tmpdir"
  return "$rc"
}
```

```bash
# ===========================================================================
# RUNNER install (macOS only) — Remote Runners Phase 2.
#
# Installs the arbitron-runner agent per-user under ~/.arbitron-runner with a
# launchd LaunchAgent (dev.arbitron.runner). The runner dials OUT to the server
# with its runner key; vendor credentials (claude/codex logins, an optional
# LunaRoute key) stay on this Mac. The server layout (~/.arbitron) is untouched.
# ===========================================================================

ARBITRON_RUNNER_LAUNCHD_LABEL="dev.arbitron.runner"

runner_home()   { printf '%s/.arbitron-runner\n' "$HOME"; }
runner_bin()    { printf '%s/bin\n' "$(runner_home)"; }
runner_config() { printf '%s/config.yaml\n' "$(runner_home)"; }
runner_env()    { printf '%s/runner.env\n' "$(runner_home)"; }
runner_logs()   { printf '%s/logs\n' "$(runner_home)"; }
_runner_plist_path() { printf '%s/Library/LaunchAgents/%s.plist\n' "$HOME" "$ARBITRON_RUNNER_LAUNCHD_LABEL"; }

# arbitron_runner_artifact_name <version> <os> <arch> — the runner release
# artifact basename `arbitron-runner_<version>_<os>_<arch>` (Makefile dist).
arbitron_runner_artifact_name() {
  local version="$1" os="$2" arch="$3"
  printf '%s\n' "arbitron-runner_${version}_${os}_${arch}"
}

# download_runner_binary — fetch + verify the runner into ~/.arbitron-runner/bin (0755).
download_runner_binary() {
  local bin
  bin="$(runner_bin)/arbitron-runner"
  mkdir -p "$(runner_bin)"
  fetch_binary_to "$bin" runner || return 1
  chmod 0755 "$bin"
  log_info "installed arbitron-runner at $bin"
}
```

```bash
# write_runner_env — create ~/.arbitron-runner/runner.env (0600) with the server
# URL and runner key (ARBITRON_RUNNER_SERVER_URL / ARBITRON_RUNNER_KEY or the
# prompts). Optional keys are left as commented guidance. An existing file is
# never overwritten; its mode is re-tightened to 0600 (the runner refuses a
# group/world-readable env).
write_runner_env() {
  local envf url key old_umask
  envf="$(runner_env)"
  if [ -f "$envf" ]; then
    chmod 600 "$envf"
    log_info "keeping existing $envf"
    return 0
  fi

  key="$(prompt_secret RUNNER_KEY 'Runner key (ark_..., shown once when an admin created it)' '')"

  umask 077

    printf '# Arbitron runner secrets. Mode 0600; never commit or share.\n'
    printf 'ARBITRON_SERVER_URL=%s\n' "$url"
    printf 'ARBITRON_RUNNER_KEY=%s\n' "$key"
    printf '# Optional: the LunaRoute key of THIS Mac (never sent to the server).\n'

    printf '# ARBITRON_EXTRA_HEADERS=CF-Access-Client-Id: <id>;CF-Access-Client-Secret: <secret>\n'
  } >"$envf"
  umask "$old_umask"
  chmod 600 "$envf"
}
```
