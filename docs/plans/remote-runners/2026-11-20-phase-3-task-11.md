## Alignment repair — required replacement work (2026-11-20)

**Fence cleanup with the active resource claim.** Copy deletion must compare run/resource key plus home/resource generation and cannot delete a newer active copy merely because a stale home row matched. Before `RemoveInstanceDir`, checkpoint removal or remote `delete_copy`, acquire the durable resource lease (P3 T3) or record a fenced tombstone pending safe cleanup; an active job/server group mutation blocks deletion. Use the same lease repo in `CopyKeeperDeps` and `RemovalDeps`, wired by P3 T13. Retain offline tombstones across restart until acknowledgment. Add failing `TestRemoval_ActiveWriterPreventsLocalAndRemoteDelete`, `TestCopyKeeper_StaleDeleteCannotRemoveNewGeneration`, and a root race test where cleanup runs during a held same-run mutation. Existing generation checks remain, but are not a replacement for an exclusive writer claim.

---

**Goal:** Track which runner holds which home generation of every run's workspace; after a planned move tell the old home to delete its copy once the new generation is recorded; on reconnect fence a runner's stale copies and tell it to delete them; when a run's workspace is removed (`RemoveInstanceDir` from completion cleanup, the group launcher or the group pruner) tell the home and every known copy holder to delete — an offline runner is told on its next `hello`; and make the runner refuse to delete a copy newer than the one named.

**Architecture:** `runner_copies` (migration 044, P3 T1) is the inventory (`adapter/sqlite/runner_copy_repo.go`). `domain/runner/copy_keeper.go:CopyKeeper` owns the rules: `HomeMoved` (called by the `NewCopyTrackingHomes` decorator around every `HandOff`/`Release`) and `ReconcileCopies` (called by the hub on admission with the runner's reported copies). The hub only transports: `Hub.DeleteCopy` sends `delete_copy` to a live session and reports whether it could. Delivery is confirmed by absence: a pending delete stays pending until a later `hello` no longer lists the copy. The engine gets a removal seam (`WorkspaceRemovalHook`, `SetWorkspaceRemovalHook` for its own cleanup, and `WithWorkspaceRemovalHook` decorating the `WorkspaceManager` handed to the group launcher and pruner); `runner.RemovalNotifier` implements it. Runner side: the agent reports held copies in `hello` and applies `delete_copy` through a `CopyJanitor` (the T9 `Syncer`), which deletes only when its local generation is ≤ the named one.

**Tech Stack:** Go 1.25.5, hand-written SQL (pattern `adapter/sqlite/audit_repo.go`, SQLite upsert), testify, `adapter/runner/hubtest` fixtures (P2 T4).

**Spec / Design:** spec "Workspace mobility" (fencing, deletion); design phase 3 §3.6 (Fencing and stale copies), §3.8 (Workspace removal on runners), §5 row "Transfer/session tokens … deletion inventory" (RR-08/RR-09: "Deletion needs a resource-generation fence and must not delete a newer copy"), "Deferred to plans: Hook `RemoveInstanceDir` call sites to runner deletion", §8 Edge-case "Deletion is delivered to a runner that was offline at removal time". // domain/runner/copies.go
```go
package runner

import (
	"context"
	"errors"
	"time"

	"github.com/google/uuid"
)

// CopyStatus is the inventory state of one runner's copy of a run's workspace.
type CopyStatus string

const (
	CopyActive        CopyStatus = "active"         // held at the recorded home generation
	CopyStale         CopyStatus = "stale"          // reported on reconnect for a generation the runner no longer owns; delete sent
	CopyDeletePending CopyStatus = "delete_pending" // deletion ordered (planned move or workspace removal); not yet confirmed
	CopyDeleted       CopyStatus = "deleted"        // a later hello no longer lists it
)

var ErrInvalidCopyStatus = errors.New("runner: invalid copy status for this operation")

type RunnerCopy struct {
	RunID          uuid.UUID
	RunnerID       RunnerID
	HomeGeneration int64
	Status         CopyStatus
	UpdatedAt      time.Time
}

// CopyInventory records runner-held workspace copies (runner_copies).
type CopyInventory interface {
	RecordHeld(ctx context.Context, runID uuid.UUID, id RunnerID, gen int64) error
	// MarkForDeletion records that copies at or below upTo must go. It never
	// touches an active row whose generation is newer than upTo.
	MarkForDeletion(ctx context.Context, runID uuid.UUID, id RunnerID, upTo int64, status CopyStatus) error
	MarkDeleted(ctx context.Context, runID uuid.UUID, id RunnerID) error
	PendingDeletes(ctx context.Context, id RunnerID) ([]RunnerCopy, error)
	ListByRun(ctx context.Context, runID uuid.UUID) ([]RunnerCopy, error)
}

// MsgDeleteCopy tells a runner to delete its copy of a run's workspace.
const MsgDeleteCopy = "delete_copy"

// DeleteCopyPayload: delete the local copy of RunID if its home generation is
// at or below HomeGeneration (a newer copy is never deleted).
type DeleteCopyPayload struct {
	RunID          uuid.UUID
	HomeGeneration int64
	Reason         string
}

// HeldCopyInfo is one copy a runner reports in hello.
type HeldCopyInfo struct {
	RunID          uuid.UUID
	HomeGeneration int64
}

// CopyReconciler decides which reported copies a reconnecting runner must delete.
type CopyReconciler interface {
	ReconcileCopies(ctx context.Context, id RunnerID, held []HeldCopyInfo) ([]DeleteCopyPayload, error)
}

// CopyDeleter sends a delete to a connected runner; false when it is offline.
type CopyDeleter interface {
	DeleteCopy(ctx context.Context, id RunnerID, p DeleteCopyPayload) bool
}
```

```go
package sqlite

import (
	"context"
	"database/sql"
	"fmt"
	"time"

	"github.com/arbitron/arbitron/domain/runner"
	"github.com/google/uuid"
)

// RunnerCopyRepo implements runner.CopyInventory over runner_copies (044).
type RunnerCopyRepo struct {
	db  *sql.DB
	now func() time.Time
}

func NewRunnerCopyRepo(db *sql.DB) *RunnerCopyRepo { return &RunnerCopyRepo{db: db, now: time.Now} }

func (r *RunnerCopyRepo) RecordHeld(ctx context.Context, runID uuid.UUID, id runner.RunnerID, gen int64) error {
	const q = `INSERT INTO runner_copies (run_id, runner_id, home_generation, state, updated_at)
	           VALUES (?, ?, ?, 'active', ?)
	           ON CONFLICT (run_id, runner_id) DO UPDATE SET
	             home_generation = excluded.home_generation, state = 'active', updated_at = excluded.updated_at`
	if _, err := r.db.ExecContext(ctx, q, uuidToString(runID), string(id), gen, timeToString(r.now())); err != nil {
		return fmt.Errorf("recording runner copy: %w", err)
	}
	return nil
}

func (r *RunnerCopyRepo) MarkForDeletion(ctx context.Context, runID uuid.UUID, id runner.RunnerID, upTo int64, status runner.CopyStatus) error {
	if status != runner.CopyStale && status != runner.CopyDeletePending {
		return fmt.Errorf("%w: %q", runner.ErrInvalidCopyStatus, status)
	}
	const q = `INSERT INTO runner_copies (run_id, runner_id, home_generation, state, updated_at)
	           VALUES (?, ?, ?, ?, ?)
	           ON CONFLICT (run_id, runner_id) DO UPDATE SET
	             home_generation = excluded.home_generation, state = excluded.state, updated_at = excluded.updated_at
	           WHERE NOT (runner_copies.state = 'active' AND runner_copies.home_generation > excluded.home_generation)`
	if _, err := r.db.ExecContext(ctx, q, uuidToString(runID), string(id), upTo, string(status), timeToString(r.now())); err != nil {
		return fmt.Errorf("marking runner copy for deletion: %w", err)
	}
	return nil
}

func (r *RunnerCopyRepo) MarkDeleted(ctx context.Context, runID uuid.UUID, id runner.RunnerID) error {
	const q = `UPDATE runner_copies SET state = 'deleted', updated_at = ?
	           WHERE run_id = ? AND runner_id = ? AND state IN ('stale', 'delete_pending')`
	if _, err := r.db.ExecContext(ctx, q, timeToString(r.now()), uuidToString(runID), string(id)); err != nil {
		return fmt.Errorf("marking runner copy deleted: %w", err)
	}
	return nil
}

func (r *RunnerCopyRepo) PendingDeletes(ctx context.Context, id runner.RunnerID) ([]runner.RunnerCopy, error) {
	return r.query(ctx, `SELECT run_id, runner_id, home_generation, state, updated_at FROM runner_copies
	                     WHERE runner_id = ? AND state IN ('stale', 'delete_pending') ORDER BY run_id`, string(id))
}

func (r *RunnerCopyRepo) ListByRun(ctx context.Context, runID uuid.UUID) ([]runner.RunnerCopy, error) {
	return r.query(ctx, `SELECT run_id, runner_id, home_generation, state, updated_at FROM runner_copies
	                     WHERE run_id = ? AND state != 'deleted' ORDER BY runner_id`, uuidToString(runID))
}
```

```go
// domain/runner/copy_keeper.go
package runner

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"strconv"
	"strings"

	"github.com/google/uuid"
)

// CopyKeeperDeps are all required. Leases is the one ResourceLeaseStore the
// workspace sync, recovery, removal and drain share (P3 T13).
type CopyKeeperDeps struct {
	Inventory CopyInventory
	Homes     HomeStore
	Deleter   CopyDeleter
	Leases    ResourceLeaseStore
}

// CopyKeeper owns the runner-copy rules: a planned move retires the old
// home's copy; a reconnecting runner's stale copies are fenced and deleted;
// absence on a later hello confirms a deletion.
type CopyKeeper struct{ d CopyKeeperDeps }

func NewCopyKeeper(d CopyKeeperDeps) (*CopyKeeper, error) {
	var missing []string
	if d.Inventory == nil {
		missing = append(missing, "Inventory")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if d.Deleter == nil {
		missing = append(missing, "Deleter")
	}
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: NewCopyKeeper missing %s", strings.Join(missing, ", "))
	}
	return &CopyKeeper{d: d}, nil
}

// tracksCopies: server storage and the built-in runner hold no runner copy.
func tracksCopies(id RunnerID) bool { return id != ServerHome && id != BuiltInRunnerID }

func deleteHolder(runID uuid.UUID, target RunnerID, upTo int64) string {
	return "delete:" + runID.String() + "@" + strconv.FormatInt(upTo, 10) + "/" + string(target)
}

// authorizeCopyDelete decides whether target may be told to delete its copy
// of runID now. An active claim OWNED BY target means target is writing that
// copy: the tombstone stays owed (ok=false). An active claim owned by another
// runner or the server does not cover target's copy; the delete's
// HomeGeneration bound protects the holder's newer generation. With no active
// claim the delete takes its own server-side claim for the send; release
// gives it back. ErrResourceBusy from that claim (a writer raced in) also
// leaves the tombstone owed.
func authorizeCopyDelete(ctx context.Context, leases ResourceLeaseStore, runID uuid.UUID, target RunnerID, upTo int64) (release func(), ok bool, err error) {
	key := runKey(runID)
	rec, active, err := leases.Active(ctx, key)
	if err != nil {
		return nil, false, fmt.Errorf("authorizing copy delete of %s on %s: %w", runID, target, err)
	}
	if active {
		if rec.Fence.Owner == string(target) {
			return nil, false, nil
		}
		return func() {}, true, nil
	}
	ref, err := leases.Claim(ctx, key, deleteHolder(runID, target, upTo), target)
	if errors.Is(err, ErrResourceBusy) {
		return nil, false, nil
	}
	if err != nil {
		return nil, false, fmt.Errorf("authorizing copy delete of %s on %s: %w", runID, target, err)
	}
	return func() {
		if err := leases.Release(context.WithoutCancel(ctx), ref); err != nil {
			slog.Warn("releasing copy-delete claim", "run", runID, "runner", target, "error", err)
		}
	}, true, nil
}

// send delivers p to target if the lease authorizes it; false when held or offline.
func (k *CopyKeeper) send(ctx context.Context, target RunnerID, p DeleteCopyPayload) (bool, error) {
	release, ok, err := authorizeCopyDelete(ctx, k.d.Leases, p.RunID, target, p.HomeGeneration)
	if err != nil || !ok {
		return false, err
	}
	defer release()
	return k.d.Deleter.DeleteCopy(ctx, target, p), nil
}

// HomeMoved is called after a committed home change from `from` to `to`.
// The new home's copy is recorded active; the old home's copies at or below
// the previous generation are tombstoned and, when authorized, deleted now
// (otherwise on its next hello).
func (k *CopyKeeper) HomeMoved(ctx context.Context, runID uuid.UUID, from RunnerID, to Home) error {
	if tracksCopies(to.RunnerID) {
		if err := k.d.Inventory.RecordHeld(ctx, runID, to.RunnerID, to.Generation); err != nil {
			return err
		}
	}
	if !tracksCopies(from) || from == to.RunnerID {
		return nil
	}
	upTo := to.Generation - 1
	if err := k.d.Inventory.MarkForDeletion(ctx, runID, from, upTo, CopyDeletePending); err != nil {
		return err
	}
	dest := string(to.RunnerID)
	if to.RunnerID == ServerHome {
		dest = "server"
	}
	_, err := k.send(ctx, from, DeleteCopyPayload{RunID: runID, HomeGeneration: upTo, Reason: "home moved to " + dest})
	return err
}

// ReconcileCopies runs on every admission. Owed deletes the runner still
// reports are re-sent (bounded by the reported generation); unknown or stale
// copies are marked stale and deleted; the current home's copy is kept; owed
// deletes the runner no longer reports are confirmed deleted. It delivers
// every authorized delete itself and returns the payloads it sent.
func (k *CopyKeeper) ReconcileCopies(ctx context.Context, id RunnerID, held []HeldCopyInfo) ([]DeleteCopyPayload, error) {
	pending, err := k.d.Inventory.PendingDeletes(ctx, id)
	if err != nil {
		return nil, err
	}
	owed := make(map[uuid.UUID]RunnerCopy, len(pending))
	for _, c := range pending {
		owed[c.RunID] = c
	}
	reported := make(map[uuid.UUID]bool, len(held))
	var sent []DeleteCopyPayload
	var errs []error
	for _, c := range held {
		reported[c.RunID] = true
		p, ok, err := k.reconcileOne(ctx, id, c, owed)
		if err != nil {
			errs = append(errs, err)
			continue
		}
		if ok {
			sent = append(sent, p)
		}
	}
	for run := range owed {
		if !reported[run] {
			if err := k.d.Inventory.MarkDeleted(ctx, run, id); err != nil {
				errs = append(errs, err)
			}
		}
	}
	return sent, errors.Join(errs...)
}

func (k *CopyKeeper) reconcileOne(ctx context.Context, id RunnerID, c HeldCopyInfo, owed map[uuid.UUID]RunnerCopy) (DeleteCopyPayload, bool, error) {
	p := DeleteCopyPayload{RunID: c.RunID, HomeGeneration: c.HomeGeneration}
	if o, ok := owed[c.RunID]; ok && c.HomeGeneration <= o.HomeGeneration {
		p.Reason = "owed deletion"
	} else {
		h, err := k.d.Homes.GetHome(ctx, c.RunID)
		if err != nil {
			return p, false, err
		}
		if h.RunnerID == id && c.HomeGeneration == h.Generation {
			return p, false, k.d.Inventory.RecordHeld(ctx, c.RunID, id, h.Generation) // the current home's copy
		}
		if h.RunnerID == id && c.HomeGeneration > h.Generation {
			slog.Warn("runner reports a copy newer than its home; keeping it", "run", c.RunID, "runner", id,
				"reported", c.HomeGeneration, "home", h.Generation)
			return p, false, nil // a newer copy is never deleted
		}
		p.Reason = "stale copy"
		if err := k.d.Inventory.MarkForDeletion(ctx, c.RunID, id, c.HomeGeneration, CopyStale); err != nil {
			return p, false, err
		}
	}
	ok, err := k.send(ctx, id, p)
	return p, ok, err
}

// copyTrackingHomes reports every committed home change to the keeper. A
// keeper failure never fails a committed handoff: the tombstone is recreated
// on the runner's next hello (stale copy).
type copyTrackingHomes struct {
	HomeStore
	k *CopyKeeper
}

func NewCopyTrackingHomes(inner HomeStore, k *CopyKeeper) HomeStore {
	if inner == nil || k == nil {
		panic("runner: NewCopyTrackingHomes requires a HomeStore and a CopyKeeper")
	}
	return copyTrackingHomes{HomeStore: inner, k: k}
}

func (c copyTrackingHomes) AcquireResource(ctx context.Context, runID uuid.UUID, owner RunnerID, expectGen int64) (Home, error) {
	prev, err := c.HomeStore.GetHome(ctx, runID)
	if err != nil {
		return Home{}, err
	}
	h, err := c.HomeStore.AcquireResource(ctx, runID, owner, expectGen)
	if err != nil {
		return h, err
	}
	c.moved(ctx, runID, prev, h)
	return h, nil
}

func (c copyTrackingHomes) HandOff(ctx context.Context, runID uuid.UUID, to RunnerID, reason string, bytes, expectGen int64, cause HomeMoveCause) (Home, error) {
	prev, err := c.HomeStore.GetHome(ctx, runID)
	if err != nil {
		return Home{}, err
	}
	h, err := c.HomeStore.HandOff(ctx, runID, to, reason, bytes, expectGen, cause)
	if err != nil {
		return h, err
	}
	c.moved(ctx, runID, prev, h)
	return h, nil
}

func (c copyTrackingHomes) Release(ctx context.Context, runID uuid.UUID, expectGen int64) error {
	prev, err := c.HomeStore.GetHome(ctx, runID)
	if err != nil {
		return err
	}
	if err := c.HomeStore.Release(ctx, runID, expectGen); err != nil {
		return err
	}
	h, err := c.HomeStore.GetHome(ctx, runID)
	if err != nil {
		slog.Warn("reading released home for copy tracking", "run", runID, "error", err)
		return nil
	}
	c.moved(ctx, runID, prev, h)
	return nil
}

// moved runs only for a real change: the CAS succeeded at prev's generation,
// so prev.RunnerID is exactly the owner that was replaced.
func (c copyTrackingHomes) moved(ctx context.Context, runID uuid.UUID, prev, h Home) {
	if h.Generation == prev.Generation {
		return
	}
```

```go
// WorkspaceRemovalHook is told after a run's server workspace directory has
// been removed, so runners holding copies can delete theirs (runner.RemovalNotifier).
type WorkspaceRemovalHook interface {
	WorkspaceRemoved(ctx context.Context, runID uuid.UUID)
}

const removalHookTimeout = 30 * time.Second

// SetWorkspaceRemovalHook installs the hook for the engine's own completion
// cleanup. Components that remove workspaces themselves (group launcher,
// group pruner) receive a WithWorkspaceRemovalHook-decorated manager instead.
func (e *Engine) SetWorkspaceRemovalHook(h WorkspaceRemovalHook) { e.removalHook = h }

func notifyRemoval(h WorkspaceRemovalHook, id uuid.UUID) {
	if h == nil {
		return
	}
	ctx, cancel := context.WithTimeout(context.Background(), removalHookTimeout)
	defer cancel()
	h.WorkspaceRemoved(ctx, id)
}

	WorkspaceManager
	hook WorkspaceRemovalHook
}

}

func (w hookedWorkspaces) RemoveInstanceDir(id uuid.UUID) error {
	if err := w.WorkspaceManager.RemoveInstanceDir(id); err != nil {
		return err
	}
	notifyRemoval(w.hook, id)
	return nil
}
```

```go
package runner

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"sort"
	"strings"

	"github.com/google/uuid"
)

// CheckpointDeleter removes every server checkpoint of a run (P3 T2 Store.Delete).
type CheckpointDeleter interface {
	Delete(ctx context.Context, runID uuid.UUID) error
}

// RemovalDeps are all required. Homes is the UNdecorated home repo: the
// notifier sends its own deletes.
type RemovalDeps struct {
	Inventory   CopyInventory
	Homes       HomeStore
	Checkpoints CheckpointDeleter
	Deleter     CopyDeleter
	Leases      ResourceLeaseStore
}

// RemovalNotifier implements engine.WorkspaceRemovalHook.
type RemovalNotifier struct{ d RemovalDeps }

func NewRemovalNotifier(d RemovalDeps) (*RemovalNotifier, error) {
	var missing []string
	if d.Inventory == nil {
		missing = append(missing, "Inventory")
	}
	if d.Homes == nil {
		missing = append(missing, "Homes")
	}
	if d.Checkpoints == nil {
		missing = append(missing, "Checkpoints")
	}
	if d.Deleter == nil {
		missing = append(missing, "Deleter")
	}
	if d.Leases == nil {
		missing = append(missing, "Leases")
	}
	if len(missing) > 0 {
		return nil, fmt.Errorf("runner: NewRemovalNotifier missing %s", strings.Join(missing, ", "))
	}
	return &RemovalNotifier{d: d}, nil
}

// WorkspaceRemoved never fails its caller (an engine hook); errors are logged
// and the durable tombstones let RetryDeferred or the runner's next hello
// finish the work.
func (n *RemovalNotifier) WorkspaceRemoved(ctx context.Context, runID uuid.UUID) {
	if err := n.remove(ctx, runID); err != nil {
		slog.Warn("runner workspace removal", "run", runID, "error", err)
	}
}

// RetryDeferred finishes every removal still owed on the server side.
func (n *RemovalNotifier) RetryDeferred(ctx context.Context) error {
	owed, err := n.d.Inventory.PendingDeletes(ctx, BuiltInRunnerID)
	if err != nil {
		return err
	}
	var errs []error
	for _, c := range owed {
		if err := n.remove(ctx, c.RunID); err != nil {
			errs = append(errs, fmt.Errorf("run %s: %w", c.RunID, err))
		}
	}
	return errors.Join(errs...)
}

func (n *RemovalNotifier) remove(ctx context.Context, runID uuid.UUID) error {
	claim, err := n.d.Leases.Claim(ctx, runKey(runID), "remove:"+runID.String(), BuiltInRunnerID)
	busy := errors.Is(err, ErrResourceBusy)
	if err != nil && !busy {
		return err
	}
	if !busy {
		defer func() {
			if err := n.d.Leases.Release(context.WithoutCancel(ctx), claim); err != nil {
				slog.Warn("releasing workspace removal claim", "run", runID, "error", err)
			}
		}()
	}
	h, err := n.d.Homes.GetHome(ctx, runID)
	if err != nil {
		return err
	}
	upTo := h.Generation + 1 // covers every generation, including the home's
	holders, err := n.holders(ctx, runID, h)
	if err != nil {
		return err
	}
	if err := n.d.Inventory.MarkForDeletion(ctx, runID, BuiltInRunnerID, upTo, CopyDeletePending); err != nil {
		return err
	}
	for _, id := range holders {
		if err := n.d.Inventory.MarkForDeletion(ctx, runID, id, upTo, CopyDeletePending); err != nil {
			return err
		}
	}
	if busy {
		slog.Info("workspace removal deferred: a writer holds the run's resource", "run", runID)
		return nil
	}
	if h.RunnerID != ServerHome {
		if err := n.d.Homes.Release(ctx, runID, h.Generation); err != nil {
			return fmt.Errorf("releasing removed workspace home: %w", err)
		}
	}
	if err := n.d.Checkpoints.Delete(ctx, runID); err != nil {
		return fmt.Errorf("deleting removed workspace checkpoints: %w", err)
	}
	if err := n.d.Inventory.MarkDeleted(ctx, runID, BuiltInRunnerID); err != nil {
		return err
	}
	for _, id := range holders {
		n.d.Deleter.DeleteCopy(ctx, id, DeleteCopyPayload{RunID: runID, HomeGeneration: upTo, Reason: "workspace removed"})
	}
	return nil
}

// holders is the current home (if remote) plus every known remote copy holder.
func (n *RemovalNotifier) holders(ctx context.Context, runID uuid.UUID, h Home) ([]RunnerID, error) {
	copies, err := n.d.Inventory.ListByRun(ctx, runID)
	if err != nil {
		return nil, err
	}
	set := map[RunnerID]bool{}
	if tracksCopies(h.RunnerID) {
		set[h.RunnerID] = true
	}
	for _, c := range copies {
		if tracksCopies(c.RunnerID) {
			set[c.RunnerID] = true
		}
	}
	out := make([]RunnerID, 0, len(set))
	for id := range set {
		out = append(out, id)
	}
	sort.Slice(out, func(i, j int) bool { return out[i] < out[j] })
	return out, nil
}
```

```go
package runnerproto

import (
	"fmt"

	"github.com/google/uuid"
)

// WireCopy is one workspace copy a runner holds, reported in hello.
type WireCopy struct {
	RunID          string `json:"runId"`
	HomeGeneration int64  `json:"homeGeneration"`
}

func (c *WireCopy) Validate() error {
	if _, err := uuid.Parse(c.RunID); err != nil {
		return fmt.Errorf("%w: copy runId", ErrMalformed)
	}
	if c.HomeGeneration < 0 {
		return fmt.Errorf("%w: copy homeGeneration", ErrMalformed)
	}
	return nil
}

// DeleteCopy orders the runner to delete its copy of RunID when the copy's
// home generation is at or below HomeGeneration.
type DeleteCopy struct {
	RunID          string `json:"runId"`
	HomeGeneration int64  `json:"homeGeneration"`
	Reason         string `json:"reason,omitempty"`
}

func (d *DeleteCopy) Validate() error {
	c := WireCopy{RunID: d.RunID, HomeGeneration: d.HomeGeneration}
	return c.Validate()
}
```

```go
func (a *Agent) heldCopies(ctx context.Context) []HeldCopy {
	if a.d.Copies == nil {
		return nil
	}
	cs, err := a.d.Copies.HeldCopies(ctx)

		a.log.Warn("listing local workspace copies", "error", err)
		return nil

	return cs

// onDeleteCopy runs synchronously in the receive loop so a later dispatch for
// the same run never races the deletion.
func (a *Agent) onDeleteCopy(ctx context.Context, d *DeleteCopy) {
	if d == nil || a.d.Copies == nil {
		return
	}
	deleted, err := a.d.Copies.DeleteCopy(ctx, d.RunID, d.HomeGeneration)
	switch {
	case err != nil:
		a.log.Warn("deleting workspace copy", "runID", d.RunID, "error", err)
	case deleted:
		a.log.Info("deleted workspace copy", "runID", d.RunID, "upTo", d.HomeGeneration, "reason", d.Reason)
	default:
		a.log.Info("kept workspace copy (absent or newer)", "runID", d.RunID, "upTo", d.HomeGeneration)
	}
}
```

```go
// adapter/runneragent/workspace/janitor.go
package workspace

import (
	"context"
	"fmt"
	"os"

	"github.com/arbitron/arbitron/domain/runneragent"
	"github.com/google/uuid"
)

var _ runneragent.CopyJanitor = (*Syncer)(nil)

// HeldCopies reports every local copy with its home generation (hello).
func (s *Syncer) HeldCopies(ctx context.Context) ([]runneragent.HeldCopy, error) {
	states, err := s.d.Copies.List(ctx)
	if err != nil {
		return nil, err
	}
	out := make([]runneragent.HeldCopy, 0, len(states))
	for _, st := range states {
		out = append(out, runneragent.HeldCopy{RunID: st.RunID.String(), HomeGeneration: st.HomeGeneration})
	}
	return out, nil
}

// DeleteCopy removes the local copy of runID when its home generation is at
// or below upTo. A newer copy (this runner became the home again and pulled)
// is kept.
func (s *Syncer) DeleteCopy(ctx context.Context, runID string, upTo int64) (bool, error) {
	id, err := uuid.Parse(runID)
	if err != nil {
		return false, fmt.Errorf("runner workspace: delete copy: %w", err)
	}
	st, ok, err := s.d.Copies.Get(ctx, id)
	if err != nil || !ok {
		return false, err
	}
	if st.HomeGeneration > upTo {
		return false, nil
	}
	local, err := s.LocalPath(st.WorkDir)
	if err != nil {
		return false, err
	}
	if err := os.RemoveAll(local); err != nil {
		return false, fmt.Errorf("runner workspace: removing %s: %w", local, err)
	}
	if err := s.d.Copies.Delete(ctx, id); err != nil {
		return false, err
	}
	return true, nil
}
```
