**Goal:** Move workspace bytes off the control channel: short-lived transfer tokens scoped to one job generation, runner, run and direction, and the `/api/v1/runners/transfers/*` endpoints that serve the committed manifest and files, accept resumable hash-verified push parts, publish a push only after the full delta verifies under the fence, and serve script bundles by hash.

**Architecture:** `domain/runner/transfer.go` gains `TransferTokenService` (random 32-byte tokens, only the SHA-256 stored, validation re-checks the ledger fence on every request) over a `TransferSessionStore` port implemented by `adapter/sqlite/transfer_token_repo.go` (`transfer_sessions`, migration 044). `adapter/http/runner_transfer_handler.go` authenticates every request with the runner key (`Authorization: Runner <key>`, machine-bound) plus `X-Arbitron-Transfer`, lifts the server's 10 s read deadline per request with `http.ResponseController`, stores parts under `cfg.Runners.StagingDir`, and hands the verified delta to `CheckpointStore.StageDelta` → `WorkspaceSync.AcceptPush`. The router mounts it outside the user auth middleware when `RouterDeps.RunnerTransfers` is set.

**Tech Stack:** Go 1.25, chi, `net/http` (`http.ResponseController`, `http.MaxBytesReader`), `crypto/rand`, `crypto/sha256`, SQLite (hand-written SQL), testify, `httptest`.

**Spec / Design:** spec §"Workspace mobility" (sync transport); design phase 3 §3.3 Transport ("chunked parts of about 64 MB, resumable; each part is hash-verified; separate HTTP requests under `/api/v1/runners/transfers/*`, authenticated by the runner key plus a short-lived transfer token scoped to the job and generation; per-request read deadlines") and Progress, §7 (partial uploads never applied, staged parts expire, part hash mismatch retries that part, disk full keeps the previous checkpoint, fenced writes rejected), §8 Error ("a transfer token for the wrong job or generation is refused", "an interrupted upload never marks the step done"). Contracts: `2026-11-20-contracts.md` §8 (Fence, ErrFenced, ErrJobNotFound), §15 (RunnerKey, KeyService.Authenticate), §16 (transfer tokens, routes, headers).

Wire formats (consumed by the runner agent, P3 T9 `adapter/runneragent/transfer`):
- `GET /manifest` (pull token) → `200` JSON `runner.Manifest` of the run's latest committed checkpoint.
- `GET /files?path=<rel>` (pull token) → `200` raw bytes of one regular file of that checkpoint; `400` unsafe path; `404` absent.
- `PUT /push/{part}` (push token, header `X-Part-SHA256: <hex>`, body ≤ `PartBytes`) → `200` `{"part":n,"received":[…]}`; `422` hash mismatch (resend that part); `413` over-size. Re-sending a part replaces it (resumable by index).
- `POST /push/commit` (push token, body `{"parts":N,"sha256":"<hex of the whole delta>"}`) → `200` JSON `runner.CheckpointRef`; `409` missing part / base moved; `422` whole-stream hash or manifest mismatch; `507` server disk full (previous checkpoint kept). A retried commit after success returns the same ref.
- `GET /bundles/{hash}` (bundle token) → `200` archive bytes; `404` unknown; `503` bundles not configured.
- Auth failures: `401` missing/unknown/unbound runner key or missing token; `403` token invalid, expired, for another runner, wrong direction, or for a job generation that is no longer live.

## Issuer constructor and scope contract (unstick 2026-11-23) — authoritative over the older Cycle 1 text

The aligned issuer checks the exact live **resource claim** as well as the job fence (design §3.1 "job, workspace and session generations are checked together"; contracts §21). The constructor therefore takes a resource-check port. `runner.ResourceLeaseStore` (P3 T3, `adapter/sqlite.ResourceLeaseRepo`) satisfies it; P3 T13 passes the same single lease repo used everywhere else.

`Issue` returns `ErrTransferScope` (and stores nothing) unless ALL hold:
- `Direction` ∈ {`TransferPull`, `TransferPush`, `TransferBundle`}; `ttl > 0`; `RunID != uuid.Nil`; `Resource.Validate() == nil`.
- Exactly one authority: **job scope** (`Fence.JobID != uuid.Nil`, `Fence.RunnerID != ""`, `Fence.Generation >= 1`, `MaintenanceOperationID == ""`, and `Resource.Owner == string(Fence.RunnerID)`) or **maintenance scope** (`Fence.JobID == uuid.Nil`, `Fence.Generation == 0`, `Fence.RunnerID != ""` naming the runner the token is bound to, `MaintenanceOperationID != ""`; used by P3 T12 drain/handoff transfers).
- pull/push: `Resource.Key == "run:"+RunID.String()`, `BaseRef` parses with `ParseCheckpointRef` to a non-zero ref whose `RunID` equals `RunID`, and `BundleHash == ""`. bundle: `BundleHash` is 64 lowercase hex and `BaseRef == ""`.
Then, job scope: `fences.FenceCheck(ctx, Fence)` (stale → its `ErrFenced`); every scope: `resources.Check(ctx, Resource)` (stale → its error, e.g. `ErrResourceFenced`). Only then is a session row (hash only) created with every pinned field (`job_id`, `generation`, `maintenance_operation_id`, `base_ref`, `bundle_hash`, `resource_*`, `runner_id`, `run_id`, `direction`, `expires_at`).

`Validate` (and `Session`/`RecordPart`/`RecordCommit`, which call it) re-checks on **every** request: unknown hash → `ErrTransferTokenInvalid`; expired → `ErrTransferTokenExpired`; other runner → `ErrTransferScope`; job scope → `FenceCheck`; every scope → `resources.Check`. It returns the full pinned `TransferToken` (`Scope()` round-trips the issued `TransferScope`). The handler serves pull manifests/files ONLY from `BaseRef` (never `Latest`), bundles ONLY for `BundleHash`, and builds `StagedCheckpoint.Resource` from the session, never from archive bytes.

// memSessions is a TransferSessionStore keyed by token hash.
type memSessions struct {
	mu   sync.Mutex
	rows map[string]runner.TransferSession
}

func (m *memSessions) Create(_ context.Context, s runner.TransferSession) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	if _, dup := m.rows[s.TokenHash]; dup {
		return fmt.Errorf("duplicate token hash")
	}
	m.rows[s.TokenHash] = s
	return nil
}

func (m *memSessions) GetByHash(_ context.Context, hash string) (runner.TransferSession, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	s, ok := m.rows[hash]
	if !ok {
		return runner.TransferSession{}, runner.ErrTransferTokenInvalid
	}
	return s, nil
}

func (m *memSessions) RecordPart(_ context.Context, hash string, index int, sha string) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	s, ok := m.rows[hash]
	if !ok {
		return runner.ErrTransferTokenInvalid
	}
	parts := map[int]string{}
	for k, v := range s.Parts {
		parts[k] = v
	}
	parts[index] = sha
	s.Parts = parts
	m.rows[hash] = s
	return nil
}

func (m *memSessions) SetCheckpointRef(_ context.Context, hash, ref string) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	s, ok := m.rows[hash]
	if !ok {
		return runner.ErrTransferTokenInvalid
	}
	s.CheckpointRef = ref
	m.rows[hash] = s
	return nil
}

func (m *memSessions) DeleteExpired(_ context.Context, now time.Time) (int64, error) {
	m.mu.Lock()
	defer m.mu.Unlock()
	var n int64
	for h, s := range m.rows {
		if !now.Before(s.ExpiresAt) {
			delete(m.rows, h)
			n++
		}
	}
	return n, nil
}

// liveFences is a FenceChecker over a job -> live (runner, generation) map.

	mu   sync.Mutex
	live map[uuid.UUID]runner.Fence
}

func (l *liveFences) FenceCheck(_ context.Context, f runner.Fence) error {
	l.mu.Lock()
	defer l.mu.Unlock()
	if cur, ok := l.live[f.JobID]; !ok || cur != f {
		return fmt.Errorf("%w: job %s", runner.ErrFenced, f.JobID)
	}
	return nil
}

	svc, _, fences, now, fence := newTokenService(t)
	run := uuid.New()
	tok, err := svc.Issue(ctx, fence, run, runner.TransferPush, time.Minute)
	require.NoError(t, err)

	_, err = svc.Validate(ctx, tok.Token, "mac-2")
	assert.ErrorIs(t, err, runner.ErrTransferScope, "a token is bound to the runner it was issued to")
	_, err = svc.Validate(ctx, "art_not-a-token", "mac-1")
	assert.ErrorIs(t, err, runner.ErrTransferTokenInvalid)
	_, err = svc.Validate(ctx, "ark_runner-key-shaped", "mac-1")
	assert.ErrorIs(t, err, runner.ErrTransferTokenInvalid)

	// Failover: the job moved to generation 4; the generation-3 token is dead.
	fences.mu.Lock()
	fences.live[fence.JobID] = runner.Fence{JobID: fence.JobID, RunnerID: "mac-2", Generation: 4}
	fences.mu.Unlock()
	_, err = svc.Validate(ctx, tok.Token, "mac-1")
	assert.ErrorIs(t, err, runner.ErrFenced)
	_, err = svc.Issue(ctx, fence, run, runner.TransferPull, time.Minute)
	assert.ErrorIs(t, err, runner.ErrFenced, "no tokens for a stale generation")

	fences.mu.Lock()
	fences.live[fence.JobID] = fence
	fences.mu.Unlock()
	*now = now.Add(2 * time.Minute)
	_, err = svc.Validate(ctx, tok.Token, "mac-1")
	assert.ErrorIs(t, err, runner.ErrTransferTokenExpired)
	n, err := svc.Sweep(ctx)
	require.NoError(t, err)
	assert.Equal(t, int64(1), n)
}

package sqlite

import (

// TransferSessionRepo persists transfer sessions (migration 044
// transfer_sessions). Only token hashes are stored. Hand-written SQL, modeled
// on AuditRepo.
type TransferSessionRepo struct {
	db *sql.DB
}

var _ runner.TransferSessionStore = (*TransferSessionRepo)(nil)

// NewTransferSessionRepo creates a TransferSessionRepo over db.
func NewTransferSessionRepo(db *sql.DB) *TransferSessionRepo {
	return &TransferSessionRepo{db: db}
}

func (r *TransferSessionRepo) Create(ctx context.Context, s runner.TransferSession) error {
	parts, err := encodeTransferParts(s.Parts)
	if err != nil {
		return err
	}
	if _, err := r.db.ExecContext(ctx,
		`INSERT INTO transfer_sessions (token_hash, job_id, generation, runner_id, run_id, direction, checkpoint_ref, expires_at, parts, created_at)
		 VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
		s.TokenHash, uuidToString(s.JobID), s.Generation, string(s.RunnerID), uuidToString(s.RunID), s.Direction,
		s.CheckpointRef, timeToString(s.ExpiresAt), parts, timeToString(s.CreatedAt)); err != nil {
		return fmt.Errorf("creating transfer session: %w", err)
	}
	return nil
}

func (r *TransferSessionRepo) GetByHash(ctx context.Context, hash string) (runner.TransferSession, error) {
	var s runner.TransferSession
	var jobStr, runnerID, runStr, expires, parts, created string
	err := r.db.QueryRowContext(ctx,
		`SELECT token_hash, job_id, generation, runner_id, run_id, direction, checkpoint_ref, expires_at, parts, created_at
		 FROM transfer_sessions WHERE token_hash = ?`, hash).
		Scan(&s.TokenHash, &jobStr, &s.Generation, &runnerID, &runStr, &s.Direction, &s.CheckpointRef, &expires, &parts, &created)
	if errors.Is(err, sql.ErrNoRows) {
		return runner.TransferSession{}, runner.ErrTransferTokenInvalid
	}
	if err != nil {
		return runner.TransferSession{}, fmt.Errorf("reading transfer session: %w", err)
	}
	if s.JobID, err = parseUUID(jobStr); err != nil {
		return runner.TransferSession{}, fmt.Errorf("transfer session job id: %w", err)
	}
	if s.RunID, err = parseUUID(runStr); err != nil {
		return runner.TransferSession{}, fmt.Errorf("transfer session run id: %w", err)
	}
	if s.ExpiresAt, err = parseTime(expires); err != nil {
		return runner.TransferSession{}, fmt.Errorf("transfer session expiry: %w", err)
	}
	if s.CreatedAt, err = parseTime(created); err != nil {
		return runner.TransferSession{}, fmt.Errorf("transfer session created_at: %w", err)
	}
	s.RunnerID = runner.RunnerID(runnerID)
	raw := map[string]string{}
	if err := json.Unmarshal([]byte(parts), &raw); err != nil {
		return runner.TransferSession{}, fmt.Errorf("transfer session parts: %w", err)
	}
	s.Parts = make(map[int]string, len(raw))
	for k, v := range raw {
		i, err := strconv.Atoi(k)
		if err != nil {
			return runner.TransferSession{}, fmt.Errorf("transfer session part index %q: %w", k, err)
		}
		s.Parts[i] = v
	}
	return s, nil
}

func (r *TransferSessionRepo) RecordPart(ctx context.Context, hash string, index int, sha256Hex string) error {
	if index < 0 {
		return fmt.Errorf("transfer session: negative part index %d", index)
	}
	res, err := r.db.ExecContext(ctx,
		`UPDATE transfer_sessions SET parts = json_set(parts, ?, ?) WHERE token_hash = ?`,
		fmt.Sprintf(`$."%d"`, index), sha256Hex, hash)
	if err != nil {
		return fmt.Errorf("recording transfer part: %w", err)
	}
	return oneTransferRow(res)
}

func (r *TransferSessionRepo) SetCheckpointRef(ctx context.Context, hash, ref string) error {
	res, err := r.db.ExecContext(ctx, `UPDATE transfer_sessions SET checkpoint_ref = ? WHERE token_hash = ?`, ref, hash)
	if err != nil {
		return fmt.Errorf("recording transfer commit: %w", err)
	}
	return oneTransferRow(res)
}

func (r *TransferSessionRepo) DeleteExpired(ctx context.Context, now time.Time) (int64, error) {
	res, err := r.db.ExecContext(ctx, `DELETE FROM transfer_sessions WHERE expires_at <= ?`, timeToString(now))
	if err != nil {
		return 0, fmt.Errorf("deleting expired transfer sessions: %w", err)
	}
	return res.RowsAffected()
}

func oneTransferRow(res sql.Result) error {
	n, err := res.RowsAffected()
	if err != nil {
		return fmt.Errorf("transfer session rows: %w", err)
	}
	if n != 1 {
		return runner.ErrTransferTokenInvalid
	}
	return nil
}

func encodeTransferParts(parts map[int]string) (string, error) {
	raw := make(map[string]string, len(parts))
	for k, v := range parts {
		raw[strconv.Itoa(k)] = v
	}
	b, err := json.Marshal(raw)
	if err != nil {
		return "", fmt.Errorf("encoding transfer parts: %w", err)
	}
	return string(b), nil
}

func partPath(dir string, index int) string {
	return filepath.Join(dir, fmt.Sprintf("part-%06d", index))

func validHexSHA256(s string) bool {
	if len(s) != 64 {
		return false
	}
	_, err := hex.DecodeString(s)
	return err == nil

// maybeSweep removes expired sessions and staged part directories older than
// the retention, at most once a minute. Best effort.
func (h *RunnerTransferHandler) maybeSweep(ctx context.Context) {
	now := h.d.Clock()
	h.mu.Lock()
	if now.Sub(h.lastSweep) < time.Minute {
		h.mu.Unlock()
		return
	}
	h.lastSweep = now
	h.mu.Unlock()
	if _, err := h.d.Tokens.Sweep(ctx); err != nil {
		slog.Warn("transfer: sweeping expired sessions", "error", err)
	}
	entries, err := os.ReadDir(h.d.StagingDir)
	if err != nil {
		return
	}
	for _, e := range entries {
		info, err := e.Info()
		if err != nil || now.Sub(info.ModTime()) < h.d.StagingRetention {
			continue
		}
		_ = os.RemoveAll(filepath.Join(h.d.StagingDir, e.Name()))
	}
}

func (h *RunnerTransferHandler) putPart(w http.ResponseWriter, r *http.Request) {
	sess, token, ok := h.authorize(w, r, runner.TransferPush)
	if !ok {
		return
	}
	h.extendDeadlines(w)
	idx, err := strconv.Atoi(chi.URLParam(r, "part"))
	if err != nil || idx < 0 || idx >= MaxTransferParts {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", fmt.Sprintf("part index must be 0..%d", MaxTransferParts-1))
		return
	}
	want := strings.ToLower(strings.TrimSpace(r.Header.Get(PartSHA256Header)))
	if !validHexSHA256(want) {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", PartSHA256Header+" must be a hex SHA-256")
		return
	}
	h.maybeSweep(r.Context())
	dir := h.sessionDir(sess)
	if err := os.MkdirAll(dir, 0o700); err != nil {
		slog.Error("transfer: creating staging dir", "error", err)
		WriteError(w, http.StatusInternalServerError, "INTERNAL", "staging failed")
		return
	}
	tmp, err := os.CreateTemp(dir, "upload-*.tmp")
	if err != nil {
		slog.Error("transfer: creating part file", "error", err)
		WriteError(w, http.StatusInternalServerError, "INTERNAL", "staging failed")
		return
	}
	hasher := sha256.New()
	n, copyErr := io.Copy(io.MultiWriter(tmp, hasher), http.MaxBytesReader(w, r.Body, h.d.PartBytes))
	closeErr := tmp.Close()
	if copyErr != nil || closeErr != nil {
		_ = os.Remove(tmp.Name())
		var tooBig *http.MaxBytesError
		switch {
		case errors.As(copyErr, &tooBig):
			WriteError(w, http.StatusRequestEntityTooLarge, "PART_TOO_LARGE", fmt.Sprintf("a part may be at most %d bytes", h.d.PartBytes))
		case errors.Is(copyErr, syscall.ENOSPC) || errors.Is(closeErr, syscall.ENOSPC):
			WriteError(w, http.StatusInsufficientStorage, "DISK_FULL", "server disk full while staging the part")
		default:
			WriteError(w, http.StatusBadRequest, "BAD_REQUEST", "the part upload was interrupted; resend it")
		}
		return
	}
	got := hex.EncodeToString(hasher.Sum(nil))
	if got != want {
		_ = os.Remove(tmp.Name())
		WriteError(w, http.StatusUnprocessableEntity, "PART_HASH_MISMATCH", "part hash mismatch; resend the part")
		return
	}
	if err := os.Rename(tmp.Name(), partPath(dir, idx)); err != nil {
		_ = os.Remove(tmp.Name())
		slog.Error("transfer: storing part", "error", err)
		WriteError(w, http.StatusInternalServerError, "INTERNAL", "staging failed")
		return
	}
	if err := h.d.Tokens.RecordPart(r.Context(), token, idx, got); err != nil {
		slog.Error("transfer: recording part", "error", err)
		WriteError(w, http.StatusInternalServerError, "INTERNAL", "recording the part failed")
		return
	}
	h.progress(r.Context(), sess, n, 0)
	received := []int{idx}
	for i := range sess.Parts {
		if i != idx {
			received = append(received, i)
		}
	}
	sort.Ints(received)
	WriteJSON(w, http.StatusOK, map[string]any{"part": idx, "received": received})
}

// concatParts writes parts 0..n-1 to w in order, re-verifying each against the
// hash recorded when it was received.
func concatParts(dir string, parts map[int]string, n int, w io.Writer) error {
	for i := 0; i < n; i++ {
		f, err := os.Open(partPath(dir, i))
		if err != nil {
			return fmt.Errorf("part %d: %w", i, err)
		}
		hasher := sha256.New()
		_, err = io.Copy(io.MultiWriter(w, hasher), f)
		_ = f.Close()
		if err != nil {
			return fmt.Errorf("part %d: %w", i, err)
		}
		if hex.EncodeToString(hasher.Sum(nil)) != parts[i] {
			return fmt.Errorf("%w: staged part %d changed after upload", runner.ErrManifestMismatch, i)
		}
	}
	return nil
}

type pushCommitBody struct {
	Parts  int    `json:"parts"`
	SHA256 string `json:"sha256"`
}

func (h *RunnerTransferHandler) commit(w http.ResponseWriter, r *http.Request) {
	sess, token, ok := h.authorize(w, r, runner.TransferPush)
	if !ok {
		return
	}
	h.extendDeadlines(w)
	if sess.CheckpointRef != "" {
		ref, err := runner.ParseCheckpointRef(sess.CheckpointRef)
		if err == nil {
			WriteJSON(w, http.StatusOK, ref)
			return
		}
		slog.Error("transfer: stored checkpoint ref unreadable", "error", err)
	}
	var body pushCommitBody
	if err := json.NewDecoder(io.LimitReader(r.Body, 4096)).Decode(&body); err != nil || body.Parts < 1 ||
		body.Parts > MaxTransferParts || !validHexSHA256(strings.ToLower(body.SHA256)) {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", `body must be {"parts":N,"sha256":"<hex>"}`)
		return
	}
	for i := 0; i < body.Parts; i++ {
		if _, have := sess.Parts[i]; !have {
			WriteError(w, http.StatusConflict, "INCOMPLETE_PUSH", fmt.Sprintf("part %d is missing; resend it before committing", i))
			return
		}
	}
	dir := h.sessionDir(sess)
	whole := sha256.New()
	if err := concatParts(dir, sess.Parts, body.Parts, whole); err != nil {
		h.writeStageError(w, err)
		return
	}
	if hex.EncodeToString(whole.Sum(nil)) != strings.ToLower(body.SHA256) {
		WriteError(w, http.StatusUnprocessableEntity, "PUSH_HASH_MISMATCH", "the assembled push does not match its hash; resend the parts")
		return
	}
	base, found, err := h.d.Checkpoints.Latest(r.Context(), sess.RunID)
	if err != nil || !found {
		WriteError(w, http.StatusConflict, "NO_BASE", "the run has no committed checkpoint to apply the push to")
		return
	}

	pr, pw := io.Pipe()
	done := make(chan struct{})
	go func() {
		defer close(done)
		pw.CloseWithError(concatParts(dir, sess.Parts, body.Parts, pw))
	}()
	staged, stageErr := h.d.Checkpoints.StageDelta(r.Context(), sess.RunID, base, pr)
	_ = pr.Close()
	<-done
	if stageErr != nil {
		h.writeStageError(w, stageErr)
		return
	}
	ref, err := h.d.Sync.AcceptPush(r.Context(), fenceOf(sess), sess.RunID, staged)
	if err != nil {
		switch {
		case errors.Is(err, runner.ErrFenced) || errors.Is(err, runner.ErrHomeOwned):
			WriteError(w, http.StatusForbidden, "FORBIDDEN", "this job generation no longer owns the workspace")
		case errors.Is(err, runner.ErrCheckpointConflict):
			WriteError(w, http.StatusConflict, "BASE_MOVED", "the committed checkpoint moved; pull again")
		default:
			h.writeStageError(w, err)
		}
		return
	}
	if err := h.d.Tokens.RecordCommit(r.Context(), token, ref.String()); err != nil {
		slog.Warn("transfer: recording push commit", "ref", ref.String(), "error", err)
	}
	_ = os.RemoveAll(dir)
	WriteJSON(w, http.StatusOK, ref)
}

func (h *RunnerTransferHandler) writeStageError(w http.ResponseWriter, err error) {
	switch {
	case errors.Is(err, syscall.ENOSPC):
		WriteError(w, http.StatusInsufficientStorage, "DISK_FULL", "server disk full while applying the push; the previous checkpoint is kept")
	case errors.Is(err, runner.ErrManifestMismatch), errors.Is(err, runner.ErrCorruptCheckpoint), errors.Is(err, runner.ErrUnsupportedFileType):
		WriteError(w, http.StatusUnprocessableEntity, "PUSH_REJECTED", err.Error())
	case errors.Is(err, runner.ErrCheckpointConflict):
		WriteError(w, http.StatusConflict, "BASE_MOVED", "the committed checkpoint moved; pull again")
	case errors.Is(err, fs.ErrNotExist):
		WriteError(w, http.StatusConflict, "INCOMPLETE_PUSH", "a staged part expired; resend the parts")
	default:
		slog.Error("transfer: applying push", "error", err)
		WriteError(w, http.StatusInternalServerError, "INTERNAL", "applying the push failed")
	}
}

func (h *RunnerTransferHandler) bundle(w http.ResponseWriter, r *http.Request) {
	if _, _, ok := h.authorize(w, r, runner.TransferBundle); !ok {
		return
	}
	if h.d.Bundles == nil {
		WriteError(w, http.StatusServiceUnavailable, "BUNDLES_UNAVAILABLE", "script bundles are not configured on this server")
		return
	}
	hash := chi.URLParam(r, "hash")
	if !validHexSHA256(hash) || strings.ToLower(hash) != hash {
		WriteError(w, http.StatusBadRequest, "BAD_REQUEST", "bundle hash must be a lowercase hex SHA-256")
		return
	}
	h.extendDeadlines(w)
	rc, err := h.d.Bundles.Open(r.Context(), hash)
	if err != nil {
		slog.Warn("transfer: bundle unavailable", "hash", hash, "error", err)
		WriteError(w, http.StatusNotFound, "NOT_FOUND", "bundle not found")
		return
	}
	defer rc.Close()
	w.Header().Set("Content-Type", "application/gzip")
	_, _ = io.Copy(w, rc)
}
