# Remote Runners — Phase 2 Task 7: Machine telemetry (MachineTelemetry port, darwin/linux/null adapters, built-in telemetry loop)

**Goal:** Real, fixture-tested machine telemetry on macOS and Linux. It covers CPU, memory used and pressure, load as a percentage of cores, free workspace disk, thermal state, uptime, cores and RAM. Every field the OS cannot supply is reported as unavailable (nil) and never as a healthy default. A built-in loop feeds the hub's telemetry window for `BuiltInRunnerID`.

**Architecture:**
- `domain/runner/telemetry.go` defines the `MachineTelemetry` port and `BuiltInTelemetryLoop`. The loop samples every interval and records the sample on the hub via `(*Hub).RecordTelemetry`, which P2 T4 provides.
- `adapter/telemetry` holds pure parsers for captured command and `/proc` text, plus two samplers (`MacSampler` and `LinuxSampler`). The samplers are untagged and use injectable command, file and disk ports, so every parser and sampler test runs on every OS against `testdata/` fixtures.
- The build-tagged `darwin.go`, `linux.go` and `other.go` files only choose the sampler and bind the real ports.

**Tech Stack:** Go 1.25.5, `os/exec`, `golang.org/x/sys/unix` (`Statfs`), `regexp`, testify.

**Spec / Design:**
- Spec: `docs/specs/2026-11-19-remote-runners-spec.md`, "Administration and visibility": the Runner detail view needs CPU, memory use and pressure, load, free workspace disk, thermal state, uptime and hardware capacity.
- Design: `docs/designs/2026-11-19-remote-runners-design-phase-2.md`:
  - §3.4 (telemetry window);
  - §3.6 MachineTelemetry;
  - §5 data-provenance row "CPU, memory use/pressure, ... sample timestamps" (UNRESOLVED DEPENDENCY RR-06);
  - §8 Edge-case "Telemetry is 'unavailable' on the null adapter".
- Contracts: `docs/plans/remote-runners/2026-11-20-contracts.md`:
  - §7 `Telemetry`;
  - §6 `BuiltInRunnerID`;
  - §15 "Telemetry" (`runner.MachineTelemetry`, `adapter/telemetry/darwin.go|linux.go|null.go`, `telemetry.New()`, `runner.NewBuiltInTelemetryLoop`);
  - §0 (hexagonal rule).

DECISION (2026-11-22, RR-06): the macOS thermal source is `/usr/bin/notifyutil -g com.apple.system.thermalpressurelevel`, a stock, cgo-free binary that reads the Darwin notify state behind `OSThermalPressureLevel` (the signal `NSProcessInfo.thermalState` is derived from). It was observed on an Apple M2 (macOS 26.5.2) printing `com.apple.system.thermalpressurelevel 0`; producer of the observed fixture: `docs/evidence/remote-runners/macos-runner-host.md` §Thermal. Mapping (enum from `<libkern/OSThermalNotification.h>`): `0` → `nominal`, `1` → `fair`, `2` → `serious`, `3` or `4` → `critical`. Output that is not exactly one line `com.apple.system.thermalpressurelevel <integer 0–4>` (missing key, another integer, non-integer, extra text), a non-zero exit, or a timeout yields `Thermal = nil` (unavailable), never `nominal`. The `pmset -g therm` parser is dropped entirely: on Apple silicon it prints only "No thermal warning level has been recorded" notes (observed), so it carries no state. No cgo/Objective-C helper is shipped, and no hardware thermal-load test is required: level 0 is the observed real fixture, levels 1–4 are synthetic fixtures from the documented enum. Every other darwin metric (CPU via `top -l 2`, `vm_stat`, `kern.memorystatus_vm_pressure_level`, `vm.loadavg`, `kern.boottime`, `hw.ncpu`, `hw.memsize`, `Statfs`) is sourced without cgo.

**Units and unavailable values:**
- `CPUPercent` is a percentage from 0 to 100 measured over an interval (macOS: the second `top` sample over 1 s; Linux: the `/proc/stat` delta over `CPUWindow`, 250 ms by default).
- `MemUsedBytes` is in bytes:
  - macOS: (active + wired + compressor-occupied pages) × page size;
  - Linux: MemTotal − MemAvailable.
- `MemPressure` is `normal`, `warn` or `critical`:
  - macOS: `kern.memorystatus_vm_pressure_level` 1/2/4;
  - Linux: PSI `some avg10 ≥ 10` gives `warn` and `full avg10 ≥ 10` gives `critical`.
- `Load1Pct` is `load1 / cores × 100`.
- `DiskFreeBytes` is in bytes (`Bavail × Bsize` for the volume holding the workspace root).
- `Thermal` is `nominal`, `fair`, `serious` or `critical`.
- `UptimeSeconds` is in seconds.
- `Cores` is the logical CPU count.
- `RAMBytes` is in bytes.
- `SampledAt` is the time the sample was taken (UTC). The hub derives the sample's age from it.
- A metric whose source fails or is absent is `nil`, which means "unavailable". It is never zero and never a healthy default.

```go
package runner

import (
	"context"
	"sync/atomic"
	"time"
)

// MachineTelemetry samples the local machine. Every Telemetry metric is a
// pointer: nil means "unavailable" and is never replaced by a healthy guess.
type MachineTelemetry interface {
	Sample(ctx context.Context) (Telemetry, error)
}

// telemetrySink is the part of *Hub the built-in loop feeds.
type telemetrySink interface {
	RecordTelemetry(id RunnerID, t Telemetry)
}

// The hub must accept built-in samples into the same window heartbeats feed.
var _ telemetrySink = (*Hub)(nil)

const defaultBuiltInTelemetryEvery = 5 * time.Second

// BuiltInTelemetryLoop samples the server machine and records it for the
// built-in runner, so the hub window holds built-in telemetry exactly like a
// remote runner's heartbeats.
type BuiltInTelemetryLoop struct {
	src     MachineTelemetry
	sink    telemetrySink
	every   time.Duration
	now     func() time.Time
	after   func(time.Duration) <-chan time.Time
	started atomic.Bool
}

// NewBuiltInTelemetryLoop builds the loop feeding h. It panics on a nil
// sampler or hub: both are composition-root programming errors.
func NewBuiltInTelemetryLoop(t MachineTelemetry, h *Hub, every time.Duration) *BuiltInTelemetryLoop {
	if h == nil {
		panic("runner: NewBuiltInTelemetryLoop requires a non-nil *Hub")
	}
	return newBuiltInTelemetryLoop(t, h, every, time.Now, time.After)
}

func newBuiltInTelemetryLoop(t MachineTelemetry, sink telemetrySink, every time.Duration,
	now func() time.Time, after func(time.Duration) <-chan time.Time) *BuiltInTelemetryLoop {
	if t == nil {
		panic("runner: built-in telemetry loop requires a MachineTelemetry")
	}
	if sink == nil {
		panic("runner: built-in telemetry loop requires a sink")
	}
	if every <= 0 {
		every = defaultBuiltInTelemetryEvery
	}
	return &BuiltInTelemetryLoop{src: t, sink: sink, every: every, now: now, after: after}
}

// Every is the sampling interval.
func (l *BuiltInTelemetryLoop) Every() time.Duration { return l.every }

// Tick samples once and records the result for BuiltInRunnerID. A sampling
// error records an all-unavailable sample stamped now and is returned.
func (l *BuiltInTelemetryLoop) Tick(ctx context.Context) error {
	s, err := l.src.Sample(ctx)
	if err != nil {
		s = Telemetry{}
	}
	if s.SampledAt.IsZero() {
		s.SampledAt = l.now()
	}
	l.sink.RecordTelemetry(BuiltInRunnerID, s)
	return err
}

// Start samples immediately and then every Every() until ctx is done. A
// second call is a no-op.
func (l *BuiltInTelemetryLoop) Start(ctx context.Context) {
	if !l.started.CompareAndSwap(false, true) {
		return
	}
	go func() {
		for ctx.Err() == nil {
			_ = l.Tick(ctx)
			select {
			case <-ctx.Done():
				return
			case <-l.after(l.every):
			}
		}
	}()
}
```

package telemetry

import (
	"regexp"
	"strconv"
	"strings"
	"time"
)

// SysctlFacts is parsed from
// `sysctl hw.ncpu hw.memsize kern.boottime vm.loadavg kern.memorystatus_vm_pressure_level`.
type SysctlFacts struct {
	Cores         *int
	RAMBytes      *uint64
	BootTime      *time.Time
	Load1         *float64
	PressureLevel *int
}

var (
	bootSecRe = regexp.MustCompile(`sec\s*=\s*(\d+)`)
	loadAvgRe = regexp.MustCompile(`^\{\s*([0-9]+(?:\.[0-9]+)?)`)
)

// ParseSysctl reads "key: value" lines; an absent or malformed key is nil.
func ParseSysctl(out string) SysctlFacts {
	var f SysctlFacts
	for _, line := range strings.Split(out, "\n") {
		key, val, ok := strings.Cut(line, ":")
		if !ok {
			continue
		}
		key, val = strings.TrimSpace(key), strings.TrimSpace(val)
		switch key {
		case "hw.ncpu":
			if n, err := strconv.Atoi(val); err == nil && n > 0 {
				f.Cores = &n
			}
		case "hw.memsize":
			if n, err := strconv.ParseUint(val, 10, 64); err == nil && n > 0 {
				f.RAMBytes = &n
			}
		case "kern.boottime":
			if m := bootSecRe.FindStringSubmatch(val); m != nil {
				if s, err := strconv.ParseInt(m[1], 10, 64); err == nil && s > 0 {
					bt := time.Unix(s, 0).UTC()
					f.BootTime = &bt
				}
			}
		case "vm.loadavg":
			if m := loadAvgRe.FindStringSubmatch(val); m != nil {
				if l, err := strconv.ParseFloat(m[1], 64); err == nil && l >= 0 {
					f.Load1 = &l
				}
			}
		case "kern.memorystatus_vm_pressure_level":
			if n, err := strconv.Atoi(val); err == nil {
				f.PressureLevel = &n
			}
		}
	}
	return f
}

// MemPressureFromLevel maps the kernel's memorystatus pressure level
// (1 normal, 2 warn, 4 critical); any other value is unavailable.
func MemPressureFromLevel(level int) *string {
	var s string
	switch level {
	case 1:
		s = "normal"
	case 2:
		s = "warn"
	case 4:
		s = "critical"
	default:
		return nil
	}
	return &s
}

var pageSizeRe = regexp.MustCompile(`page size of (\d+) bytes`)

// ParseVMStat returns used memory: (active + wired + compressor-occupied
// pages) × page size. Missing page size or any counter is unavailable.
func ParseVMStat(out string) *uint64 {
	m := pageSizeRe.FindStringSubmatch(out)
	if m == nil {
		return nil
	}
	page, err := strconv.ParseUint(m[1], 10, 64)
	if err != nil || page == 0 {
		return nil
	}
	pages := map[string]uint64{}
	for _, line := range strings.Split(out, "\n") {
		key, val, ok := strings.Cut(line, ":")
		if !ok {
			continue
		}
		n, err := strconv.ParseUint(strings.TrimSuffix(strings.TrimSpace(val), "."), 10, 64)
		if err != nil {
			continue
		}
		pages[strings.TrimSpace(key)] = n
	}
	var total uint64
	for _, k := range []string{"Pages active", "Pages wired down", "Pages occupied by compressor"} {
		n, ok := pages[k]
		if !ok {
			return nil
		}
		total += n
	}
	used := total * page
	return &used
}

var topCPURe = regexp.MustCompile(`CPU usage:.*?([0-9]+(?:\.[0-9]+)?)% idle`)

// ParseTopCPU returns 100 − idle from the last "CPU usage" line of
// `top -l 2`. The first sample is since boot, so fewer than two samples is
// unavailable.
func ParseTopCPU(out string) *float64 {
	all := topCPURe.FindAllStringSubmatch(out, -1)
	if len(all) < 2 {
		return nil
	}
	idle, err := strconv.ParseFloat(all[len(all)-1][1], 64)
	if err != nil || idle < 0 || idle > 100 {
		return nil
	}
	used := 100 - idle
	return &used
}

var (
	thermalPressureRe = regexp.MustCompile(`^com\.apple\.system\.thermalpressurelevel (\d+)$`)
	// thermalRank and worseThermal are shared with ThermalFromZones (Linux, Cycle 5).
	thermalRank = map[string]int{"nominal": 0, "fair": 1, "serious": 2, "critical": 3}
)

func worseThermal(a, b string) string {
	if a == "" {
		return b
	}
	if thermalRank[b] > thermalRank[a] {
		return b
	}
	return a
}

// ParseThermalPressure maps `notifyutil -g com.apple.system.thermalpressurelevel`
// (OSThermalPressureLevel: 0 Nominal, 1 Moderate, 2 Heavy, 3 Trapping,
// 4 Sleeping) to a thermal state. Anything other than exactly one line
// "com.apple.system.thermalpressurelevel <0-4>" is unavailable — never
// "nominal" (DECISION RR-06, docs/evidence/remote-runners/macos-runner-host.md).
func ParseThermalPressure(out string) *string {
	m := thermalPressureRe.FindStringSubmatch(strings.TrimSpace(out))
	if m == nil {
		return nil
	}
	n, err := strconv.Atoi(m[1])
	if err != nil {
		return nil
	}
	var state string
	switch n {
	case 0:
		state = "nominal"
	case 1:
		state = "fair"
	case 2:
		state = "serious"
	case 3, 4:
		state = "critical"
	default:
		return nil
	}
	return &state
}

package telemetry

import (
	"strconv"
	"strings"
)

// CPUTimes is the aggregate jiffy counters from /proc/stat.
type CPUTimes struct {
	Idle, Total uint64
	Cores       int
}

// ParseProcStat reads the aggregate "cpu" line (user..steal; guest and
// guest_nice are already inside user/nice) and counts cpuN lines.
func ParseProcStat(content string) (CPUTimes, bool) {
	var c CPUTimes
	found := false
	for _, line := range strings.Split(content, "\n") {
		fields := strings.Fields(line)
		if len(fields) == 0 {
			continue
		}
		switch {
		case fields[0] == "cpu":
			if len(fields) < 5 {
				return CPUTimes{}, false
			}
			vals := make([]uint64, 0, 8)
			for i, s := range fields[1:] {
				if i >= 8 {
					break
				}
				n, err := strconv.ParseUint(s, 10, 64)
				if err != nil {
					return CPUTimes{}, false
				}
				vals = append(vals, n)
			}
			for _, v := range vals {
				c.Total += v
			}
			c.Idle = vals[3]
			if len(vals) > 4 {
				c.Idle += vals[4]
			}
			found = true
		case strings.HasPrefix(fields[0], "cpu"):
			c.Cores++
		}
	}
	return c, found
}

// CPUPercentBetween is busy time over the interval a→b; no progress or a
// counter reset is unavailable.
func CPUPercentBetween(a, b CPUTimes) *float64 {
	if b.Total <= a.Total || b.Idle < a.Idle {
		return nil
	}
	dt := float64(b.Total - a.Total)
	di := float64(b.Idle - a.Idle)
	if di > dt {
		return nil
	}
	p := 100 * (1 - di/dt)
	return &p
}

func meminfoKB(val string) (uint64, bool) {
	f := strings.Fields(val)
	if len(f) == 0 {
		return 0, false
	}
	n, err := strconv.ParseUint(f[0], 10, 64)
	if err != nil {
		return 0, false
	}
	return n * 1024, true
}

// ParseMeminfo returns MemTotal and MemTotal − MemAvailable in bytes.
func ParseMeminfo(content string) (total, used *uint64) {
	var t, avail uint64
	var haveT, haveA bool
	for _, line := range strings.Split(content, "\n") {
		key, val, ok := strings.Cut(line, ":")
		if !ok {
			continue
		}
		switch strings.TrimSpace(key) {
		case "MemTotal":
			t, haveT = meminfoKB(val)
		case "MemAvailable":
			avail, haveA = meminfoKB(val)
		}
	}
	if !haveT || t == 0 {
		return nil, nil
	}
	total = &t
	if haveA && avail <= t {
		u := t - avail
		used = &u
	}
	return total, used
}

const (
	psiWarnSomeAvg10     = 10.0
	psiCriticalFullAvg10 = 10.0
)

func psiAvg10(fields []string) (float64, bool) {
	for _, f := range fields {
		if v, ok := strings.CutPrefix(f, "avg10="); ok {
			n, err := strconv.ParseFloat(v, 64)
			return n, err == nil
		}
	}
	return 0, false
}

// ParsePSI maps /proc/pressure/memory: full avg10 ≥ 10 → critical,
// some avg10 ≥ 10 → warn, otherwise normal. Unparseable is unavailable.
func ParsePSI(content string) *string {
	some, full := -1.0, -1.0
	for _, line := range strings.Split(content, "\n") {
		f := strings.Fields(line)
		if len(f) < 2 {
			continue
		}
		v, ok := psiAvg10(f[1:])
		if !ok {
			continue
		}
		switch f[0] {
		case "some":
			some = v
		case "full":
			full = v
		}
	}
	if some < 0 {
		return nil
	}
	s := "normal"
	if some >= psiWarnSomeAvg10 {
		s = "warn"
	}
	if full >= psiCriticalFullAvg10 {
		s = "critical"
	}
	return &s
}

// ParseLoadAvg returns the 1-minute load from /proc/loadavg.
func ParseLoadAvg(content string) *float64 {
	f := strings.Fields(content)
	if len(f) == 0 {
		return nil
	}
	l, err := strconv.ParseFloat(f[0], 64)
	if err != nil || l < 0 {
		return nil
	}
	return &l
}

// ParseUptime returns whole seconds from /proc/uptime.
func ParseUptime(content string) *uint64 {
	f := strings.Fields(content)
	if len(f) == 0 {
		return nil
	}
	s, err := strconv.ParseFloat(f[0], 64)
	if err != nil || s < 0 {
		return nil
	}
	u := uint64(s)
	return &u
}

// ThermalTrip is one /sys/class/thermal trip point.
type ThermalTrip struct {
	Type   string
	MilliC int64
}

// ThermalZone is one thermal zone's temperature and trip points.
type ThermalZone struct {
	MilliC int64
	Trips  []ThermalTrip
}

// ThermalFromZones judges each zone against its passive (fair), hot
// (serious) and critical (critical) trips; the worst judged zone wins.
// Zones without such trips cannot be judged; none judged is unavailable.
func ThermalFromZones(zones []ThermalZone) *string {
	state := ""
	for _, z := range zones {
		judged := false
		zs := "nominal"
		for _, tr := range z.Trips {
			var s string
			switch tr.Type {
			case "passive":
				s = "fair"
			case "hot":
				s = "serious"
			case "critical":
				s = "critical"
			default:
				continue
			}
			judged = true
			if z.MilliC >= tr.MilliC {
				zs = worseThermal(zs, s)
			}
		}
		if judged {
			state = worseThermal(state, zs)
		}
	}
	if state == "" {
		return nil
	}
	return &state
}

	DiskFree  func(path string) (uint64, error)
	Root      string
	Now       func() time.Time
	CPUWindow time.Duration
}

var _ runner.MachineTelemetry = LinuxSampler{}

func (s LinuxSampler) window() time.Duration {
	if s.CPUWindow > 0 {
		return s.CPUWindow
	}
	return defaultCPUWindow
}

func (s LinuxSampler) read(name string) (string, bool) {
	b, err := s.ReadFile(name)
	if err != nil {
		return "", false
	}
	return string(b), true
}

func (s LinuxSampler) readInt(name string) (int64, bool) {
	c, ok := s.read(name)
	if !ok {
		return 0, false
	}
	n, err := strconv.ParseInt(strings.TrimSpace(c), 10, 64)
	return n, err == nil
}

// Sample collects one telemetry sample.
func (s LinuxSampler) Sample(ctx context.Context) (runner.Telemetry, error) {
	t := runner.Telemetry{SampledAt: s.Now().UTC()}

	if c, ok := s.read("/proc/stat"); ok {
		if a, ok := ParseProcStat(c); ok {
			if a.Cores > 0 {
				cores := a.Cores
				t.Cores = &cores
			}
			if err := s.Sleep(ctx, s.window()); err == nil {
				if c2, ok := s.read("/proc/stat"); ok {
					if b, ok := ParseProcStat(c2); ok {
						t.CPUPercent = CPUPercentBetween(a, b)
					}
				}
			}
		}
	}
	if c, ok := s.read("/proc/meminfo"); ok {
		t.RAMBytes, t.MemUsedBytes = ParseMeminfo(c)
	}
	if c, ok := s.read("/proc/pressure/memory"); ok {
		t.MemPressure = ParsePSI(c)
	}
	if c, ok := s.read("/proc/loadavg"); ok {
		t.Load1Pct = loadPct(ParseLoadAvg(c), t.Cores)
	}
	if c, ok := s.read("/proc/uptime"); ok {
		t.UptimeSeconds = ParseUptime(c)
	}
	t.DiskFreeBytes = diskFree(s.DiskFree, s.Root)
	t.Thermal = ThermalFromZones(s.thermalZones())
	return t, nil
}

func (s LinuxSampler) thermalZones() []ThermalZone {
	if s.Glob == nil {
		return nil
	}
	dirs, err := s.Glob("/sys/class/thermal/thermal_zone*")
	if err != nil {
		return nil
	}
	sort.Strings(dirs)
	var zones []ThermalZone
	for _, d := range dirs {
		temp, ok := s.readInt(d + "/temp")
		if !ok {
			continue
		}
		z := ThermalZone{MilliC: temp}
		types, _ := s.Glob(d + "/trip_point_*_type")
		sort.Strings(types)
		for _, tp := range types {
			typ, ok := s.read(tp)
			if !ok {
				continue
			}
			v, ok := s.readInt(strings.TrimSuffix(tp, "_type") + "_temp")
			if !ok {
				continue
			}
			z.Trips = append(z.Trips, ThermalTrip{Type: strings.TrimSpace(typ), MilliC: v})
		}
		zones = append(zones, z)
	}
	return zones
}

// execCommand runs name with a timeout and the C locale, returning stdout
// even on a non-zero exit.
func execCommand(ctx context.Context, name string, args ...string) (string, error) {
	ctx, cancel := context.WithTimeout(ctx, commandTimeout)
	defer cancel()
	cmd := exec.CommandContext(ctx, name, args...)
	cmd.Env = append(os.Environ(), "LC_ALL=C")
	var out bytes.Buffer
	cmd.Stdout = &out
	err := cmd.Run()
	return out.String(), err
}

import "golang.org/x/sys/unix"

// statfsFree returns the bytes available to unprivileged users on path's volume.
func statfsFree(path string) (uint64, error) {
	var st unix.Statfs_t
	if err := unix.Statfs(path, &st); err != nil {
		return 0, err
	}
	return uint64(st.Bavail) * uint64(st.Bsize), nil
}

func sleepCtx(ctx context.Context, d time.Duration) error {
	t := time.NewTimer(d)
	defer t.Stop()
	select {
	case <-ctx.Done():
		return ctx.Err()
	case <-t.C:
		return nil
	}
}

## Sample freshness contract

Add `SampleAgeMs int64` to the wire telemetry envelope (P2 T1/P2 T8/P2 T9). The sampler records age from a monotonic local sampling clock, so a cached sample cannot become fresh by resending it. Hub ingestion stamps `Telemetry.SampledAt = serverReceiptTime - SampleAgeMs`; negative/impossible ages discard metric evidence. Built-in `RecordTelemetry` uses the server's actual sample time. Never replace a zero/missing producer timestamp with fresh health merely to satisfy tests; a zero sample is unavailable. Sample disk at the canonical workspace volume passed to `telemetry.NewForRoot`, not daemon cwd/scratch or a different mounted disk. Write `TestTelemetry_CachedSampleAgeSurvivesHeartbeat`, `TestTelemetry_DiskUsesCanonicalWorkspaceVolume`, and `TestHubTelemetry_RemoteClockSkewDoesNotChangeFreshness` before implementation.
