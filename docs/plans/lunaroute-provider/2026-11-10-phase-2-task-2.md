# LunaRoute Phase 2 · Task 2 — Connection model discovery service (domain)

**Dependencies:** P1-T5–T8 and P2-T1.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Produce the per-connection discovery view an LLM inspects over MCP: every model id the connection lists, its actual vendor family (or `unresolved`), and each capability fact as explicit `known(value, evidence)` or `unknown`, plus a note that availability does not imply compatibility.

**Architecture:** New `domain/provider/model_discovery.go`: `ModelDiscoveryService` over three ports — `ConnectionStore` (metadata `Get` + `Reveal`), `ProbeSelector`, `LunaRouteCapabilities` — admin-gated with the same `requireAdmin` rule as `ConnectionService`. The probe binding is built with `GuardLunaRouteReveal`. Provider-agnostic: non-LunaRoute providers get ids + family with every table field `unknown` (only LunaRoute is curated); `ModelsUnsupported` or no probe for the provider → `ListingSupported: false`. Table entries absent from the listing are not shown. Pure domain, no adapter imports.

**Tech Stack:** Go 1.25, testify.

**Spec:** spec §Model discovery and selection · **Design:** phase-2 §3.2, §4 (Discovery data flow)

## Global Constraints
- Output is JSON-serializable with snake_case tags; it never contains key material.
- Every capability field is explicit: `support: "unknown"` / `known: false` — never omitted, never inferred from listing membership.
- Family comes only from `modelidentity.ClassifyFamily(Canonicalize(conn.Provider), id)`.
- Note text (verbatim constant `DiscoveryNote`) states: availability does not imply task or backend compatibility; unknown is not a guarantee; choose model and backend explicitly; LunaRoute agent profiles name their backend and are pinned-only.
- Nil ports are a wiring fault (`ErrSelectionPortsMissing`), never an empty catalog.
- **LR-02 decided** (`docs/designs/2026-11-10-lunaroute-provider-decisions.md`): the table carries doc-sourced static facts for the release set. Every fact the table lacks (including all task/backend support until live runs) shows as `unknown`, never a default.
- **LR-03 decided:** family comes from `ClassifyFamily`, which uses the reviewed alias table (`claude-sonnet-5-lr1` → `anthropic`). Opaque or unreviewed aliases show `family: "unresolved"`.

## Review Focus
- Duplicate ids in a listing appear once; output order is sorted (stable for the LLM and tests).
- Non-admin caller → `ErrForbidden` before any store/probe call.
- Probe error (classified `LunaRouteFailure`) propagates unchanged so MCP can map it.
- Empty listing → `models: []` (not `null`).
- A LunaRoute model whose table entry marks `codex` unsupported still shows `pi` as `unknown` (independent facts).

type discStore struct {
	provider.ConnectionStore
	conns   map[string]provider.Connection
	key     string
	reveals int
	gets    int

func (s *discStore) Get(_ context.Context, name string) (provider.Connection, error) {
	s.gets++
	c, ok := s.conns[name]
	if !ok {
		return provider.Connection{}, provider.ErrConnectionNotFound
	}
	return c, nil
}
func (s *discStore) Reveal(_ context.Context, name string) (string, error) {
	s.reveals++
	return s.key, nil
}

// discProbe uses the binding it is given: it reveals through the binding's
// own RevealKey (so the guard is exercised) and records what it saw.
type discProbe struct {
	got    provider.ResolvedBinding
	key    string
	result provider.ProbeResult
	err    error
}

func (p *discProbe) Probe(ctx context.Context, b provider.ResolvedBinding) (provider.ProbeResult, error) {
	p.got = b
	k, err := b.RevealKey(ctx)
	if err != nil {
		return provider.ProbeResult{}, err
	}
	p.key = k
	return p.result, p.err
}

type discSelector struct {
	probe *discProbe
	none  bool
	calls int
}

func (s *discSelector) ProbeFor(b provider.ResolvedBinding) (provider.ConnectionProbe, error) {
	s.calls++
	if s.none {
		return nil, provider.ErrNoProbeForProvider

	return s.probe, nil
}

package provider

import (
	"context"
	"errors"
	"fmt"
	"sort"

	"github.com/arbitron/arbitron/domain/modelidentity"
)

// DiscoveryNote is returned with every discovery view.
const DiscoveryNote = "Availability does not imply task or backend compatibility. Fields marked \"unknown\" are not guarantees; known facts cite their evidence. " +
	"Choose the model and backend explicitly: nothing is recommended or auto-selected. LunaRoute agent profiles must name their backend and use pinned selection. " +
	"family is the model's actual vendor (aliases included); keep doer and judge on different vendors, and an \"unresolved\" family is refused."

// FactView is one support fact: "supported", "unsupported" or "unknown".
type FactView struct {
	Support  string `json:"support"`
	Evidence string `json:"evidence,omitempty"`
}

// LimitView is a token limit; Known=false means unknown.
type LimitView struct {
	Known    bool   `json:"known"`
	Tokens   int    `json:"tokens,omitempty"`
	Evidence string `json:"evidence,omitempty"`
}

// EffortView lists non-default efforts known to be supported on one axis.
type EffortView struct {
	Known    bool     `json:"known"`
	Levels   []string `json:"levels"`
	Evidence string   `json:"evidence,omitempty"`
}

// DiscoveredModel is one listed model with its known/unknown facts.
type DiscoveredModel struct {
	ID            string                `json:"id"`
	Family        string                `json:"family"`
	Tasks         map[string]FactView   `json:"tasks"`
	Backends      map[string]FactView   `json:"backends"`
	ContextTokens LimitView             `json:"context_tokens"`
	OutputTokens  LimitView             `json:"output_tokens"`
	Efforts       map[string]EffortView `json:"efforts"`
	Reasoning FactView `json:"reasoning"`
	RequestSettings map[string]FactView `json:"request_settings"`
}

// DiscoveryView is the per-connection discovery result.
type DiscoveryView struct {
	Connection       string            `json:"connection"`
	Provider         string            `json:"provider"`
	ListingSupported bool              `json:"listing_supported"`
	Note             string            `json:"note"`
	Models           []DiscoveredModel `json:"models"`
}

// ModelDiscoveryService lists a connection's models with their curated facts.
// Admin-only, like ConnectionService. It reads metadata, reveals through the
// LunaRoute guard and probes; it never persists anything.
type ModelDiscoveryService struct {
	store  ConnectionStore
	probes ProbeSelector
	caps   LunaRouteCapabilities
}

// NewModelDiscoveryService wires the three ports. Nil ports fail every call
// with ErrSelectionPortsMissing (a wiring fault, never an empty catalog).
func NewModelDiscoveryService(store ConnectionStore, probes ProbeSelector, caps LunaRouteCapabilities) *ModelDiscoveryService {
	return &ModelDiscoveryService{store: store, probes: probes, caps: caps}
}

func factView(f SupportFact) FactView {
	if f.Support == "" {
		return FactView{Support: string(SupportUnknown)}
	}
	return FactView{Support: string(f.Support), Evidence: f.Evidence}
}

func limitView(l LimitFact) LimitView {
	if !l.Known() {
		return LimitView{}
	}
	return LimitView{Known: true, Tokens: l.Tokens, Evidence: l.Evidence}
}

func effortView(e EffortFact) EffortView {
	levels := make([]string, 0, len(e.Levels))
	if e.Known {
		for _, l := range e.Levels {
			levels = append(levels, string(l))
		}
		return EffortView{Known: true, Levels: levels, Evidence: e.Evidence}
	}
	return EffortView{Levels: levels}
}

// Discover lists the named connection's models. Errors are ErrForbidden /
// ErrUnauthenticated, ErrConnectionNotFound, the LunaRoute guard sentinels, or
// the probe's (classified) failure, unchanged.
func (s *ModelDiscoveryService) Discover(ctx context.Context, name string) (DiscoveryView, error) {
	if err := requireAdmin(ctx); err != nil {
		return DiscoveryView{}, err
	}
	if s.store == nil || s.probes == nil || s.caps == nil {
		return DiscoveryView{}, fmt.Errorf("%w: model discovery", ErrSelectionPortsMissing)
	}
	conn, err := s.store.Get(ctx, name)
	if err != nil {
		return DiscoveryView{}, err
	}
	store := s.store
	b := GuardLunaRouteReveal(ResolvedBinding{
		Provider: conn.Provider, BaseURL: conn.BaseURL, Extras: conn.Extras, ConnectionRef: name,
		RevealKey: func(ctx context.Context) (string, error) { return store.Reveal(ctx, name) },
	})
	view := DiscoveryView{Connection: name, Provider: conn.Provider, ListingSupported: true, Note: DiscoveryNote, Models: []DiscoveredModel{}}
	probe, err := s.probes.ProbeFor(b)
	if errors.Is(err, ErrNoProbeForProvider) {
		view.ListingSupported = false
		return view, nil
	}
	if err != nil {
		return DiscoveryView{}, err
	}
	res, err := probe.Probe(ctx, b)
	if err != nil {
		return DiscoveryView{}, err
	}
	if res.ModelsUnsupported {
		view.ListingSupported = false
		return view, nil
	}
	route := Canonicalize(conn.Provider)
	curated := IsLunaRoute(conn.Provider)
	seen := map[string]bool{}
	ids := make([]string, 0, len(res.Models))
	for _, id := range res.Models {
		if id != "" && !seen[id] {
			seen[id] = true
			ids = append(ids, id)
		}
	}
	sort.Strings(ids)
	for _, id := range ids {
		var m LunaRouteModel
		if curated {
			m, _ = s.caps.LunaRouteModel(id)
		}
		dm := DiscoveredModel{
			ID:            id,
			Reasoning: factView(m.Reasoning),
			RequestSettings: map[string]FactView{"temperature": factView(m.RequestSettings["temperature"]), "output_schema": factView(m.RequestSettings["output_schema"])},
			Family:        string(modelidentity.ClassifyFamily(route, id)),
			Tasks:         map[string]FactView{string(ProfileKindChat): factView(m.Task(ProfileKindChat)), string(ProfileKindAgent): factView(m.Task(ProfileKindAgent))},
			Backends:      make(map[string]FactView, len(LunaRouteBackends)),
			ContextTokens: limitView(m.ContextTokens),
			OutputTokens:  limitView(m.OutputTokens),
			Efforts:       map[string]EffortView{LunaRouteChatAxis: effortView(m.Effort(LunaRouteChatAxis))},
		}
		for _, backend := range LunaRouteBackends {
			dm.Backends[backend] = factView(m.Backend(backend))
			dm.Efforts[backend] = effortView(m.Effort(backend))
		}
		view.Models = append(view.Models, dm)
	}
	return view, nil
}

## Five-category RED checklist

Before implementing, map these assertions to the named tests above (add any missing case), observe RED, then GREEN and refactor:

- **Happy:** discovery combines live ids with loaded facts.
- **Success:** sorted deduplicated ids and explicit unknown fields.
- **Failure:** forbidden/not-found/no-probe distinctions.
- **Error:** nil collaborator or untrustworthy result never becomes empty success.
- **Edge:** empty list, table-only id, non-LunaRoute and independent reasoning/settings.
