# LunaRoute Phase 1 · Task 3 — Connection credential rule (domain)

**Dependencies:** P1-T1–T2.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Decide whether a LunaRoute connection create/update is acceptable (an `lr_` key with a non-empty suffix, the hosted endpoint, no foreign-key reuse on a provider switch) and normalize the stored provider/base URL.

**Architecture:** New pure functions in `domain/provider/lunaroute_connection.go`, the key-aware sibling of `ValidateConnection`. `PrepareLunaRouteCreate` / `PrepareLunaRouteUpdate` return the (possibly normalized) connection; non-LunaRoute connections pass through byte-identical. Task 4 calls them from `ConnectionRepo.Create/Update` (the single write seam). `ErrConnectionChangedConcurrently` is added for Task 4's guarded update.

**Tech Stack:** Go 1.25, testify.

**Spec:** spec §Connection setup · **Design:** phase-1 §3.3

## Global Constraints
- Key rule: prefix `lr_` **and** at least one character after it **and** no whitespace/control characters. `lr_` alone is not a credential.
- An update that switches the provider **to** `lunaroute` without supplying a new key is rejected (a stored foreign key must never be reused).
- Base URL normalized to `https://gw.lunaroute.com` before persistence; anything else rejected with `ErrLunaRouteEndpoint`.
- Provider string normalized to `lunaroute` (handles `" LunaRoute "`).
- No error contains key material.

## Review Focus
- Key with a leading/trailing space (`" lr_abc"`, `"lr_abc\n"`) — pasted keys commonly carry whitespace; reject rather than silently trim (trimming would store a key different from what the author pasted, hiding the problem).
- Update of an existing lunaroute connection without a key (metadata-only edit) must still succeed.
- `sk-or-…` and `sk-…` keys rejected on both create and update.
- Non-LunaRoute connection with a weird base URL is untouched by this rule.

`domain/provider/lunaroute_connection.go`:
```go
package provider

import ("strings"; "unicode")

const lunaRouteKeyPrefix = "lr_"

// ValidLunaRouteKey reports whether key is shaped like a LunaRoute credential:
// the lr_ prefix, a non-empty suffix, and no whitespace or control characters.
// LunaRoute forwards any non-lr_ value upstream as a bring-your-own key, so a
// mis-pasted foreign key must never reach it.
func ValidLunaRouteKey(key string) bool {
	if !strings.HasPrefix(key, lunaRouteKeyPrefix) || len(key) == len(lunaRouteKeyPrefix) {
		return false
	}
	return strings.IndexFunc(key, func(r rune) bool { return unicode.IsSpace(r) || unicode.IsControl(r) }) < 0
}

func checkLunaRouteKey(key string) error {
	if key == "" {
		return ErrLunaRouteKeyRequired
	}
	if !ValidLunaRouteKey(key) {
		return ErrLunaRouteKeyPrefix
	}
	return nil
}

func normalizeLunaRouteConnection(c Connection) (Connection, error) {
	root, err := NormalizeLunaRouteBaseURL(c.BaseURL)
	if err != nil {
		return Connection{}, err
	}
	c.Provider = CanonicalLunaRoute
	c.BaseURL = root
	return c, nil
}

// PrepareLunaRouteCreate validates a LunaRoute create and returns the
// connection to persist (canonical provider, hosted root). Non-LunaRoute
// connections are returned unchanged.
func PrepareLunaRouteCreate(c Connection, apiKey string) (Connection, error) {
	if !IsLunaRoute(c.Provider) {
		return c, nil
	}
	if err := checkLunaRouteKey(apiKey); err != nil {
		return Connection{}, err
	}
	return normalizeLunaRouteConnection(c)
}

// PrepareLunaRouteUpdate validates a LunaRoute update. apiKey nil means "keep
// the stored key", which is only allowed when the stored provider is already
// lunaroute; storedProvider is the provider read from storage before the write.
func PrepareLunaRouteUpdate(c Connection, apiKey *string, storedProvider string) (Connection, error) {
	if !IsLunaRoute(c.Provider) {
		return c, nil
	}
	if apiKey == nil {
		if !IsLunaRoute(storedProvider) {
			return Connection{}, ErrLunaRouteKeyRequired
		}
	} else if err := checkLunaRouteKey(*apiKey); err != nil {
		return Connection{}, err
	}
	return normalizeLunaRouteConnection(c)
}
```
