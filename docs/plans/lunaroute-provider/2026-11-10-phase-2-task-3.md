# LunaRoute Phase 2 · Task 3 — OpenAI-compatible chat adapter: optional error-classification and preflight hooks

**Dependencies:** P1-T2.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Give `adapter/openrouter` two optional, provider-neutral seams — a structured error-classification hook (status, bounded body, transport error) applied to every immediate and streamed failure of `Chat` and `StreamChat`, and a request preflight run before any I/O — with byte-identical behaviour when both are nil.

**Architecture:** `adapter/openrouter/provider.go:Config` gains `ClassifyError func(status int, body string, transport error, retryAfter string, secrets ...string) error` and `Preflight func(req engine.ChatRequest) error`. `statusError` reads at most 4096 bytes of the (already bounded) body for the hook instead of parsing a formatted string; a new `transportError` routes `httpClient.Do` failures through the hook. The LunaRoute factory arm (Task 4) injects the LunaRoute classifier and launch check; no other provider sets them.

**Tech Stack:** Go 1.25, testify.

**Spec:** spec §Failure behavior · **Design:** phase-2 §3.4 "Implementation seam"

## Global Constraints
- Nil hooks: errors and requests identical to today (`ErrUpstreamStatus`, `openrouter: chat call: …`, `openrouter: stream call: …`).
- `Preflight` runs first in `Chat` and `StreamChat` — before body build, key reveal or any request.
- `ClassifyError` receives the raw (bounded, ≤4096 bytes) body; it is responsible for redaction. Its return value is returned verbatim (identity preserved).
- Streamed status errors arrive on the channel as `ChatChunk{Error: <hook result>}`; immediate transport errors are returned from `StreamChat` itself.
- With a classification hook, response read/decode/SSE protocol failures use the hook and preserve their original identity with safe text; nil-hook behaviour is unchanged. Structured SSE error frames are failures, never empty successful streams.

## Review Focus
- A body larger than 4096 bytes is omitted from diagnostics before reaching the hook; no partial secret survives an early cut.
- StreamChat preflight failure must not leak the timeout context (cancel called).
- A preflight error is returned even when the binding is pinned with a model mismatch (preflight precedes the evidence check).
- Existing openrouter tests stay green unchanged.

Replace `statusError` with:
```go
// statusError reads the bounded error body and either hands it to the
// classification hook or wraps ErrUpstreamStatus with a control-scrubbed
// snippet. It never inspects or logs the request's key.
func (p *Provider) statusError(status int, body io.Reader, retryAfter string, secrets ...string) error {
	if p.classify != nil {
		raw, err := io.ReadAll(io.LimitReader(body, classifyBodyMax+1))
		if err != nil || len(raw) > classifyBodyMax { raw = nil }
		classified := p.classify(status, string(raw), nil, retryAfter, secrets...)
		if err != nil { return &classifiedReadError{classified: classified, cause: err} }
		return classified
	}
	return fmt.Errorf("%w: status=%d body=%s", ErrUpstreamStatus, status, procenv.StatusSnippet(body))
}
```
