# LunaRoute Phase 1 · Task 7 — LunaRoute fixed-version grammar

**Goal:** Add a `lunaroute` case to the pinned-version grammar so LunaRoute profiles name an explicit, fixed executable spelling (open-weight ids, Claude-shaped `-lrN` aliases, explicitly chosen `-background` ids, and reviewed exact ids) and floating/unverified spellings are refused with an actionable message.

**Architecture:** `domain/modelidentity/version.go:explicitVersion` gains `case provider == "lunaroute"`, backed by three regexes plus a reviewed exact-id allowlist `lunaRouteReviewedIDs` (ships empty — **LR-03**). It reads no live catalog (an outage cannot stop a working run). Because `adapter/provider/pinned_route.go:validatePinnedRoute` and `ValidatePinRoutes` already call this resolver with the route provider, LunaRoute save, pin capture and pinned launch get the grammar with no further wiring (codex erasure is narrowed in Phase 4 Task 1).

**Tech Stack:** Go 1.25, `regexp`, testify.

**Spec:** spec §Model discovery ("The LLM chooses a model … explicitly"); non-goal "automatic priority selection" · **Design:** phase-1 §3.7(a)

## Global Constraints
- Accepted spellings (candidate, from `docs/ideas/lunaroute-provider.md`; **UNRESOLVED DEPENDENCY LR-03**):
  - `glm-N[.N][-flash][-background]` (e.g. `glm-5.3`, `glm-5.3-flash`, `glm-5.3-background`)
  - `deepseek-N[.N]-{flash,pro}[-background]` (e.g. `deepseek-4.1-flash`)
  - `claude-{opus,sonnet,haiku,fable}-N[-N]-lrN[-background]` (e.g. `claude-sonnet-5-lr1`)
  - any id in `lunaRouteReviewedIDs` (exact match; empty until evidence is recorded)
- Lowercase only; no `/` prefix; `latest`, empty and floating names refused.
- `-background` is accepted only because the author typed it; nothing derives it.
- **ESCALATION (LR-03):** whether a `-lrN` alias names an immutable target is unknown. The grammar accepts the candidate alias spelling so alias selection is not silently excluded from release readiness; Task 11's evidence register carries the escalation and the live check that every catalog id used in acceptance matches this grammar.

## Review Focus
- `GLM-5.3` (uppercase) refused with the accepted-spellings hint, not silently lowercased (the gateway id is case-sensitive until LR-03 says otherwise).
- `deepseek-v4.1-flash` (the deepseek/ollama spelling with `v`) is NOT a LunaRoute spelling and is refused.
- `glm-5.3-background-background` refused.
- Existing routes (openrouter, claude subscription, codex, pi) unchanged — run the whole `version_test.go`.

```go
	// LunaRoute catalog spellings (UNRESOLVED DEPENDENCY LR-03: candidate
	// grammar from the idea doc; the evidence register tracks verification).
	// -background is accepted only because the author names it explicitly.
	lunaRouteGLMRE         = regexp.MustCompile(`^glm-\d+(?:\.\d+)?(?:-flash)?(?:-background)?$`)
	lunaRouteDeepSeekRE    = regexp.MustCompile(`^deepseek-\d+(?:\.\d+)?-(?:flash|pro)(?:-background)?$`)
	lunaRouteClaudeAliasRE = regexp.MustCompile(`^claude-(?:opus|sonnet|haiku|fable)-\d+(?:-\d+)?-lr\d+(?:-background)?$`)
```
Below `piSubscriptionVendors` add:
```go
// lunaRouteReviewedIDs allow-lists exact LunaRoute ids outside the regex
// grammar. UNRESOLVED DEPENDENCY LR-03: add an id only with recorded evidence
// that it names a fixed executable target.
var lunaRouteReviewedIDs = map[string]bool{}

func lunaRouteFixed(model string) bool {
	return lunaRouteReviewedIDs[model] || lunaRouteGLMRE.MatchString(model) ||
		lunaRouteDeepSeekRE.MatchString(model) || lunaRouteClaudeAliasRE.MatchString(model)
}
```
Add to the accept consts:
```go
	acceptLunaRoute = "glm-N[.N][-flash][-background], deepseek-N[.N]-{flash,pro}[-background] or claude-{opus,sonnet,haiku,fable}-N[-N]-lrN[-background] (LunaRoute catalog ids, lowercase, no prefix), e.g. glm-5.3"
```
Add to the `switch` in `explicitVersion`, immediately after the `case provider == "bedrock" || provider == "amazon-bedrock":` arm:
