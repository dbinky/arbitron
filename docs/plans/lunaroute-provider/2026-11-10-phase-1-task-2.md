# LunaRoute Phase 1 · Task 2 — Error sentinels, refusal type, redaction and gateway-outcome classifier

**Dependencies:** P1-T1.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Define every LunaRoute sentinel (write-time, profile-save, launch-credential, gateway outcome), the `LunaRouteRefusal` error type, secret redaction, and the one pure classifier that maps a gateway outcome to a sentinel.

**Architecture:** Two new files in `domain/provider`: `lunaroute_errors.go` (sentinels + `LunaRouteRefusal`) and `lunaroute_classify.go` (`RedactLunaRoute`, `LunaRouteOutcome`, `LunaRouteFailure`, `ClassifyLunaRoute`). Pure functions, no I/O. Profile-save reasons wrap `ErrInvalidSelection` so existing callers (`PinPreflight`, `IsInvalidProfile`) keep classifying them as refusals.

**Tech Stack:** Go 1.25 (`errors`, multi-error `Unwrap() []error`), `regexp`, testify.

**Spec:** `docs/specs/2026-11-10-lunaroute-provider-spec.md` (Failure behavior) · **Design:** phase-1 §3.8, §7

## Global Constraints
- No error string ever contains key material — redact the revealed key and auth material **before** truncation.
- Snippet cap: 256 bytes, control characters replaced with spaces.
- A bare 404 on `list models` is a failed listing → `ErrLunaRouteCauseUnknown`, never "model unavailable".
- Unrecognised 400/403/404 → cause unknown. Do not guess codes from prose.
- **LR-04 decided** (`docs/designs/2026-11-10-lunaroute-provider-decisions.md` (LR-04)): `lunaRouteVerifiedCodes` ships the **documented** codes, identical for all three operations: `INVALID_API_KEY` → `ErrLunaRouteCredentialsRejected`; `CONCURRENT_REQUEST_LIMIT_EXCEEDED` → `ErrLunaRouteBusy`; `INFERENCE_UNAVAILABLE`, `NO_HEALTHY_PROVIDER`, `PROVIDER_KEY_UNAVAILABLE`, `BYOK_SPEND_GATE_UNAVAILABLE` → `ErrLunaRouteServiceFailure`; `BYOK_SPEND_CAP_REACHED`, `MODEL_UNPRICED` → new `ErrLunaRouteRequestRefused`. A recognised code beats the status mapping (a 429 carrying `BYOK_SPEND_CAP_REACHED` is refused, not busy). Never add `MODEL_NOT_FOUND` or any `*_busy` code; model availability is decided only by the `/v1/models` re-list (P2-T5). Unlisted codes fall back to status mapping. Source: LunaRoute API error docs (product owner, 2026-11-10), recorded by P1-T11 in `docs/evidence/lunaroute-provider/gateway-contract.md`. P2-T8 confirms the codes live; a contradicted code is removed and LR-04 becomes `escalated`.
- `ErrLunaRouteRequestRefused` is non-retryable: no Arbitron component retries it, and its message says a retry will not help.

## Review Focus
- A key echoed across the 256-byte cut must not leave a partial key prefix in the snippet.
- `errors.Is(failure, context.Canceled)` must still be true after classification (identity preserved), while `Error()` shows only redacted text.
- A `Bearer <token>` string not equal to the revealed key is still redacted.
- `LunaRouteRefusal` must match both its specific reason and `ErrInvalidSelection` with `errors.Is`.
- Malformed 200 listing → service failure, never an empty catalog.

import (
	"errors"
	"fmt"
	"strings"

// Connection-write sentinels (Task 3). None ever carries key material.
var (
	ErrLunaRouteKeyPrefix   = errors.New(`provider: LunaRoute keys start with "lr_" followed by the key; keys from other providers are rejected, never forwarded through LunaRoute`)
	ErrLunaRouteKeyRequired = errors.New("provider: a LunaRoute connection needs its own lr_ key; supply api_key when creating it or switching an existing connection to lunaroute")
)

// ErrLunaRouteStoredCredential fails a launch whose stored credential is not a
// LunaRoute key (defence in depth behind the write-time rule).
var ErrLunaRouteStoredCredential = errors.New("provider: the stored LunaRoute credential is not an lr_ key; update the connection with a LunaRoute key")

// Profile-save / launch refusal reasons. Each wraps ErrInvalidSelection so the
// existing refusal classification (PinPreflight, IsInvalidProfile) applies.
var (
	ErrLunaRouteFamilyUnresolved   = fmt.Errorf("%w: LunaRoute model family is unresolved", ErrInvalidSelection)
	ErrLunaRouteIncompatible       = fmt.Errorf("%w: LunaRoute model is known to be incompatible with this selection", ErrInvalidSelection)
	ErrLunaRouteAxisUnsupported    = fmt.Errorf("%w: LunaRoute setting is not supported for this model and backend", ErrInvalidSelection)
	ErrLunaRouteLimitsUnknown      = fmt.Errorf("%w: LunaRoute model limits are unknown", ErrInvalidSelection)
	ErrLunaRouteBackendUnsupported = fmt.Errorf("%w: LunaRoute is not yet supported on this agent backend", ErrInvalidSelection)
	ErrLunaRouteBackendRequired    = fmt.Errorf("%w: LunaRoute agent profiles must name their backend explicitly", ErrInvalidSelection)
	ErrLunaRoutePinnedOnly         = fmt.Errorf("%w: LunaRoute selections are pinned-only", ErrInvalidSelection)
	ErrLunaRouteSettingConflict    = fmt.Errorf("%w: LunaRoute request setting conflicts with the model's known limits", ErrInvalidSelection)
)

// Gateway outcome sentinels, produced only by ClassifyLunaRoute.
var (
	ErrLunaRouteCredentialsRejected = errors.New("LunaRoute rejected the credential; update the connection with a valid lr_ key")
	ErrLunaRouteModelUnavailable    = errors.New("the selected model is not available on this LunaRoute connection; run connection_models and choose a listed model")
	ErrLunaRouteBusy                = errors.New("LunaRoute is busy (all lanes in use); retry later")
	ErrLunaRouteServiceFailure      = errors.New("LunaRoute service failure; retry later")
	ErrLunaRouteCauseUnknown        = errors.New("LunaRoute request failed and the cause is unknown")
	// ErrLunaRouteRequestRefused (LR-04): BYOK_SPEND_CAP_REACHED / MODEL_UNPRICED.
	ErrLunaRouteRequestRefused = errors.New("LunaRoute refused this request for account or pricing reasons (spend cap reached or model not priced); it will not succeed on retry")
)

// LunaRouteGatewaySentinels lists the six gateway outcomes in a fixed order.
func LunaRouteGatewaySentinels() []error {
	return []error{ErrLunaRouteCredentialsRejected, ErrLunaRouteModelUnavailable, ErrLunaRouteBusy, ErrLunaRouteServiceFailure, ErrLunaRouteCauseUnknown, ErrLunaRouteRequestRefused}
}

// LunaRouteRefusal is a typed, actionable refusal of a LunaRoute selection. Its
// text names the model/backend and what to change; it never carries
// connection names or credentials, so MCP tools may surface it verbatim.
type LunaRouteRefusal struct {
	Reason  error
	Model   string
	Backend string
	Detail  string
}

func (e *LunaRouteRefusal) Error() string {
	var b strings.Builder
	b.WriteString(e.Reason.Error())
	fmt.Fprintf(&b, " (model %q", e.Model)
	if e.Backend != "" {
		fmt.Fprintf(&b, ", backend %q", e.Backend)
	}
	b.WriteString(")")
	if e.Detail != "" {
		b.WriteString(": ")
		b.WriteString(e.Detail)
	}
	return b.String()
}

func (e *LunaRouteRefusal) Unwrap() error { return e.Reason }

```go
package provider

import (
	"context"
	"errors"
	"fmt"
	"regexp"
	"strings"
	"unicode/utf8"
)

// LunaRouteOperation names the gateway call an outcome came from; the same
// status means different things per operation (a bare 404 on list models is a
// failed listing, not an unavailable model).
type LunaRouteOperation string

const (
	LunaRouteListModels LunaRouteOperation = "list models"
	LunaRouteChat       LunaRouteOperation = "chat"
	LunaRouteAgent      LunaRouteOperation = "agent run"
)

const lunaRouteSnippetMax = 256

// lunaRouteDocumentedCodes are LunaRoute's documented error codes (LR-04,
// docs/designs/2026-11-10-lunaroute-provider-decisions.md; source note
// docs/evidence/lunaroute-provider/gateway-contract.md). MODEL_NOT_FOUND and
// *_busy codes are deliberately absent: availability is the re-list's job.
var lunaRouteDocumentedCodes = map[string]error{
	"INVALID_API_KEY":                   ErrLunaRouteCredentialsRejected,
	"CONCURRENT_REQUEST_LIMIT_EXCEEDED": ErrLunaRouteBusy,
	"INFERENCE_UNAVAILABLE":             ErrLunaRouteServiceFailure,
	"NO_HEALTHY_PROVIDER":               ErrLunaRouteServiceFailure,
	"PROVIDER_KEY_UNAVAILABLE":          ErrLunaRouteServiceFailure,
	"BYOK_SPEND_GATE_UNAVAILABLE":       ErrLunaRouteServiceFailure,
	"BYOK_SPEND_CAP_REACHED":            ErrLunaRouteRequestRefused,
	"MODEL_UNPRICED":                    ErrLunaRouteRequestRefused,
}

// lunaRouteVerifiedCodes keys the documented codes by operation (the same
// table for each today; kept per-operation so a future operation-specific
// observation can narrow one without touching the others).
var lunaRouteVerifiedCodes = map[LunaRouteOperation]map[string]error{
	LunaRouteListModels: lunaRouteDocumentedCodes,
	LunaRouteChat:       lunaRouteDocumentedCodes,
	LunaRouteAgent:      lunaRouteDocumentedCodes,
}

// LunaRouteOutcome is the classifier input. Body is bounded response text for code decoding only; arbitrary messages
// are never surfaced as a snippet. Secrets lists revealed key(s) to redact.
type LunaRouteOutcome struct {
	Operation LunaRouteOperation
	Status    int
	Code      string
	RetryAfter string
	Transport error
	Malformed error
	Body      string
	Secrets   []string
}

// LunaRouteFailure is a classified gateway failure. Error() shows only
// redacted text; Unwrap keeps the original transport/decode error identity.
type LunaRouteFailure struct {
	Kind      error
	Operation LunaRouteOperation
	Status    int
	Snippet   string
	RetryAfter string
	cause     error
	causeText string
}

func (f *LunaRouteFailure) Error() string {
	var b strings.Builder
	fmt.Fprintf(&b, "lunaroute %s: %s", f.Operation, f.Kind.Error())
	if f.Status != 0 {
		fmt.Fprintf(&b, " (HTTP %d)", f.Status)
	}
	if f.Snippet != "" {
		b.WriteString(": ")
		b.WriteString(f.Snippet)
	}
	if f.RetryAfter != "" {
		b.WriteString("; retry after " + f.RetryAfter)
	}
	if f.causeText != "" {
		b.WriteString(": ")
		b.WriteString(f.causeText)
	}
	return b.String()
}

func (f *LunaRouteFailure) Unwrap() []error {
	if f.cause == nil {
		return []error{f.Kind}
	}
	return []error{f.Kind, f.cause}
}

var (
	lrKeyRE     = regexp.MustCompile(`lr_[A-Za-z0-9._~+/=-]+`)
	bearerRE    = regexp.MustCompile(`(?i)(bearer\s+)[^\s"',]+`)
	apiHeaderRE = regexp.MustCompile(`(?i)((?:x-api-key|lunaroute-api-key)\s*[:=]\s*)[^\s"',]+`)
)

// RedactLunaRoute removes each non-empty secret, any lr_ token, bearer tokens
// and api-key header values, then replaces control characters with spaces and
// caps the result at 256 bytes on a rune boundary. Redaction always precedes
// truncation.
func RedactLunaRoute(s string, secrets ...string) string {
	for _, sec := range secrets {
		if sec != "" {
			s = strings.ReplaceAll(s, sec, "[REDACTED]")
		}
	}
	s = lrKeyRE.ReplaceAllString(s, "lr_[REDACTED]")
	s = bearerRE.ReplaceAllString(s, "${1}[REDACTED]")
	s = apiHeaderRE.ReplaceAllString(s, "${1}[REDACTED]")
	s = strings.Map(func(r rune) rune {
		if r < 0x20 || r == 0x7f {
			return ' '
		}
		return r
	}, s)
	s = strings.TrimSpace(s)
	if len(s) <= lunaRouteSnippetMax {
		return s
	}
	cut := lunaRouteSnippetMax
	for cut > 0 && !utf8.RuneStart(s[cut]) {
		cut--
	}
	return s[:cut]
}

// ClassifyLunaRoute maps one gateway outcome to exactly one outcome sentinel.
func ClassifyLunaRoute(o LunaRouteOutcome) *LunaRouteFailure {
	f := &LunaRouteFailure{Operation: o.Operation, Status: o.Status, Snippet: ""}
	switch {
	case o.Transport != nil:
		f.cause = o.Transport
		f.causeText = RedactLunaRoute(o.Transport.Error(), o.Secrets...)
		if errors.Is(o.Transport, context.Canceled) {
			f.Kind = ErrLunaRouteCauseUnknown
		} else {
			f.Kind = ErrLunaRouteServiceFailure
		}
	case o.Malformed != nil:
		f.cause = o.Malformed
		f.causeText = "malformed response: " + RedactLunaRoute(o.Malformed.Error(), o.Secrets...)
		f.Kind = ErrLunaRouteServiceFailure
	case o.Code != "" && lunaRouteVerifiedCodes[o.Operation][o.Code] != nil:
		f.Kind = lunaRouteVerifiedCodes[o.Operation][o.Code]
		f.Snippet = "code=" + o.Code // exact allowlisted code only; never a message/body
	case o.Status == 401:
		f.Kind = ErrLunaRouteCredentialsRejected
	case o.Status == 429:
		f.Kind = ErrLunaRouteBusy
	case o.Status >= 500 && o.Status <= 599:
		f.Kind = ErrLunaRouteServiceFailure
	default:
		f.Kind = ErrLunaRouteCauseUnknown
	}
	if f.Kind == ErrLunaRouteBusy { f.RetryAfter = NormalizeLunaRouteRetryAfter(o.RetryAfter) }
	return f
}
```

## Error-envelope authority and diagnostic safety

`LunaRouteErrorCode` accepts the exact LR-04 shapes: nested `error.code` in bare/wrapped errors, or top-level `code` for a bare error object. A nested error object takes precedence; contradictory nested/top-level string codes yield no code rather than choosing a verdict. Non-string/null/missing codes and malformed JSON return empty. Test all three forms plus contradictory fields. Only codes in the operation's documented table refine classification; arbitrary `error.type` or message text never does.

LR-04 says never surface gateway messages. The classifier's Snippet is empty for unknown/unparseable bodies and can contain only `code=<allowlisted code>` for a known code. Keep raw Body only transiently for decoding; do not put it in Error()/logs. Safe local/transport errors retain identity via sanitized wrappers. Test a non-secret upstream message is absent too; checking only secret removal misses this contract. `RedactLunaRoute` remains the bounded sanitizer for local/transport diagnostics; cap/read errors never pass partial body text to it.

## Retry-After production input

Produce `func NormalizeLunaRouteRetryAfter(raw string) string`: accept an unsigned delta-seconds value or an RFC1123 HTTP date, normalize it, otherwise return empty (including CR/LF, negative values, overflow or arbitrary text). `LunaRouteOutcome.RetryAfter` is the raw header input; set `LunaRouteFailure.RetryAfter` only when the resulting Kind is ErrLunaRouteBusy, and Error() appends the normalized retry guidance.
