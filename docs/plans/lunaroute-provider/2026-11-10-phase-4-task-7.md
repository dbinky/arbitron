# LunaRoute Phase 4 · Task 7 — Release acceptance matrix (live, MCP-driven) and readiness procedure

**Goal:** Encode the release gate of design phase-4 §9 as a credential-gated live test that drives the REAL composition root through its MCP tools against the real gateway and the real installed harnesses — connection, discovery, a chat task, and a file-creating, command-running tool task on each of claude-code, codex, opencode and pi — plus the safeguard, refusal, error and no-disclosure checks; and document the manual MCP procedure and the readiness rule.

**Architecture:** `cmd/arbitron/lunaroute_acceptance_live_test.go` (package `main`, so it can boot `initDomain` via `bootSinkRoot` and use `mcpToolCaller`). It skips unless `ARBITRON_LUNAROUTE_E2E_KEY` and `ARBITRON_LUNAROUTE_ACCEPTANCE=1` are set, all four binaries are on `PATH`, the per-backend model env vars are set, and `ARBITRON_LUNAROUTE_E2E_CAPABILITIES` names an evidence-backed capabilities file (LR-02 facts for claude-code/pi limits). Runs are triggered through MCP `instance_trigger`; results are asserted at the sinks (instance state + model pins in SQLite, files in the instance workspace, MCP error texts, the server log file). `docs/evidence/lunaroute-provider/README.md` gains the manual procedure; readiness additionally requires `TestReleaseGate` (Phase 1 Task 11) to pass.

**Tech Stack:** Go 1.25, real `claude`/`codex`/`opencode`/`pi` binaries, mcp-go, testify.

**Spec:** spec §Outcomes (all five bullets; "Successful launches alone do not satisfy readiness") · **Design:** phase-4 §9; phase-2/3/4 §8 Tier 2

## Global Constraints
- Every agent task must create a file, execute a command, and leave the run `completed` (successful terminal turn) — exit codes alone are insufficient.
- No substitution: the run's model pin equals the profile's model for every backend; the backend that ran is the profile's.
- No credential disclosure: the key appears in no MCP response text and not in the server log file.
- Service failure cannot be induced against the live gateway; it is covered by the Phase 2 fake-gateway root tests and listed as such in the procedure (not silently skipped).
- Missing prerequisites → `t.Skip` naming what is missing; release readiness stays blocked.

## ESCALATIONS (readiness blockers until closed in the register)
- **ESCALATION LR-01** hosted endpoint/auth · **LR-02** limits/effort facts and per-backend completion observations (the capabilities file this test consumes) · **LR-03** alias vendor/immutability and spelling evidence (the alias model used here) · **LR-07** codex contract · **LR-08** pi contract (BLOCKED if no per-run agent-dir relocation exists). A green run of this test is necessary but not sufficient; `register.yaml` must show every item `verified`.

## Review Focus
- The acceptance alias model must classify as `anthropic` and equal-vendor with a Claude doer (safeguard holds through the gateway).
- The opaque-model refusal must be a refusal at save time, not a failed run.
- The unavailable-model case must fail the run with a LunaRoute-classified message and never fall back to another model.

package main

import (
	"encoding/json"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"regexp"
	"strings"
	"testing"

	"github.com/arbitron/arbitron/domain/instance"
	"github.com/arbitron/arbitron/domain/modelidentity"
	"github.com/google/uuid"
	"github.com/stretchr/testify/assert"
	"github.com/stretchr/testify/require"
)

type acceptanceConfig struct {
	key, caps, claudeBin           string
	chat, alias, opaque            string
	byBackend                      map[string]string
}

func acceptanceEnv(t *testing.T) acceptanceConfig {
	t.Helper()
	c := acceptanceConfig{key: os.Getenv("ARBITRON_LUNAROUTE_E2E_KEY"), caps: os.Getenv("ARBITRON_LUNAROUTE_E2E_CAPABILITIES")}
	if c.key == "" || os.Getenv("ARBITRON_LUNAROUTE_ACCEPTANCE") != "1" {
		t.Skip("set ARBITRON_LUNAROUTE_E2E_KEY and ARBITRON_LUNAROUTE_ACCEPTANCE=1 to run the release acceptance matrix; readiness stays blocked")
	}
	if c.caps == "" {
		t.Skip("ARBITRON_LUNAROUTE_E2E_CAPABILITIES unset: an evidence-backed lunaroute_models file is required (LR-02)")
	}
	for _, bin := range []string{"claude", "codex", "opencode", "pi"} {
		p, err := exec.LookPath(bin)
		if err != nil {
			t.Skipf("%s not on PATH: acceptance needs every backend", bin)
		}
		if bin == "claude" {
			c.claudeBin = p
		}
	}
	need := func(v string) string {
		s := strings.TrimSpace(os.Getenv(v))
		if s == "" {
			t.Skipf("%s unset", v)
		}
		return s
	}
	c.chat = need("ARBITRON_LUNAROUTE_E2E_CHAT_MODEL")
	c.alias = need("ARBITRON_LUNAROUTE_E2E_ALIAS_MODEL") // a proprietary/alias id, e.g. claude-sonnet-5-lr1
	c.opaque = strings.TrimSpace(os.Getenv("ARBITRON_LUNAROUTE_E2E_OPAQUE_MODEL"))
	if c.opaque == "" {
		c.opaque = "muse-spark-open"
	}
	c.byBackend = map[string]string{
		"claude-code": need("ARBITRON_LUNAROUTE_E2E_CLAUDE_MODEL"),
		"codex":       need("ARBITRON_LUNAROUTE_E2E_CODEX_MODEL"),
		"opencode":    need("ARBITRON_LUNAROUTE_E2E_OPENCODE_MODEL"),
		"pi":          need("ARBITRON_LUNAROUTE_E2E_PI_MODEL"),
	}
	return c
}

func writeTemplateWorkflow(t *testing.T, ws, name, nodeType, alias, prompt string) {
	t.Helper()
	writeWorkflow(t, ws, name, fmt.Sprintf(`{"name": %q, "description": "lunaroute acceptance", "inputs": [],
  "nodes": [{"id": "work", "type": %q, "entrypoint": true, "config": {"model_profile": %q, "templateFile": "templates/p.md"}}],
  "edges": []}`, name, nodeType, alias))
	dir := filepath.Join(ws, "users", localDefaultUser.String(), name, "templates")
	require.NoError(t, os.MkdirAll(dir, 0o700))
	require.NoError(t, os.WriteFile(filepath.Join(dir, "p.md"), []byte(prompt), 0o600))
}

var uuidRE = regexp.MustCompile(`[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`)

func triggerViaMCP(t *testing.T, call func(string, map[string]any) (bool, string), name string) uuid.UUID {
	t.Helper()
	isErr, text := call("instance_trigger", map[string]any{"workflowName": name})
	require.False(t, isErr, text)
	m := uuidRE.FindString(text)
	require.NotEmpty(t, m, text)
	return uuid.MustParse(m)
}

// familyInDiscovery finds the discovery entry for model in connection_models
// JSON (keys "id" or "model") and returns its "family" value.
func familyInDiscovery(t *testing.T, text, model string) string {
	t.Helper()
	var v any
	require.NoError(t, json.Unmarshal([]byte(text), &v))
	var walk func(any) string
	walk = func(x any) string {
		switch n := x.(type) {
		case map[string]any:
			if n["id"] == model || n["model"] == model {
				if f, ok := n["family"].(string); ok {
					return f
				}
			}
			for _, c := range n {
				if f := walk(c); f != "" {
					return f
				}
			}
		case []any:
			for _, c := range n {
				if f := walk(c); f != "" {
					return f
				}
			}
		}
		return ""
	}
	return walk(v)
}

func TestLunaRouteReleaseAcceptance(t *testing.T) {
	cfg := acceptanceEnv(t)
	agentPrompt := func(b string) string {
		return fmt.Sprintf("Create a file named acceptance-%[1]s.txt in the current directory containing exactly ok-%[1]s. Then run the shell command `ls > listing-%[1]s.txt`. Reply DONE when both are finished.", b)
	}
	ds := bootSinkRoot(t, "capabilitiespath: "+cfg.caps+"\nllm:\n  binarypath: "+cfg.claudeBin+"\n  timeoutseconds: 900\n", func(ws string) {
		writeTemplateWorkflow(t, ws, "lr-accept-chat", "llm_call", "lr-accept-chat", "Reply with the single word PONG.")
		writeTemplateWorkflow(t, ws, "lr-accept-unavailable", "llm_call", "lr-accept-unavailable", "Reply with the single word PONG.")
		for b := range map[string]bool{"claude-code": true, "codex": true, "opencode": true, "pi": true} {
			writeTemplateWorkflow(t, ws, "lr-accept-"+b, "agent_call", "lr-accept-"+b, agentPrompt(b))
		}
	})
	call0 := mcpToolCaller(t, ds)
	var transcript []string
	call := func(name string, args map[string]any) (bool, string) {
		isErr, text := call0(name, args)
		transcript = append(transcript, text)
		return isErr, text
	}
	tools := []any{"Read", "Write", "Edit", "Bash", "Glob", "Grep"}

	// 1. connection + discovery
	isErr, text := call("connection_create", map[string]any{"name": "lunaroute-main", "provider": "lunaroute", "base_url": "", "api_key": cfg.key})
	require.False(t, isErr, text)
	isErr, discovery := call("connection_models", map[string]any{"name": "lunaroute-main"})
	require.False(t, isErr, discovery)
	for _, m := range append([]string{cfg.chat, cfg.alias}, cfg.byBackend["claude-code"], cfg.byBackend["codex"], cfg.byBackend["opencode"], cfg.byBackend["pi"]) {
		assert.Contains(t, discovery, m, "model listed by connection_models")
	}

	// 2. proprietary/alias selection keeps the actual vendor; same-vendor pairing would be rejected
	assert.Equal(t, "anthropic", familyInDiscovery(t, discovery, cfg.alias))
	assert.Equal(t, modelidentity.ClassifyFamily("", "claude-opus-5-5"), modelidentity.ClassifyFamily("lunaroute", cfg.alias), "alias doer vs Claude judge = same family → safeguard rejects the pairing")
	isErr, text = call("profile_create", map[string]any{"alias": "lr-accept-alias", "kind": "agent", "backend": "claude-code", "connection_ref": "lunaroute-main", "model": cfg.alias, "allowed_tools": tools})
	require.False(t, isErr, "proprietary alias selectable: %s", text)

	// 3. unresolved family refused at save
	isErr, text = call("profile_create", map[string]any{"alias": "lr-accept-opaque", "kind": "agent", "backend": "opencode", "connection_ref": "lunaroute-main", "model": cfg.opaque})
	assert.True(t, isErr)
	assert.True(t, strings.Contains(text, "family is unresolved") || strings.Contains(text, "not a verified fixed catalog spelling"), text)

	// 4. known incompatibility refused at save, no substitution
	isErr, text = call("profile_create", map[string]any{"alias": "lr-accept-tier", "kind": "agent", "backend": "claude-code", "connection_ref": "lunaroute-main", "model": cfg.byBackend["claude-code"], "context_window": "1m"})
	assert.True(t, isErr)
	assert.Contains(t, text, "Claude-native")

	// 5. chat task completes
	isErr, text = call("profile_create", map[string]any{"alias": "lr-accept-chat", "kind": "chat", "connection_ref": "lunaroute-main", "model": cfg.chat})
	require.False(t, isErr, text)
	id := triggerViaMCP(t, call, "lr-accept-chat")
	inst := waitTerminal(t, ds, id)
	require.Equal(t, instance.StateCompleted, inst.State)
	assert.Equal(t, cfg.chat, inst.ModelPins["lr-accept-chat"])

	// 6. tool task on every backend: file + command + completed turn, no substitution
	for _, b := range []string{"claude-code", "codex", "opencode", "pi"} {
		t.Run(b, func(t *testing.T) {
			alias := "lr-accept-" + b
			isErr, text := call("profile_create", map[string]any{"alias": alias, "kind": "agent", "backend": b, "connection_ref": "lunaroute-main", "model": cfg.byBackend[b], "allowed_tools": tools})
			require.False(t, isErr, text)
			id := triggerViaMCP(t, call, alias)
			inst := waitTerminal(t, ds, id)
			if inst.State != instance.StateCompleted {
				var nerr string
				_ = ds.db.QueryRow(`SELECT COALESCE(error,'') FROM node_executions WHERE instance_id = ? AND error IS NOT NULL`, id.String()).Scan(&nerr)
				t.Fatalf("%s run ended %s: %s", b, inst.State, nerr)
			}
			assert.Equal(t, cfg.byBackend[b], inst.ModelPins[alias], "no model substitution")
			ws := filepath.Join(ds.cfg.Workspace.Path, "instances", id.String())
			got, err := os.ReadFile(filepath.Join(ws, "acceptance-"+b+".txt"))
			require.NoError(t, err, "file created")
			assert.Equal(t, "ok-"+b, strings.TrimSpace(string(got)))
			listing, err := os.ReadFile(filepath.Join(ws, "listing-"+b+".txt"))
			require.NoError(t, err, "command executed")
			assert.Contains(t, string(listing), "acceptance-"+b+".txt")
		})
	}

	// 7. invalid credential is distinguished
	isErr, text = call("connection_create", map[string]any{"name": "lunaroute-bad", "provider": "lunaroute", "base_url": "", "api_key": "lr_invalid_for_acceptance"})
	require.False(t, isErr, text)
	isErr, text = call("connection_models", map[string]any{"name": "lunaroute-bad"})
	assert.True(t, isErr)
	assert.Contains(t, text, "rejected the credential")

	// 8. unavailable model fails the run with a LunaRoute-classified error, no fallback
	isErr, text = call("profile_create", map[string]any{"alias": "lr-accept-unavailable", "kind": "chat", "connection_ref": "lunaroute-main", "model": "glm-999.9"})
	require.False(t, isErr, "grammar-valid id saves; availability is checked at run time: %s", text)
	id = triggerViaMCP(t, call, "lr-accept-unavailable")
	inst = waitTerminal(t, ds, id)
	assert.Equal(t, instance.StateFailed, inst.State)
	var nerr string
	_ = ds.db.QueryRow(`SELECT COALESCE(error,'') FROM node_executions WHERE instance_id = ? AND error IS NOT NULL`, id.String()).Scan(&nerr)
	assert.True(t, strings.Contains(nerr, "not available on this LunaRoute connection") || strings.Contains(nerr, "cause is unknown"), nerr)
	assert.Equal(t, "glm-999.9", inst.ModelPins["lr-accept-unavailable"], "no substitution")

	// 9. no credential disclosure anywhere
	for _, s := range transcript {
		assert.NotContains(t, s, cfg.key)
	}
	logBytes, _ := os.ReadFile(ds.cfg.Logging.File)
	assert.NotContains(t, string(logBytes), cfg.key)
	assert.NotContains(t, nerr, cfg.key)
}

Readiness requires ALL of:

1. `TestReleaseGate` passes: every LR-01…LR-08 item in `register.yaml` is `verified`.

   ARBITRON_LUNAROUTE_E2E_OPENCODE_MODEL=<id> ARBITRON_LUNAROUTE_E2E_PI_MODEL=<id> \

   with `claude`, `codex`, `opencode` and `pi` on `PATH`.
3. The supporting-call evidence from Phase 3 Task 5 (claude-code, opencode) and
   Phase 4 Task 1 (codex, pi) is committed under `observations/`.
4. Service-failure behaviour is proven by the Phase 2 fake-gateway root tests
   (5xx → "service failure", 429 → "busy"); it cannot be induced live.

Manual MCP walk-through (same matrix, by hand from an LLM client):
`connection_create` (provider `lunaroute`, empty `base_url`, `lr_` key) →
`connection_models` (note known/unknown fields; unknown is not support) →
`profile_create` chat + one agent profile per backend with an explicit

line may contain the key.

A skipped run, a launch-only smoke test, or a missing backend does NOT meet
readiness.
