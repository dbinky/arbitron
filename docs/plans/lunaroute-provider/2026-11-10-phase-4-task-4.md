# LunaRoute Phase 4 · Task 4 — pi LunaRoute custom provider (per-run private agent dir)

**Dependencies:** P4-T1 pi verification (LR-08), P1-T8 metadata schema/population (LR-02), and P4-T3.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Let pi call LunaRoute's OpenAI-compatible endpoint with the connection's guarded `lr_` key through a per-launch, owner-only agent directory holding a `models.json` custom-provider definition built only from evidence-backed capability facts — never touching `~/.pi`, never putting the key in argv or the file, and removing the directory on every exit path. Non-LunaRoute pi launches stay byte-identical.

**Architecture:** `adapter/pi/env.go` gains a third descriptor shape, `custom` (key-based + "needs a per-launch provider definition"), and a `lunaroute` row; `piEnv` refuses custom rows (they launch only through their definition). New `adapter/pi/lunaroute.go`: `lunaRouteModelsJSON` (pure: hosted `/v1` base from `provider.LunaRouteOpenAIBaseURL`, key referenced by env-var NAME, the binding model, `contextWindow`/`maxTokens` and independent `Reasoning` from `CapabilityRules.LunaRouteModel` — unknown required metadata → `LunaRouteRefusal{ErrLunaRouteLimitsUnknown}`) and `prepareLunaRoutePiLaunch` (validate → guarded reveal → `os.MkdirTemp` 0700 → write `models.json` 0600 → env `LUNAROUTE_API_KEY` + `PI_CODING_AGENT_DIR` → argv `--model lunaroute/<id>`). `pi.Config` gains `CapabilityRules provider.CapabilityRules`. The domain rule gains "pi on LunaRoute needs known limits" so the refusal happens at profile save too. Factory injection, enablement and root wiring are Task 5.

**Tech Stack:** Go 1.25, `encoding/json`, `os.MkdirTemp`, `adapter/procenv`, testify.

**Spec:** spec §Chat and agent workflows (Pi), §Connection setup, §Failure behavior · **Design:** phase-4 §3.3, §4 (pi data flow), §7, §8

## Global Constraints
- `models.json` shape (**LR-08 decided**, `docs/designs/2026-11-10-lunaroute-provider-decisions.md`; source: pi 1.5.1 `docs/models-configuration.md`): `{"providers":{"lunaroute":{"baseUrl":"https://gw.lunaroute.com/v1","api":"openai-completions","apiKey":"$LUNAROUTE_API_KEY","authHeader":true,"models":[{"id":<model>,"name":<model>,"reasoning":<bool>,"input":["text"],"contextWindow":<known>,"maxTokens":<known>}]}}}`. `apiKey` must use pi's `$NAME` env interpolation; a bare name is a literal key. `authHeader:true` sends the key as `Authorization: Bearer` (LR-01).
- `reasoning` comes only from P1-T8 `Reasoning.Support`: supported → true, unsupported → false, unknown → refuse. Effort support is a separate fact and never implies reasoning metadata.
- Env = `procenv.BaseEnv()` + exactly one `LUNAROUTE_API_KEY` + `PI_CODING_AGENT_DIR=<private dir>`. Argv = existing contract with `--model lunaroute/<model>` (+ `--thinking <level>` from the existing exact mapping).
- Order: definition/limits validation and argv (no I/O) → guarded reveal → create dir → write file → launch. Any failure before launch leaves no directory.
- Directory removed on success, failure, cancellation and panic (deferred `RemoveAll`).
- pi exit 0 with a failed turn stays `ErrTurnFailed` (existing semantics) and still cleans up.
- **LR-08 decided:** the file format, `api` value, `PI_CODING_AGENT_DIR` relocation (pi 1.5.1 `docs/configuration.md`: it relocates models/auth/settings/extensions/mcp, and a fresh untrusted dir does not load project `.pi` config) and `--model lunaroute/<id>` argv are the contract. **LR-02** supplies limits and reasoning. Phase 4 Task 1 verifies them. If relocation or the schema misbehaves (On-failure rule), pi + LunaRoute stays refused and LR-08 becomes `escalated` for a new human decision; never write `~/.pi`, and never drop pi from scope.

## Review Focus
- A model absent from the table (or with only one limit known) must refuse before any reveal/dir creation.
- `TMPDIR` unwritable → no launch, clear error.
- The key must not appear in `models.json` (only the `$LUNAROUTE_API_KEY` reference).
- A user `~/.pi/agent/settings.json` must be untouched and not referenced by the child env (`PI_CODING_AGENT_DIR` points elsewhere).
- Concurrent launches get distinct directories.

func envOf(env []string, name string) (string, int) {
	v, n := "", 0
	for _, e := range env {
		if strings.HasPrefix(e, name+"=") {
			v, n = strings.TrimPrefix(e, name+"="), n+1
		}
	}
	return v, n
}

// capturingRunner records the agent dir state at launch, then replays scripts.
type capturingRunner struct {
	inner      *multiRunner
	mu         sync.Mutex
	dir        string
	dirInfo    os.FileInfo
	fileInfo   os.FileInfo
	modelsJSON []byte
	panicOnRun bool
}

func (c *capturingRunner) Run(ctx context.Context, spec claudecli.RunSpec) (<-chan string, func() error, error) {
	if len(spec.Args) > 0 && spec.Args[0] != "--version" {
		c.mu.Lock()
		c.dir, _ = envOf(spec.Env, PiAgentDirVar)
		c.dirInfo, _ = os.Stat(c.dir)
		c.fileInfo, _ = os.Stat(filepath.Join(c.dir, "models.json"))
		c.modelsJSON, _ = os.ReadFile(filepath.Join(c.dir, "models.json"))
		c.mu.Unlock()
		if c.panicOnRun {
			panic("runner exploded")
		}
	}
	return c.inner.Run(ctx, spec)
}

	AuthHeader bool            `json:"authHeader"` // send the resolved key as Authorization: Bearer (LR-01)
	Models     []piCustomModel `json:"models"`

type piCustomModel struct {
	ID            string   `json:"id"`
	Name          string   `json:"name"`
	Reasoning     bool     `json:"reasoning"`
	Input         []string `json:"input"`
	ContextWindow int      `json:"contextWindow"`
	MaxTokens     int      `json:"maxTokens"`
}

// lunaRouteModelsJSON builds the per-run custom-provider definition. Required
// model metadata comes only from the evidence-backed capability table; unknown
// limits block the route. The key is referenced by env var NAME only.
func lunaRouteModelsJSON(b provider.ResolvedBinding, rules provider.LunaRouteCapabilities) ([]byte, error) {
	base, err := provider.LunaRouteOpenAIBaseURL(b.BaseURL)
	if err != nil {
		return nil, err
	}
	model := strings.TrimSpace(b.Model)
	if model == "" {
		return nil, ErrModelRequired
	}
	var m provider.LunaRouteModel
	if rules != nil {
		m, _ = rules.LunaRouteModel(model)
	}
	if !m.ContextTokens.Known() || !m.OutputTokens.Known() {
		return nil, &provider.LunaRouteRefusal{Reason: provider.ErrLunaRouteLimitsUnknown, Model: model, Backend: workflow.BackendPi,
			Detail: "pi on LunaRoute needs known context and output limits for this model in the capability table (lunaroute_models)"}
	}
	if m.Reasoning.Support != provider.SupportSupported && m.Reasoning.Support != provider.SupportUnsupported {
		return nil, &provider.LunaRouteRefusal{Reason: provider.ErrLunaRouteLimitsUnknown, Model: model, Backend: workflow.BackendPi,
			Detail: "pi on LunaRoute needs known reasoning metadata; record an independent evidence-backed reasoning fact"}
	}
	def := piModelsFile{Providers: map[string]piCustomProvider{lunaRoutePiProvider: {
		BaseURL: base, API: lunaRoutePiAPI, APIKey: "$" + LunaRouteKeyVar, AuthHeader: true,
		Models: []piCustomModel{{ID: model, Name: model, Reasoning: m.Reasoning.Support == provider.SupportSupported,
			Input: []string{"text"}, ContextWindow: m.ContextTokens.Tokens, MaxTokens: m.OutputTokens.Tokens}},
	}}}
	return json.MarshalIndent(def, "", "  ")
}

// piLaunch is one prepared LunaRoute pi launch; cleanup removes dir.
type piLaunch struct {
	args, env []string
	dir       string
	cleanup   func()
}

// prepareLunaRoutePiLaunch validates and builds everything without I/O, then
// reveals the key through the LunaRoute guard, and only then creates the
// owner-only agent dir and writes models.json. Any failure leaves nothing.
func prepareLunaRoutePiLaunch(ctx context.Context, b provider.ResolvedBinding, rules provider.LunaRouteCapabilities) (piLaunch, error) {
	def, err := lunaRouteModelsJSON(b, rules)
	if err != nil {
		return piLaunch{}, err
	}
	sel := b
	sel.Model = lunaRoutePiProvider + "/" + strings.TrimSpace(b.Model)
	args, err := buildArgs(sel)
	if err != nil {
		return piLaunch{}, err
	}
	guarded := provider.GuardLunaRouteReveal(b)
	env, err := procenv.CredentialEnv(ctx, procenv.CredentialSpec{
		Runner:   "pi: lunaroute",
		KeyVar:   LunaRouteKeyVar,
		Reveal:   guarded.RevealKey,
		EmptyKey: procenv.EmptyKeyReject,
	})
	if err != nil {
		return piLaunch{}, err
	}
	dir, err := os.MkdirTemp("", lunaRouteDirPrefix)
	if err != nil {
		return piLaunch{}, fmt.Errorf("pi: lunaroute: create private agent dir: %w", err)
	}
	cleanup := func() { _ = os.RemoveAll(dir) }
	if err := os.Chmod(dir, 0o700); err != nil {
		cleanup()
		return piLaunch{}, fmt.Errorf("pi: lunaroute: secure private agent dir: %w", err)
	}
	if err := os.WriteFile(filepath.Join(dir, "models.json"), def, 0o600); err != nil {
		cleanup()
		return piLaunch{}, fmt.Errorf("pi: lunaroute: write provider definition: %w", err)
	}
	env = procenv.RemoveVar(env, PiAgentDirVar)
	env = procenv.RemoveVar(env, "OPENAI_API_KEY")
	env = append(env, PiAgentDirVar+"="+dir)
	return piLaunch{args: args, env: env, dir: dir, cleanup: cleanup}, nil
}
