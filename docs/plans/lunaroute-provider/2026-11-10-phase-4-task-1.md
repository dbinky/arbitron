# LunaRoute Phase 4 · Task 1 — Live verification of the installed codex and pi binaries (LR-07, LR-08)

**Goal:** Before any codex/pi LunaRoute argv/config contract is relied on, provide credential-gated live tests that run the INSTALLED `codex` and `pi` binaries against the hosted gateway with the exact candidate contract Tasks 2 and 4 encode, prove auth/config isolation from the user's home, complete a tool-using task, and write credential-free observations for the evidence register.

**Architecture:** New file `test/lunaroute/backends_live_test.go` in the Phase 1 Task 11 package (`lunaroute_test`), reusing `liveKey`, `writeObservation`, `evidenceDir`. Each test skips unless `ARBITRON_LUNAROUTE_E2E_KEY`, the per-backend model env var and the binary on `PATH` are present. The candidate contract is spelled out literally here (the live test must not depend on production code it is meant to validate); Tasks 2 and 4 pin the SAME literals in golden unit tests, so a contract change found live is a two-place edit the reviewer can see. Register items LR-07/LR-08 flip only by a human committing the observation and editing `register.yaml`.

**Tech Stack:** Go 1.25 `os/exec`, `encoding/json`, testify.

**Spec:** spec §Outcomes ("Complete a representative tool-using agent task through each of … Codex … Pi") · **Design:** phase-4 §5 (LR-07, LR-08 rows), §5 Deferred "Live verification tasks first", §8 Tier 2

## Global Constraints
- Candidate codex contract (LR-07): env `LUNAROUTE_API_KEY=<lr_ key>`, `CODEX_HOME=<private temp dir>`; argv `exec --dangerously-bypass-approvals-and-sandbox -m <model> -c model_provider="lunaroute" -c model_providers.lunaroute.name="LunaRoute" -c model_providers.lunaroute.base_url="https://gw.lunaroute.com/v1" -c model_providers.lunaroute.env_key="LUNAROUTE_API_KEY" -c model_providers.lunaroute.wire_api="responses" --cd <ws> --json`, prompt on stdin.
- Candidate pi contract (LR-08): env `LUNAROUTE_API_KEY=<lr_ key>`, `PI_CODING_AGENT_DIR=<private temp dir>` containing `models.json` = `{"providers":{"lunaroute":{"baseUrl":"https://gw.lunaroute.com/v1","api":"openai-completions","apiKey":"LUNAROUTE_API_KEY","models":[{"id":"<model>","name":"<model>","reasoning":false,"input":["text"],"contextWindow":<n>,"maxTokens":<n>}]}}}`; argv `--print --mode json --no-session --model lunaroute/<model>`.
- `HOME` is a temp dir seeded with CONFLICTING `~/.codex/{auth.json,config.toml}` and `~/.pi/agent/{auth.json,settings.json,models.json}` that select another provider/model; a pass proves the run did not use them (observed provider/model, files untouched).
- Observations contain no key and no `lr_` token (enforced by `writeObservation`).
- Missing credentials/binaries → `t.Skip`; release acceptance remains pending.

## ESCALATIONS
- **ESCALATION LR-07:** the exact `-c model_providers.<id>.*` keys, `wire_api="responses"`, `env_key` credential field, independence from `auth.json`, user/project-config precedence and supporting-model routing are unverified against the installed codex. Run `TestLiveCodexLunaRoute`; if any assertion fails, update the contract in `adapter/codex/lunaroute.go` (Task 2) and this test together, then record.
- **ESCALATION LR-08:** pi's custom-provider `models.json` format (field names, `api` value, env-referenced `apiKey`, required model metadata), the `lunaroute/<id>` model argv and the `PI_CODING_AGENT_DIR` per-run relocation are unverified. If the installed pi has NO supported per-run config-dir relocation, the pi outcome is **BLOCKED**: escalate to the product owner — never write `~/.pi`, never drop pi from scope, never claim readiness.
- **ESCALATION LR-01 / LR-02 / LR-03** (carried from Phase 1): hosted endpoint/auth, model limits & per-backend completion observations, alias/spelling evidence. The pi definition needs LR-02 limits: the live test takes them from `ARBITRON_LUNAROUTE_E2E_PI_CONTEXT` / `_PI_MAX_TOKENS`, which must come from authoritative LunaRoute/vendor docs — not from this run.

## Review Focus
- The conflicting `~/.codex/auth.json` must not be read: assert the codex run succeeded with an EMPTY temp `CODEX_HOME` and that the observed rollout lives under the temp dir, not `$HOME/.codex`.
- pi's message_end `provider`/`model` must be `lunaroute`/`<model>`, proving the conflicting `settings.json` default did not win.
- Tool-task success means a file created AND a command executed AND a successful terminal turn — exit code alone is insufficient for pi.
- Observation JSON must not contain the prompt-echoed key if the model repeats env (it never sees the key; `writeObservation` refuses `lr_` anyway).

package lunaroute_test

import (
	"bufio"
	"bytes"
	"encoding/json"
	"os"
	"os/exec"
	"path/filepath"
	"strconv"
	"strings"
	"testing"
	"time"

	"github.com/stretchr/testify/require"
)

const (
	lunaRouteOpenAIBase = "https://gw.lunaroute.com/v1"
	lunaRouteKeyVar     = "LUNAROUTE_API_KEY"
	toolTaskPrompt      = "Create a file named lunaroute-ok.txt containing exactly the text ok. Then run the shell command `ls > listing.txt`. Reply DONE when both are finished."
)

func requireBinary(t *testing.T, name string) string {
	t.Helper()
	p, err := exec.LookPath(name)
	if err != nil {
		t.Skipf("%s not on PATH: live %s evidence not collected; release acceptance remains pending", name, name)
	}
	return p
}

func liveModel(t *testing.T, envVar string) string {
	t.Helper()
	m := strings.TrimSpace(os.Getenv(envVar))
	if m == "" {
		t.Skipf("%s unset: choose a LunaRoute model from connection_models for this backend", envVar)
	}
	return m
}

// seedConflictingHome builds a HOME whose codex and pi config select a
// different provider/model and carry a bogus subscription credential.
func seedConflictingHome(t *testing.T) string {
	t.Helper()
	home := t.TempDir()
	codex := filepath.Join(home, ".codex")
	require.NoError(t, os.MkdirAll(codex, 0o700))
	require.NoError(t, os.WriteFile(filepath.Join(codex, "auth.json"), []byte(`{"OPENAI_API_KEY":"sk-conflicting-home-key"}`), 0o600))
	require.NoError(t, os.WriteFile(filepath.Join(codex, "config.toml"), []byte("model = \"gpt-conflict\"\nmodel_provider = \"openai\"\n"), 0o600))
	agent := filepath.Join(home, ".pi", "agent")
	require.NoError(t, os.MkdirAll(agent, 0o700))
	require.NoError(t, os.WriteFile(filepath.Join(agent, "settings.json"), []byte(`{"defaultProvider":"openai","defaultModel":"gpt-conflict"}`), 0o600))
	require.NoError(t, os.WriteFile(filepath.Join(agent, "auth.json"), []byte(`{"openai":{"type":"api_key","key":"sk-conflicting-home-key"}}`), 0o600))
	return home
}

func runCaptured(t *testing.T, cmd *exec.Cmd, stdin string) (string, error) {
	t.Helper()
	var out, errBuf bytes.Buffer
	cmd.Stdin = strings.NewReader(stdin)
	cmd.Stdout, cmd.Stderr = &out, &errBuf
	err := cmd.Run()
	if err != nil {
		t.Logf("stderr tail: %s", tail(errBuf.String(), 2000))
	}
	return out.String(), err
}

func tail(s string, n int) string {
	if len(s) <= n {
		return s
	}
	return s[len(s)-n:]
}

func baseChildEnv(home string) []string {
	return []string{"PATH=" + os.Getenv("PATH"), "HOME=" + home, "LANG=C.UTF-8"}
}

func versionOf(t *testing.T, bin string) string {
	t.Helper()
	out, err := exec.Command(bin, "--version").CombinedOutput()
	require.NoError(t, err)
	return strings.TrimSpace(string(out))
}

func assertToolTask(t *testing.T, ws string) {
	t.Helper()
	b, err := os.ReadFile(filepath.Join(ws, "lunaroute-ok.txt"))
	require.NoError(t, err, "agent created the file")
	require.Equal(t, "ok", strings.TrimSpace(string(b)))
	listing, err := os.ReadFile(filepath.Join(ws, "listing.txt"))
	require.NoError(t, err, "agent ran the command")
	require.Contains(t, string(listing), "lunaroute-ok.txt")
}

func TestLiveCodexHelp(t *testing.T) {
	_ = liveKey(t)

		"recorded_at": time.Now().UTC().Format(time.RFC3339),
		"version":     versionOf(t, bin),
		"exec_help":   string(help),
	})
}

// TestLiveCodexLunaRoute (LR-07): the candidate -c provider contract runs a
// tool task with an EMPTY private CODEX_HOME while HOME holds a conflicting
// subscription credential and config.
func TestLiveCodexLunaRoute(t *testing.T) {
	key := liveKey(t)
	bin := requireBinary(t, "codex")
	model := liveModel(t, "ARBITRON_LUNAROUTE_E2E_CODEX_MODEL")
	home := seedConflictingHome(t)
	codexHome := t.TempDir()
	ws := t.TempDir()
	args := []string{"exec", "--dangerously-bypass-approvals-and-sandbox", "-m", model,
		"-c", `model_provider="lunaroute"`,
		"-c", `model_providers.lunaroute.name="LunaRoute"`,
		"-c", `model_providers.lunaroute.base_url="` + lunaRouteOpenAIBase + `"`,
		"-c", `model_providers.lunaroute.env_key="` + lunaRouteKeyVar + `"`,
		"-c", `model_providers.lunaroute.wire_api="responses"`,
		"--cd", ws, "--json"}
	cmd := exec.Command(bin, args...)
	cmd.Env = append(baseChildEnv(home), lunaRouteKeyVar+"="+key, "CODEX_HOME="+codexHome)
	out, err := runCaptured(t, cmd, toolTaskPrompt)
	require.NoError(t, err, "codex exec on LunaRoute must exit 0")
	completed := false
	var models []string
	sc := bufio.NewScanner(strings.NewReader(out))
	sc.Buffer(make([]byte, 0, 64*1024), 4*1024*1024)
	for sc.Scan() {
		var ev map[string]any
		if json.Unmarshal(sc.Bytes(), &ev) == nil && ev["type"] == "turn.completed" {
			completed = true
		}
	}
	require.True(t, completed, "successful terminal turn")
	assertToolTask(t, ws)
	rollouts, _ := filepath.Glob(filepath.Join(codexHome, "sessions", "*", "*", "*", "rollout-*.jsonl"))
	require.NotEmpty(t, rollouts, "rollout written under the private CODEX_HOME")
	for _, r := range rollouts {
		b, _ := os.ReadFile(r)
		for _, line := range strings.Split(string(b), "\n") {
			var ev struct {
				Type    string `json:"type"`
				Payload struct {
					Model string `json:"model"`
				} `json:"payload"`
			}
			if json.Unmarshal([]byte(line), &ev) == nil && ev.Type == "turn_context" {
				models = append(models, ev.Payload.Model)
			}
		}
	}
	for _, m := range models {
		require.Equal(t, model, m, "every turn (incl. supporting turns) ran the selected model")
	}
	homeRollouts, _ := filepath.Glob(filepath.Join(home, ".codex", "sessions", "*", "*", "*", "*.jsonl"))
	require.Empty(t, homeRollouts, "nothing written to the user's ~/.codex")
	auth, _ := os.ReadFile(filepath.Join(home, ".codex", "auth.json"))
	require.Contains(t, string(auth), "sk-conflicting-home-key", "user auth.json untouched")
	entries, _ := os.ReadDir(codexHome)
	names := []string{}
	for _, e := range entries {
		names = append(names, e.Name())
	}
	writeObservation(t, key, "lr07-codex-run.json", map[string]any{
		"recorded_at":         time.Now().UTC().Format(time.RFC3339),
		"version":             versionOf(t, bin),
		"argv_shape":          strings.Join(args[:len(args)-3], " "),
		"model":               model,
		"turn_models":         models,
		"codex_home_entries":  names,
		"tool_task_completed": true,
	})
}

// TestLivePiLunaRoute (LR-08): a per-run PI_CODING_AGENT_DIR with the candidate
// models.json runs a tool task while HOME's ~/.pi selects another provider.
func TestLivePiLunaRoute(t *testing.T) {
	key := liveKey(t)
	bin := requireBinary(t, "pi")
	model := liveModel(t, "ARBITRON_LUNAROUTE_E2E_PI_MODEL")
	ctxTokens, err1 := strconv.Atoi(os.Getenv("ARBITRON_LUNAROUTE_E2E_PI_CONTEXT"))
	maxTokens, err2 := strconv.Atoi(os.Getenv("ARBITRON_LUNAROUTE_E2E_PI_MAX_TOKENS"))
	if err1 != nil || err2 != nil || ctxTokens <= 0 || maxTokens <= 0 {
		t.Skip("ARBITRON_LUNAROUTE_E2E_PI_CONTEXT / _PI_MAX_TOKENS unset: supply authoritative LR-02 limits for the pi model")
	}
	home := seedConflictingHome(t)
	agentDir := t.TempDir()
	def := map[string]any{"providers": map[string]any{"lunaroute": map[string]any{
		"baseUrl": lunaRouteOpenAIBase, "api": "openai-completions", "apiKey": lunaRouteKeyVar,
		"models": []map[string]any{{"id": model, "name": model, "reasoning": false, "input": []string{"text"},
			"contextWindow": ctxTokens, "maxTokens": maxTokens}},
	}}}
	raw, err := json.Marshal(def)
	require.NoError(t, err)
	require.NoError(t, os.WriteFile(filepath.Join(agentDir, "models.json"), raw, 0o600))
	ws := t.TempDir()
	cmd := exec.Command(bin, "--print", "--mode", "json", "--no-session", "--model", "lunaroute/"+model)
	cmd.Dir = ws
	cmd.Env = append(baseChildEnv(home), lunaRouteKeyVar+"="+key, "PI_CODING_AGENT_DIR="+agentDir)
	out, err := runCaptured(t, cmd, toolTaskPrompt)
	require.NoError(t, err)
	type msg struct {
		Role       string `json:"role"`
		Provider   string `json:"provider"`
		Model      string `json:"model"`
		StopReason string `json:"stopReason"`
	}
	var finals []msg
	sc := bufio.NewScanner(strings.NewReader(out))
	sc.Buffer(make([]byte, 0, 64*1024), 4*1024*1024)
	for sc.Scan() {
		var ev struct {
			Type    string `json:"type"`
			Message *msg   `json:"message"`
		}
		if json.Unmarshal(sc.Bytes(), &ev) == nil && ev.Type == "message_end" && ev.Message != nil && ev.Message.Role == "assistant" {
			finals = append(finals, *ev.Message)
		}
	}
	require.NotEmpty(t, finals)
	for _, m := range finals {
		require.Equal(t, "lunaroute", m.Provider, "home settings.json default provider did not win")
		require.Equal(t, model, m.Model)
		require.NotEqual(t, "error", m.StopReason)
		require.NotEqual(t, "aborted", m.StopReason)
	}
	assertToolTask(t, ws)
	settings, _ := os.ReadFile(filepath.Join(home, ".pi", "agent", "settings.json"))
	require.Contains(t, string(settings), "gpt-conflict", "user ~/.pi untouched")
	entries, _ := os.ReadDir(agentDir)
	names := []string{}
	for _, e := range entries {
		names = append(names, e.Name())
	}
	writeObservation(t, key, "lr08-pi-run.json", map[string]any{
		"recorded_at":         time.Now().UTC().Format(time.RFC3339),
		"version":             versionOf(t, bin),
		"argv":                "--print --mode json --no-session --model lunaroute/" + model,
		"models_json_fields":  []string{"baseUrl", "api", "apiKey", "models[].id", "name", "reasoning", "input", "contextWindow", "maxTokens"},
		"agent_dir_entries":   names,
		"assistant_messages":  finals,
		"tool_task_completed": true,
	})
}
