**Dependencies:** P1 complete and P2-T1/P2-T3.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Route `lunaroute` chat bindings through the existing OpenAI-compatible adapter at `<root>/v1/chat/completions` with Bearer `lr_…`, classified gateway errors, the phase-1 launch check (incl. `MaxTokens` vs known output limit, exact effort) before any I/O and no redirects — and prove it end to end through the composition root: a LunaRoute chat profile saves against the root's capability table, a triggered `llm_call` reaches the fake gateway with the right URL/header/model, and failures surface as classified node errors.

**Architecture:** New `adapter/provider/lunaroute_chat.go`: `(*Factory).lunaRouteChat(b) engine.ChatProvider` builds `openrouter.New` with the guarded binding (request-scoped revealed key supplied by the chat hook), `BaseURL = provider.LunaRouteOpenAIBaseURL(b.BaseURL)`, `procenv.NoRedirectClient(f.deps.HTTPClient)`, `ClassifyError → provider.ClassifyLunaRoute(LunaRouteChat…)`, `Preflight → provider.CheckLunaRouteLaunch(f.deps.CapabilityRules, b, req.MaxTokens)`. `Factory.ChatProviderFor` gets a `domprovider.CanonicalLunaRoute` arm. Construction stays lazy: no reveal, no I/O, no model required (inventory builds model-empty bindings); a tampered base URL fails at call time via the preflight. New test harness `cmd/arbitron/lunaroute_root_helpers_test.go` (`bootLunaRouteRoot`, `fakeLunaRouteGateway`) is reused by Phase 2 Task 6 and Phases 3–4.

**Tech Stack:** Go 1.25, testify, real `initDomainWithModelDependencies` with `ModelDependencies.ProviderTransport`.

**Spec:** spec §Chat and agent workflows (Chat), §Failure behavior, §Outcomes ("Complete a representative chat task through LunaRoute") · **Design:** phase-2 §3.4, §4 (Chat data flow), §5 Deferred "Runtime policy"/"Chat error seam"

## Global Constraints
- URL exactly `https://gw.lunaroute.com/v1/chat/completions`; header `Authorization: Bearer <lr_ key>`; no OpenRouter-specific headers (`HTTP-Referer`, `X-Title`) and no project header (spec non-goal: usage attribution).
- Effort is emitted exactly (the launch check refuses anything `ChatReasoningEffort` would floor, e.g. `xhigh`).
- A request whose `MaxTokens` exceeds the known output limit is refused before I/O (`ErrLunaRouteSettingConflict`).
- A pinned response naming a different model stays an execution-evidence error; never disable it. **LR-03 decided** (`docs/designs/2026-11-10-lunaroute-provider-decisions.md`): the arm sets `openrouter.Config.AcceptExecutedModel = modelidentity.LunaRouteExecutedModelAccepted` (P2-T3 hook, P1-T7 producer). Fixed reviewed ids still require the exact spelling. The reviewed alias `claude-sonnet-5-lr1` accepts a reported model only in the `anthropic` family; drift inside it is recorded, and any other family fails the node.
- No fallback to another model/backend/provider on any error.
- **LR-01/LR-04 decided:** `/v1/chat/completions` with Bearer only. Error bodies (bare or wrapped) are classified through P1-T2's documented code table (a body code beats the status mapping), with status mapping as the fallback. P2-T8 confirms the codes live.

## Review Focus
- Upstream body echoing the key on 401: node error must not contain it (key captured from the guarded reveal is passed as a classifier secret, plus generic `lr_` redaction).
- `ChatProviderFor` on a model-empty inventory binding must not reveal the key (count reveals).
- Tampered stored base URL: `ChatProviderFor` succeeds (lazy), the call fails with `ErrLunaRouteEndpoint` and the gateway sees nothing.
- A 307 from the gateway is not followed with the credential.
- Non-LunaRoute openrouter bindings keep `openrouter.ErrUpstreamStatus` (hooks not applied).

package provider

import (
	"github.com/arbitron/arbitron/adapter/openrouter"
	"github.com/arbitron/arbitron/adapter/procenv"
	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/modelidentity"
	domprovider "github.com/arbitron/arbitron/domain/provider"
)

// lunaRouteChat builds the LunaRoute chat provider over the OpenAI-compatible
// adapter: <root>/v1/chat/completions, guarded lr_ reveal, no redirects,
// gateway failures classified by the shared LunaRoute classifier, and the
// shared launch check (endpoint, model, axes, max tokens) before any I/O.
// Construction is lazy: nothing is revealed or validated against a model here.
func (f *Factory) lunaRouteChat(b domprovider.ResolvedBinding) engine.ChatProvider {
	launch := b
	guarded := domprovider.GuardLunaRouteReveal(b)
	// A non-hosted stored URL keeps its value here; the preflight and the
	// reveal guard both refuse it before any request is built.
	if base, err := domprovider.LunaRouteOpenAIBaseURL(b.BaseURL); err == nil {
		guarded.BaseURL = base
	}
	caps := f.deps.CapabilityRules
	return openrouter.New(openrouter.Config{
		Binding:          guarded,
		HTTPClient:       procenv.NoRedirectClient(f.deps.HTTPClient),
		Timeout:          f.deps.HTTPTimeout,
		MaxResponseBytes: f.deps.MaxResponseBytes,
		ClassifyError: func(status int, body string, transport error, retryAfter string, secrets ...string) error {
			return domprovider.ClassifyLunaRoute(domprovider.LunaRouteOutcome{
				Operation: domprovider.LunaRouteChat, Status: status, Body: body, Transport: transport, RetryAfter: retryAfter, Secrets: secrets,
				Code: domprovider.LunaRouteErrorCode(domprovider.LunaRouteChat, body),
			})
		},
		// LR-03 decided: exact spelling for fixed ids; vendor-family evidence
		// for the reviewed alias exception.
		AcceptExecutedModel: modelidentity.LunaRouteExecutedModelAccepted,
		Preflight: func(req engine.ChatRequest) error {
			settings := []string{}
			if req.Temperature != 0 { settings = append(settings, "temperature") }
			if req.OutputSchema != nil { settings = append(settings, "output_schema") }
			return domprovider.CheckLunaRouteRequest(caps, launch, req.MaxTokens, settings)
		},
	})
}

// lunaRouteGatewayRequest is one credential-bearing request the fake gateway saw.
type lunaRouteGatewayRequest struct {
	Method, URL, Authorization, APIKey string
	Header                             http.Header
	Body                               []byte
}

// lunaRouteGatewayReply overrides the scripted answer for one "METHOD /path".
type lunaRouteGatewayReply struct {
	Status int
	Body   string
	Err    error
}

// fakeLunaRouteGateway is the ProviderTransport for root tests. It answers ONLY
// at https://gw.lunaroute.com, authenticates on Bearer only against
// validKey, lists models on GET /v1/models, and completes chat for listed
// models on POST /v1/chat/completions (echoing the model). Anything else 404s.
type fakeLunaRouteGateway struct {
	t        *testing.T
	mu       sync.Mutex
	validKey string
	models   []string
	replies  map[string]lunaRouteGatewayReply
	requests []lunaRouteGatewayRequest
}

func newFakeLunaRouteGateway(t *testing.T, validKey string, models ...string) *fakeLunaRouteGateway {
	return &fakeLunaRouteGateway{t: t, validKey: validKey, models: models, replies: map[string]lunaRouteGatewayReply{}}
}

// Reply scripts the answer for route ("GET /v1/models", "POST /v1/chat/completions").
func (g *fakeLunaRouteGateway) Reply(route string, r lunaRouteGatewayReply) {
	g.mu.Lock()
	defer g.mu.Unlock()
	g.replies[route] = r
}

// Requests returns a copy of every request seen so far.
func (g *fakeLunaRouteGateway) Requests() []lunaRouteGatewayRequest {
	g.mu.Lock()
	defer g.mu.Unlock()
	return slices.Clone(g.requests)
}

func gatewayResponse(r *http.Request, status int, body string) *http.Response {
	return &http.Response{StatusCode: status, Header: http.Header{"Content-Type": []string{"application/json"}},
		Body: io.NopCloser(strings.NewReader(body)), Request: r}
}

func (g *fakeLunaRouteGateway) RoundTrip(r *http.Request) (*http.Response, error) {
	var body []byte
	if r.Body != nil {
		body, _ = io.ReadAll(r.Body)
		_ = r.Body.Close()
	}
	route := r.Method + " " + r.URL.Path
	g.mu.Lock()
	g.requests = append(g.requests, lunaRouteGatewayRequest{Method: r.Method, URL: r.URL.String(),
		Authorization: r.Header.Get("Authorization"), APIKey: r.Header.Get("x-api-key"), Header: r.Header.Clone(), Body: body})
	override, scripted := g.replies[route]
	valid, models := g.validKey, slices.Clone(g.models)
	g.mu.Unlock()

	if r.URL.Scheme != "https" || r.URL.Host != "gw.lunaroute.com" {
		g.t.Errorf("credential-bearing request left the hosted gateway: %s", r.URL)
		return nil, fmt.Errorf("fake gateway: unexpected destination %q", r.URL.Host)
	}
	if r.Header.Get("Authorization") != "Bearer "+valid || r.Header.Get("x-api-key") != "" || r.Header.Get("LUNAROUTE-API-KEY") != "" {
		return gatewayResponse(r, 401, `{"error":{"message":"invalid api key"}}`), nil
	}
	if scripted {
		if override.Err != nil { return nil, override.Err }
		return gatewayResponse(r, override.Status, override.Body), nil
	}
	switch route {
	case "GET /v1/models":
		data := make([]map[string]string, 0, len(models))
		for _, m := range models {
			data = append(data, map[string]string{"id": m})
		}
		raw, _ := json.Marshal(map[string]any{"object": "list", "data": data})
		return gatewayResponse(r, 200, string(raw)), nil
	case "POST /v1/chat/completions":
		var req struct {
			Model string `json:"model"`
		}
		if json.Unmarshal(body, &req) != nil || !slices.Contains(models, req.Model) {
			return gatewayResponse(r, 404, `{"error":{"message":"model not found"}}`), nil
		}
		return gatewayResponse(r, 200, fmt.Sprintf(`{"model":%q,"choices":[{"message":{"role":"assistant","content":"pong"},"finish_reason":"stop"}],"usage":{"prompt_tokens":3,"completion_tokens":1}}`, req.Model)), nil
	default:
		return gatewayResponse(r, 404, `{"error":{"message":"no route"}}`), nil
	}
}

// bootLunaRouteRoot builds the REAL composition root (initDomainWithModelDependencies)
// with transport as the provider HTTP transport, mirroring bootSinkRootWithClose.
// extraCfg is appended YAML (e.g. "capabilitiespath: …\n" or an llm: block with
// binarypath); without a binarypath an always-failing claude stub is configured.
func bootLunaRouteRoot(t *testing.T, extraCfg string, transport http.RoundTripper, setup func(workspaceDir string)) *domainStack {
	t.Helper()
	pinSinkRootEnv(t)
	root := t.TempDir()
	workspaceDir := filepath.Join(root, "workspaces")
	require.NoError(t, os.MkdirAll(workspaceDir, 0o700))
	setup(workspaceDir)
	if !strings.Contains(extraCfg, "binarypath:") {
		bin := filepath.Join(root, "unconfigured-claude")
		require.NoError(t, os.WriteFile(bin, []byte("#!/bin/sh\nexit 1\n"), 0o700))
		if strings.Contains(extraCfg, "llm:\n") {
			extraCfg = strings.Replace(extraCfg, "llm:\n", "llm:\n  binarypath: "+bin+"\n", 1)
		} else {
			extraCfg += "llm:\n  binarypath: " + bin + "\n"
		}
	}
	cfg := "server:\n  host: \"127.0.0.1\"\n  port: 0\n" +
		"auth:\n  mode: \"local\"\n" +
		"database:\n  path: \"" + filepath.Join(root, "arbitron.db") + "\"\n" +
		"workspace:\n  path: \"" + workspaceDir + "\"\n" +
		"samples:\n  seed: false\n  sourcedir: \"\"\n" +
		"logging:\n  level: \"error\"\n  file: \"" + filepath.Join(root, "arbitron.log") + "\"\n" +
		"queue:\n  globalcap: 5\n  perusercap: 5\n" + extraCfg
	configPath := filepath.Join(root, "config.yaml")

	id, _ = trigger("lr-chat")
	assert.Contains(t, nodeError(t, ds, id), "LunaRoute service failure")
}
