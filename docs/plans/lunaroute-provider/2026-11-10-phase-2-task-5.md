# LunaRoute Phase 2 · Task 5 — Agent launch preflight + post-failure diagnosis wrapper (all agent backends)

**Goal:** Every agent provider the factory returns for a LunaRoute binding runs the phase-1 launch check before any subprocess, passes successful runs through untouched, and — after an opaque run failure — makes at most one bounded `/v1/models` probe on the same binding, reporting its result as a CURRENT observation that is explicitly not proof of the original cause, while preserving the original error's identity.

**Architecture:** New domain error type `provider.LunaRouteDiagnosis` (`domain/provider/lunaroute_diagnosis.go`). New `adapter/provider/lunaroute_agent.go`: unexported `lunaRouteAgent` + `wrapLunaRouteAgent(inner, b, probes, caps)`. `adapter/provider/factory.go:AgentProviderFor` is refactored: the existing backend switch moves verbatim into `(*Factory).agentProviderFor`, and `AgentProviderFor` guards the reveal and wraps the result when `provider.IsLunaRoute(b.Provider)`. `Deps` gains `Probes domprovider.ProbeSelector` (wired at the root in Task 6) and `Factory` gains the read-only accessor `ProbeSelector()`. Non-LunaRoute agent providers are returned exactly as today (same concrete types). Phases 3–4 rely on this auto-wrapping and never call `wrapLunaRouteAgent` themselves.

**Tech Stack:** Go 1.25, testify.

**Spec:** spec §Failure behavior ("Errors distinguish these conditions when known and identify uncertainty when the cause is unknown"; "Incompatible selections stop without silently substituting") · **Design:** phase-2 §3.5, §4 (Agent failure)

## Global Constraints
- Order in `RunAgent`: `CheckLunaRouteLaunch(caps, binding, 0)` → inner run → (failure only) diagnosis. A launch refusal returns directly: no probe, no inner call.
- Success: zero probe calls, result returned unchanged.
- No diagnosis when: the caller's context is done; the error is (or wraps) `context.Canceled`, `context.DeadlineExceeded`, `ErrLunaRouteStoredCredential`, `ErrLunaRouteEndpoint`, `ErrInvalidSelection`, `ErrSpecificVersionUnavailable`, `ErrSelectionPortsMissing`, factory `ErrUnknownProvider`/`ErrUnknownBackend`, `opencode.ErrUnknownProvider`, `pi.ErrUnknownProvider`; or it is already a `*provider.LunaRouteFailure`.
- At most ONE probe call per failed run, bounded by `lunaRouteDiagnosisTimeout = 20 * time.Second`.
- `errors.Is(diag, original)` stays true; a failing diagnosis never replaces the original; `LunaRouteDiagnosis.Error()` redacts `lr_` tokens from the original text and states the observation is current and not proof of the original cause.
- No retry, no substitution of model/backend/provider.
- Phase 2 enables no agent backend, so unit tests exercise the post-failure path with a chat-kind binding (the shared launch check has no backend gate for chat); Phase 3 Task 1/2 root tests exercise it with real enabled backends.

## Review Focus
- Probe returns a non-`LunaRouteFailure` error (e.g. the reveal guard) → treated as "could not check" (cause unknown), not as a gateway verdict.
- Listing succeeds but the model is missing → observation `ErrLunaRouteModelUnavailable` (now), original still matchable.
- Listing succeeds and the model is listed → `ErrLunaRouteCauseUnknown` with `ModelListed: true`.
- Cancelled context after a failure → no probe, original error returned unchanged (not wrapped).
- `probes == nil` (unwired) → diagnosis reports "could not check", never panics.

`domain/provider/lunaroute_diagnosis.go`:
```go
package provider

import "strings"

// LunaRouteDiagnosis wraps an opaque LunaRoute agent failure with the result
// of ONE gateway check made afterwards. The observation describes the gateway
// NOW; it is not proof of why the earlier run failed. Original keeps its
// identity for errors.Is/As.
type LunaRouteDiagnosis struct {
	Original    error
	Observation error // a *LunaRouteFailure or ErrLunaRouteModelUnavailable; nil when not checked or nothing found
	ModelListed bool  // the check succeeded and listed the selected model
	Checked     bool  // a gateway check completed (successfully or with a classified failure)
}

func (d *LunaRouteDiagnosis) Error() string {
	var b strings.Builder
	b.WriteString("lunaroute agent run failed: ")
	b.WriteString(RedactLunaRoute(d.Original.Error()))
	switch {
	case !d.Checked:
		b.WriteString("; the gateway could not be checked afterwards, so the cause is unknown")
	case d.Observation != nil:
		b.WriteString("; gateway check after the failure (a current observation, not proof of the original cause): ")
		b.WriteString(d.Observation.Error())
	case d.ModelListed:
		b.WriteString("; gateway check after the failure: the credential was accepted and the model is listed now, so the cause is unknown")
	default:
		b.WriteString("; the cause is unknown")
	}
	return b.String()
}

func (d *LunaRouteDiagnosis) Unwrap() []error {
	obs := d.Observation
	if obs == nil {
		obs = ErrLunaRouteCauseUnknown
	}
	return []error{d.Original, obs}
}
```

```go
package provider

import (
	"context"
	"errors"
	"slices"
	"time"

	"github.com/arbitron/arbitron/adapter/opencode"
	"github.com/arbitron/arbitron/adapter/pi"
	"github.com/arbitron/arbitron/domain/engine"
	domprovider "github.com/arbitron/arbitron/domain/provider"
)

// lunaRouteDiagnosisTimeout bounds the single post-failure gateway check.
const lunaRouteDiagnosisTimeout = 20 * time.Second

// lunaRouteAgent decorates any backend's AgentProvider for a LunaRoute
// binding: launch check first, pure pass-through on success, and one bounded
// gateway check after an opaque failure. It never retries or substitutes.
type lunaRouteAgent struct {
	inner   engine.AgentProvider
	binding domprovider.ResolvedBinding
	probes  domprovider.ProbeSelector
	caps    domprovider.LunaRouteCapabilities
}

var _ engine.AgentProvider = (*lunaRouteAgent)(nil)

func wrapLunaRouteAgent(inner engine.AgentProvider, b domprovider.ResolvedBinding, probes domprovider.ProbeSelector, caps domprovider.LunaRouteCapabilities) engine.AgentProvider {
	return &lunaRouteAgent{inner: inner, binding: b, probes: probes, caps: caps}
}

// lunaRouteLocalErrors are failures decided locally (validation, reveal,
// configuration) or by the caller; a gateway check cannot explain them.
var lunaRouteLocalErrors = []error{
	context.Canceled, context.DeadlineExceeded,
	domprovider.ErrLunaRouteStoredCredential, domprovider.ErrLunaRouteEndpoint,
	domprovider.ErrInvalidSelection, domprovider.ErrSpecificVersionUnavailable, domprovider.ErrSelectionPortsMissing,
	ErrUnknownProvider, ErrUnknownBackend, opencode.ErrUnknownProvider, pi.ErrUnknownProvider,
}

func lunaRouteDiagnosable(ctx context.Context, err error) bool {
	if ctx.Err() != nil {
		return false
	}
	for _, local := range lunaRouteLocalErrors {
		if errors.Is(err, local) {
			return false
		}
	}
	var classified *domprovider.LunaRouteFailure
	return !errors.As(err, &classified)
}

func (a *lunaRouteAgent) RunAgent(ctx context.Context, m engine.AgentMission) (*engine.AgentResult, error) {
	if err := domprovider.CheckLunaRouteLaunch(a.caps, a.binding, 0); err != nil {
		return nil, err
	}
	res, err := a.inner.RunAgent(ctx, m)
	if err == nil || !lunaRouteDiagnosable(ctx, err) {
		return res, err
	}
	return res, a.diagnose(ctx, err)
}

func (a *lunaRouteAgent) diagnose(ctx context.Context, original error) error {
	d := &domprovider.LunaRouteDiagnosis{Original: original}
	if a.probes == nil {
		return d
	}
	probe, err := a.probes.ProbeFor(a.binding)
	if err != nil {
		return d
	}
	pctx, cancel := context.WithTimeout(ctx, lunaRouteDiagnosisTimeout)
	defer cancel()
	res, err := probe.Probe(pctx, a.binding)
	var failure *domprovider.LunaRouteFailure
	switch {
	case err != nil && errors.As(err, &failure):
		d.Checked, d.Observation = true, failure
	case err != nil:
		// A local refusal inside the probe (guard, endpoint) is not a gateway
		// observation: the gateway could not be checked.
	case slices.Contains(res.Models, a.binding.Model):
		d.Checked, d.ModelListed = true, true
	default:
		d.Checked, d.Observation = true, domprovider.ErrLunaRouteModelUnavailable
	}
	return d
}
```

```go
// AgentProviderFor returns the agent provider for b (see agentProviderFor for
// the backend dispatch). LunaRoute bindings are additionally reveal-guarded
// and wrapped with the launch check + post-failure diagnosis, whatever their
// backend; every other binding is returned exactly as agentProviderFor builds it.
func (f *Factory) AgentProviderFor(b domprovider.ResolvedBinding) (engine.AgentProvider, error) {
	lunaroute := domprovider.IsLunaRoute(b.Provider)
	if lunaroute {
		b = domprovider.GuardLunaRouteReveal(b)
	}
	inner, err := f.agentProviderFor(b)
	if err != nil || !lunaroute {
		return inner, err
	}
	return wrapLunaRouteAgent(inner, b, f.deps.Probes, f.deps.CapabilityRules), nil
}
```
