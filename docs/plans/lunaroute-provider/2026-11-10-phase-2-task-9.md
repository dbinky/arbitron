## Global constraints

- The production connection still uses the canonical hosted root. Never weaken endpoint validation, disable TLS validation or install a CA in the user's trust store.
- Capture is opt-in test infrastructure. A temporary local CA, proxy and wrappers exist only for the experiment, with owner-only files and bounded lifetimes; remove all on success/error/cancel. Upstream HTTPS verifies the real LunaRoute certificate with the normal trust roots and never follows redirects.
- Secrets are compared in memory only. Persist `auth_matches_selected: true|false`, header names and a synthetic connection handle; no raw/hashed key, auth/header value, prompt, message, tool argument/result or stderr.
- A capture outage, untrusted CA, bypassed proxy, malformed/truncated stream, missing response-model field, or absent required helper trace is a failed observation. No fabricated/default model evidence. Backend tasks keep the register pending/escalated according to their decisions when runtime observation cannot be obtained.

## Files and interfaces

Create `test/lunaroute/capture_test.go`, `capture_proxy_test.go`, `capture_validator_test.go` (package `lunaroute_test`); extend the evidence README. No production file changes.

```go
type capturedInference struct {
    RunID, Backend, Connection, Category string // category is correlated to a forced helper lifecycle
    Method, Host, Path, RequestedModel string
    ReportedModels []string
    AuthMatchesSelected bool
    AuthHeaderNames []string
    Completed bool
}
type inferenceCapture struct { /* private in-memory credentials, CA and servers */ }
func startInferenceCapture(t *testing.T, runID, backend, connection, key string) *inferenceCapture
func (c *inferenceCapture) WrapBinary(t *testing.T, realBinary string) string
func (c *inferenceCapture) Records() []capturedInference
func (c *inferenceCapture) Close() error
func validateCapturedInference(records []capturedInference, selectedModel string, requiredCategories []string) error
```

`startInferenceCapture` starts a bounded loopback CONNECT proxy. It terminates TLS using an ephemeral certificate for `gw.lunaroute.com`, forwards only to `https://gw.lunaroute.com` through a separate no-proxy, no-redirect client, and records sanitized schema fields as it streams responses to the real binary. Reject other CONNECT hosts/destinations and unexpected credential headers. Decode selected `model` fields from JSON/SSE by dialect, including Responses `response.model`; never serialize an entire decoded object. Enforce body/record caps and scanner/read errors. A missing model stays missing. For a reviewed alias, validate response models with P1-T7 `LunaRouteExecutedModelAccepted`; a fixed id requires exact spelling.

`WrapBinary` creates a test-only launcher for the installed real executable, preserving argv, stdin, cwd and the production adapter's env. It adds only this capture's proxy and ephemeral CA settings (`HTTPS_PROXY`/`https_proxy`, `SSL_CERT_FILE`, and `NODE_EXTRA_CA_CERTS` where the runtime needs them); clear conflicting NO_PROXY settings in the wrapper. Those are test wrapper inputs, never additions to `procenv.BaseEnv` or production credential envs. Test the actual installed CLI's proxy/trust behavior before accepting its observations. If it bypasses the capture, fail that backend's evidence experiment; never use an insecure TLS flag to get a pass.

For root acceptance P4-T7, expose wrappers under the backend executable names on an isolated PATH (and supply the Claude wrapper via the real binarypath config). The server still constructs real production adapters; the launcher observes their exact emitted env/config/cwd. For direct P3-T5/P4-T1 experiments, `runCaptured` invokes the same wrapper around the real binary. Capture starts before the launch and `Records()` is read only after terminal completion and all requests have drained.
