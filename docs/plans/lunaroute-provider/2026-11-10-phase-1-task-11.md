# LunaRoute Phase 1 · Task 11 — Evidence register, live LR-01 gateway check, and the release-readiness gate

**Goal:** Make every unresolved external dependency (LR-01…LR-08) a tracked, checkable artifact instead of prose: a machine-readable evidence register, a credential-gated live test that verifies the hosted endpoint / dialect paths / auth headers (LR-01) and records the `/v1/models` envelope, and a gated release-readiness test that fails while any item is unresolved.

**Architecture:** `docs/evidence/lunaroute-provider/README.md` (human procedure) + `docs/evidence/lunaroute-provider/register.yaml` (status per LR item, evidence refs, escalation text). New test package `test/lunaroute/` holds (a) `register_test.go` — always-on schema check of the register, and a release gate enabled by `ARBITRON_LUNAROUTE_RELEASE_GATE=1`; (b) `gateway_live_test.go` — skipped unless `ARBITRON_LUNAROUTE_E2E_KEY` is set; it calls the real gateway with `net/http` (no Arbitron adapter) and writes a credential-free observation file under `docs/evidence/lunaroute-provider/observations/`. Phases 2–4 append their own live tasks to the same register (LR-04 in Phase 2 Task 8, LR-05/LR-06 in Phase 3 Task 5, LR-07/LR-08 in Phase 4 Tasks 1 and 5).

**Tech Stack:** Go 1.25 `net/http`, `go.yaml.in/yaml/v3`, testify.

**Spec:** spec §Outcomes ("Successful launches alone do not satisfy readiness; the tasks must finish successfully") · **Design:** phase-1 §5 (LR-01…LR-03), §8 Tier 2; phase-4 §9

## Global Constraints
- A mock/unit pass never flips a register item to `verified`; only recorded live/authoritative evidence does (the evidence ref must point at an observations file or an authoritative-source note).
- Observation files are credential-free: the test asserts the key string is absent before writing.
- Missing `ARBITRON_LUNAROUTE_E2E_KEY` → live tests `t.Skip` with a message saying release acceptance remains pending. The release gate is a separate opt-in and fails while anything is unresolved.

## ESCALATIONS (carried in the register; a human with LunaRoute access must close them)
- **ESCALATION LR-01:** the hosted root `https://gw.lunaroute.com`, dialect paths (`/v1/messages`, `/v1/chat/completions`, `/v1/responses`, `/v1/models`) and accepted auth headers (`Authorization: Bearer`, `x-api-key`) are idea-doc candidates. Run `gateway_live_test.go` with a real key.
- **ESCALATION LR-02:** authoritative per-model context/output limits, effort support, and per-model/task/backend completion observations do not exist in the repo. Needed before any claude-code LunaRoute profile can save (Phase 1 Task 9 rule 7) and before acceptance. Source: LunaRoute model docs or vendor docs + the Phase 2–4 live tasks. Values go into the operator capabilities override (or `capabilities.default.yaml` via PR) with evidence refs.
- **ESCALATION LR-03:** verified LunaRoute executable spellings, `-lrN` alias vendor + immutability, opaque-alias vendor mappings. If LunaRoute cannot supply a fixed alias target, escalate the pinning constraint to the product owner — do NOT drop aliases from release readiness and do NOT treat a numeric alias as proof.
- **ESCALATION LR-04…LR-08:** see Phase 2 Task 8, Phase 3 Task 5, Phase 4 Tasks 1 and 5.

## Review Focus
- An observation file accidentally containing the key (the test must refuse to write it).
- Register with an unknown status value (`done`, `ok`) must fail the schema test.
- A `verified` item with an empty evidence list must fail the schema test.
- Live test must not follow redirects with the credential.

```go
// Package lunaroute_test holds the LunaRoute evidence register checks and the
// credential-gated live gateway tests (Tier 2).
package lunaroute_test

import (
	"encoding/json"
	"os"
	"path/filepath"
	"runtime"
	"sort"
	"strings"
	"testing"

	"github.com/stretchr/testify/require"
	"go.yaml.in/yaml/v3"
)

type registerItem struct {
	Title      string   `yaml:"title"`
	Status     string   `yaml:"status"`
	Evidence   []string `yaml:"evidence"`
	Escalation string   `yaml:"escalation"`
}

type register struct {
	Items map[string]registerItem `yaml:"items"`
}

func repoRoot(t *testing.T) string {
	t.Helper()
	_, file, _, ok := runtime.Caller(0)
	require.True(t, ok)
	return filepath.Join(filepath.Dir(file), "..", "..")
}

func evidenceDir(t *testing.T) string {
	return filepath.Join(repoRoot(t), "docs", "evidence", "lunaroute-provider")
}

func loadRegister(t *testing.T) register {
	t.Helper()
	raw, err := os.ReadFile(filepath.Join(evidenceDir(t), "register.yaml"))
	require.NoError(t, err)
	var r register
	require.NoError(t, yaml.Unmarshal(raw, &r))
	return r
}

func validateRegister(r register) []string {
	var problems []string
	for _, id := range []string{"LR-01", "LR-02", "LR-03", "LR-04", "LR-05", "LR-06", "LR-07", "LR-08"} {
		if _, ok := r.Items[id]; !ok {
			problems = append(problems, id+": missing")
		}
	}
	for id, it := range r.Items {
		switch it.Status {
		case "verified":
			if len(it.Evidence) == 0 {
				problems = append(problems, id+": verified without evidence")
			}
		case "unresolved", "escalated":
			if strings.TrimSpace(it.Escalation) == "" {
				problems = append(problems, id+": "+it.Status+" without escalation text")
			}
		default:
			problems = append(problems, id+": unknown status "+it.Status)
		}
	}
	sort.Strings(problems)
	return problems
}

func TestRegisterSchema(t *testing.T) {
	require.Empty(t, validateRegister(loadRegister(t)))
}

func TestRegisterSchema_DetectsProblems(t *testing.T) {
	bad := register{Items: map[string]registerItem{
		"LR-01": {Status: "verified"},
		"LR-02": {Status: "done", Escalation: "x"},
		"LR-03": {Status: "unresolved"},
	}}
	got := validateRegister(bad)
	require.Contains(t, got, "LR-01: verified without evidence")
	require.Contains(t, got, "LR-02: unknown status done")
	require.Contains(t, got, "LR-03: unresolved without escalation text")
	require.Contains(t, got, "LR-08: missing")
}

// TestReleaseGate is opt-in: it fails while any LR item is not verified.
func TestReleaseGate(t *testing.T) {
	if os.Getenv("ARBITRON_LUNAROUTE_RELEASE_GATE") != "1" {
		t.Skip("set ARBITRON_LUNAROUTE_RELEASE_GATE=1 to enforce release readiness")
	}
	var open []string
	for id, it := range loadRegister(t).Items {
		if it.Status != "verified" {
			open = append(open, id+" ("+it.Status+"): "+it.Escalation)
		}
	}
	sort.Strings(open)
	require.Empty(t, open, "LunaRoute release blocked by unresolved evidence")
}

// liveKey returns the live LunaRoute key or skips the test.
func liveKey(t *testing.T) string {
	t.Helper()
	k := os.Getenv("ARBITRON_LUNAROUTE_E2E_KEY")
	if k == "" {
		t.Skip("ARBITRON_LUNAROUTE_E2E_KEY unset: live LunaRoute evidence not collected; release acceptance remains pending")
	}
	return k
}

// writeObservation writes a credential-free JSON observation for the register.
func writeObservation(t *testing.T, key, name string, v any) string {
	t.Helper()
	raw, err := json.MarshalIndent(v, "", "  ")
	require.NoError(t, err)
	require.NotContains(t, string(raw), key, "observation would leak the credential")
	require.NotContains(t, string(raw), "lr_", "observation must not contain lr_ tokens")
	p := filepath.Join(evidenceDir(t), "observations", name)
	require.NoError(t, os.WriteFile(p, raw, 0o600))
	return p
}
```

```go
package lunaroute_test

import (
	"bytes"
	"encoding/json"
	"io"
	"net/http"
	"testing"
	"time"

	"github.com/stretchr/testify/require"
)

const hostedRoot = "https://gw.lunaroute.com"

// liveClient never follows redirects with the credential.
func liveClient() *http.Client {
	return &http.Client{Timeout: 60 * time.Second, CheckRedirect: func(*http.Request, []*http.Request) error { return http.ErrUseLastResponse }}
}

type httpObservation struct {
	Method      string            `json:"method"`
	Path        string            `json:"path"`
	AuthHeader  string            `json:"auth_header"`
	Status      int               `json:"status"`
	ContentType string            `json:"content_type"`
	BodyShape   map[string]string `json:"body_shape"`
}

// shape records top-level JSON keys and their JSON types only (no values).
func shape(body []byte) map[string]string {
	var m map[string]any
	if json.Unmarshal(body, &m) != nil {
		return map[string]string{"_": "non-object"}
	}
	out := map[string]string{}
	for k, v := range m {
		switch v.(type) {
		case []any:
			out[k] = "array"
		case map[string]any:
			out[k] = "object"
		case string:
			out[k] = "string"
		case float64:
			out[k] = "number"
		default:
			out[k] = "other"
		}
	}
	return out
}

func do(t *testing.T, key, method, path, authHeader string, body []byte) (httpObservation, []byte) {
	t.Helper()
	req, err := http.NewRequest(method, hostedRoot+path, bytes.NewReader(body))
	require.NoError(t, err)
	switch authHeader {
	case "bearer":
		req.Header.Set("Authorization", "Bearer "+key)
	case "x-api-key":
		req.Header.Set("x-api-key", key)
	}
	if body != nil {
		req.Header.Set("Content-Type", "application/json")
		req.Header.Set("anthropic-version", "2023-06-01")
	}
	resp, err := liveClient().Do(req)
	require.NoError(t, err)
	defer resp.Body.Close()
	raw, _ := io.ReadAll(io.LimitReader(resp.Body, 1<<20))
	return httpObservation{Method: method, Path: path, AuthHeader: authHeader, Status: resp.StatusCode, ContentType: resp.Header.Get("Content-Type"), BodyShape: shape(raw)}, raw
}

// TestLiveGatewayContract (LR-01, and the LR-04 envelope): lists models with
// both auth headers, confirms the bad-key status, and records the ids so LR-03
// grammar coverage can be reviewed.
func TestLiveGatewayContract(t *testing.T) {
	key := liveKey(t)
	var obs []httpObservation
	o, raw := do(t, key, http.MethodGet, "/v1/models", "bearer", nil)
	obs = append(obs, o)
	require.Equal(t, 200, o.Status, "LR-01: Bearer auth on /v1/models")
	var list struct {
		Data []struct {
			ID string `json:"id"`
		} `json:"data"`
	}
	require.NoError(t, json.Unmarshal(raw, &list), "LR-04: OpenAI-style data[].id envelope")
	ids := make([]string, 0, len(list.Data))
	for _, m := range list.Data {
		ids = append(ids, m.ID)
	}
	o, _ = do(t, key, http.MethodGet, "/v1/models", "x-api-key", nil)
	obs = append(obs, o)
	o, _ = do(t, "lr_invalid_for_arbitron_evidence", http.MethodGet, "/v1/models", "bearer", nil)
	obs = append(obs, o)
	o, _ = do(t, key, http.MethodGet, "/models", "bearer", nil)
	obs = append(obs, o)
	writeObservation(t, key, "lr01-gateway-contract.json", map[string]any{
		"recorded_at": time.Now().UTC().Format(time.RFC3339),
		"root":        hostedRoot,
		"requests":    obs,
		"model_ids":   ids,
	})
}
```
Note: the invalid key contains `lr_`; `writeObservation` refuses any `lr_` token, and only shapes/status (never the key) are recorded, so the file stays clean.
