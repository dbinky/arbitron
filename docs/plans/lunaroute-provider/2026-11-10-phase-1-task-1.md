# LunaRoute Phase 1 · Task 1 — Canonical id and hosted-endpoint helper

**Dependencies:** None; endpoint constants remain gated by LR-01.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Add the `lunaroute` canonical provider id and the single domain helper that normalizes a LunaRoute base URL to the hosted root and derives each dialect's URL.

**Architecture:** `domain/provider/canonical.go` gains `CanonicalLunaRoute`. A new `domain/provider/lunaroute_endpoint.go` owns the hosted root (`https://gw.lunaroute.com`), `IsLunaRoute`, `NormalizeLunaRouteBaseURL`, `LunaRouteMessagesBaseURL` (root, Anthropic Messages — the client appends `/v1/messages`) and `LunaRouteOpenAIBaseURL` (`root + "/v1"`, chat completions / Responses / models). Every credential sink in phases 1–4 calls these before using a key.

**Tech Stack:** Go 1.25, `net/url`, testify.

**Spec:** `docs/specs/2026-11-10-lunaroute-provider-spec.md` · **Design:** `docs/designs/2026-11-10-lunaroute-provider-design-phase-1.md` §3.1–3.2

## Global Constraints
- Hosted service only: the only accepted destination is `https://gw.lunaroute.com` (scheme https, no port, no userinfo, no query/fragment, path only `""`, `/`, `/v1`, `/v1/`).
- `lunaroute` has no aliases.
- Error text never echoes the submitted URL (it may contain userinfo).
- **UNRESOLVED DEPENDENCY LR-01** (hosted address, dialect paths, auth headers) stays open: the root is the idea-doc candidate. Closing it is Phase 1 Task 11 (evidence register + live check). Do not remove this marker on a unit-test pass.

## Review Focus
- Mixed-case host (`https://GW.LunaRoute.com/v1`) must normalize, not reject.
- `https://gw.lunaroute.com:443` must reject (explicit port), even though it is the same socket.
- Percent-encoded path (`/v%31`) must reject (RawPath set).
- Trailing-dot host `gw.lunaroute.com.` must reject.
- `http://` must reject even for the right host.

```go
package provider

import (
	"errors"
	"net/url"
	"strings"
)

// LunaRouteHostedRoot is the only LunaRoute destination this release accepts.
// UNRESOLVED DEPENDENCY LR-01: the value is the idea-doc candidate; the
// evidence register (docs/evidence/lunaroute-provider/README.md) records its
// verification status.
const LunaRouteHostedRoot = "https://gw.lunaroute.com"

const lunaRouteHost = "gw.lunaroute.com"

// ErrLunaRouteEndpoint rejects any LunaRoute base URL that does not normalize
// to the hosted root. The message never echoes the submitted URL.
var ErrLunaRouteEndpoint = errors.New("provider: LunaRoute connections must use the hosted endpoint https://gw.lunaroute.com (leave base_url empty or set it to that root)")

// IsLunaRoute reports whether a provider string canonicalizes to lunaroute.
func IsLunaRoute(p string) bool { return Canonicalize(p) == CanonicalLunaRoute }

// NormalizeLunaRouteBaseURL maps every accepted spelling of the hosted root
// (empty, trailing slash, trailing /v1, mixed-case host or scheme) to
// LunaRouteHostedRoot. Any other scheme, host, port, userinfo, query,
// fragment, escaped path or path is ErrLunaRouteEndpoint.
func NormalizeLunaRouteBaseURL(raw string) (string, error) {
	s := strings.TrimSpace(raw)
	if s == "" {
		return LunaRouteHostedRoot, nil
	}
	if strings.ContainsAny(s, "#?") {
		return "", ErrLunaRouteEndpoint
	}
	u, err := url.Parse(s)
	if err != nil {
		return "", ErrLunaRouteEndpoint
	}
	if !strings.EqualFold(u.Scheme, "https") || u.Opaque != "" || u.User != nil ||
		u.RawPath != "" || u.Port() != "" || !strings.EqualFold(u.Host, lunaRouteHost) {
		return "", ErrLunaRouteEndpoint
	}
	switch u.Path {
	case "", "/", "/v1", "/v1/":
		return LunaRouteHostedRoot, nil
	default:
		return "", ErrLunaRouteEndpoint
	}
}

// LunaRouteMessagesBaseURL is the Anthropic Messages base: the hosted root.
// Claude Code appends /v1/messages itself.
func LunaRouteMessagesBaseURL(raw string) (string, error) {
	return NormalizeLunaRouteBaseURL(raw)
}

// LunaRouteOpenAIBaseURL is the OpenAI-dialect base (chat completions,
// Responses and /models): the hosted root plus exactly one /v1.
func LunaRouteOpenAIBaseURL(raw string) (string, error) {
	root, err := NormalizeLunaRouteBaseURL(raw)
	if err != nil {
		return "", err
	}
	return root + "/v1", nil
}
```
