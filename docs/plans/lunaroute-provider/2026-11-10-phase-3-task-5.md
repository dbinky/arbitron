# LunaRoute Phase 3 · Task 5 — Tier-2 live evidence: tool-using agent task on claude-code and opencode (LR-05, LR-06)

**Goal:** With a real `lr_` key and the installed `claude` / `opencode` binaries, run a representative tool-using agent mission (create a file, run a command, verify the workspace) through the PRODUCTION factory adapters on each backend, and record credential-free evidence (binary version, model, executed-model proof, tool steps, effective-config shape) for the evidence register — without flipping any register status automatically.

**Architecture:** New `test/lunaroute/agent_live_test.go` (package `lunaroute_test`, reuses Phase 1 Task 11 helpers `liveKey`, `writeObservation`, `repoRoot`). It builds the real `adapter/provider.Factory` with real `claudecli`/`opencode` runners, the operator's capability file (`ARBITRON_LUNAROUTE_E2E_CAPABILITIES`), and a real `probe.ProbeFactory` (Phase 2 wrapper input), then calls `AgentProviderFor(binding).RunAgent` with a guarded, pinned LunaRoute binding. Skips (with an explicit "release acceptance pending" message) when the key, the binary, or — for claude-code — the evidence-backed limits are missing. The evidence README gains the LR-05/LR-06 procedure, including the manual supporting-call check this test cannot perform.

**Tech Stack:** Go 1.25, real subprocesses, `net/http`, testify.

**Spec:** spec §Outcomes ("Complete a representative tool-using agent task through each of Claude Code … OpenCode, using a compatible LunaRoute model for each"; "Successful launches alone do not satisfy readiness") · **Design:** phase-3 §8 Tier 2; phase-4 §9

## Global Constraints
- Gated: `ARBITRON_LUNAROUTE_E2E_KEY` (key), optional `ARBITRON_LUNAROUTE_E2E_MODEL_CLAUDE_CODE` / `ARBITRON_LUNAROUTE_E2E_MODEL_OPENCODE` (default `glm-5.3`), `ARBITRON_LUNAROUTE_E2E_CAPABILITIES` (operator capabilities file with evidence-backed `lunaroute_models`). Missing inputs → `t.Skip`, never a pass.
- Success means the mission FINISHED: file exists with the exact content, the command output appears in the summary, the executed-model proof matched (binding `Pinned: true`), at least one tool step recorded.
- Observations contain no key and no `lr_` token (`writeObservation` enforces).
- Register status changes are a human step (README procedure); a passing run alone does not close LR-05/LR-06 — supporting-call routing needs the gateway-side check.
- **ESCALATION LR-05:** confirm that the installed Claude Code sends main AND helper calls (titles, summaries, compaction, subagents) to `https://gw.lunaroute.com` with the selected model only, and that the env names in `adapter/claudecli/lunaroute_env.go` are honoured; record version + gateway usage evidence.
- **ESCALATION LR-06:** confirm opencode's acceptance of `-m lunaroute/<id>`, whether `provider.lunaroute.models` registration is required, whether `small_model` routes helper calls, and whether ambient providers in user config can be selected; record version + `opencode debug config` output shape (if the subcommand exists).
- **ESCALATION LR-02:** claude-code live runs need evidence-backed limits in the capabilities file; the test skips claude-code otherwise.
- MCP-driven end-to-end acceptance (connection → `connection_models` → profile → workflow run) is the manual procedure in `docs/evidence/lunaroute-provider/README.md` (Phase 4 Task 5 owns the full matrix); this test covers the adapter path only and says so in its observation.

## Review Focus
- A run that "succeeds" (exit 0) without creating the file must fail the test.
- Pinned binding: a silent model fallback must fail via executed-model evidence.
- `opencode debug config` output could echo env-referenced values — the observation records only top-level key names and the `provider.lunaroute` block shape.
- The workspace path must be under the configured `WorkspaceRoot` (claude adapter pins it).

package lunaroute_test

import (
	"context"
	"encoding/json"
	"net/http"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
	"testing"
	"time"

	"github.com/arbitron/arbitron/adapter/claudecli"
	configadapter "github.com/arbitron/arbitron/adapter/config"
	"github.com/arbitron/arbitron/adapter/probe"
	providersadapter "github.com/arbitron/arbitron/adapter/provider"
	"github.com/arbitron/arbitron/domain/engine"
	"github.com/arbitron/arbitron/domain/provider"
	"github.com/stretchr/testify/assert"
	"github.com/stretchr/testify/require"
)

const proofFile = "lunaroute-proof.txt"
const proofText = "LUNAROUTE-OK"

func liveBinary(t *testing.T, name string) string {
	t.Helper()
	p, err := exec.LookPath(name)
	if err != nil {
		t.Skipf("%s not installed: live %s evidence not collected; release acceptance remains pending", name, name)
	}
	return p
}

func liveModel(envVar string) string {
	if m := os.Getenv(envVar); m != "" {
		return m
	}
	return "glm-5.3"
}

func liveRules(t *testing.T) provider.CapabilityRules {
	t.Helper()
	rules, err := configadapter.LoadCapabilityRules(os.Getenv("ARBITRON_LUNAROUTE_E2E_CAPABILITIES"))
	require.NoError(t, err)
	return rules
}

func versionOf(t *testing.T, bin string) string {
	t.Helper()
	out, err := exec.Command(bin, "--version").CombinedOutput()
	require.NoError(t, err)
	return strings.TrimSpace(string(out))
}

func liveFactory(ws, claudeBin string, rules provider.CapabilityRules) *providersadapter.Factory {
	runner := claudecli.NewExecRunner()
	return providersadapter.NewFactory(providersadapter.Deps{
		ClaudeAgentConfig: claudecli.Config{
			BinaryPath: claudeBin, Runner: runner, WorkspaceRoot: ws, Timeout: 15 * time.Minute,
			SkipPermissions: true, AllowedTools: []string{"Read", "Write", "Bash"}, CapabilityRules: rules,
		},
		Runner:          runner,
		OpencodeTimeout: 15 * time.Minute,
		CapabilityRules: rules,
		Probes:          probe.NewProbeFactory(probe.Deps{HTTPClient: &http.Client{Timeout: 30 * time.Second}, Timeout: 30 * time.Second}),
	})
}

func liveBinding(key, model, backend string) provider.ResolvedBinding {
	return provider.GuardLunaRouteReveal(provider.ResolvedBinding{
		Kind: provider.ProfileKindAgent, Provider: "lunaroute", BaseURL: "https://gw.lunaroute.com",
		Model: model, Backend: backend, AllowedTools: []string{"Read", "Write", "Bash"}, Pinned: true,
		RevealKey: func(context.Context) (string, error) { return key, nil },
	})
}

const livePrompt = "In the current directory create a file named " + proofFile + " containing exactly the text " + proofText +
	" (no newline required). Then run the shell command `cat " + proofFile + "` and reply with its output."

// runLiveMission runs the representative tool task and verifies the WORKSPACE
// result, not just the exit status.
func runLiveMission(t *testing.T, f *providersadapter.Factory, b provider.ResolvedBinding, ws string) (*engine.AgentResult, string) {
	t.Helper()
	work := filepath.Join(ws, "mission")
	require.NoError(t, os.MkdirAll(work, 0o700))
	agent, err := f.AgentProviderFor(b)
	require.NoError(t, err)
	res, err := agent.RunAgent(context.Background(), engine.AgentMission{Prompt: livePrompt, WorkDir: work, Model: b.Model, ToolScope: b.AllowedTools})
	require.NoError(t, err, "the mission must FINISH, not just launch")
	got, err := os.ReadFile(filepath.Join(work, proofFile))
	require.NoError(t, err, "the agent must have created the file through a tool call")
	assert.Equal(t, proofText, strings.TrimSpace(string(got)))
	assert.Contains(t, res.Summary, proofText, "the command output reached the reply")
	return res, work
}

func stepKinds(res *engine.AgentResult) []string {
	kinds := make([]string, 0, len(res.Steps))
	for _, s := range res.Steps {
		kinds = append(kinds, s.Kind)
	}
	return kinds
}

func TestLiveClaudeCodeAgentTask(t *testing.T) {
	key := liveKey(t)
	bin := liveBinary(t, "claude")
	model := liveModel("ARBITRON_LUNAROUTE_E2E_MODEL_CLAUDE_CODE")
	rules := liveRules(t)
	m, _ := rules.LunaRouteModel(model)
	if !m.ContextTokens.Known() || !m.OutputTokens.Known() {
		t.Skipf("LR-02: no evidence-backed limits for %q in ARBITRON_LUNAROUTE_E2E_CAPABILITIES; claude-code acceptance remains pending", model)
	}
	ws := t.TempDir()
	res, _ := runLiveMission(t, liveFactory(ws, bin, rules), liveBinding(key, model, "claude-code"), ws)
	writeObservation(t, key, "lr05-claude-code-agent.json", map[string]any{
		"recorded_at":         time.Now().UTC().Format(time.RFC3339),
		"scope":               "adapter path via production Factory; MCP end-to-end is the README procedure",
		"claude_version":      versionOf(t, bin),
		"model":               model,
		"executed_model_proof": "pinned binding: modelUsage matched",
		"tool_steps":          stepKinds(res),
		"env_names_emitted": []string{"ANTHROPIC_BASE_URL", "ANTHROPIC_API_KEY", "ANTHROPIC_MODEL", "ANTHROPIC_DEFAULT_HAIKU_MODEL",
			"ANTHROPIC_SMALL_FAST_MODEL", "ANTHROPIC_DEFAULT_SONNET_MODEL", "ANTHROPIC_DEFAULT_OPUS_MODEL", "CLAUDE_CODE_SUBAGENT_MODEL",
			"CLAUDE_CODE_GATEWAY_HINT_HEADERS", "CLAUDE_CODE_MAX_CONTEXT_TOKENS", "CLAUDE_CODE_MAX_OUTPUT_TOKENS"},
		"supporting_calls": "NOT VERIFIED BY THIS TEST: check gateway usage for the run window (README LR-05 procedure)",
	})
}

func TestLiveOpencodeAgentTask(t *testing.T) {
	key := liveKey(t)
	bin := liveBinary(t, "opencode")
	model := liveModel("ARBITRON_LUNAROUTE_E2E_MODEL_OPENCODE")
	ws := t.TempDir()
	res, work := runLiveMission(t, liveFactory(ws, "claude", liveRules(t)), liveBinding(key, model, "opencode"), ws)

	// Effective-config shape, if this opencode version exposes it. Only key
	// names and the lunaroute block's shape are recorded.
	cfgShape := map[string]any{"available": false}
	cmd := exec.Command(bin, "debug", "config")
	cmd.Dir = work
	cmd.Env = append(os.Environ(), "OPENCODE_CONFIG_CONTENT="+`{"$schema":"https://opencode.ai/config.json","provider":{"lunaroute":{"npm":"@ai-sdk/openai-compatible","options":{"apiKey":"{env:LUNAROUTE_API_KEY}","baseURL":"https://gw.lunaroute.com/v1"},"models":{"`+model+`":{}}}},"small_model":"lunaroute/`+model+`"}`)
	if out, err := cmd.Output(); err == nil {
		var doc map[string]any
		if json.Unmarshal(out, &doc) == nil {
			keys := make([]string, 0, len(doc))
			for k := range doc {
				keys = append(keys, k)
			}
			cfgShape = map[string]any{"available": true, "top_level_keys": keys, "small_model_effective": doc["small_model"]}
		}
	}
	writeObservation(t, key, "lr06-opencode-agent.json", map[string]any{
		"recorded_at":          time.Now().UTC().Format(time.RFC3339),
		"scope":                "adapter path via production Factory; MCP end-to-end is the README procedure",
		"opencode_version":     versionOf(t, bin),
		"model_argv":           "-m lunaroute/" + model,
		"executed_model_proof": "pinned binding: export providerID/modelID matched",
		"tool_steps":           stepKinds(res),
		"effective_config":     cfgShape,
		"supporting_calls":     "NOT VERIFIED BY THIS TEST: check gateway usage for the run window (README LR-06 procedure)",
	})
}
