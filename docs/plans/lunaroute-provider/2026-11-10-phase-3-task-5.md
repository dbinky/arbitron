## Global constraints

Emitting a key the binary ignores is a defect: remove it (On-failure rule). An unroutable helper stops that backend's enablement and sets the item to `escalated`.

- Missing key/binary/required facts skips local experiments with a readiness-pending message. Release mode (`ARBITRON_LUNAROUTE_RELEASE_GATE=1`) fails missing prerequisites; no empty observation is success.
