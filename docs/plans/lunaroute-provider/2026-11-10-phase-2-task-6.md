# LunaRoute Phase 2 · Task 6 — Serve-path wiring: one ProbeFactory, model discovery service, `connection_models` MCP tool

**Dependencies:** P2-T2/P2-T4/P2-T5.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** Construct one `ProbeFactory` in the serve composition root and inject it into (a) the model discovery service and (b) the provider factory (agent diagnosis wrapper); expose discovery to the LLM as the MCP tool `connection_models` with actionable, credential-free error text; prove the whole chain through the production MCP server built from `ds.mcpDeps()` with the fake gateway as the sink.

**Architecture:** `cmd/arbitron/main.go:initDomainWithModelDependencies` builds `probeFactory := adaptprobe.NewProbeFactory(adaptprobe.Deps{HTTPClient: httpClient, …})` right after the shared outbound `httpClient` (so `ModelDependencies.ProviderTransport` reaches it), sets `providersadapter.Deps.Probes: probeFactory`, builds `modelDiscovery := provider.NewModelDiscoveryService(connStore, probeFactory, capabilityRules)`, and stores `probeFactory`, `providerFactory`, `modelDiscovery` on `domainStack`. `mcpDeps()` sets the new `adaptmcp.Deps.ModelDiscovery`. New `adapter/mcp/tools_connection_models.go` registers `connection_models` from `RegisterConnectionTools` and maps errors (forbidden, unauthenticated, not found, classified gateway failures, guard sentinels, wiring fault, unknown).

**Tech Stack:** Go 1.25, mcp-go v0.53.0, testify.

**Spec:** spec §Model discovery ("An LLM operating through MCP can inspect models available through a selected LunaRoute connection"), §Outcomes · **Design:** phase-2 §3.3, §5 Deferred "Composition-root wiring (serve path)", "Error mapping tables"

## Global Constraints
- Exactly ONE serve-path `ProbeFactory`; the CLI `connection validate` keeps its own (`cmd/arbitron/connection.go:buildValidateDeps`).
- Tool result never contains key material (asserted on the raw tool text).
- Tool description: unknown fields are not guarantees; availability ≠ compatibility; choose model AND backend explicitly; LunaRoute agent profiles name their backend and are pinned-only; family is the actual vendor (doer/judge); nothing is recommended or auto-selected.
- Error texts are static or come from `LunaRouteFailure.Error()` (already redacted); the default branch never echoes the raw error.
- **LR-02/LR-03 decided** (`docs/designs/2026-11-10-lunaroute-provider-decisions.md`): the root test uses a distinctive override capabilities file, so it proves the feed and not the shipped values. The shipped default carries the release set's doc-sourced facts (P1-T8). A separate assertion loads the embedded default and checks that `connection_models` shows those facts for a listed release id.
- **LR-04 decided:** a documented refusal code reaches the tool text through `LunaRouteFailure.Error()`.

## Review Focus
- Non-admin MCP caller → `forbidden: admin only`, and the gateway sees no request.
- Unknown connection → `connection "x" not found`.
- Gateway 401 / 429 / 503 → distinct messages; the key echoed by the gateway is not in the text.
- Table entry for a model the gateway does not list is not shown.
- `ds.providerFactory.ProbeSelector()` is the same instance as `ds.probeFactory` (one factory, not two).

package mcp

import (
	"context"

	"github.com/mark3labs/mcp-go/server"

const connectionModelsDescription = "List the models available through one connection (admin only), each with its vendor family and KNOWN capabilities: " +
	"task kinds (chat/agent), compatible agent backends (claude-code, opencode, codex, pi), context/output token limits and supported efforts. " +
	"Every capability field is either known (with an evidence reference) or explicitly \"unknown\"; unknown is not a guarantee, and availability in the listing does NOT imply task or backend compatibility. " +
	"Choose the model and the backend explicitly: nothing is recommended or auto-selected. LunaRoute agent profiles must name their backend and use pinned selection. " +
	"family is the model's actual vendor, aliases included: keep doer and judge on different vendors; an \"unresolved\" family is refused. Never returns credentials."

func registerConnectionModelsTool(srv *Server) {
	srv.AddTool(
		gomcp.NewTool("connection_models",
			gomcp.WithDescription(connectionModelsDescription),
			gomcp.WithString("name", gomcp.Required(), gomcp.Description("Connection name")),
		),
		connectionModelsHandler(srv),
	)
}

func connectionModelsHandler(srv *Server) server.ToolHandlerFunc {
	return func(ctx context.Context, request gomcp.CallToolRequest) (*gomcp.CallToolResult, error) {
		if srv.deps.ModelDiscovery == nil {
			return gomcp.NewToolResultError("model discovery not available"), nil
		}
		name, _ := request.GetArguments()["name"].(string)
		if name == "" {
			return gomcp.NewToolResultError("name is required"), nil
		}
		view, err := srv.deps.ModelDiscovery.Discover(ctx, name)
		if err != nil {
			// SECURITY: name only plus redacted text; never the key.
			connLogger(srv).Warn("connection_models failed", slog.String("connection", name), slog.String("error", provider.RedactLunaRoute(err.Error())))
			return discoveryErrorResult(name, err), nil
		}
		return MarshalResult(view)
	}
}

// discoveryErrorResult maps discovery failures to stable, actionable text.
// Classified gateway failures are already redacted by the LunaRoute classifier.
func discoveryErrorResult(name string, err error) *gomcp.CallToolResult {
	var failure *provider.LunaRouteFailure
	switch {
	case errors.Is(err, provider.ErrForbidden):
		return gomcp.NewToolResultError("forbidden: admin only")
	case errors.Is(err, provider.ErrUnauthenticated):
		return gomcp.NewToolResultError("authentication required")
	case errors.Is(err, provider.ErrConnectionNotFound):
		return gomcp.NewToolResultError(fmt.Sprintf("connection %q not found", name))
	case errors.As(err, &failure):
		return gomcp.NewToolResultError(fmt.Sprintf("connection %q: %s", name, failure.Error()))
	case errors.Is(err, provider.ErrLunaRouteStoredCredential):
		return gomcp.NewToolResultError(fmt.Sprintf("connection %q: %s", name, provider.ErrLunaRouteStoredCredential.Error()))
	case errors.Is(err, provider.ErrLunaRouteEndpoint):
		return gomcp.NewToolResultError(fmt.Sprintf("connection %q: %s", name, provider.ErrLunaRouteEndpoint.Error()))
	case errors.Is(err, provider.ErrSelectionPortsMissing):
		return gomcp.NewToolResultError("model discovery is not configured; contact the administrator")
	default:
		return gomcp.NewToolResultError(fmt.Sprintf("model listing for connection %q failed and the cause is unknown (see server logs)", name))
	}
}
