# LunaRoute Phase 1 · Task 9 — LunaRoute compatibility check (save + launch rule)

**Dependencies:** P1-T1–T3, P1-T5 and P1-T6–T8.

**Shared contract:** Read [README.md](README.md) for execution order, production provenance and the five-category RED → GREEN → REFACTOR gate. All required coverage/provenance sections below belong to this task's RED/GREEN cycle and commit; read the complete document before Step 1.

**Goal:** One pure domain rule that decides whether a LunaRoute route (kind, model, effective backend, context tier, effort, requested output tokens) may run, in the fixed order backend-enablement → grammar → family → table compatibility → axes → limits, each refusal a typed, actionable `LunaRouteRefusal`. A launch-time wrapper applies the same rule to an actual `ResolvedBinding`.

**Architecture:** New `domain/provider/lunaroute_validate.go`: `LunaRouteRoute`, `CheckLunaRouteRoute(caps, route)`, `CheckLunaRouteLaunch(caps, binding, maxOutputTokens)`, the temporary enablement set `lunaRouteEnabledBackends` (empty in phase 1; Phase 3 Task 3 enables `claude-code`/`opencode`; Phase 4 Tasks 3/5 enable `codex`/`pi`) and the exact-emission table `lunaRouteExactEffort` (the effort values each emission path can send verbatim; generic flooring is never used for LunaRoute). Task 10 feeds it at profile save/pin capture; Phase 2 Tasks 4–5 feed it at real chat/agent calls.

**Tech Stack:** Go 1.25, testify.

**Spec:** spec §Chat and agent workflows ("Settings known to conflict with the chosen model's capabilities are rejected"), §Failure behavior ("Incompatible selections stop without silently substituting") · **Design:** phase-1 §3.7(b), launch validation paragraph

## Global Constraints
- Order: (1) agent backend present and enabled → (2) LunaRoute grammar → (3) family resolved → (4) table task/backend not `unsupported` → (5) context tier default → (6) effort exact-emittable AND known-supported for this model/axis → (7) claude-code and opencode need known context+output limits (LR-05/LR-06 decided; Phase 4 Task 4 adds pi) → (8) requested max output tokens ≤ known output limit.
- `unknown` table facts are allowed except where (6)/(7) require positive knowledge.
- Never rewrites model/backend/effort (no substitution, no flooring).
- Exact emission table (from current emitters): chat (openrouter `reasoning_effort`) → none, low, medium, high, max; claude-code (`CLAUDE_CODE_EFFORT_LEVEL` / `MAX_THINKING_TOKENS=0`) → none, low, medium, high, xhigh, max; codex (`-c model_reasoning_effort`, none→"minimal" is lossy) → low, medium, high, xhigh; pi (`--thinking`, none→off) → none, low, medium, high, xhigh, max; opencode (emits nothing) → no non-default effort, including `none`.
- `caps == nil` is a wiring fault: `ErrSelectionPortsMissing`.

## Review Focus
- Agent profile with backend `""` (relying on deployment default) → `ErrLunaRouteBackendRequired`, never silently the default.
- `xhigh` on chat → refused (openrouter would floor it to high).
- `none` on codex → refused (would become "minimal").
- Effort known for `chat` but requested on `opencode` axis → refused (facts are per axis).
- `MaxOutputTokens` set but output limit unknown → allowed (no known conflict).

// EnableLunaRouteBackendsForTest temporarily enables backends for a test.
func EnableLunaRouteBackendsForTest(t *testing.T, backends ...string) {
	t.Helper()
	saved := lunaRouteEnabledBackends
	t.Cleanup(func() { lunaRouteEnabledBackends = saved })
	next := map[string]bool{}
	for k, v := range saved {
		next[k] = v
	}
	for _, b := range backends {
		next[b] = true
	}
	lunaRouteEnabledBackends = next

}

package provider

import (
	"context"
	"fmt"
	"slices"
	"strings"

	"github.com/arbitron/arbitron/domain/modelidentity"
	"github.com/arbitron/arbitron/domain/workflow"
)

// LunaRouteRoute is one prospective or actual LunaRoute execution route.
// Backend is the effective agent backend ("" for chat). MaxOutputTokens is a
// request-level setting (0 = not requested).
type LunaRouteRoute struct {
	Kind            ProfileKind
	Model           string
	Backend         string
	ContextWindow   ContextWindow
	Effort          Effort
	MaxOutputTokens int
	RequestedSettings []string
}

// ErrLunaRouteModelSpelling refuses a model that is not a verified fixed
// LunaRoute catalog spelling. It wraps ErrSpecificVersionUnavailable so pin
// preflight keeps classifying it as a refusal.
var ErrLunaRouteModelSpelling = fmt.Errorf("%w: LunaRoute model is not a verified fixed catalog spelling", ErrSpecificVersionUnavailable)

// lunaRouteEnabledBackends is the temporary per-phase enablement gate: an agent
// backend runs LunaRoute only once its execution path exists. Phase 1 enables
// none; phase 3 adds claude-code and opencode; phase 4 adds codex and pi.
var lunaRouteEnabledBackends = map[string]bool{}

// LunaRouteBackendEnabled reports whether backend may carry LunaRoute routes.
func LunaRouteBackendEnabled(backend string) bool { return lunaRouteEnabledBackends[backend] }

// lunaRouteExactEffort lists, per emission path, the efforts that path sends
// verbatim. LunaRoute never uses generic flooring: anything else is refused.
var lunaRouteExactEffort = map[string]map[Effort]bool{
	LunaRouteChatAxis:          {EffortNone: true, EffortLow: true, EffortMedium: true, EffortHigh: true, EffortMax: true},
	workflow.BackendClaudeCode: {EffortNone: true, EffortLow: true, EffortMedium: true, EffortHigh: true, EffortXHigh: true, EffortMax: true},
	workflow.BackendCodex:      {EffortLow: true, EffortMedium: true, EffortHigh: true, EffortXHigh: true},
	workflow.BackendPi:         {EffortNone: true, EffortLow: true, EffortMedium: true, EffortHigh: true, EffortXHigh: true, EffortMax: true},
	workflow.BackendOpencode:   {},
}

func evidenceNote(ev string) string {
	if ev == "" {
		return ""
	}
	return " (evidence: " + ev + ")"
}

// CheckLunaRouteRoute applies the LunaRoute save/launch rule in a fixed order:
// lunaRouteNeedsLimits lists the backends whose LunaRoute launch emits model
// limits and therefore refuses unknown ones (LR-05/LR-06 decisions; Phase 4
// Task 4 adds workflow.BackendPi).
var lunaRouteNeedsLimits = map[string]bool{workflow.BackendClaudeCode: true, workflow.BackendOpencode: true}

// backend enablement, grammar, family, table compatibility, axes, limits.
func CheckLunaRouteRoute(caps LunaRouteCapabilities, r LunaRouteRoute) error {
	if caps == nil {
		return fmt.Errorf("%w: lunaroute capability table", ErrSelectionPortsMissing)
	}
	refuse := func(reason error, detail string) error {
		return &LunaRouteRefusal{Reason: reason, Model: r.Model, Backend: r.Backend, Detail: detail}
	}
	axis := LunaRouteChatAxis
	switch r.Kind {
	case ProfileKindAgent:
		if strings.TrimSpace(r.Backend) == "" {
			return refuse(ErrLunaRouteBackendRequired, "set backend to claude-code, opencode, codex or pi explicitly; deployment defaults never choose a LunaRoute backend")
		}
		if !lunaRouteEnabledBackends[r.Backend] {
			return refuse(ErrLunaRouteBackendUnsupported, fmt.Sprintf("LunaRoute on %s not yet supported in this release", r.Backend))
		}
		axis = r.Backend
	case ProfileKindChat:
	default:
		return refuse(ErrLunaRouteIncompatible, fmt.Sprintf("unknown profile kind %q", r.Kind))
	}
	if _, err := modelidentity.NewVersionResolver().SpecificVersion(context.Background(),
		VersionRequest{Model: r.Model, RouteProvider: CanonicalLunaRoute, ConnectionRef: "lunaroute", Backend: r.Backend}); err != nil {
		// The grammar message names the accepted spellings; carry it verbatim.
		return refuse(ErrLunaRouteModelSpelling, err.Error())
	}
	if modelidentity.ClassifyFamily(CanonicalLunaRoute, r.Model) == modelidentity.FamilyUnresolved {
		return refuse(ErrLunaRouteFamilyUnresolved, "establish vendor evidence before adding a reviewed alias mapping")
	}
	m, _ := caps.LunaRouteModel(r.Model)
	if f := m.Task(r.Kind); f.Support == SupportUnsupported {
		return refuse(ErrLunaRouteIncompatible, fmt.Sprintf("the capability table marks %s tasks unsupported%s; choose another model", r.Kind, evidenceNote(f.Evidence)))
	}
	if r.Kind == ProfileKindAgent {
		if f := m.Backend(r.Backend); f.Support == SupportUnsupported {
			return refuse(ErrLunaRouteIncompatible, fmt.Sprintf("the capability table marks backend %s unsupported%s; choose another backend or model", r.Backend, evidenceNote(f.Evidence)))
		}
	}
	if r.ContextWindow != "" && r.ContextWindow != ContextDefault {
		return refuse(ErrLunaRouteAxisUnsupported, fmt.Sprintf("context %q is a Claude-native switch, not a LunaRoute model limit; set context to default", r.ContextWindow))
	}
	if r.Effort != "" && r.Effort != EffortDefault {
		if !r.Effort.Valid() {
			return ErrInvalidEffort
		}
		if !lunaRouteExactEffort[axis][r.Effort] {
			return refuse(ErrLunaRouteAxisUnsupported, fmt.Sprintf("effort %q has no exact emission on %s; set effort to default or a level that path sends verbatim", r.Effort, axis))
		}
		if f := m.Effort(axis); !f.Known || !slices.Contains(f.Levels, r.Effort) {
			return refuse(ErrLunaRouteAxisUnsupported, fmt.Sprintf("effort %q is not known to be supported for this model on %s; set effort to default or record evidence in the capability table", r.Effort, axis))
		}
	}
	if r.Kind == ProfileKindAgent && lunaRouteNeedsLimits[r.Backend] && (!m.ContextTokens.Known() || !m.OutputTokens.Known()) {
		return refuse(ErrLunaRouteLimitsUnknown, r.Backend+" on LunaRoute needs known context and output limits for this model in the capability table (lunaroute_models)")
	}
	if r.MaxOutputTokens > 0 && m.OutputTokens.Known() && r.MaxOutputTokens > m.OutputTokens.Tokens {
		return refuse(ErrLunaRouteSettingConflict, fmt.Sprintf("max tokens %d exceeds the model's known output limit %d", r.MaxOutputTokens, m.OutputTokens.Tokens))
	}
	for _, setting := range r.RequestedSettings {
		if f := m.RequestSettings[setting]; f.Support == SupportUnsupported {
			return refuse(ErrLunaRouteSettingConflict, fmt.Sprintf("request setting %s is unsupported%s", setting, evidenceNote(f.Evidence)))
		}
	}
	return nil
}

// CheckLunaRouteLaunch applies CheckLunaRouteRoute to an actual binding (after
// pins and backend precedence) plus the hosted-endpoint check. It performs no
// I/O and is a no-op for non-LunaRoute bindings.
func CheckLunaRouteLaunch(caps LunaRouteCapabilities, b ResolvedBinding, maxOutputTokens int) error {
	return CheckLunaRouteRequest(caps, b, maxOutputTokens, nil)
}

func CheckLunaRouteRequest(caps LunaRouteCapabilities, b ResolvedBinding, maxOutputTokens int, requestedSettings []string) error {
	if !IsLunaRoute(b.Provider) {
		return nil
	}
	if _, err := NormalizeLunaRouteBaseURL(b.BaseURL); err != nil {
		return err
	}
	route := LunaRouteRoute{Kind: b.Kind, Model: b.Model, ContextWindow: b.ContextWindow, Effort: b.Effort, MaxOutputTokens: maxOutputTokens, RequestedSettings: requestedSettings}
	if b.Kind == ProfileKindAgent {
		if !b.BackendExplicit {
			return &LunaRouteRefusal{Reason: ErrLunaRouteBackendRequired, Model: b.Model, Detail: "select a backend explicitly in the profile or node; deployment defaults do not choose LunaRoute backends"}
		}
		route.Backend = strings.TrimSpace(b.Backend)
	}
	return CheckLunaRouteRoute(caps, route)
}
